# Computing left global dimension with cyclic modules

Module `StacksFrontier.RingTheory.GlobalDimension.Cyclic`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

A bound on the projective dimensions of cyclic modules already bounds the projective dimensions of all modules over the ring.

`ringGlobalDimension_lt_tfae`, proved by `Stacks.GlobalDimension.CyclicModules.solution`, gives four equivalent conditions for a ring R and a natural number n.

1. The supremum of projective dimensions of left R-modules is strictly below n.
2. Every left R-module has projective dimension strictly below n.
3. Every finitely generated left R-module has projective dimension strictly below n.
4. Each quotient R/I by a left ideal I has projective dimension strictly below n.

To pass from cyclic modules to arbitrary modules, the proof well-orders the elements of a module and filters it by the spans of initial segments. Each graded piece is generated by the image of one element, so the projective-dimension bound for a well-ordered filtration gives the desired bound.

The Lean statement uses `HasProjectiveDimensionLT`, so the Stacks bound ≤ n is obtained by using n + 1. The formal statement includes the strict bound at zero. The supremum and the quotients R/I use the universe of R. Conditions (2) and (3) use a possibly different universe v with `Small.{v} R`, and linear equivalences transport the bounds across universes. The theorem allows noncommutative rings and concerns left modules.

The equivalence is Tag 065T and the invariant is from Tag 00O6. The filtration argument uses Tag 0D1U and is attributed to M. Auslander, *On the dimension of modules and algebras. III. Global dimension*, Nagoya Math. J. **9** (1955), 67–77. The file also cites EGA 0 17.2.8.
