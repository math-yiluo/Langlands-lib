# A shared Artin–Schreier extension for base-field parameters

Module `StacksFrontier.RingTheory.DiscreteValuationRing.EppConstantNumeratorFamily`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

For a finite family of DVR towers A → Bᵢ → Cᵢ, this file constructs one extension of the common fraction field K that serves all the Artin–Schreier layers whose parameters have a base-field part ξᵢ ∈ K and an integral part bᵢ ∈ Bᵢ.

- `exists_artinSchreierSplitting_forall` puts roots of all equations wᵖ − w = ξᵢ in a single finite separable extension of a field of characteristic p > 1.
- `SplitConstantClassSolvable` expresses that a prescribed finite separable K₂/K splitting ξ solves the layer with parameter ξ + b. The theorem `splitConstantClassSolvable` proves this for prime p, complete A and B, perfect residue field of A, weakly unramified A → B, and a finite layer generated by the given Artin–Schreier root. Its middle-layer lemma treats the analogous splitting over a finite separable extension of Frac(B).
- `exists_finite_extension_forall_isWeakSolution_of_base_parameter_add_integral` gives one finite K₂/K and a weak solution over it for every family member under these tower and presentation hypotheses. `exists_finite_extension_forall_isWeakSolution_of_constant_laurent` obtains the presentation from Laurent coefficients with compatible lifts modulo the common depth N and pᴺ-th roots coming from the base residue field.

The splitting field is built by iterating separable Artin–Schreier splitting fields. At each field factor, subtracting the base root leaves an integral parameter, giving ramification index one. The weak solutions compose through the middle rings.

The family results use a single universe for the towers and extension. The docstrings of the file call `SplitConstantClassSolvable` an open obligation, but `splitConstantClassSolvable` proves it. The module docstring also announces a reduction of combinations of base parameters, a trichotomy for their Artin–Schreier extensions and a producer from Frobenius presentations, which the file does not contain.

The file concerns a branch of Tag 09F9.
