# Adjoining a root with irreducible residue polynomial

Module `StacksFrontier.RingTheory.DiscreteValuationRing.MonicResidueIrreducible`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

Let A be a discrete valuation ring with fraction field K and residue field κ. For a monic polynomial p of positive degree with irreducible reduction over κ, the file studies B = A[X]/(p) as a discrete valuation ring and computes its ramification and residue degrees.

- `AdjoinRoot.irreducible_of_irreducible_map_residue` proves irreducibility over A, and `AdjoinRoot.prime_of_irreducible_map_residue` makes p prime. The quotient domain is supplied by `AdjoinRoot.isDomain_of_irreducible_map_residue`.
- `AdjoinRoot.isDiscreteValuationRing` gives the discrete valuation ring structure. `AdjoinRoot.irreducible_algebraMap` preserves uniformizers, and `AdjoinRoot.ramificationIdx_eq_one` gives ramification index one.
- `AdjoinRoot.inertiaDeg_eq_natDegree` computes the inertia degree as deg p. `AdjoinRoot.finrank_residueField_eq_natDegree` expresses this as [κ(B) : κ] = deg p. `AdjoinRoot.eval₂_residue_root_eq_zero` reduces the adjoined root's defining equation to the residue field. The helper `inertiaDeg_eq_finrank_residueField` identifies inertia degree with residue field degree for any local homomorphism of local rings.

Monicity lets a factorization descend to the residue field. The quotient is finite with maximal ideal generated by the image of a base uniformizer. The power basis and the local fundamental identity give the residue degree once the index is known.

The discrete valuation and degree statements take local ring and domain instances on B. The residue field degree statement also takes a localness instance on the structure map, available from the monic construction. The ramification assertion is weak unramifiedness, meaning index one. The hypotheses allow an inseparable residue extension. The module docstring also announces irreducibility of p over K, which the file does not contain.

Tag 09E4 is cited for weak unramifiedness. Tag 09EX is cited for the related case X^q − a, with the residue of a not a q-th power, which `StacksFrontier.RingTheory.DiscreteValuationRing.AdjoinPthRoot` states for the subring A[α] of K[X]/(X^q − a) generated by a root α; neither result is literally an instance of the other.
