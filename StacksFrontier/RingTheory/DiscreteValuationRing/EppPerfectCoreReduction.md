# Perfect-core reduction for complete discrete valuation rings

Module `StacksFrontier.RingTheory.DiscreteValuationRing.EppPerfectCoreReduction`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

This file proves the complete cases of Epp’s weak-solution theorem in positive equal characteristic and in mixed characteristic. It reduces an arbitrary base residue field to its perfect core and transports a weak solution back to the original base.

`exists_cohenRing_lift` lifts a prescribed homomorphism of residue fields from a Cohen domain Λ to a complete local ring A. It assumes residue characteristic p on Λ and maximal ideal generated by p. The lift is a ring homomorphism Λ → A inducing the prescribed map. The private lemma `eppCondition_of_perfectCore_base` shows that Epp’s separability condition on the upstairs perfect core descends to a smaller base whose residue map identifies it with the original base’s perfect core.

`exists_finite_extension_isWeakSolution_of_cohenRing_proved` treats a Cohen base with perfect residue field and maximal ideal generated by p. `exists_finite_extension_isWeakSolution_of_powerSeries_proved` treats k⟦X⟧ for a perfect field k of characteristic p. Both take a complete DVR extension satisfying `EppCondition` and return a finite fraction-field extension with a weak solution.

For an extension A ⊆ B of complete DVRs with residue characteristic p prime and `hepp : EppCondition A B p`, the two complete-case theorems remove perfectness of the base residue field.

- `exists_finite_extension_isWeakSolution_of_complete_mixedCharacteristic_proved` assumes p is nonzero in A and produces a finite extension F/K and a weak `IntegralClosureBaseChange` solution.
- `exists_finite_extension_isWeakSolution_of_complete_equalCharacteristic_proved` assumes p vanishes in A and takes a uniformizer π. It also returns a pⁿ-th root ρ of π in F with minimal polynomial X^(pⁿ) − π and F separable over K(ρ).

The Cohen lift uses formal smoothness along successive square-zero adic quotients and completeness to take the limit. The perfect-residue cases interpose a DVR with the upstairs residue field and use the tower theorem with `familyTowerSolvable_all_proved`. For arbitrary residue fields the proof embeds a Cohen or power-series ring over the perfect core. The equal-characteristic proof tracks the root through a field factor of the scalar extension to retain its separability datum.

The endpoint statements use one universe for the rings, fraction fields and base change. The Cohen lifting lemma concerns a single prescribed residue map.

References include EGA 0 19.8.6 (i), in the Cohen lifting special case, and SGA 7 IX 12.8 for the perfect-core Cohen subring.
