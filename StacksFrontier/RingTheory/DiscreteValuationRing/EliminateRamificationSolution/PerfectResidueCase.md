# Eliminating ramification over a perfect residue field

Module `StacksFrontier.RingTheory.DiscreteValuationRing.EliminateRamificationSolution.PerfectResidueCase`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

For an extension of discrete valuation rings A → B with fraction fields K → L, the file uses perfection of the residue field of A to strengthen a weak solution to a solution. A solution requires maximal-ideal-adic formal smoothness of the induced maps between the localizations of the two integral closures.

## Results

- `exists_finite_extension_isSolution_of_charZero` gives a finite K-extension K₁ and an `IntegralClosureBaseChange` satisfying `IsSolution` if the residue field of A has characteristic zero.
- `exists_finite_extension_isSolution_of_perfectField` gives the same conclusion when the residue field of A is perfect and the residue field of B is essentially of finite type over it.
- `formallySmoothNAdic_integralClosure_of_isSolution` transfers a solution for a finite K₁/K to the canonical integral closures of A in K₁ and of B in the reduction of L ⊗[K] K₁. The comparison map must agree with the tensor inclusion on elements (`hf`). It gives adic formal smoothness at every maximal ideal of the target and its contraction.

The proofs upgrade ramification index one using separability over perfect residue fields and the DVR criterion for adic formal smoothness. In positive residue characteristic p, an element of the finitely generated residue extension with pⁿ-th roots for every n is algebraic because the successive roots generate an ascending chain inside a finite algebraic extension of the field generated by the element. Perfection then makes the element separable. Transport lemmas identify the localized maps under ring isomorphisms and move the adic lifting property across test universes using `ULift`.

Both existence theorems assume `hEpp`, Epp’s theorem providing a weak solution when its residue-field condition holds. In residue characteristic zero that condition is vacuous. The lifting property is `RingHom.FormallySmoothNAdic`, which tests square-zero lifting diagrams whose map from the target ring to the square-zero quotient kills a positive power of the target maximal ideal. The solutions permit any test universe.
