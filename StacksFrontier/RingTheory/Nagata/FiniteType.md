# Nagata rings and finite-type algebras

Module `StacksFrontier.RingTheory.Nagata.FiniteType`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

The file proves Nagata's theorem for commutative rings. The main implication is stability of the Nagata condition under passing to a finite-type algebra.

`isNagataRing_tfae`, proved by `Stacks.Nagata.FiniteTypeTFAE.solution`, gives the equivalence of three conditions on `R`.

1. `R` is Nagata.
2. Every finite-type `R`-algebra is Nagata.
3. `R` is universally Japanese and Noetherian.

The private `isJapaneseRing_of_monogenic` proves that a domain generated by one element over a Nagata domain is Japanese when the base map is injective. The other helpers apply this to prime quotients of polynomial rings and pass to quotients, using contraction of primes and the image of the polynomial variable as the generator.

Presenting a finite-type algebra as a quotient of a polynomial ring in finitely many variables reduces the main implication to the monogenic result. A transcendental generator gives a polynomial ring, where the Japanese property is already available. For an algebraic generator and a finite extension of the target fraction field, the integral closure of the base in that extension is a finite normal Nagata domain. Adjoining the generator to this new base reduces the desired finiteness to `MonogenicN1.module_finite_integralClosure`. The other implications use the identity algebra, the zero prime of a domain, and Noetherianity of finite-type algebras over a Noetherian ring.

Nagata is the class `StacksIsNagataRing` and universally Japanese the class `IsUniversallyJapaneseRing`; the docstrings and the note of the Stacks attribute, reproduced in the table, write the first without the prefix `Stacks`. The list quantifies over finite-type algebras in the universe of `R`. The domain and injectivity hypotheses belong to the monogenic reduction, while the equivalence applies to any commutative ring.

References include Tag 0334 for the equivalence, Tag 032R for the definitions, Tag 032O for polynomial rings, and Tag 032T for the Nagata property of the finite integral closure used in the algebraic branch. The table cites EGA IV 7.7.2 (a) ⇔ (b) and EGA IV 10.4.10 for a more general result.
