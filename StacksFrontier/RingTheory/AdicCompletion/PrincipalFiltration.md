# The filtration by powers of a principal ideal

Module `StacksFrontier.RingTheory.AdicCompletion.PrincipalFiltration`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

The powers of a principal ideal give the submodules used to form the adic completion of a commutative ring R. If the generator π of the ideal is a nonzerodivisor, multiplication by π shifts this filtration by one step.

`Module.pow_smul_top_eq_span_pow` identifies IⁿR with the ideal generated by πⁿ for every natural n when I is generated by π. It uses the multiplication rule for principal ideals.

`Module.mul_mem_span_pow_succ_iff` says that πa belongs to the ideal generated by πⁿ⁺¹ exactly when a belongs to the ideal generated by πⁿ. The forward implication cancels π using `IsSMulRegular R π`. The reverse implication multiplies the equation a = cπⁿ by π and keeps the witness c.
