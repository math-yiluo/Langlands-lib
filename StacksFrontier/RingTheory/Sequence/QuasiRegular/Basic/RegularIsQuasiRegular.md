# The ideal of a list with a first element

Module `StacksFrontier.RingTheory.Sequence.QuasiRegular.Basic.RegularIsQuasiRegular`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

For a commutative ring R, an element f of R and a list gs in R, `Stacks.QuasiregularSequence.ofList_cons_sup` shows that the ideal generated by the entries of f :: gs is the sum of the principal ideal (f) and the ideal generated by gs: `Ideal.ofList (f :: gs) = Ideal.span {f} ⊔ Ideal.ofList gs`. The proof writes the set of entries of f :: gs as that of gs with f inserted and applies `Ideal.span_insert`.

The module docstring and the section comments describe multi-index powers of a list, a coefficient form of quasi-regularity, its induction steps and the theorem that regular sequences are quasi-regular (Stacks 00LN); none of these is in the file, which keeps only this lemma of the cons step and, after it, a comment about a step that is not there.
