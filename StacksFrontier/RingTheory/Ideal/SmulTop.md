# Ideal multiples of modules and quotients

Module `StacksFrontier.RingTheory.Ideal.SmulTop`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

This file relates the submodule generated by ideal multiples to surjections and ring quotients. Over a commutative ring R, `smul_top_ne_top_of_surjective` says that if f is a surjective linear map from M to N and IN is a proper submodule, then IM is proper.

For ideals I and J of R, `smul_top_quotient_eq_top_iff` says that J acting on R/I generates all of R/I exactly when I + J = R. The alias `ideal_smul_top` records that the ideal multiples of R by I give I itself.

The proofs use that taking the image commutes with ideal multiplication. The image of IM under the surjection f is IN, and the submodule generated by J acting on R/I is the image of J under the quotient map.
