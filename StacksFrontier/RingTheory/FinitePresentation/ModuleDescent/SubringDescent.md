# Descent to a finite-type subring of the base

Module `StacksFrontier.RingTheory.FinitePresentation.ModuleDescent.SubringDescent`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

A finitely presented algebra and a finitely presented module over it can be defined together over a subring of the original base generated by finitely many coefficients over ℤ.

`Algebra.exists_subring_finiteType_int_isPushout_isBaseChange`, proved by `Stacks.FinitePresentation.ModuleDescent.solution`, assumes a finitely presented map of commutative rings `R → S` and a finitely presented `S`-module `M`. It gives a finite-type ℤ-subring `R₀ ⊆ R`, a finite-type `R₀`-algebra `S₀`, and a finite `S₀`-module `M₀`. The map `S₀ → S` exhibits `S ≅ R ⊗[R₀] S₀` as an `Algebra.IsPushout`. The linear map `f : M₀ →ₗ[S₀] M` exhibits `M ≅ S ⊗[S₀] M₀` via `IsBaseChange` with the compatible restricted scalars.

The proof takes a polynomial presentation of `S` and a finite matrix presenting `M`. The relations and polynomial lifts of the matrix entries determine the generators of `R₀`. Over that subring the same equations give the algebra model, and the cokernel of the lifted matrix gives the module model. The proof uses base change of the polynomial presentation and preservation of the cokernel.

The statement gives a single subring model. The directed-system form in the reference is recovered by taking finite-type subrings containing `R₀` and base changing both models. The explicit output finiteness conditions are finite type for `S₀` and finite generation for `M₀`. The rings `R` and `S` and the models `S₀` and `M₀` share a universe, while `M` can lie in another.
