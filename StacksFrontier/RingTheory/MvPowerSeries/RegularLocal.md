# The ideal of the variables in a power series ring

Module `StacksFrontier.RingTheory.MvPowerSeries.RegularLocal`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

For any commutative ring R and n : ℕ, `MvPowerSeries.span_X_eq_ker_constantCoeff` proves that in R⟦x₁, …, xₙ⟧, modelled as `MvPowerSeries (Fin n) R`, the ideal generated by the variables is the kernel of the constant coefficient map: a power series with vanishing constant term is a combination of the variables. One inclusion is immediate. The other is proved by induction on n: splitting off one variable with `MvPowerSeries.finSuccEquiv` writes such a series as a series in the remaining variables, again with vanishing constant term, plus that variable times a series.

The module docstring still announces that the power series ring over a field is a regular local ring; that theorem, and the description of the maximal ideal and the Krull-dimension bound behind it, are not in the file.
