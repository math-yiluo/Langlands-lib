# Noether normalization over fields

Module `StacksFrontier.RingTheory.NoetherNormalization`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

This file constructs finite maps from polynomial algebras over a field, with the normalizing elements in the integer subalgebra generated by a given finite set of generators.

- `Stacks.RingTheory.NagataNormalization.exists_isIntegral_aeval` starts with n+1 generators of an algebra over a field and a nonzero polynomial relation. It finds n elements in the ℤ-subalgebra generated by the original tuple such that evaluation from the polynomial ring in n variables is integral.
- `exists_finite_inj_aeval_ringKrullDim_eq_of_adjoin_eq_top` starts with a nonzero commutative k-algebra S over a field k and a finite generating set s. It finds r elements of `Algebra.adjoin ℤ s` for which evaluation k[Y₁,…,Yᵣ] → S is injective and module-finite, and r equals the Krull dimension of S. It restates `Stacks.RingTheory.NagataNormalization.solution`.

The proof inducts on the number of generators. The substitution in a relation uses powers growing fast enough to give each monomial a distinct degree in one variable, so the leading coefficient is a unit and that variable is integral over the reduced set of generators. Integrality gives finiteness because S is of finite type, and the dimension follows by invariance under injective integral maps.

The later module docstrings of the file also describe a separate lemma computing the dimension from any injective finite evaluation map, and Noether normalization over a domain (Tag 07NA); the file contains neither.
