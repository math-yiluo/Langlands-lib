# Universal homeomorphisms of schemes

Module `StacksFrontier.AlgebraicGeometry.Morphisms.UniversalHomeomorphism.Defs.Basic`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

This file defines universal homeomorphisms of schemes.

`AlgebraicGeometry.UniversalHomeomorphism` is a proposition-valued class on a scheme morphism `f : X ⟶ Y`. Its field `universally_isHomeomorph` requires every base change of `f` to induce a homeomorphism on underlying spaces. The lemma `universalHomeomorphism_iff`, generated by `mk_iff`, unfolds this condition, which quantifies over all pullback squares via `MorphismProperty.universally`.

The module docstring also lists stability under composition among the main results; that lemma is not in this file.

References for the definition are Tag 04DD, EGA IV 2.4.2, and SGA 4 VIII 1.4.
