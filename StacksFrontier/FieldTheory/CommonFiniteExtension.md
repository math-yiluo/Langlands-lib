# Common finite extensions of a field

Module `StacksFrontier.FieldTheory.CommonFiniteExtension`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

A finite family of finite extensions of K can be embedded over K into a single finite extension.

`exists_finiteDimensional_algHom_forall` constructs such a field. It embeds the fields into an algebraic closure and takes the compositum of their images. Finiteness follows from finiteness of the family. The base field, the member fields, and the common field share a universe. The finite index type may have its own universe.

The module docstring also describes a separable version of this result and the finiteness of the extension generated by finitely many algebraic elements; neither is in the file. The table records Tag 09GH for Mathlib’s `IntermediateField.finiteDimensional_adjoin`.
