# The norm quotient of an abstract valued norm

Module `Nyll.ValuedFieldTheory.LocalField.DiscreteValuationField.Norm.Quotients`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The file computes the quotient of a group by the image of an abstract norm map. The setting is the library's `ValuedNorm`: groups `G` and `H` with integer-valued valuations `v_G`, `v_H` (`MultiplicativeIntegerValuation`), a homomorphism `N.toHom : H →* G` and a natural number `f = N.residueDegree` with `v_G(N y) = f · v_H(y)`. Write `G⁰` for the elements of valuation zero (`vG.zeroSubgroup`) and `normSubgroup` for the image of `N`. Under the right hypotheses `G / normSubgroup` is cyclic of order `f`, generated by the class of a uniformizer.

## Main results

- `residueDegree_dvd_valuation_of_mem_normSubgroup`: the valuation of every norm is divisible by `f`. Given a uniformizer of `H`, every multiple of `f` occurs, and every norm is an element of `G⁰` times the norm of a power of that uniformizer.
- `mem_normSubgroup_iff_residueDegree_dvd_val_of_zeroSubgroup_le`: given a uniformizer of `H` and `hzero : G⁰ ≤ normSubgroup`, an element is a norm if and only if `f` divides its valuation.
- `normQuotientEquivValueModResidueDegree` and `normQuotientEquivZMod`: under the same hypotheses, a uniformizer of `G` and normality of `normSubgroup`, an isomorphism `G / normSubgroup ≅ ℤ/fℤ`, also as `Multiplicative (ZMod f)`, sending the class of `x` to `v_G(x)` mod `f`. `card_normQuotient_eq_residueDegree`: the quotient has `f` elements when `f ≠ 0` and the quotient is finite.
- `normQuotient_closure_uniformizerClass_eq_top` and its companions: the quotient is generated by the class of a uniformizer `ϖ_G`, whose powers `ϖ_G^m` and `ϖ_G^n` agree exactly when `f` divides `m − n`.
- The same computation passes through `G / G⁰`: `zeroQuotientModuloResidueDegreeClassEquivValueModResidueDegree` identifies `G / G⁰` modulo the classes of valuation divisible by `f` with `ℤ/fℤ`, and `zeroQuotientModuloNormClassEquivNormQuotient` is the third isomorphism theorem `(G/G⁰)/(normSubgroup/G⁰) ≅ G/normSubgroup`.
- `normSubgroup_eq_sup_of_source_decomposition`: if every element of `H` is `u · ϖ^n` with `u` in a subgroup `U`, `N(U) = P` and `N(ϖ) = γ`, then `normSubgroup = P ⊔ ⟨γ⟩`. The file calls this the group-theoretic core of finite Lubin–Tate norm-subgroup formulas. If moreover `P ⊆ G⁰` and `v_G(γ) ≠ 0`, then for `x`, `y` of equal valuation, `x / y` is a norm if and only if it lies in `P` (`normSubgroup_quotient_iff_targetSubgroup_of_equal_valuation`).
- Helpers give membership and equality criteria in left- and right-quotient form and simp lemmas for the equivalences.

## Watch for

- Everything is abstract group theory; no field extension appears. `ValuedNorm` and `MultiplicativeIntegerValuation` are the library's own structures.
- The identification with `ℤ/fℤ` rests on the hypothesis `hzero`, that every element of valuation zero is a norm. The file assumes it and does not prove it for any extension.
- The groups need not be commutative: normality of `normSubgroup` is an instance hypothesis wherever a quotient by it is formed.
