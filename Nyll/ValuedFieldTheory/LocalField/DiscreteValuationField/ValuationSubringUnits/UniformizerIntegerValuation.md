# The integer valuation defined by a uniformizer of a complete DVF

Module `Nyll.ValuedFieldTheory.LocalField.DiscreteValuationField.ValuationSubringUnits.UniformizerIntegerValuation`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a complete discretely valued field `F : CompleteDVF K` of the library, whose valuation takes values in an abstract value group, a chosen uniformizer `π` turns the valuation into an integer valuation on `Kˣ`: the value of each unit is an integral power of `v(π)`, and the exponent is the integer valuation.

## Definitions and results

- `fieldUnitValueUnit F x`: the value `v(x)` of a unit `x`, as a unit of the value group; multiplicative.
- `uniformizerValueUnit F hπ`: the value `v(π)` as a unit of the value group.
- `exists_uniformizerValueUnit_zpow_eq_fieldUnitValueUnit`: for every `x : Kˣ` there is `n : ℤ` with `v(π)ⁿ = v(x)`.
- `uniformizerValueUnit_zpow_inj`: this `n` is unique, since `0 < v(π) < 1`.
- `uniformizerValueExponent F hπ x`: the chosen exponent `n`.
- `multiplicativeIntegerValuationOfUniformizer F hπ`: the integer valuation `x ↦ n` on `Kˣ`, as a `MultiplicativeIntegerValuation`.
- `multiplicativeIntegerValuationOfUniformizer_isUniformizer`: `π` has integer valuation `1`.
- `multiplicativeIntegerValuationOfUniformizer_zeroSubgroup_eq_unitGroup`: the units of integer valuation `0` are exactly the units of the valuation ring.

## Proofs

Existence of the exponent uses that the value group of the valuation is generated by `v(π)` (`IsUniformizer.zpowers_eq_valueGroup`); uniqueness uses injectivity of integer powers of a positive element different from `1` (`zpow_right_inj₀`), applied to `0 < v(π) < 1`.

## Watch for

- The exponent is chosen with `Classical.choose`, so the valuation is noncomputable; it is determined uniquely only through `uniformizerValueUnit_zpow_inj`.
- The sign convention makes `π` have valuation `+1`; the valuation is defined on `Kˣ` only, and the file states no positivity result for nonzero elements of the maximal ideal.
