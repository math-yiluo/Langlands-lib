# Additive form of a group isomorphism

Module `Nyll.ValuedFieldTheory.LocalField.NonarchimedeanLocalField.AdditiveEquiv`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The file contains a single definition. For groups `A` and `B` and a group isomorphism `e : A ≃* B`, `LocalFieldTheory.additiveEquivOfMulEquiv e : Additive A ≃+ Additive B` is the same map viewed as an isomorphism of the additive recodings of `A` and `B`. It is Mathlib's `MulEquiv.toAdditive e` under a library name.
