# Trivial inertia in a compositum of number fields

Module `Nyll.ValuedFieldTheory.Ramification.HilbertRamification.Dedekind.CompositumUnramified`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The file gives criteria for a prime of a finite Galois extension of number fields `M/K` to be unramified: trivial inertia can be checked on normal subextensions that generate `M`, and trivial inertia follows from ramification index one and is equivalent to Mathlib's `Algebra.IsUnramifiedAt`. The inertia group is the prime-ideal one of the Dedekind layer (`σx − x ∈ Q` for all integers `x`).

## Main results

- `inertiaGroup_eq_bot_of_restrictNormal_of_sup_eq_top`: if `A`, `B` are intermediate fields normal over `K` with `A ⊔ B = M`, and the inertia groups of `Q ∩ 𝓞_A` in `Gal(A/K)` and of `Q ∩ 𝓞_B` in `Gal(B/K)` are trivial, then the inertia group of `Q` in `Gal(M/K)` is trivial.
- `inertiaGroup_eq_bot_of_finset_adjoin_eq_top`: the same for a finite set `T ⊆ M` with `K(T) = M`, each `K(x)` (`x ∈ T`) normal over `K` and with trivial inertia at the prime below `Q`. The file's comment describes it as the form used for Kummer extensions generated by finitely many radicals.
- `inertiaGroup_eq_bot_of_ramificationIdx_eq_one`: for primes `P | p` with `p ≠ 0` and `P` maximal, `e(P|p) = 1` implies trivial inertia.
- `inertiaGroup_eq_bot_of_isUnramifiedAt` and `isUnramifiedAt_of_inertiaGroup_eq_bot`: for a maximal ideal `P` of `𝓞_M`, trivial inertia is equivalent to `Algebra.IsUnramifiedAt (𝓞 K) P`.
- `inertiaGroup_eq_bot_of_ramificationIdx_eq_one_int` and `isUnramifiedAt_int_of_inertiaGroup_eq_bot`: with base `ℤ`, for `K/ℚ` Galois, `e = 1` implies trivial inertia, and trivial inertia implies `Algebra.IsUnramifiedAt ℤ P`.

## Proofs

For the compositum criteria, an inertia element restricts to inertia elements of the normal subextensions, hence to the identity there, so it fixes a generating set of `M` and is trivial. The other results use `|I_P| = e`, available because residue fields of number fields are finite and therefore perfect, so the residue extension is separable.

## Points to watch

- In the compositum criteria `Q` is any ideal of `𝓞_M`; primality is not required.
- Both pieces must be normal over `K`; the criteria concern inertia groups only.
