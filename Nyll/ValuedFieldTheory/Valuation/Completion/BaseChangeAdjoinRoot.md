# Base change of a simple extension as an adjoined-root algebra

Module `Nyll.ValuedFieldTheory.Valuation.Completion.BaseChangeAdjoinRoot`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

If a field extension `L/K` has a power basis with generator `α`, then for any field `A` over `K` the scalar extension `A ⊗_K L` is canonically `A[X]/(f)`, where `f` is the minimal polynomial of `α` over `K` with coefficients mapped into `A`. This presentation is used to split scalar extensions of finite extensions.

## Main definitions and results

- `powerBasisBaseChange pb`: the power basis of `A ⊗_K L` over `A` generated by `1 ⊗ α`, with the same dimension.
- `minpoly_map_aeval_one_tmul`: `1 ⊗ α` is a root of the mapped minimal polynomial.
- `adjoinRootToBaseChange pb`: the `A`-algebra map `AdjoinRoot f → A ⊗_K L` sending the root to `1 ⊗ α`; it is surjective (`adjoinRootToBaseChange_surjective`).
- `adjoinRoot_baseChange_finrank_eq`: both sides have the same dimension over `A`.
- `adjoinRootEquivBaseChange pb : AdjoinRoot f ≃ₐ[A] A ⊗_K L` and its inverse `baseChangeEquivAdjoinRoot pb`, with the root corresponding to `1 ⊗ α`.

## Proof

The map is surjective because its image contains the base-changed power basis; since both sides are finite-dimensional over `A` of the same dimension, it is also injective.

## Points to watch

- `K`, `A` and `L` are all assumed to be fields; the result is stated for an extension given with a power basis, not for an arbitrary finite separable extension.
