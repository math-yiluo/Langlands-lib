# Extensions of an absolute value to an algebraic extension

Module `Nyll.ValuedFieldTheory.Valuation.Completion.AbsoluteValueExtensions`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let `v` be a nontrivial real absolute value on a field `K`, `K_v = v.Completion` its completion and `K̄_v = AlgebraicClosure K_v`. The file proves the classical description of the extensions of `v` to an algebraic extension `L/K`: each one is obtained by pulling back the unique absolute value `v̄` on `K̄_v` extending the completion absolute value on `K_v` along a `K`-embedding `L → K̄_v`, and two embeddings give the same extension exactly when they are conjugate over `K_v`.

## Main definitions and results

- `AbsoluteValueExtension v L`: absolute values `w` on `L` with `Extends v w` (`w` restricts to `v`). An extension of a nontrivial `v` is nontrivial.
- `absoluteValueExtension_algebraicClosureAbsoluteValue`: `v̄` on `K̄_v`, taken from the library's unique-extension theorem for the complete field `K_v`; it is invariant under `K_v`-automorphisms.
- `absoluteValueExtension_pullback v hv τ`: the absolute value `x ↦ v̄(τ x)` on `L`, for `τ : L →ₐ[K] K̄_v`; it extends `v`.
- `AbsoluteValueExtensionConjugateOverCompletion v τ τ'`: some `K_v`-automorphism `σ` of `K̄_v` has `τ' = σ ∘ τ`.
- `absoluteValueExtension_extension_exists_embedding` (part (i)): for `L/K` algebraic, every extension `w` equals the pullback along some `τ`.
- `absoluteValueExtension_pullback_eq_iff_conjugate` (part (ii)): pullbacks along `τ` and `τ'` agree if and only if `τ`, `τ'` are conjugate over `K_v`.
- `absoluteValueExtension_extension_theorem`: (i) and (ii) together.
- `AbsoluteValueExtension.extendToAlgebraicallyClosed`: an extension of `v` to `L` extends further to any algebraically closed `Ω` algebraic over `L`, with no finiteness hypothesis.

## Proof

For (i), the subfield of the completion `L_w` generated by `L` over `K_v` (the library's `algebraicLocalization`) is algebraic over `K_v`, so it embeds into `K̄_v`; uniqueness of extensions over the complete field `K_v` identifies `w` with the pullback. For (ii), an isometric `τ` extends to the completions, the image of that subfield lands in the dense copy of `K̄_v`, and two `K_v`-embeddings into an algebraic closure are conjugate (`absoluteValueExtension_algHom_conjugate_in_algClosure`).

## Points to watch

- Despite the module docstring's mention of finite extensions, the main statements only assume `L/K` algebraic.
- The algebraic closure is Mathlib's specific `AlgebraicClosure v.Completion`, and `v̄` is the library's construction, not a hypothesis.
- No nonarchimedean hypothesis is made; only nontriviality of `v` is assumed.
