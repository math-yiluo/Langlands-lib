# In finite degree, L·K_v is the whole completion L_w

Module `Nyll.ValuedFieldTheory.Valuation.Completion.FiniteLocalization`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let `L / K` be a finite extension, `v` a nontrivial real absolute value on `K` and `w` an absolute value on `L` extending it. The file shows that the subfield of the completion `L_w` generated by `K_v` and the image of `L` (the library's "algebraic localization") is all of `L_w`. No separability is assumed.

## Main definitions and results

- `absoluteValueExtension_completionNontriviallyNormedField` and `absoluteValueExtension_completionNormedAlgebra`: `K_v` as a nontrivially normed field, and `L_w` as a normed `K_v`-algebra through the isometric completion map.
- `absoluteValueExtension_localizationTensorHom`: the `K_v`-algebra map `K_v ⊗_K L → L_w`, `b ⊗ x ↦ b·x`; `absoluteValueExtension_localizationTensorHom_surjective`: it is surjective when `[L : K]` is finite.
- `absoluteValueExtension_finiteLocalization_eq_top`: the algebraic localization equals `⊤`.
- `LocalizedCompletion`: an abbreviation for the algebraic localization; `localizedCompletionModuleFinite`: it is finite over `K_v`; `localizedCompletionEquivCompletion`: the resulting `K_v`-algebra isomorphism onto `L_w`, which is the inclusion.

## Proof

The image of `K_v ⊗_K L` is a finite-dimensional `K_v`-subspace of the normed space `L_w`, hence closed, and it contains the dense image of `L`.

## Points to watch

The absolute value on `K` must be nontrivial (`IsNontrivial`); this is what makes finite-dimensional subspaces closed.
