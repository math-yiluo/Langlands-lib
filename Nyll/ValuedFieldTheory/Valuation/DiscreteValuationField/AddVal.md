# Two facts on the additive valuation of a discrete valuation ring

Module `Nyll.ValuedFieldTheory.Valuation.DiscreteValuationField.AddVal`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Two general lemmas about Mathlib's normalized additive valuation `addVal R : R → ℕ∞` on a discrete valuation ring `R`.

## Main results

- `IsDiscreteValuationRing.mem_maximalIdeal_pow_iff_addVal_ge`: `a ∈ 𝔪ⁿ` if and only if `n ≤ addVal R a`. Proof: `𝔪ⁿ` is generated by `ϖⁿ` for a uniformizer `ϖ`, and divisibility by `ϖⁿ` is read off the valuation.
- `IsDiscreteValuationRing.addVal_ringEquiv`: a ring automorphism `e` of `R` preserves the valuation, `addVal R (e a) = addVal R a`. Proof: `e` sends a uniformizer to a uniformizer, so it preserves the decomposition `a = u ϖⁿ`.
