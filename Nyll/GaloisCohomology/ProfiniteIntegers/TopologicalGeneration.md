# Topological generation of groups (class formation interface)

Module `Nyll.GaloisCohomology.ProfiniteIntegers.TopologicalGeneration`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a topological group `G`, the file provides, under the namespace `ClassFormation`, the notion of a set topologically generating `G` and the closed subgroup generated by a set. Every declaration is a thin wrapper around the corresponding one in the library's `ProCGroups.Generation`; nothing new is proved here.

- `TopologicallyGenerates X`: the closure of the abstract subgroup generated by `X` is all of `G`; `topologicallyGenerates_iff_dense` restates it as density of that subgroup.
- `closedSubgroupGenerated X`: the closed subgroup topologically generated by `X`; `closedSubgroupGeneratedMap` and `closedSubgroupGeneratedMap_topologicallyGenerates` view a family `φ : A → G` inside it, where it is topologically generating.
- `map_mem_closedSubgroupGenerated_image`, `map_mem_closedSubgroupGenerated_singleton`: a continuous homomorphism maps the closed subgroup generated by `X` into the one generated by the image of `X`.
- `topologicallyGenerates_singleton_of_denseRange_mint`: if a homomorphism from `ℤ` (written `Multiplicative ℤ`) has dense image, the image of `1` topologically generates.
- `topologicallyGenerates_image_of_continuousSurjective`, `topologicallyGenerates_quotient_image`: topological generation passes to continuous surjective images and to quotients by normal subgroups.
