# Kummer generation for finite abelian extensions

Module `Nyll.GaloisCohomology.Kummer.Concrete.FiniteGeneration`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The file proves that a finite abelian Galois extension `L/K` whose Galois group is killed by `n`, over a field `K` containing a primitive `n`-th root of unity, is generated by the `n`-th roots of elements of `K`.

## Main definitions and results

- `finiteKummerRootSet n`: the set of nonzero `β ∈ L` with `βⁿ` in the image of `Kˣ`.
- `nthRootsOfUnityInBase_of_primitiveRoots`: a primitive `n`-th root of unity in `K` implies that every `n`-th root of unity in `L` comes from `K` (the hypothesis `NthRootsOfUnityInBase` of the finite character isomorphism).
- `rootQuotient_eq_of_same_pow_of_primitiveRoots`: under the same hypothesis, the quotient `σ(u)/u` does not depend on which `n`-th root `u` of a given `a ∈ Kˣ` is used.
- `finiteKummerRootSet_adjoin_eq_top`: if `L/K` is finite, Galois, with commutative Galois group killed by `n`, and `K` contains a primitive `n`-th root of unity, then `K(finiteKummerRootSet n) = L`.

## Proof

By the Galois correspondence it suffices that only `σ = 1` fixes the adjoined field. For `σ ≠ 1`, Mathlib's separation of points by characters gives `χ : Gal(L/K) → μ_n` with `χ(σ) ≠ 1`; surjectivity of the finite Kummer character (`finiteKummerQuotientCharacter_surjective`) writes `χ` as `τ ↦ τ(β)/β` for some `n`-th root `β` of an element of `K`. Since `σ` fixes `β`, `χ(σ) = 1`, a contradiction.

## Points to watch

This is the finite, field-theoretic, `n`-th power form of the generation theorem; the infinite case is in a separate file, and the abstract-operator form is not covered.
