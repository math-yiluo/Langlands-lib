# Finite support of elements of a Kummer radical extension

Module `Nyll.GaloisCohomology.Kummer.Concrete.FiniteSupport`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a field `Ω` over `K`, a subgroup `Δ ≤ Kˣ` and `n ≥ 1`, the radical extension `K(ⁿ√Δ)` (the library's `kummerRadicalExtension`) is generated by the set of `β ∈ Ω` with `βⁿ ∈ Δ` (`kummerRootSet`). The file shows that each element of `K(ⁿ√Δ)` only involves finitely many roots, and, when `Δ` contains `Kˣⁿ`, extracts from them a subgroup `Δ₀ ≤ Δ` with `Δ₀ / Kˣⁿ` finite. This prepares the reduction of infinite Kummer theory to the finite case.

## Main definitions

For a finite set `T` of roots in `kummerRootSet n Δ`:

- `chosenFiniteSupportCoefficient`: for each `β ∈ T`, a chosen `a ∈ Δ` with `βⁿ = a` (`chosenFiniteSupportCoefficient_pow`); `chosenFiniteSupportCoefficientSet` collects them in a finite subset of `Kˣ`.
- `chosenFiniteSupportCoefficientSubgroup`: the subgroup they generate; it lies in `Δ`.
- `admissibleFiniteSupportSubgroup`: for `Δ` a `KummerSubgroup K n` (a subgroup of `Kˣ` containing `Kˣⁿ`, as used in this file), the subgroup `Δ₀ = Kˣⁿ · ⟨coefficients⟩`, again a `KummerSubgroup` and contained in `Δ`.
- `FiniteSupportKummerQuotient`: the quotient `Δ₀ / Kˣⁿ`, with its commutative group structure, projection `finiteSupportKummerQuotientMk`, lift `finiteSupportKummerQuotientLift`, induction principle and simp lemmas for equality of classes.

## Main results

- `exists_finset_kummerRootSet_of_mem_kummerRadicalExtension`: an element of `K(ⁿ√Δ)` lies in `K(T)` for a finite `T ⊆ kummerRootSet n Δ`.
- `exists_finiteKummerSupport`: such a `T`, together with the generated subgroup inside `Δ` and an equation `βⁿ = a` with `a` in that subgroup for every `β ∈ T`.
- `chosenFiniteSupportCoefficientToQuotient_surjective`: the coefficient subgroup surjects onto `Δ₀ / Kˣⁿ`.
- `finiteSupportKummerQuotient_pow_eq_one` and `finiteSupportKummerQuotient_finite`: `Δ₀ / Kˣⁿ` is killed by `n` and finite, being a finitely generated commutative torsion group.
- `exists_admissibleFiniteKummerSupport`: the full package for one element: `T`, `Δ₀ ≤ Δ`, the power equations over `Δ₀`, and finiteness of `Δ₀ / Kˣⁿ`.

## Points to watch

- The coefficients are chosen noncomputably after `T` is fixed; `Δ₀` depends on `T`.
- `KummerSubgroup`, `kummerRootSet`, `kummerRadicalExtension` and `unitNthPowersSubgroup` (`Kˣⁿ`) are the library's own definitions from other files.
- No result of finite Kummer theory is used or proved here.
