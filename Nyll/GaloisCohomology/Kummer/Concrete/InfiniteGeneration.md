# Kummer generation for infinite abelian extensions

Module `Nyll.GaloisCohomology.Kummer.Concrete.InfiniteGeneration`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

- `kummerRootSet_adjoin_eq_top`: let `Ω/K` be a Galois extension, possibly infinite, with commutative Galois group killed by `n`, and let `K` contain a primitive `n`-th root of unity. Then `Ω` is generated over `K` by the nonzero `β ∈ Ω` with `βⁿ ∈ K` (`finiteKummerRootSet`).

Each `x ∈ Ω` lies in the finite Galois intermediate field generated by `x`. Restriction to it is surjective, so that finite stage is again abelian and killed by `n`, and the finite generation theorem (`finiteKummerRootSet_adjoin_eq_top`) puts `x` in the field generated by its radicals, which are radicals of `Ω` too.

This covers field extensions and the `n`-th power map only; the abstract-operator form of the generation theorem is not claimed.
