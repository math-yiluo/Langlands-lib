# Abstract Kummer theory: descending a global operator to a cyclic layer

Module `Nyll.GaloisCohomology.Kummer.Abstract.KummerGlobalOperator`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The file passes from a global equivariant operator `wp : A ⟶ A` on an integral representation of a group `G` equipped with a topology to the induced operator on `A_L`, the `G_L`-invariants of `A` viewed as a representation of `G_K / G_L` (for closed subgroups `G_L ≤ G_K` with `G_L` normal in `G_K`), and feeds it to the cyclic single-radical theorem.

## Main definitions and results

- `extensionFixedEndomorphism`: the endomorphism of `A_L` obtained by restricting `wp` to `G_K` and applying Mathlib's invariants functor `Rep.quotientToInvariantsFunctor`; on underlying elements it is `wp` (`extensionFixedEndomorphism_apply_val`).
- `extensionFixedKernelElement`: an element `xi ∈ A` fixed by `G_K`, seen in `A_L`. It keeps its additive order, is fixed by `G_K / G_L`, and lies in the kernel of the induced operator when `wp xi = 0`.
- `cyclicGlobalOperator_singleRadical`: if `G_K / G_L` is finite and generated by one element and killed by `n`, and `xi` is fixed by `G_K`, of additive order `n`, with `wp xi = 0`, then some `a ∈ A_L` has trivial stabilizer in `G_K / G_L` and its image under the induced operator is fixed.

The theorem is the earlier cyclic statement with the operator and kernel element built from the global data.

## Points to watch

- `hAxiom : SatisfiesIntegralCyclicNormKernelVanishing A`, defined elsewhere in the library, is a Hilbert-90-type hypothesis supplying the vanishing of Tate `Ĥ⁻¹` on the cyclic layer; it is assumed.
- This is only the finite cyclic step, not the abelian Kummer correspondence.
