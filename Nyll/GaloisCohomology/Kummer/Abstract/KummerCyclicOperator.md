# Abstract Kummer theory: the finite cyclic single-radical step

Module `Nyll.GaloisCohomology.Kummer.Abstract.KummerCyclicOperator`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a finite cyclic group acting on an integral representation, the vanishing of Tate `Ĥ⁻¹` produces a "radical": an element whose orbit is free and whose image under a given equivariant operator is invariant. In additive notation this is the abstract analogue of choosing `a` with `σ(a) − a = ζ`.

## Main definitions and results

- `representationStabilizer B a`: the stabilizer of `a` for the action of a representation `B`, defined directly because a representation does not install a `MulAction` instance.
- `cyclic_single_radical_of_tateHMinusOne_isZero`: let `Q` be a finite group generated by `g`, `B` an integral representation with `Ĥ⁻¹(Q, B) = 0` (the library's `IntegralGroupCohomology.Universe.tate`), `wp : B ⟶ B` an equivariant endomorphism, and `xi ∈ B` fixed by `Q`, of additive order `n`, with `wp xi = 0`, where `n` kills `Q`. Then some `a ∈ B` has `wp a` fixed by `Q` and trivial stabilizer.
- `cyclicOperator_singleRadical_of_normKernelVanishing`: the same statement for `B = A_L`, the `G_L`-invariants of `A` as a representation of a finite cyclic `G_K / G_L`, where the vanishing of `Ĥ⁻¹` is taken from the hypothesis `hAxiom`.

## Proof

With `d = |Q|`, the element `η = (n/d)·xi` has order `d`, is fixed, and has norm `d·η = 0`. Vanishing of `Ĥ⁻¹` gives `a` with `g a − a = η`. Then `g^i a = i·η + a`, so the stabilizer of `a` is trivial, and `wp(g a − a) = wp η = 0`, so `wp a` is fixed.

## Points to watch

- `hAxiom : SatisfiesIntegralCyclicNormKernelVanishing A` is a Hilbert-90-type hypothesis defined elsewhere in the library; here it is applied to supply `Ĥ⁻¹(G_K/G_L, A_L) = 0`. It is assumed, not proved.
- The operator in the second theorem is given on `A_L`, not descended from `A`; only the cyclic step is treated.
