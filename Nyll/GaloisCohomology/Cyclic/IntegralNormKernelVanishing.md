# Vanishing of integral Tate groups of cyclic groups and the norm

Module `Nyll.GaloisCohomology.Cyclic.IntegralNormKernelVanishing`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a finite group G generated by g and an integral representation A (G and A in independent universes), the file turns vanishing of the Tate groups `tate A n` into statements about elements.

- `ulift_generator`: a generator of G generates its universe lift.
- `normKernel_of_tate_isZero`: if `tate A (-1)` is zero, every element of norm zero is `g·y − y`.
- `exists_norm_eq_of_tate_isZero`: if `tate A 0` is zero, every element fixed by g is a norm.
- `SatisfiesIntegralCyclicNormKernelVanishing A`, for a group with a topology: for all closed L ≤ K with L normal in K and `K/L` finite cyclic, `tate` in degree −1 of `extensionFixedRepresentation A K L hLK hnormal` (the L-invariants of A, acted on by K/L) is zero.
- `satisfiesIntegralCyclicNormKernelVanishing_iff_original`: in universe 0 this is the library's `SatisfiesCyclicNormKernelVanishing`, stated with Mathlib's Tate cohomology.

The proofs pass to the lifted representation and use Mathlib's finite-cyclic norm complexes.

`SatisfiesIntegralCyclicNormKernelVanishing` is only a definition, a property to be assumed or proved elsewhere.
