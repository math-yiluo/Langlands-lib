# Cyclic closures detected by a p-adic degree

Module `Nyll.ClassFieldTheory.AbstractClassFieldTheory.Degree.PadicCyclicClosure`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The file isolates two topological-group arguments used for the Frobenius at finite places. `G` is a compact topological group with a continuous homomorphism `degree : G → ℤ_p` (written multiplicatively). For an element `τ`, `padicCyclicClosure τ` is the closed subgroup topologically generated by `τ`, and `padicCyclicClosureGenerator τ` is `τ` as an element of it.

## Main results

- `padicCyclicClosure_isOpen_of_degree_ne_one`: if the kernel of `degree` is finite and `degree τ ≠ 0` (written `≠ 1` multiplicatively), the closed subgroup generated by `τ` is open in `G`. The degree image of the closure is compact, hence closed in `ℤ_p`, and nonzero, hence open; so it has finite index in the degree image of `G`. The kernel part is finite, and the index formula through a homomorphism from the relative-index file gives finite index, so the closed subgroup is open.
- `padicCyclicClosure_degree_injective_of_primePower_finiteCoordinate`: let `Q` be a discrete group and `finiteCoordinate : G → Q` a continuous homomorphism, such that `g ↦ (finiteCoordinate g, degree g)` is injective. If `γ` has `finiteCoordinate γ` of order dividing `p^m` and `degree γ = n` with `n > 0` a natural number, then `degree` is injective on the closed subgroup generated by `γ`. If an element `z` of the closure has degree `0`, approximate it by a power `γ^k` lying in the open set where the finite coordinate equals that of `z` and the degree lies in `n p^m ℤ_p`. Cancelling `n` gives `p^m ∣ k`, so the finite coordinate of `z` is trivial, and joint injectivity gives `z = 1`.

## Points to watch

- Neither statement assumes `G` profinite. The first needs `G` compact and the kernel of `degree` finite; the second drops compactness but needs the joint injectivity hypothesis.
- In the second result the degree of `γ` must be exactly a positive integer `n`, not an arbitrary nonzero `p`-adic number.
