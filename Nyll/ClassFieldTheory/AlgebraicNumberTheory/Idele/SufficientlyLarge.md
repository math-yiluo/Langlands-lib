# A finite set S with I_K = I_K^S Kˣ

Module `Nyll.ClassFieldTheory.AlgebraicNumberTheory.Idele.SufficientlyLarge`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a number field `K`, this file produces a finite set `S` of finite places such that every idele is the product of an idele that is a local unit at every finite place outside `S` and a principal idele: `I_K = I_K^S Kˣ`.

## Main definitions and results

- `IdeleGroup.sufficientlyLargeFiniteSet`: choose, for each ideal class `c` of `𝓞 K`, an idele mapping to `c` under `idealClass`, and a finite set of finite places outside which it is a local unit; take the union over all classes. It is a finite set because the ideal class group is finite.
- `IdeleGroup.idealClass_surjective_on_sufficientlyLarge`: every ideal class is the class of an idele in `supportedAt` of this set.
- `IdeleGroup.supportedAt_sup_principalSubgroup_eq_top`: the subgroup `I_K^S` for this set `S`, joined with the principal ideles, is the whole idele group.
- `IdeleGroup.exists_finset_supportedAt_sup_principalSubgroup_eq_top`: the existential form, some finite `S` has this property.

## Proof

Given an idele `a`, pick `r ∈ I_K^S` with the same ideal class. Then `a r⁻¹` lies in the kernel of `idealClass`, which an imported result (`ordinaryIdealClassSubgroup_eq_ker`) identifies with a subgroup generated by the ideles integral at all finite places and the principal ideles; both lie in `I_K^S ⊔ Kˣ`. The surjectivity of `idealClass` and finiteness of the class group are imported.

## Points to watch

- As elsewhere in the library, `S` contains only finite places; the archimedean components are never restricted.
- The set is defined by arbitrary choices, so it is not canonical; only the existence of such a set has invariant meaning.
