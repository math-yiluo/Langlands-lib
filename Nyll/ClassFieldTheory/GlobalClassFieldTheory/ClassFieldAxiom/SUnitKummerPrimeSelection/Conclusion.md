# The selected primes cut out the Kummer radical

Module `Nyll.ClassFieldTheory.GlobalClassFieldTheory.ClassFieldAxiom.SUnitKummerPrimeSelection.Conclusion`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The setting is that of the S-unit Kummer prime selection: a number field K with a primitive n-th root of unity, `n = p^v` a prime power, a finite abelian extension E/K inside a separable closure Ω with `Gal(E/K) ≅ (ℤ/n)^r`, a finite set S of finite places, its Kummer-radical enlargement `S'`, and the selected prime set `T = sUnitKummerPrimeSet … S`. The file proves that local n-th power conditions at the primes of T detect exactly which `S'`-units have an n-th root in E.

## Main results

- `sUnitLocalPowerKernel_sUnitKummerPrimeSet_eq_comap_sUnitFiniteKummerRadical`: an `S'`-unit x is a local n-th power at every place of T if and only if x has an n-th root in E. In Lean: the kernel `sUnitLocalPowerKernel n S' T` equals the trace on `S'`-units of `sUnitFiniteKummerRadical n S'`.
- `supportedAt_sup_principalSubgroup_eq_top_of_enlargeByRadicalSupport`: if ideles supported on S and Kˣ generate `I_K`, the same holds for the enlarged set.

## Proof

Let N be the extension generated by n-th roots of all `S'`-units, and β an n-th root of x in N. By an imported Kummer criterion, x is a local n-th power at a place w exactly when β is fixed by the decomposition group at w. At the i-th chosen place that decomposition field is the coordinate fixed field `N_i` (imported). Thus if x is a local power at every place of T, β is fixed by every kernel generator; these generate the kernel of restriction `Gal(N/K) → Gal(E/K)`, so β lies in E. Conversely an n-th root in E lies in every `N_i`.

## Points to watch

- T is built from a noncanonical choice of base places, so the statement is about that particular set. K and Ω must lie in `Type`.
