# The norm subgroup of the small Hilbert class field

Module `Nyll.ClassFieldTheory.GlobalClassFieldTheory.GlobalClassFields.SmallHilbertClassField`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a number field K, the file defines the subgroup of the idele class group C_K that corresponds to the (small) Hilbert class field: the image of the ideles whose finite components are all local units. It shows that the quotient by it is the ideal class group, and compares it with the narrow (big) Hilbert class field.

## Main definitions and results

- `smallHilbertClassFieldNormSubgroup`: the image in C_K of the subgroup generated by these ideles (`IdeleGroup.integralAtFinitePlaces`) and the principal ideles. The principal ideles are put in first, so the third isomorphism theorem applies literally.
- `smallHilbertClassFieldQuotientEquivClassGroup`: C_K modulo this subgroup is isomorphic to `ClassGroup (𝓞 K)`. Hence `smallHilbertClassFieldQuotient_card_eq_classNumber`: the quotient has order the class number.
- The subgroup is open, closed and of finite index. Modulus 0 is a defining modulus (`smallHilbertClassFieldNormSubgroup_isDefiningModulus`). This gives `smallHilbertClassFieldConductorialSubgroup`, whose narrow finite conductor is 0 (`smallHilbertClassField_narrowFiniteConductor`).
- `bigHilbertClassFieldNormSubgroup_le_smallHilbertClassFieldNormSubgroup`: the narrow Hilbert norm subgroup lies in the small one.
- `bigHilbertClassFieldQuotientToSmallHilbertClassFieldQuotient`: the induced map between the two quotients. It is surjective, and its kernel is the image of the small subgroup.
- `classNumber_dvd_narrowClassGroup_card`: the class number divides the order of the narrow class group.
- `narrowClassGroup_card_eq_bigToSmallKernel_card_mul_classNumber`: that order is the order of the kernel times the class number. `narrowClassGroup_card_eq_smallHilbertNormImage_card_mul_classNumber` states the same with the kernel written as an image subgroup.

## Proof

The isomorphism with the class group composes the third isomorphism theorem with `IdeleGroup.quotientIntegralSupPrincipalEquiv`, an isomorphism from an imported file. Openness holds because the subgroup contains the congruence subgroup of modulus 0, which is open. The counting results use the imported isomorphism of the narrow Hilbert quotient with `RayClass.NarrowClassGroup K`, together with the index of a kernel.

## Points to watch

- No field is built here: the "small Hilbert class field" is only its norm subgroup and the quotient by it. The comment on the inclusion speaks of class-field duality, but the file proves only the inclusion of subgroups.
- `ConductorialSubgroup`, `IsDefiningModulus` and the narrow finite conductor are the library's own notions.
