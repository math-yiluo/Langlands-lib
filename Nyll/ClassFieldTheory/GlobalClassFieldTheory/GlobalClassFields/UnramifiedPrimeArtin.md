# Artin elements of primes at unramified places

Module `Nyll.ClassFieldTheory.GlobalClassFieldTheory.GlobalClassFields.UnramifiedPrimeArtin`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let L/K be an abelian Galois extension of number fields and v a finite place of K. The file defines the global Artin element of the idele that has a normalized prime element at v and 1 elsewhere. It studies this element when the chosen completion of L above v is unramified. There it generates the decomposition group, its order is the local degree, and it is trivial exactly when v splits completely.

## Main definitions and results

- `finitePlacePrimeArtin v`: the image of the one-place prime idele `finitePrimeIdele v` under the global Artin homomorphism `Reciprocity.globalArtinMonoidHom`, an element of Gal(L/K).
- `finitePlacePrimeArtin_eq_chosenFinitePlaceArtin`: it equals the chosen local Artin map at v applied to the chosen local element of normalized order 1.

Each of the following assumes `ChosenFinitePlaceIsUnramified v`:

- `chosenFinitePlaceArtin_eq_of_localOrder_eq_of_chosenUnramified`: two local elements of the same normalized order have the same local Artin symbol.
- `chosenFinitePlaceArtin_eq_primeArtin_zpow_of_chosenUnramified`: the local Artin symbol of x is `finitePlacePrimeArtin v` raised to the normalized order of x.
- `finitePlaceDecompositionGroup_eq_zpowers_finitePlacePrimeArtin_of_chosenUnramified`: the decomposition group at v is generated by the prime Artin element.
- `orderOf_finitePlacePrimeArtin_eq_finitePlaceLocalDegree_of_chosenUnramified`: its order is the local degree at v.
- `finitePlacePrimeArtin_eq_one_iff_splitsCompletely_of_chosenUnramified`: it is trivial if and only if v splits completely in L.

## Proof

The global Artin map restricted to a one-place idele is the chosen local Artin map; this is imported. At an unramified place the local units lie in the local norm group, which is the kernel of the local Artin map. So the local symbol depends only on the order. The image of the local Artin map is the decomposition group, whose order is the local degree. Complete splitting means local degree 1.

## Points to watch

- The hypothesis concerns the library's chosen completion of L above v, not unramifiedness stated through ideals.
- `finitePlacePrimeArtin` is defined through the reciprocity map. The file does not compare it with the Frobenius automorphism defined by its action on residue fields.
