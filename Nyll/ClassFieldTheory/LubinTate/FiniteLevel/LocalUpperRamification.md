# Upper ramification groups of standard Lubin–Tate levels as local upper groups

Module `Nyll.ClassFieldTheory.LubinTate.FiniteLevel.LocalUpperRamification`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let `K` be a nonarchimedean local field (Mathlib's `IsNonarchimedeanLocalField`, with the library's canonical packaged structure `standardLocalField K`), `π` a uniformizer, and `L_n` the standard Lubin–Tate level `n`. The file compares the upper ramification groups computed with the valuation chosen in the Lubin–Tate construction against the library's canonical local upper ramification groups, and identifies the integral upper groups with kernels of restriction along the tower of levels.

## Main results

- `standardLubinTateRealUpperRamificationGroup_eq_localUpperRamificationGroup`: for every real `t`, the upper group of `L_n/K` at `t` defined with the Lubin–Tate valuation equals `localUpperRamificationGroup K L_n t`.
- `standardLubinTateRealUpperRamificationGroup_eq_restrictKer`: for `1 ≤ k ≤ n + 1`, the upper group of `L_n/K` at `k` is the kernel of the restriction map `Gal(L_n/K) → Gal(L_(k−1)/K)`, where `L_(k−1) ≤ L_n` by the tower lemma.

## Proof

Both valuations on `L_n` extend the valuation of `K` uniquely, so they have the same valuation ring, and upper groups depend only on that ring. For the kernel: upper groups are compatible with restriction to the subextension `L_(k−1)`, where the upper group at `k` has order `q^0 = 1` (`q` the cardinality of the residue field of `K`) by the Herbrand formula, so the upper group lies in the kernel. The kernel has order `q^(n+1−k)` (from the Galois group orders `(q − 1)·q^n` and `(q − 1)·q^(k−1)` and surjectivity of restriction), the same as the upper group, hence equality.

## Points to watch

- Indices follow the library's convention: `L_n` is generated by a primitive point killed by `[π^(n+1)]`, so the upper group at `k` is the kernel of restriction to `L_(k−1)`. The comments call this "level `k`" in the primitive-level counting.
- The results are stated for the canonical package `standardLocalField K` only, and the kernel description only for integer upper indices `1 ≤ k ≤ n + 1`.
