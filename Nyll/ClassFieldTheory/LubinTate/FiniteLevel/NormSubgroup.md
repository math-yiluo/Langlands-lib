# The norm subgroup of a standard Lubin–Tate level

Module `Nyll.ClassFieldTheory.LubinTate.FiniteLevel.NormSubgroup`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let `F` be a local field structure on `K`, `π` a uniformizer, and `L_n` the standard Lubin–Tate level `n`. The file defines the norm subgroup `N(L_nˣ) ⊆ Kˣ` and shows that it contains the uniformizer `π` and all its integer powers.

- `standardLubinTateNormSubgroup hπ n`: the library's local norm subgroup `localNormSubgroup K L_n`, the image of the norm map on units.
- `standardLubinTateBaseUniformizerUnit hπ`: `π` as an element of `Kˣ`.
- `standardLubinTateBaseUniformizerUnit_mem_normSubgroup`: `π` is a norm from `L_n`, namely the norm of minus the chosen generator.
- `standardLubinTateBaseUniformizerUnit_inv_mem_normSubgroup`, `standardLubinTateBaseUniformizerUnit_zpowers_le_normSubgroup`, `standardLubinTateBaseUniformizerUnit_inv_zpowers_le_normSubgroup`: the same for `π⁻¹` and for the cyclic subgroups generated by `π` and by `π⁻¹`.

The proof uses the norm identity for the negative primitive generator from the file on the norm of the uniformizer.

Only the uniformizer part is treated: that the principal units `U^(n+1)` are norms is left to later files.
