# The norm subgroup of a standard Lubin–Tate level

Module `Nyll.ClassFieldTheory.LocalClassFieldTheory.LubinTateApplication.StandardNormSubgroupExact`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let `K` be a nonarchimedean local field (Mathlib's `IsNonarchimedeanLocalField`). The file identifies the norm subgroup of the standard Lubin–Tate extension of level `n` with the subgroup of `Kˣ` generated by a uniformizer and the principal units `U_K^(n+1)`.

- `standardLubinTateFieldPrincipalUnits_le_normSubgroup`: for any uniformizer `π` of `standardLocalField K`, every unit of `U_K^(n+1)` lies in `standardLubinTateNormSubgroup hπ n`.
- `standardLubinTateUniformizerPrincipalSubgroup_le_normSubgroup`: the subgroup generated by `π` and `U_K^(n+1)` lies in that norm subgroup.
- `standardLubinTateCanonicalUniformizerPrincipalSubgroup_eq_normSubgroup`: for the canonical uniformizer, the two subgroups are equal.
- `standardLubinTateCanonicalNormSubgroup_eq_normalizedUniformizerPrincipalSubgroup`: the same subgroup, generated by the inverse canonical uniformizer (positive normalized valuation) and `U_K^(n+1)`.

The containment uses the changed-uniformizer norm computation and the earlier result that the powers of `π` lie in the norm subgroup (`standardLubinTateBaseUniformizerUnit_zpowers_le_normSubgroup`). Equality follows because both subgroups have the nonzero index `(q − 1)·q^n`, `q` the residue field cardinality, computed in two other files.

Equality is proved only for the canonical uniformizer; for an arbitrary uniformizer the file gives only the containment.
