# Herbrand quotients along the valuation sequence

Module `Nyll.ClassFieldTheory.LocalClassFieldTheory.ClassFormation.ValuationHerbrand`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let `L/K` be a finite extension, `L` a nonarchimedean local field whose valuation extends that of `K`, with `𝒪_L` the integral closure of `𝒪_K`. The file applies multiplicativity of Herbrand quotients to `1 → 𝒪_Lˣ → Lˣ → ℤ → 0`, with the Galois actions on units and the trivial action on `ℤ`.

- `valuationHerbrand_shortExact`: both maps are equivariant, the inclusion is injective, the valuation is surjective, and its kernel is `𝒪_Lˣ`.
- `galoisGroupValueGroup_herbrandQuotientDefined`: for every `g`, the Herbrand quotient of `ℤ` with trivial action is defined.
- `valuationHerbrand_multiplicativity_of_integerUnits_defined`: if `Gal(L/K)` is generated by `g` and the Herbrand quotient of `𝒪_Lˣ` is defined (hypothesis `hU`), then that of `Lˣ` is defined and `h(Lˣ) = h(𝒪_Lˣ) · h(ℤ)`.

The proof uses `herbrandQuotientDefined_middle_of_left_right` and `herbrandQuotient_multiplicative_of_shortExact`.

Definedness for `𝒪_Lˣ` is a hypothesis, not proved here, and `h(ℤ)` is not evaluated. No Galois hypothesis is made: `Gal(L/K)` is the automorphism group, assumed cyclic only in the multiplicativity theorem. `K` and `L` are taken in `Type` (universe 0).
