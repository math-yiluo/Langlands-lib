# Frobenius normalization of the canonical local Artin map

Module `Nyll.ClassFieldTheory.LocalClassFieldTheory.Finite.LocalReciprocity.UnramifiedNormalization`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a finite unramified Galois extension L/K of nonarchimedean local fields, the file identifies the canonical local norm-residue symbol `localArtinMonoidHom K L`, which comes from the library's class formation, with the explicit unramified Artin map `unramifiedLocalArtinMap K L`. The outcome is the formula Art(x) = Frob^(`valuationMap` x), algebraically and for the continuous Artin map into the topological abelianization.

## Main definitions and results

Hypotheses: K, L : Type nonarchimedean local fields (L with a uniform structure), L/K finite Galois, the valuation of L extending that of K, and `IsUnramifiedValuedExtension K L`.

- `localAbstractPrimeFieldUnit K`: the unit of K corresponding to the canonical prime element of the local henselian valuation of the class formation; `valuationMap_localAbstractPrimeFieldUnit_mod`: its valuation is ≡ 1 mod n for every n > 0.
- `normClass_localAbstractPrimeFieldUnit_eq_uniformizer`: in K^×/N(L^×) it has the same class as `inverseIntegerRingUniformizerFieldUnit K`.
- `localArtinMonoidHom_localAbstractPrimeFieldUnit`: the canonical symbol sends it to the class of `arithmeticFrobeniusOfUnramifiedValuation K L` in the abelianization.
- `abelianizationEquivNormQuotient_symm_eq_unramifiedLocalReciprocityIso` and `localArtinMonoidHom_eq_unramifiedLocalArtinMap`: the canonical reciprocity isomorphism and Artin map equal the unramified ones.
- `localArtinMonoidHom_inverseIntegerRingUniformizerFieldUnit`, `localArtinMonoidHom_eq_frobenius_zpow`: Art(x) is the class of Frob^(`valuationMap` x).
- Continuous versions: `localArtinMap_eq_frobenius_zpow`, `localArtinMap_localAbstractPrimeFieldUnit`, `localArtinMap_uniformizer`, `localArtinMap_eq_one_of_valuationMap_eq_zero`, `localArtinMap_units_unramified` (units of 𝒪_K map to 1).
- For L/K abelian: `abelianLocalArtinMonoidHom_eq_frobenius_zpow`, and in the namespace `ClassFieldTheory`: `finiteAbelianLocalArtinMap_eq_frobenius_zpow`, `finiteAbelianLocalArtinMap_uniformizer` (an element of valuation one maps to Frob) and `finiteAbelianLocalArtinMap_inverseUniformizer_residue_pow` (its image acts on residues by x ↦ x^q, q = #𝓀_K).

## Proof

The prime-norm formula for the concrete norm-residue symbol sends the abstract prime to the abstract unramified Frobenius, which is arithmetic Frobenius by the comparison of abstract and concrete Frobenius. The norm quotient is cyclic of order n = [L:K] via K^×/N(L^×) ≅ ℤ/nℤ, generated by the class of the abstract prime, so two isomorphisms that agree on it agree everywhere.

## Caveats

- Sign convention: `valuationMap` is 1 on `inverseIntegerRingUniformizerFieldUnit K`, the inverse of a uniformizer. So `localArtinMap_uniformizer` and `finiteAbelianLocalArtinMap_uniformizer`, despite their names, concern inverse uniformizers; by the power formula a uniformizer itself goes to Frob⁻¹.
- `valuationMap_localAbstractPrimeFieldUnit_mod` states the valuation of the abstract prime only modulo n.
- All fields are in `Type`; the `ClassFieldTheory` theorems carry `UniformSpace L` and `IsUniformAddGroup L` among their hypotheses.
