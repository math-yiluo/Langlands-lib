# The trivial modulus

Module `Nyll.ClassFieldTheory.Definitions.ConductorsAndRayClassFields.OrdinaryRayClassModulus`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The ray modulus of a number field that imposes no condition at all, and its place at the bottom of the divisibility order.

- `ordinaryRayClassModulus K`: the ray modulus of a number field `K` with zero finite part and no real places.
- `ordinaryRayClassModulus_le`: it lies below every ray modulus in the divisibility order.

## Points to watch

The docstring says its ray class group is the ordinary ideal class group; the file does not prove this identification.
