# The narrow modulus

Module `Nyll.ClassFieldTheory.Definitions.ConductorsAndRayClassFields.NarrowRayClassModulus`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The ray modulus of a number field that imposes positivity at every real place and no finite congruence.

- `narrowRayClassModulus K`: the ray modulus of a number field `K` with zero finite part and with every real place in its infinite part.

## Points to watch

The docstring says its ray class group is the narrow ideal class group; the file only defines the modulus and proves nothing about that group.
