# Ray class groups

Module `Nyll.ClassFieldTheory.Definitions.ConductorsAndRayClassFields.RayClassGroup`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The ideal-theoretic ray class group `I^m / P^m` of a number field `K` for a ray modulus `m`.

- `RayClassGroup m`: the quotient of `rayClassPrimeToIdeals m`, the group of nonzero fractional ideals prime to the finite part of `m`, by its subgroup `rayPrincipalIdealSubgroupInPrimeTo m` of ray-principal ideals, those in the subgroup generated by principal ideals `(x)` with `x ≡ 1 mod* m`. It is an abbreviation.
- `instIsMulCommutativeRayClassGroup`: the ray class group is commutative.

## Points to watch

Finiteness of the ray class group is not proved here.
