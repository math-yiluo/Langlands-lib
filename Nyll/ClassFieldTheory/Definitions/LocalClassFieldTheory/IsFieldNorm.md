# Being a field norm

Module `Nyll.ClassFieldTheory.Definitions.LocalClassFieldTheory.IsFieldNorm`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

A predicate for nonzero elements that are norms from a finite field extension.

- `IsFieldNorm K L x`: for a finite-dimensional field extension `L/K` and `x ∈ Kˣ`, `x` lies in `fieldNormSubgroup K L`, that is, `x` is the norm of some `y ∈ Lˣ`.
