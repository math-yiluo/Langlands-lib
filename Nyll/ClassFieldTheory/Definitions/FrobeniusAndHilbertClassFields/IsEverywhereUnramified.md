# Everywhere unramified extensions

Module `Nyll.ClassFieldTheory.Definitions.FrobeniusAndHilbertClassFields.IsEverywhereUnramified`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

The condition that an extension of number fields is unramified at all places, finite and infinite.

- `IsEverywhereUnramified K L`: `IsUnramifiedAtFinitePlaces K L` (every finite prime of `K` is unramified in `𝓞 L`) together with Mathlib's `IsUnramifiedAtInfinitePlaces K L`.
