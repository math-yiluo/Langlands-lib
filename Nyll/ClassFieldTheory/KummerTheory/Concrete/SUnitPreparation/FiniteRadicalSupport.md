# Finite S-unit support for a Kummer radical

Module `Nyll.ClassFieldTheory.KummerTheory.Concrete.SUnitPreparation.FiniteRadicalSupport`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

Let `K` be a number field containing a primitive `n`-th root of unity and `L/K` a finite Galois extension. The Kummer radical `D = Kˣ ∩ Lˣⁿ` of `L/K` has finitely many classes modulo `Kˣⁿ`. Choosing one representative of each class and, for each representative, a finite set of places outside which it is a unit, and taking the union of these sets, gives a finite set of places; after adding it to any `S`, the radical `D` is generated by its `S`-units together with `Kˣⁿ`. Consequently an abelian extension of exponent dividing `n` is generated by `n`-th roots of `S`-units for this enlarged `S`.

## Main definitions and results

- `sUnitFiniteKummerRadical n S`: the subgroup `Kˢ ∩ D` of `S`-units having an `n`-th root in `L`. `sUnitKummerSubgroup n S`: the subgroup `(Kˢ ∩ D) · Kˣⁿ`, as a Kummer subgroup; it lies in `D` and in the full `S`-unit Kummer subgroup `Kˢ · Kˣⁿ` (`sUnitKummerSubgroup_le_fullSUnitKummerSubgroup`).
- `chosenUnitFiniteSupport x`: a chosen finite set of places outside which `x ∈ Kˣ` is a unit, so that `x` is an `S`-unit for it.
- `finite_chosenFiniteKummerRadicalQuotient`: for `L/K` finite Galois with a primitive `n`-th root of unity in `K`, the quotient of `D` by `Kˣⁿ` (in the library's model, `chosenFiniteKummerRadicalDatum`) is finite. `K` need not be a number field here.
- `finiteKummerRadicalSupport` and `enlargeByFiniteKummerRadicalSupport n S = S ∪ finiteKummerRadicalSupport`: the union of the supports of chosen class representatives, and its union with `S`.
- `enlargedSUnitKummerSubgroup_eq_finiteKummerRadicalSubgroup`: for the enlarged set, `(Kˢ ∩ D) · Kˣⁿ = D`.
- `kummerRadicalExtension_enlargedSUnitKummerSubgroup_eq`: for `E` a finite abelian extension of `K` inside a separable closure `Ω`, with Galois group of exponent dividing `n`, the extension obtained by adjoining the `n`-th roots of `(Kˢ ∩ D) · Kˣⁿ`, for the enlarged `S`, is `E`.
- Helpers: `sUnitGroup_mono` (`S`-units grow with `S`) and `kummerRadicalExtension_mono`.

## Proofs

Finiteness comes from the library's Kummer character equivalence between the radical quotient and the homomorphisms `Gal(L/K) → μ_n`, a finite set. Each element of `D` differs from the chosen representative of its class by an `n`-th power, which gives the equality of subgroups. The generation statement then follows from the library's result that an abelian exponent-`n` extension is the Kummer extension of its own radical.

## Remarks

- The enlarged set is defined through choices (`Classical.choose`) and depends on `L`; it is not canonical.
