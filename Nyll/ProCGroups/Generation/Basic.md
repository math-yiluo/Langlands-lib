# Topological generation, generators converging to 1, and topological rank

Module `Nyll.ProCGroups.Generation.Basic`, copied unchanged from the Lean library NYLL. The origin of the file is given at the end of this page.

For a topological group `G`, the file sets up the vocabulary of generator arguments in profinite groups: sets that topologically generate `G`, sets that converge to `1`, the least cardinality of a topological generating set, and the basic behaviour of these notions under homomorphisms, quotients and isomorphisms.

## Main definitions

- `TopologicallyGenerates X`: the closure of the abstract subgroup generated by `X` is `G`.
- `ConvergesToOne X`: the inclusion of `X` tends to `1` along the cofinite filter, that is, every neighbourhood of `1` contains all but finitely many elements of `X`.
- `ConvergesToOneAlongOpenSubgroups X`: the weaker condition that every open subgroup contains all but finitely many elements of `X`.
- `GeneratesAndConvergesToOne`, `GeneratesAndConvergesToOneAlongOpenSubgroups`: the conjunctions with topological generation.
- `topologicalRank G`: the least cardinality of a topological generating set.
- `convergentGeneratorRank G`: an `Option Cardinal`, the least cardinality of a generating set converging to `1`, or `none` if there is no such set.
- `closedSubgroupGenerated X`: the closed subgroup topologically generated by `X`, with `closedSubgroupGeneratedMap` for an indexed family.
- `wordProducts X n`: the products of `n` elements of `X` (`{1}` for `n = 0`).

## Main results

- Convergence: finite sets converge to `1`; `ConvergesToOne` implies the open-subgroup version, and the two agree in a nonarchimedean group (`convergesToOne_iff_alongOpenSubgroups`).
- Rank: `topologicalRank_le_mk_of_topologicallyGenerates`; `exists_topologicallyGenerates_card_eq_topologicalRank` (the rank is attained); `topologicalRank_ne_zero` for a nontrivial `T1` group; `topologicalRank_eq_of_continuousMulEquiv` (for two groups in the same universe).
- `continuousMonoidHom_ext_of_topologicallyGenerates`: continuous homomorphisms into a Hausdorff group that agree on a topological generating set are equal.
- `map_mem_closedSubgroupGenerated_image` (and the singleton form): continuous homomorphisms map the closed subgroup generated by `X` into the one generated by the image of `X`.
- `map_mem_zpowers_of_topologicallyGenerates_singleton` (and a `MonoidHom` form): if `x` topologically generates `A`, every continuous homomorphism to a discrete group maps `A` into the powers of the image of `x`.
- `topologicallyGenerates_singleton_of_denseRange_mint`: a homomorphism from `ℤ` with dense image makes the image of `1` a topological generator.
- Generation is unchanged by taking the closure of `X` or adding `1`, is kept when `X` is enlarged, and passes to continuous surjective images, quotients by normal subgroups, and across topological isomorphisms.
- `continuousMonoidHom_surjective_of_topologicallyGenerates_subset_range`: a continuous homomorphism from a compact group to a Hausdorff group whose range contains a topological generating set is surjective.

## Points to watch

- `ConvergesToOneAlongOpenSubgroups` is weaker in general; the file proves that it agrees with `ConvergesToOne` under `NonarchimedeanGroup`.
- `convergentGeneratorRank` is `none` when no generating set converging to `1` exists, rather than `0`; `topologicalRank` is always defined since `G` itself generates.
- `wordProducts` is only defined here; no results about it are proved in the file.
