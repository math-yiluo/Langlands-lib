# A good order of a finite family of cuspidal data (all fields)

Lean module: `Langlands.AllFieldBZ.Representation.Whittaker.PadicMirabolicNondegeneracyOrder`,
namespace `Langlands.AllFieldBZ.Whittaker.PadicMirabolicNondegeneracy`.

This helper module belongs to the proof of Bernstein–Zelevinsky 1977, Theorem 4.9, over an
arbitrary nonarchimedean local field. Source: I. N. Bernstein and A. V. Zelevinsky, *Induced
representations of reductive p-adic groups I*, Ann. Sci. ÉNS 10 (1977), literature id
`bernstein-zelevinsky-1977-induced-i`. Their deduction of Theorem 4.9 from Theorem 4.11 (printed
p. 456, PDF p. 17) begins: "We order the `ρ_i` so that `ρ_j ≇ νρ_i` when `i < j`". The source does
not prove that such an order exists. This module proves it.

## Setting

`F : Langlands.AllFieldBZ.LocalFieldPackage` is a packaged field with no base field and no
characteristic hypothesis, and `T : F.TopologicalData` is its local-field structure, the Library's
`Langlands.LocalFieldData F.Carrier`. A cuspidal datum `ρ : T.CuspidalDatum` (ported module
`Langlands.AllFieldBZ.Representation.Classification.Segments`) is a positive rank together with an
isomorphism class of irreducible supercuspidal representations of `GL_rank(F)`. `ρ.twist s` is its
twist by `ν^s = |det|^s`.

## Declarations

- `eq_zero_of_twist_eq_self T ρ s h`: if `ν^s ρ = ρ` for a real `s`, then `s = 0`. Proof: unfold
  the datum to a class `[A]` of supercuspidal representations. The hypothesis gives an isomorphism
  `ν^s A ≅ A` (`SupercuspidalRep.isoClass_eq_iff`). The ported lemma
  `Langlands.AllFieldBZ.Derivative.OrderedCuspidalProductTwistOne.exponent_eq_zero` states that
  an irreducible supercuspidal representation equivalent to its own `ν^s`-twist has `s = 0`.
- `above T ρ i` for a family `ρ : Fin k → T.CuspidalDatum`: the finite set of indices `l` with
  `ρ_l = ν^m ρ_i` for some natural number `m ≥ 1`. `mem_above` is its membership criterion.
- `card_above_lt T ρ h`: if `ρ_j = ν ρ_i`, then `above j` has strictly fewer elements than
  `above i`. Proof: `above j ⊆ above i`, because `ρ_l = ν^m ρ_j` gives `ρ_l = ν^(m+1) ρ_i`
  (`LocalFieldPackage.TopologicalData.CuspidalDatum.twist_twist`). Also `j ∈ above i` (take
  `m = 1`). But `j ∉ above j`: otherwise `ρ_j = ν^m ρ_j` with `m ≥ 1`, contradicting
  `eq_zero_of_twist_eq_self`.
- `exists_ordered_perm T ρ`: there is a permutation `e` of `Fin k` such that
  `ρ (e j) ≠ (ρ (e i)).twist 1` whenever `i < j`. Proof: take
  `e = Tuple.sort (fun i => (above T ρ i).card)`. Then `i ↦ #above(e i)` is monotone
  (`Tuple.monotone_sort`). If `i < j` and `ρ (e j) = ν ρ (e i)`, then `card_above_lt` gives
  `#above(e j) < #above(e i)`. Monotonicity gives `#above(e i) ≤ #above(e j)`, a contradiction.

The order condition is stated as inequality of cuspidal data, which are isomorphism classes. So it
is the source's condition `ρ_j ≇ νρ_i`.
