# Jacquet vanishing for uniform quasicuspidal inducing blocks

`Langlands.AllFieldBZ.CuspidalSupport.UniformJacquetVanishingStatement`
fixes a nonarchimedean local field and two ordered block shapes \(B,C\)
of the same rank. Each block of \(B\) has size \(r\). The inducing
representation on the actual product Levi of \(B\) is smooth and
quasicuspidal, so all its normalized restrictions to proper standard
refinements vanish. If any block size of \(C\) fails to be divisible
by \(r\), the actual normalized Jacquet module along \(C\) of every
smooth subquotient of the normalized induction is zero.

This is the equal-block consequence of Bernstein and Zelevinsky,
*Induced representations of reductive p-adic groups I* (1977),
§2.13(a), printed p. 449 (`bernstein-zelevinsky-1977-induced-i`).
Zelevinsky, *Induced representations of reductive p-adic groups II*
(1980), Proposition 3.4, printed pp. 181–182
(`zelevinsky-1980-induced-ii`), uses this divisibility argument for
the segment socle and a two-block target.
