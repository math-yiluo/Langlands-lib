# Rigidity for closed subgroups of split tori

This internal construction defines the Hopf coordinate restriction of an actual
homomorphism between affine group schemes. Full faithfulness of the Hopf spectrum
functor identifies its spectrum map with the original homomorphism between the
chosen coordinate presentations. When the homomorphism is a closed immersion,
the spectrum map is a closed immersion. Surjectivity on global sections and the
canonical global-sections comparison for spectra prove that the coordinate
restriction is surjective.

A surjective coalgebra map sends a spanning set of group-like elements to a
spanning set of group-like elements. Consequently, group-like spanning of Hopf
coordinates passes to every closed affine subgroup. The published split-torus
Hopf-spectrum comparison supplies such a spanning set for a split torus. Thus
the full Hopf coordinate algebra of every closed affine subgroup of a split
torus is spanned by group-like elements. This includes nonsmooth subgroups.

Combining this conclusion with the preceding smooth connected affine actor
rigidity theorem proves that every actual automorphic action of a smooth
connected affine group on such a subgroup is trivial on every scheme test.
The field is arbitrary, all types share one arbitrary universe, and neither
the target subgroup nor the test scheme is assumed smooth or reduced. These
are internal deductions from the published affine coordinate, spectrum,
split-torus and action interfaces. Centre containment and the host semigroup
comparison are not asserted here.
