# Actual Weil-restricted special-linear images in the parabolic elementary subgroup

Let `F E : Type u` be fields with a finite-dimensional algebra structure `F → E`, and let `n : Type` be any finite decidable index type. The source `SpecialLinear.WeilRoot.groupScheme F E` is the existing actual affine Weil restriction of the split `SL_n` group over `E`. The target `G` is an actual connected reductive group scheme over `F`, and its source homomorphism is arbitrary. Characteristic and the field universe are unrestricted. Separability of `E/F` is not needed, so the result includes finite separable extensions.

This internal contribution combines the existing actual restricted coordinate-root maps, their explicit contracting `F`-cocharacters, actual rational-point generation, and the proved dynamic-to-geometric-parabolic-radical bridge.

`map_rootPoint_mem_parabolicUnipotentPointSet` proves that every actual rational point of a restricted coordinate-root family maps into the original generator set `parabolicUnipotentPointSet G`. The imported all-test contraction puts the restricted root point in the source identity-limit subgroup. Its tensor-valued polynomial curve has coefficient `s² x` and identity value at zero. Dynamic functoriality carries this point under the original source map `f` into the target identity-limit subgroup for `cocharacter F E hij ≫ f`. The proved geometric bridge constructs the actual parabolic-radical witness required by the generator set.

`rationalPoints_range_le_parabolicElementarySubgroup` proves containment of the full original rational image in `parabolicElementarySubgroup G`. It applies the existing `rationalPoints_range_le_of_coordinate_dynamics`, which uses generation of the actual source rational points by all restricted coordinate-root images. The proved `dynamicUnipotent_le_parabolicElementarySubgroup` supplies the required containment for each composed cocharacter. The source generation theorem identifies actual `F`-rational restricted points with determinant-one `E`-matrices, compares their actual root images with scalar transvections, and uses the existing transvection generation theorem. No normality premise is needed for that generation argument.

`rationalPoints_range_le_parabolicElementarySubgroup_of_iso` gives the same containment for any actual ground-field model `A` with a specified group-scheme isomorphism `e : A ≅ groupScheme F E` and an actual map `a : A → G`. The imported model comparison uses the cocharacters followed by `e.inv ≫ a` and cancels the actual isomorphism on rational points. It retains the original rational map of `a`.

`rationalPointsToParabolicElementarySubgroup` restricts the codomain of that original full point homomorphism using the proved containment. Its coercion identity is reflexivity: the underlying rational point is exactly `rationalPoints.map a x`.

All results are internal consequences of the imported actual scheme constructions and proved generation and geometric recognition results. The target's connected reductivity supplies the geometric input. There is no supplied ambient root-containment, torus-conjugacy, root-separation, parabolic-presentation, or radical-existence premise. No reductivity assumption on the source or injectivity assumption on its map is needed.

This proves full-image containment for the specified restricted split special-linear sources. It does not classify general rank-one local groups, address nonsplit division-algebra or unitary forms, prove local SK1, or show that such source images generate every target.
