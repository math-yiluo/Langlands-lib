# Depth models on actual root representatives without higher roots

This derived construction applies the natural-coordinate depth models to every
supplied representative of the actual relative-root subgroup functor when the
root has no higher positive integral multiple. The ambient field and group
remain arbitrary; the ambient group is smooth and affine and the supplied torus
is split. The root is an actual relative root, and the valuation is a surjective
integer-valued valuation with the specified valuation ring.

The existing all-test weight-coordinate theorem supplies natural vector
coordinates on this very representative. Their dimension is positive: otherwise
the coordinate group would be trivial on the field test, contradicting the
existing nonidentity rational root-point theorem. Evaluating the same coordinates
on the field test, using the canonical global-sections identification, gives
coordinates on the actual ambient rational root subgroup. The representing
inclusion and the original weight-equivariance prove the required conjugation
formula. This connects the actual scheme coordinates and the rational root-value
API without making separate coordinate choices.

The model is the previously constructed integer-depth vector model retargeted
along the isomorphism induced by those all-test coordinates. Its underlying
integral group is a polynomial vector group, so it is smooth with geometrically
connected fibres. For the Henselian additive valuation API, its actual integral
points map into the ambient group as exactly the filtration of the induced
coordinate-minimum root value. This equality uses the exact coordinate valuation
bounds and the additive threshold bridge. In the reverse direction the
all-test representing inclusion supplies the unique preimage of the ambient root
point.

The actual ordered-depth transition extends the generic identity, and every
compatible identity extension has a smooth, connected and unipotent actual
special-fibre kernel. These assertions specialize the natural-coordinate
transition and kernel calculations.

The provenance is internal specialization and comparison of the existing
all-test and rational coordinate constructions. Kaletha–Prasad,
*Bruhat–Tits theory: a new approach* (2023), Section C.2, printed pp.697–698 /
PDF pp.728–729, motivates the additive depth convention. The induced local root
value is not asserted to be a valuation of the whole root datum, or to agree with
an arbitrary supplied apartment filtration. Those remain separate obligations
for the full C.5.3 target.
