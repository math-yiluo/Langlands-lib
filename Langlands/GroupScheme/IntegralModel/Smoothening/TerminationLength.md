# Termination of the smoothening sequence: length bookkeeping

Author: Worker 348. Internal helper module for the termination of the smoothening sequence
(Kaletha–Prasad, Theorem A.6.2). It is pure module theory over a domain or a discrete valuation
ring and uses no external result beyond Mathlib.

All declarations are in `Langlands.GroupScheme.IntegralModel.Smoothening.Termination`.

## Definitions

- `defect R M`: the length (in `ℕ∞`) of the torsion submodule `Submodule.torsion R M`.
- `torsionByLength R M a`: the length of the `a`-torsion `Submodule.torsionBy R M a`.
- `DivisionExtension ϖ T U c z`: an injective linear map `ι : T → U` and elements `ζ k` of `U`
  with `ϖ • ζ k = ι (z k)`, such that `U` is spanned by `ι T` and the `ζ k`. It models
  "adjoining `z k / ϖ`".
- `IndepModulo ϖ z`: a combination `∑ a k • z k` lies in `ϖ T` only if every `a k` is divisible by
  `ϖ`.
- `pushoutRel`, `Pushout`, `pushout`: the concrete division extension
  `(T × Rᶜ) / ⟨(z k, -ϖ e_k)⟩`. Injectivity of `ι` uses that `R` is a domain and `ϖ ≠ 0`.

## Main results

- `length_eq_inf_ker_add_map`: for a linear map `f` and a submodule `N`,
  `length N = length (N ⊓ ker f) + length (f N)`. It is a consequence of Mathlib's
  `Module.length_eq_add_of_exact`.
- `defect_eq_add_of_surjective`: for a surjection `f : M → N` with torsion kernel,
  `defect M = length (ker f) + defect N`.
- `two_mul_length_le`: if `W ≤ a • V` and `a • W = 0`, then `2 * length W ≤ length V`.
- `DivisionExtension.torsionBy_eq`: under `IndepModulo`, the `ϖ`-torsion of `U` is the image of the
  `ϖ`-torsion of `T`.
- `DivisionExtension.defect_le`: `defect U ≤ torsionByLength T ϖ + defect T`. The proof splits
  `torsion U` along multiplication by `ϖ`, whose image lies in `ι (torsion T)`.
- `DivisionExtension.defect_add_le` (**defect drop**): let `f : U → N` be surjective with torsion
  kernel `V`, and suppose every `ϖ`-torsion element `t` of `T` satisfies `ι t = ϖ • v` for some
  `v ∈ V`. Then `defect N + torsionByLength T ϖ ≤ defect T`. Proof:
  `defect U = length V + defect N`, `length V ≥ 2 · torsionByLength T ϖ`, and the bound on
  `defect U`. The cancellation in `ℕ∞` is justified because `torsionByLength ≤ defect`.
- `torsionByLength_ne_zero`: over a DVR with uniformizer `ϖ`, a nonzero defect forces nonzero
  `ϖ`-torsion. A torsion element is killed by a power of `ϖ`, and the last nonzero multiple is
  `ϖ`-torsion.
- `defect_ne_top`: a finitely generated module over a DVR has finite defect. The torsion
  submodule is generated by finitely many torsion elements. Each cyclic piece is a quotient of
  `R/(a)`, which has finite length by Mathlib's `isFiniteLength_quotient_span_singleton`.
- `exists_eq_zero_of_drop`: if `δ (n+1) + ν n ≤ δ n`, `δ 0 < ⊤`, and `ν n ≠ 0` whenever
  `δ n ≠ 0`, then some `δ n` vanishes.
