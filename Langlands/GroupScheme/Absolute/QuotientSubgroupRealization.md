# Realizing prescribed subgroup images by rational conjugation

`QuotientSubgroupRealization.HasSurjectiveImageFactorization q i j` is defined for group schemes over any field `k : Type u`. It means that some homomorphism `p`, surjective on underlying scheme spaces, satisfies `i ≫ q = p ≫ j`. This diagram predicate imposes no closed-embedding assumptions on `i` or `j`.

All three theorems below work over an algebraically closed field `k : Type u`. The generic conjugation theorem assumes that the source `G` of `q` is locally of finite type over `k` and that `q` is surjective on underlying scheme spaces. The Borel realization corollary assumes that `G` and `Q` are smooth connected affine group schemes. The maximal-torus realization corollary assumes that both ambient groups are smooth and affine and that `Q` is connected; `G` may be disconnected. Both realization corollaries assume scheme surjectivity of `q` and retain the image-preservation premises specified below.

This internal module formalizes the conjugacy argument in Milne, *Algebraic Groups* (2017), Proposition 17.20, pp.357–358. It does not assume the full quotient-subgroup image statement.

- `QuotientSubgroupRealization.exists_conjugate_image`: given maps `i : H ⟶ G`, `j : C ⟶ Q`, a surjective homomorphism `p : H ⟶ C` with `i ≫ q = p ≫ j`, and a rational subgroup conjugacy from `j` to `j' : C' ⟶ Q`, there are `g : G(k)` and a surjective `f : H ⟶ C'` such that `(i ≫ Int(g)) ≫ q = f ≫ j'`. The maps `i`, `j` and `j'` need not be embeddings. Lift the conjugating point to `G`, use naturality of inner automorphisms, and compose `p` with the source isomorphism witnessing conjugacy. The conclusion uses `HasSurjectiveImageFactorization`, whose expanded form is this existential factorization.
- `QuotientSubgroupRealization.exists_borel_image_of_borel_images`: assume that every source Borel admits a target Borel and a scheme-surjective factor map giving its commuting image square. Every prescribed Borel `j : C' ⟶ Q` is then the image of a source Borel with a scheme-surjective factor map. Choose a source Borel, use the given Borel-image premise, and apply the preceding lemma using Borel conjugacy. Conjugation preserves the source Borel property.
- `QuotientSubgroupRealization.exists_maximalTorus_image_of_maximalTorus_images`: assume that each supplied smooth closed image of a source maximal torus, with a scheme-surjective factor map and commuting square, is a target maximal torus. Every prescribed maximal torus `s : S.toGrp ⟶ Q` is then the image of a source maximal torus `t : T.toGrp ⟶ G`, with an actual homomorphism `f : T ⟶ S` of commutative group schemes whose underlying scheme map is surjective and which gives the commuting square. Choose a source maximal torus, form its actual smooth connected schematic image, and identify the image as a split torus using schematic dominance. The preservation premise makes it maximal. Maximal-torus conjugacy and the generic lifting lemma give the required source embedding and factor map.

The existence and conjugacy inputs are the published Library theorems. Flatness of the ambient map is not needed for this conjugacy step.
