# Fppf-local innerness of special-linear matrix conjugation

Suppose one invertible matrix over the base field intertwines an actual
special-linear group automorphism on every test scheme. Adjoin a root of the
inverse determinant, of order equal to the matrix size, on a faithfully flat
finitely presented cover. Scaling the matrix by that unit makes its determinant
one. The point with this matrix implements the same automorphism on every
refinement of the cover because scalar matrices commute with all matrices.

This internal consequence of the actual point functors and the unit-root
cover applies over arbitrary fields, including when the characteristic divides
the matrix size. It supplies local innerness of the matrix discrepancies in
the norm-one calculation.
