# Actual conjugation parameters in relative Hom schemes

For a group-scheme homomorphism `f : H → G` and a point `g` of `G` over a test scheme, `conjugationFamily` is the actual pulled-back homomorphism followed by conjugation by the actual pulled-back point `g`. Given an actual universal relative Hom family `i` on a scheme `Y`, `conjugationParameter f i hi g` chooses its unique parameter in `Y`. The point `g` can lie over any test scheme. There are no smoothness, affineness or torus hypotheses in these constructions.

For a commutative group-scheme source `A`, the exact fiber theorem says that two parameters associated to `g` and `h` agree if and only if `g⁻¹ * h` belongs to the published all-test subgroup functor `torusCentralizer f`. The source need not be a torus for this assertion. `conjugationParameter_comp` proves naturality under every morphism of test schemes, so the parameter of the universal point restricts to the parameter of each point.

The implemented proof compares direct and iterated pullback points through the published family point adjunction, first proving its compatibility with relative Hom evaluation. Constant relative homomorphisms and inner automorphisms commute with restriction. Uniqueness in the supplied universal family then proves parameter naturality. For the fiber theorem, arbitrary base change carries the all-test centralizer to the centralizer of the actual pulled-back homomorphism. The base-point centralizer criterion identifies it with the equality obtained by fixing that homomorphism under an inner automorphism. The group law for inner automorphisms turns equality of conjugations by `g` and `h` into fixing by `g⁻¹ * h`. Finally, injectivity of universal evaluation transfers this equality to parameters.

This module is an internal derived construction from the Library's `HomScheme.Universal`, the pullback point comparisons in `RelativeLevi.ModuliConjugation`, the actual inner automorphisms, and `torusCentralizer_baseChange`. It transcribes no additional literature assertion and changes no existing statement.
