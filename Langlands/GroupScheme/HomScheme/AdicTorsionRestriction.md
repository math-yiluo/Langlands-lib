# Algebraized torsion restrictions of adic Hom systems

`AdicTorsionRecoveryStatement.{u}` concerns formal Hom systems from a relative
commutative group of multiplicative type over a complete noetherian local
ring. Precomposing a system with each positive integer torsion inclusion
produces a formal Hom system from a finite source. The finite-source adic
bijection lifts these restrictions to actual maps. Its uniqueness makes the
actual maps compatible under divisibility, including along any prime-power
tower.

An actual map recovers the original formal system exactly when it induces
these maps on all positive integer torsion. For the reverse implication,
detection on torsion is applied at each adic level after the canonical
base change comparison. This also gives injectivity of adic Hom restriction
for the original source.

The construction of the actual torsion maps is the finite-source step in
SGA 3, Exposé XV, Proposition 4.3, Gille–Polo recomposition, PDF p. 28.
The recovery equivalence here uses all positive integer torsion.
