# Exclusion of the inner E6 branch marking

The argument uses the actual triple of the first ambient E6 weight. It is
star-fixed for the inner action and lies in the integral root span, so its
Tits obstruction is zero. The comparison with the actual anisotropic
kernel identifies this class with the obstruction of the restricted weight.
The restriction is the triple of the first weight in the induced A5 kernel
numbering.

The kernel has an actual norm-one presentation by a central division
algebra of reduced degree six. Its Tits class normalization gives the
division algebra class and its negative at the endpoints of the A5
numbering provided by the norm-one chart. The actual E6 kernel endpoint
comparison identifies the restricted fundamental weight with one of these
endpoints. Additivity makes the restricted triple obstruction the triple
of the corresponding signed division algebra class. The tensor-cube
nonsplitting theorem gives nonvanishing for either sign.

The contradiction excludes the specified branch marking and trivial full
star action over any field.
