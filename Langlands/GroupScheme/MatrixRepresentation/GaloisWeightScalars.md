# Descent of equivariant scalar operators on actual weight spaces

This internal derived module realizes Galois-equivariant scalars on
actual geometric character spaces as one actual intertwining matrix
over the original field. The hypotheses are an affine original group,
a Galois field extension, spanning of the extended character spaces,
and a scalar function on the actual characters whose values transform
by the coefficient automorphisms on every occurring character. There
is no irreducibility or multiplicative-type hypothesis.

First prescribe scalar action on all character spaces by summing the
scalar multiples of the character coefficient projectors. Only finitely
many character spaces are nonzero, by independence and finite dimension.
The projector equations prove the required scalar action, including on
the zero character spaces. With spanning, preservation of every character
space proves actual equivariance on all affine algebra tests.

The resulting extension-field linear operator commutes with
coefficientwise Galois conjugation. For each automorphism, the vectors
on which this commutation holds form a subspace. Scalar covariance and
Galois compatibility prove that each character space lies in it;
spanning therefore proves commutation everywhere. Applying this to
standard basis vectors shows that every matrix entry is fixed by every
ground-field automorphism. The Galois fixed-field theorem descends
each entry to the original field. Functional descent of intertwiners
then gives original actual equivariance, and the recovered matrix still
acts by the prescribed scalars on all geometric character spaces.

The proof uses arbitrary affine algebra tests throughout, including
nonreduced algebras. Its provenance is internal: these are coordinate
and descent constructions for the existing actual character spaces,
projectors, Galois character action and intertwining predicates, intended
for the fixed-field endomorphism clause of the representation theorem.
