# Split-torus character spaces under field extension

This internal development identifies the actual character spaces of a finite matrix representation of a split commutative group scheme over a field with the scalar extensions of the original character spaces. It uses the all-affine-test meaning of `MatrixRepresentation.characterSpace`, so the assertion concerns scheme representations, including points over nonreduced algebras. The extension field is arbitrary.

`latticeCharacterSpace` reindexes the existing character space by the actual character lattice. `extendedLatticeCharacterSpace` is its scalar-extended span in the standard coordinates. The membership theorem follows from the actual affine base-change comparison and equality of character values. These extended spans still span the extended representation: tensor induction reduces this to the published complete split-torus character decomposition. The refinement lemma and independence of the new character spaces then identify each new character space with the corresponding extended span. Injectivity of character-lattice base change isolates the single summand. The standard coordinate tensor equivalence and flatness produce `latticeCharacterSpaceBaseChangeEquiv`; equality of finite dimensions and preservation of nonzero character support follow.

Provenance: this is a derived linear-algebra consequence of the published character decomposition and scheme base-change APIs. It supplies the weight-space part of the proof route for Milne, *Algebraic Groups* (2017), Theorem 12.12 (printed pp.234–235) and the base-change discussion in 22.5 (p.464), registered source `milne-2017-algebraic-groups`, SHA-256 `899b0f44f3c3ccfbaf5ed1cf9c180be7a8016b1c0e9709ca0c206304e5bd1cd0`. The official 2017 errata snapshot registered as `milne-2017-algebraic-groups-errata-2026-11-02` was read; it does not amend these assertions. No highest-weight classification or irreducibility theorem is assumed here.
