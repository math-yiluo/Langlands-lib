# The sum of normal-subgroup character spaces

Worker 1228.

For a normal subgroup represented by a monomorphism, conjugation by an ambient
base point gives an actual automorphism of the subgroup. This construction uses
the published normalized-conjugation morphism and its naturality, followed by
the group-scheme Yoneda construction. Its composite with the subgroup inclusion
is ambient conjugation on every test scheme.

The matrix of a constant point is scalar extension of the ground-ring rational
matrix, both on arbitrary scheme tests and in an affine test algebra. These
identities follow from representation naturality and the standard isomorphism
between the sections of the base spectrum and the base ring.

For an affine normal subgroup over any field, translating a subgroup character
vector by an ambient rational point produces a vector for the character pulled
back by inverse conjugation. This is checked at the subgroup's universal affine
point, using its actual conjugation morphism and the matrix identity relating
conjugation and translation. Consequently the sum of all subgroup character
spaces is preserved by every ambient rational matrix.

If the field is algebraically closed and the ambient group is reduced and
locally of finite type, the rational-point stability detector makes any split
coordinates of this sum invariant on all scheme tests. The subgroup is not
assumed smooth or reduced. This is an internal derivation from the published
normalization, actual representation, character-space, and rational-point
detection interfaces. It does not yet construct the restricted representation,
prove its character-space spanning, cancel a character, or construct a quotient.
