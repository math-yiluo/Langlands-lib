# First intrinsic cyclic cutoff and the dynamic unipotent subgroup

This internal bridge for the proof of `RelativeUnipotentRadicalFiltrationStatement`
(`RelativeUnipotent.RadicalFiltrationProof`) identifies the first rank-one intrinsic
cyclic weight cutoff with the actual dynamic unipotent subgroup. It works in
arbitrary universe `u`, over an arbitrary commutative ring. No field,
smoothness, finite type, reducedness, connectedness or nonempty-base
hypothesis is imposed.

For a corepresented group `G = Corepresented.groupScheme F e` and a supplied
cocharacter `χ : Gm → G`, `rankOneAction e χ` is the actual conjugation action
transported through the inverse of `splitTorus.gmIso`, with the identity
isomorphism on `G`, then read on coefficient-algebra points through
`TorusAction.ofAutomorphicAction`. `rankOneFirstCut e χ` is the unchanged
`cutSubgroupFunctor` associated to the intrinsic `weightIdeal` of the cyclic
tail generated by the constant exponent one, starting at one.

`rankOneExponentEquiv` reads the only exponent in `PUnit → ℤ`.
`rankOneLaurentEquiv` is its induced algebra equivalence to the usual Laurent
polynomial algebra. It preserves constants and sends the universal rank-one
unit to the Laurent unit `T`. `rankOne_torusPt` checks that the actual inverse
torus isomorphism reads that one unit, using the existing point comparison
for `gmIso`.

The proof of `rankOne_rho_eq_coaction` compares the actual intrinsic coaction
`rho` with the dynamic conjugation coaction `coaction χ`. It pushes the
universally twisted point along the Laurent algebra equivalence, uses
naturality of the action, and applies the existing `pointRing_conj` formula
to the resulting conjugation by `χ(T)`. The existing affine-point coordinate
comparison and `eval₂_T_mapRingHom` identify the resulting ring map exactly.
Applying this to the universal point gives equality of the coactions.
`rankOne_comp_eq_coaction_coeff` consequently identifies an intrinsic
component at `m` with the Laurent coefficient at `m PUnit.unit`.

The two existing counits agree because both classify the identity point.
The first cyclic tail consists exactly of the exponent vectors whose only
coordinate is positive. Thus `mem_rankOne_firstCut_iff` identifies the
intrinsic component equations outside that tail with vanishing of every
negative Laurent coefficient and agreement of the constant coefficient with
the identity augmentation. These are precisely the equations in the
arbitrary-ring theorem `mem_unipotent_iff`.

`rankOne_firstCut_eq_unipotent` proves equality with `Dynamic.unipotent χ`
on all scheme tests, including non-affine and nonreduced tests. It uses the
preceding affine-point equality and the existing
`cutSubgroupFunctor_affineSubgroups` theorem for the actual affine cutout
`isAffineCutOutBy_unipotent χ`. No extra effectivity or local membership
premise is supplied.

For any group `G` over `Spec R` with affine total space,
`Dynamic.Affine.intrinsicFirstCut χ` constructs this cutoff in
`AffineCoordinates.corepresentation G` and transports it to `G`.
`Dynamic.Affine.intrinsicFirstCut_eq_unipotent` uses the existing dynamic
isomorphism-transport theorem to prove equality with the supplied
cocharacter's actual unipotent subgroup functor.

The provenance is internal: the result is derived from the existing split
torus point comparison, corepresented coordinates, conjugation coaction and
dynamic representability results. Only the arbitrary-ring definition of
`cyclicTail` is used from the polynomial weight interface; no field-only
weight-filtration comparison is invoked. Root-chart existence, higher cutoff
invariance, parabolic normality and the radical-filtration statement
`RelativeUnipotentRadicalFiltrationStatement` remain separate obligations.
