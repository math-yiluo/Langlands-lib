# Constructed affine etale face charts of a supplied relative parabolic

Let `p : H → G` be a supplied relative parabolic of a reductive group scheme over an arbitrary scheme `S` in universe `u`. The ambient structure morphism is recorded as affine. For every point `s : S`, `affineParabolicFaceChartAt` constructs an actual affine etale chart through `s` containing all local data needed for the canonical face filtration.

The resulting `AffineParabolicFaceChart` stores its coefficient ring, actual map to the original base, etaleness, and a specified point over `s`. It stores a finite coordinate torus maximal in every ambient residue-field fibre, a full fibrewise root datum, genuine actual root parametrizations, one fixed integral coordinate cocharacter dynamically presenting the original pulled-back parabolic inclusion, and an actual `SplitParabolicFaceChart` with its original unscaled face weights. Neither a split chart nor a dynamic presentation nor root parametrizations are assumed to exist as additional inputs. The finite coordinate and root-index types may vary with the point.

The proof starts with an actual affine etale maximal split torus inside the parabolic. Geometric maximality reflects to each residue fibre through the closed ambient inclusion. The principal-neighborhood construction for this prescribed torus supplies one fixed integral presenting cocharacter, a full root datum and free actual root weight lines simultaneously. Along the composite map to the original base, the proof transports the torus and root datum by the actual pullback comparison, transports the free actual weight lines, and uses global root parametrization from these free weights. The established face-chart existence proof constructs the chart. The dynamic presentation is transported through the same actual pullback comparison, preserving the original supplied parabolic map. The principal localization has a point over the first chart point, so the resulting etale chart retains a specified point over the original `s`.

No affineness of `S`, nontriviality or locality of any coefficient ring, reducedness, connectedness, or prescribed local root datum is assumed. The result is a local construction; finite extraction of a cover, a global bound, effective descent and the final finite-series theorem remain separate steps.

The implementation is derived internal infrastructure using the established relative-parabolic split maximal-torus charts, principal full-root data, global root parametrization, canonical face-chart construction and actual pullback coherence. It adds no independent literature assertion.

The supporting `SplitParabolicWeightChart`, `SplitParabolicVectorSeries` and `SplitParabolicFaceChart` pairs each receive one explicit name for an existing local affine-source instance. Their types, proofs, local scopes and mathematical declarations are unchanged. These naming changes resolve anonymous-declaration collisions exposed when importing the face-chart development together with global root parametrization; they are needed for this combined construction to compile.
