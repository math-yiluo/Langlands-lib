# All-test matching of the original face terms on chart overlaps

This internal descent input proves matching of the actual original face-term
maps from two constructed charts of the same supplied relative radical.

For a common affine parameter scheme, construct the two full face models in
the same actual direct pullback of the original ambient group. The supplied
relative radical is preserved by base change in a relative parabolic of a
reductive group. The canonical model comparison therefore identifies the
original term ranges at each unchanged cutoff. Over a zero coefficient ring
the parameter spectrum is empty; all subgroup functors agree there on every
test, which handles that case without a nontriviality premise.

For an arbitrary common parameter scheme, reflect equality of the two
monically represented subgroup functors on its affine basis cover. Actual
pullback tower coherence identifies each restriction with its direct original
ambient comparison; the source tower comparison is an isomorphism and hence
does not change the represented range. Applying the affine comparison on
each component gives the desired all-test equality. The original inclusions
and actual ambient comparison maps occur throughout the conclusion.

This proves term matching rather than assuming a descent datum. It makes no
claim yet about the effectivity of the global quotient or vector bundle descent.
