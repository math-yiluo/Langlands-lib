# Additive root maps into the generic Chevalley closure

This internal construction factors every additive root homomorphism through
the same generic Chevalley integral model over a Dedekind domain with a
specified fraction field. The generic Chevalley group is chosen once.

The ring-level root matrix maps commute with every homomorphism of base
rings. Both composites have the same root exponential on all test points,
using the published vector-group and general-linear base-change comparisons.
The additive group is flat because its polynomial coordinate algebra is free.
Its generic projection is therefore schematically dominant, so the generic
root factorization descends through the closed integral model inclusion.
Cancellation through that inclusion gives the group laws, uniqueness and
compatibility with the original generic root map.

The provenance is internal: these are consequences of the published integral
matrix maps, generic closure, schematic-dominance factorization and vector
base change. This module does not establish integral root closedness,
smoothness or reductivity of the closure, or comparison of all field fibres.
