# Actual affine row coordinates

This derived comparison identifies the explicit determinant-one quotient with
the chosen affine coordinate algebra of the special linear group. It first
uses the affine spectrum/global-sections comparison and then the proved
identification of chosen coordinates with actual global functions.

The comparison sends a row polynomial to a function whose value on every
relative test scheme is the polynomial evaluated at that matrix row. Thus the
full binary homogeneous space embeds into the actual coordinate algebra, using
the injectivity of the bottom-row map over the base field.

The binary monomial expansion proves that scaling both variables multiplies a
homogeneous polynomial of degree `m` by the `m`-th power of the scalar, over any
commutative test algebra. Matrix multiplication then gives the corresponding
bottom-row scaling for an upper-triangular left factor. For any actual affine
group map into the binary special linear group whose matrices are upper
triangular on every test scheme, and any coordinate whose evaluations are the
last diagonal entry on every test scheme, this proves membership of each
homogeneous row function in the covariant subspace for the corresponding
power of that coordinate. The universal-test theorem converts the pointwise
identity into the defining tensor equation; it uses no density assumption.

These are elementary consequences of the published coordinate comparisons,
polynomial substitution and binary basis. They do not yet identify the entire
covariant coordinate subspace or construct a Borel subgroup.
