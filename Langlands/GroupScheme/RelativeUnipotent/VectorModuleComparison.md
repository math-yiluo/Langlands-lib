an actual free module map on all scheme tests in canonical section coordinates.
It proves uniqueness of the module map from those coordinates, and compatibility
with composition and inverses. Positive-weight vector-group isomorphisms supply
actual compatible comparisons through the constructed free-module isomorphism.

The uniqueness proof uses canonical pulled-back basis vectors on the identity
test, actual free-sheaf generator faithfulness, and faithfulness of identity
module pullback.

`Compatible` is the exact canonical all-test section equation. Its composition
and inverse rules follow from the original group-map equations, actual module
pullback functoriality, and invertibility of the prescribed module comparison.
`Comparison` contains an actual module isomorphism and this equation for an
actual original vector-group isomorphism. `Comparison.ofWeight` constructs it
from a positive common scalar weight, using the preceding arbitrary-ring
free-module isomorphism construction. Only the forward weight is needed.
`Comparison.unique`, `trans` and `symm` retain the actual maps and compatibility.

Consequently, whenever two comparison constructions implement the same original
group isomorphism, their actual module isomorphisms agree. This supplies the
faithfulness step for deriving module cocycle equations from the original
quotient comparison equations, without postulating such equations for the
module maps. The parent filtration construction still must supply the original
overlap group comparisons, coefficient-basechange compatibility, actual overlap
gluing and the resulting descent datum.

The base ring is arbitrary, the two finite ranks are independent, and zero
ranks and the zero ring are included. Provenance is an internal derivation from
actual free-sheaf generators, canonical free-vector section coordinates and
the constructed positive-weight module isomorphisms.
