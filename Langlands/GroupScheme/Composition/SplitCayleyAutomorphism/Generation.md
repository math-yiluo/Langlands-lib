# Generation of the split Cayley automorphisms by root and torus elements

Coordinates on Zorn's algebra are `(a, u₁, u₂, u₃, v₁, v₂, v₃, b)`, indexed `0, …, 7`, as in
`RootGroups.md`. `e₀ = Pi.single 0 1` and `e₇ = Pi.single 7 1` are the two diagonal idempotents;
their sum is the unit. `IsAutomorphism f` means that `f` fixes the unit and preserves Zorn's
product `mulFun`.

## Block matrices and the long-root `SL₃`

- `IsAutomorphism.comp` and `isAutomorphism_mul`: composites and matrix products of automorphisms
  are automorphisms.
- `zornBlock M N` is the block-diagonal `8 × 8` matrix `diag(1, M, N, 1)` for `3 × 3` matrices
  `M` (acting on `u`) and `N` (acting on `v`). `zornBlock_mulVec` computes it on a vector, and
  `zornBlock_mul` and `zornBlock_one` state that `zornBlock` is multiplicative and unital.
  `matrix_eq_of_mulVec` states that two matrices with the same action on all vectors are equal.
- `rootTorusClosure k` is the subgroup of `GL₈(k)` generated by all root elements
  `rootGL α r` and all torus elements `torusGL s t`. `rootTorusMatrices k` is the submonoid of
  its underlying matrices; `mem_rootTorusClosure_of_val_mem` recovers membership in the subgroup.
- `sl3BlockMatrix M` is the displayed block matrix `zornBlock M (M⁻¹)ᵀ = diag(1, M, (M⁻¹)ᵀ, 1)`.
  It is multiplicative (`sl3BlockMatrix_mul`). The next section shows that every automorphism
  matrix fixing the diagonal idempotent `e₀` is `sl3BlockMatrix M` with `det M = 1`. These
  matrices form the stabilizer of `e₀`, which is the long-root `SL₃` of `G₂`. Its six roots are
  the long roots `lᵢⱼ`, which form a subsystem of type `A₂`. It is not a Levi factor of a
  parabolic subgroup: the proper standard Levi factors of `G₂` have semisimple rank at most one.
  - `sl3BlockMatrix_transvection_mem`: the block matrix of an elementary transvection
    `1 + c Eᵢⱼ` (`i ≠ j`) is the long-root element `x_{lᵢⱼ}(c)`.
  - `sl3BlockMatrix_diagonal_mem`: the block matrix of a diagonal matrix `diag(d₀, d₁, d₂)` with
    `d₀d₁d₂ = 1` is the torus element with parameters `d₀, d₁`.
  - `sl3BlockMatrix_mem_of_det_eq_one`: for every `3 × 3` matrix `M` of determinant `1`, the
    block matrix of `M` lies in `rootTorusMatrices k`. The proof writes `M` as a product of
    transvections, a diagonal matrix and transvections with Mathlib's
    `Matrix.Pivot.exists_list_transvec_mul_diagonal_mul_list_transvec`. Taking determinants
    shows that the diagonal factor has determinant `1`.

## The stabilizer of `e₀`

Let `M` be an automorphism matrix with `M e₀ = e₀`.

- `fix_seven`: `M e₇ = e₇`, because `M` fixes the unit `e₀ + e₇`.
- `stab_u`, `stab_v`: the columns `M uᵢ` lie in the `u`-block and the columns `M vᵢ` lie in the
  `v`-block. The proof applies `M` to `e₀ uᵢ = uᵢ`, `uᵢ e₀ = 0`, `vᵢ e₀ = vᵢ` and `e₀ vᵢ = 0`.
- `fix_eq_zornBlock`: hence `M = zornBlock (blockU M) (blockV M)`, where `blockU M` and
  `blockV M` are the `3 × 3` blocks of `M` on `u` and on `v`.
- `fix_transpose_mul`: `(blockU M)ᵀ (blockV M) = 1`. The proof applies `M` to the products
  `uᵢ vⱼ = δᵢⱼ e₀`, using `fix_dot` to read off the `a`-coordinate.
- `fix_det`: `det (blockU M) = 1`. The proof applies `M` to `u₁ u₂ = v₃`, which expresses the
  `v₃`-column of `M` as the cross product of the `u₁`- and `u₂`-columns. It then compares this
  with the `(3, 3)` entry of `fix_transpose_mul`.
- `exists_sl3BlockMatrix_of_fix`: therefore `M = sl3BlockMatrix B` for the matrix `B = blockU M`
  of determinant `1`.

## Moving an idempotent to `e₀`

- `Good p`: every automorphism matrix `g ∈ GL₈(k)` with `g e₀ = p` lies in
  `rootTorusClosure k`.
- `IsIdem p`: `p` is an idempotent (`p p = p`) different from `0` and from the unit.
  `IsIdem.coords` writes out the coordinate equations of `p p = p`:
  `a² + u·v = a`, `(a + b)uᵢ = uᵢ`, `(a + b)vᵢ = vᵢ` and `b² + u·v = b`.
- `good_of_rootFun`: if `Good (x_α(r) p)` holds then `Good p` holds. Indeed `x_α(r) g` has first
  column `x_α(r) p`. `isIdem_rootFun` states that root elements preserve `IsIdem`.
- `good_single_zero`: `Good e₀`, by `exists_sl3BlockMatrix_of_fix` and
  `sl3BlockMatrix_mem_of_det_eq_one`.
- `sub_ne_zero_of_idem`: if `u·v = 0` and some `uᵢ` or `vᵢ` is nonzero, then `a + b = 1` and
  `a² = a`, hence `a - b ≠ 0`. If `a = b` then `2a = 1` and `a² = a`, which gives `1 = 0`. This
  works in every characteristic.

The reduction applies root elements step by step:

- Step A (`good_of_diag`): if `u = v = 0` then `a, b ∈ {0, 1}`. Since `p ≠ 0` and `p` is not the
  unit, `p` is `e₀` or `e₇`. The case `e₇` is reduced to `e₀` by
  `x_{v₁}(1) x_{u₁}(1) x_{v₁}(1) e₇ = e₀`.
- Step B (`good_B`, `good_B2`, `good_B2a`, `good_B3`): if `u = 0`, then `x_{l₂₁}(-1)` or
  `x_{l₃₁}(-1)` makes `v₁ ≠ 0` (unless `v = 0`, which is Step A). Next, `x_{l₁₂}(v₂/v₁)` and
  `x_{l₁₃}(v₃/v₁)` make `v₂ = v₃ = 0`. Finally `x_{v₁}(-v₁/(a - b))` makes `v = 0`. Each of these
  elements keeps `u = 0`.
- Step C (`good_of_isIdem`, `good_C2`, `good_C2a`, `good_C3`): if `u ≠ 0`, then `x_{l₁₂}(1)` or
  `x_{l₁₃}(1)` makes `u₁ ≠ 0`. Next, `x_{l₂₁}(-u₂/u₁)` and `x_{l₃₁}(-u₃/u₁)` make `u₂ = u₃ = 0`.
  Then `x_{u₁}(r)` makes `u = 0` when `u₁ + r(a - b) - r²v₁ = 0`; this is Step B. Such an `r`
  exists (`exists_root_C3`): if `v₁ ≠ 0` it is a root of a quadratic polynomial, which exists
  because `k` is algebraically closed; if `v₁ = 0` then `a - b ≠ 0` and `r` solves a linear
  equation.

## Conclusion

- `isIdem_mulVec_single_zero`: for an automorphism `g ∈ GL₈(k)`, the first column `g e₀` is an
  idempotent. It is nonzero and is not the unit, because `g` is injective and fixes the unit.
- `mem_rootTorusClosure`: over an algebraically closed field every automorphism matrix in
  `GL₈(k)` lies in `rootTorusClosure k`.
- `generation : GenerationStatement.{u}` proves the generation statement of `Interface.lean`.

This is an internal elementary argument written for this development. It is used to prove that
the automorphism group scheme of the split Cayley algebra is connected.
