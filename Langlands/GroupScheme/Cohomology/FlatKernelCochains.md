# Regular deformation cochains from actual flat kernels

Let `H` be a flat affine group scheme and `G` any smooth group scheme over `Spec R`, with a square-zero ideal `I` supplied as `Fact (SmoothLifting.SqZero I)`. Set `M = Additive(NonaffineKernel.kernel G I)`, with its actual base reduction-kernel module structure. The target need not be affine or separated. There are no module finiteness hypotheses.

The flat pair-coordinate algebra is `C_H ⊗[R] C_H`. `tripleCoordinateAlgebra` is `(C_H ⊗[R] C_H) ⊗[R] C_H`, with three independent actual source points and a specialization map to any prescribed triple. The specialization identities follow from the tensor-algebra universal property and the chosen source coordinates. `twoCocycle_of_flat` proves that a regular two-cochain satisfying the cocycle equation on all flat tests satisfies it on every affine test: specialize the equation at this flat generic triple and use naturality of the cochain and representation. `oneCocycle_of_flat` makes the analogous argument at the flat generic pair.

For the defect construction, the inputs are an actual scheme morphism `s : H.X → G.X` and, on each affine algebra `A`, a supplied homomorphism `s₀(A) : H(A) → G(A/IA)` that agrees with the actual reduction of `s`. `liftDefectPoint` is the actual kernel element with point value `s(h) s(k) s(hk)⁻¹`. Its coefficient naturality follows from the actual coefficient maps on kernel points and regularity of `s`.

`regularDefectCochain` applies the canonical flat kernel equivalence to the actual defect at the independent generic pair, then specializes that tensor to define a regular two-cochain on all affine tests. `regularDefectCochain_flat` proves that on every flat test it agrees with the actual kernel defect under the flat comparison. This uses coefficient naturality and the specialization of the generic pair.

`regularDefectCochain_isCocycle` combines the actual kernel's associative defect identity with the regular action constructed in `FlatKernelActions`. The identity first holds on flat tests, where both comparisons are valid; `twoCocycle_of_flat` gives it on all tests. If the actual quotient-base source `H_{R/I}` has `HasVanishingLowDegreeCohomology`, `regularDefectCochain_isCoboundary` gives an actual natural one-cochain primitive over the original base. This invokes `SurjectiveBaseChange.lowDegreeCoboundaries_of_baseChange`, using the canonical `R/I`-module structure on the base square-zero kernel.

For actual homomorphisms `f,f' : H → G`, the second construction takes an equality of their pointwise reductions on every affine algebra. `homKernelRepresentation` is the regular kernel representation through `f`. `homDifferencePoint` has actual value `f'(h) f(h)⁻¹` and is natural under coefficient maps. `regularDifferenceCochain` constructs a regular one-cochain from its generic-point tensor, with a flat-test comparison proved as for the defect. The actual kernel difference identity and `oneCocycle_of_flat` prove `regularDifferenceCochain_isCocycle` on every affine test. Under the same quotient-base vanishing hypothesis, `regularDifferenceCochain_isCoboundary` supplies an actual element of the original base kernel as primitive.

This is an internal derived construction from actual nonaffine kernels, their canonical comparison on flat algebras, affine coordinate specialization and quotient-base reflection. The supporting kernel and flat-base-change modules are reused unchanged. The supplied scheme map, reducing homomorphisms, pointwise reduction equalities and quotient-base vanishing remain explicit inputs. The module identifies no actual reduction kernel on nonflat tests. It does not reconstruct a corrected scheme homomorphism or a base-point conjugator and does not prove the full infinitesimal lifting statement.
