# Affine presentation of the actual roots-of-unity kernel

Author: Worker 354. Worker 407 supplied the proposed interface and functorial proof route.

`Langlands.GroupScheme.MuAffinePresentationStatement.{u}` defines the proposition

```lean
∀ (A : CommRingCat.{u}) (n : ℕ), 0 < n →
  Nonempty ((mu (Spec A) n).X ≅
    Over.mk (Spec.map (CommRingCat.ofHom
      (algebraMap A (AdjoinRoot ((Polynomial.X : Polynomial A) ^ n - 1))))))
```

The isomorphism is in `Over (Spec A)`. Thus it identifies the actual structure
morphism of the existing roots-of-unity kernel with the spectrum map of the
canonical algebra map. Mathlib's `AdjoinRoot f` is the quotient of the polynomial
ring by the ideal generated by `f`; the expression here is `A[X]/(X^n - 1)`.
There is no separately supplied affine model or presentation hypothesis.
This module defines a proposition and does not prove it.

## Exact scope and existing construction

The quantifiers range over every commutative ring in an arbitrary universe `u`
and every positive natural number. Trivial rings are included. There is no
invertibility hypothesis on `n`, and no nontriviality, reducedness, field,
connectedness, or noetherianity hypothesis on `A`.

The unchanged import `Langlands.GroupScheme.Multiplicative` defines `mu S n`
using `torsion (Gm S).toGrp n`, hence the kernel of the existing multiplication
endomorphism. Its `Gm` is the base change of the integral Laurent spectrum and
represents global units. The present target refers to that actual kernel, with
its existing structural morphism. It asserts only the existence of an
isomorphism of schemes over the base; it does not choose an isomorphism or state
its compatibility with group operations, inclusions, or transition maps.
It also does not assert finiteness, flatness, étaleness, rank, or a monodromy
comparison.

## Sources and functorial derivation

The Stacks Project, [Example 39.5.2, Tag 040M](https://stacks.math.columbia.edu/tag/040M),
identifies the roots-of-unity functor with the spectrum of `ℤ[X]/(X^n - 1)` and
states its base-change description for every base scheme. The proof of
[Lemma 59.28.1, Tag 03PL](https://stacks.math.columbia.edu/tag/03PL), constructs
`A[T]/(T^n - a)` over an affine open. Taking the unit parameter `a = 1` gives
the algebra in this statement. The retained comments to Tag 03PL specify that
`n` is positive. Its hypothesis that `n` be invertible is needed for the étale
calculation and exactness conclusion, not for this affine presentation.

Edixhoven, van der Geer and Moonen, *Abelian Varieties*, preliminary draft,
Chapter III, Examples 2–3, printed p. 32 (PDF p. 36), gives the global-units
functor and its roots-of-unity subgroup, with Laurent-coordinate algebra
`𝒪_S[X,X⁻¹]/(X^n - 1)`. This is construction provenance, not a citation for a
finite-étale theorem.

The following explains the mathematical derivation of the target; it is not
an implemented Lean proof in this module. For any test scheme
`T : Over (Spec A)`, the published natural equivalence `mu.pointsEquiv`
identifies maps from `T` into the actual kernel with units `z` in
`Γ(T.left, ⊤)` satisfying `z^n = 1`. On the other side, `Gm.specHomEquiv`
identifies maps from `T.left` into the quotient spectrum with ring maps from
`A[X]/(X^n - 1)` into `Γ(T.left, ⊤)`. Requiring the morphism to be over `Spec A`
requires that ring map to extend the fixed map from `A` induced by `T.hom`.
The universal property of `AdjoinRoot` therefore identifies these maps with
sections `z` satisfying `z^n = 1`.

Since `n > 0`, each such section is a unit, with inverse `z^(n-1)`. Conversely,
a root of unity has an underlying section with the required polynomial
relation. These constructions commute with pullback of global sections for
every morphism of test schemes, by `mu.pointsEquiv_naturality`,
`Gm.specHomEquiv_comp`, and the quotient universal property. They give a natural
equivalence of the two represented functors on the whole category
`Over (Spec A)`. Yoneda then gives exactly the requested isomorphism in that
category. This argument does not assume that a test scheme is affine and
remains valid for the zero ring.
