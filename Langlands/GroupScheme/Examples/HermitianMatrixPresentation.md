# All-test Hermitian matrix presentations

This internal interface packages supplied presentation data for the general Hermitian matrix point functor. It uses elementary composition of the actual group equivalences in `HermitianMatrixTensorPoints` and `HermitianMatrixReindex`. It assumes no classification or representability theorem and asserts no existence of a presentation for an arbitrary group scheme.

The base and separable quadratic extension fields `k` and `L` have the same arbitrary universe. Finite matrix index types have independent arbitrary universes, and every characteristic is allowed. For a nonsingular Hermitian form `H` and a group scheme `G` over `Spec k`, `SchemeModel.Presentation k L H G` stores a multiplicative equivalence from `(T ⟶ G.X)` to the actual determinant-one matrix subgroup `tensorPoints k L H T`, for every test scheme `T`. Its second field is the entrywise matrix naturality equation for every test morphism `a : T' ⟶ T`, using the actual `SpecialLinear.WeilRoot.tensorMap k L a`. `Presentation.pointsEquiv_map` derives equality in the matrix subgroup itself from this equation by extensionality of subtypes and matrix units.

`tensorReindexEquiv` relabels both matrix axes on every test scheme. Its matrix formula is `Matrix.reindex r r`, with entries pulled back along `r.symm` on both axes. It comes from `specialUnitaryReindexEquiv`, so has the inverse relabeling as its inverse and preserves both Gram preservation and determinant one. `tensorReindexEquiv_naturality` states equality with the actual test restriction on either side of this equivalence; both underlying matrix operations are entrywise.

`Presentation.transport` composes a supplied presentation with a supplied family of multiplicative equivalences of the actual tensor subgroups, provided that family commutes with every test restriction. Its naturality proof combines the two supplied naturality equations. It permits independent finite index types on the two sides.

`Presentation.isometry` instantiates transport using an actual invertible matrix `P` satisfying `adjoint P * J.gram * P = H.gram`. It replaces a presentation for `H` with one for `J`. The exposed value formula is conjugation by `tensorMatrix k L P T` on each test scheme. No determinant-one condition on `P` is imposed. `Presentation.reindex` instantiates transport using relabeling of finite indices, and exposes the corresponding matrix formula. All these constructions retain the full all-test naturality data needed for later scheme identification. They do not store a Witt decomposition or a theorem giving a presentation.
