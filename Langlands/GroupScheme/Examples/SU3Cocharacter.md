# The actual split diagonal cocharacter of the special unitary scheme

This internal construction works over fields `k` and `L` in a common arbitrary universe, with a separable quadratic `k`-algebra extension `L`. It constructs a homomorphism `cocharacter` from the actual multiplicative group scheme over `Spec k` to the closed special unitary scheme `SchemeModel.groupScheme k L`. No characteristic restriction is imposed.

The preliminary coefficient constructions allow commutative rings in independent universes with involutions and a ring homomorphism commuting with them. `twistFixedMap` restricts the entrywise SL3 homomorphism to the inverse-adjoint fixed subgroup. Composing with the established fixed-matrix comparisons gives `specialUnitaryMap` on the actual determinant-one Hermitian GL3 subgroups. Its underlying matrix is entrywise coefficient change. `map_diagonal` and `specialUnitaryMap_diagonal` prove compatibility with the existing diagonal matrix, and `diagonalSpecialUnitaryHom` restricts that matrix homomorphism using its proved form-preservation and determinant-one identities.

For an arbitrary relative test scheme `T`, the existing `SpecialLinear.WeilRoot.includeSections` includes its actual relative global sections in `L ⊗[k] Γ(T, O_T)` through the right tensor factor. `sectionToTensor_bar` proves that quadratic conjugation fixes this image, using conjugation on pure tensors and preservation of one. The existing `SpecialLinear.WeilRoot.tensorMap_includeSections` gives compatibility with the actual restriction of sections. Both are reused from `Langlands.GroupScheme.SpecialLinearWeilDynamicRoots`. `pointsEquiv_map` expresses naturality of the existing all-test special-unitary matrix equivalence as equality in the actual Hermitian subgroup.

`scalarUnit` takes a multiplicative-group point to its invertible global function and then applies the tensor inclusion. Its value is fixed by conjugation, and `scalarUnit_naturality` proves compatibility with every relative test morphism. `cocharacterPoints` applies the diagonal matrix homomorphism to this unit and transports it through the inverse all-test point equivalence. Its naturality follows from the preceding coefficient and scalar identities.

The construction `homOfPoints` then gives the actual group-scheme homomorphism `cocharacter`. `pointsEquiv_cocharacter` verifies its action on every test point. Because the scalar unit is fixed by conjugation, `pointsEquiv_cocharacter_val` identifies its underlying matrix exactly with `diag(t, 1, t⁻¹)`, where `t` is the tensor image of the invertible function represented by that point.

The provenance is internal: the file combines the published fixed SL3/Hermitian matrix comparison, all-test point equivalence, explicit unitary diagonal, multiplicative-group section coordinates and the natural-point construction of group-scheme homomorphisms. It proves the specified map and matrix formulas. It does not establish dynamic root contraction, comparison with actual parabolic radicals, smoothness or reductivity of this model, rank-one classification, or the unrestricted local Kneser–Tits theorem.
