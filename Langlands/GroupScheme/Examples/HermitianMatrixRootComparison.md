# General Hermitian matrices and the existing root model

This is internal comparison infrastructure between `HermitianMatrix` and the existing `HermitianRoot` matrix and scheme interfaces. Its provenance is elementary matrix extensionality, scalar extension and composition with the published `HermitianRoot.SchemeModel.isoOfMatrixPoints`. It uses no outer-type-A classification, Witt decomposition or rank-one identification theorem.

For a commutative coefficient ring with a specified involution, `ofRoot H w hw` puts the existing hyperbolic-plus-negative-diagonal matrix `HermitianRoot.gram H` into the general nonsingular `Form` interface. The unit witnesses `w` for the middle weights supply the actual inverse through `HermitianRoot.gramElement`; they impose no determinant-one condition on the Gram matrix. Hermitian symmetry follows entrywise from the involution-fixed middle weights. The middle index and coefficient ring have independent arbitrary universes and the construction permits every characteristic.

`preserves_ofRoot_iff` identifies the two full Gram-preservation equations. `specialUnitarySubgroup_ofRoot` proves equality of the actual subgroups in the same general-linear group, and `rootEquiv` gives the corresponding multiplicative equivalence. Its forward and inverse values are the original invertible matrices. `ofRoot_map` identifies the two ways to perform any compatible coefficient change, and `rootEquiv_map` proves that the actual subgroup maps commute with this comparison.

For fields `k L : Type u` with a separable quadratic extension structure, the scheme comparison uses the existing level-zero middle index type required by `HermitianRoot.SchemeModel`. `tensorForm_ofRoot` identifies scalar extension of the general form with the form built from the specialized tensor weights and their actual tensor unit witnesses. `specialUnitarySubgroup_tensorRoot` proves equality of the resulting subgroups. `tensorRootEquiv` is identity on the actual matrices in both directions. Its naturality theorem states that it commutes with the actual restriction associated to every test morphism, using the existing tensor coefficient map and involution comparison. `rootPresentation` equips the existing represented root model with the general all-test presentation data.

For supplied general presentation data with Gram matrix `ofRoot H w hw`, `Presentation.rootPointsEquiv` converts all test points to the specialized subgroup while retaining matrix naturality. `Presentation.rootIso` applies the existing `isoOfMatrixPoints` to construct the actual scheme isomorphism. `rootIso_hom` identifies its matrix values with those originally supplied. For an arbitrary general form on `HermitianRoot.Index Middle`, `Presentation.rootIsometryIso` first transports a supplied presentation along an actual invertible matrix `P` satisfying `adjoint P * HermitianRoot.gram H * P = J.gram`, then applies the comparison. `rootIsometryIso_hom` states that on every test scheme this isomorphism realizes conjugation by the scalar extension of `P`. No existence of a congruence or of a general presentation is claimed; these remain explicit inputs. A presentation on any equivalent finite index type can first use `Presentation.reindex`.
