# Actual upper points and contraction in the special unitary scheme

This internal construction uses fields `k` and `L` in a common arbitrary universe, with `L/k` a separable quadratic extension. On every relative test scheme over `Spec k`, it constructs the original upper-unitriangular special unitary matrices as actual points of the closed scheme `SchemeModel.groupScheme k L`. It proves these points contract under the actual split diagonal cocharacter. There is no characteristic restriction.

The coefficient constructions work over commutative rings with involution in independent universes. `upperSpecialUnitaryHom` is the original parameter embedding with codomain restricted to the determinant-one Hermitian matrix subgroup using its proved membership. `specialUnitaryMap_upper` proves compatibility with every involution-compatible coefficient homomorphism. `diagonalSpecialUnitaryHom_conjugate_upper` transfers the existing concrete diagonal conjugation identity to this subgroup. `scale_zero_apply` identifies the zero-scaled parameter with the group identity.

For every test `T`, `upperPoints` transports these matrices through the inverse of the actual all-test `pointsEquiv`, with parameters in the actual tensor coefficient algebra `L ⊗[k] Γ(T, O_T)` and its quadratic involution. `pointsEquiv_upperPoints` verifies the specified matrices, and `upperPoints_naturality` proves that restriction pulls back precisely the original two coordinates. Their ranges therefore define the subgroup functor `upperFunctor` on all schemes over the base. This construction does not assume or assert representability of the parameter functor.

`upperContraction` is a morphism `T × A¹ → SU3`. It restricts the original parameter along the first projection and applies `Parameters.scale` with the tensor image of the actual affine-line coordinate along the second projection. That scalar is fixed by conjugation. Thus its first coordinate is multiplied by `s` and its second coordinate by `s²`. `pointsEquiv_comp_upperContraction` verifies this formula after every change of test scheme, using coefficient naturality and the actual composition law for tensor restrictions. The scalar inclusion and its naturality are the existing `SpecialLinear.WeilRoot.includeSections` and `SpecialLinear.WeilRoot.tensorMap_includeSections`.

The final inclusion `upperFunctor_le_dynamicUnipotent` supplies this explicit curve and the two identities as a witness for the dynamic unipotent subgroup on every test scheme.
