# Root images in the hyperbolic unitary group

These internal lemmas prove the root-image conjuncts of `QuasiSplitUnitary.DynamicStatement` from the existing matrix definitions. On every test scheme, an upper (respectively lower) unipotent matrix has the elementary matrix form. Its off-diagonal unitary equation is precisely that the parameter has trace zero. That parameter supplies its preimage under the upper (respectively lower) root homomorphism. Conversely, the defining root matrices meet all three unipotent entry conditions.

The proof uses global sections and the existing point equivalence on arbitrary schemes. It does not require reducedness, invertibility of two, or that the automorphism be nonidentity. This is a direct derived matrix calculation; its source framework and conventions are those recorded in `QuasiSplitUnitaryDynamicStatement.md`.
