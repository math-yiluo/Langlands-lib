# Tensor convention comparison with the existing unitary API

This is an internal compatibility unit for the coordinate construction of Kaletha–Prasad, *Bruhat–Tits Theory: A New Approach* (2023), §2.7, (2.7.2), printed pp.109–110 (PDF pp.140–141). Registered original: `kaletha-prasad-2023-bruhat-tits-new-approach`, SHA-256 `05ad9a284a2577b34d1a270228b74dfb28f520561ae7772d8f38dddb78938732`. It adds no source theorem beyond the already constructed coordinate group. Its purpose is to compare the actual tensor and conjugation conventions with the published `QuasiSplitUnitary` API.

The existing unitary API writes `L tensor[k] R` and places all types in a common universe. The SU3 construction writes `R tensor[k] L` and permits independent universes. In the common-universe case where both APIs apply, `tensorSwap_conjugation` proves that Mathlib's canonical tensor swap intertwines the actual quadratic conjugation with `QuasiSplitUnitary.scalarConjugation`. The proof is induction on tensors: pure tensors agree by definition and addition follows from the algebra-map laws.

`unitaryTensorInvolution` packages the existing scalar conjugation, using its existing involutivity proof. `tensorSwapParametersEquiv` applies tensor swap to the two coordinates and yields a group equivalence, with explicit first- and second-coordinate formulas. `tensorSwap_embedding` proves that this equivalence commutes with the SU3 three-by-three matrix embedding. `tensorSwap_coefficientMap` compares first-factor coefficient change with the existing right-factor coefficient-change map, again by tensor induction.

The unit compares scalar involutions and the resulting SU3 coordinate groups. The two-by-two U(1,1) matrix group of the existing API is a different construction; no identification of it with the SU3 matrix group is asserted. The main SU3 definitions retain independent universes and all characteristics. This compatibility unit shares a universe solely to match the older API, without imposing a characteristic restriction. Group-scheme representability and arbitrary-relative-root-group identifications remain separate obligations.
