# Generation of the actual determinant-one Hermitian matrix subgroup

This internal construction and calculation uses the existing concrete quadratic root parameters, upper and opposite embeddings, diagonals and Weyl representative. It introduces no external structural assertion. The coefficient ring and, in the quadratic specialization, the two fields have arbitrary universes.

For a commutative ring `A` and `RingInvolution A`, `unitarySubgroup` is the subgroup of actual invertible three-by-three matrices preserving the existing Gram matrix `[[0,0,1],[0,-1,0],[1,0,0]]`. Here preservation means `bar(g)ᵀ J g = J` for the specified involution. `specialUnitarySubgroup` is its intersection with the kernel of the actual determinant homomorphism. The conjugate-transpose multiplication identity proves closure under products; cancellation by an invertible matrix proves closure under inverses. The existing upper, diagonal and Weyl form-preservation and determinant calculations give their membership. Rewriting the existing opposite embedding as conjugation by the Weyl matrix gives opposite membership. Therefore the subgroup generated by the two actual coordinate ranges is contained in `specialUnitarySubgroup`.

Over a field `L`, `preservesForm_entry` gives, for all column indices `i,j`, the equation `bar(g₂ᵢ) g₀ⱼ - bar(g₁ᵢ) g₁ⱼ + bar(g₀ᵢ) g₂ⱼ = Jᵢⱼ`. Suppose the involution moves some scalar. To prove the reverse containment, first consider a special unitary matrix with `g₂₀ = 0`. The first-column equation forces `g₁₀ = 0`. Pairing the first column with the third gives `bar(g₀₀) g₂₂ = 1`, so `g₀₀` is nonzero; pairing with the second then gives `g₂₁ = 0`. The determinant-one equation determines `g₁₁ = bar(g₀₀)/g₀₀`. Multiplication by the inverse diagonal with parameter `g₀₀` yields an upper unipotent form-preserving matrix. The existing exact range characterization identifies it with an upper root matrix. The preceding diagonal-generation result then gives membership of the original matrix in `elementarySubgroup`.

For the other case write the first column as `(a,b,d)` with `d ≠ 0`. Its isotropy equation is `bar(d) a - bar(b) b + bar(a) d = 0`. `firstColumnParameter` is the actual root parameter `(bar(b/d), a/d)`: clearing the nonzero denominators in the same equation proves its required trace-norm identity. The lower-left entry of `w · embedding(x)⁻¹ · g` is `a - bar(b/d) b + bar(a/d) d`, which vanishes by that equation. This product remains special unitary, so the preceding case puts it in `elementarySubgroup`. Both the upper root matrix and the actual Weyl matrix already belong to that subgroup; multiplying back proves that `g` does too.

Consequently `specialUnitarySubgroup_eq_elementarySubgroup` identifies the two subgroups over every field with a nonidentity involution, with no characteristic restriction. The theorem `specialUnitarySubgroup_eq_elementarySubgroup_quadratic` specializes to the existing canonical involution of any separable quadratic extension `L/k`; its nonidentity is proved by the imported `fieldInvolution_exists_nonfixed`. No nonidentity assumption is left in this specialization. The proof uses no division by two, so characteristic two is included.

These are concrete matrix-subgroup constructions and generation results. Scheme representability and identification of these matrices and coordinate ranges with actual rational points and parabolic radicals, arbitrary reductive-group root identifications, division-algebra arithmetic, rank-one classification, and the unrestricted local Kneser–Tits theorem remain open.
