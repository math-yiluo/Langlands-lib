# Levi elements of square reduced norm lie in the Eichler subgroup

Module `Langlands.GroupScheme.Quaternionic.EichlerReducedNorm`, namespace
`Langlands.GroupScheme.Quaternionic.FirstKindInvolution.Eichler`.

## Setting

* `D` is a finite-dimensional central division `K`-algebra of reduced degree `2` (a
  quaternion division algebra), with an involution of the first kind `σ`.
* `q` is a Tits `σ`-quadratic form on `D^n`, with `n` linearly ordered.
* `(e, f)` is a hyperbolic pair of `q` (`IsHyperbolic`, module `HyperbolicLevi`).
* `a₀ ∈ Alt` is nonzero, where `Alt = {a - σ a}`.
* `x₀` is orthogonal to `e` and `f` and has `q(x₀) ≠ 0`.

`N_E` is `eichlerLeviSubgroup hP`: the units `a` whose hyperbolic scaling `ℓ(a)`
(`e ↦ a e`, `f ↦ σ(a)⁻¹ f`, identity on `{e, f}^⊥`) lies in the subgroup `E` generated by
Eichler transformations.

## Results

* `mem_eichlerLeviSubgroup_of_reducedNorm_eq_one`: every unit `a` with
  `reducedNorm K D K (1 ⊗ a) = 1` lies in `N_E`.
* `mem_eichlerLeviSubgroup_of_reducedNorm_eq_sq`: every unit `a` with
  `reducedNorm K D K (1 ⊗ a) = t²` for some `t ∈ K` lies in `N_E`.

## Proofs

**Reduced norm `1`.**

1. Choose `c₀` with `[c₀] = q(x₀)` and put `z = -σ(c₀) a₀⁻¹`. Then `z ∉ K`. Otherwise
   `c₀ = k a₀` would be alternating, using `σ(a₀) = -a₀`, and `q(x₀) = 0` would follow.
2. By `CentralDivision.exists_mul_add_eq_conj`, write `a = y X y⁻¹ X⁻¹` with `X = z + s`.
3. Put `c = c₀ + s a₀`. Then `[c] = q(x₀)`, `c ≠ 0`, and `σ(c) = X σ(a₀)`.
4. `commutator_mem_eichlerLeviSubgroup` (module `HyperbolicLevi`) puts
   `g⁻¹ X g X⁻¹ ∈ N_E` for every `g`. Taking `g = y⁻¹` gives `a ∈ N_E`.

**Square reduced norm.**

1. `t ≠ 0`, because `1 ⊗ a` is a unit.
2. Write `a = t · (t⁻¹ a)`.
3. The scalar `t` lies in `N_E` by `algebraMap_mem_eichlerLeviSubgroup`.
4. `t⁻¹ a` has reduced norm `t⁻² t² = 1`, using `reducedNorm_scalar` with reduced degree `2`.

## Provenance

Internal: a combination of the Library's reduced norm with the modules
`HyperbolicLevi` and `QuaternionCommutator`. It is used for Task 5398. Together with the
spin-side fact that a Levi element `ℓ(a)` lifting to the spin group has square reduced norm,
it shows that such `ℓ(a)` lies in the subgroup generated by Eichler transformations.
