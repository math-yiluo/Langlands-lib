# Generation of the unitary group of the standard rank-two antihermitian form

Module `Langlands.GroupScheme.Quaternionic.StandardGenerationTwo`.

Setting: `K` a field, `D` a division `K`-algebra, `σ : FirstKindInvolution K D`. Vectors are
rows and `g` is an isometry of the Gram matrix `H` when `g H ᵗg^σ = H` (see
`UnitaryMatrices`).

## Definitions

- `gramTwo D = !![0, 1; -1, 0]`: a hyperbolic pair `e, f` with `h(e, f) = 1`. Every
  nondegenerate antihermitian form of rank 2 and Witt index 1 has this Gram matrix in a
  suitable basis (proved in a later module). The division algebra `D` is an explicit
  argument.
- `weightTwo = (1, -1)`: the weights of the cocharacter `t ↦ diag(t, t⁻¹)`.
- `diagTwo p q`, `weylTwo s = !![0, s; -s⁻¹, 0]`, `upTwo x = !![1, x; 0, 1]`,
  `loTwo x = !![1, 0; x, 1]`.
- `elementaryTwo`: `contractingElementarySubgroup (gramTwo D) weightTwo`, the subgroup
  generated by isometries of contracting shape for `(1, -1)` or `(-1, 1)`.

## Results

- `mul_gramTwo_mul_apply`, `isometry_gramTwo_iff`: entrywise,
  `(M J ᵗM^σ) i j = M i 0 σ(M j 1) - M i 1 σ(M j 0)`. `isUnit_gramTwo`.
- `upTwo_isometry`, `loTwo_isometry` (for `σ x = x`), `diagTwo_isometry` (`p σ q = 1`),
  `upTwo_isContracting`, `loTwo_isContracting`.
- `realized_upTwo`, `realized_loTwo`, `weylTwo_eq`
  (`weyl(s) = up(s) lo(-s⁻¹) up(s)`), `realized_weylTwo` (for symmetric `s ≠ 0`).
- `realized_diagTwo`: `diag(a, σ(a)⁻¹)` for `a ≠ 0` is realized, writing `a = s t` with
  `s, t` symmetric (`exists_eq_mul_symmetric`, needs `dim_K D = 4`, `dim_K D^σ = 3`) and
  `diag(s t, σ(s t)⁻¹) = weyl(s) weyl(-t⁻¹)`.
- `exists_realized_row_zero_two`: for an isometry `M`, a realized `N` makes `(M N) 0 1 = 0`:
  a Weyl matrix if `M 0 0 = 0`, else `up(-(M 0 0)⁻¹ M 0 1)`, which is symmetric because the
  first row is isotropic.
- `realized_of_row_zero_two`: an isometry with `M 0 1 = 0` equals `diag(a, σ(a)⁻¹) L` with
  `a = M 0 0` and `L` a lower isometry of contracting shape for `(-1, 1)`.
- **`unitaryMatrixGroup_gramTwo_le`**: if `dim_K D = 4` and `dim_K D^σ = 3`, every element
  of `unitaryMatrixGroup (gramTwo D)` lies in `elementaryTwo`; `elementaryTwo_eq` states
  the equality.

## Provenance

Internal. This is the rank-two analogue of `StandardGenerationThree`. Generation is proved
directly by explicit matrix factorizations, and only under the stated hypotheses (`D` of
dimension `4` with a `3`-dimensional symmetric part). The diagonal factor `diag(a, σ(a)⁻¹)` is a
product of Weyl-type matrices because every quaternion is a product of two symmetric elements
(`exists_eq_mul_symmetric`). This is not an instance of a general theorem about unitary groups:
for an arbitrary isotropic unitary group, the rational points need not be generated by unipotent
radicals. All identities are verified in Lean by direct computation.
