# Generation of the unitary group of the standard rank-three antihermitian form

Module `Langlands.GroupScheme.Quaternionic.StandardGenerationThree`.

Setting: `K` a field, `D` a division `K`-algebra, `σ : FirstKindInvolution K D`. Vectors are
rows and `g` is an isometry of the Gram matrix `H` when `g H ᵗg^σ = H` (see
`UnitaryMatrices`).

## Definitions

- `gramThree c = !![0, 1, 0; -1, 0, 0; 0, 0, c]`: a hyperbolic pair `e, f` with
  `h(e, f) = 1`, orthogonal to an anisotropic vector of value `c`. It satisfies the published
  `IsAntihermitian` condition exactly when `c ∈ {a - σ a}` (the diagonal entries must be
  alternating). Skewness `σ c = -c` alone does not suffice in characteristic `2`, where the
  skew elements are the symmetric ones. Every nondegenerate antihermitian form of rank 3 and
  Witt index 1 has such a Gram matrix with `c ∈ {a - σ a}`, `c ≠ 0`, in a suitable basis
  (proved in a later module).
- `weightThree = (1, -1, 0)`: the weights of the cocharacter `t ↦ diag(t, t⁻¹, 1)`.
- `diagThree p q r`, `weylThree s = !![0, s, 0; -s⁻¹, 0, 0; 0, 0, 1]`,
  `upThree c b x = !![1, x, b; 0, 1, 0; 0, c σ(b), 1]`,
  `loThree c b x = !![1, 0, 0; x, 1, b; -c σ(b), 0, 1]`,
  `nThree x = !![0, x, 0; -σ(x)⁻¹, 0, 0; 0, 0, σ(x) x⁻¹]`.
- `elementaryThree c`: `contractingElementarySubgroup (gramThree c) weightThree`, the
  subgroup generated by isometries of contracting shape for `(1, -1, 0)` or `(-1, 1, 0)`.

## Results

- `mul_gramThree_mul_apply`, `isometry_gramThree_iff`: entrywise,
  `(M H₀ ᵗM^σ) i j = M i 0 σ(M j 1) - M i 1 σ(M j 0) + M i 2 c σ(M j 2)`.
- `isUnit_gramThree` (for `c ≠ 0`).
- `upThree_isometry` (`σ c = -c` and `x - σ x = b c σ b`), `loThree_isometry`
  (`x - σ x = -(b c σ b)`), `diagThree_isometry` (`p σ q = 1`, `r c σ r = c`), and the
  contracting shapes `upThree_isContracting`, `loThree_isContracting`.
- `realized_upThree`, `realized_loThree`, `realized_weylThree`
  (`weylThree s = up(0, s) lo(0, -s⁻¹) up(0, s)` for symmetric `s ≠ 0`).
- `realized_diagThree_left`: `diag(a, σ(a)⁻¹, 1)` for `a ≠ 0` is realized, since
  `a = s t` with `s, t` symmetric (`exists_eq_mul_symmetric`, needs `dim_K D = 4`,
  `dim_K D^σ = 3`) and `diag(s t, σ(s t)⁻¹, 1) = weyl(s) weyl(-t⁻¹)`.
- `nThree_eq`, `realized_nThree`: for `x ≠ 0` and `c = x - σ x ≠ 0`,
  `nThree x = up(1, x) lo(-x⁻¹, -σ(x)⁻¹) up(-σ(x) x⁻¹, x)`.
- `realized_diagThree_right`: `diag(1, 1, w)` with `w c σ(w) = c` is realized. For `w ≠ 1`
  put `x = (1 - w)⁻¹ c`; then `x - σ x = c` and `σ(x) x⁻¹ = w`, and
  `weyl(1) diag(σ(x)⁻¹, x, 1) diag(1, 1, w) = nThree x`.
- `exists_realized_row_zero_of_two`, `exists_realized_row_zero`: for an isometry `M`, a
  realized `N` makes the first row of `M N` equal to `(*, 0, 0)`. If `M 0 1 ≠ 0`, a lower
  matrix with `b = -(M 0 1)⁻¹ M 0 2` clears the third entry; then either a Weyl matrix (first
  entry zero) or an upper matrix `up(0, -(M 0 0)⁻¹ M 0 1)` (symmetric by isotropy of the
  first row) clears the second entry. If `M 0 1 = 0`, isotropy forces `M 0 2 = 0`.
- `realized_of_row_zero`: an isometry with first row `(a, 0, 0)` equals
  `diag(a, σ(a)⁻¹, 1) diag(1, 1, M 2 2) L` with `L` an isometry of contracting shape for
  `(-1, 1, 0)`.
- **`unitaryMatrixGroup_gramThree_le`**: if `dim_K D = 4`, `dim_K D^σ = 3`,
  `c ∈ {a - σ a}` and `c ≠ 0`, then every element of `unitaryMatrixGroup (gramThree c)` lies
  in `elementaryThree c`; `elementaryThree_eq` states the equality.

## Provenance

Internal. The generation is proved directly, by explicit matrix factorizations for this
Gram matrix, and only under the stated hypotheses: `D` of dimension `4` with a `3`-dimensional
symmetric part, and `c ∈ {a - σ a}` nonzero. Row reduction uses the contracting matrices, and
the remaining diagonal (Levi) factor is generated separately. `diag(a, σ(a)⁻¹, 1)` is a product
of Weyl-type matrices because every quaternion is a product of two symmetric elements
(`exists_eq_mul_symmetric`), and `diag(1, 1, w)` is handled through `nThree`. This is not an
instance of a general theorem about unitary groups: for an arbitrary isotropic unitary group,
the full group of rational points need not be generated by unipotent radicals (in `U(1,1)` over
`ℝ`, the scalar `i·I₂` has determinant `-1`). All identities are verified in Lean by direct
computation.
