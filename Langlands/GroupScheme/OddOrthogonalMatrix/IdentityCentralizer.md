# The rational centralizer of the actual odd identity component

Over every field, an actual rational point of the full split odd
norm-one group that commutes with every relative point of its identity
component is the identity.

The actual point is first expressed as a matrix over the original field.
Its constant family has precisely the scalar extension of that matrix
on every test scheme. The diagonal torus and all short parameter-one
points belong to the identity component, so centralizing the component
implies the matrix commutation hypotheses from `MatrixCentralizer`.
That calculation forces the matrix to be scalar. The actual quadratic
and determinant equations, on the original base test, then force it to
be the identity. Injectivity of the actual point chart finishes.

The commutation premise quantifies over all relative test schemes,
not just rational points. These are internal consequences of the
actual matrix coordinates and connected elementary subgroups; no new
external translation or algebraic-closure premise is used.
