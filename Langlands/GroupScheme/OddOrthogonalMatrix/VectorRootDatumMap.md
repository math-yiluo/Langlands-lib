# The actual odd vector morphism of root data

A finite reduced integral root datum whose coroots span its full
cocharacter lattice and whose numbered Cartan matrix is type B receives
a morphism from the actual odd identity-torus datum. Both lattice maps
are injective. The index equivalence matches the supplied simple-root
numbering. Its character image is exactly the target datum's integral
root lattice.

The actual odd datum is replaced by its full-coroot construction.
Its cocharacter quotient is finite, as computed by the parity quotient,
so the canonical character restriction is injective. The published
full-coroot Cartan equivalence identifies this datum with the supplied
one, preserving the specified simple numbering. Composing gives the
morphism. Every root-datum morphism maps the root span onto the root
span; since the odd short roots generate its full character lattice,
this also computes the entire character image.

The final existence theorem chooses an actual reduced odd root datum
from the preceding numbered-base theorem and applies this construction.
These are internal consequences of the actual root data and integral
Cartan comparison. The proof pattern is shared with the published
type-D vector morphism, but the type-B character image is simply the
root lattice. The field and characteristic remain unrestricted.
