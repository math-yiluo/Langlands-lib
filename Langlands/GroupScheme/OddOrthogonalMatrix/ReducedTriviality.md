# Triviality when the hyperbolic hyperplane is fixed

Every actual test-scheme matrix of the odd norm-one group satisfies its
full alternating quadratic-defect and determinant-one equations.
Over a reduced commutative coefficient algebra, such a matrix is the
identity if it fixes each hyperbolic basis vector pointwise. Indeed the
fixed columns give the explicit `axisColumnMatrix` block normal form with an axis entry, an identity even
block and a residual axis column. Determinant one forces the axis entry
to be one. The diagonal quadratic-defect equations force the square of
each residual coefficient to be zero, so reducedness makes them vanish.

Consequently an actual homomorphism from a smooth field group to this
odd norm-one group is the trivial underlying morphism if the hyperbolic
basis is fixed in its standard representation. Apply the matrix lemma
to the universal point of the source. Its ring of global sections is
reduced because the source is smooth over a field; faithfulness of the
actual odd matrix inclusion then identifies the morphism with the unit.

Reducedness is used only for this universal test, not asserted for all
test algebras. All scheme maps and fixed-vector conditions retain their
all-test meanings. This is an internal consequence of the actual matrix
equations and the published reducedness of smooth schemes over fields,
valid in every characteristic and with no new source translation.
