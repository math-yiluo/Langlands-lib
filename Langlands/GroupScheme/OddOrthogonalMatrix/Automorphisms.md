# Inner automorphisms of the actual split odd identity component

The actual split odd identity component, with at least two hyperbolic
indices, has a pinning whose base carries the exact type-B numbering
and whose roots generate its full integral character lattice. Every
based automorphism of this pinning is trivial. Over an algebraically
closed field, every automorphism of the identity component is
conjugation by one of its own rational points.

The existence argument builds a witness using the actual diagonal
maximal torus, the numbered root datum and root-line trivializations
from the published split root-line theorem. `numberedPinning` then
chooses a package carrying precisely the properties in `NumberedPinning`:
an actual pinning, a type-B Cartan numbering and full integral root span.
These bundled properties determine the scope of the chosen package.
The supporting integral rigidity lemma makes every based automorphism
trivial. The published pinned
automorphism decomposition then expresses any group automorphism as
an adjoint-quotient inner action. Surjectivity of that quotient over an
algebraically closed field lifts the acting rational point to the
original group, giving actual conjugation.

The intermediate `NumberedPinning` package and its innerness argument
apply to any supplied full-root pinning of type B. These are internal
applications of published pinning and adjoint-quotient results; no new
external translation is used. Innerness here has an algebraically
closed field premise. Full odd-group connectedness is not asserted.
