# Characteristic polynomials of pattern and ordinary products on path representations

This module is in the namespace `Langlands.GroupScheme.SplitPinning`. It imports
`Langlands.GroupScheme.Rational.PathCorootMatrices` (the coroot on the path lines),
`Langlands.GroupScheme.Rational.EvenChainLocality` (factors acting trivially), and
`Langlands.LinearAlgebra.PathCoxeterProducts` (the linear algebra of path products). It is an
internal prerequisite of the split even-path cross-section task
(`Langlands.GroupScheme.SplitEvenChainCrossSectionStatement`, Steinberg 1965, §9.15–9.19).

**Provenance: internal.** Steinberg's §9 proves the cross-section by other means; these
statements were derived for this project. Every result is stated below and proved in Lean.

## Setting

`k` is a field and `G` a group scheme over `Spec k` with a split pinning `p`.
`ρ : MatrixRepresentation G V` has highest weight `lam` (`p.IsHighestWeight ρ lam`).
`β : Fin L → p.base.support` is a path component of the Dynkin diagram (`IsPathComponent β`),
and `lam` is the fundamental weight of its end vertex `β 0` (`IsPathFundamental β lam`).
`x` is a family of normalized simple root parametrizations, and `v₀ ≠ 0` is a vector of the
highest weight space. The Library's `normalizedPathMatrix hρ hβ hlam x v₀ hv₀ : rationalPoints G
→* Matrix (Fin (L + 1)) (Fin (L + 1)) k` is the matrix of `ρ(g)` on the `L + 1` normalized
path lines. By the Library lemma `charpoly_normalizedPathMatrix`, `ρ(g)` and this matrix have
the same characteristic polynomial.

The matrices `sfac`, `core`, `endpointMat`, `torusMat`, `blockBeta`, `patY`, `ordY`, the
polynomial `ordPoly` and the coordinates `patCoord` are those of the modules
`Langlands.LinearAlgebra.PathCoxeterCharpoly`, `PathCoxeterCoordinates` and
`PathCoxeterProducts`. In particular `sfac n i c` is the simple factor on the lines `i, i+1`
of `k^n` (columns `e_i ↦ -c e_i - e_(i+1)`, `e_(i+1) ↦ e_i`), and `core n j β` acts by the
`3 × 3` block `β` on the lines `j, j+1, j+2` and as the identity elsewhere.

## Library matrices in the path Coxeter notation

- `pathSimpleFactorMatrix_eq_sfac`: `pathSimpleFactorMatrix i c = sfac (L + 1) i c` for
  `i : Fin L`.
- `pathEndpointReflectionMatrix_eq_endpointMat`:
  `pathEndpointReflectionMatrix i l a b = endpointMat (L + 1) i l a b`.
- `adjacentCorootMatrix_eq_torusMat`:
  `adjacentCorootMatrix L i t = torusMat (L + 1) i t t⁻¹` (true by definition).

## Positions on a path

- `pathIndex β w : Option ℕ` (definition): `some v` if `w = β v`, and `none` if `w` is not on
  the path. When several `v` satisfy `β v = w` it uses a chosen one; the lemmas below only use
  injective `β`.
- `pathIndex_apply`: for injective `β`, `pathIndex β (β v) = some v`.
- `pathIndex_eq_none`: `pathIndex β w = none` if `w` is not in the range of `β`.
- `exists_of_pathIndex_eq_some`: if `pathIndex β w = some v` then `v < L` and `β v = w`.

## Factors on the path lines

- `normalizedPathMatrix_eq_one`: if `ρ(g) = 1` then the path matrix of `g` is `1`.
- `normalizedPathMatrix_rootFactor`: the path matrix of the simple-root factor
  `x_w(c) n_w` (with `n_w` the canonical reflection representative) is `sfac (L + 1) v c`
  if `pathIndex β w = some v`, and `1` if `w` is off the path.
- `exists_normalizedPathMatrix_block`: let `D : p.SteinbergModifiedData` have merged simple
  roots `D.a = β i` and `D.b = β (i+1)` (`i + 2 ≤ L`), with `D.nAlpha` in the subgroup
  generated by the root subgroups of `±α`. Write `λ` for `pathRootScalar … D.xAlpha i (i+2)`,
  the coefficient of the root map of `α` between the lines `i` and `i + 2`. There are `a b : k`
  with `a b = -1` such that for all `s : k` and `t : kˣ`

  - the path matrix of `u_b u_a x_α(s) n_α α^∨(t)` is
    `core (L + 1) i (blockBeta t t⁻¹ a b (s λ) c_a c_b)`, and
  - the path matrix of `x_α(s) n_α` is `core (L + 1) i (blockBeta 1 1 a b (s λ) 0 0)`.

  Proof: the path matrices of `u_a`, `u_b`, `x_α(s)`, `n_α` and `α^∨(t)` are
  `1 + E_(i,i+1) c_a`, `1 + E_(i+1,i+2) c_b`, `1 + E_(i,i+2)(s λ)`,
  `pathEndpointReflectionMatrix i (i+2) a b` and `adjacentCorootMatrix L i t` (Library lemmas
  `normalizedPathMatrix_rationalRoot`, `normalizedPathMatrix_pathRoot`,
  `exists_normalizedPathMatrix_adjacentReflection`,
  `normalizedPathMatrix_corootRationalPoint_adjacent`). The products are computed by
  `block_eq_core` and `block_eq_core_false`.
- `charpoly_rootFactorProduct` (**ordinary products**): let `L = 2m + 2`, `E : Fin r ≃
  p.base.support` an ordering of the simple roots and `cf : Fin r → k`. The product
  `∏_j x_(E j)(cf j) n_(E j)` (in the order of `j`) has characteristic polynomial (under `ρ`)
  `ordPoly m cf'`, where `cf' v = cf (E⁻¹ (β v))` for `v < L` and `cf' v = 0` otherwise.

  Proof: the factor of `E j` has path matrix `ordY (L+1) m cf' v` if `E j = β v` and `1`
  otherwise. The path positions of the factors form a permutation of `0, …, 2m+1`, so
  `charpoly_prod_ordY` applies.

## Pattern products on the representation at the end of a path

Let `C : p.EvenChainData J`. For an ordering `e : Fin q ≃ C.Rest` of the unmerged simple roots
and coordinates `z : Fin q → k`:

- `EvenChainData.restCoord e z c v` (definition): for `v < 2 · half c`, it is `z j` when the
  path vertex `C.path c v` is the unmerged root `e j`, and `0` when that vertex is merged. It
  is `0` for `v ≥ 2 · half c`.
- `restCoord_eq`: `restCoord e z c v = z j` when `e j = C.path c v`.
- `modified_a_eq`, `modified_b_eq`: if `half c = m + 1`, the merged roots of the path `c` are
  its vertices `m` and `m + 1`.
- `path_mem_rest`: a vertex of the path `c` other than `m`, `m + 1` is unmerged.
- `ne_of_rest_eq_path`: an unmerged vertex at position `v` of the path `c` has `v ≠ m`,
  `v ≠ m + 1`.
- `EvenChainData.charpoly_patternProduct` (**pattern products**): let `half c = m + 1`, so
  the path `c` has `2m + 2` vertices, and let `ρ` have highest weight the fundamental weight of
  the end vertex `C.path c 0` (with `v₀ ≠ 0` as above). There are constants `A ≠ 0`, `B ≠ 0`
  such that for all orderings `o : Fin r ≃ J`, `e : Fin q ≃ C.Rest`, every pattern
  `ε : J → Bool`, and all `s : J → k`, `t : J → kˣ`, `z : Fin q → k`, the characteristic
  polynomial of `ρ(C.patternProduct x n o e ε s t z)` (with `n` the canonical reflection
  representatives) is

  `ordPoly m (patCoord m (C.restCoord e z c) σ δ)`,

  with `σ = -(s_c A)`, `δ = 0` if `ε c = false`, and `σ = -(t_c s_c A)`, `δ = t_c B` if
  `ε c = true`. Here `A = λ a` and `B = a c_a c_b` with `a`, `λ` from
  `exists_normalizedPathMatrix_block` for `D = C.modified c`.

  Proof: the block factor of `c` has path matrix `core (2m+3) m β'` with
  `β' = blockBeta …` as above, the block factors of the other paths act trivially
  (`rationalMatrix_block_eq_one_of_ne`), and the unmerged factor at path position `v` has path
  matrix `sfac v (z j)`. These are the factors `patY (2m+3) m c' β' i` (with
  `c' = restCoord e z c`) indexed by a permutation of `0, …, 2m`, so `charpoly_prod_patY`
  gives the characteristic polynomial of `pathMat m c' β'`. Then
  `charpoly_pathMat_pattern_eq_ordPoly` evaluates it as
  `ordPoly m (patCoord m c' (-β'₀₀) (β'₀₁ β'₁₀))`, and `-β'₀₀ = σ`, `β'₀₁ β'₁₀ = δ`.
