# Actual root systems from rational reflection functionals

This internal supporting construction generalizes the published integral
reflection assembly in `RootReflectionAssembly` and its chamber argument in
`RelativeWeylChamberGeneration`. It uses the same actual torus embedding,
relative-root span and relative Weyl quotient. The new data allow rational
coroot functionals on that span, without requiring integral cocharacter lifts.
The formulas on roots must still be integral.

`RelativeRootRationalReflectionData` records one rational functional and one
element of the actual Weyl quotient for each actual root. The functional pairs
to two with its own root, pairs integrally with every root, and gives the actual
quotient action by the reflection formula. The structure does not assert that
such data exist.

For a split torus with finitely many actual roots, the actual Weyl action
preserves the root vectors. Finiteness and reflection stability imply that the
coroot functionals are injective. `RootPairing.mk''` therefore constructs a
root pairing on the existing rational root span with its evaluation duality.
The root vectors span, and the integral evaluations imply both the root-system
and crystallographic properties. Its root image is exactly the actual root
image. Its reflection image is the subgroup generated by the supplied actual
quotient reflections.

At a generic cocharacter with trivial positive-root stabilizer, the published
chamber-transitivity argument proves that the supplied representatives generate
the entire actual quotient. Faithfulness follows from that same stabilizer
condition. `hasRelativeRootSystem_of_positive_stabilizer` combines these facts
to prove the unchanged published `HasRelativeRootSystem` predicate.

This is a conditional assembly interface. It supplies neither root reflections
nor the positive-root stabilizer theorem. In particular, it does not by itself
prove inheritance for an actual Levi or the finite induced-cuspidal embedding.
