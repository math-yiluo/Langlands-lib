# Actual root supports for twisted standard-Levi intersections

This internal continuation uses the actual Weyl pairing stabilizer to identify
the intrinsic intersection subset with those simple roots of the right face
whose images pair to zero with a left-face standard cocharacter. Reflection
in a transported simple root preserves that pairing exactly when the root
has zero pairing: apply the conjugate reflection to that root for one direction,
and use its integral reflection formula for the other.

For a minimal double-coset representative, each right-face simple root has a
positive image. Thus its pairing with a left-face standard cocharacter is
nonnegative. Induction in the additive monoid of the right face shows that
zero pairing cuts out exactly the monoid generated by the intersection subset.
This is a positive-monoid assertion and does not assert an intersection formula
for arbitrary linear spans.

The provenance is internal. Dependencies are the realized simple-reflection
formula, `pairingStabilizer_eq_standardSubgroup`,
`minimalityLengthCriterion_proof`,
`IsStandardCocharacter.pairing_nonneg_of_positive`, and additive-monoid
closure induction. The all-test scheme equality remains a separate obligation.

`twistedStandardPositiveZeroSupport` defines the actual additive submonoid
of right-face positive combinations with zero transported pairing. The theorem
`IsRelativeWeylCoxeterRealization.twistedStandardPositiveZeroSupport_eq`
identifies it with the monoid generated by the intrinsic intersection subset.
This formulation uses no global root-negation assumption or independent
root-system realization. It assumes the supplied actual Coxeter realization,
genericity, a standard cocharacter for the left face, and double-coset minimality.
