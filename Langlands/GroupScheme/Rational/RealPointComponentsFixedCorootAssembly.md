# Assembly of the real components theorem from fixed coroot signs

The first clause follows once the fixed simple coroot sign condition
and split-torus representatives of real components are supplied. The
representative hypothesis is the connected reductive case of Borel–Tits
(1965), Theorem 14.4. Choose a maximal split torus. The cocharacter and norm
argument puts its real image in the identity component. Each real point
shares a component with a point of that image, so all components are the
identity component.

The second clause uses the published finite-components theorem for
connected reductive real groups, proved using polar decomposition and
compactness. This internal assembly uses the evaluation topology in both
clauses.
