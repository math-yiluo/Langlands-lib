# Uniqueness of lifts annihilating the selected coroots

This is derived internal linear algebra on the published actual torus spaces,
reflection data and standard-Levi split-component maps. It supports the lift
comparison needed in Renard VII.4.1 without identifying any representation
parameter with such a lift.

For selected actual roots `J`, `D.selectedWeylGroup J` is the subgroup of the
actual relative Weyl group generated by the supplied normalizer reflection
classes for roots in `J`. Its full real character action can be summed over
any finite enumeration; `D.selectedWeylSum J` is this unnormalized linear sum.
Right multiplication reindexes the sum. The reflection belonging to a selected
root negates its full real character vector, so the sum kills that vector and
therefore the span of all selected root vectors.

If a full real character annihilates the selected coroots, the reflection
formula fixes it under each generator, hence under the selected subgroup.
When the actual Weyl group is finite, the sum is multiplication by the positive
order of this subgroup. A vector in the selected-root span annihilating all
selected coroots must therefore vanish. No invariant inner product or
minimal-length representative is used.

For an actual compatible parabolic root presentation, the reverse inclusion
from the selected-root cocharacter annihilator into the split-component
cocharacter image is already proved. Perfect real character/cocharacter
duality implies that the kernel of character restriction is contained in the
span of the selected simple roots. Consequently two full real characters
restricting to the same split-component parameter and annihilating every
selected coroot coincide. Connected reductivity supplies actual Weyl
finiteness; the universes and actual scheme maps are retained.

This proves lift uniqueness only. Actual unramified-character transport,
comparison with Weyl conjugation and the full regularity assertion remain
separate obligations.
