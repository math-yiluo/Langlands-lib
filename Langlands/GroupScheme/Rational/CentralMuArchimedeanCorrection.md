# Simultaneous archimedean correction of a lift through a roots-of-unity kernel

`Cocycle.ArchimedeanTrivial` means triviality on the actual pullback cover over every infinite completion. The comparison `LocalKummerCorrection.isTrivial_of_powerClass` works over a compatible finite Galois local coefficient field. If the global scalar represents the same local power class as the scalar of the local correction, the ratio of the radicals gives a kernel-valued cochain. Combining this with the cochain lifting the projected coboundary trivializes the difference cocycle on that coefficient field. Fpqc descent over the completion reflects triviality to the actual pullback cover.

`exists_corrected_archimedeanTrivial` chooses all local corrections using the algebraic closures of the infinite completions. Weak approximation gives one global scalar, and a single finite Galois refinement contains a root of that scalar. The refined global field embeds into the same local algebraic closure over the original coefficient field. The resulting actual global kernel cocycle makes the difference trivial over every infinite completion. This is the roots-of-unity case of the archimedean correction used in the adjoint Hasse argument.
