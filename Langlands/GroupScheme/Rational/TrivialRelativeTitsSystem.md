# The actual relative Tits system with full torus centralizer

This internal unit identifies the actual relative Weyl quotient with the trivial
group when `centralizerPoints i = ⊤`. The construction
`relativeWeylEquivPUnitOfCentralizerEqTop` uses the quotient by the full subgroup,
so the identification concerns the published quotient itself.

If in addition the actual relative root set is empty, every simple-root set is
empty. The whole-torus centralizer lies in every standard parabolic, so the
minimal standard parabolic has all rational points. These facts prove every
field of the actual `HasRelativeTitsSystem` predicate: the quotient map is
surjective with full kernel, the ambient-group join is full, the trivial Weyl
group is generated by the empty set, and the reflection, multiplication and
nondegeneracy conditions are vacuous. Both compatibility conditions indexed by
simple roots are vacuous as well. No genericity or root-system premise is used.

The published anisotropic results give precisely these two hypotheses for a
split subtorus: `IsAnisotropic.centralizerPoints_eq_top` and
`IsAnisotropic.relativeRoots_eq_empty`. Thus `IsAnisotropic.hasRelativeTitsSystem`
proves the actual Tits-system conclusion for any affine anisotropic group, each
split subtorus, and every cocharacter. This specialization is derived entirely
from the published constructions and anisotropic lemmas.

This result covers the indicated anisotropic case. It does not assert that
empty relative roots alone force a full centralizer, and it does not prove the
general connected-reductive `RelativeTitsSystemStatement`.
