## Statement proved

`standardMaximalLeviWeyl : StandardMaximalLeviWeylStatement.{u}`.

The statement is published in
[StandardLeviWeylStatements](StandardLeviWeylStatements.md). The theorem's type is exactly
that proposition. The proof adds no hypothesis and leaves the statement module unchanged.

Notation. `k` is a nonarchimedean local field, `G` connected reductive, `i : T ⟶ G` a maximal
split torus, `ν` a generic cocharacter and `Δ` the simple relative roots. For a finite set `I`
of simple roots, `P_I(k) = parabolic i ν I`, `L_I(k) = levi i ν I`,
`W_I = standardRelativeWeylGroup i ν (rootSet i ν I)` and `W = relativeWeylGroup i = N(k)/Z(k)`.
`⟨α, λ⟩` is `latticePairing T α λ`. For `n ∈ N(k)`, `w α` means `weylAction i n α`. A standard
cocharacter `ζ_I` of `I` vanishes on `I` and is positive on `Δ ∖ I`.

The proof fixes the published Coxeter system of `W` (`relativeWeylCoxeter`): a Coxeter system
`cs` labelled by `Δ` such that the simple reflection `s_a` acts on characters by
`χ ↦ χ - f(χ) a` with `f(a) = 2`, lengths are read off positivity of roots, and the Coxeter
parabolic subgroup of `I` is `W_I` (`IsRelativeWeylCoxeterRealization`). It also gives the
finiteness of `W` and of `Δ`.

## Tools

**Conjugating cocharacters.** `conjCochar i n ζ` is the cocharacter `ζ ≫ σ` of `T`, where `σ`
is the automorphism of `T` through which `n ∈ N(k)` normalizes `i`. Then:

- `latticePairing_conjCochar`: `⟨α, conjCochar n ζ⟩ = ⟨w⁻¹ α, ζ⟩` (from the published
  `latticePairing_characterAut_cocharacterAut`);
- `parabolic_conjCochar_points`: `n P(ζ)(k) n⁻¹ = P(conjCochar n ζ)(k)`;
- `parabolic_eq_comap_conjCochar`: `P(ζ) = P(conjCochar n ζ).comap Int(n)` as subgroup
  functors (published `groupHom_cocharacterAut_comp`, `Dynamic.parabolic_eq_comap_of_iso`).

**Standard Weyl subgroups.**

- `pairing_action_eq_of_mem_standard`: every `u ∈ W_J` preserves `⟨·, λ⟩` when `λ` vanishes on
  `J`. Induction over the generators `s_b`, `b ∈ J`, using the reflection formula.
- `pairing_action_simple_eq_zero`: if `w s_a w⁻¹ ∈ W_J`, then `⟨w a, λ⟩ = 0` for every `λ`
  vanishing on `J`, because `w s_a w⁻¹` sends `w a` to `-w a`.
- `mem_of_simple_mem_standard`: `s_x ∈ W_K` implies `x ∈ K` (published
  `mem_of_simple_mem_standardSubgroup`).
- `conj_mem_standardRelativeWeylGroup`: if `n L_I(k) n⁻¹ ⊆ L_J(k)`, then
  `[n] W_I [n]⁻¹ ⊆ W_J`, by the definition of `W_I` as the image of `N(k) ∩ L_I(k)`.

**The key identity** (`key_identity`). Let `I = Δ ∖ {a}`, `n L_I(k) n⁻¹ ⊆ L_J(k)`, and `ζ_I`,
`ζ_J` standard for `I`, `J`. Then for every relative root `α`,

`⟨α, conjCochar n ζ_I⟩ · ⟨w a, ζ_J⟩ = ⟨α, ζ_J⟩ · ⟨a, ζ_I⟩`.

Put `p = ⟨a, ζ_I⟩` and `q = ⟨w a, ζ_J⟩`. The additive map
`β ↦ ⟨β, ζ_I⟩ q - ⟨w β, ζ_J⟩ p` vanishes on every simple root: at `a` trivially, and at
`x ∈ I` because `⟨x, ζ_I⟩ = 0` and `⟨w x, ζ_J⟩ = 0` (the previous two lemmas, with
`s_x ∈ W_I`). It therefore vanishes on the additive group generated by `Δ`, which contains the
relative roots (published `relativeRoots_subset_addSubgroupClosure_simpleRelativeRoots`, with
the published negation stability `relativeRootNegation`). Apply this at the root `w⁻¹ α`.

**Parabolic comparisons.**

- `parabolic_eq_of_nonneg_iff`: cocharacters `λ`, `μ` with `0 ≤ ⟨α, λ⟩ ↔ 0 ≤ ⟨α, μ⟩` for all
  relative roots have the same dynamic parabolic (both inclusions of the published
  `relativeRootSignInclusions`).
- `eq_and_mk_mem_of_standardParabolic_eq_comap`: if `P_K = P_{K'}.comap Int(n)` with
  `n ∈ N(k)`, then `K = K'` and `[n] ∈ W_K`. Uniqueness in the published
  `standardParabolicClassification` (with `P_K = P(ζ_K)`, `standardCocharacter`) gives
  `K = K'`. Then `n` normalizes `P_K(k)`, which is self-normalizing
  (`standardParabolicPointsStatement_proof`), so `n ∈ P_K(k)` and `[n] ∈ W_K` (the published
  `normalizerStandardParabolicStatement_of_statements` with `rationalBruhat`).
- `parabolic_le_iff`: `P_I(k) ≤ P_J(k) ↔ I ⊆ J`. One direction is the published
  `standardParabolicOrder`. Conversely, a lift `m ∈ N(k) ∩ L_I(k)` of `s_x`, `x ∈ I`, lies in
  `P_J(k)`, so `s_x ∈ W_J` and `x ∈ J`.
- `parabolic_univ`, `parabolic_eq_top_iff`: `P_J(k) = G(k)` exactly when `J = Δ`
  (published `standardParabolicEndpoints`).

## Clause 1 (`isMaximal_iff`)

By `parabolic_le_iff`, `P_I(k) < P_J(k)` exactly when `I ⊊ J`, and `P_J(k) = G(k)` exactly
when `J = Δ`. So `P_I` is maximal exactly when `I ≠ Δ` and every strictly larger `J` is `Δ`.
This holds exactly when `I = Δ ∖ {a}` for some `a`: if two roots `a ≠ b` were missing from
`I`, then `I ⊊ I ∪ {b} ≠ Δ`.

## The dichotomy and clause 3

`mk_mem_or_parabolic_eq_neg`: for `I = Δ ∖ {a}`, `n L_I(k) n⁻¹ = L_J(k)` and standard `ζ_I`,
`ζ_J`, either `[n] ∈ W_I` or `P(conjCochar n ζ_I) = P(-ζ_J)`. With `p > 0`, the key identity
gives three cases on the sign of `q`.

- `q < 0`: `⟨α, conjCochar n ζ_I⟩` and `⟨α, -ζ_J⟩` have the same sign for every root, so the
  two dynamic parabolics agree.
- `q = 0`: then `⟨α, ζ_J⟩ = 0` for every root, so `J = Δ`. Hence `L_J(k) = G(k)`, so
  `L_I(k) = G(k)` and `P_I(k) = G(k)`, contradicting clause 1. This case is impossible.
- `q > 0`: the signs agree with those of `ζ_J`, so `P(conjCochar n ζ_I) = P_J` and
  `P_I = P_J.comap Int(n)`. Then `eq_and_mk_mem_of_standardParabolic_eq_comap` gives
  `[n] ∈ W_I`.

`parabolic_map_conj_eq` (clause 3): if `[n] ∉ W_I`, the second alternative holds, and
`n P_I(k) n⁻¹ = P(conjCochar n ζ_I)(k) = P(-ζ)(k)` by `parabolic_conjCochar_points`.

## Clause 2 (`isMaximal_iff_card`)

The internal definitions `WLstar I` and `cosets I` restate the statement's local `WLstar` and
the image used in `ell`: `cosets I` is the set of cosets `w W_I` of the classes `w = [n]` with
`n L_I(k) n⁻¹ = L_J(k)` for some `J`. The final theorem identifies `ell I` with
`Nat.card (cosets I)` definitionally.

Helpers: `one_mem_WLstar` (`n = 1`); `mk_mem_iff_mem_levi` (`[n] ∈ W_I ↔ n ∈ L_I(k)`, since
`Z(k) ⊆ L_I(k)`); `eq_of_levi_eq` (`L_K(k) = L_{K'}(k)` gives `W_K = W_{K'}`, hence `K = K'`);
`levi_map_conj_of_image` (if `w` maps the roots of `K` onto those of `K'`, then
`n L_K(k) n⁻¹ = L_{K'}(k)`, from the published
`restrictedStandardSubgroups_eq_comap_of_character_images`); `exists_simple_neg` (if
`n L_I(k) n⁻¹ = L_K(k)` and `[n] ∉ W_I`, then `⟨w x, ζ_K⟩ < 0` for some simple `x`; otherwise
`λ = conjCochar n⁻¹ ζ_K` would be standard for the set `F` of simple roots it kills, so
`P_F = P_K.comap Int(n)`; then `F = K`, `[n] ∈ W_K`, and conjugating back by `n⁻¹` gives
`[n] ∈ W_I`).

**Maximal `I = Δ ∖ {a}`: exactly two cosets** (`card_cosets_eq_two`).

- `exists_mem_WLstar_not_mem`: for a lift `m` of the published longest representative
  `longestRep cs I`, the published `weylAction_image_associatedStandardFamily` gives
  `m L_{I'}(k) m⁻¹ = L_I(k)` with `I' = associatedSubset cs I`. So `[m]⁻¹ ∈ WLstar I`, and
  `[m]⁻¹ ∉ W_I` by the published `longestRep_not_mem_standardSubgroup`.
- `coset_eq_of_not_mem`: two elements `[n₁]`, `[n₂]` of `WLstar I` outside `W_I` (targets `J₁`,
  `J₂`) have the same coset. By the dichotomy, `P(conjCochar n_k ζ_I) = P(-ζ_{J_k})`, so
  `0 ≤ ⟨w_k⁻¹ α, ζ_I⟩ ↔ ⟨α, ζ_{J_k}⟩ ≤ 0` for all roots. With negation stability this shows
  that `y = n₂ n₁⁻¹` satisfies `P(conjCochar y ζ_{J₁}) = P(ζ_{J₂})`, so
  `P_{J₁} = P_{J₂}.comap Int(y)`. Hence `[y] ∈ W_{J₁}`, and conjugating back by `n₁⁻¹` gives
  `[n₁]⁻¹[n₂] ∈ W_I`.
- So `cosets I = {W_I, [m]⁻¹ W_I}` with two distinct elements, and its cardinality is `2`.

**`I = Δ`: at most one coset** (`card_cosets_le_one_of_univ`): `W_Δ = W`.

**Two simple roots `a ≠ b` outside `I`: at least three cosets** (`three_le_card_cosets`).

- `exists_longest_lift`: for `c ∉ I`, a lift `m` of `longestRep cs (Δ ∖ {c})` maps the
  associated simple roots bijectively onto `Δ ∖ {c}` (published
  `schemeWeylCharacterAction_associatedSimpleEquiv`, `weylAction_image_associatedStandardFamily`).
  So `n = m⁻¹` satisfies `n L_I(k) n⁻¹ = L_K(k)` for the corresponding subset `K`, and for every
  simple `x ∉ I ∪ {c}` the root `w x` is a simple root outside `K`, so `⟨w x, ζ_K⟩ > 0`.
- For `c = a, b` this gives `n_a`, `n_b` with classes outside `W_I` (as `W_I ⊆ W_{Δ∖{c}}`
  does not contain `longestRep cs (Δ ∖ {c})`). Since `⟨w x, ζ_K⟩ = 0` for `x ∈ I`,
  `exists_simple_neg` forces `⟨w_a a, ζ_{K_a}⟩ < 0`, while `⟨w_b a, ζ_{K_b}⟩ > 0`.
- If `[n_a] W_I = [n_b] W_I`, then `n_a⁻¹ n_b ∈ L_I(k)`, so `L_{K_a}(k) = L_{K_b}(k)` and
  `K_a = K_b`. The element `[n_a⁻¹ n_b] ∈ W_I` preserves the pairing with
  `conjCochar n_a⁻¹ ζ_{K_a}`, which vanishes on `I`. This gives
  `⟨w_b a, ζ_{K_a}⟩ = ⟨w_a a, ζ_{K_a}⟩`, a contradiction.
- So `W_I`, `[n_a] W_I`, `[n_b] W_I` are three distinct members of the finite set `cosets I`.

`isMaximal_iff_card` combines these cases with clause 1.

## Main theorem

`standardMaximalLeviWeyl` introduces the binders, installs `hG.isAffineHom` and
`hi.isSplitSubtorus.mono` as the statement does, takes the Coxeter system from
`relativeWeylCoxeter` (with `Fintype` instances from its finiteness), introduces the statement's
local definitions, and returns `isMaximal_iff`, `isMaximal_iff_card` and
`parabolic_map_conj_eq`.
