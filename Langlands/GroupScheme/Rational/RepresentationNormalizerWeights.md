# Actual normalizer matrices on universal character spaces

Author: Worker 1284. Provenance: internal. This construction restricts the actual rational matrix of a normalizing point to the Library's universal character spaces. It is derived from actual normalizer conjugation, naturality of representation matrices and the character-space evaluation theorem.

For the general construction, `k : Type u` is an arbitrary field, `G` is an actual group scheme over `k`, and `T` is an affine commutative group scheme equipped with a homomorphism `i : T.toGrp -> G`. A supplied base point `g` and automorphism `sigma : T` satisfy `IsNormalizingPoint i g sigma`. The finite matrix representation `rho` is actual. The generic part requires neither affineness of `G`, splitness of `T`, a monomorphism condition on `i`, nor algebraic closedness, simple connectedness or irreducibility. Only the affine constant-matrix and commutation lemmas precede the affineness assumption on `T`; the character-space constructions require it.

The existing `affineMatrix_constantPoint` from
`MatrixRepresentation.NormalCharacterSpan` identifies the matrix of the constant extension of `g` on any affine coefficient test with entrywise scalar extension of `rho.rationalMatrix g`. It specializes the general constant-point matrix identity to `CommRingCat.of k`. `affineMatrix_normalizer_commutation` then proves that the extended rational matrix intertwines the torus matrix at `t` with the torus matrix at `sigma.inv(t)`. The inverse occurs because the Library defines `characterAut sigma lam` by precomposition with `sigma.inv`.

`rationalMatrix_mem_characterSpace` proves that multiplication by the actual rational normalizer matrix carries the universal character space of `lam` to the universal character space of `characterAut sigma lam`. It evaluates the original weight equation at the inverse-transformed universal point of `T`, uses the preceding matrix identity, and identifies the character scalar by character evaluation under composition. Thus the conclusion concerns the actual character spaces, whose equations hold over every commutative coefficient algebra, including nonreduced ones. No rational-point density argument is used.

`normalizerWeightMap` packages this action as a linear map between the two subspaces. `normalizerWeightEquiv` proves it is an equivalence: the normalizer matrix is invertible, and the inverse base point normalizes through `sigma.symm` and sends the transformed weight back to the original one. The underlying-vector equations for both packages are proved and are multiplication by the same actual rational matrix. This construction differs from the existing `Torus.NormalizerRepresentationWeights` calculation in exponent coefficient matrices: its source and target are the actual universal character submodules of the supplied representation, and it requires no identification of `T` with a standard split torus.

The final two theorems specialize to a supplied split pinning and a supplied simple-reflection representative. Its specified `characterAut_eq` identifies the transported weight with the actual simple root-datum reflection. The rational matrix therefore sends `p.representationWeightSpace rho lam` into the reflected weight space, and the two weight spaces have equal dimension. The split torus's existing affineness supplies the generic hypothesis. Every supplied representative is allowed.

This pair constructs no reflection representative or fundamental representation. It proves neither invariant generation nor a triangular character formula or a canonical quotient isomorphism. Those structural obligations remain in the host task.
