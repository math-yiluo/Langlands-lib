# Constancy of bounded maps on split-torus power grids

This derived helper transfers the bounded Laurent function result to actual
morphisms from a split torus into an affine group scheme. It uses the existing
universal split-torus point over its Laurent algebra and evaluates its image
under the morphism. The resulting Laurent coordinates are constant if they are
bounded on all integer-power tuples of a unit with nonzero integer valuation.
All rational points therefore have the same image. The coordinate evaluation
is compared explicitly with the algebraic-boundedness evaluation convention.
