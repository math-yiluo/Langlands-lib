# Smooth connected representability of the closed torus envelope

Worker 1333. `TorusGeneratedEnvelopeExistenceStatement.{u}` is the proposition
that, over every field `k : Type u`, each smooth connected affine actual group
scheme `G` has a `TorusGeneratedEnvelope G` whose group is smooth and connected.
There is no solvability, reductivity, splitness, perfection, infinitude, or
characteristic hypothesis.

The representative data use the existing fixed `closedTorusEnvelope G`: the
intersection of all actual closed subgroup ranges containing every closed
ground-field torus on every relative test scheme. The existential witness
therefore includes an actual group scheme, an actual closed inclusion, and its
representation of that precise functor. Smoothness and connectedness concern
that actual source. Affineness already follows from the closed inclusion into
the affine ambient group by `TorusGeneratedEnvelope.isAffineHom`.

The source is Conrad--Gabber--Prasad, *Pseudo-reductive groups*, second edition
(2015), Proposition A.2.11, printed pp.477--480 / PDF pp.503--506, registered as
`conrad-gabber-prasad-2015-pseudo-reductive`. Its opening defines the smooth
connected subgroup generated by the ground-field tori of any smooth connected
affine group over a field. The proof's first paragraph cites Borel, section 2.2,
for generation by a finite family of tori. The closed subgroup generated by
that family has the least closed-image universal property used here: it
contains each torus and lies in every closed subgroup containing them.
Identifying its all-test range with the fixed intersection supplies the
`represents` field. This correspondence, including smooth connected
representability, is a proof obligation of this target.

Only this existence assertion from the source is formalized here. The source's
normality, unirationality, unipotent quotient, and compatibility with field
extension are additional theorems. This file states none of them. In particular,
it asserts no equality with a pointwise abstract subgroup generated by torus
points. This is a proposition target, with no supplied proof or assumed axiom.

For the full solvable maximal-torus conjugacy route, the existing envelope
lemmas then restrict each ambient maximal torus to this smooth connected
representative, inherit affineness and solvability, and transport a conjugacy
back to the original ambient group. The separate radical and conjugacy
arguments remain necessary.
