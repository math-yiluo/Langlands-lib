# Actual cover points representing relative Weyl classes

This internal construction works over an arbitrary field `k : Type u`. It uses
a maximal split torus `i : T → G` and a supplied simply connected cover
`π : C → D` of the supplied actual derived subgroup `d : D → G`. All point
groups are the actual rational points of these group schemes, and the Weyl
group is the actual quotient `N_G(T)(k)/Z_G(T)(k)`.

For integral reflection data `R : RelativeRootReflectionData i`, every actual
relative root subgroup has its rational points in the image of `C(k) → G(k)`.
Indeed, a relative root `a` is nonzero. Splitness of `T` supplies a cocharacter
`ν` whose integral pairing with `a` is positive, by
`IsSplitTorus.exists_pairing_eq_pos`. The all-test inclusion
`RelativeRoot.subgroup_le_dynamicUnipotent` puts that root subgroup in
`U_G(ν)`. The contracting-point lifting theorem
`Dynamic.unipotentPoints_le_derivedCoverImage_of_reflectionData` then puts
its rational points in the image of the literal composite `π ≫ d`.
This proves `RelativeRoot.subgroupPoints_le_derivedCoverImage_of_reflectionData`.
There is no root-system or Weyl-generation premise in this step.

Suppose now that actual opposite-root factor pairs exist, expressed by
`RelativeRoot.HasOppositeFactorPairs i`. Smoothness from the cover premise
and splitness construct integral reflection data
`RelativeRootReflectionData.ofOppositeFactorPairs`. Their actual normalizer
representatives lie in the subgroup generated by the corresponding two root
groups, hence in the actual cover image by the preceding inclusion.
The root-generated Weyl-surjectivity theorem therefore applies to that image.
`subgroupRelativeWeylMap_derivedCover_surjective` retains
`HasRelativeRootSystem i` as the quotient-generation input.
Its `_of_positive_stabilizer` alternative instead retains a generic
cocharacter and `HasTrivialPositiveRootStabilizer i ν`; finiteness of the
actual roots follows from splitness and the affine smooth ambient group.

`exists_derivedCoverWeylRepresentative` lifts every class `w` through this
surjective restricted quotient map, then uses actual image membership to
obtain a point of `C(k)`. The chosen
`derivedCoverWeylRepresentative i hcover hi hE hroot w` belongs to the
subgroup of `C(k)` whose images under `π ≫ d` normalize `T`. Its
`_mem_normalizer` theorem records this membership, and its `_class` theorem
states that this image has exactly class `w` in the original quotient.
This is a set-theoretic choice; no multiplicative compatibility is asserted.
The `_normalizer_factorization` theorem uses equality of these quotient
classes to write any original normalizer point as the image of the selected
cover point times a point of the actual whole-torus centralizer.

Finally, `exists_derivedCover_mul_centralizer_of_oppositeFactorPairs`
combines the cover-image unipotent inclusion and Weyl surjectivity with the
existing Bruhat product reduction. The published `genericCentralizer`
supplies equality of the dynamic and whole-torus centralizers for the
supplied generic cocharacter. This produces actual points `c : C(k)` and
`z : Z(k)` with

`g = rationalPoints.map (π ≫ d) c * rationalPoints.map j z`.

The theorem retains opposite-pair existence, the actual-root-system
realization, and rational Bruhat decomposition as explicit structural
premises. Its `_of_positive_stabilizer` alternative replaces the root-system
premise by triviality of the positive-root stabilizer. Neither assembly
theorem takes unipotent containment, Weyl surjectivity or generic-centralizer
equality as an additional premise. No normality of the rational cover image
is assumed: the existing reduction uses centralizer normalization of the
dynamic unipotent subgroup.

The provenance is internal. The proof combines the named Library
constructions with the independently developed `RootGeneratedWeylRepresentatives`,
`SimplyConnectedCentralizerProductReduction`, `DerivedCoverUnipotentLift`
and `DerivedCoverReflectionLift` units. Worker 1353 authored the two cover
lifting units reused here. The construction contributes to the minimal
Levi product associated with Kaletha–Prasad, Fact 2.6.22; it does not prove
the unconditional `SimplyConnectedCentralizerProductStatement`.
Opposite-pair existence, quotient generation or positive-stabilizer
triviality, and rational Bruhat decomposition remain to be proved or
imported for that target. No restriction on characteristic, perfectness,
valuation, topology or universe is imposed.
