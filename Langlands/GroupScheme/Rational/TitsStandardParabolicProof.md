# Proof: the standard parabolics of the rational Tits system

Author: Worker 3857.

`Langlands.GroupScheme.titsStandardParabolic : TitsStandardParabolicStatement.{u}` proves the
published statement `TitsStandardParabolicStatement` of
`Langlands.GroupScheme.Rational.TitsStandardParabolicStatement` at an arbitrary universe `u`.

The statement covers a field `k : Type u`, a connected reductive group scheme `G` over
`Spec k`, a maximal split torus `i : T.toGrp ⟶ G`, a generic cocharacter `ν` of `T` and a set
`J ⊆ simpleRelativeRoots i ν`. It asserts the equality of subsets of `G(k)`

`(standardParabolicPoints i ν J : Set _) =
  TitsSystem.standardParabolic (standardParabolicPoints i ν ∅) π (relativeReflections i J)`,

with `π = QuotientGroup.mk' ((centralizerPoints i).subgroupOf (normalizerPoints i))`. In words,
`P_J(k) = B W_J B`, where `B = P_∅(k)` and `W_J` is the subgroup of `N(k)/Z(k)` generated by
the reflections in the roots of `J`.

The theorem has no premises. It adds no assumption of characteristic, perfectness, splitness,
quasi-splitness, local fields or reducedness of the relative roots. The cases `J = ∅` and
semisimple `k`-rank zero (where `simpleRelativeRoots i ν = ∅`) are included. It depends only
on the axioms `propext`, `Classical.choice` and `Quot.sound`.

## Proof as implemented

The proof is one application of the published conditional theorem
`titsStandardParabolicStatement_of_statements` (module
`Langlands.GroupScheme.Rational.TitsStandardParabolicStatement`) to three published proofs:

- `standardParabolicEndpoints : StandardParabolicEndpointsStatement`
  (`Langlands.GroupScheme.Rational.StandardParabolicEndpointsProof`). It identifies
  `P_∅(k)` with the rational points of the dynamic minimal parabolic
  `Dynamic.parabolic (CommGroupScheme.groupHom ν ≫ i)`.
- `standardParabolicPointsStatement_proof : StandardParabolicPointsStatement`
  (`Langlands.GroupScheme.Rational.StandardParabolicPointsProof`). Its first clause says that
  `g ∈ P_J(k)` exactly when `g = p * n * q` with `p, q` in the dynamic minimal parabolic and
  `n` a normalizing point whose class lies in `standardRelativeWeylGroup i ν J`.
- `standardRelativeWeylGeneration : StandardRelativeWeylGenerationStatement`
  (`Langlands.GroupScheme.Rational.StandardRelativeWeylGenerationProof`). It gives
  `Subgroup.closure (relativeReflections i J) = standardRelativeWeylGroup i ν J`.

The conditional theorem rewrites membership in `P_J(k)` by the first clause of the
rational-point statement. It replaces the dynamic minimal parabolic by `P_∅(k)` using the
endpoint statement, and `standardRelativeWeylGroup i ν J` by the closure of
`relativeReflections i J` using the generation statement. Unfolding
`TitsSystem.standardParabolic` and `TitsSystem.cell` then matches the two descriptions of
`B W_J B`. The Markdown of each imported module describes its own argument.

## Provenance

The target is Borel–Tits, *Groupes réductifs* (1965), §5.17 (printed p.101):
`P_Θ,k = P_k · W_Θ · P_k`. The statement module documents the source and the derived parts
of the formulation. The original proof of §5.17 first observes that the relative Weyl group of
the Levi subgroup `Z_Θ` is `W_Θ` (cf. §5.12). It then applies the Bruhat decomposition §5.15
to `Z_Θ`, together with the Levi decomposition `P_Θ,k = Z_Θ,k · V_Θ,k`, to get
`P_Θ,k = (U ∩ Z_Θ)_k · W_Θ · (U ∩ Z_Θ)_k · V_Θ,k`. Since `P_k ⊆ P_Θ,k`, it follows that
`P_Θ,k = P_k · P_Θ,k · P_k = P_k · W_Θ · P_k`. The verification of the Tits axioms from
§5.15–5.16 comes afterwards in Borel–Tits, as the proof of §5.18, which also uses §5.17.

The formal proof takes a different route, which the task allows. This module composes the
three published proofs named above and nothing else. The upstream input
`standardParabolicPointsStatement_proof` gets `P_J(k) = B W_J B` from the relative Tits system
`(G(k), P_∅(k), N(k), S)` and abstract Tits-system theory, not from a Bruhat decomposition of
the Levi `Z_Θ`; its Markdown describes that argument. This module adds no hypotheses and no new
source claim.
