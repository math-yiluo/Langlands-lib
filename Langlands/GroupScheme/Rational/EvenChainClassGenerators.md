# Path characteristic polynomials and off-path traces detect the class quotient

Module `Langlands.GroupScheme.Rational.EvenChainClassGenerators`.

## Main results

- `SplitPinning.rho_eq_of_pathCharpoly_eq_of_trace_eq`: let `G` be a simply connected group
  scheme over an algebraically closed field `k`, with a split pinning `p`, and let
  `β c : Fin (L c) → p.base.support` (`c : J`) be path components of type `A` of the Dynkin
  diagram (`IsPathComponent`). Let `g, g'` be rational points of `G`. Assume
  1. for every `c` and every fundamental representation `F` at the end vertex `β c 0`, the
     matrices of `g` and `g'` under `F` have the same characteristic polynomial, and
  2. for every simple root `a` off all paths and every fundamental representation `F` at `a`,
     the matrices of `g` and `g'` under `F` have the same trace.

  Then `g` and `g'` have the same image under the canonical quotient map
  `ClassFunctions.rho G`. The paths need not be disjoint.
- `SplitPinning.EvenChainData.rho_eq_of_charpoly_eq_of_trace_eq`: the same statement for the
  paths `C.path c` of supplied even-path data `C`.

This is the generator step of the comparison argument in the task context (route step 2):
over an algebraically closed field, the class functions are generated by characteristic
polynomial coefficients of path representations and by off-path fundamental characters.

## Proof of the main result

Choose generators `f_a` with top weights `ν_a` by `exists_generator`. Their torus
restrictions form a family of top-weight elements at the fundamental weights, and polynomials
in them are reflection invariant (`torusRestriction_coeff_reflection`). By
`Triangular.mem_range_aeval` (with `eq_zero_of_forall_simple_coroot_of_isSemisimple` for the
semisimple group), the torus restriction of every class function `h` is a polynomial `q` in the
restricted generators; injectivity of torus restriction over an algebraically closed field
(`torusRestriction_injective`) gives `h = q(f)`. Evaluation at a rational point is an algebra
homomorphism, so `h(g) = q(f(g)) = q(f(g')) = h(g')`, and `rho_eq_of_classEvaluation_eq`
concludes.

## Sources

The argument follows route step 2 of the task context of Task 5373 and adapts the Library
proof of `splitFundamentalCharacterGeneration`. Steinberg, *Regular elements of semi-simple
algebraic groups* (1965), source `steinberg-1965-regular-elements-semisimple-groups`, uses the
fundamental characters as coordinates of the quotient in the proof of 9.19 (printed p. 77);
on each path the present module replaces the fundamental characters at the path vertices by
signed characteristic-polynomial coefficients of one representation, which have the same top
weights. This replacement is internal to the formalization; it is not taken from Steinberg.
