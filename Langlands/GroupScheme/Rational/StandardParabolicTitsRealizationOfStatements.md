# The standard-parabolic Tits realization from the relative Tits system and generation

This internal auxiliary module proves the realization proposition
`StandardParabolicTitsRealization` (module
`Langlands.GroupScheme.Rational.StandardParabolicPointsTits`) from two statement
propositions:

- `RelativeTitsSystemStatement` (module
  `Langlands.GroupScheme.Rational.RelativeTitsSystemStatement`), which asserts the Tits
  axioms for `(P_∅(k), N(k), N(k)/Z(k), S)` with
  `S = simpleRelativeReflections i ν`, that every simple relative root has exactly one
  relative reflection, and that distinct simple relative roots have distinct
  reflections;
- `StandardRelativeWeylGenerationStatement` (module
  `Langlands.GroupScheme.Rational.TitsStandardParabolicStatement`), which asserts
  `Subgroup.closure (relativeReflections i J) = standardRelativeWeylGroup i ν J` for every
  set `J` of simple relative roots.

The module introduces no definitions and adds no hypotheses or axioms. It does not prove
either input.

## Results

- `relativeReflections_setOf_eq`: suppose every simple relative root `α` has at most one
  relative reflection, that is, `IsRelativeReflection i α w` and
  `IsRelativeReflection i α w'` imply `w = w'`. Then every set
  `X ⊆ simpleRelativeReflections i ν` equals `relativeReflections i J_X`, where
  `J_X` is the set of simple relative roots `α` with `IsRelativeReflection i α w` for
  some `w ∈ X`.
- `standardParabolicTitsRealization_of_statements`: `RelativeTitsSystemStatement` and
  `StandardRelativeWeylGenerationStatement` together imply
  `StandardParabolicTitsRealization`. The set `S` it provides is
  `simpleRelativeReflections i ν`.

## Proof

`relativeReflections_setOf_eq`. Let `w ∈ relativeReflections i J_X`. Then `w` is a
reflection in some `α ∈ J_X`, and `α` has a reflection `w' ∈ X`. Since `α` is simple, the
uniqueness hypothesis gives `w = w'`, so `w ∈ X`. Conversely, let `w ∈ X`. Since
`X ⊆ simpleRelativeReflections i ν = relativeReflections i (simpleRelativeRoots i ν)`,
`w` is a reflection in some simple relative root `α`. Then `α ∈ J_X` by definition, so
`w ∈ relativeReflections i J_X`.

`standardParabolicTitsRealization_of_statements`. Fix the data and take
`S = simpleRelativeReflections i ν`.

- The Tits axioms are the projection `HasRelativeTitsSystem.isTitsSystem` of the relative
  Tits system statement.
- Let `J` be a set of simple relative roots. Take `X = relativeReflections i J`. Then
  `X ⊆ S` by `relativeReflections_subset_simple`, and the generation statement gives
  `standardRelativeWeylGroup i ν J = Subgroup.closure X`.
- Let `X ⊆ S`. Take `J = J_X`, which consists of simple relative roots. The generation
  statement for `J_X` gives
  `standardRelativeWeylGroup i ν J_X = Subgroup.closure (relativeReflections i J_X)`.
  This set of reflections is `X` by `relativeReflections_setOf_eq`. The uniqueness
  hypothesis of that lemma follows from
  `HasRelativeTitsSystem.existsUnique_isRelativeReflection`.

Only the "exactly one reflection" conjunct of `HasRelativeTitsSystem` is used, together
with its Tits axioms. Its last conjunct, that distinct simple roots have distinct
reflections, is not needed.

## Provenance

These are internal, derived results that compose the published realization interface with
the two statements above. They support the proof of
`Langlands.GroupScheme.StandardParabolicPointsStatement`, through
`standardParabolicPointsStatement_of_titsRealization`. Borel–Tits, *Groupes réductifs*
(1965) is the classical counterpart. 5.15–5.16 (printed pp. 100–101) verify the Tits axioms
for `(G(k), P(k), N(k))` with the fundamental reflections `r_a` (`a ∈ Δ`) as `S`. 5.17
(printed p. 101) defines `W_θ` as the subgroup generated by the `r_a` with `a ∈ θ`. With
this labelling, every subset of `S` has the form `{r_a | a ∈ θ}` for some `θ ⊆ Δ`. The
module proves that correspondence in the Lean setting, where `S` is described through
reflections of the relative root span (module
`Langlands.GroupScheme.Rational.RelativeReflection`).
