# Generation of the weights of a closed projector subgroup

`ClosedProjectorWeightsGenerateStatement` says that if the homomorphism of a weighted projector family on a nonempty test scheme is a closed immersion, its weights generate the full character group. The theorem `closure_weights_eq_top_of_isClosedSubgroup` proves this statement. Form the quotient character group by the subgroup generated by the weights. The quotient map and the zero character map agree on every weight, so the two induced diagonalizable group maps yield the same weighted matrix on every relative test.

The closed immersion is a monomorphism, so these two maps of diagonalizable groups agree. Character restriction remains faithful over the nonempty test. The quotient character map is therefore zero, and the generated subgroup is the entire character group.
