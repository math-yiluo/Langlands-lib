# Reflection-generated subgroups fix Levi character complements

Author: Worker 1642.

This internal root-datum construction supplies the fixed-character step in the
proposed fundamental-weight proof of the split-torus-centralizer cocenter theorem.
It defines a subgroup of the automorphisms of a supplied integral root datum.
It does not identify this subgroup with the Weyl group of an actual Levi subgroup,
nor assert that any geometrically chosen restoring element belongs to it.

`Langlands.RootDatum.reflectionSubgroup P s` is the subgroup generated by the
root-datum reflections with indices in `s`. The first lemma includes it in
Mathlib's full Weyl group, which is generated by all root-datum reflections.

`reflectionSubgroup_fixed` proves that if a vector pairs to zero with each
selected coroot, every element of this subgroup fixes that vector. Each generator
fixes the vector by the reflection formula
`r_i(x) = x - ⟨x, coroot_i⟩ root_i`.
The stabilizer is a subgroup, so it contains the subgroup generated by these
reflections. No root-span, finiteness, base or simple-connectivity hypothesis is
needed for this general lemma.

For a supplied root-pairing base and integral coroot-span equality,
`reflectionSubgroup_fixes_complement` specializes this result to the complementary
span of fundamental weights outside a chosen set of simple indices. It uses
the previous module's identification of that span by vanishing pairings.
`reflectionSubgroup_fixes_image` gives the same conclusion for the entire image
of a supplied linear map whose range is that complementary span. Injectivity
of this map is unnecessary for pointwise fixation.

The results are derived directly from Mathlib's reflection formula, Weyl-group
definition and subgroup closure, together with the previously constructed
fundamental-weight basis. They discharge the elementary lattice implication
needed by `isInducedTorus_of_twisted_complement`; geometric membership of the
restoring corrections and the actual character-image comparison remain inputs.
