# Actual Tits index of a prescribed separable-closure pinning diagram

This derived internal adapter starts with actual Galois pinning data for a
semisimple group over an algebraic splitting extension and a specified
isomorphism from the original field's separable closure to that extension.
It constructs an actual Tits index of the original group together with an
equivalence of its entire simple-vertex set with the supplied pinning's base.
Every ordered Cartan pairing and each full absolute-Galois star element are
preserved through the specified closure isomorphism.

First use the published finite-stage pinning theorem with the canonical map
from the separable closure to the splitting extension. The original torus
splits over that separable closure because it is a torus. Independently choose
an actual Tits index by the published existence theorem. Same-group star
independence compares its pinning with the descended finite-stage pinning.
Composing the two root-datum equivalences gives the vertex equivalence and
ordered pairing formula. Their simultaneous star identities give compatibility
for every absolute-Galois element transported through the closure isomorphism.

The supplied pinning need not itself satisfy the positivity conditions for a
Tits index. The output is an actual Tits index, while the comparison retains
only the Cartan diagram and full star action. No claim about distinguished
vertices is made. The construction has no characteristic restriction.
