# Assemble common fibrewise root data from actual field data

This internal unit expresses actual field root data in integral coordinates and assembles one common full fibrewise root datum from supplied field data and an integral representation. It constructs neither the input representation nor the input field root data.

The transport theorem `IsRootDatumOf.of_identityEquiv` concerns two root data on the actual character and cocharacter lattices of the same torus map over a field. A full `RootPairing.Equiv` between them must have identity weight and contravariant coweight maps on both entire lattices. The pairing and root range then agree, and its index equivalence identifies the full reflections. The original actual normalizing points and torus automorphisms therefore witness the reflection clause for the second datum. This preserves every clause of the published `IsRootDatumOf` predicate.

For a field `k : Type u` and a finite coordinate type `I : Type u`, `CoordinateRootDatum.ofField` maps an actual root datum of `splitTorus.commGroupScheme (Spec k) I` to the entire coordinate lattices `I → ℤ`. Its root-index type may lie in an independent universe `v`. The construction uses the canonical character and cocharacter coordinate equivalences, and `ofFieldEquiv` is the resulting full root-pairing equivalence. The composite `fieldRealizationOfFieldEquiv` compares the original actual datum with the field realization of its coordinate expression. Both actual lattice maps are identities, with explicit simp formulas. Consequently `isRootDatumOf_fieldRealization_ofField` preserves the complete actual predicate. The theorem `ofField_isReduced` also preserves reducedness: injectivity of the character-coordinate map preserves linear independence of each pair of roots, and the original reducedness criterion gives equality or opposite roots in coordinates.

The theorem `CoordinateRootDatum.isRootDatumOf_of_identityEquiv` concerns two coordinate data realized on one field. It conjugates their identity-lattice equivalence by the canonical field-realization equivalences. The resulting actual lattice maps are identities, so the preceding transport theorem applies. These transports require neither finiteness of the root-index types nor reducedness.

For the local assembly, let `R : Type u` be a commutative local ring, `I : Type u` a finite type with decidable equality, `G` a smooth affine group over `Spec R`, and `i : splitTorus (Spec R) I ⟶ G` a supplied morphism. Supply a matrix representation `ρ` on `Fin N` whose composite with `i` is a monomorphism of underlying schemes. The theorem `isFibrewiseRootDatumOf_of_fieldData` starts with one finite reduced coordinate datum `P`, indexed in any universe `v`, whose realization is an actual root datum on one supplied field fibre. Assume that every field `l : Type u` with its supplied `R`-algebra structure has some coordinate datum, indexed in `Type u`, whose realization is an actual root datum of the canonical pullback of `i`. No finiteness or reducedness of these other data is needed in this theorem.

For each such field, `CoordinateRootDatum.equivOfRepresentation` compares its supplied datum with `P` using the original integral representation. This full equivalence fixes both entire coordinate lattices. Applying `isRootDatumOf_of_identityEquiv` proves that `P` itself realizes an actual root datum on that field fibre. Together with the original finiteness and reducedness, this is precisely `IsFibrewiseRootDatumOf I G i P`. All field fibres use their original algebra structures and the canonical split-torus pullback identifications.

The theorem `exists_fibrewiseRootDatumOf_of_actualFieldData` accepts field data in the actual-lattice form used by `RootDatumExistenceStatement`: for every supplied field algebra, a finite root-index type in `Type u`, an actual root datum, the complete `IsRootDatumOf` predicate, and reducedness. It chooses such data over `IsLocalRing.ResidueField R`, expresses that datum in coordinates, and applies the preceding theorem. The conclusion is the existence of a coordinate datum, with root indices in `Type u`, satisfying `IsFibrewiseRootDatumOf` for the original torus map.

Finally, `exists_fibrewiseRootDatumOf_of_rootDatumExistence` assumes `IsReductive G`, a proof of `RootDatumExistenceStatement.{u}`, the supplied representation and its monomorphic torus composite, and maximality of the canonical coordinate torus map on every supplied field fibre. Reductivity supplies smoothness and affineness over the base and connected reductivity of each actual field pullback. The field existence statement then supplies the actual data consumed by the preceding adapter. This wrapper requires no separate ambient smoothness or affineness instance. Its maximality premise quantifies over every field-valued fibre; no implication from residue-fibre maximality is proved here.

The provenance is internal. The unit uses canonical coordinate equivalences, `RootPairing.map`, the full-lattice reflection-intertwining law, the proved integral-representation fibre comparison, and reductive field-base-change results. It invokes the field existence proposition only through its explicit proof argument. It adds no domain, Noetherian, characteristic, strictly Henselian, root-spanning, or prescribed-generic-map condition. Integral representation existence, unconditional actual field root-data existence, maximality transport, and the integral group-scheme isomorphism remain separate obligations. In particular this supporting unit does not prove `StrictHenselianGenericIsoStatement`.
