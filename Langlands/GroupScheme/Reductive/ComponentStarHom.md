# Full star naturality for an embedded orthogonal root component

Derived interface for an injective integral root embedding whose
image is orthogonal to all outside roots and preserves the supplied simple bases.
The ambient and component lattices and full root sets need not be equivalent.
An ambient reflection in the component restricts to the matching component
reflection; every outside reflection fixes the embedded roots. Thus each whole
ambient Weyl word restricts to one Weyl word acting on all component roots.
The uniqueness of the based representative in each Weyl coset then gives exact
compatibility of based projection and the full star actions from ordinary
Galois root-index or actual character compatibility. The input embedding and
its orthogonality/base properties are explicit data, not asserted existence.
