# Normal root support is a union of Cartan components

Worker 634.

For the supplied integral RootComponentCoordinates of an affine pinned model,
reflection in any root preserves every root's component. A predicate invariant
under root reflections and constant across nonzero simple Cartan edges is
therefore constant on all roots of each component. These purely integral
conclusions use the existing simple-reflection induction for a root-datum base.

For a smooth connected closed normal subgroup of any semisimple field fibre
over an algebraically closed field, actual full root-subgroup containment has
these properties, so its root support is a union of the integral Cartan
components. The published normal-root dichotomy assigns every remaining root
group to the subgroup's full centralizer. The actual coroot-containment and
orthogonality lemmas then propagate root containment across any nonzero Cartan
pairing. This avoids a classification by Dynkin types.

This is an internal derivation from the imported integral component coordinates,
actual coroot-containment, and normal-root dichotomy results. It prepares the
local component decomposition motivated by Conrad, *Reductive group schemes*
(2014), Proposition 6.4.4, pp.232–233; no existence of a product decomposition is
asserted here.
