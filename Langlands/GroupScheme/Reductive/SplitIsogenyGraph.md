# Actual graphs of local reductive isogenies

This internal support module constructs graphs from actual isogenies between corresponding cocharacter centralizers. It derives from `SplitIsogenyLocalLevis` and the generated-family construction in `SplitLeviGluingGraph`. Its intended application is the graph argument of Milne, *Algebraic Groups* (2017), §§23.16–23.24. It does not assert general isogeny realization.

`LocalIsogeny` retains the two actual closed centralizers, both representing identities on all scheme tests, their torus factors, and an actual isogeny commuting with a prescribed morphism between potentially different tori. `localIsogeny` constructs this package at any rank-at-most-one source direction using the previously proved corresponding-centralizer realization theorem. The source and target cocharacters are respectively `ν` and the prescribed coweight map applied to `ν`.

`localIsogenyGraphEnvelope` constructs the smooth connected affine closed subgroup of the product generated by the paired local maps and the graph of the prescribed torus map. Each local torus factor equals the distinguished graph torus. Every source centralizer, and thus every root subgroup annihilating its direction, lies in the first projection on all scheme tests.

`first_geometry` applies the proved simple-Levi generation criterion to a supplied generic chamber whose simple roots are each annihilated by some local direction. With the chamber centralizer identified with the source torus, the first projection is flat, surjective, locally of finite presentation, and quasi-compact. The module imposes no separability or smooth-kernel condition on any local isogeny. It does not establish that the first projection is invertible or that the graph torus is maximal.
