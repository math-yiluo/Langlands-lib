# First projection of the local-isogeny graph

This is derived support for split root-datum isogeny realization. It adapts
only the source-side part of the published common-torus comparison argument
in `SplitLeviGluingFactorInjectivity` and the factor assembly in
`SplitLeviGluingGraphFactorIsomorphisms`. The graph has two possibly different
tori, and the target local maps can be inseparable. The result constructs an
actual isomorphism whose homomorphism is the first graph projection.

## Data and scope

Let `D : SimpleIsogenyGraph i₁ i₂ t` be the actual graph generated by the
source torus and the prescribed source-simple local isogenies, with
`i₁ : T.toGrp ⟶ G₁`, `i₂ : T'.toGrp ⟶ G₂` and `t : T ⟶ T'`.
The ambient groups are smooth affine groups over a field `k : Type u`.
All constructions retain this arbitrary universe.

`GraphDynamicFactors.positiveFirstProjectionData` and
`negativeFirstProjectionData` construct the restrictions of the first
projection on the full positive and negative graph factors over an
algebraically closed field. Their additional inputs are a source root datum
`IsRootDatumOf i₁ P`, source connected reductivity and maximality of `i₁`.
Each result records the actual factor map, its inclusion square, flatness,
scheme surjectivity, local finite presentation and quasi-compactness.

`firstProjectionIsoOfGeometry` additionally takes graph connected reductivity
and `D.GraphTorusGeometry`. This geometry records the full factors, maximality
of the graph torus and equality of its roots with the source roots. It
constructs an isomorphism from the graph to `G₁`, whose homomorphism is exactly
`D.envelope.first`, as proved by `firstProjectionIsoOfGeometry_hom`.

The entry definition `firstProjectionIsoOfReductive` constructs that geometry
from finite reduced root data `P`, `P'` on the actual character and cocharacter
lattices of `T`, `T'`; finiteness of all four lattices; splitness of the target
torus; a root-datum isogeny `f : RootDatumIsogeny p P' P`; and the equation
`t ≫ χ = f.weightMap χ` for every target character. The source torus is split
as part of `D`. It retains explicit source connected reductivity, source-torus
maximality, graph connected reductivity and algebraic closedness of the field.
`firstProjectionIsoOfReductive_hom` identifies its homomorphism with the
supplied first projection. The natural number `p` and all root factors remain
general; no factor-one or separability hypothesis is introduced.

## Implemented proof

The positive and negative source root maps represent the actual simple root
subgroups after composition with the first projection. They lie in the full
graph factors. Factoring through their closed inclusions gives containment of
each simple root subgroup in the image of the corresponding restricted map.
The generic `unipotentProjectionData` construction then uses the closed
homomorphism image and reductive simple-root generation to establish the
recorded faithfully flat geometry. The negative argument negates both root
and chamber and uses the same local maps as the positive argument.

The first differential is injective one graph-torus weight space at a time.
For a nonzero weight orthogonal to a chosen simple-root direction, root
equality places it in the source root set. The actual local centralizer root
theorem places it in that source local Levi. Its nonzero tangent vector maps
to the graph weight space, which is one-dimensional by graph reductivity and
graph-torus maximality. The first projection restricts there to the closed
source Levi inclusion, so it cannot kill that vector. Thus its kernel meets
the graph weight space trivially.

Actual source normalizer representatives lift through the same local Levis
into the graph. Conjugation by these points transports triviality of the
weight-space kernel under source simple reflections. Positive-root induction
starts with the simple roots and their doubles, which are orthogonal to their
chosen directions, and handles both signs. The zero weight space belongs to
the self-centralizing graph torus; the torus square and monicity of `i₁`
prove injectivity there. Nonzero weights outside the graph root set have zero
weight spaces. The split-torus internal weight decomposition therefore makes
the entire first differential injective.

The reused `UnipotentProjectionData.isIso_of_lieKernel` upgrades each of the
two faithfully flat unipotent restrictions to an isomorphism. It uses the
actual fibre product with the source torus and the connected dynamic
unipotent group with zero Lie algebra, so its kernel argument holds on every
test scheme. Finally `Dynamic.isoOfTripleCellIsomorphisms` assembles the two
unipotent isomorphisms and the identity on the source torus. The constructed
isomorphism has the original first projection as its homomorphism.

## Remaining application

The graph reductivity input must still be supplied from projection coverage
in the intended realization. This module proves first-projection invertibility
over algebraically closed fields. Descent to arbitrary fields, construction
of the final ambient isogeny and the full realization/extension theorem are
separate obligations.
