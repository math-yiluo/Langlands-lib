# Etale-local coroot normalizers

Fix an arbitrary commutative ring `R` in universe `u`, a finite coordinate type `I`, and a reductive group scheme `G` over the affine base `Spec R`, with `IsAffineHom G.X.hom`. Let `i : splitTorus (Spec R) I → G` be the supplied coordinate-torus homomorphism and let `P` satisfy `IsFibrewiseRootDatumOf I G i P`. Under these hypotheses, this module constructs actual normalizing sections for every coordinate reflection on an affine etale neighbourhood of each prescribed base point. Reductivity supplies `hG.smooth`, the smoothness input to the published pointed etale transporter lifting theorem.

The fibrewise root-datum predicate supplies an actual normalizing rational point for each root reflection on every field-valued fibre. The proof uses the canonical residue-field algebra at the prescribed point, applies `LocalSplitCorootTransport.isRealizedAt_reflection`, and lifts the actual transporter with its prescribed integral torus action using `pointedEtaleNormalizerOfTransporter`. Exact residue recovery ensures that the image of the neighbourhood contains the prescribed point. The affine base ring need not be local or reduced, and this construction requires no root-group parametrization. Its provenance is this internal combination of the published fibrewise root-datum and pointed transporter lifting interfaces.

`EtaleCoordinateReflectionData` records an etale cover of `Spec R` with affine members and actual normalizing sections for the specified torus homomorphism and inverse exponent reflection. The structure itself records these data without a reductivity field. The constructor `etaleCoordinateReflectionData` requires the full reductive affine setting and fibrewise root-datum hypotheses above; it chooses one pointed neighbourhood for each base point and assembles the resulting jointly surjective etale cover.

Separately, `splitTorus.exponentCocharacter_comp_reflection` works over any scheme `S` with finite coordinate type `I` and a coordinate root datum `P` whose integral pairing is the standard dot product. Under that explicit standard-pairing premise, it proves that the actual exponent reflection inverts its fixed-exponent coroot. The proof verifies equality through each torus projection and the root-coroot pairing value two; it is an equality of maps over the whole base, including its nilpotent structure.
