# Fppf-local perfectness of relative semisimple groups

The theorem `Langlands.GroupScheme.relativeSemisimpleFppfPerfect.{u}` proves exactly the published `RelativeSemisimpleFppfPerfectStatement.{u}`. For every scheme `S`, every group scheme `G` over `S` that is reductive with semisimple geometric fibres, every test `T : Over S`, and every point `x : T ⟶ G.X`, there is a jointly surjective flat locally finitely presented cover of `T` on whose members the restricted points belong to the ordinary abstract commutator subgroups of the groups of points. This is the unchanged predicate `RelativeDerived.LocallyCommutator`. The theorem has no additional hypothesis on the base, test, characteristic, splitness, or quasi-compactness.

The internal descent lemma `relativeSemisimpleFppfPerfect_of_split` first reduces the result to the affine split case with its actual fibrewise maximal coordinate torus and full fibrewise root datum. For a reductive group with semisimple geometric fibres over an arbitrary scheme, it chooses the published affine étale splitting neighbourhood at each base point. Semisimplicity transfers to each chart through the actual pullback-composition isomorphism. The split premise gives local commutator membership on every test over each chart. For a test over the original base, the lemma pulls this étale cover back to a flat locally finitely presented cover. The actual multiplicative base-change point equivalence transfers membership on each member to the original group. Identity maps reassociate the structure maps, and cover descent completes this reduction.

The final theorem discharges the split premise. For each root it takes the integral isolating cocharacter supplied by `RelativeRootDynamicCell.isolatingExponent`. The two properties of that choice are exactly the premises of `LocalRootGroup.locallyCommutator_root`, giving local abstract commutator membership for every value of the actual dynamic root factor and its actual inclusion. The reduction `RelativeRootDynamicCell.locallyCommutator_of_rootValues` combines these root values with the established torus commutator result. Its actual ordered root-factor cell is open and contains the unit; smooth surjective double-cell multiplication then gives local membership for every point. Applying the arbitrary-base descent lemma proves the exact target in every universe.

This is a composition of the actual dynamic-root, torus, open-cell and descent constructions. The root-value input inverts the root commutator map after a quadratic fppf refinement; the torus input uses coroots and local extraction of unit powers. These arguments implement the open-cell and root/coroot approach in the final paragraph of Brian Conrad, *Reductive group schemes* (2014), p.163, proof of Theorem 5.3.1 (registered source `conrad-2014-reductive-group-schemes`). The implemented proof uses the actual dynamic groups in place of a separate reduction to `SL₂`. It does not assume the relative derived-group existence or uniqueness statement.
