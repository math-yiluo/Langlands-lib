# Proof: subgroups directly spanned by root groups over an affine base

`Langlands.GroupScheme.affineSplitRootSubgroupSpanning :
AffineSplitRootSubgroupSpanningStatement.{u}` proves the Library statement
[`AffineSplitRootSubgroupSpanningStatement`](AffineSplitRootSubgroupSpanningStatement.md).
The statement packages Conrad, *Reductive group schemes* (2014), Theorem 5.1.13,
Proposition 5.1.14 and Proposition 5.1.16(1) for a split reductive group over `Spec R`, with
`R` any commutative ring. The theorem uses only the standard axioms `propext`,
`Classical.choice` and `Quot.sound`.

## Assembly

After introducing the binders of the statement, the proof proves the four clauses
separately:

1. **Open cell.** This is the Library's `LocalSplitBigCell.isOpenImmersion_cellMap`
   ([`LocalSplitFlatBigCell`](LocalSplitFlatBigCell.md)), which already holds over an
   arbitrary commutative ring.
2. **The closed subgroup `T ⋉ U_{Φ⁺}`.** This is `exists_closedSubgroup_torus_positive`
   from [`AffineSplitPositiveBorel`](AffineSplitPositiveBorel.md). `B` is the closed
   dynamic parabolic subgroup of a cocharacter that is positive exactly on the positive
   roots.
3. **Directly spanned subgroups `U_Ψ`.** This is `exists_closedRootSubgroup` from
   [`AffineSplitClosedRootSubgroup`](AffineSplitClosedRootSubgroup.md). `U_Ψ` represents
   the subgroup functor generated by the root groups of `Ψ`. Its points are the ordered
   products in any order, by a height-collection argument that uses clause 4. Each
   ordered product map is a closed immersion
   ([`AffineSplitPositiveProductClosed`](AffineSplitPositiveProductClosed.md)), because
   `Ψ` is positive for some base
   ([`IntegralClosedRootSetBase`](../../LinearAlgebra/IntegralClosedRootSetBase.md)).
4. **Commutator relations.** This is `exists_commutator_orderedProduct` from
   [`AffineSplitCommutatorRelations`](AffineSplitCommutatorRelations.md). It evaluates the
   Library's universal commutator polynomials on arbitrary test schemes.

Each helper theorem states its clause in exactly the form of the target statement, so the
assembly is direct application.

## Helper modules used by this proof

- [`LinearAlgebra/IntegralClosedRootSetBase`](../../LinearAlgebra/IntegralClosedRootSetBase.md):
  a closed set of roots with `Ψ ∩ -Ψ = ∅` is positive for some base (Conrad, Lemma 5.1.15),
  and closed sets contain the positive integral combinations of their members that are
  roots.
- [`AffineSplitCommutatorRelations`](AffineSplitCommutatorRelations.md): clause 4.
- [`AffineSplitPositiveBorel`](AffineSplitPositiveBorel.md): clause 2.
- [`AffineSplitPositiveProductClosed`](AffineSplitPositiveProductClosed.md): ordered
  products over distinct positive roots are closed immersions.
- [`AffineSplitClosedRootSubgroup`](AffineSplitClosedRootSubgroup.md): clause 3.
- [`Dynamic/ContractingClosedSubgroupFibres`](../Dynamic/ContractingClosedSubgroupFibres.md):
  a closed subgroup contained in the contracting subgroup of a
  cocharacter has unipotent geometric fibres. Clause 3 uses it.
