# Actual simple roots and rank-one directions for Levi gluing

Author: Worker 1444.

This internal derived construction chooses the actual simple-root family used
by the Levi graph argument. It uses the intrinsic roots of the supplied torus
map, rather than assuming a root-group family or a chamber as additional input.
The base field and the universe are arbitrary.

For a split torus mapping into an affine group locally of finite type,
`simpleRootDirections` selects the existing generic integral cocharacter. For
each intrinsic simple root it selects the existing generic kernel cocharacter.
The character pairs to zero with that direction, and the zero-pairing ambient
roots satisfy exactly `IsRankOneDirection`. These facts use root finiteness and
the earlier kernel-direction theorem; they do not require reductivity or a root
datum.

For a root datum realizing the actual roots, `finite_rootIndex` proves its
index type finite from finiteness of the actual root set and injectivity of the
root map. `mem_baseOf_iff_simple` identifies positive indecomposable root-datum
indices with the intrinsic simple-root characters for any specified
cocharacter. `simpleRootIndexEquiv` is the actual equivalence of these index
types. Its inverse recovers each character through the root map.

For a generic cocharacter, Mathlib's integral independence theorem for positive
indecomposable roots gives `linearIndependent_simpleRoots`. This only uses the
root family, without requiring an integral base for both roots and coroots.
`closure_simpleRoots_eq_positive` identifies the additive monoids generated by
the intrinsic simple roots and by all intrinsic positive roots. The proof
transports the finite-family indecomposable-generation theorem through the
actual root-set equality. It does not assert generation of algebraic groups or
generation on rational points.

`simple_sub_not_root` transports the existing indecomposable difference
exclusion theorem through the same index equivalence. Distinct intrinsic simple
roots therefore have difference outside the actual roots. This statement alone
does not assert commutation of the corresponding root groups.

The provenance is internal composition of imported Library and Mathlib results.
No reducedness hypothesis is imposed: the chosen family is the positive
indecomposable root family, and the construction does not claim it is a base
for the dual coroots. Higher mixed-root exclusion, algebraic group generation,
root-group commutation, graph density and global projection invertibility remain
obligations of the gluing proof.
