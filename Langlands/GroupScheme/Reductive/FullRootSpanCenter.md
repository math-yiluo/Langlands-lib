# Full root span and the full scheme-theoretic centre

A connected reductive field group with a supplied split maximal torus
and actual root datum has trivial full scheme-theoretic centre whenever
its roots generate the entire integral character lattice.

The actual centre lies in the self-centralizing maximal torus. Every
root evaluates to one on its universal centre point, using the actual
adjoint action on nonzero root vectors. Integral generation makes every
character evaluate to one. The split torus character-point equivalence
then makes that universal torus point the identity, so the full centre
functor is trivial on every test scheme, including nonreduced tests.

This internally strengthens the published finite-root-index centre
argument in `SplitSemisimpleRootSpanSufficiency` in the case where the
quotient lattice is zero. No new external translation, characteristic
restriction or reduced-centre premise is used.
