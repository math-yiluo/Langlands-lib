# Fppf-local commutators in actual relative root groups

This internal composition proves local abstract commutator membership for values of the actual dynamic root group. Its inputs are the actual root commutator isomorphism, the arbitrary scalar-extension comparison for dynamic root groups, the quadratic fppf-cover construction, the root-character calculation, and descent for the existing `RelativeDerived.LocallyCommutator` predicate. It introduces no new literature assertion or change to that predicate.

Let `R` be any commutative ring, `G` an affine group scheme over `Spec R`, and `i` a homomorphism from the split torus with finite coordinate type `I` into `G`. Assume `G` is reductive, `i` is a fibrewise maximal torus, and `P` is a full fibrewise coordinate root datum for this map. For a root `α`, let `mu` be an integral vector with zero dot product with `P.root α`, such that every root with zero dot product with `mu` equals `P.root α` or its negative. The actual group used throughout is `LocalRootGroup.Uc i mu (P.coroot α)`, with its existing ambient homomorphism `incl`.

The main theorem `locallyCommutator_root` says that for every test scheme `Z` over `Spec R` and every point `x` of this actual root group, the ambient point `x ≫ incl.hom.hom` satisfies `LocallyCommutator`. Thus a jointly surjective flat locally finitely presented cover of `Z` makes its restrictions lie in the abstract commutator subgroups of the groups of points. There is no affineness premise on `Z` and no local-ring, reducedness, nontriviality, characteristic, or semisimplicity premise on `R` or `G` beyond the hypotheses just listed. In particular the theorem includes tests over the zero ring.

## Implemented proof

`mem_commutator_incl_of_unit` first takes a torus section over the base whose root-character value minus one is a unit in the global functions of `Spec R`. The existing `rootCommutatorIso` inverts the actual root commutator map. Composing `x` with its inverse gives a root point whose ambient commutator with the supplied torus section is `x ≫ incl.hom.hom`. This proves membership in the original abstract commutator subgroup on the same test scheme.

`mem_commutator_baseChange_incl_of_quadratic_unit` works over every supplied commutative `R`-algebra `A`. It assumes the explicit integer dot-product equation `sum (P.root α * P.coroot α) = 2` and a unit `tau` in the global functions of `Spec A` satisfying `tau² - 1 = tau`. Applying the actual coroot to this unit gives a torus point whose root-character value minus one is a unit by `QuadraticRootCharacterUnit`. Reductivity, fibrewise maximality, and the full coordinate root datum pass to this scalar extension. The preceding criterion applies to the newly constructed actual root group; `rootGroupBaseChangeIso` and its compatibility with the ambient inclusion transport the result to the base change of the original actual root group.

`locallyCommutator_root_affine_of_pairing` applies the quadratic fppf refinement to an affine test `Z`, obtaining an affine `W`, a surjective flat locally finitely presented map `W → Z`, and such a quadratic unit on `W`. Its global functions provide an `R`-algebra `A`, and the canonical affine isomorphism identifies `W` with `Spec A` over `Spec R`. The unit and its equation transfer along that isomorphism. The multiplicative pullback adjunction lifts the restricted actual root point to a point over `Spec A`, so the scalar-extension lemma makes its ambient value an abstract commutator there. The equivalence `locallyCommutator_baseChange_iff` returns local membership over the original base. Restriction along the affine isomorphism and descent along `W → Z` complete this step.

`locallyCommutator_root_of_pairing` uses the canonical affine cover of any test, viewed as an fppf cover, and the cover descent lemma to extend this result to every test while retaining the explicit dot-product premise.

Finally, `locallyCommutator_root` removes that premise. On an empty test, the empty fppf cover proves the conclusion. On a nonempty test, a chosen point maps to a base point; its residue field is an actual field `R`-algebra. The supplied fibrewise root datum identifies its coordinate pairing with the standard integer dot product, and the root-coroot axiom gives the required value two. This avoids extracting a field fibre from an empty base or imposing nontriviality on `R`.

The definition `rootLocallyCommutatorPointHom` packages the resulting factorization on each test: the usual homomorphism from actual root points to ambient points has codomain restricted to `locallyCommutatorSubgroup`. Its underlying map is exactly composition with the existing inclusion, and its membership proof is `locallyCommutator_root`.

This pair supplies root values for the open-cell perfectness argument. It does not by itself assert the full arbitrary-base `RelativeSemisimpleFppfPerfectStatement`.
