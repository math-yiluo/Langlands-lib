# Reindexing actual matrix representations

This internal coordinate change uses an equivalence between finite index
types to reindex invertible matrices. Entrywise naturality under every
coefficient-algebra map gives an actual homomorphism of general linear
group schemes and hence `reindexRepresentation`.

The point-matrix formula is proved on every relative scheme. The
unit-scalar stabilizer equation for a coordinate basis vector is unchanged
when its index and the matrix are reindexed together. This permits the
exterior-power index type to be replaced by `Fin (n+1)` without altering
the line stabilizer on any test scheme.
