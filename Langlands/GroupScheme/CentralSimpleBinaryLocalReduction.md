# Local arithmetic reduction for restricted binary norm-one images

This internal reduction connects the exact local division-algebra SK1
proposition with the existing actual affine Weil-restricted binary
norm-one groups. It retains `LocalSK1Statement` as an explicit premise.
It supplies neither a proof of that arithmetic proposition nor the
unrestricted local Kneser–Tits theorem.

Let `F : Type u` be a nonarchimedean local field in the original
valuative-relation and topology convention. Let `E : Type u` be a field
with its original finite-dimensional `F`-algebra structure, and let
`D : Type u` be a finite-dimensional central division `E`-algebra.
There is no topology or valuative-relation hypothesis on `E` and no
separability or characteristic restriction. The common universe is
arbitrary. The declarations are in
`Langlands.GroupScheme.CentralSimpleUnits.BinaryRoot.WeilRoot`.

## Arithmetic and generation

`coefficientNorm_ker_of_localSK1 F E D hSK` installs the constructed
spectral norm topology, spectral valuative relation, and proved
nonarchimedean local-field property on the original field `E`, from
`Langlands.LocalField.FiniteExtension`. It then applies the explicitly
supplied `hSK : Langlands.CentralDivision.LocalSK1Statement` to `E` and
`D`. The conclusion is equality of the actual original coefficient
reduced-norm kernel and `commutator Dˣ`. The coefficient norm is
definitionally the tensor-inclusion composite in that exact statement.
All topological choices disappear from this algebraic conclusion.

For any finite coefficient basis `bD`,

`rationalPoints_range_le_parabolicElementarySubgroup_of_localSK1`
combines the coefficient equality with the existing actual-image
containment theorem. The target subgroup is the original

`rationalPointsToParabolicElementarySubgroup_of_localSK1` is the
original full rational map with codomain restricted by that containment.

The variant ending in `_of_iso` allows an arbitrary actual source model
