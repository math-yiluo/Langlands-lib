# Integral index of two A2 pairs in type D4

For a fixed-point-free order-three action on a coroot lattice, a coroot and its first translate form an A₂ pair. Between two such pairs the cross block has entries `a,b,c,a` because the action preserves the pairing. The orbit sum is zero, so `a + b + c = 0`. The determinant lemma treats the case when these entries lie in `{-1,0,1}` and some entry is nonzero. Checking those possible triples gives Gram determinant four. The D₄ Cartan matrix has the same determinant, so the coordinate matrix of the four coroots has unit determinant. Thus the four coroots give an integral basis in this configuration.

This is the integral determinant step in the torus decomposition used by Platonov and Rapinchuk, *Algebraic Groups and Number Theory* (1994), §6.8, printed pp. 372–373.
