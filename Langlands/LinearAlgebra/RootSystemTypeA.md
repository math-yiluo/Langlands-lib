# The type `A` root system over `ℚ`, transported along an injective linear map

Author: Worker 1220.

This module builds the root system of type `A` as a Mathlib `RootPairing` over `ℚ`,
together with its reflections and the image of its Weyl group. It is pure linear
algebra. It is written as a helper for the planned `GL_n` case of the relative root
system statement of task 6edfb074; that statement and its proof are not yet written.
All declarations are in the namespace `Langlands.LinearAlgebra.RootSystemTypeA`.

## Source

- Milne, *Algebraic Groups* (2017), source ID `milne-2017-algebraic-groups`, SHA-256
  `899b0f44f3c3ccfbaf5ed1cf9c180be7a8016b1c0e9709ca0c206304e5bd1cd0`.
  Printed page = PDF page − 16.
  - C.15 (printed p.611, PDF p.627): the Weyl group of a root system `(V, R)` is the
    group of automorphisms of `V` generated by the reflections `s_α`, `α ∈ R`.
  - Example C.16 (printed p.611, PDF p.627): `V` is the hyperplane `∑ xᵢ = 0` in
    `F^{n+1}` and `R = {eᵢ - eⱼ | i ≠ j}`; the map interchanging the `i`th and `j`th
    entries is a reflection with vector `eᵢ - eⱼ` preserving `R`, and `R` is a root
    system in `V`.
  - C.25 (printed pp.612–613, PDF pp.628–629): this Weyl group has a natural
    identification with the symmetric group `S_{n+1}`.

## Setting (derived generalization)

Milne takes `V` to be the hyperplane itself. Here the setting is more flexible, so that
it applies directly to a span of relative roots inside `ℚ ⊗ X*(T)`:

- `n` is a type with decidable equality (finite where needed), and `V` is a
  `ℚ`-vector space;
- `Φ : V →ₗ[ℚ] (n → ℚ)` is injective (`hΦ`);
- `Index n = {p : n × n // p.1 ≠ p.2}` indexes the roots, and `r : Index n → V`
  satisfies `Φ (r p) = rootVec p.1.1 p.1.2` (`hr`), where
  `rootVec i j = Pi.single i 1 - Pi.single j 1 = eᵢ - eⱼ`;
- for the root pairing, `[Finite n]`, `[FiniteDimensional ℚ V]` and
  `hsp : span ℚ (range r) = ⊤`.

When `V` is Milne's hyperplane, `Φ` is its inclusion and `r p = e_{p.1} - e_{p.2}`,
this is exactly Example C.16. This generalization is the provenance rationale: the
statements are Milne's, read through an injective map `Φ`.

## Definitions

- `rootVec i j : n → ℚ`, the vector `eᵢ - eⱼ`; `rootVecInt i j : n → ℤ`, the same
  vector with integer entries.
- `reflIdx p q : Index n`: the pair `q` with both entries moved by the transposition
  `swap p.1 p.2`.
- `corootFun Φ p : Dual ℚ V`, the linear form `x ↦ Φ x p.1 - Φ x p.2`. It is the coroot
  of `r p`.
- `permSubgroup Φ : Subgroup (V ≃ₗ[ℚ] V)`: the automorphisms `g` for which some
  permutation `σ` of `n` satisfies `Φ (g x) = Φ x ∘ σ` for all `x`. The proofs that it
  contains `1` and is closed under products and inverses use `σ = 1`, `τ * σ` and
  `σ⁻¹`.
- `rootPairing hΦ hr hsp : RootPairing (Index n) ℚ V (Dual ℚ V)`, built with Mathlib's
  `RootPairing.mk''` from the evaluation pairing `Module.Dual.eval ℚ V`, the roots `r`
  and the coroots `corootFun Φ`. The inputs are `corootFun_r_self` (pairing `2`) and
  `preReflection_r` (the reflection in `r p` sends `r q` to `r (reflIdx p q)`).
  Mathlib's `mk''` derives the coroot conditions from these over a field of
  characteristic zero.

## Lemmas about the vectors `eᵢ - eⱼ`

- `rootVec_apply`: the entries of `rootVec i j`.
- `comp_swap_eq`: `v ∘ swap i j = v - (v i - v j) • rootVec i j`, by cases on the
  coordinate.
- `rootVec_comp_perm`: `rootVec i j ∘ σ = rootVec (σ⁻¹ i) (σ⁻¹ j)`.
- `rootVec_injective`: for `i ≠ j`, `rootVec i j = rootVec k l` forces `i = k` and
  `j = l`, by evaluating at `i` and `j`.
- `perm_eq_one_of_rootVec_comp`: a permutation `σ` with `rootVec i j ∘ σ = rootVec i j`
  for all `i ≠ j` is `1`. If some `j ≠ i` exists, apply the hypothesis to
  `(σ i, σ j)` and use `rootVec_comp_perm` and `rootVec_injective`; otherwise every
  element equals `i`, in particular `σ i`.
- `rootVec_eq_cast`: `rootVec i j m = (rootVecInt i j m : ℚ)`.

## Lemmas about roots and coroots

- `corootFun_apply`: `corootFun Φ p x = Φ x p.1 - Φ x p.2` (by definition).
- `mem_permSubgroup`: membership unfolds to the existence of `σ`.
- `r_injective` and `corootFun_injective`: from `rootVec_injective`, and from
  evaluating `corootFun Φ p = corootFun Φ q` at `r p` (the value `2` forces the
  indices to agree).
- `corootFun_r`: `corootFun Φ p (r q)` is the difference of two entries of
  `rootVec q.1 q.2`; `corootFun_r_self`: `corootFun Φ p (r p) = 2`.
- `map_preReflection`: `Φ (x - corootFun Φ p x • r p) = Φ x ∘ swap p.1 p.2`, which is
  `comp_swap_eq` read through `Φ`.
- `preReflection_r`: `r q - corootFun Φ p (r q) • r p = r (reflIdx p q)`, by applying
  the injective `Φ` and `rootVec_comp_perm`.

## Lemmas about the root pairing

- `rootPairing_toLinearMap`, `rootPairing_root`, `rootPairing_coroot`,
  `range_rootPairing_root`: the pairing is `Dual.eval ℚ V`, the roots are `r` and the
  coroots are `corootFun Φ` (all by definition).
- `isRootSystem_rootPairing`: the root pairing is a root system (`IsRootSystem`), by
  Mathlib's `isRootSystem_mk''`. Its integrality hypothesis holds because the pairing
  of `r p` with the coroot of `q` is the integer
  `rootVecInt p.1 p.2 q.1 - rootVecInt p.1 p.2 q.2`. This is a theorem, not an
  instance, because it depends on the proof arguments `hΦ`, `hr` and `hsp`.
- `map_rootPairing_reflection`: `Φ (reflection p x) = Φ x ∘ swap p.1 p.2`; and
  `rootPairing_reflection_mem`: each reflection lies in `permSubgroup Φ`.
- `exists_mem_closure_reflection`: for every permutation `σ` of `n` there is `g` in the
  subgroup generated by the reflections with `Φ (g x) = Φ x ∘ σ`. The proof is
  induction on `σ` as a product of transpositions (`Equiv.Perm.swap_induction_on`):
  for `swap i j * f`, take `g * reflection (i, j)`.
- `closure_range_reflection`: the subgroup generated by the reflections equals
  `permSubgroup Φ`. One inclusion is `rootPairing_reflection_mem`. For the other,
  given `g` with permutation `σ`, the element of the previous lemma has the same
  `Φ`-coordinates as `g`, so equals `g` because `Φ` is injective.
- `weylGroup_map_weightHom`: the image of the Weyl group of `rootPairing hΦ hr hsp`
  under `RootPairing.Equiv.weightHom` is `permSubgroup Φ`. It combines
  `MonoidHom.domRestrict_range`, Mathlib's `RootPairing.range_weylGroup_weightHom`
  (the image is generated by the reflections) and `closure_range_reflection`. This is
  the formal counterpart of Milne's identification of the Weyl group with the
  symmetric group (C.25), stated as a subgroup of `GL(V)`.
