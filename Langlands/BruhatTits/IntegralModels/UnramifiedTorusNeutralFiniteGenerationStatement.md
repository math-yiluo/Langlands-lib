# Torus points modulo neutral integral points are finitely generated

`Langlands.BruhatTits.IntegralModels.UnramifiedTorusNeutralFiniteGenerationStatement.{u}`
is an unproved proposition. It isolates the finite-generation claim in the
proof of Kaletha–Prasad Corollary B.8.6 over the maximal unramified field.
This module supplies no proof.

## Exact formulation

Let `F : Type u` be a nonarchimedean local field, and put
`K = inertiaFixedField F` (its maximal unramified extension inside a
separable closure) and `O = fixedFieldIntegers F`. Let `T` be a group scheme
over `Spec K` which is a torus. Supply
`D : RelativeComponentModelData O K T`: a smooth full model, a smooth
neutral model with connected fibres, and a compatible inclusion representing
the actual relative identity component. Assume the full model's
integral-point image equals the character-valuation kernel
`characterValuationKernel (fixedFieldValuation F) T`, the common kernel of
the valuations of all rational characters, i.e. the maximal bounded
subgroup `T(K)^1`. The conclusion is that some finite set
`s ⊆ T(K)` satisfies

```text
Subgroup.closure s ⊔ D.neutral.integralPoints = ⊤.
```

Equivalently, `T(K)` is generated by finitely many elements together with
the neutral integral points `T^0(O)`, i.e. `T(K)/T^0(O)` is finitely
generated. The closure formulation avoids a quotient-group instance on
`rationalPoints T`. No affineness assumption on `T` is added beyond what
the model data provide. The statement is at arbitrary universe `u`.

## Source and provenance

The source is Kaletha–Prasad, *Bruhat–Tits Theory: A New Approach* (2023),
registered as `kaletha-prasad-2023-bruhat-tits-new-approach`, SHA-256
`05ad9a284a2577b34d1a270228b74dfb28f520561ae7772d8f38dddb78938732`.
The proof of Corollary B.8.6, printed p. 683 / PDF p. 714, claims that
`B^lft(Ô)/B^0(Ô)` is finitely generated. It argues that `B^ft(Ô)/B^0(Ô)` is
finite because `B^ft` is of finite type. By Proposition B.7.2,
`B^lft(Ô)/B^ft(Ô)` equals `B(K)/B(K)^1`. By Lemma 11.1.3, printed p. 422 /
PDF p. 453, the latter embeds into the finitely generated group
`X_*(B)_I`.

This statement is derived from that claim. It is posed over the
non-complete Henselian field `K` instead of its completion, and for every
supplied smooth model datum whose full integral points are the maximal
bounded subgroup. It does not use lft-Néron models: the source quotient
`B^lft(Ô)/B^0(Ô)` corresponds here to `T(K)` modulo the neutral integral
points.

## Remaining proof obligation

A proof must show that `T(K)/T(K)^1` is finitely generated, for example via
the injective valuation map into `Hom(X^*(T)^I, ℤ)` (with `I` the inertia
group, which is the full absolute Galois group of `K`). It must also show that the neutral
integral points have finite index in the full integral points. For the
latter, use the finiteness of the component group of the special fibre of
the full model, together with Hensel lifting over the strictly Henselian
ring `O`.
