# Integral root and centralizer intersections

This internal supporting unit constructs the subgroup
`IntegralModel.rootCentralizerIntegralPoints`: the subgroup generated by the
intersections of the model's integral points with every actual generic root
subgroup and with the actual whole-torus centralizer. It is contained in the
model's integral points.

The generation theorem assumes a strictly Henselian local integral domain,
a smooth affine integral model with geometrically connected fibres, a connected
reductive generic group, a maximal split torus in that generic group, and an
actual compatible integral split torus. Under these hypotheses the constructed
subgroup equals all integral points. The common universe parameter is arbitrary.
The integral model is not assumed reductive.

The proof chooses coordinates on the compatible integral split torus and
transports generic maximality through the specified torus and ambient
isomorphisms. The published relative root system theorem supplies the actual
generic root system. A cocharacter of the generic coordinate torus with the
same centralizer as the whole torus is expressed by integral exponents and
lifted to the integral coordinate torus. Actual root-functor base change and
the commuting generic isomorphism square place each integral root section in
the prescribed generic root intersection. Dynamic centralizer base change,
the chosen cocharacter equality and whole-torus centralizer transport place
each integral centralizer section in the prescribed centralizer intersection.
`RelativeRoot.eq_top_of_exponentRoots_and_dynamicCentralizer` applied to the
inverse image under the model's integral-point homomorphism proves generation.

The auxiliary `SubgroupFunctor.baseChangeSectionHom_mem` records the actual
restriction of a section into a base-changed subgroup functor. It follows
directly from the definition of subgroup base change and stability under
precomposition.

This is derived content using the actual root, centralizer, lattice and
integral-section APIs. It is a generation result for supplied compatible data;
it does not construct the full fixer model or prove the host parahoric-model
statement.
