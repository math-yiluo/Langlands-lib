# Quotient-image upper bounds along prescribed cocharacter rays

This internal supporting result is conditional on
`UnramifiedRootPositiveReductionStatement`, whose proof is a separate task.
It concerns the actual schematic image of a supplied generic-identity model
comparison in a supplied reductive quotient. All declarations have arbitrary
universe `u`.

The target is the neutral model of supplied relative component data, characterized
at an apartment point `x`. A split integral apartment torus `A` with closed
inclusion is supplied in that model. Its specialization identifies any prescribed
residue cocharacter with a generic cocharacter. For any positive real parameter,
let `y` be the corresponding point on its ray from `x`. A smooth source model
with geometrically connected fibres is characterized at `y`; an actual comparison
to the target and a split integral apartment torus `B` in the source are supplied.
No compatibility of `A` and `B` under the comparison is required.

The implemented argument first treats integral sections. The source integral
points are generated by their intersections with all actual generic root groups
and with the whole generic torus centralizer, using `B`. Each generator is also
integral in the target and hence lifts into the actual root or centralizer model
constructed from `A`. Nonnegative root reductions belong to the dynamic
parabolic, including roots with pairing zero. Centralizer reductions belong to
its dynamic centralizer. For a negative root, the filtration translation formula
puts the source root point in positive target depth. The explicit
positive-reduction premise then puts its reduction in the radical, which the
quotient kills. Subgroup generation and injectivity of the target integral-point
map give the claim for every source integral section.

Henselian smooth reduction lifts every source residue point to such a section.
The algebraically closed residue-field containment theorem promotes this point
calculation to containment on every scheme test. The universal property of the
actual schematic image supplies the stated image upper bound.
`HasPrescribedRayQuotientImageContainment` packages this conditional conclusion
for every prescribed cocharacter, positive parameter, and supplied source model,
torus and comparison; `hasPrescribedRayQuotientImageContainment` proves it.

No incident-facet condition or smallness of the parameter is needed for this
upper bound once the actual comparison is supplied. The result does not prove
the positive-reduction premise, existence of a comparison or supplied tori,
equality of the image with the parabolic, or the host facet–parabolic order
bijection.

The provenance is internal: the proof composes integral root/centralizer models,
integral root/centralizer generation, the prescribed cocharacter direction and
lattice specialization, dynamic functoriality, actual quotient kernels,
Henselian reduction, closed subgroup containment, and schematic-image
functoriality. It makes no new original-literature assertion.
