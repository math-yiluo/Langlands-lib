# Transporting generated model images to generic points

This is internal, derived content for the unramified parahoric-model proof. It
uses compatible actual integral models, generic-point naturality, injectivity
of generic evaluation on an affine model over a domain, and Mathlib subgroup
image and index identities. It invokes no new geometric existence theorem or
external-source assertion.

Let `N` be an integral model of a group `G` over a fraction field `K` of a
commutative domain `R`. For an arbitrary family of groups `H_j`, integral
models `M_j`, generic homomorphisms `f_j : H_j → G`, and actual compatible
model maps `φ_j : M_j → N`, put

```text
V = supremum_j range(φ_j on integral sections),
U = supremum_j image(f_j on M_j.integralPoints).
```

These suprema are the subgroups generated by the corresponding image
subgroups; the family need not be finite or nonempty. The definition
`IntegralModel.generatedIntegralImages H M f` names the subgroup `U`
using the supplied models and generic homomorphisms. It does not require
compatible maps into a common integral model merely to define that subgroup.
The transport lemmas additionally require those maps. `Hom.map_sectionRange`
uses the exact generic compatibility equation to identify each section image
under `N.integralPointMap` with its specified generic image. The theorem
`map_iSup_sectionRange` takes their supremum and proves `map(V) = U`.

The generic-point map of an affine model over a domain is injective.
`comap_iSup_integralPoints` therefore proves `comap(U) = V`.
`iSup_sectionRange_finiteIndex_iff` uses Mathlib's `index_comap` identity to
show that `V` has finite index in **all** integral sections of `N` if and
only if `U` has finite relative index in `N.integralPoints`. Here relative
index means the index of `U ∩ N.integralPoints` in `N.integralPoints`.
Compatibility already places every generating image in that ambient
integral-point subgroup, so `U` itself lies in it.

If `R` is local, `congruenceKernelAt_le_iSup_sectionRange_iff` additionally
identifies containment of the actual kernel of reduction modulo a positive
maximal-ideal power in `V` with containment of its generic image
`N.congruenceSubgroupAt m` in `U`. It uses injectivity to reflect subgroup
inclusion. This is a comparison of the existing quotient-ring kernels,
without any claim about a point topology.

Finally, for `D : RelativeComponentModelData R K G`, the theorem
`iSup_integralPoints_eq_neutral_of_sections` transports a supplied equality
`V = D.neutralSections` to `U = D.neutral.integralPoints`. Its proof maps
the supplied equality through `D.full.integralPointMap` and uses the
published `D.neutralPoints_eq`.

The module makes the section-level connected-generation criterion usable
with generic-point hypotheses. It does not establish that criterion,
construct a torus or root model, extend a generic morphism, or identify the
generated subgroup with the intersection of `E.zeroPoints` and a building
fixer. Those are retained obligations of the parahoric-model construction.
