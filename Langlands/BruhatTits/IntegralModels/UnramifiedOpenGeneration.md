# Actual open root-centralizer generation in a neutral unramified model

This internal derived unit combines the constructed integral centralizer,
the proved equality of actual root intersections in the neutral model,
noncompact adic congruence cofinality, and general topological-field
root-centralizer generation. All fields retain arbitrary universe `u`.

Let `F` be a nonarchimedean local field, `K` its actual inertia fixed field,
and `R` its actual unramified integer ring. Supply maximal-unramified
building data `C`, relative-component model data `D`, an apartment subset
`Ω`, and an equality identifying `D.full.integralPoints` with the actual
character-valuation kernel intersected with the pointwise fixer of `Ω`.

`unramifiedNeutralRootCentralizerGroup` is the subgroup of the original
`G(K)` generated by the image of the integral points of the constructed
neutral centralizer model and the actual sharp fixer `C.sharpFixer Ω`.
The centralizer's generic arrow is exactly `C.centralizer.j`.
`unramifiedNeutralRootCentralizerGroup_le_neutral` proves containment in
`D.neutral.integralPoints`, using the actual compatible centralizer map and
the proved containment of every sharp-fixer generator.

`isOpen_unramifiedNeutralRootCentralizerGroup` proves openness for the
published `fixedFieldTopology F` on `K` and the canonical affine
rational-point topology on `G(K)`. The neutral model's integral-point image
is open by the proved integral-image openness theorem. Its intersection
with each actual root carrier is exactly the corresponding root fixer, so
each root fixer is open in that carrier's subspace topology. The actual
centralizer model also has an open integral-point image. The general-field
root-centralizer theorem therefore makes their generated subgroup open.
The proof uses the equality between the spectral-norm topology and the
published fixed-field topology to discharge the topological-field inputs.

`exists_congruenceSubgroupAt_le_unramifiedNeutralRootCentralizerGroup`
then places one actual positive congruence subgroup of the original
`D.full` inside this generated subgroup. It applies the proved unramified
adic cofinality theorem to the open identity neighborhood just obtained.

No boundedness or nonemptiness of `Ω` is needed for these conclusions.
The proof uses neither compactness of `R` nor local compactness of `K`.
It does not prove finite relative index, identify this centralizer subgroup
with a torus-Iwahori generated subgroup, or identify all neutral integral
points with an arbitrary supplied zero datum. Those are separate remaining
obligations in the host parahoric-model theorem.
