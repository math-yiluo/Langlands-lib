# The derivative root datum of a facet in a supplied KP model

This focused definition unit expresses Kaletha–Prasad, *Bruhat–Tits theory: a new approach* (2023), Axiom 4.1.22(6), printed p.164 / PDF p.195. The November 2024 corrections, PDF p.27, retain Axiom 4.1.22 in the corrected ten-axiom Definition 4.1.26. It defines the clause on supplied actual building and model data and makes no existence or structural theorem assertion.

`IntegralTorusData.genericCocharacterEquiv` and `specialCocharacterEquiv` are the actual cocharacter base-change equivalences of the supplied integral split torus. The generic equivalence additionally composes with the specified generic-fibre isomorphism to the original maximal split torus. `cocharacterSpecialization` passes from the generic cocharacter lattice to the special one through that integral lattice, just as `characterSpecialization` does for characters. These are derived constructions implementing the source's common torus identifications. The intrinsic theorem `latticePairing_generic` applies pairing invariance under the generic isomorphism and then under base change. `latticePairing_specialization` lifts a character and cocharacter to their unique integral preimages, cancels the two inverse equivalences, and applies pairing invariance for the special and generic fibres.

`facetDerivativeRoots B F` consists of the actual relative roots `a` of `B.i` for which some actual affine root of `B.affineRoots` has derivative `rootForm B.i a` and vanishes on every point of `F`. This realizes the source's derivative image of the affine roots vanishing on the facet. The ambient apartment is the existing quotient of the real cocharacter space by the common root kernel; `rootForm` is the descended evaluation functional. No arbitrary root list or affine root system is supplied.

The supplied `D : RelativeRootReflectionData B.i` records a cocharacter for each actual generic relative root, pairing to two, together with a point of the actual normalizer acting by its integral reflection formula on every character. `facetDerivativeRootCorootGraph` restricts those corresponding root-coroot pairs to `facetDerivativeRoots` and transports both entries by the same integral torus. This keeps the correspondence between roots and coroots rather than comparing their two sets independently. The existence of the original integral reflection data is a retained structural obligation; the definition does not supply it.

`RelativeComponentModelHom.HasFacetDerivativeRootDatum` uses the actual source integral torus's image in the actual target reductive quotient, through `φ.quotientTorusInclusion Q T`. It requires a finitely indexed Mathlib root datum on that torus's character and cocharacter lattices which is `IsRootDatumOf` this actual inclusion and whose set of matching root-coroot pairs is exactly the derivative graph. The imported `IsRootDatumOf` fixes the actual integer lattice pairing, the full set of actual adjoint roots and actual normalizer witnesses for the root reflections. Thus the clause compares the entire root datum, with the prescribed root-coroot matching. There is no reducedness assumption on the original relative root system and no splitness assumption on the ambient reductive group.

The surrounding full validity interface must supply actual facets, their appropriate source and target model indices, the integral split-torus clause, validity of `Q` as the maximal reductive quotient, and the maximal-split-torus clause. In the direct model of `F`, the morphism is the identity map of that model; allowing an incident source model uses the common torus already required by Axiom 4.1.22(2). This focused formula does not assert those surrounding conditions, any existence result, or complete corrected Definition 4.1.26 validity.
