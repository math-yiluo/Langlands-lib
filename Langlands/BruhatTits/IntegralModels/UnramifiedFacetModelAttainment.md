# Actual quotient attainment by supplied full-facet models

This internal composition works at arbitrary universe `u`. It converts conditional attainment at a building point into attainment by every supplied smooth, geometrically connected model characterized by the zero fixer of an entire incident full building facet. It also constructs a generic-identity comparison from each such model. The actual schematic image of every such comparison followed by the supplied reductive quotient projection equals the prescribed parabolic subgroup functor on every scheme test.

The hypotheses are explicit: maximal-unramified building data `C` for the actual group `G`, any zero datum `E`, relative component model data `D` characterized at an apartment point `x`, a reductive special-fibre quotient `Q`, `UnramifiedRootPositiveReductionStatement` and `MaximalUnramified.ZeroFacetNoInversionsStatement`. The last two propositions remain premises; this module does not prove them.

The module first proves `UnramifiedZeroDatum.zeroFixer_eq_of_nonempty_subset_buildingFacet`. For any nonempty subset `Ω` of a full building facet `Fc`, its zero fixer equals that of `Fc`. If `g` fixes `Ω`, choose `x ∈ Ω`. Translation carries `Fc` to another full facet containing `g • x = x`. The proved full-facet partition identifies that translate with `Fc`. The supplied no-inversions proposition, through its proved all-facet consequence `mem_pointwiseFixer_of_isFacet`, shows that `g` fixes `Fc` pointwise. The reverse inclusion follows from `Ω ⊆ Fc`. The singleton specialization `zeroFixer_singleton_eq_buildingFacet` applies this to a point and its chosen full facet.

The comparison-existence theorem `nonempty_hom_of_incidentBuildingFacet` does not assume no inversions or positive-root reduction. An element integral in a supplied smooth model of the upper full facet fixes the lower full facet, by `pointwiseFixer_le_of_facetPrecedes`, and hence fixes the given base point `x`. It also belongs to `E.zeroPoints`, so the target characterization places it in `D.neutral.integralPoints`. The proved `smoothHomExtension`, specialized to the maximal-unramified integers by `fixedField_hasSmoothHomExtension`, extends the generic identity to a model homomorphism. Its arithmetic ring hypotheses are supplied by that published specialization.

For a prescribed parabolic inclusion, `exists_incidentFacet_model_quotientImage_eq_parabolic` takes the point `z` already chosen by `exists_incidentBuildingPoint_quotientImage_eq_parabolic` and uses `C.buildingFacetAt z`. The singleton zero-fixer equality puts every supplied full-facet model under the earlier point-model theorem. The comparison-existence theorem supplies nonemptiness of the compatible homomorphism type; the earlier theorem then identifies the actual image for every comparison. The full facet is selected before any source model or comparison. `HasIncidentFacetModelQuotientAttainment` packages this assertion, and `hasIncidentFacetModelQuotientAttainment` proves it.

The source models remain supplied universally; no model-existence theorem is asserted. This module does not assert descent, injectivity, order reflection or the host descended order bijection. Its provenance is internal composition of the preceding conditional building-point attainment, the published full-facet partition and fixer-incidence theorems, the published no-inversions proposition's conditional facet consequence, and the proved strictly Henselian homomorphism extension theorem. It makes no new original-literature assertion.
