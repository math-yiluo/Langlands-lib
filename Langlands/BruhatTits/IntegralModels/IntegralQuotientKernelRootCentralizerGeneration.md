# Actual root and centralizer generation of a special-fibre quotient kernel

This derived internal result keeps the original generic point group of a smooth
affine model over a local domain. The model has geometrically connected fibres
and a compatible integral split torus whose generic image is a maximal split
torus in a connected reductive generic group. The special-fibre map is smooth
and surjective, its target is smooth connected affine, and its full
scheme-theoretic kernel is connected and unipotent.

`rootCentralizerQuotientKernelPoints` is the subgroup generated by intersections
of the generic image of the full reduction–quotient kernel with every actual
generic root group and with the whole generic torus centralizer.
`IntegralSplitTorusData.rootCentralizerQuotientKernelPoints_eq` identifies this
subgroup with that entire generic kernel image. The corresponding containment
criterion bounds the full image from bounds for those root and centralizer
intersections. No Henselian or residue-closedness assumption is used.

The coordinate helper applies the original integral dynamic factorization of
the quotient kernel. Each dynamic-unipotent intersection is bounded using the
integral ordered-root-chart quotient-kernel theorem, once for the exponent
cocharacter and once for its negative. A generic cocharacter with the full
split-torus centralizer supplies the middle factor. The actual generic root
system is derived from reductivity and maximality, rather than assumed as an
extra root-chart premise. Restriction to the generic fibre and the exact torus
and group isomorphism square transport all original integral factor bounds to
the original generic root groups and torus centralizer. A coordinate
trivialization of the supplied integral split torus then gives the intrinsic
statement.

This combines the previously proved integral quotient-kernel factorization,
smooth quotient coordinate reflection and local root generation with the
existing compatible-integral-torus transport. It asserts generation of the full
quotient-kernel image and does not identify a supplied quotient with a reductive
quotient or assume Bruhat–Tits model comparisons.
