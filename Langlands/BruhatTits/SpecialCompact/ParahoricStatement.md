# The parahoric subgroup lies in the compact stabilizer: statement target

Worker 1249, task `219b673d-b7f3-47fb-9019-d1642687d4ac`.

This module states
`Langlands.BruhatTits.SpecialCompact.ParahoricLeCompactStabilizer`, a
proposition-valued definition, not a proof.

## Statement

For every nonarchimedean local field `F` (both characteristics), every
`F`-group `G` with `IsAffineHom G.X.hom`, all parahoric building data
`P : ParahoricBuildingData G` and every point `x : P.Apartment`,

`P.parahoricAt x ≤ P.apartment.specialCompactSubgroup x`.

The objects are all published Library definitions; this module introduces no
new subgroup.

- `P : ParahoricBuildingData G` (Worker 1238's module
  `Langlands.Geometry.Building.KPParahoric`) extends the published
  `ValuationBuildingData G`. That structure bundles: `G` connected reductive; a
  maximal split torus `i : S → G`; the `N(F)`-stable equipollence class `A(S)` of
  valuations of the root datum as `P.apartment : KPApartmentData i
  (localFieldOrder F)`; the actual centralizer `Z = Z_G(S)` as
  `P.centralizer : CentralizerDatum i`; and axiom V 6 on all of `Z(F)`. To
  this, `P` adds `P.zeroDatum : ZeroSubgroupDatum i P.centralizer.j`, the data of
  KP Definition 2.6.23 for `Z(F)^0` and `G(F)^0` relative to the same `S` and
  `Z`.
- `P.parahoricAt x = P.parahoric {x}` is
  `P_x = G(F)^0_x`. It is defined as the join (the generated subgroup)
  `j(Z(F)^0) ⊔ G(F)^♯_x`. Here `Z(F)^0 = P.centralizerZero` (KP Definition
  2.6.23(2)), `j = P.centralizer.j`, and `G(F)^♯_x = P.sharpFixer {x}` is
  generated by the root fixers `U_{a,x,0}` (KP Definition 7.4.1(1),(2),(4)).
- `P.apartment.specialCompactSubgroup x` is Worker 1229's
  `D.specialCompactSubgroup x` (module
  `Langlands.Geometry.Building.SpecialCompact`) for `D = P.apartment`. By
  definition it is `D.compactStabilizer (D.apartmentMap x) = G(F)^1 ∩ G(F)_x`,
  where `G(F)^1` is the common kernel of the normalized absolute values of all
  rational characters (`rationalCommonNormKernel G`, KP Notation 2.6.15) and
  `G(F)_x` is the stabilizer of the image of `x` in the reduced building. When
  `D.IsSpecialApartmentVertex x` holds it is the `K_0` of this task. It is the
  same definition as in `SpecialCompactProperties`,
  `SharpFixerLeCompactStabilizer` and the existence target
  `SpecialMaximalCompactExistence`.

The statement is quantified over every apartment point `x`, special or not.
The case of a special vertex is `P_x ⊆ K_0`.

## Role and provenance

The task contract asks for `P_x ⊆ K_0`. This is the actual statement, now
that `Z(F)^0` and `P_x` can be formed. It completes the earlier factor
`SharpFixerLeCompactStabilizer` (`G(F)^♯_x ⊆ K_x`, module
`Langlands.BruhatTits.SpecialCompact.SharpFixerStatement`).

The inclusion is derived from KP and is not a numbered result there. By
Proposition 7.6.4(1), `P_x` is the stabilizer of `x` in `G(k)^0`. By
Definition 2.6.30, `G(k)^0 ⊆ G(k)^1`. Hence `P_x ⊆ G(k)^1 ∩ G(k)_x = G(k)^1_x`,
the group of Theorem 4.2.15. Only the inclusion `P_x ⊆ G(k)_x` from
Proposition 7.6.4(1) is used, not the equality.

## Why the statement is expected to hold for every `P`

The target is universal over all `P`, so it must hold for data that satisfy
only the bundled conditions. The expected proof uses nothing beyond them.

1. `G(F)^♯_x ⊆ K_x`. This is the statement `SharpFixerLeCompactStabilizer` for
   `D = P.apartment`. `G(F)^♯_x` fixes the image of `x` (published
   `sharpFixer_le_reducedFixer`), and every rational character is trivial on
   each actual root group, so the root-group points lie in `G(F)^1`.
2. `Z(F)^0 ⊆ Z(F)^1`, KP's "immediate" inclusion in the proof of
   Lemma 2.6.27, combined with `Z(F)^1 = Z(K)^1 ∩ Z(F)`. Here
   `Z(F)^0 = Z(K)^0 ∩ Z(F)` (preimage under extension of scalars to the
   maximal unramified extension `K`). `Z(K)^0` is generated by the image of
   `Z_sc(K)` and the norm image `N_{L/K}(T(L)^b)` for a maximally split
   maximal torus `T` of `Z_K` and a finite Galois splitting field `L`. A
   rational character `χ` of `Z` is trivial on the image of the simply
   connected semisimple cover. On `N_{L/K}(t)` it takes the value
   `N_{L/K}(χ(t))`, whose valuation is trivial because `χ(t)` has trivial
   valuation when `t ∈ T(L)^b`.
3. `j(Z(F)^1) ⊆ K_x`. This is the published theorem
   `ValuationBuildingData.map_mem_compactStabilizer`, a consequence of the
   bundled axiom V 6 on `Z(F)`.
4. `K_x` is a subgroup, so it contains the join of `j(Z(F)^0)` and
   `G(F)^♯_x`.

This argument is a plan; no proof is supplied here.

## The distinction between `P_x`, `K_0` and the full fixer

The statement is an inclusion and the inclusion can be strict. KP
Example 4.2.16 gives one instance: for `PGL_2` the stabilizer `G(k)^1_x` of the
barycenter `x` of the standard chamber is generated by the standard Iwahori
subgroup and the element `[[0, 1], [π, 0]]`. The valuation of its
determinant is odd (well defined modulo 2), so the element is not in
`G(k)^0 ⊇ P_x`, and `P_x ⊊ G(k)^1_x`. That point is not a vertex; the example
illustrates the inclusion only. No equality, index or strictness claim is
stated in Lean. The full fixer `G(F)_x` (`P.fixer (P.apartmentMap x)`)
remains a third, distinct definition. The published
`ValuationBuildingData.compactStabilizer_le_fixer` gives `K_x ⊆ G(F)_x`.
Remark 7.4.2 (`G(k)^♯_x ⊊ G(k)^0_x` for `SL_2` at a chamber barycenter) shows
that `G(F)^♯_x` can be strictly smaller than `P_x`, so the earlier factor
statement does not imply this one.

## What this target does not assert

- It does not assert that `ParahoricBuildingData G` is inhabited: neither the
  building data nor a zero-subgroup datum for the same `S` and `Z` is claimed to
  exist.
- It does not discharge the task's full existence target for data satisfying
  the corrected KP Definition 4.1.26 (corrections, PDF p. 27). The bundled
  conditions of `ValuationBuildingData` omit V 7, AS 5 and the other axioms
  listed there. The supplementary existence target `SpecialMaximalCompactExistence`
  does not provide a zero datum either, so it is not linked to this statement
  in Lean.
- It does not state `P_x = G(F)^0 ∩ G(F)_x` (Proposition 7.6.4(1)), the
  normality or finite index of `G(F)^0` in `G(F)^1` (Lemma 2.6.29), or any
  property of `P_x` beyond the inclusion.
