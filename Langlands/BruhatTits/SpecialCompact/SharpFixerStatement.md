# The sharp fixer lies in the compact stabilizer: statement target

Worker 1249, task `219b673d-b7f3-47fb-9019-d1642687d4ac`.

This module states
`Langlands.BruhatTits.SpecialCompact.SharpFixerLeCompactStabilizer`, a
proposition-valued definition, not a proof.

## Statement

For every nonarchimedean local field `F` (both characteristics), every
`G` with `hG : IsConnectedReductive G`, and every maximal split torus
`i : S.toGrp ⟶ G` (`hi : IsMaximalSplitTorus i`): for all valid apartment data
`D : KPApartmentData i (localFieldOrder F)` and every point `x : D.Apartment`,

`D.sharpFixer {x} ≤ D.compactStabilizer (D.apartmentMap x)`.

Here `D.sharpFixer {x}` is the published `G(F)^♯_x`. It is the subgroup
generated by the groups `U_{a,x,0} = U_a(F) ∩ D.filtration x a 0` for the
relative roots `a` (KP Definition 7.4.1(1),(2), PDF page 286, in Worker
1238's `KPBuilding`). The right side is the published compact stabilizer
`D.compactStabilizer (D.apartmentMap x) = G(F)^1 ∩ G(F)_x` of the image of
`x` in the reduced building. It is by definition Worker 1229's
`D.specialCompactSubgroup x` (module `Langlands.Geometry.Building.SpecialCompact`),
the `K_0` of the existence target when `x` is a special vertex. The instances
`IsAffineHom G.X.hom` and `Mono i.hom.hom.left` come from `hG` and `hi`.

## Role and provenance

The task asks for `P_x ⊆ K_0`, where `P_x = G(k)^0_x = Z(k)^0 · G(k)^♯_x` is
the parahoric subgroup (KP Definition 7.4.1(4)). The actual `Z(F)^0` (KP
Definition 2.6.23) and `G(F)^0` are not yet available in the Library, so
`P_x` cannot be formed. This target states the factor of `P_x` that can be
formed now: `G(F)^♯_x ⊆ K_0`. Once `Z(F)^0` exists, a follow-up target
`Z(F)^0 ⊆ K_0` together with this one gives `P_x ⊆ K_0`. That follow-up is
not stated here, and no substitute for `Z(F)^0` is introduced.

This is a conditional structural statement on supplied valid data, in
addition to the existence target `SpecialMaximalCompactExistence`; it does
not replace it. Unlike the full special-compact properties, it is expected to
hold for every published `KPApartmentData` and every apartment point, special
or not. By the published `sharpFixer_le_reducedFixer`, `G(F)^♯_x` fixes the
image of `x`. The remaining point is that the actual root-group points lie in
`G(F)^1`, the common kernel of the normalized absolute values of all rational
characters: a rational character is trivial on each actual root group. This
target is derived from KP Definition 7.4.1 and the definition of `G(k)^1_x`
in Theorem 4.2.15. Its formulation as a separate inclusion is internal: it
isolates the part of `P_x ⊆ K_0` that does not need `Z(F)^0`.
