# Restricting actual root valuations to the prescribed Levi

`leviRestrictedRootFunctionFamily iM j φ` evaluates the original ambient family along the original Levi point map for every actual Levi root, and takes infinity off the Levi root support. It retains the same character lattice and agrees with the ambient value for every Levi rational point, including points outside the corresponding root group. This total normalization matches the published `RootFunctionFamily` and `IsRootDatumValuation` conventions.

The setting is an arbitrary field and universe `u`, a connected reductive ambient group, its prescribed maximal split torus, and a closed representative of a cocharacter centralizer with the same torus factored through it. Affineness and finite type of the representative are explicit. No building assignment, availability premise, splitness of the ambient group or restriction on characteristic is used.

The finite-level filtrations are literal preimages under the actual inclusion (`leviRestrictedRootFiltration_eq_comap`), and their images are exactly the ambient filtrations (`image_leviRestrictedRootFiltration`). The value images on corresponding root groups are equal (`image_leviRestrictedRootFunctionFamily`). The V3 generating union has exactly the same image (`image_leviRestricted_commutatorGenerators`), because every occurring root combination has zero pairing with the defining cocharacter.

`leviRestricted_isRootDatumValuation` proves every clause of the original V0–V5 predicate. Normalization follows from closed-embedding root pullback. V0 follows from equality of value images. V1 at finite levels pulls back the actual ambient subgroups, and its infinity clause uses injectivity of the original closed point map. For V2, the same-torus normalizer map retains the full reflection action, so the ambient reflection formula applies. For V3, subgroup commutators and algebraic subgroup closures map under the original point homomorphism; the finite-level image and generating-union equalities identify the ambient formula, and injectivity reflects it. V4 uses the same actual doubled root and its unchanged character. V5 maps the original opposite-root factors and their normalizer element into the ambient group. The companion `leviValuationRestriction` bundles this construction as a map between the actual valuation subtypes.

`leviRestricted_isSplitTorusCompatible` retains the same field valuation and the same split torus, by the literal torus factorization. `leviRestrictedRootFunctionFamily_vadd` and `leviRestrictedRootFunctionFamily_smul` prove translation and actual normalizer equivariance. The latter uses invariance of the actual Levi roots under its Weyl action, so normalization outside the root support is also respected.

The source is KP Lemma 6.7.1(1)–(3), *Bruhat–Tits theory: a new approach* (2023), printed page 233/PDF264, registered `kaletha-prasad-2023-bruhat-tits-new-approach`, SHA256 `05ad9a284a2577b34d1a270228b74dfb28f520561ae7772d8f38dddb78938732`. The implementation expands the source's root-restriction argument into the existing normalized actual-group API. Library inputs include `relativeRoots_centralizer_factor dynamicLie`, the actual closed-embedding and root-image lemmas in `LeviRootTransport`, and the published relative-root-system proof for root negation. No unproved proposition target is assumed.

The apartment class and projection are constructed in `LeviApartmentRestriction`. Neither this module nor that class construction yet proves full centralizer omega compatibility, preservation of special vertices or equality of special compact subgroups.
