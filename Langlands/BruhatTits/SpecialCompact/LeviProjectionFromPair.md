# The canonical Levi projection from a restriction pair

This derived construction works with any supplied ambient and Levi valuation apartments at the same maximal split torus, not only the literal image-class construction. `leviProjectionFromPair` is the affine map whose linear part is the published quotient projection and which sends the specified ambient point to the specified Levi point. It is defined by translating the source point to the origin, applying that linear map and translating to the chosen target point.

If the base pair satisfies the existing `IsLeviRestriction`, translation by the same full real cocharacter vector proves literal restriction at every pair of points on this map. Normalization at infinity off the actual root support identifies each resulting target valuation with the normalized restricted root-function family on all characters. The published normalizer action on that family proves normalizer equivariance. Surjectivity follows from the surjective quotient linear map.

For any literal restriction pair, each finite-depth Levi filtration maps into the ambient filtration at the same depth. This uses the original closed inclusion, its actual root-group image comparison and the defining valuation equality. Taking the subgroup generated by all depth-zero root filtrations yields the sharp-fixer inclusion for that pair.

This is an internal affine and group-theoretic deduction from the already implemented quotient projection, root transport and valuation restriction. It does not assume full building availability or assert a compact-stabilizer equality, specialness, vertexhood or a simultaneous basis.
