# Intrinsic locally constant scalar sheaves

This constructs the scalar ring sheaf in David Renard, *Représentations des groupes réductifs p-adiques*, French version dated 9 July 2026, registered as `renard-2026-representations-groupes-reductifs-padiques`, printed pp.38–39 / PDF pp.44–45, the example following II.2.4. Renard's original example has complex coefficients on a totally disconnected space. `basisSheaf B ℂ` and `allOpenSheaf X ℂ` are that specialization. Allowing any unital ring, including noncommutative rings, and any supplied topology is an internal generalization: neither the pointwise gluing argument nor local constancy uses those additional hypotheses.

The section carriers and restrictions remain exactly the actual `LocallyConstant U R` rings and `comapRingHom` pullbacks from `LocallyConstantScalarPresheaf`. The intrinsic ring-sheaf package consists of `basisRingPresheaf B R`, its actual forgetful composite `rawPresheaf B R`, and the proved `basisSheaf B R`. `basisSheaf_forget` states their literal forgetful identification. No ring-sheaf category or replacement function model is introduced.

The implemented proof is direct. `compatible_value` refines the actual open intersection at a point using the published `OpenBasis.exists_subset`. The intrinsic `Compatible` equality on that smaller basis open then gives equality of the original values at the point. This requires no intersection-closure property of the chosen basis. `glueFunction` chooses a covering member separately at each point. `glueFunction_eq` proves that its value agrees with every member containing that point. `glueFunction_isLocallyConstant` applies the existing generic `Langlands.Sheaf.Equivariant.LocallyConstantSheaf.localPredicate X R`: the restriction to each actual cover member equals its given locally constant function, so locality proves the chosen function locally constant. The imported predicate has no group, action, module, or coefficient topology assumptions.

`glue` is therefore an actual locally constant function. `glue_restrict` proves the actual ring-restriction equation on every original cover member. `familySheafCondition` proves existence and uniqueness for the published intrinsic family condition; uniqueness is pointwise, evaluating the restriction equation on a cover member containing the point. The space, coefficient and cover-index universes are independent `u`, `r`, and `w`; the function carriers live in `Type (max u r)`. There is no `Small` or bound on the index universe. `sheafCondition` converts this result to the literal published set-cover `SheafCondition`, and `isNormalized` derives empty normalization from that condition. `normalizedPresheaf` and `basisSheaf` bundle these proved properties.
