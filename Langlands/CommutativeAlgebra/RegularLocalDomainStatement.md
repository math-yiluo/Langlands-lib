# Regular local rings are domains

`Langlands.CommutativeAlgebra.RegularLocalDomainStatement.{u}` is the following
`Prop`-valued definition:

```lean
∀ (R : Type u) [CommRing R], IsRegularLocalRing R → IsDomain R
```

It says that every commutative ring `R` that is a regular local ring is a
domain. This is Lemma 10.106.2 of the Stacks Project (Tag 00NP), stated for
every `R` in one arbitrary universe `u`.

## The Mathlib notions used

The module imports only `Mathlib.RingTheory.RegularLocalRing.Defs`. It uses
Mathlib's `CommRing`, `IsRegularLocalRing` and `IsDomain` unchanged and
introduces no new notion.

- `IsRegularLocalRing R` is a class that extends `IsLocalRing R` and
  `IsNoetherianRing R`. Its one further field, `spanFinrank_maximalIdeal`, says
  `(maximalIdeal R).spanFinrank = ringKrullDim R`. Here `spanFinrank` is the
  least number of elements generating the maximal ideal, a natural number, and
  `ringKrullDim R : WithBot ℕ∞` is the Krull dimension of `R`. So the equality
  also says that the Krull dimension is finite. Mathlib's docstring describes the
  class as "its maximal ideal can be generated by `dim R` elements".
  `IsRegularLocalRing.iff_finrank_cotangentSpace` gives the equivalent condition
  `dim_κ(m/m²) = dim R` for Noetherian local rings.
- `IsDomain R` extends `IsCancelMulZero R` and `Nontrivial R`. For a
  commutative ring it says that `0 ≠ 1` and that `R` has no zero divisors.
  Since `IsLocalRing` already extends `Nontrivial`, the content of the
  conclusion is the absence of zero divisors.

The hypothesis `IsRegularLocalRing R` is an explicit argument, not an instance
binder, so a proof must install it as an instance itself if it needs one. The
conclusion refers to the given `CommRing R` structure.

## Agreement with the Stacks definition

Mathlib marks `IsRegularLocalRing` with `@[stacks 00KU]`. Stacks Definition
10.60.10 (Tag 00KU) calls a Noetherian local ring `(R, m)` of dimension `d` a
regular local ring if `m = (x_1, ..., x_d)` for some `x_1, ..., x_d` in `m`. The
two definitions agree for every Noetherian local ring:

- Krull's height theorem gives `ringKrullDim R ≤ (maximalIdeal R).spanFinrank`
  (Mathlib's `ringKrullDim_le_spanFinrank_maximalIdeal`). So equality holds
  exactly when `spanFinrank ≤ dim R`.
- If `m` is generated by `d = dim R` elements, then `spanFinrank ≤ d`, by
  `Submodule.spanFinrank_span_le_ncard_of_finite`.
- Conversely, if `spanFinrank = dim R`, then `m` is generated by a finite set
  of exactly that many elements, by
  `Submodule.FG.exists_span_finset_card_eq_spanFinrank` (the maximal ideal is
  finitely generated because `R` is Noetherian).

## Scope

The universe `u` is arbitrary; the Stacks Project does not track universes. No
hypothesis is added beyond regularity: there is no restriction on dimension,
characteristic, completeness, excellence or residue field. Fields (dimension 0,
with maximal ideal generated by no elements) and discrete valuation rings are
included. The statement says nothing about non-local regular rings
(`IsRegularRing`) or about unique factorization.

## Original source

The original is Stacks Project Lemma 10.106.2
([Tag 00NP](https://stacks.math.columbia.edu/tag/00NP)): "Any regular local
ring is a domain." The retained file is `00NP.html` in the registered literature
source `stacks-regular-local-domain-2026-10-29`, content SHA-256
`db2b1bc0bca1bf0b9a1fb465a2b9cafdde71accc7986bedd0c7752179f9461f0`. The Lean
proposition is a direct formalization of this statement, with the Stacks
definition of a regular local ring replaced by Mathlib's equivalent
`IsRegularLocalRing` as explained above.

The Stacks proof uses `⋂ m^n = 0` (Krull intersection, Lemma 10.51.4, Tag 00IP)
and Lemma 10.106.1 (Tag 00NO), which says that the graded ring
`⊕ m^n/m^{n+1}` of a regular local ring of dimension `d` with residue field `κ`
is isomorphic to the graded polynomial algebra `κ[X_1, ..., X_d]`. Given
`fg = 0`, take `a` and `b` maximal with `f ∈ m^a` and `g ∈ m^b`. Since
`fg ∈ m^{a+b+1}`, Lemma 10.106.1 gives `f ∈ m^{a+1}` or `g ∈ m^{b+1}`, a
contradiction. The page has two comments. Comment #8848 proposes to embed `R`
into its associated graded ring. The maintainers' reply, Comment #9238, rejects
this: there is no ring map `R → ⊕ m^n/m^{n+1}`, and a map of multiplicative
monoids exists only a posteriori and not for general Noetherian local rings.
This shortcut is therefore not a valid proof.

The Stacks Project has no separate errata file. On 30 October 2026 the current
official 00NP page was byte-identical to the retained file. The six comments on
Section 10.106 (Tag 00NN) concern Lemmas 00NO and 00NR and a link to the
definition; none corrects Lemma 10.106.2. The current 00NN and 00KU pages were
also retained. This check is the registered source
`stacks-regular-local-domain-current-check-2026-10-30`, content SHA-256
`d036b6e51123a8430d84830047fdc7623a43da95939da6c6b789c81cb037e29d`.

## Proof boundary

The Lean file only defines this proposition; it supplies no proof. At the pinned
Mathlib commit, no theorem in `Mathlib/RingTheory/RegularLocalRing` or elsewhere
concludes `IsDomain` from `IsRegularLocalRing`. A separate proof must establish
this exact proposition.
