# Prime localizations of regular local rings are regular

`Langlands.CommutativeAlgebra.RegularLocalLocalizationsStatement.{u}` is the
following `Prop`-valued definition:

```lean
∀ (R : Type u) [CommRing R], IsRegularLocalRing R → IsRegularRing R
```

It says that every commutative ring `R` that is a regular local ring is a
regular ring in Mathlib's sense. In other words, its localization `R_p` at every
prime ideal `p` is again a regular local ring. This is the second sentence of
Lemma 10.110.6 of the Stacks Project (Tag 0AFS), stated for every `R` in one
arbitrary universe `u`. The Lean file only defines this proposition. It supplies
no proof and no new axiom.

## The Mathlib notions used

The module imports only `Mathlib.RingTheory.RegularLocalRing.Defs`. It uses
Mathlib's `CommRing`, `IsRegularLocalRing` and `IsRegularRing` unchanged and
introduces no new notion.

- `IsRegularLocalRing R` is a class that extends `IsLocalRing R` and
  `IsNoetherianRing R`. Its one further field, `spanFinrank_maximalIdeal`, says
  `(maximalIdeal R).spanFinrank = ringKrullDim R`. Here `spanFinrank` is the
  least number of elements generating the maximal ideal, and
  `ringKrullDim R : WithBot ℕ∞` is the Krull dimension. So the equality also says
  that the Krull dimension is finite. Mathlib marks the class `@[stacks 00KU]`.
  The published Markdown of
  `Langlands.CommutativeAlgebra.RegularLocalDomainStatement` explains why it
  agrees with Stacks Definition 10.60.10 (Tag 00KU): a Noetherian local ring of
  dimension `d` whose maximal ideal is generated by `d` elements.
- `IsRegularRing R` is a class that extends `IsNoetherianRing R`. Its one further
  field is

  ```lean
  isRegularLocalRing_localization (p : Ideal R) [p.IsPrime] :
    IsRegularLocalRing (Localization.AtPrime p)
  ```

  Mathlib's lemma `isRegularRing_iff` restates this for Noetherian `R` as
  `IsRegularRing R ↔ ∀ (p : Ideal R) [p.IsPrime],
  IsRegularLocalRing (Localization.AtPrime p)`. Mathlib's docstring describes the
  class as "A noetherian ring is regular if its localization at any prime
  `IsRegularLocalRing`."

The hypothesis `IsRegularLocalRing R` is an explicit argument, not an instance
binder, so a proof must install it as an instance itself if it needs one. The
conclusion refers to the given `CommRing R` structure.

## Correspondence with `IsRegularRing`

The conclusion `IsRegularRing R` has two parts.

1. `IsNoetherianRing R`. This is already part of the hypothesis
   `IsRegularLocalRing R`, so it adds nothing to the content of the statement.
2. For every prime ideal `p` of `R`, `IsRegularLocalRing (Localization.AtPrime p)`.
   This is the content of the Stacks clause "`R_p` is a regular local ring for
   all primes `p`".

Some details of the second part:

- `Localization.AtPrime p` is Mathlib's construction of `R_p`, namely
  `Localization p.primeCompl`: the localization of `R` at the complement of `p`.
  Any other ring `S` with `IsLocalization.AtPrime S p` is isomorphic to it as a
  ring (for example by `IsLocalization.algEquiv p.primeCompl`).
  `IsRegularLocalRing.of_ringEquiv` transports regularity along ring
  isomorphisms. So the choice of model of `R_p` does not change the meaning.
- `IsRegularLocalRing (Localization.AtPrime p)` asserts, in its own fields, that
  `R_p` is local and Noetherian. Both facts are standard and are proved in Mathlib.
  `Localization.AtPrime.isLocalRing` is an instance. Noetherianity follows from
  that of `R`, by `IsLocalization.isNoetherianRing` and the corresponding
  instance for `Localization`. The remaining content is the equality
  `(maximalIdeal R_p).spanFinrank = ringKrullDim R_p`, that is, the maximal ideal
  `p R_p` is generated by `dim R_p` elements.
- Every prime ideal is included. In particular `p` may be the maximal ideal of `R`
  (then `R_p ≅ R`) or a minimal prime.

Stacks Definition 10.110.7 (Tag 00OD), quoted below, calls a Noetherian ring
regular if all of its localizations at primes are regular local rings. Mathlib's
`IsRegularRing` is exactly this definition. So the proposition also reads: "a
regular local ring is a regular ring" in the sense of Definition 10.110.7. The
Mathlib file `Mathlib/RingTheory/RegularLocalRing/Defs.lean` at the pinned commit
notes that this "is not immediate under this definition" and lists it as a TODO.
The converse direction is already in Mathlib:
`IsRegularLocalRing.of_isRegularRing_of_isLocalRing` derives
`IsRegularLocalRing R` from instances `[IsLocalRing R] [IsRegularRing R]`.

## Scope

The universe `u` is arbitrary; the Stacks Project does not track universes. No
hypothesis is added beyond regularity of `R`. There is no domain hypothesis
(although regular local rings are domains, by the published
`Langlands.CommutativeAlgebra.regularLocalDomain`, which this module does not
import). There is also no restriction on dimension, characteristic, residue field,
completeness, henselianity or excellence. Fields and discrete valuation rings are
included.

Only the prime-localization clause of Lemma 10.110.6 is stated. Its first
sentence, the equivalence of regularity with finite global dimension, is not part
of this proposition. Nor are localizations at arbitrary multiplicative subsets,
other than those at primes.

## Original source

The original is Stacks Project Lemma 10.110.6
([Tag 0AFS](https://stacks.math.columbia.edu/tag/0AFS)), in Section 10.110
"Regular rings and global dimension":

> A Noetherian local ring `R` is a regular local ring if and only if it has
> finite global dimension. In this case `R_p` is a regular local ring for all
> primes `p`.

The Lean proposition formalizes the second sentence. "In this case" refers to a
regular local ring, which is the hypothesis `IsRegularLocalRing R`. The retained
file is `0AFS.html` (SHA-256
`b87a3b180fd468914b8d74516dde72cc5a785d51ee4c36a495da50ecf2d6d55f`) in the
registered folder source `stacks-regular-local-localizations-2026-11-01`
(directory SHA-256
`36be521ada23e27c1eca7157d1965ba42be3180b96968bfe57ce1cb78e21c1c1`). The page has
no comments. On 1 November 2026 the current official 0AFS page was byte-identical
to this file. The Stacks Project has no separate errata file, and no public
errata note for this source exists in the Library.

The definition of a regular ring is Stacks Definition 10.110.7
([Tag 00OD](https://stacks.math.columbia.edu/tag/00OD)):

> A Noetherian ring `R` is said to be regular if all the localizations `R_p` at
> primes are regular local rings.

It is retained in the registered source `stacks-regular-ring-definition-2026-11-01`
(file SHA-256
`869e1ee636490fffe7252661f05607b2ca5a623b7f4fe6be4da91078547ec12a`). That page
also has no comments.

The Stacks proof of 0AFS is homological. Propositions 10.110.5 (Tag 00OC) and
10.110.1 (Tag 00O7) show that a Noetherian local ring is regular if and only if it
has finite global dimension. Lemma 10.109.13 (Tag 00O8) shows that every
localization `R_p` of a ring of finite global dimension again has finite global
dimension, and so `R_p` is regular. This describes only the source argument. None
of it is implemented in this module, and a proof of the proposition may take a
different route.

## Proof boundary

The Lean file only defines this proposition; it supplies no proof. At the pinned
Mathlib commit, no theorem concludes `IsRegularRing R`, or regularity of
`Localization.AtPrime p`, from `IsRegularLocalRing R` for a general prime `p`.
The nearest Mathlib results are narrower. The low-priority instance in `Defs.lean`
gives `IsRegularRing R` for every Dedekind domain `R`. The lemma
`Polynomial.isRegularLocalRing_localization_atPrime_of_comap_eq_maximalIdeal`
in `Mathlib/RingTheory/RegularLocalRing/Polynomial.lean` concerns only primes of
a polynomial ring `R[X]` lying over the maximal ideal of a regular local ring `R`.
A separate proof must establish this exact proposition.
