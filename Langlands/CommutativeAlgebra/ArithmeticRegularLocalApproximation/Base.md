# The prime subring of a discrete valuation ring as a regular base

Module `Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximation.Base`.

The general presentation theorem `chartConclusion_of_presentation` (module
`Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximation.Presentation`) needs a base ring
`R₀` in the same universe as `Λ`, regular, generated by the integers, with `R₀ → Λ` a regular
map. This module takes `R₀ = (⊥ : Subring Λ)`, the image of `ℤ` in `Λ`, and specializes the
presentation theorem to discrete valuation rings `Λ`. It is an internal step of the proof of
`Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximationStatement`.

## Results

- `intCast_surjective_bot`: every element of `(⊥ : Subring Λ)` is an integer
  (`Subring.mem_bot`).
- Instances for a domain `Λ`:
  - `isPrincipalIdealRing_bot`: `(⊥ : Subring Λ)` is a principal ideal ring, as a quotient of
    `ℤ` (`IsPrincipalIdealRing.of_surjective`);
  - `isRegularRing_bot`: it is a regular ring (Mathlib's instance for Dedekind domains, the
    subring being a domain and a principal ideal ring);
  - `isTorsionFree_bot`: `Λ` is a torsion-free module over it, since the inclusion is injective
    and `Λ` is a domain (`FaithfulSMul.to_isTorsionFree`);
  - `flat_bot`: `Λ` is flat over it, since over a Dedekind domain flatness is torsion-freeness
    (`IsDedekindDomain.flat_iff_torsion_eq_bot`).
- `regularAlgebra_bot`: if `Λ` is a discrete valuation ring in which every prime number `n` is
  zero, a unit, or a generator of the maximal ideal, then `RegularAlgebra (⊥ : Subring Λ) Λ`
  holds. This is `regularAlgebra_of_isLocalRing` with the hypothesis on prime ideals supplied by
  `map_prime_eq_of_intCast` (module
  `Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximation.RegularAlgebra`).
- `intCast_prime_cases`: let `Λ` be a local domain whose residue field has characteristic `p`,
  where `(p : Λ)` is zero or generates the maximal ideal. Then every prime number `n` is zero, a
  unit, or a generator of the maximal ideal of `Λ`. Proof: if `n` is nonzero in the residue field
  it is a unit. Otherwise `p ∣ n`; then `p` is not zero (else `n = 0`), so `p` is prime and `n`
  is associated to `p` in `ℤ`, hence `(n : Λ)` is associated to `(p : Λ)` and shares its
  property.
- `chartConclusion_of_dvr`: `chartConclusion_of_presentation` with `R₀ = (⊥ : Subring Λ)`, for
  a discrete valuation ring `Λ` whose prime numbers are zero, units or uniformizers, and the same
  presentation data `ψ`, `F`: under these hypotheses `ChartConclusion W' C F'` holds for every
  finite type `ℤ`-algebra `C` and ring map `F' : C → Frac W'`.
