# Completing a regular local chart mapping to a complete discrete valuation ring

Module `Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximation.Chart`.

This module isolates the part of
`Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximationStatement` that concerns the
Henselian regular local ring `B`, and proves it once a regular local "chart" `P` with a
finitely generated residue field has been found. It is an internal step of the proof of that
statement.

Take `B = P̂`, the completion of `P` at its maximal ideal. The ring `B` is regular and
Henselian, and completeness of `W'` lets the local map `P → W'` extend to a local map `B → W'`.
In Deligne, SGA 7 I, Exposé I, Lemma 0.5.1 (pp. I-4–I-5), the finite-data approximation is by
Henselian smooth essentially finite type algebras over the base trait, obtained by Néron
desingularization of finite type subalgebras.

## Definition

`ChartConclusion W' C F` (for a commutative ring `W'` in universe `u`, a commutative ring `C`
and a ring map `F : C → FractionRing W'`) is the proposition: there are a commutative ring
`B : Type u`, an element `t : B` and a ring map `j : B → W'` such that

- `B` is a domain, a regular local ring and a Henselian local ring;
- `j` is a local homomorphism;
- `t` lies in the maximal ideal of `B` but not in its square, `B ⧸ (t)` is a regular local ring,
  and `j t` is irreducible in `W'`;
- the residue field of `B` is purely inseparable over a finitely generated subfield;
- there are ring maps `jAway : B[1/t] → FractionRing W'` and `g : C → B[1/t]` with
  `jAway ∘ (B → B[1/t]) = (W' → FractionRing W') ∘ j` and `jAway ∘ g = F`.

These are exactly the conditions on `B`, `t`, `j`, `jAway` and `g` in the target statement,
with `iFrac ∘ f` replaced by `F`.

## Auxiliary results

- `henselianLocalRing_of_isAdicComplete_maximalIdeal`: a local ring complete for its maximal ideal is a
  Henselian local ring. This repackages Mathlib's instance `IsAdicComplete.henselianRing`.
- `fieldFG_of_surjective`: if `K` is a finitely generated field and `K → L` is a surjective ring
  map of fields, then `L` is finitely generated. The image of a finite generating set generates,
  by `RingHom.map_field_closure`.
- `isPurelyInseparable_top`: a field is purely inseparable over its top subfield (every element
  lies in the image of `⊤`).
- `irreducible_notMem_maximalIdeal_sq`: in a discrete valuation ring an irreducible element `ϖ`
  is not in `𝔪²`; otherwise `ϖ = a ϖ²` would make `ϖ` a unit.
- `exists_adicCompletion_lift`: a local map `h : P → W'` from a local ring to a local ring that
  is complete for its maximal ideal extends along `P → P̂` (the `𝔪_P`-adic completion). The maps
  `P̂ → P/𝔪_P^n → W'/𝔪_{W'}^n` are compatible, and `IsAdicComplete.liftRingHom` assembles them;
  the identity `j ∘ (P → P̂) = h` is checked modulo every power of `𝔪_{W'}` and follows from
  Hausdorffness (`IsHausdorff.funext'`).

## Main theorem

`chartConclusion_of_regularLocal` assumes: `W'` is a discrete valuation ring complete for its
maximal ideal; `P : Type u` is a regular local ring with finitely generated residue field;
`h : P → W'` is a local homomorphism; `t : P` has `h t` irreducible; and there are ring maps
`jAway₀ : P[1/t] → FractionRing W'` and `g₀ : C → P[1/t]` with
`jAway₀ ∘ (P → P[1/t]) = (W' → FractionRing W') ∘ h` and `jAway₀ ∘ g₀ = F`. It concludes
`ChartConclusion W' C F`.

Proof. Take `B = P̂`, the adic completion of `P` at its maximal ideal.

1. `B` is a regular local ring by `FiniteTypeIntGRing.isRegularLocalRing_adicCompletion`, a
   domain by `regularLocalDomain`, and Henselian by `henselianLocalRing_of_isAdicComplete_maximalIdeal`.
2. `exists_adicCompletion_lift` gives `j : B → W'` with `j ∘ (P → B) = h`. The maximal ideal
   of `B` is the extension of `𝔪_P` (`AdicCompletion.maximalIdeal_eq_map`), and `h` maps
   `𝔪_P` into `𝔪_{W'}`, so `j` is local.
3. Let `t_B` be the image of `t`. Then `j t_B = h t` is irreducible. So `t_B` is not a unit
   (else `h t` would be one), and `t_B ∉ 𝔪_B²`, because the local map `j` sends `𝔪_B²` into
   `𝔪_{W'}²`, which does not contain the irreducible `h t`. The quotient `B ⧸ (t_B)` is regular by
   `RegularLocalFactorial.isRegularLocalRing_quotient_span_singleton`.
4. The residue field of `B` is the image of that of `P` under a bijection
   (`AdicCompletion.residueField_map_bijective`), so it is finitely generated by
   `fieldFG_of_surjective`; take `k = ⊤` and `isPurelyInseparable_top`.
5. `jAway : B[1/t_B] → FractionRing W'` is `IsLocalization.Away.lift` of
   `(W' → FractionRing W') ∘ j`, which sends `t_B` to a unit because `j t_B ≠ 0`. Put
   `g = awayMap (P → B) t ∘ g₀`. The maps `jAway ∘ awayMap (P → B) t` and `jAway₀` agree on `P`,
   hence on `P[1/t]` (`IsLocalization.ringHom_ext`), so `jAway ∘ g = jAway₀ ∘ g₀ = F`.
