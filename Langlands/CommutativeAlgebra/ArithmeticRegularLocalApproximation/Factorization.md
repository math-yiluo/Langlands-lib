# Factoring a map to a fraction field through a localization at one element

Module `Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximation.Factorization`.

This module is an internal step of the proof of
`Langlands.CommutativeAlgebra.ArithmeticRegularLocalApproximationStatement`. It produces the
factorization `C → P[1/t] → Frac W'` before the chart `P` is completed to `B`. The construction
uses the fact that each value of `C → Frac W'` on a generator of `C` is a quotient `a / ϖⁿ`.

## `exists_mul_pow_eq_algebraMap`

Let `W` be a discrete valuation ring, `K` its fraction field and `ϖ` an irreducible element.
For every `x ∈ K` there are `a ∈ W` and `n : ℕ` with `x · ϖⁿ = a` in `K`.

Proof. Write `x = a / b` with `b ≠ 0` (`IsFractionRing.div_surjective`) and
`b = u ϖⁿ` with `u` a unit (`IsDiscreteValuationRing.eq_unit_mul_pow_irreducible`). Then
`x · ϖⁿ = a u⁻¹`.

## `exists_away_factorization`

Data and hypotheses:

- commutative rings `A`, `P`, `C` and a domain `W'`;
- ring maps `Θ : A → W'`, `Ψ : A → P` and `hP : P → W'` with `hP ∘ Ψ = Θ` and
  `ker Θ ⊆ ker Ψ`;
- an element `a₀ ∈ A` with `Θ a₀ ≠ 0`;
- a ring map `F : C → Frac W'` and a set `s ⊆ C` generating `C` as a `ℤ`-algebra, such that
  for every `c ∈ s` there are `a ∈ A` and `n : ℕ` with `F c · (Θ a₀)ⁿ = Θ a` in `Frac W'`.

Conclusion: there are ring maps `jAway : P[1/Ψ a₀] → Frac W'` and `g : C → P[1/Ψ a₀]` with
`jAway ∘ (P → P[1/Ψ a₀]) = (W' → Frac W') ∘ hP` and `jAway ∘ g = F`.

Proof. Let `S = Θ(A) ⊆ W'`, a subring.

1. Since `ker Θ ⊆ ker Ψ`, `Ψ` factors through the surjection `A → S`
   (`RingHom.liftOfSurjective`): there is `θ : S → P` with `θ (Θ a) = Ψ a`. Then
   `hP (θ r) = r` for every `r ∈ S`.
2. Let `x₀ = Θ a₀ ∈ S` and `ι : S[1/x₀] → Frac W'` the map induced by the inclusion
   (`IsLocalization.Away.lift`; `x₀ ≠ 0` is invertible in `Frac W'`). It is injective: if
   `ι (r / x₀ᵐ) = 0` then `r = 0` in `Frac W'`, hence in `S`.
3. The image of `F` lies in the image of `ι`. This is a subring, so by induction on the
   `ℤ`-algebra generated by `s` (`Algebra.adjoin_induction`) it suffices to treat `c ∈ s`, and
   then `F c = ι (Θ a / x₀ⁿ)` by the hypothesis (`IsLocalization.lift_mk'_spec`).
4. Hence `F = ι ∘ g₁` for `g₁ : C → S[1/x₀]`, obtained by composing the corestriction of `F`
   with the inverse of the ring isomorphism `S[1/x₀] ≅ ι(S[1/x₀])`.
5. Let `μ : S[1/x₀] → P[1/Ψ a₀]` be induced by `θ` (it inverts `x₀`, as `θ x₀ = Ψ a₀`), and
   `jAway : P[1/Ψ a₀] → Frac W'` be induced by `(W' → Frac W') ∘ hP`, which inverts
   `Ψ a₀` since `hP (Ψ a₀) = Θ a₀ ≠ 0`; then
   `jAway ∘ (P → P[1/Ψ a₀]) = (W' → Frac W') ∘ hP` by construction. The maps `jAway ∘ μ`
   and `ι` agree on `S` because `hP ∘ θ` is the inclusion of `S`, hence agree on `S[1/x₀]`
   (`IsLocalization.ringHom_ext`). Put `g = μ ∘ g₁`; then `jAway ∘ g = ι ∘ g₁ = F`.
