# Factoring a map into `Λ_q` through a finite-level localization

This module proves a finite-presentation localization lemma. It is the first
step of the implemented proof of Stacks Project, *Smoothing ring maps*, Lemma 9.3
(tag 07F9), in `LocalDimZeroResolutionProof`. That proof differs from the Stacks
proof, which works with a presentation and homogenized equations. The Stacks proof
does not contain this lemma.

Let `T` be a finitely presented `R_p`-algebra with a map `T → Λ_q`. The lemma
gives an element `ℓ ∉ q`. Then `T → Λ_q` factors through `M⁻¹Λ` for every
submonoid `M ⊆ Λ \ q` that contains the image of `R \ p` and `ℓ`. The base
denominators from `R \ p` cannot be omitted. A localization `Λ_λ` at a single
element is not enough in general. For example, take `R = A = Λ = ℤ`,
`q = p = (0)`, `T = ℚ`, `u` the inclusion and `v` the identity of `ℚ = Λ_q`.
Then there is no ring map `ℚ → ℤ[1/λ]` for any `λ ≠ 0`. Later the lemma is used
with `M` the submonoid generated by the image of `R \ p` and `ℓ`.

## Auxiliary facts

- `isUnit_of_mem_closure`: if a ring map sends every element of a set `s` to a
  unit, it sends every element of the submonoid generated by `s` to a unit.
- `isUnit_of_dvd'`: if `g(y)` is a unit and `x ∣ y`, then `g(x)` is a unit.

## Main lemma

`exists_localization_factor` has the following data. `A` is a finite type
`R`-algebra and `f : A → Λ` an `R`-algebra map. `q` is a prime of `Λ` and
`p = q ∩ R`. `T` is a finitely presented `R_p`-algebra. Finally, `u : A → T` and
`v : T → Λ_q` are ring maps such that `u` is compatible with `R → R_p → T` and
`v ∘ u = (Λ → Λ_q) ∘ f`.

It produces `ℓ ∉ q` with the following property. Let `M` be a submonoid of `Λ` that

- contains the image of `R \ p`,
- contains `ℓ`, and
- is contained in `Λ \ q`.

Then there is a ring map `w : T → M⁻¹Λ` with `w ∘ u = (Λ → M⁻¹Λ) ∘ f`.

Proof:

1. Present `T = R_p[X_1, …, X_N]/(G_1, …, G_m)` and `A` as a quotient of
   `R[Y_1, …, Y_K]` via `ψA`.
2. Write `v(X_i) = a_i / w_i` with `w_i ∉ q`, and put `ℓ₁ = ∏ w_i`. Let `M₀` be
   the submonoid generated by the image of `R \ p` and `ℓ₁`, and `L₀ = M₀⁻¹Λ`.
   The map `R_p → L₀` exists by the universal property. Evaluation at
   `X_i ↦ a_i / w_i` gives `ε₀ : R_p[X] → L₀`. Its composite with `L₀ → Λ_q` is
   `v ∘ P`, where `P` is the presentation map.
3. `Λ_q` is a localization of `L₀` (`IsLocalization.isLocalization_of_submonoid_le`).
   So every element of `L₀` that maps to zero in `Λ_q` is killed by some `c ∉ q`
   (`IsLocalization.map_eq_zero_iff`). Apply this to the following elements:
   - each `ε₀(G_j)`, killed by `c_j`;
   - for each generator `Y_k` of `A`, the difference between `ε₀` of a lift of
     `u(ψA(Y_k))` and the image of `f(ψA(Y_k))`, killed by `c'_k`.
4. Put `ℓ = ℓ₁ · ∏ c_j · ∏ c'_k`. For `M` as above, `L₀ → M⁻¹Λ` exists, and the
   composite `ε : R_p[X] → M⁻¹Λ` kills every `G_j`, because `c_j` divides `ℓ` and
   is a unit there. So `ε` descends to `w : T → M⁻¹Λ`
   (`RingHom.liftOfRightInverse`).
5. `w ∘ u` and `(Λ → M⁻¹Λ) ∘ f` agree on the image of `R` and on every generator
   `ψA(Y_k)`, because `c'_k` is a unit in `M⁻¹Λ`. Hence they agree on `A`.
