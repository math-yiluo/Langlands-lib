# Proof: minimal generators of the maximal ideal of a regular local ring are regular

This module proves the Library proposition
`Langlands.CommutativeAlgebra.Popescu.RegularLocalParametersStatement.{u}` from
`Langlands.CommutativeAlgebra.Popescu.RegularLocalParametersStatement`:

```lean
theorem regularLocalParameters : RegularLocalParametersStatement.{u}
```

Let `R : Type u` be a regular local ring with maximal ideal `m`, and let
`x : Fin d → R` with `d = m.spanFinrank` and `Ideal.span (Set.range x) = m`. Then
`RingTheory.Sequence.IsRegular R (List.ofFn x)`. No hypotheses are used beyond those
in the statement.

The module imports the unchanged statement module and the published proof module
`Langlands.CommutativeAlgebra.RegularLocalDomainProof`. From the latter it uses
`Langlands.CommutativeAlgebra.regularLocalDomain : RegularLocalDomainStatement.{u}`,
which says that a regular local ring is a domain (Stacks Lemma 10.106.2, Tag 00NP).
Every other ingredient comes from Mathlib.

## Provenance and route

The statement is the first assertion of Stacks Project, Chapter 10, Lemma 10.106.3
(Tag 00NQ). The Stacks proof: `R/x₁R` is a Noetherian local ring of dimension
`≥ d − 1` whose maximal ideal is generated by the images of `x₂, …, x_d`, so it is
regular of dimension `d − 1`. The element `x₁` is a nonzerodivisor because `R` is a
domain (Lemma 10.106.2). One then inducts on `d`.

The Lean proof follows this route. It inducts on the number `n` of generators, for
all regular local rings in universe `u` at once. Mathlib supplies the dimension
count: for a nonzerodivisor `r` in `m`, `dim R/(r) + 1 = dim R`. With this the proof
gets the exact dimension `d − 1` of the quotient directly, not just the lower bound.
The Lean arrangement was written for this module.

## Auxiliary lemmas

All are in the namespace `Langlands.CommutativeAlgebra.Popescu.RegularLocalParameters`.

- `spanFinrank_span_range_le`: for a commutative ring `S` and `y : Fin n → S`,
  `(Ideal.span (Set.range y)).spanFinrank ≤ n`. By
  `Submodule.spanFinrank_span_le_ncard_of_finite`, the `spanFinrank` is at most
  `(Set.range y).ncard`. Writing the range as the image of `Set.univ`, this is at
  most `n` (`Set.ncard_image_le`).
- `span_range_eq_span_range_succ_of_eq_zero`: for `z : Fin (n + 1) → S` with
  `z 0 = 0`, `Ideal.span (Set.range z) = Ideal.span (Set.range fun i => z i.succ)`.
  For `≤`, each `z i` is either `z 0 = 0` or some `z j.succ` (`Fin.cases`). The
  inclusion `≥` holds because every `z j.succ` is a value of `z`.
- `exists_nat_eq_of_ne_bot_of_le`: an element `a : WithBot ℕ∞` with `a ≠ ⊥` and
  `a ≤ k` for some `k : ℕ` equals `m` for some `m : ℕ`. Case analysis
  (`WithBot.recBotCoe`, `ENat.recTopCoe`) rules out `⊥` and `⊤`
  (`ENat.natCast_lt_top`).

## Main induction

`isRegular_ofFn_of_spanFinrank_eq (n : ℕ)`: for every `R : Type u` with
`[CommRing R] [IsRegularLocalRing R]` and every `x : Fin n → R` with
`m.spanFinrank = n` and `Ideal.span (Set.range x) = m`,
`IsRegular R (List.ofFn x)`. The proof is by induction on `n`, generalizing `R` and
`x`.

1. **`n = 0`.** Then `List.ofFn x = []` (`List.ofFn_zero`). The empty sequence is
   regular on the nontrivial module `R` (`RingTheory.Sequence.IsRegular.nil`).
2. **`n + 1`: `R` is a domain.** This is `regularLocalDomain`.
3. **`x 0` is a nonzero element of `m`.** It lies in `m` because it is one of the
   generators. If `x 0 = 0`, then by `span_range_eq_span_range_succ_of_eq_zero` the
   `n` elements `x i.succ` span `m`, so `m.spanFinrank ≤ n`
   (`spanFinrank_span_range_le`). This contradicts `m.spanFinrank = n + 1`. Since `R`
   is a domain, `x 0` is `R`-regular (`IsSMulRegular.of_ne_zero`).
4. **The quotient `S = R ⧸ Ideal.span {x 0}` is local.** As `x 0 ∈ m` is not a unit,
   `Ideal.span {x 0} ≠ ⊤` (`Ideal.span_singleton_eq_top`). So `S` is nontrivial
   (`Ideal.Quotient.nontrivial_iff`), and it is local as a quotient of a local ring
   (`IsLocalRing.of_surjective'`). It is Noetherian by Mathlib's quotient instance.
5. **The images `y' i` of `x i.succ` span the maximal ideal `m_S` of `S`.** The
   maximal ideal of `S` is the image of `m`
   (`IsLocalRing.map_maximalIdeal_of_surjective`), which is spanned by the images of
   all `x i` (`Ideal.map_span`, `Set.range_comp`). The image of `x 0` is `0`, so
   `span_range_eq_span_range_succ_of_eq_zero` drops it. Hence
   `m_S.spanFinrank ≤ n` (`spanFinrank_span_range_le`).
6. **Dimension count.** Mathlib's
   `ringKrullDim_quotient_span_singleton_succ_eq_ringKrullDim` (for the `R`-regular
   element `x 0 ∈ m`) gives `ringKrullDim S + 1 = ringKrullDim R`. Regularity of `R`
   (`IsRegularLocalRing.spanFinrank_maximalIdeal`) gives `ringKrullDim R = n + 1`.
   Mathlib's `ringKrullDim_le_spanFinrank_maximalIdeal` gives
   `ringKrullDim S ≤ m_S.spanFinrank`. Since `ringKrullDim S ≠ ⊥`
   (`ringKrullDim_ne_bot`), `exists_nat_eq_of_ne_bot_of_le` writes
   `ringKrullDim S = m'` with `m' : ℕ`. Then `m' + 1 = n + 1` in `WithBot ℕ∞`, so
   `m' = n` (`Nat.cast_injective`). Also `m' ≤ m_S.spanFinrank`. Together with
   step 5, `m_S.spanFinrank = n`.
7. **`S` is regular.** `m_S.spanFinrank = n = ringKrullDim S`, so
   `IsRegularLocalRing.of_spanFinrank_maximalIdeal_le` applies. `S` lives in the
   same universe `u`.
8. **Induction hypothesis.** Applied to `S` and `y'`, it gives
   `IsRegular S (List.ofFn y')`, with `S` as a module over itself.
9. **Transfer to `QuotSMulTop (x 0) R`.** As submodules of `R`,
   `x 0 • ⊤ = Ideal.span {x 0}` (`Submodule.ideal_span_singleton_smul`,
   `Ideal.mul_top`). So `Submodule.quotEquivOfEq` gives an `R`-linear equivalence
   `e : QuotSMulTop (x 0) R ≃ₗ[R] S`. `AddEquiv.isRegular_congr` transfers regular
   sequences along an additive equivalence that matches the scalar actions term by
   term. Here `List.ofFn y'` is the image of `List.ofFn (fun i => x i.succ)` under
   the quotient map (`List.map_ofFn`). For each `a : R`,
   `e (a • z) = a • e z = (Ideal.Quotient.mk _ a) • e z` (`map_smul`,
   `Ideal.Quotient.algebraMap_eq`, `algebraMap_smul`). Hence the `R`-module
   `QuotSMulTop (x 0) R` has the regular sequence `List.ofFn (fun i => x i.succ)`.
10. **Conclusion.** `List.ofFn x = x 0 :: List.ofFn (fun i => x i.succ)`
    (`List.ofFn_succ`). `RingTheory.Sequence.IsRegular.cons` combines step 3 and
    step 9 into `IsRegular R (List.ofFn x)`.

Finally, `regularLocalParameters` introduces `R` and `x` and applies
`isRegular_ofFn_of_spanFinrank_eq` with `n = m.spanFinrank`.

## Scope

As in the statement, only the first assertion of Lemma 10.106.3 is proved. Step 7
shows along the way that `R/(x₁)` is regular local of dimension `d − 1`. This is not
exported as a separate result. The assertions about `R/(x₁, …, x_c)` for general `c`
and about Cohen–Macaulayness are not proved here.
