# `H₁` and `Ω` of a simple purely inseparable extension of degree `p`

Helpers for the Cartier-type equality used in Faltings' proof of Stacks, More on Algebra,
Proposition 15.36.1 (07E5), (2) ⇒ (4). Everything lives in
`Langlands.CommutativeAlgebra.Popescu.Faltings`. `H₁(L_{L/M})` is Mathlib's naive cotangent
complex `Algebra.H1Cotangent M L`, and `Ω_{L/M}` is `Ω[L⁄M]`. These are internal helper results with
standard proofs.

## `minpoly_eq_X_pow_sub_C`

Let `L/M` be a field extension, `char M = p` prime, and `α ∈ L` with `α^p = c ∈ M` and `α ∉ M`.
Then the minimal polynomial of `α` over `M` is `X^p − c`.

Proof: `X^p − c` is irreducible by Mathlib's `X_pow_sub_C_irreducible_of_prime`, provided `c` is not
a `p`-th power in `M`. If `c = b^p` then `(α − b)^p = α^p − b^p = 0`, so `α = b ∈ M`, which is
excluded. The polynomial is monic and kills `α`, so it is the minimal polynomial.

## `simpleExtension`

For a surjection `aeval α : M[X] → L`, the `Algebra.Extension M L` with underlying ring the
one-variable polynomial ring `M[X]`, where `M[X]` acts on `L` through `aeval α`. The section `σ`
is chosen by surjectivity. It is an `abbrev` so that its ring is visibly `M[X]`.

## `simpleExtensionH1Equiv`

`H₁` of `simpleExtension` is `L`-linearly isomorphic to `Algebra.H1Cotangent M L`, which is `H₁` of
the canonical presentation `M[L] → L`. The comparison is Mathlib's
`Extension.H1Cotangent.equiv`. It is applied to the hom `M[X] → M[L]`, `X ↦ X_α`, and to
`defaultHom`. Mathlib proves that `H₁` does not depend on the presentation.

## `rank_simple_step`

If `L = M(α)` (`Algebra.adjoin M {α} = ⊤`), `α ∉ M` and `α^p = c ∈ M`, then `H₁(L_{L/M})` and
`Ω_{L/M}` both have rank `1` over `L`.

Proof, with `P = simpleExtension`:
1. The kernel of `M[X] → L` is generated by the minimal polynomial `f = X^p − c`.
2. Its conormal module `P.Cotangent = I/I²` is spanned by the class of `f`
   (`Cotangent.span_eq_top_of_span_eq_ker`). That class is nonzero: otherwise `f² ∣ f`, which would
   make `f` a unit, but `f` has degree `p`. So `I/I²` has rank `1`.
3. `df = p X^{p−1} dX = 0`, so the cotangent complex `I/I² → L ⊗ Ω_{M[X]/M}` is zero. Hence `H₁`,
   its kernel, is all of `I/I²` and has rank `1`. Transporting along `simpleExtensionH1Equiv` gives
   the claim for `H1Cotangent M L`.
4. The cotangent complex is zero and exact against `L ⊗ Ω_{M[X]/M} → Ω_{L/M}`, which is surjective.
   So `Ω_{L/M} ≅ L ⊗_{M[X]} Ω_{M[X]/M}`. The latter has rank `1`, since `Ω_{M[X]/M}` is free of rank
   one (`KaehlerDifferential.polynomialEquiv`).
