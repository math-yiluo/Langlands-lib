# The subalgebra `σ(F)[t₁, …, t_d]` of Stacks Lemma 11.1

This module supports the proof of Stacks Project, *Smoothing Ring Maps*, Lemma 11.1
(Tag 07FG), in `ArtinianFlatSubalgebra`. All declarations are in the namespace
`Langlands.CommutativeAlgebra.Popescu.ArtinianFlat`.

Setting: `(L, 𝔪, κ)` is a local `k`-algebra, `σ : κ → L` a section of the residue map,
`F ⊆ κ` a subfield containing `k`, and `t : Fin d → L`. `A ⊆ L` is a `k`-subalgebra whose
elements are the polynomials in the `tᵢ` with coefficients in `σ(F)`. The source's algebra
is `F[x₁, …, x_d]/(g₁, …, g_t)`, and the claim shows that it is a `k`-subalgebra of `Λ`. The
lemmas below prove the properties that the source calls "clear", or derives from Algebra,
Lemma 54.4.

## Declarations

### Local, Artinian, `𝔪_A L = 𝔪`

- `isUnit_of_residue_ne_zero A σ hσ F hres hσA hnil a ha`: assume the residues of elements
  of `A` lie in `F`, `σ(F) ⊆ A`, and `𝔪` is nil. Then an element `a ∈ A` with nonzero
  residue `c` is a unit of `A`. Indeed `σ(c⁻¹) a = 1 − y` with `y` nilpotent.
- `isLocalRing_of_residue A hunit`: if every element of `A` with nonzero residue is a unit
  of `A`, then `A` is local (`IsLocalRing.of_isUnit_or_isUnit_one_sub_self`).
- `mem_maximalIdeal_iff_of_residue`: then `𝔪_A = A ∩ 𝔪`.
- `map_maximalIdeal_eq A hmem t ht htA`: if `𝔪_A = A ∩ 𝔪` and `𝔪 = (tᵢ)` with `tᵢ ∈ A`,
  then `𝔪_A L = 𝔪`.
- `isArtinianRing_of_residue A hmem hn`: if `A` is local and Noetherian, `𝔪_A = A ∩ 𝔪`
  and `𝔪ⁿ = 0`, then `A` is Artinian. Here `𝔪_Aⁿ = 0`, and
  `isArtinianRing_iff_isNilpotent_maximalIdeal` applies.

### Freeness

- `coeffMap φ P`: for a `K`-linear map `φ : κ → K`, apply `φ` to the coefficients of
  `P ∈ κ[x]`. Lemmas: `coeff_coeffMap`, `coeffMap_zero`, `coeffMap_add`, `coeffMap_X_mul`,
  `coeffMap_C_mul` (`coeffMap φ (c P) = coeffMap (φ ∘ c·) P`), `coeffMap_map`
  (`coeffMap φ Q = φ(1) Q` for `Q ∈ K[x]` viewed in `κ[x]`).
- `coeffMap_mul_mem`, `coeffMap_mem_of_mem_map J hP φ`: if `P` lies in the extension
  `J κ[x]` of an ideal `J ⊆ K[x]`, then `coeffMap φ P ∈ J` for every `K`-linear
  `φ : κ → K`. The property "for all `φ`" is stable under `+`, under multiplication by
  `xᵢ`, and under multiplication by constants `c ∈ κ` (replace `φ` by `φ ∘ (c ·)`).
- `free_of_ker_le σ t A hA hsurj hker`: assume `A` consists exactly of the polynomials in
  `t` with coefficients in `σ(K)` (`hA`), `κ[x] → L`, `xᵢ ↦ tᵢ`, is surjective (`hsurj`),
  and its kernel is generated by the kernel of `K[x] → L` (`hker`). Then `L` is a free
  `A`-module. A basis is `σ(bⱼ)`, for a `K`-basis `b` of `κ`.
  **Proof.**
  1. Spanning: every `x ∈ L` is `h(t)` with `h ∈ κ[x]`. Write each coefficient in the basis
     `b` and induct on `h`.
  2. Linear independence: let `Σ aⱼ σ(bⱼ) = 0` with `aⱼ = Hⱼ(t)`, `Hⱼ ∈ K[x]`. Then
     `P = Σ bⱼ Hⱼ ∈ κ[x]` lies in the kernel, hence in `J κ[x]` for
     `J = ker(K[x] → L)`.
  3. `coeffMap_mem_of_mem_map` with `φ` the `l`-th coordinate of `b` gives `H_l ∈ J`, so
     `a_l = 0`.

  The source calls this flatness "clear": `A = F[x]/(g) → K[x]/(g) = Λ` is a base change of
  the free map `F → K`. The proof here makes that argument explicit inside `L`, without
  identifying `A` with `F[x]/(g)`.

### Essentially of finite type

- `essFiniteType_of_residue σ hσ F S hS t ht0 A hA hunit hn`: assume:
  - `F = k(S)` for a finite set `S` (`hS`);
  - `A` consists exactly of the polynomials in `t` with coefficients in `σ(F)` (`hA`);
  - `residue(tᵢ) = 0` (`ht0`) and `𝔪ⁿ = 0` (`hn`);
  - elements of `A` with nonzero residue are units of `A` (`hunit`).

  Then `A` is essentially of finite type over `k`.
  **Proof.**
  1. Let `s₀ = σ(S) ∪ {tᵢ} ⊆ A`, and `R = {x ∈ A : x u ∈ k[s₀]` for some unit
     `u ∈ k[s₀]}`. `R` is a subring.
  2. By `Algebra.essFiniteType_iff`, it suffices that `R = A`. Apply
     `mem_subring_of_nilpotent` inside `A` with `J = ker(A → κ)`, which satisfies `Jⁿ = 0`
     and is generated by the `tᵢ`. An element `Ψ(h)` of `J` has `h(0) = 0`, so it lies in
     `(tᵢ)` (induction on `h`).
  3. Every `b ∈ A` is congruent mod `J` to an element of `R`. Its residue lies in
     `F = k(S)`, so it is `u / v` with `u, v ∈ k[S]` (`IntermediateField.mem_adjoin_iff_div`).
     Since `k[S]` is the image of `k[s₀]` under the residue map, `u` and `v` are the residues
     of some `a₀, b₀ ∈ k[s₀]`. If `v = 0`, take `0`. Otherwise `b₀` is a unit, and
     `a₀ b₀⁻¹ ∈ R` has the residue of `b`.

  The source cites Algebra, Lemma 54.4 (Tag 07DT): an Artinian local `R`-algebra `S` is
  essentially of finite type iff its residue field is. That lemma is not in Mathlib. The
  argument above proves the needed case directly.
