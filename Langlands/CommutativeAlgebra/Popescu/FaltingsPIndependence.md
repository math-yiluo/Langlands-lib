# `p`-independence: adjoining `p`-th roots of `p`-independent elements

In Faltings' proof of Stacks, More on Algebra, Proposition 15.36.1 (07E5), (2) ⇒ (4), one starts
from `a₁, …, a_n ∈ k` with `da₁, …, da_n` linearly independent in `Ω_{k/𝔽_p}`. In Lean this is
`Ω[k⁄ℤ]`, which is the same module in characteristic `p`. The proof then uses
`k' = k(a₁^{1/p}, …, a_n^{1/p}) = k[x]/(x_j^p − a_j)`, which is Stacks, Algebra, Lemma 10.158.3.
This module proves the degree statement `[k' : k] = p^n` needed for that identification. All
declarations live in `Langlands.CommutativeAlgebra.Popescu.Faltings`.

## `kaehler_span_of_adjoin`

If `v : ι → S` generates `S` as an `R`-algebra, then the `d v_i` span `Ω_{S/R}` over `S`. The proof
is by induction on `Algebra.adjoin`, using the Leibniz rule.

## `isIntegral_of_pow_mem`

If `x^p = c ∈ k`, then `x` is integral over `k`, as a root of the monic `X^p − c`.

## `not_pow_of_independent`

Let `char k = p` and let `M/k` be generated by `β₁, …, β_n` with `β_j^p = a_j`. Suppose
`da₁, …, da_{n+1}` are linearly independent in `Ω_{k/ℤ}`. Then `a_{n+1}` is not a `p`-th power in
`M`.

Proof, assuming `m^p = a_{n+1}` with `m ∈ M`:
1. The `n + 1` vectors `1 ⊗ da_j ∈ M ⊗_k Ω_{k/ℤ}` are linearly independent, by flat base change
   (`Module.Flat.linearIndependent_one_tmul`).
2. Each `a_j` is a `p`-th power in `M`, and `d(x^p) = 0` in characteristic `p`. So these vectors lie
   in the kernel of `M ⊗_k Ω_{k/ℤ} → Ω_{M/ℤ}`. By Jacobi–Zariski exactness
   (`exact_δ_mapBaseChange`), that kernel is the image of `δ : H₁(L_{M/k}) → M ⊗_k Ω_{k/ℤ}`.
3. Hence `n + 1 ≤ dim H₁(L_{M/k})`. By Cartier's equality for `p`-root extensions
   (`rank_eq_of_pRoots`), `dim H₁(L_{M/k}) = dim Ω_{M/k}`. Since `Ω_{M/k}` is spanned by
   `dβ₁, …, dβ_n` (`kaehler_span_of_adjoin`), this is at most `n`. Contradiction.

## `finrank_pRoots`

Let `char k = p` and `da₁, …, da_n` be linearly independent in `Ω_{k/ℤ}`. If a field `L` is
generated as a `k`-algebra by `β₁, …, β_n` with `β_j^p = a_j`, then `[L : k] = p^n`.

The proof is by induction on `n`.
- `n = 0`: `L = k`.
- Step: let `M = k(β₁, …, β_n)`, which has degree `p^n` by induction, and `γ = β_{n+1}`.
  1. `L = M(γ)` (`adjoin_last_eq_top`) and `γ^p = a_{n+1}`.
  2. `γ ∉ M` by `not_pow_of_independent`, so the minimal polynomial of `γ` over `M` is `X^p − a_{n+1}`
     (`minpoly_eq_X_pow_sub_C`).
  3. Hence `[L : M] = p` (`IntermediateField.adjoin.finrank`), and the tower law gives
     `[L : k] = p^{n+1}`.
