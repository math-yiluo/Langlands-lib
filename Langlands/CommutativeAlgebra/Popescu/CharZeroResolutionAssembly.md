# Assembly of Stacks Lemma 10.3 in characteristic zero

`charZeroResolution_of` proves `CharZeroResolutionStatement.{u}`: Stacks Project,
*Smoothing Ring Maps*, Lemma 10.3 (Tag 07FE), for a base field of characteristic zero.
It takes eight Library statements as hypotheses:

- `NilpotentLiftingStatement` (Proposition 5.3);
- `StrictlyStandardDesingularizationStatement` (Lemma 7.3);
- `StrictlyStandardSmoothStatement` (Lemma 3.7(d));
- `DimZeroResolutionStatement` (Lemmas 9.3 and 9.4);
- `CharZeroFieldFactorizationStatement` (Algebra 07BV);
- `RegularSequenceFlatStatement` (Algebra 07DY);
- `RegularParameterChoiceStatement` (Lemma 10.2);
- `StrictlyStandardRetractStatement` (Lemmas 3.1 and 3.7(e)).

## Auxiliary lemmas

- `exists_pow_map_le`: if `q` is minimal over `I` in a Noetherian ring, then
  `qⁿΛ_q ⊆ IΛ_q` for some `n`. Every prime of `Λ_q` containing `IΛ_q` is the maximal
  ideal, so the maximal ideal lies in the radical of `IΛ_q`. Then use
  `Ideal.exists_pow_le_of_le_radical_of_fg`.
- `singularIdeal_le_of_smooth`: if `R` is smooth over `k`, then `H_{D/R} ⊆ H_{D/k}`.
- `mem_singularIdeal_of_pow`: an element with a strictly standard power lies in the
  singular ideal. This uses Lemma 3.7(d) and the fact that the singular ideal is radical.
- `SmoothingAlgebra.algebraMap_X_mem_singularIdeal`: if all `aⱼ ∈ H_{B/R}`, then all
  `xᵢ ∈ H_{B/R}`, since `xᵢⁿ = Σ zᵢⱼ aⱼ`.

## The proof

The proof follows the source.

1. **Setup.** `A` is Noetherian, and its singular ideal is generated by `a₁, …, a_r`.
   Put `I = H_{A/k}Λ`. The prime `q` is minimal over `I`, so `qⁿΛ_q ⊆ IΛ_q` for some `n`.
2. **The algebra `B`.** Put `d = embdim Λ_q`, `R = k[x₁, …, x_d]` and
   `B = A[x, z]/(xᵢⁿ − Σ zᵢⱼ aⱼ)` (module `SmoothingAlgebra`). Each `B_{aⱼ}` is smooth
   over `R`. Hence every `aⱼ` and every `xᵢ` lies in `H_{B/R}`.
3. **The retract `C`.** Lemmas 3.1 and 3.7 give a retract `B → C → B` of finitely
   presented `R`-algebras. Some power `g(xᵢ)^{cᵢ}` is strictly standard in `C`. Put
   `c = Σ cᵢ + 1`. Then every `xᵢ^c` is strictly standard in `C`
   (`IsStrictlyStandard.mul_right`).
4. **The parameters `π`.** Lemma 10.2 with this `n` and `e = 8c` gives `π₁, …, π_d`. Their
   images generate the maximal ideal of `Λ_q` and form a regular sequence there. Also
   `πᵢⁿ ∈ I`, and the annihilator conditions hold with exponent `8c`.
   - Make `Λ` an `R`-algebra by `xᵢ ↦ πᵢ`.
   - Write `πᵢⁿ = Σ λᵢⱼ f(aⱼ)`.
   - This defines `B → Λ` (`SmoothingAlgebra.lift`) and `f_C : C → B → Λ`.
5. **Lemma 9.2.** Apply `canBeResolved_of_sequence` to `R → C → Λ ⊃ q` and the sequence
   `x₁^c, …, x_d^c`.
   - The annihilator conditions in `R` come from `X_pow_annihilator`.
   - In `Λ`, the conditions with exponent `8c` give them for `πᵢ^c` (`pow_annihilator`).
   - Strict standardness comes from step 3.
   - The bottom condition is `bottomCondition_of_flat` (module `ArtinianBottom`).

   This gives a resolution `C → D → Λ` over `R`.
6. **Back to `k`.** Make `D` a `k`-algebra through `R`. It is finitely presented over `k`.
   The composite `A → B → C → D → Λ` equals `f`, because `C → B` is a retraction of
   `B → C`.
   - **`h_A ⊆ h_D`.** For a generator `aⱼ`: some power of `g(aⱼ)` is strictly standard in
     `C`, by Lemma 3.7(e) applied through `B_{aⱼ}` smooth. So `g(aⱼ) ∈ H_{C/R}` and
     `f(aⱼ) ∈ h^R_C ⊆ h^R_D ⊆ h^k_D`. The last inclusion holds because `R` is smooth over
     `k`.
   - **`h_D ⊄ q`.** Since `h^R_D ⊄ q` and `h^R_D ⊆ h^k_D`, also `h^k_D ⊄ q`.
