# The coefficient claim of Stacks Lemma 11.1: inductive step

This module supports the proof of Stacks Project, *Smoothing Ring Maps*, Lemma 11.1
(Tag 07FG), in `ArtinianFlatSubalgebra`. All declarations are in the namespace
`Langlands.CommutativeAlgebra.Popescu.ArtinianFlat`. It formalizes the inductive step of the
"Claim" in the source proof.

Notation: `B` is a `k`-algebra with a ring map `π : B → κ` to a field (later the residue map),
and `t : Fin d → B` (the source's `λ₁, …, λ_d`). For a ring map `σ : κ → B` and a subfield
`F ⊆ κ`, `Ψ_σ(h) = eval₂ (σ ∘ (F → κ)) t h` evaluates `h ∈ F[x₁, …, x_d]` at `t` with
coefficients mapped by `σ`.

## Declarations

- `residue_eval₂ π σ hσ t ht ι h`: if `σ` is a section of `π` and `π(tᵢ) = 0`, then
  `π(Ψ_σ(h)) = ι(h(0))`. So the residue of a polynomial in `t` is its constant term.
- `eval₂_eq_add σ σ₁ t ht ι h`: if `(σ₁ x − σ x) tᵢ = 0` for all `x, i`, then
  `Ψ_{σ₁}(h) = Ψ_σ(h) + σ₁(h(0)) − σ(h(0))`. So changing `σ` by something killed by the `tᵢ`
  changes only the constant term.
- `eval₂_surjective π σ hσ t ht hn hspan`: assume `ker π` is nilpotent and generated by the
  `tᵢ`, and `σ` is a section of `π`. Then every element of `B` is a polynomial in `t` with
  coefficients in `σ(κ)`. This applies `mem_subring_of_nilpotent` to the range of `Ψ_σ`.
- `CoeffClaim k κ B π t` (definition, `Prop`): there are a section `σ` of `π` and a finitely
  generated subextension `F` of `κ / k` such that every `algebraMap k B a` is `Ψ_σ(h)` for
  some `h ∈ F[x₁, …, x_d]`. This is the source's claim: "the image of `k` in `Λ` is contained
  in `Ψ_σ(F[x₁, …, x_d])`".
- `coeffClaim_of_surjective p hV g hg π π' hπ hπk t ht hn hspan hsq hNI h'`: the inductive
  step. Let `g : B → B'` be a surjective `k`-algebra map with kernel `I`, and let `π' : B' → κ`
  satisfy `π' ∘ g = π` (`hπ`). Assume:
  - `π` restricts to the structure map on `k`: `π(a · 1) = a · 1` (`hπk`);
  - `I² = 0` (`hsq`) and `(ker π) I = 0` (`hNI`);
  - `ker π` is nilpotent and generated by the `tᵢ`, and `π(tᵢ) = 0`;
  - `k` has characteristic `p`;
  - `hV`: the kernel of `κ ⊗_k Ω_k → Ω_κ` is finitely generated.

  Then the claim for `(B', g ∘ t)` implies the claim for `(B, t)`.
  **Proof** (numbered as in the Lean comments):
  1. Lift the section `σ'` of `π'` to `σ₀ : κ → B` (`exists_lift_of_sq_zero`). It is a section
     of `π`.
  2. `g` maps `A = Ψ_{σ₀}(F'[x])` onto `A' = Ψ_{σ'}(F'[x])` with square-zero kernel. Lift
     `k → A'` to `τ : k → A` (`exists_lift_of_sq_zero` again). These are the source's `A` and
     `τ`, except that `A` is the image subring and not `F'[x]/(x)ⁿ`.
  3. `θ = i − τ : k → I` (with `i` the structure map). `I` is a `κ`-module via `σ₀`, and
     `σ₀(ā)` acts on `I` as `a` does, since `(ker π) I = 0`. So `θ` is a derivation. By
     `exists_derivation_approx'` there are `D : κ → I` and a finite `S ⊆ I` with
     `θ a − D ā = Σ_{s ∈ S} c_s(a) s`.
  4. `σ₁ = σ₀ + D` is a ring map, since `I² = 0`, and a section of `π`. Also `D(x) tᵢ = 0`.
  5. Each `s ∈ S` is `Ψ_{σ₀}(H_s)` with `H_s(0) = 0` (`eval₂_surjective`, `residue_eval₂`).
     Hence also `s = Ψ_{σ₁}(H_s)` (`eval₂_eq_add`).
  6. `F = F' ⊔ k(coefficients of the H_s)` is finitely generated, and each `H_s` has
     coefficients in `F`.
  7. For `a ∈ k`, write `τ(a) = Ψ_{σ₀}(h_a)` with `h_a ∈ F'[x]`. Then
     `a = Ψ_{σ₁}(h_a + Σ_s C(c_s(a)) H_s)`. Here `Ψ_{σ₁}(h_a) = τ(a) + D(ā)` because
     `h_a(0) = ā`, and `σ₁(c) s = σ₀(c) s` because `D(c) s ∈ I² = 0`.

  The source writes `θ(a) = Σ_{j ∈ J₀} a_j f_j` and expands the `f_j ∈ I` in the monomials of
  degree `n − 1` in the `λᵢ`. Here the `f_j` are the elements of `S`, expanded as arbitrary
  polynomials in `t` without constant term.
