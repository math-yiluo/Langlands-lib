# `δ` and `Ω` for a presentation `B' = B[x]/(x_j^p − b_j)`

This module formalizes the presentation step of Faltings' proof of Stacks, More on Algebra,
Proposition 15.36.1 (07E5), (2) ⇒ (4). For `A' = A[x]/(x_j^p − a_j)`, the proof uses that
`Ω_{A'/A}` is free of rank `n`. It also uses that the image of `H₁(L_{A'/A})` in
`Ω_{A/𝔽_p} ⊗ A'` is spanned by the `da_j ⊗ 1`; the source obtains this by unwinding Stacks,
Algebra, Lemma 10.134.4. The module proves both facts for an arbitrary commutative ring `B`.
All declarations live in `Langlands.CommutativeAlgebra.Popescu.Faltings`. Throughout,
`Q : Algebra.Generators B B' (Fin n)` is a presentation whose kernel `Q.ker` equals
`rootIdeal p b` (`hker`).

## `pow_char_D`

If `p = 0` in `S`, then `d(x^p) = p x^{p−1} dx = 0` in `Ω_{S/R}`.

## `δAux_mem_of_mem_span`

Mathlib computes the Jacobi–Zariski connecting map `δ : H₁(L_{T/S}) → T ⊗_S Ω_{S/R}` through an
auxiliary map `δAux R Q : Q.Ring → T ⊗_S Ω_{S/R}`. Let `f_j ∈ Q.Ring` vanish in `T`, and let `N`
be a submodule containing every `δAux (f_j)`. Then `N` contains `δAux g` for every `g` in the ideal
generated by the `f_j`.

Proof: write `g = Σ h_j f_j`. Then `δAux (h_j f_j) = h_j(val) • δAux f_j + f_j(val) • δAux h_j`
(`δAux_mul`), and the second term vanishes because `f_j(val) = 0`. The lemma is stated for an
abstract presentation `Q`. This avoids an instance clash between the `Generators` algebra
structure and the quotient algebra structure that appears with a concrete quotient.

## `val_pow_eq`, `mapBaseChange_one_tmul_D`

- `val_pow_eq`: the generators satisfy `(val j)^p = b_j` in `B'`, because `x_j^p − b_j ∈ Q.ker`.
- `mapBaseChange_one_tmul_D`: if `p = 0` in `B'`, then `1 ⊗ db_j` maps to
  `d(b_j) = d((val j)^p) = 0` in `Ω_{B'/ℤ}`.

## `range_δ_le_span`

The image of `δ : H₁(L_{B'/B}) → B' ⊗_B Ω_{B/ℤ}` is contained in the `B'`-span of the `1 ⊗ db_j`.

Proof:
1. By Mathlib's `δ_comp_equiv`, `δ` on the canonical presentation agrees with `δ` computed on the
   presentation `Q`.
2. An element of `H₁` for `Q` is the class of some `g ∈ Q.ker = rootIdeal p b`, and its image is
   `δAux g` (`δ_eq_δAux`).
3. `δAux(x_j^p − b_j) = δAux(x_j^p) − 1 ⊗ db_j = −(1 ⊗ db_j)`. Here `δAux` of a monomial with
   coefficient `1` is `1 ⊗ d1 = 0`.
4. `δAux_mem_of_mem_span` concludes.

## `exists_kaehler_basis`

If `p = 0` in `B'`, then `Ω_{B'/B}` has a basis `e` with `e_j = d(val j)`.

Proof:
1. The conormal module `Q.ker/Q.ker²` is spanned by the classes of the `x_j^p − b_j`.
2. Their images in the cotangent space `B' ⊗ Ω_{B[x]/B}` vanish, because all partial derivatives of
   `x_j^p − b_j` are multiples of `p`. So the cotangent complex of `Q` is zero.
3. By exactness of `Q.ker/Q.ker² → B' ⊗ Ω_{B[x]/B} → Ω_{B'/B} → 0`, the map `toKaehler` is then an
   isomorphism.
4. The standard basis `dx_j` of the cotangent space (`cotangentSpaceBasis`) is transported along it.
