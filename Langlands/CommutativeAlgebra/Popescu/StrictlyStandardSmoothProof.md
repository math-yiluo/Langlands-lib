# Proof: inverting a strictly standard element gives a smooth algebra

`Langlands.CommutativeAlgebra.Popescu.strictlyStandardSmooth :
StrictlyStandardSmoothStatement.{u}` proves the Library statement
`Langlands.CommutativeAlgebra.Popescu.StrictlyStandardSmoothStatement`: if `a` is strictly
standard in `A` over `R` (`IsStrictlyStandard R a`), then `Localization.Away a` is smooth over
`R`. The source is Stacks Project, *Smoothing Ring Maps*, Lemma 3.7(d) (Tag 07EZ). The source
proof uses Lemma 2.5 (07CA) for smoothness and Lemma 2.4 (07ET) for the conormal module.

The Lean proof takes a different route. It checks the infinitesimal lifting property
directly, by a first-order Newton correction, and does not use conormal modules.

## Auxiliary lemmas (namespace `Langlands.CommutativeAlgebra.Popescu.StrictlyStandardSmooth`)

- `aeval_add_of_mul_eq_zero`: for `t, δ : σ → T` (with `σ` finite) such that `δᵢ δⱼ = 0` for
  all `i, j`, every `p ∈ R[x_σ]` satisfies `p(t + δ) = p(t) + Σᵢ (∂ᵢ p)(t) δᵢ`. The proof is
  by induction on `p` (constants, sums, multiplication by a variable).
- `exists_right_inverse`: let `M` be a `c × n` matrix whose `c × c` minors
  `Mₑ = M.submatrix id e` (columns `e : Fin c ↪o Fin n`) satisfy `Σₑ rₑ det(Mₑ) = 1` for a
  finitely supported `r`. Then `M` has a right inverse `N = Σₑ rₑ · Pₑ · adj(Mₑ)`. Here `Pₑ`
  is the `n × c` matrix with `(Pₑ)_{i,k} = 1` if `i = e(k)` and `0` otherwise, so that
  `M Pₑ = Mₑ`. The matrix `adj` is `Matrix.adjugate`, and the proof uses `Matrix.mul_adjugate`.
- `exists_right_inverse_of_mem_span`: the same conclusion for a matrix `M` over `S`, given a
  ring map `κ : A → S`, elements `Dₑ ∈ A` with `κ(Dₑ) = det(Mₑ)`, `a ∈ (Dₑ)ₑ`, and `u` with
  `u κ(a) = 1`. Write `a = Σ wₑ Dₑ` as a finsupp combination and apply the previous lemma
  with `rₑ = u κ(wₑ)`.

## Main proof

Unpack `IsStrictlyStandard R a`:
- a surjective presentation `φ : R[x₁, …, xₙ] → A` with kernel `(f₁, …, f_m)`;
- `a ∈ (φ(Δₑ))ₑ`, where `Δₑ` are the `c × c` minors of the Jacobian of the first `c`
  relations;
- a lift `g` of `a` with `g f_j ∈ (f₁, …, f_c) + (f₁, …, f_m)²` for `j ≥ c`.

**Finite presentation.** `A` is finitely presented over `R`, since `ker φ` is generated by
the finitely many `fⱼ`. `A_a` is finitely presented over `A`
(`IsLocalization.Away.finitePresentation`), hence over `R`
(`Algebra.FinitePresentation.trans`).

**Formal smoothness.** This is checked with `Algebra.FormallySmooth.of_comp_surjective`. Let
`T : Type u` be an `R`-algebra, let `J ⊆ T` be an ideal with `J² = 0`, and let
`ψ : A_a → T/J` be an `R`-algebra map. Write `θ : A → T/J` for the composite of `ψ` with
`A → A_a`.

1. **Lift the variables.** Choose `t ∈ Tⁿ` with `tᵢ ↦ θ(φ(xᵢ))` in `T/J`. Then
   `p(t) ↦ θ(φ(p))` for every polynomial `p`, so `fⱼ(t) ∈ J` for every `j`.
2. **Correct them.** The element `ū = ψ(1/a)` satisfies `ū θ(a) = 1`. By
   `exists_right_inverse_of_mem_span` with `κ = θ`, the Jacobian matrix
   `(θ(φ(∂ᵢ f_j)))_{j < c, i ≤ n}` over `T/J` has a right inverse. Lift its entries to a
   matrix `Ñ` over `T` and set `δᵢ = −Σₖ Ñᵢₖ fₖ(t)` (sum over `k < c`). Then every `δᵢ ∈ J`,
   so `δᵢ δⱼ = 0`, and `p(t + δ) ≡ p(t)` modulo `J` for every polynomial `p`.
3. **The first `c` relations.** For `k < c`, the Taylor formula gives
   `fₖ(t + δ) = fₖ(t) − Σₗ (Σᵢ (∂ᵢ fₖ)(t) Ñᵢₗ) fₗ(t)`. Each coefficient
   `Σᵢ (∂ᵢ fₖ)(t) Ñᵢₗ` is congruent to `[k = l]` modulo `J`, and `fₗ(t) ∈ J` with `J² = 0`,
   so the sum is `fₖ(t)` and `fₖ(t + δ) = 0`.
4. **The remaining relations.** `g(t + δ)` is a unit of `T`: if `v` lifts `ū`, then
   `ε = g(t + δ) v − 1 ∈ J`, so `ε² = 0` and `g(t + δ) · v(1 − ε) = 1`. For `j ≥ c`, evaluate
   `g fⱼ ∈ (f_{<c}) + (f)²` at `t + δ`. The image of `(f_{<c})` is `0` by step 3, and the
   image of `(f)²` lies in `J² = 0`, since every `fᵢ(t + δ) ∈ J`. Hence
   `g(t + δ) fⱼ(t + δ) = 0`, and therefore `fⱼ(t + δ) = 0`.
5. **The lift.** Evaluation at `t + δ` kills `ker φ = (f₁, …, f_m)`, so it descends to an
   `R`-algebra map `ρ : A → T` (`AlgHom.liftOfSurjective`). It sends `a = φ(g)` to the unit
   `g(t + δ)`, so it extends to a ring map `A_a → T` (`IsLocalization.Away.lift`), which is
   an `R`-algebra map. Composed with `T → T/J`, it agrees with `ψ` on the image of `A`,
   because `t + δ ≡ t` modulo `J`. Hence it agrees with `ψ` on all of `A_a`
   (`IsLocalization.ringHom_ext`).

The proof uses only the axioms `propext`, `Classical.choice` and `Quot.sound`.
