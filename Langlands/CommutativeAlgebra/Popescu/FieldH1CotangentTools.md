# `H₁` of field extensions: vanishing over perfect fields and naturality of `δAux`

All objects are Mathlib's naive cotangent complex. `H₁(L_{L/F})` is `Algebra.H1Cotangent F L`, the
`H₁` of the canonical presentation `F[L] → L` (`Algebra.Generators.self F L`).

## `defaultHom_self_toAlgHom`

For `K → L → M`, the default hom of presentations `K[L] → K[M]` (`Generators.defaultHom`) is
renaming of variables along `L → M`. Both are `K`-algebra maps sending `X_l` to `X_{l}`.

## `subsingleton_h1Cotangent_of_perfectField`

For a perfect field `F` and any field extension `L/F`, `H₁(L_{L/F}) = 0`. No finiteness is assumed
on `L/F`.

Proof:
1. An element of `H₁` is the class of a polynomial `f ∈ F[L]` with `f(id) = 0` and `1 ⊗ df = 0`,
   that is, all partial derivatives of `f` vanish at the tautological point.
2. Let `L'` be the subfield generated by the finitely many variables of `f`, so `f = rename f'`
   with `f' ∈ F[L']`.
3. `f'` also vanishes at the point. Its partial derivatives vanish too, by `pderiv_rename` and
   injectivity of `L' → L`. So `f'` defines an element of `H₁(L_{L'/F})`, which maps to the class
   of `f` under `H1Cotangent.map F F L' L`.
4. `L'/F` is finitely generated (`IntermediateField.essFiniteType_iff`). Over a perfect field it is
   therefore formally smooth (Mathlib's `Algebra.FormallySmooth.of_perfectField`), so
   `H₁(L_{L'/F}) = 0`.

Stacks, Algebra, Proposition 10.158.9 (Tag 0322; source `stacks-commutative-algebra-chapter-ed88ff78`,
PDF page 434) shows that `H₁(L_{L/F}) = 0` when `L/F` is separable. Every extension of a perfect
field is separable, so this lemma is that special case. The colimit argument above is original to
this formalization.

## `δAux_rename`

Mathlib defines the Jacobi–Zariski connecting map through an explicit auxiliary map
`δAux R Q : S[T] → T ⊗_S Ω_{S/R}`, sending `∏ X_t^{n_t} · s` to `∏ t^{n_t} ⊗ ds`.

For `T → T'`, `δAux` for `T'` applied to a renamed polynomial equals `cancelBaseChange (1 ⊗ δAux g)`,
where `cancelBaseChange : T' ⊗_T (T ⊗_S Ω) ≅ T' ⊗_S Ω`.

The proof is by induction on the polynomial: constants, sums, and multiplication by a variable, via
`δAux_mul` and `δAux_X`.
