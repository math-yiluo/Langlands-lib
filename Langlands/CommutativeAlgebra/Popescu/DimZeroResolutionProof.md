# Proof: resolving the local problem at a minimal prime

Module `Langlands.CommutativeAlgebra.Popescu.DimZeroResolutionProof`.
Author: Worker 2971 (Task 6374).

## Statement proved

The theorem `Langlands.CommutativeAlgebra.Popescu.dimZeroResolution` proves the published
proposition `Langlands.CommutativeAlgebra.Popescu.DimZeroResolutionStatement.{u}` exactly,
with no hypotheses. That proposition is in module
`Langlands.CommutativeAlgebra.Popescu.DimZeroResolutionStatement`.

The proposition says the following. Let `R` and `Λ` be Noetherian rings, `A` a finitely
presented `R`-algebra, `f : A →ₐ[R] Λ` and `q` a prime of `Λ`, all in `Type u`. Assume
`h_A ⊆ q` (`singularRadical R f ≤ q`), `q ∈ minimalPrimes Λ`, and property PT for `Λ_q`
(`HasSmoothFactorizations R (Localization.AtPrime q)`). Then `R → A → Λ ⊃ q` can be resolved
(`CanBeResolved R f q`). This is Stacks, *Smoothing Ring Maps*, Lemmas 9.3 and 9.4
(Tags 07F9 and 07FA, printed p. 23), in the form used in the proof of Lemma 10.3
(Tag 07FE). The statement's Markdown gives the source and the encoding.

## Route

The Lean proof does not follow Stacks' proof. Stacks works with presentations and
strictly standard elements. The Lean proof builds the resolving algebra `B` directly as a
finitely generated `R`-subalgebra of the product `D × A × Λ`, where `D = C[X]_X` and `C` is
the smooth algebra given by PT. It uses no unproved Library statement; in particular it does
not use `LocalizationStandardDescentStatement` or `StrictlyStandardSmoothStatement`.

Notation: `H_{A/R}` is `singularIdeal R A`, `h_A` is `singularRadical R f`, `Λ_q` is
`Localization.AtPrime q`, and `A_a`, `Λ_{f(a)}`, `D = C[X]_X` are `Localization.Away`.

## Helper lemmas (namespace `DimZeroResolutionProof`)

- `mem_singularIdeal_of_smooth`: if `B` is finitely presented over `R` and `B_e` is smooth
  over `R`, then `e ∈ H_{B/R}`. `smooth_away_of_mem_singularIdeal`: if `A` is finitely
  presented and `a ∈ H_{A/R}`, then `A_a` is smooth over `R`. Both follow from Mathlib's
  `Algebra.basicOpen_subset_smoothLocus_iff_smooth` and the definition of `H_{A/R}` as the
  vanishing ideal of the complement of the smooth locus.
- `smooth_away_of_isLocalization`: let `φ : B →ₐ[R] Y` with `Y` smooth over `R`. Assume
  `φ e` is a unit, every `y : Y` has the form `y · φ(e)^n = φ(b)`, and `φ b = 0` implies
  `e^n b = 0` for some `n`. Then `B_e` is smooth over `R`. The three conditions make `Y` a
  localization of `B` away from `e` (`IsLocalization.Away.mk`). Then `B_e ≅ Y` as
  `R`-algebras.
- `exists_mul_eq_zero_of_algebraMap_eq_zero`: for a prime `q` of a Noetherian ring `Λ`,
  some `s ∉ q` kills the kernel `K` of `Λ → Λ_q`. Since `K` is a finite `Λ`-module with
  `K_q = 0`, `q` is not in its support, so `Ann(K) ⊄ q`.
- `exists_pow_algebraMap_eq_zero`: if `q` is a minimal prime and `x ∈ q`, then
  `x^(n+1) ↦ 0` in `Λ_q` for some `n`. Here `Λ_q` has a single prime, so its image of `x`,
  which lies in the maximal ideal, is nilpotent.
- `pow_mul_eq_zero_of_le`: `x^k y = 0` and `k ≤ m` give `x^m y = 0`.
- `away_X_induction`: an induction principle for `C[X]_X`, where `C` is generated over `R`
  by a finite set `tc`. A property holds on all of `C[X]_X` if it is closed under `+` and
  `·`, holds on the image of `R`, on `X` and on each `c ∈ tc`, and passes from
  `y · X^m` to `y`. The proof uses `Algebra.adjoin` for `C`, polynomial induction for
  `C[X]`, and `IsLocalization.Away.surj`.

## Main proof (`dimZeroResolution`)

1. *Choices in `A` and `Λ`.* `A` is Noetherian (finite type over Noetherian `R`), so
   `H_{A/R}` is generated by a finite set `t`. Choose `s ∉ q` killing `ker(Λ → Λ_q)`. For
   `a ∈ t` we have `f(a) ∈ h_A ⊆ q`, so by minimality some `f(a)^(n_a+1)` maps to `0` in `Λ_q`.
   Hence `s · f(a)^(n_a+1) = 0` in `Λ`. Consequently `s · y ↦ 0` in `Λ_{f(a)}` for every
   `y : Λ` and `a ∈ t`.
2. *The smooth algebra `D`.* PT applied to `A → Λ → Λ_q` gives `g : A → C` and
   `ψ : C → Λ_q` with `ψ ∘ g = (A → Λ_q)` and `C` smooth over `R`. Choose finite generators
   `tc` of `C` over `R` and a common denominator `u ∉ q`, with `u · ψ(c) = l_c / 1` for
   `c ∈ tc` (`IsLocalization.exist_integer_multiples`). Let `D = C[X]_X`. It is smooth over
   `R`: `C[X]` is smooth over `C`, hence over `R`, and `D` is a localization of `C[X]`.
   Since `su ∉ q`, the image `su/1` is a unit of `Λ_q`. So `ψ` extends to
   `ψD : D →ₐ[R] Λ_q` with `X ↦ su/1` (`Polynomial.aevalTower` and
   `IsLocalization.Away.liftAlgHom`).
3. *The fibre-product algebra `P`.* `P ⊆ D × A × Λ` is the `R`-subalgebra of triples
   `(d, a', λ)` with `ψD(d) = λ/1` in `Λ_q` and `f(a') = λ` in `Λ_{f(a)}` for every
   `a ∈ t`. The map `ι : A → D × A × Λ`, `a' ↦ (g(a'), a', f(a'))`, lands in `P`. So do the
   elements
   - `e1 = (X, 0, su)`,
   - `β_c = (c·X, 0, s·l_c)` for `c ∈ tc`,
   - `e2_a = (0, a^(n_a+1), f(a)^(n_a+1))` for `a ∈ t`.

   The checks use step 1: `s · y ↦ 0` in each `Λ_{f(a)}` and `f(a)^(n_a+1) ↦ 0` in `Λ_q`.
   For `β_c` they also use `ψD(c·X) = ψ(c) · su/1 = s·l_c/1`.
4. *The algebra `B`.* `B = ι(A) ⊔ R[e1, β_c, e2_a]`, a finitely generated `R`-subalgebra
   contained in `P`. It is of finite type, hence of finite presentation because `R` is
   Noetherian (`Algebra.FinitePresentation.of_finiteType`). The factorization is
   `g_B : A → B` (the corestriction of `ι`) and `h_B : B → Λ` (the third projection), with
   `h_B ∘ g_B = f`.
5. *`e1 ∈ H_{B/R}`.* Apply `smooth_away_of_isLocalization` to the first projection
   `φ1 : B → D`. `φ1(e1) = X` is a unit of `D`. Every element of `D` has the form
   `φ1(b) / X^n`, by `away_X_induction`: `R` and `C` are reached through `ι`, `X = φ1(e1)`,
   and `c ∈ tc` satisfies `c · X = φ1(β_c)`. If `φ1(b) = 0`, then `b = (0, a', λ)` with
   `λ/1 = ψD(0) = 0` in `Λ_q`. So `sλ = 0`, and `e1 · b = (0, 0, suλ) = 0`. Hence
   `B_{e1} ≅ D` is smooth and `e1 ∈ H_{B/R}`.
6. *`e2_a ∈ H_{B/R}` for `a ∈ t`.* Apply `smooth_away_of_isLocalization` to
   `φ2 : B → A_a`, the second projection followed by `A → A_a`. `φ2(e2_a) = (a/1)^(n_a+1)`
   is a unit. Every element `a'/a^m` of `A_a` equals
   `φ2(g_B(a' · a^(n_a·m))) / φ2(e2_a)^m`. If `φ2(b) = 0` for `b = (d, a', λ)`, then
   `a^k a' = 0` for some `k`. Membership in `P` gives `f(a)^k' f(a') = f(a)^k' λ` for some `k'`.
   Hence `f(a)^(k+k') λ = 0`, and `e2_a^(k+k'+1) · b = 0`: the first coordinate is `0`, and
   the other two vanish because `(n_a+1)(k+k'+1) ≥ k+k'`. `A_a` is smooth because
   `a ∈ H_{A/R}`. Hence `B_{e2_a}` is smooth and `e2_a ∈ H_{B/R}`.
7. *Conclusion.* `h_A ⊆ h_B`: `H_{A/R}Λ` is generated by the `f(a)`, `a ∈ t`, and
   `f(a)^(n_a+1) = h_B(e2_a) ∈ H_{B/R}Λ`. `h_B ⊄ q`: `h_B(e1) = su ∈ H_{B/R}Λ` and `su ∉ q`.
