Provenance: internal, adapted from S. L. Kleiman, *The Picard scheme*
(`kleiman-2005-picard-scheme-arxiv-math0504020v1`), proof of Lemma 3.4,
pp.22–23. Kleiman tensors the sequences `0 → I → B → C → 0` and
`0 → K → B → I → 0` with the residue field `k` of the base, uses that the
Tor terms vanish because `C` (and then `I`) is flat over the base, and
concludes with Nakayama's lemma over the local ring `B`. Here the residue
field is replaced by a local ring `T` that is flat over a pushout
`S = R ⊗[A] A'`, and Nakayama's lemma is used along the local homomorphism
`R → T`. The ring `R` is not assumed local. So the conclusions hold after
inverting one element `g` of `R` that becomes a unit in `T`. Kleiman's local
criterion of flatness is not needed.

## Tor vanishing (section `TorInj`)

Throughout, `A → R`, `A → A'`, `R → S`, `A' → S` are ring maps with
`Algebra.IsPushout A R A' S`, so that `S = R ⊗[A] A'`.

- `baseChangeEquiv A R A' S N`: for an `R`-module `N`, the `A`-linear
  isomorphism `A' ⊗[A] N ≃ S ⊗[R] N`. It sends `a ⊗ n` to
  `(image of a in S) ⊗ n` (`baseChangeEquiv_tmul`). It is built from
  `TensorProduct.AlgebraTensorModule.cancelBaseChange` and the pushout
  isomorphism `R ⊗[A] A' ≃ S`.
- `lTensor_injective_pushout`: let `0 → N → M → C → 0` be an exact sequence
  of `R`-modules (`g` injective, `f` surjective, `Function.Exact g f`), with
  `C` flat over `A`. Then `S ⊗[R] N → S ⊗[R] M` is injective. Proof: Mathlib's
  `LinearMap.lTensor_injective_of_exact_of_flat` gives injectivity of
  `A' ⊗[A] N → A' ⊗[A] M`, and `baseChangeEquiv` identifies this map with
  `S ⊗[R] N → S ⊗[R] M`.
- `lTensor_injective_of_flat`: the same for `T ⊗[R] N → T ⊗[R] M`, where `T`
  is an `S`-algebra that is flat over `S`. Proof: tensor the previous
  injection with `T` over `S` and cancel the base change
  `T ⊗[S] (S ⊗[R] N) ≃ T ⊗[R] N`.

## Nakayama along a local homomorphism (section `Nakayama`)

- `exists_smul_eq_zero_of_subsingleton`: let `T` be a local `R`-algebra and
  `M` a finite `R`-module with `T ⊗[R] M = 0`. Then there is `g : R` whose
  image in `T` is a unit and with `g • m = 0` for all `m : M`.

  Proof. Let `p` be the preimage in `R` of the maximal ideal of `T`. If no
  such `g` exists, the annihilator of `M` lies in `p`. Since `M` is finite,
  `p` is in the support of `M`
  (`Module.mem_support_iff_of_finite`), so `κ(p) ⊗[R] M ≠ 0`
  (`Module.mem_support_iff_nontrivial_residueField_tensorProduct`). The map
  `R → K` to the residue field `K` of `T` factors through `κ(p)`
  (`Ideal.ResidueField.lift`), so `K ⊗[κ(p)] (κ(p) ⊗[R] M) ≅ K ⊗[R] M ≅
  K ⊗[T] (T ⊗[R] M) = 0`. A nonzero vector space stays nonzero after a field
  extension, a contradiction.

## Flatness of the ideal (section `Ideals`)

- `flat_ideal`: if `R` and `R ⧸ I` are flat over `A`, so is the ideal `I`
  (Kleiman, p.23: "Since B and C are A-flat ... also I is A-flat"). Proof:
  for an injective `A`-linear `L : N → N'`, compare `I ⊗ N → I ⊗ N'` with
  `R ⊗ N → R ⊗ N'` (all over `A`). The map `I ⊗ N → R ⊗ N` is injective
  because `R ⧸ I` is flat, and `R ⊗ N → R ⊗ N'` is injective because `R` is
  flat; so the composite, and hence `I ⊗ N → I ⊗ N'`, is injective.

## Generators in a local ring (section `Generators`)

- `isSMulRegular_of_mem_span`: if a regular element `s` lies in `(a)`, then
  `a` is regular.
- `exists_isUnit_of_span_eq_top`: in a local ring, if a set generates the
  unit ideal, one of its members is a unit.
- `exists_mem_map_eq_span`: let `φ : R → T` be a ring map to a local ring
  and `I` an ideal of `R` with `I.map φ = (s)`, `s` regular. Then there is
  `f ∈ I` with `I.map φ = (φ f)` and `φ f` regular. Proof: let `J` be the
  ideal of `T` generated by all `b` with `φ x = b * s` for some `x ∈ I`. Then
  `I.map φ ⊆ J · (s)`, so `s = z * s` with `z ∈ J`. Regularity of `s` gives
  `z = 1`, so `J = ⊤`, and some generator `b` of `J` is a unit. The
  corresponding `x ∈ I` has `φ x = b * s`.

## Lifting generators and regularity (section `Lift`)

In this section, `A → R → S` and `A → A' → S` form a pushout as above, and `T`
is a local `S`-algebra, flat over `S`, with `IsScalarTower R S T`.

- `exists_mul_eq_of_map_eq_span` (Kleiman, proof of Lemma 3.4, (ii) ⟹ (iii)):
  let `R` be noetherian, `I` an ideal of `R` with `R ⧸ I` flat over `A`, and
  `f ∈ I` such that the extension of `I` to `T` is generated by the image of
  `f`. Then there is `g : R`, a unit in `T`, such that for every `x ∈ I` there
  is `r : R` with `g * x = r * f`.

  Proof. By `lTensor_injective_of_flat` for `0 → I → R → R ⧸ I → 0`, the map
  `ι : T ⊗[R] I → T` is injective. Its image is `I.map (R → T) = (f)`, so
  every element of `T ⊗[R] I` has the form `c ⊗ f`. Hence `T ⊗[R] (I ⧸ R f)`
  vanishes. The module `I ⧸ R f` is finite since `R` is noetherian, and
  `exists_smul_eq_zero_of_subsingleton` gives `g`.
- `exists_mul_eq_zero_of_isSMulRegular` (Kleiman, proof of Lemma 3.4,
  (iii) ⟹ (i)): let `R` be noetherian and flat over `A`, and `f : R` with
  `R ⧸ (f)` flat over `A`. If the image of `f` in `T` is regular, there is
  `g : R`, a unit in `T`, with `g * r = 0` whenever `r * f = 0`.

  Proof. The ideal `(f)` is flat over `A` (`flat_ideal`). Let
  `μ : R → (f)`, `r ↦ r f`, and `K = ker μ`. By `lTensor_injective_of_flat`
  for `0 → K → R → (f) → 0`, `T ⊗[R] K → T ⊗[R] R` is injective. The
  composite `T ⊗[R] R → T ⊗[R] (f) → T` is multiplication by the image of `f`,
  which is injective. Hence `T ⊗[R] K = 0`. The module `K` is finite since
  `R` is noetherian, and `exists_smul_eq_zero_of_subsingleton` gives `g`.

## Inverting one element (section `Away`)

Let `R_g` be a localization of `R` away from `g` (`IsLocalization.Away g R_g`).

- `map_eq_span_of_mul_eq`: if `f ∈ I` and for every `x ∈ I` there is `r` with
  `g * x = r * f`, then `I.map (R → R_g) = (f)`.
- `isSMulRegular_of_mul_eq_zero`: if `g * r = 0` whenever `r * f = 0`, then
  the image of `f` in `R_g` is regular.
