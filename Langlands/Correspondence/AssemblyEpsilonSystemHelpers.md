# Local-constant system helpers for epsilon inheritance

This internal development follows directly from the published correspondence
predicates and the existing scalar character-line construction.

A character acts by scalars on a universe-lifted copy of the complex line.
That line is a simple complex module, so each subrepresentation is either zero
or the whole line. The existing rank and continuity proofs therefore give an
actual continuous irreducible rank-one class, with an arbitrary carrier
universe. Taking the trivial character supplies a test class over every local
Weil group.

The self-dual measure theorem specializes
`SupercuspidalPairFactorCompatibility` at that test class in both arguments.
The existence of a self-dual measure is an explicit conjunct of the specialized
predicate. The correspondence version extracts its witnessed local-constant
system and applies the same theorem. These lemmas do not prove epsilon
inheritance or geometric reciprocity uniqueness.
