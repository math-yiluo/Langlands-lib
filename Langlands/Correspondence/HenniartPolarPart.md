# The polar-part model `ν(n, f, s; q)` of the numerical local Langlands route

This module defines the polar-part model of the operator route note and states
three propositions about it: the closed formula, the counting identity, and a
truncated form of the converse of the counting identity. It contains definitions
and `Prop`-valued statements only. It proves none of the statements; the one
proof in the file is the routine check that the admissible maps form a
Galois-stable set, which `polarParts` needs as a structure field.

Proposition 5.12 (b) applies, for `f = 1`.

## Encoding of the model

Everything below is in the namespace `Langlands.Henniart.Numerical`.

### Fields

For `q = p ^ a` a prime power, `p = q.minFac` and `a = q.factorization p`.

- `polarBaseField q` is `GaloisField p a`, a field with `q` elements; it plays
  the role of `𝔽_q`. It takes the instance argument `[Fact q.minFac.Prime]`.
- `polarExtensionField q f` (for `f ≥ 1`, instance argument `[NeZero f]`) is
  Mathlib's `FiniteField.Extension (polarBaseField q) p f`, a chosen extension
  of `polarBaseField q` of degree `f` with its `Algebra` structure. It has
  `q ^ f` elements and plays the role of `𝔽_{q^f}`.

Any fixed field with `q ^ f` elements would do. Since `ν` is a number of
orbits, it does not depend on the choice up to isomorphism. The extension is
used with its `Algebra (polarBaseField q)` structure, because condition (P2)
and the Galois group refer to the subfield `𝔽_q`. The group
`Gal(𝔽_{q^f}/𝔽_q)` is cyclic of order `f`, generated by the `q`-power
Frobenius `x ↦ x ^ q`, so its orbits are the orbits of that Frobenius. The
Lean definition uses the whole group `Gal(L/k)` (Mathlib's `L ≃ₐ[k] L`).

### Admissible maps and orbits

These definitions work for any field extension `L/k` (`[Field k] [Field L]
[Algebra k L]`) and numbers `r, m`. In the model, `k = 𝔽_q`, `L = 𝔽_{q^f}`,
`r = n / f` and `m = s / f`.

- A map `c : {0, …, m} → L` is a function `Fin (m + 1) → L`.
- `polarSupportGcd c` is the gcd of the finite set of numbers
  `{i : 1 ≤ i ≤ m, c i ≠ 0}` (`Finset.gcd`). It is `0` when the set is empty.
- `IsPolarPart k r m c` is the conjunction of
  - (P1) `c 0 ≠ 0` and `c m ≠ 0` (`c (Fin.last m) ≠ 0`);
  - (P2) `IntermediateField.adjoin k (Set.range c) = ⊤`: the values of `c`
    generate `L` over `k`;
  - (P3) `Nat.gcd r (polarSupportGcd c) = 1`. The gcd of `r` and a finite set
    of numbers is `gcd(r, gcd of the set)`. When the set is empty,
    `polarSupportGcd c = 0` and `Nat.gcd r 0 = r`. This is the note's
    convention `gcd(n/f, ∅) = n/f`.
- `polarParts k L r m` is the set of maps satisfying (P1)–(P3), as a
  `SubMulAction` of `Gal(L/k)` on `Fin (m + 1) → L`. The group acts on maps
  value by value: `(g • c) i = g (c i)`. The structure field `smul_mem'`
  proves that the set is stable: `g` preserves non-vanishing, maps the field
  generated by the values to the field generated by the new values (so (P2)
  is preserved), and does not change the support `{i : c i ≠ 0}`.
- `PolarPartModel k L r m` is the orbit space
  `MulAction.orbitRel.Quotient Gal(L/k) (polarParts k L r m)`, the set of
  `Gal(L/k)`-orbits of admissible maps. This is `𝒫(n, f, s; q)`.
- `polarPartCountOf k L r m` is `Nat.card (PolarPartModel k L r m)`.

### The numbers `ν` and `τ`

- `polarPartCount q n f s` is `ν(n, f, s; q)`. If `q` is a prime power,
  `n ≥ 1`, `f ≥ 1`, `f ∣ n` and `f ∣ s`, it is
  `polarPartCountOf (polarBaseField q) (polarExtensionField q f) (n / f) (s / f)`:
  the number of `Gal(𝔽_{q^f}/𝔽_q)`-orbits of maps
  `c : {0, …, s/f} → 𝔽_{q^f}` satisfying (P1)–(P3) with `r = n/f`. In every
  other case the value is `0`: when `q` is not a prime power (a documented
  choice; the note only uses prime powers), and when `n = 0`, `f = 0`,
  `f ∤ n` or `f ∤ s` (the convention needed by statements that range over
  all `(s, f)`).
- `polarTwistCount q n s` is `τ(n, s; q)`, defined as `polarPartCount q n 1 s`.

## The three statements

Everything below is in the namespace `Langlands.Henniart`. Here `μ` is
`ArithmeticFunction.moebius`, `Σ_{i ∣ f}` runs over `f.divisors`, and `/` on
natural numbers is floor division. Each statement quantifies over every prime
power `q` (`IsPrimePow q`).

### `PolarPartClosedFormulaStatement` (route note, Lemma 3.2, `lem:nu`)

For every prime power `q` and all `n, f, s` with `n ≥ 1`, `f ≥ 1`, `f ∣ n`,
`f ∣ s`:

- if `s ≥ 1`, then with `m = s / f`, in `ℤ`,
  `f · ν(n, f, s; q) = Σ_{i ∣ f} μ(f/i) (q^i − 1)² Σ_{e ∣ gcd(n/f, m)} μ(e) q^{i(m/e − 1)}`;
- if `s = 0`, then `ν(n, f, 0; q) = 0` when `f ≠ n`, and, in `ℤ`,
  `n · ν(n, n, 0; q) = Σ_{i ∣ n} μ(n/i) (q^i − 1)`.

The note writes the formulas with a factor `1/f` (resp. `1/n`) on the right.
The Lean statement multiplies both sides by `f` (resp. `n`), which is
equivalent since `f, n ≥ 1`. The exponent `i (m/e − 1)` uses natural
subtraction; it is exact, because `e ∣ m` and `m ≥ 1` give `m/e ≥ 1`.

### `PolarPartCountingIdentityStatement` (route note, Lemma 3.3, `lem:polar`, identity `eq:polar`)

For every prime power `q`, all `n ≥ 1`, `f ≥ 1` with `f ∣ n`, and every
`j ≥ 0`, in `ℤ`,
`f · Σ_{d ∣ n/f} Σ_{s ≥ 0, f ∣ s, d s ≤ j} ν(n/d, f, s; q) = Σ_{i ∣ f} μ(f/i) (q^i − 1) q^{i ⌊j/f⌋}`.

The note's right-hand side is `κ_f(j)`, which carries a factor `1/f`; the Lean
statement multiplies both sides by `f`. The inner sum is written over the
`s ∈ {0, …, j}` with `f ∣ s` and `d s ≤ j`. This is the same index set as in
the note, because every divisor `d` of `n/f` satisfies `d ≥ 1`, so `d s ≤ j`
forces `s ≤ j`.

### `PolarPartTruncatedUniquenessStatement` (converse of Lemma 3.3 for `f = 1`, truncated as in Proposition 5.12 (b))

For every prime power `q`, every bound `e ∈ ℕ` and every function
`T : ℕ → ℕ → ℕ∞` (first argument the rank `d`, second the Swan exponent `k`):
suppose that for all `n ≥ 1` and all `j` with `j < n · e`,
`Σ_{d ∣ n} Σ_{k ≥ 0, n k ≤ d j} T(d, k) = (q − 1) q^j` in `ℕ∞`.
Then `T(n, s) = τ(n, s; q)` for all `n ≥ 1` and all `s` with `s < n · e`.

Conventions: `n k ≤ d j` is the note's `k ≤ d j / n`, and `k` runs over all
natural numbers, including `k = 0` (route note, Remark 2.1). The inner sum is
written over `k ∈ {0, …, j}` with `n k ≤ d j`; this is the same index set,
because every divisor `d` of `n` satisfies `d ≤ n`, so `n k ≤ d j` forces
`k ≤ j`. The right-hand side is the natural number `(q − 1) q^j` cast to
`ℕ∞`; its natural subtraction is exact since `q ≥ 2`. The sum is taken in
`ℕ∞` so that `T` may a priori take the value `⊤` (an infinite count).

Why this form: in the uniqueness argument of Lemma 3.3, the identity at
`(n, j)` involves only values `T(d, k)` of slope `k/d ≤ j/n`, and the
difference of the identities at `(n, j)` and `(n, j − 1)` is
`Σ_{m ∣ gcd(n, j)} T(n/m, j/m)`, whose terms all have slope `j/n`; the term
`m = 1` is `T(n, j)` and the others have smaller rank. So the identities for
`j < n e` determine `T` on the range `s < n e`. This is the reasoning of the
proof of Proposition 5.12 (b); it is recorded here as motivation only, and the
module proves nothing.
