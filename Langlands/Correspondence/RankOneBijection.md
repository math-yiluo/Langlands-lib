# Actual rank-one character bijections

This internal development uses the actual class construction in
`RankOneExistence`. It proves that a genuine rank-one automorphic class
determines its continuous field character. Equivalences between scalar
character representations have the same determinant, so the characters
agree. Surjectivity of the GL₁ determinant recovers the field character
from its composition with the determinant. This proves injectivity of the
constructed class map. Together with its proved surjectivity it gives an
actual equivalence from continuous field characters to supercuspidal GL₁
classes, with independent field and representation carrier universes.

The same determinant argument shows uniqueness of the abstract Weil
character of an actual rank-one continuous irreducible class. Pullback
along a supplied reciprocity candidate is injective by the published
inverse field-character transport identity. No reciprocity candidate is
constructed, and no local-factor compatibility is asserted.
