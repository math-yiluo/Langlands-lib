# Two consecutive vanishing degrees for a `p`-group

This module proves `Langlands.Tate.pGroupTateVanishing : PGroupTateVanishing.{u}`,
the proposition of module `CohomologicalTrivialityStatement`: for a prime `p`, a
finite `p`-group `P : Type u`, a representation
`C : Rep.{u} IntegralScalar.{u} P` and an integer `q`, if `tateCohomology C q`
and `tateCohomology C (q + 1)` are zero objects, then `tateCohomology C n` is a
zero object for every integer `n`.

## Source and route

The mathematics is Serre, *Local Fields*, Chapter IX, §4, Lemmas 4–5 and
Theorems 5–6 (printed pages 142–143, PDF pages 148–149), and the first step of
the proof of §5, Theorem 8 (printed page 145, PDF page 151). The implemented
proof follows the same reduction (modules killed by `p`, then modules without
`p`-torsion, then arbitrary modules via a torsion-free acyclic cover), with two
changes:

- Serre's Lemma 5 assumes vanishing of the ordinary *homology* `H₁(P, A) = 0`
  of a module killed by `p`. Using coinvariants, it builds a surjection from a
  free `𝔽_p[P]`-module onto `A` and shows that `A` is free. The Lean proof
  replaces this with a cohomological analogue. It assumes vanishing of the
  ordinary *cohomology* `H¹(P, A) = groupCohomology A 1` instead, uses
  invariants instead of coinvariants, and embeds `A` into the module coinduced
  from the trivial subgroup with values in its invariants. It then shows that
  this embedding is an isomorphism (section (A) below). The Library already
  knows that coinduced modules have vanishing actual Tate cohomology
  (`coinduced_tate_isZero`, module `Coinduced`).
- Instead of a free `ℤ[P]`-module, the cover in the last step is the
  coinduced module of the trivial representation on the free abelian group
  on the underlying set of `C`.

"Cohomologically trivial" (vanishing for all subgroups) is never needed: only
the group `P` itself occurs.

## Proof

Notation: `coinduced A` is the Library's coinduction from the trivial subgroup
(module `Coinduced`), with `coinducedEmbedding`, `coinducedDelta`,
`coinducedProjection`, and `shiftUp A` / `shiftDown A` with the isomorphisms
`shiftUpIso`, `shiftDownIso` and `tate_delta_isIso` (module `ShiftDefinitions`).

### General facts

- `tate_isZero_of_subsingleton`: over a trivial group the embedding
  `A ⟶ coinduced A` is surjective, hence an isomorphism, so the actual Tate
  cohomology vanishes.
- `card_smul_eq_zero`: `Fintype.card G` kills `tateCohomology A n`. This is the
  Library law `corestriction_restriction` (module `TransferProof`) for the
  trivial subgroup, whose restricted group is zero by the previous item.
- `exists_fixed_ne_zero`: if `p` kills `M` and `a ≠ 0`, the additive subgroup
  generated by the orbit of `a` is finite, has order divisible by `p` and is
  stable under `P`; Mathlib's
  `IsPGroup.exists_fixed_point_of_prime_dvd_card_of_fixed_point` gives a
  nonzero fixed vector in it (Serre's Theorem 2, used in Lemma 4).
- `killed_coinduced`, `killed_cokernel`, `killed_kernel`: being killed by `p`
  (`p • 𝟙 A = 0`) passes to `coinduced A`, to cokernels and to kernels.

### (A) Modules killed by `p` with `H¹ = 0` (`tate_isZero_of_killed_of_H1`)

Let `A` be killed by `p` with `groupCohomology A 1 = 0`.

1. `exists_retraction`: as an `𝔽_p`-vector space (`AddCommGroup.zmodModule`),
   `A` has an additive retraction `π` onto its invariants (a complement from
   `Submodule.exists_isCompl`). It is made scalar-linear over `IntegralScalar`
   by `integralLinear`.
2. `toCoinduced A π : A ⟶ coinduced (Rep.trivial _ P Aᴾ)` sends `a` to
   `x ↦ π (x • a)`; it is the morphism adjoint (`Rep.resCoindToHom`) to `π`.
3. Injectivity (`toCoinduced_injective`): the kernel is a subrepresentation;
   a nonzero kernel element would give, by `exists_fixed_ne_zero`, a nonzero
   fixed vector `b` in the kernel, but the value of `toCoinduced A π b` at `1`
   is `π b = b`.
4. Surjectivity (`surjective_of_fixed_mem_range`, `toCoinduced_surjective`): if
   the image is proper, `exists_fixed_mod_range` applies
   `exists_fixed_ne_zero` to the quotient representation and yields `f'` outside
   the image with `g • f' - f' = Φ (c g)` for all `g`. Injectivity of `Φ` makes
   `c` a 1-cocycle of `A`; since `H¹(P, A) = 0` it is a coboundary
   `c g = g • y - y`, so `f' - Φ y` is a fixed vector. Fixed vectors of
   `coinduced (Rep.trivial _ P Aᴾ)` are constant functions with a value
   `β ∈ Aᴾ`, and such a function is the image of `β` because
   `π (x • β) = π β = β`; so `f'` lies in the image, a contradiction.
5. Hence `toCoinduced A π` is an isomorphism and
   `tateCohomology A n ≅ tateCohomology (coinduced _) n = 0` for all `n`.

### (B) Modules killed by `p`: one degree suffices (`tate_isZero_of_killed`)

Induction on `q` from `1` (`Int.inductionOn'`), for all modules killed by `p`
simultaneously. In degree `1` the actual Tate group is `groupCohomology A 1`
(`TateCohomology.isoGroupCohomology 1`) and (A) applies. Going up, `shiftUp A`
is killed by `p` and `tateCohomology (shiftUp A) k ≅ tateCohomology A (k + 1)`;
going down, `shiftDown A` is killed by `p` and
`tateCohomology A (k - 1) ≅ tateCohomology (shiftDown A) k`. This is the
shifting step of Serre's Theorem 5.

### (C) Modules without `p`-torsion (`tate_isZero_of_torsionFree`)

Let `p • 𝟙 A` be a monomorphism and `tateCohomology A q`,
`tateCohomology A (q + 1)` vanish. The short exact sequence
`0 → A → A → A/pA → 0` (multiplication by `p`, then the cokernel) and the long
exact sequence (`TateCohomology.exact₃`) give `tateCohomology (A/pA) q = 0`;
`A/pA` is killed by `p`, so by (B) all its Tate groups vanish. Then
`TateCohomology.exact₁` shows that multiplication by `p` is injective on every
`tateCohomology A (m + 1)`. Since `|P| = p ^ e` (`IsPGroup.iff_card`) kills
these groups (`card_smul_eq_zero`), they are zero (Serre's Theorem 6,
i) ⇒ ii), for the group `P` only).

### (D) Passage along a torsion-free acyclic cover (`tate_isZero_of_cover`)

Given an epimorphism `ε : L ⟶ C` from `L` with all Tate groups zero and
`p • 𝟙 L` mono, the kernel `K` of `ε` has no `p`-torsion, and the connecting
maps `tateCohomology C m ≅ tateCohomology K (m + 1)` (`tate_delta_isIso`)
transport the two vanishing degrees of `C` to `K`. By (C) all Tate groups of
`K`, hence of `C`, vanish.

### The cover (`exists_torsionFree_cover`)

Let `F` be the free `IntegralScalar`-module on the underlying set of `C` and
`T` the trivial representation on `F`. The map
`coinduced T ⟶ coinduced C ⟶ C`, built from the linear combination map
`F → C` (`Rep.coindMap`) followed by `coinducedProjection C`, is surjective:
`coinducedDelta T (single c 1)` maps to `c` (`coinducedProjection_delta`).
`coinduced T` has all Tate groups zero (`coinduced_tate_isZero`) and
multiplication by `p` on it is injective, because `F` is additively
torsion-free (`mono_nsmul_coinduced`, `mono_nsmul_trivial`,
`integralScalar_isAddTorsionFree`).

### Main theorem

`pGroupTateVanishing` takes the cover of `C` from `exists_torsionFree_cover`
and applies (D).
