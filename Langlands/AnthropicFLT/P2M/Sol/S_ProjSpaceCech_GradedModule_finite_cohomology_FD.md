# The graded Čech cohomology of `S(d)` is finitely generated (proof)

Module `Langlands.AnthropicFLT.P2M.Sol.S_ProjSpaceCech_GradedModule_finite_cohomology_FD`. Its only declaration
is `P2MW.S_ProjSpaceCech_GradedModule_finite_cohomology_FD.solution`.

## Statement

`solution`: for a commutative ring `R`, `n : ℕ`, `d₀ : ℤ` and `i : ℕ`, the `i`-th graded Čech cohomology
`ProjSpaceCech.GradedModule.H (ProjSpaceCech.GradedModule.FD R n d₀) i` of the free graded module `S(d₀)` over
`S = R[X₀, …, Xₙ]` (`Def_AlgebraicGeometry_ProjSpaceCechGradedModule`) is a finitely generated `R`-module.
The theorem module `Theorems.Thm_ProjSpaceCech_GradedModule_finite_cohomology_FD` states this as
`ProjSpaceCech.GradedModule.finite_cohomology_FD` and proves it from `solution`.

## Proof outline

`ProjSpaceCech.GradedModule.nonempty_HEquiv_FD` (`Theorems.Thm_ProjSpaceCech_GradedModule_nonempty_HEquiv_FD`)
gives an `R`-linear equivalence `e` from the monomial Čech cohomology `ProjSpaceCech.Twist.H R n d₀ i` to this
module. The former is finitely generated by `ProjSpaceCech.Twist.finite_cohomology`
(`Theorems.Thm_ProjSpaceCech_Twist_finite_cohomology`), so `Module.Finite.equiv e` concludes.
