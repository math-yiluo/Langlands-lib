# The narrow ray class group of a number field

For a number field K and an ideal 𝔣 of its ring of integers, the module defines the following.
- `coprimeToModulus K 𝔣`: the group of fractional ideals coprime to 𝔣.
- `narrowRaySubgroup K 𝔣`: the subgroup generated by the principal ideals (α) with α totally positive and α ≡ 1 modulo 𝔣.
- `NarrowRayClassGroup K 𝔣`: the quotient of the first group by the second.

It also defines the ray symbols `raySymbolHom`, the multiplicative extension to coprime fractional ideals of a function on primes, and their descent `raySymbolDescend` to the narrow ray class group when the function kills the narrow ray subgroup. It defines prime classes and the map to the ideal class group. It also defines `rayClassSubgroup`, the subgroup generated by the classes of principal ideals (α) with α ≡ 1 modulo 𝔣 and no positivity condition, and proves that it is finite. The moving lemma (`movingLemma`, for 𝔣 ≠ 0) states: if x ∈ Kˣ has valuation 0 at every prime dividing 𝔣, then βx is integral for some nonzero β ≡ 1 modulo 𝔣. By the moving lemma, the map from the quotient by `rayClassSubgroup` to the ideal class group has finite kernel; its image lies in the finite class group. Together with the finiteness of `rayClassSubgroup`, this proves that the narrow ray class group is finite for 𝔣 ≠ 0 (`Deep.NTSupply.finite`).
