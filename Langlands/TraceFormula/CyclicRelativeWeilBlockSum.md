# The shifted relative Weil block-sum embedding

Derived from Clozel–Rajan, *Solvable base change*, arXiv:1806.02513v1, §6, (6.1)–(6.3) and (6.13)–(6.15) (PDF pp. 16, 18–19), and §7.2, the construction of `ξ₀` (PDF p. 25). This is the relative Weil group calculation preceding ellipticity and transfer, not a local Langlands correspondence or an existence theorem for a match of test functions.

Let `W = RelativeWeilGroup c F E`. This is the Library's extension of `Gal(E/F)` by the actual idele class group `C_E`; its interpretation as the arithmetic relative Weil group uses the arithmetic class in the supplied family `c`. The code uses the same field universe for `F` and `E`. Use a finite additive commutative index group `I` and a multiplicative identification `κ : Gal(E/F) ≃* Multiplicative I`. In the cyclic application take `I = ZMod [E:F]`, with `σ` labeled by `1`. For lifts `r_i` of the labels and `k` the Weil degree, `ideleDefect` is determined by `r_i t = inclusion(δ_i(t)) r_(i+k(t))`. Exactness puts the defect in the actual idele-class subgroup. Cancellation gives the shifted product law for `δ_i`, and the relative Weil conjugation theorem identifies `δ_i(inclusion(a))` with the action of the automorphism underneath `r_i` on `a`.

`shiftedBlockEmbedding` sends `(h,t)` to `(g,t)` with outer row `g_i = ⊕_α (η_α(δ_i(t)) · h_(i−α))`. Blocks use `Fin b × I` as matrix indices, of cardinality `b · |I|`. Both semidirect products use the outer action `f_i ↦ f_(i+k(t))`. The sign of the block offset is the convention in which the subsequent cyclic block permutation sends `α` to `α+k(t)`, as required by (6.13)–(6.14); read the offset in §7.2 with this block-label convention, not as an independent change in the arithmetic Galois action. The multiplicativity proof uses the shifted defect law and centrality of the character scalars. The right component determines `t`; block `0` in each row then determines the corresponding component of `h`, proving injectivity.

For `r_0 = 1` the row at `0` on the upper idele-class subgroup is exactly `⊕_α η_α(a) h_(−α)`. This is the matrix formula to apply to unramified data: if `a` is the idele class of a uniformizer at `w`, and row `i` contains the Satake data at `σ^i w`, the block offset implements inverse arithmetic pullback. This assertion about reading the formula is not a Lean identification of the genuine spectral attachments. This unit permits any family of Hecke characters; the recurrence, endoscopic conjugate section, classification and spectral use belong to subsequent units.
