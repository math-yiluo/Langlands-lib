# Character separation from trace class of smooth integrated operators

`Langlands.TraceFormula.ArchimedeanUnitaryCharacterSeparationReductionStatement`
states that `ArchimedeanUnitaryTraceClassStatement`, in the universes of the
summand and target Hilbert spaces separately, implies
`ArchimedeanUnitaryCharacterSeparationStatement`. The number field and index
universes also remain independent.

This implication is the trace-class reduction of the domination argument in
the remark to Jacquet–Langlands, Lemma 16.1.1. Trace class supplies a positive
character value on a test autocorrelation with nonzero integrated operator.
Over the inequivalent summands, it identifies the trace at each autocorrelation
with the squared Hilbert–Schmidt norm. Absolute convergence of the weighted
traces then supplies the square-summable family to which the domination argument
applies.
