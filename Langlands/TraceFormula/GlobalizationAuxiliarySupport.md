# Auxiliary support for periodization

Localization of a rational general-linear matrix at one place is injective
by entrywise injectivity of the field map. The same holds on the actual
principal norm-one subgroup by the rational and local point comparisons.

The intersection of a compact set with the principal subgroup is finite
because the subgroup is closed and discrete. The finite set of auxiliary
coordinates of its nonidentity points avoids the identity. The complement
of that set is an open neighborhood of the identity at the chosen finite
place. A cutoff supported in this neighborhood leaves only the identity
contribution when evaluating the periodization of a compact test there.

This is a compact-support argument for point evaluation of a Poincaré
series. It uses the actual norm-one group and works at every supplied
finite place. The arithmetic input is the rational-to-completion
point comparison for general linear groups.

The identity-value formula uses counting measure on the principal subgroup.
On that subgroup the restricted test is a function supported at the
identity, so the quotient average there is the value of the test itself.
