# The Translation Principle

Fix a hereditary order `𝔄` in a finite-dimensional endomorphism algebra over
a nonarchimedean local field, an admissible `ψ_F`, and levels with `0 ≤ m` and
`m+1 < n`.
`SimpleCharacterTranslationStatement` takes simple strata
`[𝔄,n,m+1,γ₁]` and `[𝔄,n,m+1,γ₂]` with the same depth-`m+1` character pairs.
Given simple `[𝔄,n,m,β₁]` whose depth-`m+1` stratum is equivalent to the one
for `γ₁`, it asserts that there is a simple `[𝔄,n,m,β₂]` whose depth-`m+1`
stratum is equivalent to the one for `γ₂`. The character-pair sets for
`β₁` and `β₂` at depth `m` are equal. The equivalences at the common level
`m+1` are expressed as differences in the filtration lattice `𝔓^{−(m+1)}`.

(1994), (2.11), printed p. 123 (PDF p. 136). The proof is in §5, printed
pp. 132–135. Literature ID `bushnell-kutzko-1994-simple-types-conjugacy-classes`,
