# Centralizers of endomorphisms annihilated by a maximal ideal

Module `Langlands.BushnellKutzko.NonsplitFundamentalSimpleAlgebra`, namespace
`Langlands.BushnellKutzko.NonsplitSimple`. It imports only Mathlib. It supplies the ring theory
used to prove BK93 (2.4.13) in `NonsplitFundamentalSimpleProof`.

## Declarations

Let `R` be a commutative ring, `M` an `R`-module and `φ ∈ End_R(M)`. Write `M_φ` for `M` viewed
as an `R[X]`-module with `X` acting by `φ` (Mathlib's `Module.AEval' φ`).

- `commute_aeval_of_commute`: in an `R`-algebra, an element commuting with `φ` commutes with
  every polynomial `q(φ)`, `q ∈ R[X]`.
- `centralizerEquivAEval φ`: a ring isomorphism from the centralizer
  `Subalgebra.centralizer R {φ}` of `φ` in `End_R(M)` to `End_{R[X]}(M_φ)`. An endomorphism
  commuting with `φ` commutes with every `q(φ)`, so it is `R[X]`-linear; conversely an
  `R[X]`-linear map commutes with the action of `X`, which is `φ`.
- `isSemisimpleRing_centralizer`: if `M` is finite over `R` and a maximal ideal `I` of `R[X]`
  satisfies `q(φ) = 0` for all `q ∈ I`, then the centralizer of `φ` is a semisimple ring.
- `eq_zero_of_isNilpotent_of_commute`: in a semisimple ring, a nilpotent element commuting with
  every element is zero.

## Proofs

For `isSemisimpleRing_centralizer`, `M_φ` is annihilated by `I`, so it is a module over the
field `R[X]/I` (Mathlib's `Module.IsTorsionBySet.module`). Every module over a field is
semisimple, and `Module.IsTorsionBySet.isSemisimpleModule_iff` makes `M_φ` a semisimple
`R[X]`-module. It is finite over `R[X]` because `M` is finite over `R`. The endomorphism ring of
a finite semisimple module is semisimple (Mathlib's `IsSemisimpleRing.moduleEnd`, a consequence
of the Wedderburn–Artin theorem), and `centralizerEquivAEval` transports this to the
centralizer.

For `eq_zero_of_isNilpotent_of_commute`, Mathlib's `IsSemisimpleRing.ideal_eq_span_idempotent`
writes the left ideal generated by the central element `w` as the left ideal generated by an
idempotent `e`. Then `e = a w` for some `a`, and `e = e^m = a^m w^m = 0` when `w^m = 0` with
`m ≥ 1`. Thus the ideal is zero and `w = 0`. If `m = 0`, then `1 = 0` and the ring is zero.

These are standard facts of noncommutative algebra; they are recorded here in the form needed
for the residue centralizer of BK93 (2.4.13), C. J. Bushnell and P. C. Kutzko, *The admissible
dual of GL(N) via compact open subgroups* (1993), printed p. 75, literature ID
`bushnell-kutzko-1993-admissible-dual-gln`.
