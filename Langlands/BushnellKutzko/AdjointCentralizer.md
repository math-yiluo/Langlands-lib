# The centralizer and the global commutator sequence

Bushnell–Kutzko (1993), registered as `bushnell-kutzko-1993-admissible-dual-gln`,
uses the commutator by a generator of `E/F` and the centralizer
`B = End_E(V)` in §1.4, printed pp. 35–36. This module proves the field-level
identities used to establish (1.4.7).

Commutation with the scalar endomorphism for `β` implies commutation with the
endomorphisms in its generated `F`-subalgebra. This gives precisely the scalar
compatibility needed to regard an element of the commutator kernel as an
`E`-linear endomorphism. Conversely, every `E`-linear map commutes with `β`.
Strictness of the chain gives a nonzero vector, so the field action is
faithful and preserves the nonscalar condition.

The tame corestriction is `F`-linear by its left module law. Its two module
laws and commutativity with the `E`-scalar show that it kills the commutator.
Using the order-image law, a single scalar denominator for a relative
endomorphism produces a preimage over `F`. Rank–nullity for the commutator
and the corestriction then identifies the commutator image with the full
corestriction kernel.
