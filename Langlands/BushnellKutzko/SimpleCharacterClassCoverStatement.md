# Covering simple-character classes by simple strata

`SimpleCharacterClassCoverStatement` fixes a hereditary order in a
finite-dimensional endomorphism algebra over a nonarchimedean local field,
an admissible `ψ_F` and integers `0 ≤ m < n`. It asserts that there exists a function assigning to each simple
stratum at those levels a pair in its own `Ĉ(𝔄,m,β)`. If two strata become
equivalent after conjugating the first by an element of `U(𝔄)`, the function
sends them to `U(𝔄)`-conjugate pairs. Equivalence is tested by subtracting the
conjugated first element from the second modulo `𝔓^{−m}`. Every pair in
`S^m_n(𝔄)` is `U(𝔄)`-conjugate to an assigned pair.

These clauses give the upper bound from the source theorem. Its map on
classes is well defined and surjective, and (2.3)(ii) provides an actual
pair in each stratum's character set from the specified image class.
