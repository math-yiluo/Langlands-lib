# The adjacent restriction fibre of a core approximation

`SimpleCharacterCore.mul_mem_of_trivial_on_succ` takes a simple-character member over a nonarchimedean local field with the base conductor of `IsBKAdditiveCharacter`. It assumes the original index is nonnegative, the depth is below half the level, and the given core agrees with the original domain at the adjacent depth. If a twisting character is trivial at the adjacent depth and factors through the determinant on the core centralizer, multiplication by it preserves membership. The proof uses `SimpleCharacterRestrictionStatement`.

This is the determinant sufficiency argument of Bushnell and Kutzko, *The admissible dual of GL(N) via compact open subgroups* (1993), (3.5.6) and the last step in (3.5.8), printed pp. 119–121 (PDF pp. 131–133). The fibre identity used in Lean is (3.2.5), printed p. 99 (PDF p. 111). The source identifier is `bushnell-kutzko-1993-admissible-dual-gln` and the retained PDF SHA-256 is `811693b94c03fcbc2cfe33955bc5a00b0fc0b5645ca343f8cc1a3c6511de9c73`.

For a nonscalar core, the restriction fibre identity applies at the core cutoff. The character trivial at the adjacent depth is trivial also at the cutoff. For a scalar core, the defining sequence is terminal. The determinant factors multiply and the twisting character is trivial on the unit group at the terminal test depth, by the high-index domain formula. This preserves the prescribed values. Transport the twist to the core, multiply there, then use the bidirectional core correspondence and equality of character values to return to the original set.

`SimpleCharacterCore.domain_eq_of_le` derives all deeper domain equalities from the exact carrier formula of `SimpleStratumGroupPropertiesStatement`. A deeper group is the intersection of the given group and the corresponding unit filtration step. The core and original stratum use the same chain.

`SimpleCharacterCoreComparisonStatement` specifies the input needed from the core-intertwining calculation of (3.5.4), (3.5.7) and (3.5.8). Below half the level, for two depth-zero simple inputs of equal order and level with common character `θ`, it supplies a core for each, and a common depth at least the current one. The self-intertwining set of `θ` restricted to that depth contains both core centralizers and intertwines every quotient by `θ` from either current set. `simpleCharacterCoherenceFibre_of_coreComparison` applies the relative determinant assertion to a twist intertwined by that set, and uses core multiplication on both sides. `SimpleCharacterCoherenceCoreReductionStatement` concludes the full published coherence proposition from exact carriers, the restriction proposition, relative determinant factorization and the core comparison.
