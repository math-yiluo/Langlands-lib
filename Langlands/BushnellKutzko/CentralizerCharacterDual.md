# Character dual of a relative filtration step

`traceDualLattice ψ M` bundles the set of endomorphisms `x` with `ψ(tr(xy)) = 1` for every `y ∈ M` as an `𝒪_F`-submodule. Addition uses the character law. For each scalar `a ∈ 𝒪_F`, the test on `a x` is the test on `x` against `a y ∈ M`, since `tr((a x)y) = tr(x(a y))`. This is the star operation of Bushnell–Kutzko, *The admissible dual of GL(N) via compact open subgroups* (1993), (1.1.4), printed p. 22 (PDF p. 34). The construction applies to any `𝒪_F`-submodule. Under the conductor condition on `ψ`, `traceDualLattice_endFiltration` gives `(𝔓^k)* = 𝔓^(1−k)`.

`traceDualLattice_centralizerLattice` expresses the character dual of `𝔓^k ∩ B_b` as the sum of `𝔓^(1−k)` and the image of the commutator map `a_b(x) = bx−xb`. The set-valued version is `mem_dual_centralizerLattice_iff`. This is the relative filtration duality used in the calculations of (3.1.18)–(3.1.21), printed pp. 96–97 (PDF pp. 108–109). The registered source `bushnell-kutzko-1993-admissible-dual-gln` has SHA-256 `811693b94c03fcbc2cfe33955bc5a00b0fc0b5645ca343f8cc1a3c6511de9c73`.

The character `ψ` is trivial on `𝔭_F` and nontrivial on `𝒪_F`. If `ψ(a tr(xy)) = 1` for every `a ∈ 𝒪_F`, then `tr(xy) ∈ 𝔭_F`. To prove the dual formula, project onto the vector-space quotient by `im(a_b)`. If the class of an element misses the image of `𝔓^(1−k)`, separate it from that finitely generated `𝒪_F`-submodule by a linear functional with tests in the conductor ideal. The trace product represents the pulled-back functional by an endomorphism. Trace duality of the full filtration puts this endomorphism in `𝔓^k`. The commutator map is skew-adjoint for the trace product, so vanishing on `im(a_b)` makes the endomorphism commute with `b`. This contradicts membership in the dual of `𝔓^k ∩ B_b`. The reverse inclusion uses the same skew-adjointness and the full filtration duality. [CorestrictionLatticeDual](CorestrictionLatticeDual.md)
