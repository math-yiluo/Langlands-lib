# Restricting a simple character to the depth of a core approximation

The proof of coherence restricts a common character to a depth where the core approximation contributes no additive twist. At such a depth, the self-intertwining calculation for the core character identifies a set containing its centralizer. This is the use of (3.3.2) and (3.5.5) in Bushnell and Kutzko, *The admissible dual of GL(N) via compact open subgroups* (1993), (3.5.8), printed p. 120 (PDF p. 132). The source identifier is `bushnell-kutzko-1993-admissible-dual-gln` and the retained PDF SHA-256 is `811693b94c03fcbc2cfe33955bc5a00b0fc0b5645ca343f8cc1a3c6511de9c73`.

The propositions for exact group carriers, restriction and self-intertwining are inputs to `simpleCharacterCoreRestriction`. The input stratum is simple at a nonnegative index over a nonarchimedean local field, and the base additive character is trivial on the maximal ideal and nontrivial on the integer ring. The restriction index `k` is at least the given character depth and the core approximation depth, and remains strictly below the stratum level and the core critical depth.

The core correspondence gives a member of the core set at the given depth. Iterating the adjacent restriction formula keeps its restriction in the core set at `k`. The two domains at `k` coincide by exact carriers. The approximation difference lies in `𝔓^{-k}`, so additive duality makes its twist trivial on `U^{k+1}`. The two restricted characters give the same values and hence the same self-intertwining set. The core self-intertwining formula then contains its centralizer by taking the identity in each outer factor.

`SimpleCharacterCore.selfIntertwining_subset_ratio_of_depth_le` uses the same comparison at the given depth itself when this depth is at least the core approximation depth. Both characters match core characters at that depth. Their self-intertwining sets then agree by the formula for the same core. An element that intertwines both characters also intertwines their quotient.
