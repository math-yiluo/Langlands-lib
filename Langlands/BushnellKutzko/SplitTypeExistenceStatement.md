# A representation containing no simple type contains a split type

`SplitTypeExistenceStatement` ranges over every nonarchimedean local
field \(F\), every \(n>0\), and every additive character
\(\psi_F\) trivial on \(\mathfrak p_F\) and nontrivial on
\(\mathfrak o_F\). If an irreducible smooth complex representation
\(\pi\) of \(\mathrm{GL}_n(F)\) contains no `IsGLSimpleType` pair, it
contains an `IsGLSplitType` pair. Both predicates use the same
\(\psi_F\). The disjunction in `IsGLSplitType` includes all four
level cases of (8.1.1)–(8.1.4).

Containment is `ContainsType`, a nonzero intertwining map into the
restriction of \(\pi\) to the type subgroup. The field, the carrier
of \(\pi\), and the carrier of a type have independent universe
parameters.

C. J. Bushnell and P. C. Kutzko, *The admissible dual of GL(N) via
compact open subgroups* (1993), (8.1.5), printed p. 267.
