## Targets and complete telescopes

Lean includes only the section variables a declaration uses. M118.002,
M118.003 and M118.004 mention `G` and `A`, so each has, before the binders

### M118.002

```lean
def herbrandQuotient_eq_card_ratioStatement (σ : G)
    [Finite (HerbrandH0 G A)] [Finite (HerbrandHMinusOne G A σ)] : Prop :=
    herbrandQuotient (G := G) (A := A) σ =
      (Nat.card (HerbrandH0 G A) : ℚ) /
        (Nat.card (HerbrandHMinusOne G A σ) : ℚ)
```

The Herbrand quotient equals the ratio `#H⁰ / #H⁻¹` of the cardinalities of
the two low-degree groups.

### M118.003

```lean
def herbrandQuotient_eq_one_of_card_eqStatement (σ : G)
    [Finite (HerbrandH0 G A)] [Finite (HerbrandHMinusOne G A σ)]
    (hcard : Nat.card (HerbrandH0 G A) = Nat.card (HerbrandHMinusOne G A σ)) : Prop :=
    herbrandQuotient (G := G) (A := A) σ = 1
```

If the two low-degree groups have the same finite cardinality, the Herbrand
quotient is `1`.

### M118.004

```lean
def herbrandQuotient_finite_module_eq_oneStatement
    (σ : G) (hgen : ∀ g : G, g ∈ Subgroup.zpowers σ) [Finite A] : Prop :=
    herbrandQuotient (G := G) (A := A) σ = 1
```

For a finite module `A` over a finite group generated by `σ`, the Herbrand
quotient is `1`. The two finiteness instances that `herbrandQuotient`
requires are found by instance resolution from `[Finite A]`; the published
instances `herbrandH0FiniteOfFinite` (M113.056) and
`herbrandHMinusOneFiniteOfFinite` (M113.057) have exactly this form. Since
`Finite` is a proposition, the statement does not depend on which proof is
found.

### M118.005

```lean
def herbrandQuotient_exact_multiplicativeStatement
    {G A B C : Type}
    [Group G] [Fintype G]
    [CommGroup A] [CommGroup B] [CommGroup C]
    [MulDistribMulAction G A] [MulDistribMulAction G B]
    [MulDistribMulAction G C]
    (i : A →* B) (j : B →* C)
    (hi : ∀ (g : G) (a : A), i (g • a) = g • i a)
    (hj : ∀ (g : G) (b : B), j (g • b) = g • j b)
    (hker : ∀ b : B, j b = 1 ↔ ∃ a : A, i a = b)
    (hinj : Function.Injective i)
    (hsurj : ∀ c : C, ∃ b : B, j b = c) (σ : G)
    (hgen : ∀ g : G, g ∈ Subgroup.zpowers σ)
    [Finite (HerbrandH0 G A)] [Finite (HerbrandHMinusOne G A σ)]
    [Finite (HerbrandH0 G B)] [Finite (HerbrandHMinusOne G B σ)]
    [Finite (HerbrandH0 G C)] [Finite (HerbrandHMinusOne G C σ)] : Prop :=
    herbrandQuotient (G := G) (A := B) σ =
      herbrandQuotient (G := G) (A := A) σ *
        herbrandQuotient (G := G) (A := C) σ
```

For a finite group `G` generated by `σ` and a short exact sequence
`1 → A → B → C → 1` of multiplicative `G`-modules whose low-degree Herbrand
groups are finite, the Herbrand quotient of `B` is the product of those of
`A` and `C`.
