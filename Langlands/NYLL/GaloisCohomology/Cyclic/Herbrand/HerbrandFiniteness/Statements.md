### M119.006

```lean
def herbrandQuotientDefined_middle_of_left_rightStatement
    (i : A →* B) (j : B →* C)
    (hi : ∀ (g : G) (a : A), i (g • a) = g • i a)
    (hj : ∀ (g : G) (b : B), j (g • b) = g • j b)
    (hker : ∀ b : B, j b = 1 ↔ ∃ a : A, i a = b)
    (hinj : Function.Injective i)
    (hsurj : ∀ c : C, ∃ b : B, j b = c)
    (σ : G) (hgen : ∀ g : G, g ∈ Subgroup.zpowers σ)
    (hA : HerbrandQuotientDefined G A σ)
    (hC : HerbrandQuotientDefined G C σ) : Prop :=
    HerbrandQuotientDefined G B σ
```

For a finite group `G` generated by `σ` and a short exact sequence
`1 → A → B → C → 1` of multiplicative `G`-modules, if the Herbrand quotients
of `A` and `C` are defined, so is that of `B`.

### M119.010

```lean
def herbrandQuotient_multiplicative_of_shortExactStatement
    (i : A →* B) (j : B →* C)
    (hi : ∀ (g : G) (a : A), i (g • a) = g • i a)
    (hj : ∀ (g : G) (b : B), j (g • b) = g • j b)
    (hker : ∀ b : B, j b = 1 ↔ ∃ a : A, i a = b)
    (hinj : Function.Injective i)
    (hsurj : ∀ c : C, ∃ b : B, j b = c)
    (σ : G) (hgen : ∀ g : G, g ∈ Subgroup.zpowers σ)
    [Finite (HerbrandH0 G A)] [Finite (HerbrandHMinusOne G A σ)]
    [Finite (HerbrandH0 G B)] [Finite (HerbrandHMinusOne G B σ)]
    [Finite (HerbrandH0 G C)] [Finite (HerbrandHMinusOne G C σ)] : Prop :=
    herbrandQuotient (G := G) (A := B) σ =
      herbrandQuotient (G := G) (A := A) σ *
        herbrandQuotient (G := G) (A := C) σ
```

For such a sequence whose six low-degree Herbrand groups are finite, the
Herbrand quotient of `B` is the product of those of `A` and `C`.

### M119.014

```lean
def herbrandQuotient_eq_one_of_finite_moduleStatement
    (σ : G) (hgen : ∀ g : G, g ∈ Subgroup.zpowers σ) [Finite A] : Prop :=
    herbrandQuotient (G := G) (A := A) σ = 1
```

For a finite module `A` over a finite group generated by `σ`, the Herbrand
quotient is `1`. As for M118.004, the two finiteness instances that
`herbrandQuotient` requires are found by instance resolution from
`[Finite A]`, for which the published instances `herbrandH0FiniteOfFinite`
(M113.056) and `herbrandHMinusOneFiniteOfFinite` (M113.057) have exactly the
needed form; since `Finite` is a proposition, the statement does not depend
on which proof is found.
