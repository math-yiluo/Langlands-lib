# Integer units modulo principal units at a level

For an arbitrary `K : Type u` with `[Field K] [ValuativeRel K]`, and every
`n : Nat`, this module defines the actual quotient group
`𝒪[K]ˣ ⧸ Langlands.NYLL.LocalFieldTheory.principalUnits K n`.
The integer ring is Mathlib's canonical valuation ring of the supplied
valuation relation. The subgroup is the published natural-indexed subgroup of
integer-ring units congruent to one modulo `𝓂[K] ^ n`.
Zero is an allowed level; no local-field, topology, completeness, discreteness,
finiteness or nontrivial-valuation assumption is added.

With `open scoped ValuativeRel` and
`open Langlands.NYLL.LocalFieldTheory`, the complete interfaces in namespace
`Langlands.NYLL.CyclicCohomology` are:

```lean
IntegerUnitsModPrincipalUnitsAtLevel
    (K : Type u) [Field K] [ValuativeRel K] (n : Nat) : Type u

integerUnitsModPrincipalUnitsAtLevelCommGroup
    (K : Type u) [Field K] [ValuativeRel K] (n : Nat) :
    CommGroup (IntegerUnitsModPrincipalUnitsAtLevel K n)

integerUnitsModPrincipalUnitsAtLevelConcreteEquiv
    (K : Type u) [Field K] [ValuativeRel K] (n : Nat) :
    IntegerUnitsModPrincipalUnitsAtLevel K n ≃*
      (𝒪[K]ˣ ⧸ principalUnits K n)

integerUnitsModPrincipalUnitsAtLevelMk
    (K : Type u) [Field K] [ValuativeRel K] (n : Nat) :
    𝒪[K]ˣ →* IntegerUnitsModPrincipalUnitsAtLevel K n

integerUnitsModPrincipalUnitsAtLevelLift
    {K : Type u} {M : Type v} [Field K] [ValuativeRel K] [Group M]
    (n : Nat) (f : 𝒪[K]ˣ →* M) (h : principalUnits K n ≤ f.ker) :
    IntegerUnitsModPrincipalUnitsAtLevel K n →* M
```

Here `v` denotes the independent universe generated by the source's
`{M : Type*}` binder; the Lean file retains that binder verbatim.
The lift allows any group `M`, without a commutativity assumption.
The order and explicit, implicit and instance kinds of every source binder
are retained.

The quotient definition unfolds to the displayed concrete quotient.
The instance unfolds this named type and uses Mathlib's canonical quotient
commutative group. Its target has the new named type as its head, and the
instance retains the source's global scope and default priority. It adds no
instance directly on Mathlib's concrete quotient.
The concrete equivalence is `MulEquiv.refl` after unfolding the named type.
The canonical projection is `QuotientGroup.mk' (principalUnits K n)`.
The lift is `QuotientGroup.lift (principalUnits K n) f h`.
All tactic bodies, including the instance's `change` and `infer_instance`,
are retained verbatim from the source.
