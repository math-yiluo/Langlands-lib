## Exact statement

```lean
def Langlands.NYLL.CyclicCohomology.hilbert90_unitsTateHminusOne_isZeroStatement
    (K L : Type) [Field K] [Field L] [Algebra K L] [FiniteDimensional K L]
    (g : Gal(L/K)) (hg : ∀ x : Gal(L / K), x ∈ Subgroup.zpowers g) : Prop :=
  CategoryTheory.Limits.IsZero
    (tateCohomology (Rep.ofAlgebraAutOnUnits K L) (-1))
```

The parameters are the theorem's binders, in the source order and with the
source binder kinds, and the body is the theorem's asserted proposition. For
a finite extension `L/K` whose automorphism group `Gal(L/K) = L ≃ₐ[K] L` is
generated by `g` (hypothesis `hg`), the proposition says that Mathlib's Tate
cohomology `Ĥ⁻¹(Gal(L/K), Lˣ)` of the integral unit representation
`Rep.ofAlgebraAutOnUnits K L` is a zero object of `ModuleCat ℤ`. The
`Fintype` instance on `Gal(L/K)` needed by `tateCohomology` is Mathlib's
`AlgEquiv.fintype`, which uses `[FiniteDimensional K L]`, exactly as in the
source. No Galois hypothesis is assumed. `g` and `hg` do not occur in the
proposition; they remain premises of the target, as in the source.
