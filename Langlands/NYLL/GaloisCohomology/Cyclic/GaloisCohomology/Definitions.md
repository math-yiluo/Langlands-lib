## The declarations

```lean
noncomputable def Langlands.NYLL.CyclicCohomology.cyclic_H1_iso_HminusOne
    {k G : Type} [CommRing k] [Group G] [Fintype G] (A : Rep k G) (g : G)
    (hg : ∀ x : G, x ∈ Subgroup.zpowers g) :
    groupCohomology A 1 ≅ tateCohomology A (-1)

noncomputable def Langlands.NYLL.CyclicCohomology.unitsH1IsoTateHminusOne
    (K L : Type) [Field K] [Field L] [Algebra K L] [FiniteDimensional K L]
    (g : Gal(L/K)) (hg : ∀ x : Gal(L / K), x ∈ Subgroup.zpowers g) :
    groupCohomology.H1 (Rep.ofAlgebraAutOnUnits K L) ≅
      tateCohomology (Rep.ofAlgebraAutOnUnits K L) (-1)
```

- `cyclic_H1_iso_HminusOne A g hg` is an isomorphism in `ModuleCat k` from
  Mathlib's first group cohomology `H¹(G, A)` to Mathlib's Tate cohomology
  `Ĥ⁻¹(G, A)` (`tateCohomology A (-1)`, defined in Mathlib for finite `G`),
  for a finite group `G` generated by `g` (the hypothesis `hg`). Both the
  source and the port build it the same way. From `hg` they obtain a local
  `IsCyclic G` instance, and hence the commutative group structure
  `IsCyclic.commGroup`. Then they compose Mathlib's
  `Rep.FiniteCyclicGroup.groupCohomologyIsoOdd A g hg 1 (by decide)`, which
  identifies `H¹` with the homology of the short complex
  `A --(g - 1)--> A --(norm)--> A`, with the inverse of
  `Langlands.NYLL.TateCohomology.isoFiniteCyclicNegOne A g hg` (published
  M003.003), which identifies `Ĥ⁻¹` with the homology of the same short
  complex.
- `unitsH1IsoTateHminusOne K L g hg` is `cyclic_H1_iso_HminusOne`
  specialized to the integral unit representation
  `Rep.ofAlgebraAutOnUnits K L` of `Gal(L/K)` on `Additive Lˣ`, for a finite
  extension whose automorphism group is generated by `g`. The `Fintype`
  instance on `Gal(L/K)` is Mathlib's instance `AlgEquiv.fintype`, which uses
  `[FiniteDimensional K L]`, as in the source. No Galois hypothesis is
  assumed.
