# Topological generation descends to quotients

This module proves the theorem
`Langlands.NYLL.ClassFormation.topologicallyGenerates_quotient_image`.
Its complete unapplied type is the already published closed proposition
`Langlands.NYLL.ClassFormation.topologicallyGenerates_quotient_imageStatement.{u}`.
This is the proof phase of M007.010 in the
[NYLL partition](../../../../../../notes/reuse/nyll-public-port/m001-m024.md#m007).

## Closed target and binders

The target internally quantifies over exactly this telescope and conclusion:

```lean
∀ {G : Type u} [Group G] [TopologicalSpace G] [IsTopologicalGroup G]
  (N : Subgroup G) [N.Normal]
  {X : Set G} (hX : TopologicallyGenerates (G := G) X),
  TopologicallyGenerates (G := G ⧸ N) ((QuotientGroup.mk' N) '' X)
```

| Binders | Kind | Meaning |
| --- | --- | --- |
| `G : Type u` | implicit | The ambient group |
| `[Group G]`, `[TopologicalSpace G]`, `[IsTopologicalGroup G]` | instance-implicit | Its group structure, topology and the continuity of its operations |
| `N : Subgroup G` | explicit | The subgroup by which the quotient is taken |
| `[N.Normal]` | instance-implicit | Normality of `N` |
| `X : Set G` | implicit | The generating set |
| `hX : TopologicallyGenerates (G := G) X` | explicit | `X` topologically generates `G` |

The conclusion is that the image of `X` under the canonical quotient
homomorphism `QuotientGroup.mk' N : G →* G ⧸ N` topologically generates
the actual quotient group `G ⧸ N`. That quotient carries Mathlib's
quotient topology `QuotientGroup.instTopologicalSpace` and the
topological-group instance `QuotientGroup.instIsTopologicalGroup`, which
uses `[N.Normal]` (approved `Mathlib/Topology/Algebra/Group/Quotient.lean`,
lines 32 and 151). The single universe parameter `u` is arbitrary. The
theorem adds no hypothesis: in particular, `N` need not be closed, so
`G ⧸ N` need not be Hausdorff, and no compactness, profiniteness or
separation axiom is assumed.

By the published definition imported through the Statements module,
`TopologicallyGenerates (G := K) Y` means
`(Subgroup.closure Y).topologicalClosure = ⊤` in a topological group `K`:
the topological closure of the abstract subgroup generated by `Y` is the
whole group.

## Implemented proof

The sole direct import is
`Langlands.NYLL.GaloisCohomology.ProfiniteIntegers.TopologicalGeneration.Statements`,
which also supplies `TopologicallyGenerates` through its published
Definitions import. The proof introduces the target's binders, naming the
four instances anonymously, and then argues as follows.

1. `hmap`: the image of the abstract subgroup generated by `X` under
   `QuotientGroup.mk' N` equals the abstract subgroup generated by the
   image of `X`. This is Mathlib's `MonoidHom.map_closure` (approved
   `Mathlib/Algebra/Group/Subgroup/Map.lean`, line 582), applied to
   `QuotientGroup.mk' N` and `X`.
2. `htop`: the topological closure of that image subgroup is `⊤`. This is
   Mathlib's `DenseRange.topologicalClosure_map_subgroup` (approved
   `Mathlib/Topology/Algebra/Group/Subgroup.lean`, lines 68–74). Its
   inputs are:
   - continuity of the quotient map, `continuous_quotient_mk'`
     (approved `Mathlib/Topology/Constructions.lean`, line 744), which
     applies because the coercion of `QuotientGroup.mk' N` is
     definitionally the quotient map of the coinduced quotient topology;
   - dense range, from surjectivity `QuotientGroup.mk'_surjective N`
     (approved `Mathlib/GroupTheory/QuotientGroup/Defs.lean`, line 100)
     through `Function.Surjective.denseRange`
     (approved `Mathlib/Topology/Continuous.lean`, line 265);
   - the hypothesis `hX` itself, which by definition is
     `(Subgroup.closure X).topologicalClosure = ⊤`.
3. Unfolding `TopologicallyGenerates` in the goal and rewriting backwards
   with `hmap` turns the goal into exactly `htop`.

Mathematically: the closure of `⟨X⟩` is `G`, so `⟨X⟩` is dense; a
continuous map with dense range sends dense sets to dense sets, so the
image of `⟨X⟩`, which is `⟨image of X⟩`, is dense in `G ⧸ N`.
