# Singleton functoriality of closed topological generation

This module proves the theorem
`Langlands.NYLL.ClassFormation.map_mem_closedSubgroupGenerated_singleton`.
Its complete unapplied type is the already published closed proposition
`Langlands.NYLL.ClassFormation.map_mem_closedSubgroupGenerated_singletonStatement.{u, v}`.
This is the proof phase of M007.007 in the
[NYLL partition](../../../../../../notes/reuse/nyll-public-port/m001-m024.md#m007).

## Closed target and binders

The target quantifies internally over exactly this telescope and conclusion:

```lean
∀ {G : Type u} [Group G] [TopologicalSpace G] [IsTopologicalGroup G]
  {H : Type v} [Group H] [TopologicalSpace H] [IsTopologicalGroup H]
  (φ : G →ₜ* H) (x : G) {y : G}
  (hy : y ∈ (closedSubgroupGenerated (G := G) ({x} : Set G) : Subgroup G)),
  φ y ∈ (closedSubgroupGenerated (G := H) ({φ x} : Set H) : Subgroup H)
```

| Binders | Kind | Meaning |
| --- | --- | --- |
| `G` | implicit, `Type u` | Source group |
| `[Group G]`, `[TopologicalSpace G]`, `[IsTopologicalGroup G]` | instance-implicit | Its group structure, topology and continuity of the group operations |
| `H` | implicit, `Type v` | Target group |
| `[Group H]`, `[TopologicalSpace H]`, `[IsTopologicalGroup H]` | instance-implicit | The same three structures on `H` |
| `φ : G →ₜ* H` | explicit | A bundled continuous monoid homomorphism |
| `x : G` | explicit | The generator |
| `y : G` | implicit | The element being mapped |
| `hy` | explicit | `y` lies in the closed subgroup generated by `{x}` |

The universes `u` and `v` are independent and arbitrary. The conclusion
says that `φ y` lies in the closed subgroup of `H` generated by the single
element `φ x`. No compactness, Hausdorff, profinite, surjectivity or
injectivity assumption is added.

The sole import is
`Langlands.NYLL.GaloisCohomology.ProfiniteIntegers.TopologicalGeneration.Statements`,
which in turn imports the published
`Langlands.NYLL.GaloisCohomology.ProfiniteIntegers.TopologicalGeneration.Definitions`.
There, `closedSubgroupGenerated X` is the Mathlib `ClosedSubgroup` whose
underlying subgroup is `(Subgroup.closure X).topologicalClosure`, with
closedness given by `Subgroup.isClosed_topologicalClosure`. So both sides
of the target concern the actual topological closure of the actual
abstract subgroup generated by a singleton.

## Implemented proof

The proof introduces the twelve binders of the target, naming the six
instances anonymously:

```lean
intro G _ _ _ H _ _ _ φ x y hy
```

It then proves the auxiliary membership

```lean
himage : φ y ∈ (closedSubgroupGenerated (G := H) (φ '' ({x} : Set G)) : Subgroup H)
```

by the argument of the source theorem M007.006 for the generating set
`{x}`:

1. `K` is the preimage subgroup
   `(closedSubgroupGenerated (φ '' {x}) : Subgroup H).comap (φ : G →* H)`.
2. `hX : {x} ⊆ K`. For `z ∈ {x}`, the point `φ z` lies in `φ '' {x}`
   (witness `⟨z, hz, rfl⟩`), hence in the abstract closure by
   `Subgroup.subset_closure`, hence in its topological closure by
   `Subgroup.le_topologicalClosure`.
3. `hKclosed : IsClosed (K : Set G)`. After a definitional `change` of the
   carrier of `K` to `{z | φ z ∈ closedSubgroupGenerated (φ '' {x})}`, this
   is the preimage of the closed carrier, the `isClosed'` field of the
   `ClosedSubgroup`, under the continuous map `φ`. The continuity proof
   `φ.continuous` elaborates to
   `ContinuousMap.continuous φ.toContinuousMap`.
4. `(Subgroup.closure_le (K := K)).2 hX` gives
   `Subgroup.closure {x} ≤ K`. Since `K` is closed,
   `Subgroup.topologicalClosure_minimal` extends this to
   `(Subgroup.closure {x}).topologicalClosure ≤ K`. Applied to `hy`, this
   gives `y ∈ K`, which is definitionally `himage`.

Finally `rw [Set.image_singleton] at himage` rewrites `φ '' {x}` to
`{φ x}`, and `exact himage` closes the goal.
