# Topological generation along a continuous surjective homomorphism

## Target and mathematical meaning

Unfolding the published assertion gives

```lean
∀ {G : Type u} [Group G] [TopologicalSpace G] [IsTopologicalGroup G]
  {H : Type v} [Group H] [TopologicalSpace H] [IsTopologicalGroup H]
  (f : G →* H) (hf : Continuous f) (hfsurj : Function.Surjective f)
  {X : Set G} (hX : TopologicallyGenerates (G := G) X),
  TopologicallyGenerates (G := H) (f '' X)
```

The eleven internal binders keep their source kinds and order: implicit
`G : Type u` with its three instance arguments `[Group G]`,
`[TopologicalSpace G]`, `[IsTopologicalGroup G]`; implicit `H : Type v`
with the corresponding three instance arguments; the explicit ordinary
monoid homomorphism `(f : G →* H)` (not a bundled continuous homomorphism);
the separate explicit continuity hypothesis `(hf : Continuous f)` and
surjectivity hypothesis `(hfsurj : Function.Surjective f)`; the implicit set
`{X : Set G}`; and the explicit hypothesis
`(hX : TopologicallyGenerates (G := G) X)`.

The published predicate `TopologicallyGenerates X` means
`(Subgroup.closure X).topologicalClosure = ⊤`: the closure of the abstract
subgroup generated by `X` is the whole group. The assertion says that if
`X` topologically generates `G`, then its image `f '' X` topologically
generates `H` whenever `f` is a continuous surjective group homomorphism.
Mathematically: `f` maps the subgroup generated by `X` onto the subgroup
generated by `f '' X`; that subgroup is dense in `G`, and a continuous map
with dense range sends dense sets to dense sets, so its image is dense in
`H`. Surjectivity is used only through the weaker fact that `f` has dense
range. No compactness, Hausdorff, profinite or normality premise is present
or used.

## Implemented proof

The complete proof body is

```lean
  intro G _ _ _ H _ _ _ f hf hfsurj X hX
  have hmap :
      (Subgroup.closure X).map f = Subgroup.closure (f '' X) := by
    simpa using MonoidHom.map_closure f X
  have htop :
      ((Subgroup.closure X).map f).topologicalClosure = ⊤ := by
    exact DenseRange.topologicalClosure_map_subgroup
      (f := f) (hf := hf) (hf' := hfsurj.denseRange)
      (by simpa [TopologicallyGenerates] using hX)
  rw [TopologicallyGenerates, ← hmap]
  exact htop
```

The introductions expose all eleven binders of the closed assertion in
their original order, including both triples of anonymous instance
arguments. The remaining lines are the original proof body verbatim.

1. `hmap` is Mathlib's `MonoidHom.map_closure f X`
   (`Mathlib/Algebra/Group/Subgroup/Map.lean`): the image under `f` of the
   subgroup generated by `X` is the subgroup generated by `f '' X`. The
   original `simpa using` wrapper is retained; it closes the goal with this
   exact equation.
2. `htop` applies Mathlib's `DenseRange.topologicalClosure_map_subgroup`
   (`Mathlib/Topology/Algebra/Group/Subgroup.lean`): for a continuous
   homomorphism `f` with dense range and a subgroup `s` with
   `s.topologicalClosure = ⊤`, also `(s.map f).topologicalClosure = ⊤`.
   Here `s` is `Subgroup.closure X`, continuity is `hf`, dense range is
   `hfsurj.denseRange` (Mathlib's `Function.Surjective.denseRange`,
   `Mathlib/Topology/Continuous.lean`), and the subgroup hypothesis is `hX`
   with the published `TopologicallyGenerates` unfolded by `simpa`.
3. The goal `TopologicallyGenerates (f '' X)` is unfolded to
   `(Subgroup.closure (f '' X)).topologicalClosure = ⊤`, rewritten backwards
   along `hmap` to `((Subgroup.closure X).map f).topologicalClosure = ⊤`,
   and closed by `htop`.

No additional hypothesis, instance, simp registration or auxiliary
declaration is introduced. The development check in the approved
environment reported no errors or warnings, and the theorem depends only on
the standard axioms `propext`, `Classical.choice` and `Quot.sound`.
