# M344.002: maximalIdeal_map_eq_target_maximalIdeal_pow_ramificationIndex

## Result

The theorem
`Langlands.NYLL.LocalFieldTheory.DiscreteValuationField.ValuedExtension.maximalIdeal_map_eq_target_maximalIdeal_pow_ramificationIndex`
proves exactly the published Library statement
`Langlands.NYLL.LocalFieldTheory.DiscreteValuationField.ValuedExtension.maximalIdeal_map_eq_target_maximalIdeal_pow_ramificationIndexStatement`
of the module
`Langlands.NYLL.ValuedFieldTheory.LocalField.DiscreteValuationField.RamificationIdeal.ImageStatements`.
Its result type is that statement applied to `base` and `target`. The
statement module and its imports are not edited.

Mathematically: let `K → L` be an extension of fields carrying chosen complete
discretely valued structures `base` and `target`, with the base valuation
extended by the target valuation (`Valuation.HasExtension`). Then the ideal of
the target valuation subring generated by the image of the base maximal ideal
is the `e`-th power of the target maximal ideal, where `e` is Mathlib's
ramification index `Ideal.ramificationIdx' base.maximalIdeal target.maximalIdeal`.

## Telescope

The four universes `u v w x` remain independent. The complete telescope is

```lean

(base : CompleteDVF.{u,v} K) (target : CompleteDVF.{w,x} L)
[base.valuation.HasExtension target.valuation]
```

There are no further element or natural-number binders, and no
finite-dimensionality or additional module hypothesis is introduced. The
chosen `CompleteDVF` projections (`valuation`, `valuationSubring`,
`maximalIdeal`) and the canonical algebra
`algebraMap base.valuationSubring target.valuationSubring` supplied by
`Valuation.HasExtension` are the published ones.

## Proof

1. **Unfold the statement.** A `change` replaces the Statement by its body
   `Ideal.map (algebraMap base.valuationSubring target.valuationSubring) base.maximalIdeal =
   target.maximalIdeal ^ Ideal.ramificationIdx' base.maximalIdeal target.maximalIdeal`.
2. **The image is nonzero (`hne`).** The algebra map between the valuation
   subrings is injective (`Valuation.HasExtension.algebraMap_injective`), so by
   `Ideal.map_eq_bot_iff_of_injective` the mapped ideal is `⊥` only if
   `base.maximalIdeal = ⊥`. The base valuation subring is a discrete valuation
   ring, so its maximal ideal is nonzero (`IsDiscreteValuationRing.not_a_field`).
3. **The image is a power of the target maximal ideal.** The target valuation
   subring is a Noetherian local domain with principal maximal ideal, so
   Mathlib's `exists_maximalIdeal_pow_eq_of_principal` writes the nonzero mapped
   ideal as `target.maximalIdeal ^ n` for some `n` (`hn`).
4. **No containment in the next power (`hnot`).** The target valuation subring
   is a Dedekind domain whose maximal ideal is neither `⊥`
   (`IsDiscreteValuationRing.not_a_field`) nor `⊤` (`Ideal.IsMaximal.ne_top`).
   Hence `Ideal.pow_right_strictAnti` gives
   `target.maximalIdeal ^ (n + 1) < target.maximalIdeal ^ n`, so
   `target.maximalIdeal ^ n` is not contained in `target.maximalIdeal ^ (n + 1)`.
5. **Identify the exponent (`he`).** The mapped ideal is contained in
   `target.maximalIdeal ^ n` (from `hn`) and, rewriting with `hn`, not in
   `target.maximalIdeal ^ (n + 1)` (from `hnot`). Mathlib's
   `Ideal.ramificationIdx'_spec` therefore gives
   `Ideal.ramificationIdx' base.maximalIdeal target.maximalIdeal = n`.
6. **Conclude.** Rewriting the exponent by `he` turns the goal into `hn`.

Only the standard axioms `propext`, `Classical.choice` and `Quot.sound` are used.
Every imported mathematical dependency is already in the Library or in the
pinned Mathlib environment.
