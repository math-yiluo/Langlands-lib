## Exact data and scalar maps

The target quantifies, in order, over
`(K : Type u) (L : Type w) [Field K] [Field L] [Algebra K L]
[FiniteDimensional K L] (base : CompleteDVF.{u, v} K) [Algebra.IsSeparable K L]`.
The `K`-algebra structure on `L` and the complete discrete valuation `base`
are supplied arbitrary data. The value group stored in `base` lies in
`Type v`; the three universe levels remain independent.

Write

- `A := base.valuation.valuationSubring`, the actual valuation subring of `K`;
- `B := integralClosure A L`, Mathlib's actual integral-closure subalgebra of `L`;
- `m := IsLocalRing.maximalIdeal A`, using the valuation-subring local-ring instance;
- `M := CanonicalIntegralClosure.maximalIdeal (K := K) (L := L) base`, the
  published M245.007 ideal of `B`.

The conclusion is `∃ n : ℕ, 0 < n ∧ m.map (algebraMap A B) = M ^ n`.
The scalar map `algebraMap A B` is the canonical map obtained by the inclusion
`A → K`, the supplied `algebraMap K L`, and corestriction to the integral
closure. The image ideal is generated by the images of elements of `m`.
The power is ordinary Mathlib ideal power. These objects and maps are not
transported to other rings or replaced by a chosen extension valuation.
The quantifiers include every finite separable extension, including `L = K`.
There are no additional premises.

## Implemented proof

The proof follows the original argument.

1. Introduce exactly the quantified data. Define the local abbreviations `A`
   and `B`, and install
   `integralClosure_isLocalRing_of_finite_separable.{u, v, w} K L base`
   as a local `IsLocalRing B` witness.
2. Unfold the canonical maximal ideal through `change`, expressing the goal
   with `IsLocalRing.maximalIdeal B`. The published M245.007 definition uses
   precisely the M245.006 witness installed in step 1. Thus this is a
   definitional identification of the same ideal, with the same ring and
   scalar maps. No global instance is added.
3. Apply the published M245.012 theorem to obtain `n : ℕ` and
   `hn : m.map (algebraMap A B) = M ^ n`. Use this exponent and equality;
   only positivity remains.
4. If `0 < n` were false, `Nat.eq_zero_of_not_pos` would give `n = 0`.
   Simplifying `hn` then gives
   `htop : m.map (algebraMap A B) = ⊤`, since the zeroth ideal power is the
   unit ideal.
5. Apply the published M245.008 containment theorem to get
   `m.map (algebraMap A B) ≤ IsLocalRing.maximalIdeal B`.
   Rewrite with `htop` to conclude
   `⊤ ≤ IsLocalRing.maximalIdeal B`.
6. `top_le_iff.mp` makes that maximal ideal equal to `⊤`, contradicting
   `(IsLocalRing.maximalIdeal.isMaximal B).ne_top`. This proves `0 < n`.

The Mathlib maximal-ideal API is from
`Mathlib/RingTheory/LocalRing/MaximalIdeal/Defs.lean`, available through the
published imports. The localness witness, decomposition and containment are
proved imported facts, rather than extra hypotheses. No further helper
declaration is required.
