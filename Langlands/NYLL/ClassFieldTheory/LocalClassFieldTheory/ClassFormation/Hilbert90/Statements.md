## Exact statement

```lean
def Langlands.NYLL.LocalClassFieldTheory.unitsTateHminusOne_card_eq_oneStatement
    (K L : Type) [Field K] [Field L] [Algebra K L] [FiniteDimensional K L]
    (g : Gal(L/K)) (hg : ∀ σ : Gal(L / K), σ ∈ Subgroup.zpowers g) : Prop :=
  Nat.card (tateCohomology (Rep.ofAlgebraAutOnUnits K L) (-1)) = 1
```

The parameters are the theorem's binders, in the source order and with the
source binder kinds (including the bound-variable name `σ` in `hg`), and the
body is the theorem's asserted proposition. For a finite extension `L/K`
whose automorphism group `Gal(L/K)` is generated by `g`, it says that
Mathlib's Tate cohomology `Ĥ⁻¹(Gal(L/K), Lˣ)` of the integral unit
representation has exactly one element (`Nat.card … = 1`). The `Fintype`
instance on `Gal(L/K)` is Mathlib's `AlgEquiv.fintype`, as in the source. No
Galois hypothesis is assumed. `g` and `hg` do not occur in the proposition;
they remain premises of the target, as in the source.

This target and M112.005 (`hilbert90_unitsTateHminusOne_isZeroStatement`, in
`Langlands/NYLL/GaloisCohomology/Cyclic/GaloisCohomology/Statements`) are
different propositions about the same object (cardinality one versus being a
zero object), so neither replaces the other.

## Scope

This target is Hilbert 90 in the form of a cardinality statement for
negative-degree Tate cohomology of units. It does not assert a
class-formation, cup-product, transfer or reciprocity result, and in
