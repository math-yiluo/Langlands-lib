# Finite abstract fields have finite residue subfields: target

This module states NYLL source unit M250.011 as a closed proposition. It
exports one Prop-valued `def` in namespace
`Langlands.NYLL.LocalClassFieldTheory`:

- `localAbstractFixedResidueIntermediateField_finiteDimensionalStatement`
  (M250.011), for the source theorem
  `localAbstractFixedResidueIntermediateField_finiteDimensional`.

Nothing is proved here. A later proof unit will prove it under the adapted
source name
`Langlands.NYLL.LocalClassFieldTheory.localAbstractFixedResidueIntermediateField_finiteDimensional`.

Mathematically, let `K` be a nonarchimedean local field, let `K^sep` be its
separable closure, and let `B` be the valuation ring
`localSeparableValuationSubring K` of `K^sep` chosen in M249.006. Let `λ` be
the residue field of `B` (`selectedResidueField B`) and let `κ_K` be the
residue field attached to `B` over `K` (`decompositionResidueField K B`), so
that `λ` is a field extension of `κ_K`.

Let `H` be a closed subgroup of `Gal(K^sep/K)`, let `E = (K^sep)^H` be its
fixed field and let `κ_E` be the residue field attached to `B` over `E`
(`decompositionResidueField E B`), which also maps to `λ`. Let
`F ⊆ λ` be the intermediate field over `κ_K` generated by the image of
`κ_E` (M250.001). The statement says:

if `H` has finite index in `Gal(K^sep/K)`, then `F` is finite-dimensional
over `κ_K`.

The finite-index hypothesis is written, as in the source, in the
presentation of abstract class field theory: `H` has finitely many cosets in
the subgroup representing the distinguished base field, which is the whole
group. The source docstring says the same thing: a finite abstract field has
a genuinely finite residue subfield inside the selected residue algebraic
closure.

## The proposition

```lean
attribute [local instance] Langlands.NYLL.PortInternal.M250.d002
  Langlands.NYLL.PortInternal.M250.d003 Langlands.NYLL.PortInternal.M250.d004

def localAbstractFixedResidueIntermediateField_finiteDimensionalStatement : Prop :=
  ∀ (K : Type) [Field K] [ValuativeRel K] [TopologicalSpace K]
    [IsNonarchimedeanLocalField K]
    (H : ClosedSubgroup (Gal(SeparableClosure K/K)))
    [Finite
      ((baseField (Gal(SeparableClosure K/K))).toSubgroup ⧸
        extensionSubgroup
          (baseField (Gal(SeparableClosure K/K))) H
          (le_baseField H))],
    FiniteDimensional
      (decompositionResidueField K (localSeparableValuationSubring K))
      (localAbstractFixedResidueIntermediateField K H)
```

The `attribute` line is inside a `section` that ends after the definition,
so the three instances are not exported (see "Local instances" below).

The definition has no universe parameters: `K` lives in `Type`, as in the
source. The binders, in order, are the source section variables (lines

### The finiteness hypothesis

`baseField G` (M010.003) is the closed subgroup of `G` whose underlying
subgroup is `⊤`, the whole group; in abstract class field theory it
represents the distinguished base field. `le_baseField H` (M010.005) is the
proof that `H.toSubgroup ≤ (baseField G).toSubgroup`.
`extensionSubgroup (baseField G) H (le_baseField H)` (M004.002) is the
abbreviation for `H.toSubgroup.subgroupOf (baseField G).toSubgroup`, that is,
`H` viewed as a subgroup of the subgroup `⊤`. So the instance binder says
that this subgroup has finitely many cosets in `⊤`, which is the same as
saying that `H` has finite index in `Gal(K^sep/K)`. By Galois theory this
means that the fixed field `E` is a finite extension of `K`.

The binder is an instance binder because it is one in the source. The
conclusion does not mention it; it is a genuine hypothesis, as in the
source. It is a `∀`-binder of the proposition, not an argument of the
definition, so no unused-variable linter option is needed.

### The conclusion

`FiniteDimensional κ_K F` is Mathlib's `FiniteDimensional`
(`Module.Finite`) for `F = localAbstractFixedResidueIntermediateField K H`,
an `IntermediateField` of `selectedResidueField (localSeparableValuationSubring K)`
over `decompositionResidueField K (localSeparableValuationSubring K)`. Here
`F` is used as a type through its coercion to the subtype of its elements.

The source file declares three local instances on that subtype (M250.002–
M250.004, lines 54–79): the algebra `F.algebra` over `κ_K`, and the scalar
action and module structure derived from it. They are in scope at the source
theorem. The Library publishes them under the reserved names
`Langlands.NYLL.PortInternal.M250.d002`, `d003` and `d004`, also as local
instances. As in the source, this module activates them with
`attribute [local instance]` before the definition, so the module structure
in `FiniteDimensional` is elaborated as in the source.

A private probe printed both elaborations with `pp.explicit`. With the three
instances active, the module structure in the conclusion is
`Langlands.NYLL.PortInternal.M250.d004 K H`. Without them, Lean elaborates it
as Mathlib's `IntermediateField.module'`. The probe checked by `Iff.rfl` that
the two propositions are definitionally equal (both module structures are
the scalar action of `κ_K` on `λ` restricted to `F`). So activating the instances changes only the syntactic form of
the target, not its meaning.

  and valuation ring `A` of `L` the extension
  `selectedResidueField A / decompositionResidueField K A` is normal. It is
  not yet published.

The published M099.003 proof `ambientQuotientFiniteOfAbstractFinite` is
used as in the source. The proof runs as follows. By M099.003, `H` has
finite index in `Gal(K^sep/K)`. Since the residue action
`ρ_K : Gal(K^sep/K) → Aut(λ/κ_K)` is surjective (M249.021), the index of
`ρ_K(H)` divides the index of `H`, so it is finite. By M250.007,
`ρ_K(H)` is the fixing subgroup of `F`. A closed subgroup of finite index
is open, so the fixing subgroup of `F` is open, and by Mathlib's
`InfiniteGalois.isOpen_iff_finite` the field `F` is finite-dimensional over
`κ_K`.

The probe makes one change to the source text: before applying
`InfiniteGalois.isOpen_iff_finite`, which needs `IsGalois κ_K λ`, it adds
`have : IsGalois k Omega := IsGalois.mk`. The source compiles without this
line against its pinned Mathlib `065356127b`, so there instance search finds
the instance; in our Mathlib `5ed29652` it does not. `IsGalois.mk` builds it
from the normality hypothesis (M243.030) and separability. A second probe
file in the same check printed the separability instance that instance
search finds: Mathlib's
`Algebra.IsAlgebraic.isSeparable_of_perfectField`, with algebraicity from
`Normal.toIsAlgebraic` and perfectness from `PerfectField.ofFinite` applied
to the published M249.014 instance `localDecompositionResidueFinite`
(`κ_K` is finite). This shows that the target is the intended proposition and that its proof
needs, besides published declarations, only the proofs of M249.021 and
M250.007 and the instance M243.030. The probe is development evidence only;
the proof is a separate unit and is not part of this module.

## Relation to other Library and Mathlib declarations

The whole Library at commit `e1fa6f689f9e976eb7574f0dce4453b3b5705ac0` was
searched for `localAbstractFixedResidueIntermediateField`. It occurs only in
its M250.001 definition and in the local instances M250.002–M250.004. No
Library declaration states that it is finite-dimensional. The published
M099.005 target `abstractFixedField_finiteDimensionalStatement` says, under
the same finiteness hypothesis, that the fixed field `E` itself is
finite-dimensional over the base field; the present target is the analogous
statement for residue fields inside `λ`. Mathlib's
`InfiniteGalois.isOpen_iff_finite`, which the source proof uses, is about
the intermediate fields of one Galois extension. Mathlib has no
declaration about `selectedResidueField`, which is a Library definition.
