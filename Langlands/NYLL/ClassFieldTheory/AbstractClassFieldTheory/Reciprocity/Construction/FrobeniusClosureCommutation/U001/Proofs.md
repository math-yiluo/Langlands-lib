## Implemented proof

The proof unfolds the target with `show` to `q * c.1 = c.1 * q`. It first installs, as a local instance, the closedness of `D.extensionInertiaWithin K.field L hLK = L.toSubgroup.subgroupOf K.field.toSubgroup ⊓ D.fieldInertiaWithin K.field` in `G_K`: the first subgroup is the preimage of the closed set `L` under the continuous inclusion, and the second is the set where the continuous restricted degree `D.restrictedDegree K.field` (M010.008) equals `1`, closed because `ZHatMul` is Hausdorff; their intersection is closed. This is the source proof of the theorem `extensionInertiaWithin_isClosed` (M014.022, `Nyll/ClassFieldTheory/AbstractClassFieldTheory/Degree/FrobeniusFixedField.lean`, docstring line 446 and theorem lines 447–464, tactic block lines 452–464; retained file SHA-256 `cda9dddf5f551fc8c81de825093b52cba99d644e45eb274682d2ee986585bfe3`). Its statement is published as `Langlands.NYLL.ClassFormation.DegreeData.extensionInertiaWithin_isClosedStatement`, but no proof of it is in the Library at base `72480b70c88adff84a438bd7029d64ee3977469c`, so the closedness is proved here inside the theorem's own proof as an anonymous local instance; no declaration under the name `extensionInertiaWithin_isClosed` is added. With this instance Mathlib makes the quotient `Q` Hausdorff. The subgroup generated by `X = {σ.1}` lies in the centralizer of `{q}` by `hq`; the centralizer is closed (`Set.isClosed_centralizer`), so the topological closure of the generated subgroup, which contains `c.1`, lies in it too (`Subgroup.topologicalClosure_minimal`), and `Subgroup.mem_centralizer_singleton_iff` gives the commutation. These steps are the source's.

```lean
/-- Commuting with the chosen generator means commuting with its closed
procyclic closure. -/
theorem frobeniusClosure_commutes_of_commutes_generator (D : DegreeData G)
    [IsTopologicalGroup G] [CompactSpace G] [T2Space G]
    [TotallyDisconnectedSpace G]
    (K : FiniteResidueAbstractField D) (L : ClosedSubgroup G)
    (hLK : L.toSubgroup ≤ K.field.toSubgroup)
    [hLnormal : (extensionSubgroup K.field L hLK).Normal]
    (σ : D.FrobeniusElements K L hLK)
    (q : K.field.toSubgroup ⧸ D.extensionInertiaWithin K.field L hLK)
    (hq : q * σ.1 = σ.1 * q)
    (c : D.frobeniusClosure K L hLK σ) :
    q * c.1 = c.1 * q := by
  let : IsClosed
      (D.extensionInertiaWithin K.field L hLK : Set K.field.toSubgroup) :=
    D.extensionInertiaWithin_isClosed K L hLK
  let : T2Space
      (K.field.toSubgroup ⧸ D.extensionInertiaWithin K.field L hLK) := by
    infer_instance
  let Q := K.field.toSubgroup ⧸ D.extensionInertiaWithin K.field L hLK
  let X : Set Q := Set.range (fun _ : Unit => σ.1)
  have hclosure : Subgroup.closure X ≤
      Subgroup.centralizer ({q} : Set Q) := by
    rw [Subgroup.closure_le]
    rintro x ⟨i, rfl⟩
    exact Subgroup.mem_centralizer_singleton_iff.mpr hq.symm
  have htop : (Subgroup.closure X).topologicalClosure ≤
      Subgroup.centralizer ({q} : Set Q) :=
    Subgroup.topologicalClosure_minimal _ hclosure
      (Set.isClosed_centralizer (M := Q) ({q} : Set Q))
  have hc : c.1 ∈ (Subgroup.closure X).topologicalClosure := c.2
  exact (Subgroup.mem_centralizer_singleton_iff.mp (htop hc)).symm
```
