### M042.001

```lean
def frobeniusClosure_commutes_of_commutes_generatorStatement (D : DegreeData G)
    [IsTopologicalGroup G] [CompactSpace G] [T2Space G]
    [TotallyDisconnectedSpace G]
    (K : FiniteResidueAbstractField D) (L : ClosedSubgroup G)
    (hLK : L.toSubgroup ≤ K.field.toSubgroup)
    [hLnormal : (L.toSubgroup.subgroupOf K.field.toSubgroup).Normal]
    (σ : D.FrobeniusElements K L hLK)
    (q : K.field.toSubgroup ⧸ D.extensionInertiaWithin K.field L hLK)
    (hq : q * σ.1 = σ.1 * q)
    (c : D.frobeniusClosure K L hLK σ) : Prop :=
    q * c.1 = c.1 * q
```

Let `G` be a compact, Hausdorff, totally disconnected topological group with
degree data `D`, `K` a field with finite residue quotient and `L` a closed
subgroup of `G_K` that is normal in `G_K`. If an element `q` of
`G_K ⧸ I_L` commutes with the Frobenius element `σ`, then `q` commutes with
every element `c` of the closed subgroup `Γ` topologically generated by `σ`.

### M042.002

```lean
def conjugate_frobeniusFixedField_eq_of_commutesStatement (D : DegreeData G)
    [IsTopologicalGroup G] [CompactSpace G] [T2Space G]
    [TotallyDisconnectedSpace G]
    (K : FiniteResidueAbstractField D) (L : ClosedSubgroup G)
    (hLK : L.toSubgroup ≤ K.field.toSubgroup)
    [hLnormal : (L.toSubgroup.subgroupOf K.field.toSubgroup).Normal]
    (σ : D.FrobeniusElements K L hLK)
    (q : K.field.toSubgroup ⧸ D.extensionInertiaWithin K.field L hLK)
    (hq : q * σ.1 = σ.1 * q) : Prop :=
    let k : K.field.toSubgroup := Quotient.out q
    conjugateClosedSubgroup (D.frobeniusFixedField K L hLK σ) k.1⁻¹ =
      D.frobeniusFixedField K L hLK σ
```

In the same setting, if `q` commutes with `σ` and `k ∈ G_K` is the
representative of `q` chosen by `Quotient.out`, then conjugation by `k`
stabilizes the fixed field: the closed subgroup of `G` with underlying
subgroup `k Σ k⁻¹` (with `k` viewed in `G`) equals `Σ`.
