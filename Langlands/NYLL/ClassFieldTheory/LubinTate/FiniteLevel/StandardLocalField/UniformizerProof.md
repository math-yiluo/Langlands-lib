# The standard local-field uniformizer is a uniformizer (M335.021)

`Langlands.NYLL.LubinTate.standardLocalFieldUniformizer_isUniformizer`
proves the fully applied published target
`Langlands.NYLL.LubinTate.standardLocalFieldUniformizer_isUniformizerStatement K`.
It preserves the complete source telescope:

```lean
(K : Type) [Field K] [ValuativeRel K] [TopologicalSpace K]
  [IsNonarchimedeanLocalField K]
```

Thus `K` is explicit and in Type 0, with no additional hypothesis. The
conclusion is that the underlying field element of
`standardLocalFieldUniformizer K` satisfies Mathlib's
`Valuation.IsUniformizer` predicate for `(standardLocalField K).valuation`.

## Implemented proof

The proof first unfolds the named target. It imports the published
`Langlands.NYLL.LocalFieldTheory.chosenIntegerRingUniformizer_irreducible`
from the M133.005 proof module, rather than reproducing that theorem.
The ring equivalence `standardLocalFieldIntegerEquiv K` transports this
irreducibility to `standardLocalFieldUniformizer K` by `Irreducible.map`.
For the valuation subring's discrete valuation ring structure,
`hirr.maximalIdeal_eq` identifies its maximal ideal with the principal
ideal generated by this element. Mathlib's
`Valuation.isUniformizer_of_maximalIdeal_eq_span` then proves the desired
uniformizer property. All valuation and discrete-rank instances come from
the published standard local-field package.

The only imports are the exact target module
`Langlands.NYLL.ClassFieldTheory.LubinTate.FiniteLevel.StandardLocalField.UniformizerStatements`
and the published proof module
`Langlands.NYLL.ValuedFieldTheory.LocalField.NonarchimedeanLocalField.IdealQuotients.U005.Proofs`.

is introduced.
