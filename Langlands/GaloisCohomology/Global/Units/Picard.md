# The `S`-Picard group and `H¹(G_S, 𝒪_Sˣ)`

`Langlands/GaloisCohomology/Global/Units/Picard.lean`, namespace `Langlands.GaloisCohomology`.

`SPicardGroup S` is `Pic(𝒪_S)`: the divisors prime to `S` modulo the divisors of units of `F`. It is
generated by the images of the ideal classes of `F` (`closure_range_sPicardGen`), hence finite
(`finite_sPicardGroup`) and killed by the class number (`classNumber_nsmul_sPicardGroup`).

For a Galois extension `Ω / F`, the `G_S`-modules `𝒪_Sˣ ⊆ K_Sˣ` give the short exact sequence
`0 → 𝒪_Sˣ → K_Sˣ → K_Sˣ/𝒪_Sˣ → 0` (`sUnitsQuotSequence_shortExact`). Since `H¹(G_S, K_Sˣ) = 0`
(Hilbert 90 for `K_S / F`, foundations), the connecting map
`(K_Sˣ/𝒪_Sˣ)^{G_S} → H¹(G_S, 𝒪_Sˣ)` is onto with kernel the image of `Fˣ`
(`invariantsToCohomologyOne_surjective`, `_eq_zero_iff`). The invariants are the classes of the
`S`-invariant units (`sInvariantToInvariants_surjective`), and their divisors (`divAbove`) define
`cohomologyOneSUnitsToSPicard : H¹(G_S, 𝒪_Sˣ) → Pic(𝒪_S)`.

- It is injective for every `S` (`cohomologyOneSUnitsToSPicard_injective`).
- `S`-units have divisor zero (`divAbove_eq_zero_of_mem`). Hence, if `x ^ N = a y` with `a ∈ Fˣ`
  and `y` an `S`-unit of `K_S`, then `N • divAbove(x) = sDivisorOf(a)`
  (`nsmul_divAbove_eq_sDivisorOf`); with `y = 1` this is the identity behind Kummer capitulation
  (`exists_divAbove_eq`).
- If `Ω` is separably closed, its image contains every class killed by an `N` invertible outside
  `S` (`exists_cohomologyOneSUnitsToSPicard_eq`, by Kummer capitulation `exists_divAbove_eq`).
- Hence, if the order of `Pic(𝒪_S)` is invertible outside `S`, it is an isomorphism
  `cohomologyOneSUnitsEquiv : H¹(G_S, 𝒪_Sˣ) ≃+ Pic(𝒪_S)`.

Without that hypothesis the map is still an isomorphism (NSW (8.3.11) (ii)), because every class of
`Pic(𝒪_S)` becomes principal in `K_S`; this is the principal ideal theorem (capitulation in the
Hilbert class field, which is unramified and so contained in `K_S`). The isomorphism for every `S`
is proved in `PicardCapitulation.lean` (`cohomologyOneSUnitsToSPicard_surjective`,
`cohomologyOneSUnitsPicardEquiv`) from the principal ideal theorem of the copy `Nyll/`, stated in
`Langlands.ClassFieldTheory.Global.Artin.PrincipalIdeal`. That module imports the copy, so the other
files of this directory do not import it. The hypothesis holds for instance when `S` contains the places above the primes
dividing the class number.

## Outline of the proofs

Injectivity: if the divisor class of an `S`-invariant unit `x` is trivial, `divAbove(x) =
sDivisorOf(a)` for some `a ∈ Fˣ`, so `x a⁻¹` is an `S`-invariant unit with divisor zero, i.e. an
`S`-unit (`mem_maximalSUnits_of_divAbove_eq_zero`); then the class of `x` in `K_Sˣ/𝒪_Sˣ` comes from
`Fˣ` and its image in `H¹` vanishes. Surjectivity on `N`-torsion: write the class as that of a
divisor `D` with `N • D = sDivisorOf(a)` and apply `exists_divAbove_eq`. The finiteness of
`Pic(𝒪_S)`: the class of `v ∉ S` is the image of the ideal class of `v`, and `ClassGroup (𝓞 F)` is
finite. `nsmul_divAbove_eq_sDivisorOf`: `divAbove` is additive on the `S`-invariant units, so
`N • divAbove(x) = divAbove(a) + divAbove(y)`, with `divAbove(a) = sDivisorOf(a)`
(`divAbove_algebraMap`) and `divAbove(y) = 0`.
