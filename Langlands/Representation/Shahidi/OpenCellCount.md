# Counting classes of bounded depth

Module `Langlands.Representation.Shahidi.OpenCellCount`, namespace
`Langlands.Shahidi.OpenCell`.

## Contents

- `residueLift`, `digitValue`, `digitClass`: base-`ϖ` digit expansions of the classes of
  `ϖ^(-D) 𝒪 / 𝒪` with digits in a set of residue representatives.
- `mem_integralMatrices_iff`: membership in `integralMatrices` is entrywise integrality.
- `finite_and_ncard_le`: a set of classes of `M_(a×b)(K) / M_(a×b)(𝒪)` all of whose
  representatives `Y` satisfy `ϖ^D Y` integral is finite with at most `q^(a b D)` elements.

## Provenance

Elementary counting; used for the convergence of the open-cell sum.
