# Six decompositions for actual block subgroups

This module states `Langlands.Geometric.BlockParabolicSixDecomposable.{uR}`
as a proposition-valued definition. It does not prove that proposition.

## Statement

The ring universe `uR` is arbitrary. The proposition quantifies over every
commutative ring `R : Type uR`, every natural rank `n` (including `n = 0`),
block shapes `B, C : BlockShape n`, and permutations
`w : Equiv.Perm (Fin n)`. For these data put

```
P = B.parabolic R       M = B.leviSubgroup R       U = B.unipotentSubgroup R
Q = C.parabolic R       N = C.leviSubgroup R       V = C.unipotentSubgroup R
g = GeneralLinear.permutation n R w.
```

The proposition asserts exactly `General.SixDecomposable P M U Q N V g`,
using the definition in `Langlands.Representation.Geometric.GeneralIntersections`.

All seven objects are the published actual matrices and subgroups of
`Langlands.GeneralLinear n R`, that is, of `Matrix.GeneralLinearGroup (Fin n) R`:

- `B.parabolic R` is the standard upper block parabolic. In the consecutive
  block numbering of `B`, its matrices have zero blocks strictly below the
  diagonal.
- `B.leviSubgroup R` is the range of the block-diagonal embedding
  `B.leviEmbedding R`. It consists of the invertible block-diagonal matrices.
- `B.unipotentSubgroup R` is the kernel of the diagonal-block projection
  `B.leviProjection R`, included as a matrix subgroup. Thus it consists of the
  matrices in `B.parabolic R` whose diagonal blocks are identity matrices.
- The groups for `C` are defined in the same way.
- `GeneralLinear.permutation n R w` is the permutation matrix sending each
  standard basis vector `e j` to `e (w j)`. Its `(i, j)` entry is `1` if
  `w j = i` and `0` otherwise.

`General.conjugate H x` is the actual subgroup `x H x⁻¹`. Written out,
`General.SixDecomposable P M U Q N V g` is the conjunction, in this order, of

1. `General.IsDecomposable (General.conjugate P g) N V`;
2. `General.IsDecomposable (General.conjugate M g) N V`;
3. `General.IsDecomposable (General.conjugate U g) N V`;
4. `General.IsDecomposable (General.conjugate Q g⁻¹) M U`;
5. `General.IsDecomposable (General.conjugate N g⁻¹) M U`;
6. `General.IsDecomposable (General.conjugate V g⁻¹) M U`.

`General.IsDecomposable H A K` is the literal equality of sets

```
(H : Set (GeneralLinear n R)) ∩ ((A : Set _) * (K : Set _))
  = ((H ⊓ A : Subgroup _) : Set _) * ((H ⊓ K : Subgroup _) : Set _).
```

The products are pointwise products of subsets. In each product the Levi
factor (`N` or `M`) comes first and the radical factor (`V` or `U`) comes
second. The claim concerns these actual sets and groups. It does not concern a
subgroup join, a subgroup generated by the factors, or an abstract semidirect
product.

There is no topology, field assumption, nontriviality assumption,
positive-rank assumption, minimal-Weyl-representative assumption, supplied
intersection refinement, projection-stability hypothesis, factorization
premise or decomposability premise. In particular, the statement includes rank
zero, the zero ring, and every permutation.

## Provenance

Bernstein and Zelevinsky, *Induced representations of reductive p-adic groups I*
(1977), section 5.1, printed pages 459–460 (PDF pages 20–21), works with closed
subgroups `P, M, U` and `Q, N, V` of an l-group satisfying `MU = P` and
`NV = Q`. It writes `w(g) = w g w⁻¹` for a chosen `w` with `Pw⁻¹` in the
orbit `Z`. It calls a subgroup `H` decomposable with respect to `(M, U)` if
`H ∩ (MU) = (H ∩ M)(H ∩ U)`. Condition 5.1(4) on printed page 460 requires
that `w(P), w(M), w(U)` are decomposable with respect to `(N, V)`, and that
`w⁻¹(Q), w⁻¹(N), w⁻¹(V)` are decomposable with respect to `(M, U)`. The six
conjuncts above follow this order, with the same Levi-then-radical products.

Section 6.4, printed pages 468–469 (PDF pages 29–30), applies Theorem 5.2 to
parabolic triples of a reductive group over a non-archimedean field. It takes
the representative `w` in the set `W^{M,N}` of minimal double-coset
representatives, and states that conditions 5.1(1)–(4) follow directly from
section 6.1. Section 6.1, printed page 467 (PDF page 28), gives the
intersection formulas for the subgroups attached to closed sets of roots.

The registered original is `bernstein-zelevinsky-1977-induced-i`, SHA-256
`8424600228ab72c5937e45edceefcae410a2a0b8f5ebf282185691542aa89092`.
Sections 5.1 and 6.1–6.4 of the original were read. The project has no
erratum note for this source.

The source asserts the six conditions only for minimal Weyl representatives in
the reductive-group setting. The formulation here, for arbitrary commutative
rings, all ranks and all permutations, is an internal algebraic specialization
to the Library's explicit block matrices. The source does not state it in this
generality.

The broader scope is expected to hold for an elementary reason. Let `x` be a
matrix that lies in the conjugated group and also in the product of the Levi
and radical groups. The proposed proof takes the embedded diagonal-block
projection `m` of `x`. This projection keeps the entries of `x` inside the
blocks and sets every entry between two distinct blocks to zero. A
permutation-conjugated block parabolic, Levi or radical is cut out by
conditions requiring some entries to be zero and some to be identity entries.
The projection preserves such conditions. The complementary radical factor is
then `m⁻¹ * x`, so that `x = m * (m⁻¹ * x)` in the required order. This is
proposed proof guidance only. It is not a hypothesis and is not proved in this
module.

## Proof boundary

This module leaves the proposition unproved. A separate proof successor must
prove the unchanged proposition and describe its implemented argument.

The statement does not establish the local orbit integration, the Haar
comparison, the normalization cancellation or the natural normalized Jacquet
comparison. Those parts of
`Langlands.Geometric.PadicParabolicOrbitJacquetComparison` remain outstanding.
Once proved, this proposition would supply the six conditions of BZ77 5.1(4)
for the actual block groups over actual finite p-adic extensions, but none of
those remaining comparisons.
