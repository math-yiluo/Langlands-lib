# Counting generic classes by cuspidal multisets

Every block of a cuspidal datum has a nonzero Whittaker space by cuspidal genericity. Commutativity of the Gelfand–Graev endomorphisms bounds that dimension by one, so the dimension is exactly one. Whittaker heredity then gives dimension one for the induced datum. The constituent pairing formula says that this datum contains exactly one generic constituent, since each positive term is at least one.

Each generic class has cuspidal support. Two supports of that class have the same labels, and the multiplicities of a support depend only on its unordered labels. Thus the generic class and its cuspidal multiset determine each other. Every multiset of the required total rank is realized by taking a list of its entries as the ordered blocks. This gives the equivalence used for counting. The Gelfand–Graev dimension formula computes the number of multisets in rank `m + 1` as the number of units in the field times the field cardinality to the power `m`.

The arguments are internal to the finite-field cuspidal count. The proof uses finite Whittaker spaces and actual constituent multiplicities for the Library's cuspidal class models.
