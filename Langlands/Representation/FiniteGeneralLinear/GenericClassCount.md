# Counting generic classes by cuspidal multisets

Fix a nontrivial complex additive character `ψ` of the finite field. In rank `m + 1`, the generic classes are the irreducible constituents of `gelfandGraev ψ (m + 1)`. Every block of a cuspidal datum has a nonzero `ψ`-Whittaker space by cuspidal genericity. Commutativity of the Gelfand–Graev endomorphisms bounds that dimension by one, so the dimension is exactly one. Whittaker heredity then gives Whittaker dimension one for the induced datum. The constituent pairing formula shows that the induced datum contains exactly one generic constituent, since each positive term is at least one.

Each generic class has cuspidal support. Two supports of that class have the same labels, and the multiplicities of a support depend only on its unordered labels. Thus the generic class and its cuspidal multiset determine each other. Every multiset of the required total rank is realized by taking a list of its entries as the ordered blocks. This gives the equivalence used for counting. The theorem `card_cuspidalMultiset_succ` chooses a nontrivial additive character internally and uses the Gelfand–Graev dimension formula to count the multisets in rank `m + 1`. The count is the number of units in the field times the field cardinality to the power `m`.

The arguments are internal to the finite-field cuspidal count. The proof uses finite Whittaker spaces and actual constituent multiplicities for the Library's cuspidal class models.
