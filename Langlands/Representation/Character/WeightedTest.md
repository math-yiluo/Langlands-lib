# Character weights on Schwartz–Bruhat tests

`weightedTest` multiplies a Schwartz–Bruhat test by a locally constant multiplicative character. `weightedTest_apply` gives its value at a group element.

For an admissible representation with an admissible twist, `distribution_twist_weightedTest` evaluates the twisted character on a test by evaluating the original distribution on the weighted test. `distribution_eq_of_equiv` gives equality of character distributions for equivalent admissible representations with the same Haar measure.
