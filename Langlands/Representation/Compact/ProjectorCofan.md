# Actual coproducts from orthogonal projectors

Worker 141 supplies derived linear and categorical infrastructure for the
compact block decompositions. No new source assertion is posed here.

A pointwise finite family of intertwiners has an actual equivariant linear sum.
For orthogonal idempotents on a smooth representation, each range is a smooth
subrepresentation. If their pointwise sum is the identity, the subtype maps of
these ranges are an actual coproduct cofan. The descent morphism to any other
cofan is the pointwise sum of its component morphisms after projection into the
ranges. Orthogonality proves the factorization identities; exhaustion proves
uniqueness.

The final two helpers derive the finite-support and identity-sum hypotheses
from exhaustion by the supremum of the projector ranges. Submodule-supremum
induction shows each vector has finitely many nonzero components: this holds
on each range by orthogonality, at zero, and under addition. A second induction
proves the sum equals the original vector, using idempotence on each range.

The index universe is independent of group and carrier universes. All component
objects and the vertex stay in the fixed carrier universe; no oversized global
coproduct assumption is introduced. Empty index types are covered.
