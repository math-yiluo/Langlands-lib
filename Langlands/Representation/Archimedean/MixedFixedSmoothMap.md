# Pullback from mixed smooth vectors through a fixed Hilbert level

A continuous map from local smooth vectors to smooth vectors in a fixed
Hilbert subspace gives a linear map to the ambient mixed smooth space.
The archimedean smooth inclusion preserves the underlying vector, and
the open subgroup fixing the image witnesses finite smoothness.

An ambient derivative-continuous functional that computes the mixed
functional on this level gives continuity of the pullback by composition
with the derivative map and fixed-level inclusion. If the underlying map
is a bounded intertwiner along the local inclusion, the mixed smooth
map intertwines the corresponding genuine local and ambient actions.
Consequently a mixed evaluation with the prescribed local character
pulls back to a continuous local Whittaker functional.

This internal construction uses the existing genuine derivative topology,
fixed-level inclusion, and mixed smooth vectors.
