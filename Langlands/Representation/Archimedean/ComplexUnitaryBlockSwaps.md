# Composition of the adjacent swaps

The compact test vector is determined by its restriction to the unitary group. The swap of a Hermitian pair preserves the list of weights, so the source and target have the same compact test. For disjoint rows the test is multiplied by the base scalar. For the two rows of the pair there is an additional real factor \((1-2\operatorname{Re}t)/(1+2\operatorname{Re}t)\), since the exponents are \(t\) and \(-\overline{t}\).

The proof composes the swaps in order through the list of blocks, with the identity at each fixed character. The base test receives the product of the nonzero base scalars. A row-difference test for a selected block receives the same product times the relative factor at that block, because its rows are disjoint from every other block. This is the composition used for the signature comparison in Vogan, *The unitary dual of GL(n) over an archimedean field* (1986), Proposition 10.5, p. 476, and Theorem 11.5(f)–(h), p. 479.
