# Finite-dimensional lowest weight modules from minors

Module `Langlands.Representation.Archimedean.GLLowestModule`, namespace
`Langlands.Archimedean.GLReynolds`. It imports `GLLowestWeight` and Mathlib's multivariate
polynomial, derivation and determinant libraries.

This module is the third part of a planned proof of Kostant's multiplicity bound
(`VermaGL.KostantMultiplicityStatement`, Library module `LowerVerma`). For every `A : ℕ` it
constructs a finite-dimensional irreducible module with a lowest weight vector of weight
`A · (0, 1, …, n - 1)`. It contains no Library statement and proves only the results listed
below; no new axioms are used.

## Construction

* `Pol n = MvPolynomial (Fin n × Fin n) ℂ`, the polynomial functions in the entries `x_ab` of
  an `n × n` matrix.
* `polyDer p q`: the derivation of `Pol n` with `x_ab ↦ [a = q] x_pb`, built with
  `MvPolynomial.mkDerivation`. By `polyDer_apply` it equals `Σ_b x_pb ∂/∂x_qb`.
* `polyFam n p q`: the underlying linear map of `polyDer p q`.
* `minorMat r`, `minor r` (`r : Fin n`): the matrix `(x_ij)_{i,j > r}`, indexed by the subtype
  `{s // r < s}`, and its determinant `Δ_r`. This is the bottom right minor of size
  `n - 1 - r`; for `r = n - 1` it is the empty determinant `1`.
* `lowVec n A = Π_r Δ_r ^ A` and `lowWt A = (A · p)_p`.
* `lowSub n A = genSub (polyFam n) {lowVec n A}`, the subspace generated by `lowVec n A`, with
  the abbreviation `LowMod n A`. `lowFam n A` is the restricted family and `lowGen n A` is
  `lowVec n A` as an element of `LowMod n A`.

## Results

* `isGlFamily_polyFam`: the operators `polyFam n p q` satisfy the commutation relations of
  the matrix units. Both sides of `[e_ab, e_cd] = δ_bc e_ad - δ_da e_cb` are derivations, so it
  suffices to compare them on the variables (`MvPolynomial.derivation_ext`).
* `isHomogeneous_polyDer`, `isStable_restrictTotalDegree`: `polyDer p q` preserves homogeneous
  polynomials of each degree (`IsHomogeneous.pderiv`), so the polynomials of total degree at
  most `D` form a stable subspace.
* `der_prod_eigen`, `der_pow_eigen`: if a derivation maps each `g_i` to `c_i g_i`, it maps
  `Π g_i` to `(Σ c_i) Π g_i`.
* `flow p q`: the algebra map `Pol n → (Pol n)[T]`, `x_ab ↦ x_ab + [a = q] x_pb T`.
  `flow_coeff`: the coefficient of `T⁰` in `flow p q f` is `f` and the coefficient of `T¹` is
  `polyDer p q f`. Proof by induction on `f`.
* `flow_minor_lower`: for `q < p`, `flow p q (Δ_r) = Δ_r`. If `r < q`, then also `r < p`. The
  substitution adds `T` times row `p` to row `q` of the minor matrix, and both rows occur in it,
  so the determinant is unchanged (`Matrix.det_updateRow_add_smul_self`). Otherwise row `q` does
  not occur and nothing changes. Hence `polyDer_minor_lower`: `e_pq Δ_r = 0` for `q < p`.
* `flow_minor_diag`, `polyDer_minor_diag`: `flow t t` multiplies row `t` by `1 + T` when
  `r < t` and does nothing otherwise. Hence `e_tt Δ_r = [r < t] Δ_r`.
* `minor_ne_zero`: `Δ_r` is the image of the generic determinant
  `det (Matrix.mvPolynomialX)` under an injective renaming of variables, and that determinant
  is nonzero (`Matrix.det_mvPolynomialX_ne_zero`).
* `lowVec_ne_zero`, `isLowest_lowVec`: `lowVec n A` is a nonzero lowest weight vector of weight
  `lowWt A`. By `der_prod_eigen`, `e_tt` acts on it by `A · #{r : r < t} = A · t`, and `e_pq`
  with `q < p` kills it.
* `lowSub_le` and the `FiniteDimensional` instance: `LowMod n A` lies in the polynomials of
  total degree at most `totalDegree (lowVec n A)`, so it is finite-dimensional.
* `isGlFamily_lowFam`, `intWeights_lowFam`, `isLowest_lowGen`, `lowGen_ne_zero`,
  `genSub_lowGen`: the restricted family satisfies the relations and has integral weights.
  `lowGen n A` is a nonzero lowest weight vector of weight `lowWt A` generating `LowMod n A`.
  These follow from `GLLowestWeight` (`isGlFamily_resFam`, `intWeights_resFam_genSub`,
  `genSub_resFam_eq_top`).
* `eq_top_of_isStable_lowMod`: `LowMod n A` is irreducible: every nonzero stable subspace is
  `⊤`. This is `eq_top_of_lowest` from `GLLowestWeight`.

The construction is the classical realization of irreducible `GL_n`-modules inside the
polynomial functions on matrices, with lowest weight vectors given by products of powers of
corner minors. The module is only needed for weights `A · (0, 1, …, n - 1)`.
