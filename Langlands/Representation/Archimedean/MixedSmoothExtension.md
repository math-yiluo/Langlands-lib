# Continuous finite-level extensions and finite translation

A family of continuous extensions of original evaluations is prescribed
at every compact open level. Assume the smooth images of the original
fixed vectors are dense at each level in the genuine derivative topology.
For a vector fixed at two levels, compare each evaluation with the
evaluation for the intersection. The intersection evaluation agrees
with each of the two extensions on the dense original image of that
extension's level, so all three give the same value on the vector.
This gives one extended evaluation on the mixed smooth space for
each finite argument. Its restriction to each fixed level is the
restriction of the given derivative-continuous functional.

The original smooth representation maps to the mixed smooth space
whenever its supplied map to the genuine smooth space intertwines
finite translations. The map retains the same genuine smooth values.

For a finite translating element, a bounded intertwiner induces a
continuous map on the derivative smooth space. A vector fixed at one
level translates to a vector fixed at the conjugate level. The original
evaluation covariance and the original smooth-map covariance give
agreement on the dense source level. The glued functionals therefore
obey the same finite covariance identity.

A value formula on the original fixed vectors after archimedean
translation computes the glued identity evaluation after both finite
and archimedean translation of any original vector.

A scalar covariance identity comparing that translated value with the
identity value extends to the whole mixed smooth space. At the level
fixing the vector, both expressions are continuous for the derivative
topology and agree on the dense original fixed vectors.

These results are internal applications of derivative-topology
density, bounded smooth intertwiners and the algebraic gluing theorem.
