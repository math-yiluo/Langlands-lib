# Independence of the lowest weight vectors `R(c)(ξ ⊗ v₀)`

Module `Langlands.Representation.Archimedean.GLVermaInject`, namespace
`Langlands.Archimedean.GLReynolds`. It imports `GLVermaTheta` (the trace functional `lamFun`)
and `GLLowestModule` (the finite-dimensional module `LowMod n A` generated by the lowest
weight vector `lowGen n A` of weight `lowWt A`, with `lowWt A p = A · p`).

This module is part of a planned proof of Kostant's multiplicity bound
(`VermaGL.KostantMultiplicityStatement`, Library module `LowerVerma`). It contains no Library
statement and proves only the results listed below; no new axioms are used. The weight
statement for lower Verma modules enters through its proof
`VermaPBW.lowerVermaWeight` (module `LowerVermaPBW`).

## Notation

`λ = lowWt A = A · (0, 1, …, n-1)` as an integral weight and `lamA n A` as a complex weight.
`L = LowMod n A` with family `lowFam n A` and generator `v₀ = lowGen n A`. `M⁻(λ)` is the
Library lower Verma module `VermaGL.LowerVerma n (lamA n A)` with family
`famM n A = famOf (VermaGL.action n (lamA n A))`. `ht`, `casVal`, `wordWt`, `IsUpperWord` are as
in `GLReynolds` and `GLLowestWeight`.

## Results

### Estimates on words and weights

* `ht_add`; `ht_wordWt`: `ht (wordWt l) = Σ_{(a,b) ∈ l} (a - b)`.
* `ht_wordWt_add_length_le`: for an upper word, `ht (wordWt l) + length l ≤ 0`.
* `abs_wordWt_le`: for an upper word, `|wordWt l p| ≤ length l` for each `p`.
* `casVal_lowWt_add_lt`: for a nonempty upper word `l` with `length l ≤ A`,
  `casVal (λ + wordWt l) < casVal λ`. By `casVal_add_sub` and `sum_wordWt_mul`
  (`GLLowestWeight`), the difference is `Σ_{(a,b) ∈ l} (z_a - z_b)` with
  `z_p = 2A p + (wordWt l)_p + 2p + 1 - n`. For a letter `a < b`, the bound
  `|wordWt l| ≤ length l ≤ A` gives `z_a - z_b ≤ -(2A + 2) + 2A = -2`.
* `neg_ht_le`: `-ht μ ≤ (n - 1) Σ_p |μ_p|`.
* `casVal_lowWt_lt_sub`: if `ht μ < 0` and `(n - 1) Σ_p |μ_p| ≤ A`, then
  `casVal λ < casVal (λ - μ)`. The difference equals
  `(2A + 2)(-ht μ) + Σ_p (μ_p² + (n - 1) μ_p)`, and the second sum is at least
  `-(n - 1) Σ_p |μ_p| ≥ -A`.

### Intertwining maps

* `map_cas_comm`, `map_aeval_cas_comm`: a linear map intertwining two families intertwines
  their Casimir operators and every polynomial in them.

### The map `π : M⁻(λ) → L`

* `isLowest_genM`: `gen` is a lowest weight vector of weight `λ` in `M⁻(λ)` (Library
  `BGChase.unitU_smul_gen_diag`, `BGChase.unitU_smul_gen_of_lt`).
* `genSub_genM`: `M⁻(λ)` is generated by `gen` as a module over the family. By induction on
  `U(𝔤𝔩_n)` (`InfinitesimalCharacter.envInduction`), `genSub {gen}` is stable under all of
  `U(𝔤𝔩_n)`, and every element is `u · gen` (`BGChase.smul_gen`).
* `mem_upperSpan_genM`, `exists_word_of_weight`: every element of `M⁻(λ)` lies in the span of
  the vectors `word l gen` with `l` upper (`genSub_le_upperSpan`). Hence every nonzero weight
  vector has weight `λ + wordWt l` for some upper word `l`.
* `piU n A u = u · v₀` (through `envOf`); `piU_mem`: it vanishes on the defining left ideal of
  `M⁻(λ)`, since `v₀` is a lowest weight vector of weight `λ`.
* `piM n A : M⁻(λ) → L`: the induced linear map, with `piM_gen` (`π gen = v₀`) and `piM_fam`
  (`π` intertwines `famM n A` and `lowFam n A`).
* `vermaKer` (**the kernel of `π` has only deep weights**): let `d ≤ A + 1` and let
  `z ∈ M⁻(λ)` be a weight vector of weight `ν` with `π z = 0` and `ht λ - ht ν < d`. Then
  `z = 0`.
  Proof by induction on `d`. For `d = 0`, a nonzero `z` would have weight `λ + wordWt l` with
  `ht (wordWt l) ≤ 0`, contradicting `ht λ - ht ν < 0`. In the inductive step, each
  `e_pq z` (`q < p`) has weight of larger height and lies in `ker π`, so it vanishes by
  induction. Thus `z` is a lowest weight vector. Suppose `z ≠ 0` and write
  `ν = λ + wordWt l`. The Casimir operator acts on `z` by `casVal ν` (`cas_apply_lowest`) and by
  `casVal λ` (`cas_apply_of_mem_genSub`, since `M⁻(λ) = genSub {gen}`), so these are equal.
  If `l = []`, then by `VermaPBW.lowerVermaWeight` the vector `z` is a multiple `c · gen`.
  Since `π z = c · v₀ = 0` and `v₀ ≠ 0` (`lowGen_ne_zero`), `z = 0`. If `l ≠ []`, then
  `length l ≤ -ht (wordWt l) = ht λ - ht ν ≤ A`, and `casVal_lowWt_add_lt` contradicts the
  equality of Casimir values.

### Independence

Let `W` carry a family `s` with a basis `b` of weight vectors, `b_i` of weight `μ_i`, and
assume `(n - 1) Σ_p |μ_i(p)| ≤ A` for every `i`.

* `hom_eq_zero` (**injectivity of `π_*` at weight `λ`**): a vector `y ∈ Hom(W, M⁻(λ))` of
  weight `λ` for `homFam s (famM n A)` with `π ∘ y = 0` vanishes. Each `y(b_i)` is a weight
  vector of weight `λ + μ_i` in `ker π`, and `ht λ - ht (λ + μ_i) = -ht μ_i ≤ A < A + 1`, so
  `vermaKer` applies.
* `polR_eval_ne_zero`: `R(casVal λ) ≠ 0` for `R = polR μ λ`
  `= ∏_{ht μ_i < 0} (X - casVal (λ - μ_i))`, by `casVal_lowWt_lt_sub`.
* `ys_eq_zero` (**independence**): let `σ` be a representation of `𝔤𝔩_n(ℂ)` on a
  finite-dimensional `W` with `s = famOf σ`. Let `c` be coefficients with `c_k = 0` whenever
  `μ_k ≠ 0`, and suppose `Σ_k c_k ys k = 0`, where
  `ys k = R(c)(b_k^* ⊗ v₀) ∈ Hom(W, L)` (`GLTensorLowest`). Then `c = 0`.
  Proof: put `η = Σ_k c_k b_k^*` and lift to `x̃ = η ⊗ gen ∈ Hom(W, M⁻(λ))`, a vector of weight
  `λ`. Let `ỹ = R(c) x̃`. Postcomposition with `π` intertwines the families, so
  `π ∘ ỹ = R(c)(η ⊗ v₀) = Σ_k c_k ys k = 0`. By `hom_eq_zero`, `ỹ = 0`. Apply the trace
  functional `Λ = lamFun σ λ` (`GLVermaTheta`):
  `0 = Λ(ỹ) = R(casVal λ) · Λ(η ⊗ gen) = R(casVal λ) · η` (`lamFun_aeval_cas`,
  `lamFun_smulRight_gen`). Since `R(casVal λ) ≠ 0`, `η = 0`, and evaluating at the basis
  vectors gives `c = 0`.

The choice of the deep weight `λ = A · (0, 1, …, n-1)`, the comparison of Casimir values and
the trace functional are derived content written for this proof of Kostant's bound; the
standard fact used is that weights of `M⁻(λ)` are `λ` plus sums of positive roots
(here proved directly from the generating property of `gen`).
