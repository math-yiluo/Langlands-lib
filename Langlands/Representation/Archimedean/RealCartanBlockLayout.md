# The original real blocks as a Levi coordinate partition

The rank of an ordered list of real blocks is the sum of the ranks of the individual blocks. The position maps from the Levi coordinate chart identify each coordinate fiber with its block. The position characters, exponents, and induced-block tags restrict to those of the corresponding singleton list, by the formulas for concatenated lists.

The two-coordinate fibers are exactly the induced blocks. The list of compact Fourier slots is a permutation of the slots found at the original block starts, as each slot has a unique start and both lists contain the same starts. The full sign-coordinate list can also be grouped into its disjoint block lists. These internal layout facts use the original block order and its actual Fourier and sign filters.
