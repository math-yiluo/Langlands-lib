# Maximally faithful proper quotients with an infinitesimal character

Lean module: `Langlands.Representation.Archimedean.MaximallyFaithfulAnnihilator`.

## Statement

`Langlands.Archimedean.MaximallyFaithfulAnnihilatorStatement` (universe parameters `uL`, `uV`):

```lean
def MaximallyFaithfulAnnihilatorStatement : Prop :=
  ∀ (L : Type uL) [LieRing L] [LieAlgebra ℂ L] (V : Type uV) [AddCommGroup V] [Module ℂ V]
    (π : L →ₗ⁅ℂ⁆ Module.End ℂ V) (R : Submodule ℂ V),
    HasInfinitesimalCharacter π → R ≠ ⊤ → IsMaximallyFaithfulModulo π R →
      ∀ u : UniversalEnvelopingAlgebra ℂ L, (∀ v : V, envelopingAction π u v ∈ R) →
        envelopingAction π u = 0
```

Let `L` be a complex Lie algebra and `π` a representation of `L` on `V`, and assume:

- `π` has an infinitesimal character: every central element of `U(L)` acts by a scalar
  (`HasInfinitesimalCharacter`, Library `RealGenericLargeReduction`);
- `R` is a proper subspace of `V`;
- `V / R` is maximally faithful (`IsMaximallyFaithfulModulo π R`, Library
  `RealLargeLanglandsQuotientReduction`). This means every `u ∈ U(L)` with `u · V ⊆ R` lies in
  the ideal generated by the central `z` with `z · V ⊆ R`.

Then every `u ∈ U(L)` annihilating `V / R`, meaning `u · v ∈ R` for all `v ∈ V`, acts by `0`
on `V`. In other words, the annihilators of `V / R` and of `V` in `U(L)` coincide. The
inclusion `Ann(V) ⊆ Ann(V / R)` is trivial and is not stated.

`R` need not be `π`-stable. When it is, the hypothesis `∀ v, u · v ∈ R` says that `u`
annihilates the `U(L)`-module `V / R`.

## Provenance

This is an internal statement, introduced as a prerequisite for
`ComplexLinkedLanglandsQuotientNotLargeStatement` (Task 7064). There it reduces non-largeness
of a Langlands quotient `I / R` to finding an element of `U(L)` that kills `I / R` but not `I`.

## Proof

- `MaximallyFaithfulAnnihilator.envelopingAction_eq_zero_of_center`: let `z` be central with
  `z · V ⊆ R`. Then `z` acts by some scalar `c`. If `c ≠ 0`, every `v = c⁻¹ (z · v)` lies in
  `R`, contradicting `R ≠ ⊤`. So `c = 0` and `z` acts by `0`.
- `MaximallyFaithfulAnnihilator.envelopingAction_eq_zero`: the kernel of the algebra map
  `envelopingAction π` is an ideal. By the previous step it contains every generator of the
  ideal in the definition of `IsMaximallyFaithfulModulo π R`, so it contains the whole ideal.
  That ideal contains `u`, so `u` acts by `0`.
- `maximallyFaithfulAnnihilator : MaximallyFaithfulAnnihilatorStatement.{uL, uV}` packages the
  second step.
