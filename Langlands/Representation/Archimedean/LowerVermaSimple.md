# Simple lower Verma modules with constant `Re(λ_p) + p`

Module: `Langlands.Representation.Archimedean.LowerVermaSimple`, namespace
`Langlands.Archimedean.VermaSimple`. Everything here is proved.

`U = U(𝔤𝔩_n(ℂ))` (`glU n`). `E_pq = Matrix.single p q 1`, with image `unitU n p q` in `U`.
`M⁻(λ) = LowerVerma n λ` is `U` modulo the left ideal generated by the `E_pq` (`q < p`) and the
`E_pp - λ_p`, and `gen n λ` is the class of `1`. `Q₊ = posRootCone n` is the additive monoid
generated by the `ε_p - ε_q` with `p < q`.

Main results. Suppose `Re(λ_p) + p` does not depend on `p` (hypothesis
`hre : ∀ p q, (λ p).re + p = (λ q).re + q`). Then:

- `isZExtremal_of_re`: `λ` is `Z`-extremal (`IsZExtremal n λ`, module `LowerVerma`). That is, for
  each `μ ≠ λ` with `λ - μ ∈ Q₊`, some central element acts on `gen λ` by a scalar `c` and does not
  act on `gen μ` by `c`.
- `gen_mem_of_ne_bot`: every nonzero `U`-submodule of `M⁻(λ)` contains `gen λ`.
- `eq_bot_of_gen_not_mem`: a `U`-submodule not containing `gen λ` is zero.

So `M⁻(λ)` is simple. This is a standard fact about Verma modules: Casimir eigenvalues separate the
weights of a Verma module whose highest weight is "regular enough". The literature states it in a
different form (for example: a Verma module is simple when no positive coroot pairs with `λ + ρ` in
the positive integers). The Casimir proof below is internal to this project. It is used for the
spherical tempered core, where `λ` is the exponent of the evaluation-at-`1` functional and
`Re(λ_p) + p` is constant.

## The Casimir eigenvalue

- `casC ν = Σ_a ((ν_a + a) ν_a - Σ_{c < a} ν_c)`.
- `cas2 n`: Gelfand's element `C_2 = gel n 2 = Σ_{p,q} E_pq E_qp`, as an element of the center
  (`gel_mem_center`).
- `eval_gamC_cas2`: `eval ν (gamC n (cas2 n)) = casC ν`. Here `gamC` is the Harish-Chandra map of
  `LowerVermaCentral`; its value on `gel n 2` comes from `gam_gel`, `gelPoly_succ` and
  `gelPoly_zero`.
- `casC_add_sub`: `casC(λ + β) - casC λ = Σ_a (β_a (2λ_a + a) + β_a²) - Σ_a Σ_{c<a} β_c`.
- `sum_Iio_eq`: `Σ_a Σ_{c<a} b_c = Σ_c (n - 1 - c) b_c`.
- `re_casC_add`: under `hre`, for real `b` with `Σ_r b_r = 0`,
  `Re casC(λ + b) = Re casC λ + Σ_r b_r²`. The linear terms cancel because `Re(λ_a) + a` is a
  constant `κ`, so `Σ_a b_a (2 Re λ_a + a) - Σ_c (n - 1 - c) b_c = 2κ Σ b - (n - 1) Σ b = 0`.

## The cone

- `cone_sum`, `cone_im`: elements of `Q₊` have coordinate sum `0` and real coordinates (induction on
  the additive closure).
- `hz m = -Σ_r r m_r`, the height of an integer vector `m`. `hgt_wc` relates it to
  `VermaCentral.hgt`; `hz_nonneg` (from `cone_hgt`) gives `hz m ≥ 0` on `Q₊`. `hz_step`:
  `hz(m + ε_a - ε_b) = hz m - a + b`.

## Weights

- `Hd λ p = E_pp - λ_p` acting on `M⁻(λ)`. A weight vector of weight `m : Fin n → ℤ`
  (`IsWt (Hd λ) m u`, module `BGChaseReps`) satisfies `E_pp u = (λ_p + m_p) u`.
- `wc m`: the integer vector `m` as a vector in `ℂⁿ`.
- `unitU_comm_diag`: `E_pp E_ab = E_ab E_pp + (δ_pa - δ_pb) E_ab` (from `ι_diagonal_mul`).
- `isWt_unitU`: `E_ab` maps weight `m` to weight `m + ε_a - ε_b`.
- `isWt_W_smul_gen`: for a word `W(l)` in upper matrix units (`a < b` for each letter),
  `W(l) · gen` is a weight vector with weight in `Q₊`.
- `coneSp λ`: the sum of the weight spaces with weight in `Q₊`. `coneSp_eq_top`: it is all of
  `M⁻(λ)`. Proof: the PBW basis `basisU` spans `U`, and `basisU_smul_gen` writes
  `basisU α · gen` as a scalar times `W(l) · gen` with `l` upper.
- `cone_of_isWt`: every nonzero weight vector has weight in `Q₊`. Otherwise write it as a finite sum
  of weight vectors with weights in `Q₊` (`coneSp_eq_top`), and the difference is a zero sum of
  weight vectors of distinct weights; `mem_of_sum_mem` (module `BGChaseReps`) shows each term is
  zero.

## Central elements on primitive vectors

- `center_smul`: a central `z` acts on all of `M⁻(λ)` by `eval λ (gamC n z)`
  (`eval_gamC_smul_gen`, `M⁻(λ) = U · gen`).
- `center_smul_of_primitive`: if `u ∈ M⁻(λ)` is killed by the `E_ab` with `b < a` and
  `E_pp u = w_p u`, then `z u = eval w (gamC n z) u`. Proof: `u ↦ x u` kills the ideal of `M⁻(w)`,
  and `z - eval w (gamC n z)` lies in that ideal by `eval_gamC_smul_gen` for `M⁻(w)`.
- `casC_ne_of_wt`: under `hre`, if `wc m ∈ Q₊` and `m ≠ 0`, then `casC(λ + wc m) ≠ casC λ`
  (`re_casC_add` with `b = m`; `Σ m_r² > 0`).

## Proofs of the main results

`isZExtremal_of_re`: take `z = C_2`. If `C_2` had the same eigenvalue on `gen μ` and `gen λ`, then
`casC μ = casC λ`. Here `μ = λ - v` with `v ∈ Q₊`, so `v` is real with coordinate sum `0`, and
`re_casC_add` with `b = -Re v` gives `Σ_r (Re v_r)² = 0`. So `v = 0`, that is `μ = λ`.

`gen_mem_of_ne_bot`: let `N ≠ 0`. `N` is stable under the `Hd λ p`, and every vector of `M⁻(λ)` lies
in the integral span of these operators (`coneSp_eq_top`). So `N` is spanned by its weight vectors
(`mem_span_wt_of_mem`, module `BGChaseReps`), and contains a nonzero weight vector. By `Nat.find`,
choose a nonzero weight vector `u₀ ∈ N` of weight `m₀` with minimal height `hz m₀`. For `b < a`, the
vector `E_ab u₀ ∈ N` has weight `m₀ + ε_a - ε_b` and height `hz m₀ - a + b < hz m₀`. Its weight is
in `Q₊` if it is nonzero, so its height is nonnegative, and minimality forces `E_ab u₀ = 0`.
Then `center_smul_of_primitive` and `center_smul` give `casC(λ + wc m₀) = casC λ`, so `m₀ = 0` by
`casC_ne_of_wt`. Now `u₀` has weight `λ`, so `u₀ = c · gen` with `c ≠ 0` (`lowerVermaWeight`), and
`gen = c⁻¹ u₀ ∈ N`.

`eq_bot_of_gen_not_mem` is the contrapositive.
