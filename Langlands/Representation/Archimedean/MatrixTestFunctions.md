# Test functions in the matrix model of the general linear group

This module relates the test functions used for distributions in Shalika
(1974), §2, to the smooth compactly supported kernels used for Gårding
averages in §3. A test function on the open set of invertible matrices
restricts to a kernel on the unit group. Its support is compact by the
embedding of the group and the support condition of a test function.

Conversely, extension by zero is smooth on the open set of invertible
matrices. The image of the compact kernel support is closed and contains
the support of the extension, so the extension is locally zero at every
singular matrix. Restriction and extension are inverse complex-linear
maps. The two differentiations along matrix multiplication are the
vector fields with values \(Xx\) and \(xX\) and preserve test-function
support.
