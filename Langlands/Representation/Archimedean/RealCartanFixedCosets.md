# The fixed compact cosets at equal elliptic rank

A placement is a bijection between the source Cartan labels and the target block labels that preserves the fiber cardinalities. Choose a bijection inside each matching fiber. This gives a coordinate permutation and hence an orthogonal permutation matrix. The frames supported on that assignment form a right coset of the compact block diagonal subgroup. The coset is compact because the group of block frames is compact. Two different assignments are disjoint when every source label occurs, since each column of an orthogonal matrix has a nonzero entry.

The compact support theorem gives an assignment for an identity test argument when the left compact factor is block diagonal and the source and target have equal pair counts. Both label maps are surjective with fibers of size one or two. The source matrix is invertible and normal, vanishes between distinct labels, and has opposite nonzero off-diagonal entries in each pair. Its Gram matrix is diagonal with a constant value on each label and distinct values across all labels. The coset criterion turns the column support supplied by that theorem into membership in exactly one of the fixed cosets.

If the source matrix is a slotwise positive scalar diagonal times an orthogonal part, the permutation transports the positive value of each source slot to its matched target block. The placed diagonal therefore commutes with the compact block factor. The signed orthogonal factor of that positive diagonal is one. Thus over the compact frame `k * w`, the identity test argument occurs exactly when the left compact factor is `k * R⁻¹ * k⁻¹`, with `R` the placed orthogonal part. These are internal consequences of the regular matrix support and signed orthogonal factorization.
