# Bounded functionals of smooth compactly supported averages

Integrating a compactly supported smooth kernel against a continuous
orbit gives a linear map into the genuine smooth-vector subspace.
Composing it with a derivative-continuous functional gives a bounded
functional of the original vector. The same integral is linear in the
kernel, so the regularizations form a linear map into the continuous dual.

For an isometric action the operator norm is bounded by a fixed multiple
of a finite sum of `L¹` norms of genuine kernel derivatives. If all kernels have support in a given compact set,
the derivatives also have support there. Integrating a uniform bound
over that set gives the corresponding finite uniform derivative
seminorm estimate, with the Haar measure of the compact set as a factor.
The words in the bound come from the original smooth-vector functional
and work for every compact support.

These estimates give the fixed-support continuity of the regularization
in Shalika's *The multiplicity one theorem for GL(n)* (1974),
Proposition 3.2, printed pp. 183–184.
