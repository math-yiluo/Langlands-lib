# Infinitesimal covariance along an upper root

Pull back a test by left multiplication by an elementary
upper-root transvection. For parameters in a fixed
neighborhood of zero, all translated supports lie in
the compact image of the original support and a closed
parameter interval under the inverse translations. That
image lies in the open set of invertible matrices.

The test family is jointly smooth. Its parameter derivative
at zero is the genuine field `X * g` for the corresponding
matrix unit. The fixed-support differentiation theorem
therefore gives the derivative of the distribution applied
to the test family. Upper-unipotent covariance identifies
the same derivative with the infinitesimal character
times the distribution's value on the original test.
This is the covariance equation used in Shalika (1974),
Proposition 2.10.
