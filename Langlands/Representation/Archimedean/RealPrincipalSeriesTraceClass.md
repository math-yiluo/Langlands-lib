# Trace-class smoothing on the real Hilbert principal series

For a compactly supported continuous test whose extension by zero off the real general linear group is smooth, the compact-picture kernel has a jointly smooth extension in real matrix coordinates. The Borel measure on the group is finite on compact sets. A smooth cutoff around the compact group keeps the output inversion inside the invertible set. The integral uses a fixed compact set of ambient group elements that contains the support at every compact output and input coordinate. Compact parameter integration gives joint smoothness of the extension.

For an s-finite left- and right-invariant measure, the smooth compact kernel criterion gives trace class on the ambient compact L² space. The bounded integrated principal-series operator is given by its pointwise Bochner formula. It is the compression by the inclusion and orthogonal projection, which preserves trace class.
