# Polynomial extension for finite compact multiplier families

This module proves a finite algebraic extension mechanism for the
existing generic block multipliers. Its crossing-word conclusion retains an
explicit grid-equality hypothesis. It does not prove that hypothesis.

`polynomialFamilies sigma W` is the complex submodule of vector-valued functions
generated by the functions `z ↦ eval z P • v`, where `P` is a scalar multivariate
polynomial and `v` is a constant vector. Thus each member is a finite sum of
such functions. Linear and bilinear maps preserve these families. This allows
noncommuting operator products without using a noncommutative coefficient ring
for multivariate polynomials.

For every algebraic linear functional on `W`, a polynomial family becomes a
scalar polynomial. Scalar polynomial extensionality on a product of infinite
sets and separation by the algebraic dual therefore prove
`polynomial_zero_of_grid` and `polynomial_eq_of_grid`. No finite-dimensional
hypothesis is needed for these abstract lemmas.

`HasDenominator F D` means there is a polynomial vector family `A` satisfying
`A(z) = D(z) • F(z)` wherever the scalar polynomial `D` is nonzero.
The relation is intentionally restricted to that set: Lean's total division
does not give polynomial cancellation at poles. Bilinear composition multiplies
denominators. `rational_eq_of_grid` compares the cross-multiplied polynomial
numerators and extends an equality from an infinite product grid to parameters
where both denominators are nonzero. `rational_eq_on_of_grid` performs this
comparison only on a specified set of source vectors.

For the existing generic sequence, define

`D(eps,B,q) = product(i < B) (eps + 2i + 1 + q)`.

For `m ≤ B`, its cleared numerator is

`product(i < m) (eps + 2i + 1 - q) *
 product(m ≤ i < B) (eps + 2i + 1 + q)`.

`clear_seq` proves this formula away from the zeros of `D`. Negative modes
acquire the existing reflection factor `(-1)^eps.natAbs` in
`clearedMultiplier`. Summing these scalar polynomial coefficients against the
fixed mode projections proves `spectral_hasDenominator`. In compact degree
`N`, every index in `[-N,N]` satisfies `abs(j)/2 ≤ N`, so the bound `B=N`
works simultaneously for the whole compact model.

The explicit three-crossing words act on `degreeLE 3 N`. Write
`G_p(eps,q)` for `compactGeneric` on axis `p` and parameter `q`. Composition
is multiplication of endomorphisms, so the rightmost map acts first:

`leftWord = G_0(eta,y) G_1(kappa,x+y) G_0(eps,x)`,

`rightWord = G_1(eps,x) G_0(kappa,x+y) G_1(eta,y)`.

Both use the same scalar denominator

`D(eta,N,y) D(kappa,N,x+y) D(eps,N,x)`.

`leftNumerator` and `rightNumerator` replace each factor by its explicit
cleared spectral polynomial. They are polynomial operator families everywhere,
and equal the common denominator times the respective generic word wherever
that denominator is nonzero.

The grid is
`x = eps + 2(a+1), y = eta + 2(b+1)`, with `a,b` natural.
Each side is infinite. When `eps,eta,kappa` are nonnegative, the denominator is
nonzero throughout this grid; more generally it is nonzero whenever both `x`
and `y` have positive real part. Given equality of the two generic words on
this grid and on any chosen source set `T`,
`threeCrossing_numerators_eq_of_grid` proves equality of the cleared words for
all complex parameters, including poles of the original denominator.
`threeCrossing_eq_of_grid` proves equality of the generic words at every
parameter with nonzero common denominator.
`RealRationalCompactFamiliesStatement` packages precisely these conditional
conclusions, and `realRationalCompactFamilies` proves it.

The construction uses only the explicit generic product, fixed finite spectral
projections, finite sums, polynomial extensionality and algebraic dual
separation. No literature input or differential braid is assumed. In
particular, equality on the grid, compatibility with the actual character
parity models, degeneration to canonical tails, and either filtration
kernel-image containment are separate obligations.
