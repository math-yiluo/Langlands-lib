# Smoothness of compactly averaged orbit vectors

Bochner integration over a compact space with a finite Borel measure is a
bounded real linear map on continuous functions in the supremum norm.
Its operator norm is bounded by the mass of the compact space.

For a jointly continuous action of the units of a real Banach algebra on a
complex Banach space, every compact weighted orbit average preserves genuine
smooth vectors. The parameter space is compact with a finite Borel measure,
and the parameter map and scalar weight are continuous. If \(v\) is smooth,
the function \((g,h)\mapsto R(gh)v\) is jointly smooth on the units. In the
open units chart, restriction of this function and scalar multiplication to
the continuous compact parameter family gives a smooth map in \(g\) with
values in the continuous-function space. Composing with the bounded
integration map computes the orbit of the averaged vector.

If the real Banach algebra is finite-dimensional and its units carry a
Borel Haar measure, the smooth vectors are norm dense. For an average with
finite-dimensional range, the smooth subspace inside that range is closed.
Its inverse image under the bounded averaging map contains the norm-dense
smooth vectors, and thus all input vectors. Every output is therefore
genuinely smooth.

This internal result supplies the smooth compact-finite insertions needed
to compare algebraic modules by finite traces.
