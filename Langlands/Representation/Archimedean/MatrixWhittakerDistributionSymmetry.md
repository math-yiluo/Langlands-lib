# Weyl-transpose symmetry of the matrix distribution

Weyl-conjugated transpose is a real linear involution that preserves the invertible matrices. Its pullback is continuous on the actual complex test space. The anti-multiplication identity and the trace identity make it preserve the real trace pairing, so the trace Casimir commutes with this pullback.

The transpose of a distribution with two-sided Whittaker covariance has the same left covariance, since the transpose changes a left translation to a right translation and preserves the standard character. It also has the same Casimir eigenvalue. The long-cell symmetry theorem gives equality on tests supported in the long cell. The descending Bruhat filtration then gives equality on all tests.

This proves the transpose step of Shalika's archimedean distribution argument for the given trace-Casimir eigenvalue and two-sided covariance.
