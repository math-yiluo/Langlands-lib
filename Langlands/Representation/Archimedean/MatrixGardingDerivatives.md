# Derivatives of Gårding kernels in matrix coordinates

These identities connect Shalika's distribution derivatives in §2 to the
regularization in §3, using the actual smooth representation derivatives.
The kernel \(f(g^{-1}y)\) has derivative in \(g\) at the identity given by
the field \(-Xy\), since inversion has derivative \(-X\) there. After
conjugate reversal the kernel is \(\overline{f(y^{-1}g)}\), so the same
derivative instead gives the right field \(y^{-1}X\) on the original test
function before conjugate reversal.

Iteration gives the corresponding continuous operators for words of
directions. The matrix test derivative preserves support at each step.
