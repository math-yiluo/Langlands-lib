# Non-largeness of linked real Langlands quotients from a quotient with a larger annihilator

Lean module: `Langlands.Representation.Archimedean.RealLinkedQuotientAnnihilator`
(namespace `Langlands.Archimedean`).

This module states `RealLinkedStandardQuotientAnnihilatorStatement`. It proves that this
statement, together with the existence of an infinitesimal character on every real standard
module, implies the Library statement `RealLinkedLanglandsQuotientNotLargeStatement` (module
`RealLargeStandardIrreducibleReduction`). It proves neither
`RealLinkedStandardQuotientAnnihilatorStatement` nor the infinitesimal-character property.

Notation: `I(ds)` is `kFiniteFunctions (realStandardModule n ds) (unitaryCompact ℝ n)`, the
`O(n)`-finite functions of the standard module of `ds` (Library `StandardModule`,
`RealStandardModuleGKModule`). Its `(𝔤, K)`-structure is `realStandardRep n ds` (right
translation by `O(n)`) and `realStandardLie n ds` (right derivatives, extended `ℂ`-linearly to
`ℂ ⊗_ℝ 𝔤𝔩_n(ℝ)`). `U(𝔤)` is `UniversalEnvelopingAlgebra ℂ (ℂ ⊗[ℝ] Matrix (Fin n) (Fin n) ℝ)`,
acting through `envelopingAction` (Library `RealGenericLargeReduction`).

## The statement

```lean
def RealLinkedStandardQuotientAnnihilatorStatement : Prop :=
  ∀ (n : ℕ) (ds : List RealBlock), realRank ds = n → IsRealLanglandsOrdered ds →
    ¬ IsRealMoeglinUnlinked ds →
      ∃ W : Submodule ℂ (kFiniteFunctions (realStandardModule n ds) (unitaryCompact ℝ n)),
        IsGKSubmodule (realStandardRep n ds) (realStandardLie n ds) W ∧ W ≠ ⊤ ∧
        ∃ u : UniversalEnvelopingAlgebra ℂ (ℂ ⊗[ℝ] Matrix (Fin n) (Fin n) ℝ),
          (∀ v, envelopingAction (realStandardLie n ds) u v ∈ W) ∧
          envelopingAction (realStandardLie n ds) u ≠ 0
```

Take a list `ds` of real blocks of total rank `n` (`realRank`). Assume it is in Langlands order
(`IsRealLanglandsOrdered`, Library `RealGenericParameterReduction`) and that two of its Mœglin
data are linked (`¬ IsRealMoeglinUnlinked ds`, Library
`RealLargeStandardIrreducibleReduction`). These are the hypotheses on `ds` of
`RealLinkedLanglandsQuotientNotLargeStatement`. The statement gives:

* a `(𝔤, K)`-submodule `W` of `I(ds)` (`IsGKSubmodule`, Library
  `RealLargeLanglandsQuotientReduction`: stable under every `realStandardRep n ds k` and every
  `realStandardLie n ds X`) with `W ≠ I(ds)`;
* an element `u ∈ U(𝔤)` that maps every vector of `I(ds)` into `W`, but does not act by `0`
  on `I(ds)`.

So `u` annihilates the quotient `I(ds) / W` but not `I(ds)`: the annihilator of the proper
quotient `I(ds) / W` in `U(𝔤)` is strictly larger than that of `I(ds)`. Nothing requires `W`
to be the largest proper submodule.

### Provenance and why it holds

This is an internal intermediate statement of Task 7070, the proof of
`RealLinkedLanglandsQuotientNotLargeStatement`. It is not quoted from a source. It is a form of
that statement in which the central elements no longer appear.

The two statements are equivalent for those `ds` for which `I(ds)` has an infinitesimal
character and is itself maximally faithful (`IsMaximallyFaithful`). This equivalence is
motivation only; this module proves just one direction (below). For the other direction, let
`R` be the largest proper submodule and suppose `I(ds)/R` is not maximally faithful. Then some
`u` annihilates `I(ds)/R` without lying in the ideal generated by the central elements
annihilating `I(ds)/R`. These central elements act on `I(ds)` by scalars that must be `0`
(otherwise `R = I(ds)`), so they are exactly the central elements annihilating `I(ds)`. Since
`I(ds)` is maximally faithful, `u` does not annihilate `I(ds)`, and `W = R` with this `u`
satisfies the statement.

Both properties of `I(ds)` are expected for every standard module. The centre acts by scalars
on a module induced from a module with an infinitesimal character. `I(ds)` should be maximally
faithful because it has a large constituent, whose annihilator is the minimal primitive ideal
(Vogan 1978, Definition 6.1 and Theorem 6.2, p. 89). Mœglin 1997, Theorem 10b (Bailey–Knapp,
PSPM 61, printed p. 164), together with Vogan 1978, Theorem 6.2, says that the Langlands
quotient of a standard module with a linked pair is not large. With the equivalence above,
this is why the statement is expected to hold.

The suggested route to the statement uses Gelfand–Kirillov dimension. After the blocks are
rearranged, a linked pair of minimal gap can be made adjacent with its order kept. A submodule
`W` then comes from a module induced from the kernel of the Langlands quotient of the pair. A
module induced from a non-large module has only non-large constituents (Vogan 1978, Lemma 6.5
and Corollary 6.6, p. 94). That proof is not part of this module.

## The reduction

`realLinkedLanglandsQuotientNotLarge_of_quotientAnnihilator
(hZ : ∀ n ds, HasInfinitesimalCharacter (realStandardLie n ds))
(hP : RealLinkedStandardQuotientAnnihilatorStatement) :
RealLinkedLanglandsQuotientNotLargeStatement`.

The hypothesis `hZ` says that the centre of `U(𝔤)` acts by scalars on every `I(ds)`
(`HasInfinitesimalCharacter`, Library `RealGenericLargeReduction`, after Kostant 1978, §3.9).

Let `n`, `ds` and `R` be as in `RealLinkedLanglandsQuotientNotLargeStatement`, and assume
`IsMaximallyFaithfulModulo (realStandardLie n ds) R`. The proof derives a contradiction.

1. Apply `hP` to `n` and `ds`. This gives a proper `(𝔤, K)`-submodule `W` and an element `u`
   with `u · v ∈ W` for every `v ∈ I(ds)` and `envelopingAction (realStandardLie n ds) u ≠ 0`.
2. By the hypothesis on `R`, every proper `(𝔤, K)`-submodule lies in `R`. So `W ≤ R`, and
   `u · v ∈ R` for every `v`.
3. The Library theorem `MaximallyFaithfulAnnihilator.envelopingAction_eq_zero` (module
   `MaximallyFaithfulAnnihilator`) applies to `realStandardLie n ds`, which has an
   infinitesimal character by `hZ n ds`, and to `R ≠ ⊤` with the assumed maximal faithfulness
   of `I(ds)/R`. It shows that `u` acts by `0` on `I(ds)`. This contradicts step 1.

The hypothesis that `R` is itself a `(𝔤, K)`-submodule is not used.
