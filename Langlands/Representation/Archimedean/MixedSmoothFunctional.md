# Gluing compatible smooth functionals across finite levels

For a mixed smooth vector, choose a compact open subgroup fixing its
underlying Hilbert vector. A family of scalar linear functionals on
genuine archimedean smooth vectors gives a value there. Agreement on
each common fixed vector makes the value independent of the level.
For addition, the intersection of the two levels is a common compact
open subgroup. Scalar multiplication preserves the given level.

The resulting linear functional has the prescribed value at every
level fixing the vector. This is an internal algebraic use of the
existing compact open subgroup intersection and mixed smooth space.
