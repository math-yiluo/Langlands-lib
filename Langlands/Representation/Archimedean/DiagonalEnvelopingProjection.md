# Diagonal polynomials of complex matrix enveloping centres

For a finite product of complex matrix Lie algebras, use the column index minus the row index as the weight of each matrix unit. The diagonal matrix algebra has precisely the weight-zero basis. The positive right ideal is generated by the strict upper matrix units. The resulting centre projection takes values in the enveloping algebra of the diagonal. Its universal property identifies it with the polynomial algebra on the diagonal entries.

`diagonalCenterPolynomial_eq_rename_of_congruence` compares diagonal polynomials across a Lie map respecting the diagonal and strict upper matrix units. The comparison uses uniqueness of the representative modulo the strict upper right ideal. `diagonalCenterPolynomial_blockProjection` applies it to the actual standard block diagonal inclusion. The block projection and the ambient diagonal projection yield the same polynomial after identifying their diagonal coordinates.

This derived comparison is an algebraic step towards the centre finiteness for Levi slices of constant terms in Langlands, *On the notion of an automorphic representation* (1979), Lemma 4, printed p. 204.
