# Symbols of the central ideal of a module with a Borel eigenfunctional

Namespace `Langlands.Archimedean.Kostant.BorelCentralIdeal`.

## Setting

`ι` is a finite index type and `n : ι → ℕ` gives the block sizes. `𝔤 = GLProd ℂ n` is
`∏ᵢ 𝔤𝔩_{n i}(ℂ)` (Library `Kostant/Center`) with the basis of matrix units `E_c = glBasis ℂ n c`,
`c = ⟨i, p, q⟩ : Coord n`. `U = U(𝔤)`, `U_N = degreeFiltration ℂ 𝔤 N`, and
`σ_N = (glSymbol ℂ n).symbol N : U → MvPolynomial (Coord n) ℂ` is the degree-`N` symbol.
`π : 𝔤 →ₗ⁅ℂ⁆ Module.End ℂ V` is a representation and `envelopingAction π` its extension to `U`.
Two ideals from the Library are used:

* `centralIdeal n π` (Library `Kostant/Assembly`) is `Ideal.span` of the central elements `z` of
  `U` with `envelopingAction π z = 0`;
* `charpolyIdeal n` (Library `Kostant/NilpotentCone`) is the ideal of
  `MvPolynomial (Coord n) ℂ` generated by the coefficients of `t^k`, `k < n i`, of the
  characteristic polynomials of the generic blocks.

## Definitions

* `killVars T` is the `ℂ`-algebra endomorphism of `MvPolynomial σ ℂ` sending the variables of the
  finite set `T` to `0` and fixing the others.
* `upper n` is the finite set of coordinates `⟨i, p, q⟩` with `p ≤ q` (on or above the diagonal of
  their block).
* `IsBUpper n x` says that every block `x i` is upper triangular (`Matrix.BlockTriangular id`).
* `muLin n μ x = ∑_{e ∈ upper n} x_e μ_e` for `μ : Coord n → ℂ`.
* `IsBorelEigen π ℓ μ` says `ℓ (π (E_c) v) = μ_c ℓ(v)` for all `c ∈ upper n` and all `v : V`:
  `ℓ : V →ₗ[ℂ] ℂ` is an eigenfunctional of the upper triangular matrix units.
* `shiftGen n μ c = E_c - μ_c ∈ U`.
* `InJ n μ M P` says `P = ∑_{c ∈ upper n} (E_c - μ_c) w_c` for some `w_c ∈ U_M`. The union over
  `M` is the right ideal `J_μ = ∑_{c upper} (E_c - μ_c) U`.

## Main results

* `inJ_of_mem_centralIdeal`: if `IsBorelEigen π ℓ μ` and `ℓ ≠ 0`, every element of
  `centralIdeal n π` lies in `J_μ`.
* `eval_symbol_eq_zero`: under the same hypotheses, for `u ∈ U_N ∩ centralIdeal n π`, the symbol
  `σ_N(u)` vanishes at every point `y : Coord n → ℂ` with `y_c = 0` for `c ∈ upper n`.
* `symbol_mem_charpolyIdeal`: under the same hypotheses, `σ_N(u) ∈ charpolyIdeal n` for
  `u ∈ U_N ∩ centralIdeal n π`.

## Provenance

The module is internal to Task 7070, where it provides the lower bound for the growth of `U(𝔤)`
modulo the central ideal (`Kostant/BorelCentralGrowth`). The argument follows the pattern of
Matumoto's proof of Kostant's theorem (Matumoto 1987, §2; Library `Kostant/Assembly`): show that
the symbols vanish on a set whose orbit closure is the nilpotent cone, then apply the Library's
nilpotent-cone and orbit results. Here a Borel eigenfunctional takes the place of the Whittaker
functional, and the vanishing set is the strictly lower triangular tuples rather than one
regular nilpotent point.

## Proof

1. **Syzygies of variables** (section `Koszul`). `exists_sub_killVars`: `g - killVars T g` is a
   combination `∑_{c ∈ T} a_c X_c`, by induction on `g`.
   `exists_antisymm_of_sum_X_mul_eq_zero`: if `∑_{c ∈ T} X_c f_c = 0`, there is an
   antisymmetric family `s` with `f_c = ∑_{c' ∈ T} s_{c c'} X_{c'}` for `c ∈ T`. The proof is
   induction on `T`. For `T ∪ {t}`, applying `killVars T` gives `killVars T (f_t) = 0`, so
   `f_t = ∑_{c ∈ T} a_c X_c`. Replacing `f_c` by `f_c + a_c X_t` gives a relation over `T`.
   `exists_antisymm_homogeneous` takes degree-`M` components when every `f_c` is homogeneous of
   degree `M + 1`.

2. **Borel eigenfunctionals** (section `Borel`). An upper triangular `x` is
   `∑_{e upper} x_e E_e` (`eq_sum_upper`), so `ℓ(π(x) v) = muLin n μ x · ℓ(v)`
   (`IsBorelEigen.apply`). Brackets of upper triangular elements are upper triangular, and taking
   `v` with `ℓ v ≠ 0` gives `muLin n μ ⁅x, y⁆ = 0` (`IsBorelEigen.muLin_lie`). With
   `⁅E_{ipp}, E_{ipq}⁆ = E_{ipq}` for `p ≠ q` (`lie_unit_diag`) this gives `μ_c = 0` for strictly
   upper `c` (`IsBorelEigen.eq_zero`).

3. **The right ideal** (section `RightIdeal`). `InJ` is closed under sums, scalars, finite sums,
   increase of `M` and right multiplication (`InJ.mul_right`: `U_M · U_K ⊆ U_{M+K}`).
   `symbol_shiftGen_mul`: `σ_{M+1}((E_c - μ_c) w) = X_c σ_M(w)` for `w ∈ U_M`, since the scalar
   part has degree `M`. `shiftGen_comm`: if `muLin n μ` vanishes on brackets of upper triangular
   elements, then for `c, c' ∈ upper n`,
   `[E_c - μ_c, E_{c'} - μ_{c'}] = ∑_{e upper} (E_e - μ_e) ⁅E_c, E_{c'}⁆_e`.

4. **Descent** (`InJ.descend`, `InJ.descend_le`). Let `P = ∑ (E_c - μ_c) w_c` with
   `w_c ∈ U_{K+1}` and `P ∈ U_{K+1}`. Then `0 = σ_{K+2}(P) = ∑ X_c σ_{K+1}(w_c)`. Step 1 gives an
   antisymmetric homogeneous `S` of degree `K` with `σ_{K+1}(w_c) = ∑_{c'} S_{c c'} X_{c'}`.
   Lift it to `A'_{c c'} = ½(A_{c c'} - A_{c' c}) ∈ U_K` with `σ_K(A'_{c c'}) = S_{c c'}`
   (Library `exists_symbol_eq`), and put `w'_c = w_c - ∑_{c'} (E_{c'} - μ_{c'}) A'_{c c'}`. Its
   degree-`(K+1)` symbol vanishes, so `w'_c ∈ U_K` (Library
   `mem_degreeFiltration_of_symbol_eq_zero`). The remainder is
   `D = ∑_{c,c'} (E_c - μ_c)(E_{c'} - μ_{c'}) A'_{c c'}`. By antisymmetry it is half the sum of
   the commutator terms, which lie in `InJ n μ K` by step 3. Iterating, an element of `J_μ`
   lying in `U_{N+1}` lies in `InJ n μ N`.

5. **Annihilation.** `ℓ(π(E_c - μ_c) v) = 0` for `c ∈ upper n`, so `ℓ(π(P) v) = 0` for every
   `P ∈ J_μ` (`IsBorelEigen.apply_of_inJ`).

6. **Central elements** (`inJ_of_mem_center`). Let `z` be central with `π(z) = 0`. Write `z` in
   the ordered monomials `E^α` for the enumeration `sortedCoords n` by decreasing degree
   `deg ⟨i, p, q⟩ = q - p` (Library `Kostant/Matumoto`, `degreeFiltration_le_orderedSpan`).
   Since `z` is central, `gradDer n z = 0`, and `E^α` is an eigenvector of `gradDer n` with
   eigenvalue `wdeg n α`. Evaluating a Lagrange interpolation polynomial at `gradDer n` shows
   that `z` equals its part of weighted degree `0`. `inJ_word_sub_prod`: for a word sorted by
   decreasing degree with total degree `0`, `word - ∏ μ(letters)` lies in `J_μ`. If the first
   letter has positive degree, it is strictly upper, so it lies in `upper n` and has `μ = 0`.
   Otherwise every letter has degree `≤ 0`, the total is `0`, so the first letter is diagonal,
   and the rest follows by induction. Hence `z - C ∈ J_μ` for a scalar `C`, and applying step 5
   at `v` with `ℓ v ≠ 0` gives `C = 0`. `inJ_of_mem_centralIdeal` follows by span induction,
   since `a z = z a` for central `z`. `mul_mem_centralIdeal` shows the central ideal is also a
   right ideal.

7. **Vanishing of symbols** (`eval_symbol_eq_zero`). Let `u ∈ U_N ∩ centralIdeal n π`. By step 6,
   `u ∈ InJ n μ K` for some `K`. If `N = 0`, `u` is a scalar `a` with `a ℓ(v) = 0`, so `a = 0`.
   If `N = M + 1`, step 4 gives `u = ∑ (E_c - μ_c) w_c` with `w_c ∈ U_M`, so
   `σ_N(u) = ∑_{c upper} X_c σ_M(w_c)` vanishes at `y`.

8. **The characteristic polynomial ideal** (`symbol_mem_charpolyIdeal`). Let
   `W = σ_N(U_N ∩ centralIdeal n π)`. It is stable under `coadDer (E_{iab})`, `a ≠ b`. Indeed
   `xQ - Qx` stays in `U_N` and in the two-sided central ideal, and
   `σ_N(xQ - Qx) = coadDer x (σ_N Q)` (Library `symbol_commutator`, `coadDer_ξ`). By step 7, `W`
   vanishes on every tuple of strictly lower triangular matrices. Let `M` be a tuple of
   nilpotent matrices. Each `(M i)ᵀ` is nilpotent, so `g_i (M i)ᵀ g_i⁻¹` is strictly upper
   triangular for some invertible `g_i` (Library `exists_conj_strictUpper_field`). With
   `G_i = g_iᵀ`, the tuple `Y_i = G_i⁻¹ M_i G_i` is strictly lower triangular, so
   `Y ∈ zeroSet n W`. Library `conj_mem_zeroSet` (Kostant/OrbitVanishing) gives
   `G Y G⁻¹ = M ∈ zeroSet n W`. So `σ_N(u)` vanishes on all nilpotent tuples, and the Library
   theorem `nilpotentConeIdeal n` puts it in `charpolyIdeal n`.
