# A monomial order adapted to the characteristic polynomials of generic blocks

Setting: `ι : Type` finite, `n : ι → ℕ`, and the polynomial ring `ℂ[X_c]`,
`c = ⟨b, p, q⟩ ∈ Coord n` (block `b`, row `p`, column `q`), from module
`Kostant.Coordinates`.

## Definitions

- `prio n c = toLex (index of b, toLex (toDual q, p))`. This is the priority key of a
  variable: block first, then column in descending order, then row in ascending order.
  It is injective (`prio_injective`).
- `PCoord n` is a type synonym of `Coord n` that carries the linear order pulled back along
  `prio n`. It is finite and hence `WellFoundedGT`. `PCoord.lt_iff` unfolds the order.
- `colWeight n ⟨b, p, q⟩ = q` is the column index.
- `ord n = weightLex (σ := PCoord n) (colWeight n)`, a `MonomialOrder (Coord n)`.
  Monomials are compared first by their column weight `Σ_c a c * q(c)`. Ties are broken by
  `Finsupp.Lex` for the variable order of `PCoord n`: at the first variable (for that order)
  where the two monomials differ, the larger exponent wins. `ord_lt_iff` states this.
- `antidiag n b k` is the squarefree monomial `∏ X ⟨b, p, q⟩` over the entries of block `b`
  with `p + q = n b - 1 + k`. For `k < n b` these are exactly the antidiagonal entries
  `(n b - 1 + k - q, q)`, `k ≤ q < n b`, of the trailing `(n b - k) × (n b - k)` block.

## Statement

`CharpolyLeadingStatement n`: for every block `b` and `k < n b`, the leading monomial
(`(ord n).degree`) of the coefficient of `t^k` of the characteristic polynomial of
`genericBlock n b` is `antidiag n b k`, and its leading coefficient is a unit.

Why this should hold: expanding `det (t - M)` over permutations `σ` and the set `F` of
diagonal positions where `t` is chosen, the coefficient of `t^k` is
`Σ_{σ, F} sign σ (-1)^(N-k) ∏_{q ∉ F} X ⟨b, σ q, q⟩`, where `N = n b` and the sum runs over
`|F| = k` and permutations `σ` fixing `F` pointwise. The column weight `Σ_{q ∉ F} q` is
largest exactly for `F = {0, …, k-1}`. Among those terms, the reversal `σ₀ q = N - 1 + k - q`
of `{k, …, N-1}` is lexicographically largest. At the largest column `q*` where `σ` differs
from `σ₀`, the reversal uses the smaller row `σ₀ q* < σ q*`. Its row has higher priority,
and so `σ₀` wins. The leading coefficient is `sign σ₀ (-1)^(N-k) = ±1`.

## Use

The leading monomials `antidiag n b k` (for `k < n b`) are squarefree and have pairwise
disjoint supports, since distinct `(b, k)` give distinct antidiagonals. By the coprime
leading-term criterion, the normalized characteristic polynomial coefficients then form a
Gröbner basis of `charpolyIdeal n`, and that ideal is radical. These steps are the input to
the proof of `NilpotentConeIdealStatement`.

## Provenance

This is internal to the proof of `NilpotentConeIdealStatement` (Kostant, *Lie group
representations on polynomial rings*, Amer. J. Math. 85 (1963), for `𝔤𝔩_n`). The choice of
order and the leading-term computation are this project's own route to the radicality of
the ideal generated by the characteristic polynomial coefficients.
