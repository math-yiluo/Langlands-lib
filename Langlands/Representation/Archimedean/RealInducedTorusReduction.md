# Reduction of torus averages to block coordinates

Lean module: `Langlands.Representation.Archimedean.RealInducedTorusReduction`.

This module is part of the proof
of `RealStandardLanglandsQuotientStatement` (module `RealLargeLanglandsQuotientReduction`). Let
`p_1, …, p_r` be pairwise disjoint blocks of `GL_N(ℝ)` and let `T` be the torus generated by the
block rotations `r_{p_i}(θ)`. The module reduces torus averages `∫_T F(τ y) dτ` at an arbitrary
point `y` to the block coordinates of `y`. Unprefixed names below are in the namespace
`Langlands.Archimedean.RealInducedTorusReduction`.

Notation follows `RealInducedBlockSlice.md`, `RealInducedBlockBound.md` and
`RealInducedTorusCore.md`. `GL_N(ℝ)` is `Langlands.GeneralLinear N ℝ` and `O(N)` is the Library's
`unitaryCompact ℝ N`. `r_p(θ)` is `blockRotation N p θ`. `ia h` and `ib h` are the indices `p`
and `p + 1` of a block `h : p + 1 < N`. `b(x, y, w) = blockB h x y w` is the identity outside the
block and `[[e^x, w], [0, e^y]]` on it, and `diagEntry h x y` is its diagonal (`e^x`, `e^y` on the
block, `1` elsewhere). `Slot`, `Slot.Disjoint`, `coeffs` and `point`
(`point [s_1, …, s_r] = b_{s_1} ⋯ b_{s_r}`) are from `RealInducedBlockBound`.
`RealBlockDerivative.IsExpEquivariant α φ` (Library) means
`φ(exp(diag x) · n · g) = e^{Σ_i α_i x_i} φ(g)` for all `x ∈ ℝ^N`, upper unipotent `n` and `g`;
`RealBlockDerivative.conj N p θ A = r_p(θ) A r_p(−θ)` (Library).

## Definitions

* `rotations L`: the set of block rotations `r_{s.p}(θ)` for the slots `s` of `L` and `θ ∈ ℝ`.
* `torus L`: the submonoid of `GL_N(ℝ)` generated by `rotations L`.
* `IsAdapted L c`: the matrix of `c` is upper triangular with positive diagonal, and for every
  slot `s` of `L` it is the identity on the block `s.p`: `c_{pp} = c_{qq} = 1` and `c_{pq} = 0`
  for `p = s.p`, `q = s.p + 1`.
* `chi α c = exp(Σ_i α_i log c_ii)` for `α : Fin N → ℂ`.
* `readSlot C s`: the slot `s` with coordinates `x = log C_pp`, `y = log C_qq`, `w = C_pq`
  (`p = s.p`, `q = s.p + 1`), all other fields unchanged.
* `readSlots C L`: `readSlot C` applied to every slot of `L`.

## Results

The torus.

* `blockRotation_mem_torus`: `r_{s.p}(θ) ∈ torus L` for every slot `s` of `L`.
* `torus_mono`: if every slot of `L` is in `L'`, then `torus L ≤ torus L'`.
* `torus_le_unitaryCompact`: `torus L ≤ O(N)`.
* `coeffs_congr_torus`: if `F(x g) = F'(x g)` for all `x ∈ torus L`, then
  `coeffs L F g = coeffs L F' g`.
* `coeffs_const_mul`: `coeffs L (x ↦ a F(x)) g = a · coeffs L F g`.
* `coeffs_congr_map`: `coeffs L F = coeffs L' F` if `L` and `L'` have the same lists of pairs
  `(s.p, s.j)` (block and mode).

Adapted matrices and conjugation.

* `ne_of_disjoint`: the indices `t.p, t.p + 1` of a slot `t` disjoint from `s` differ from
  `s.p, s.p + 1`.
* `ia_lt_ib`: `p < p + 1` as elements of `Fin N`.
* `val_conj`: the matrix of `r_p(θ) c r_p(θ)⁻¹` is `RealBlockDerivative.conj N p θ c`.
* `conj_ia_ib`: if `A` is upper triangular and the identity on the block `p`, then the
  `(p, p + 1)` entry of `conj N p θ A` is `0`.
* `conj_apply_of_ne`: if neither `i` nor `k` is `p` or `p + 1`, then `(conj N p θ A)_{ik} = A_{ik}`.
* `isAdapted_conj`: for pairwise disjoint `L`, a slot `s` of `L` and `IsAdapted L c`, the
  conjugate `r_{s.p}(θ) c r_{s.p}(θ)⁻¹` is adapted to `L` and has the same diagonal as `c`.
* `isAdapted_conj_of_mem_torus`: the same for conjugation by any `x ∈ torus L`.

The character and the reduction.

* `norm_chi`: `|chi α c| = exp(Σ_i Re α_i · log c_ii)`.
* `apply_mul_of_upper`: if `IsExpEquivariant α φ` and `c` is upper triangular with positive
  diagonal, then `φ(c g) = chi α c · φ(g)`.
* `apply_mul_mul_of_mem_torus` (**reduction**): for pairwise disjoint `L`,
  `IsExpEquivariant α φ`, `IsAdapted L c` and `x ∈ torus L`:
  `φ(x c g) = chi α c · φ(x g)`.
* `coeffs_mul_adapted`: under the same hypotheses, for every `H`:
  `coeffs L (x ↦ φ(x c g) H(x)) 1 = chi α c · coeffs L (x ↦ φ(x g) H(x)) 1`.
* `coeffs_mul_adapted'`: the same with the factors in the order `H(x) φ(x c g)`.

Factorization along the blocks.

* `diagEntry_ia`, `diagEntry_ib`, `diagEntry_of_ne`: the entries `e^x`, `e^y` and `1` of
  `diagEntry h x y`.
* `mul_blockB_apply`: `(A · b(x, y, w))_{ik} = A_{ik} · diagEntry h x y k + [k = p + 1] A_{ip} w`.
* `blockB_inv`: `b(x, y, w)⁻¹ = b(−x, −y, −w e^{−x−y})`.
* `pairwise_readSlots`: `readSlots C L` is pairwise disjoint if `L` is.
* `coeffs_readSlots`: `coeffs (readSlots C L) F = coeffs L F`.
* `exists_factor` (**factorization**): let `c` be upper triangular with positive diagonal and
  `L` pairwise disjoint. Then there is `c''` with `c = c'' · point (readSlots c L)`,
  `IsAdapted L c''`, and `c''_{ik} = c_{ik}` for every column `k` that is not an index of a block
  of `L`.
* `exists_decomp` (**decomposition**): for pairwise disjoint `L`, every `y ∈ GL_N(ℝ)` is
  `y = c · (point (readSlots C L) · k)` for some matrix `C`, some `c` with `IsAdapted L c` and
  some `k ∈ O(N)`.

## Proofs

* `coeffs_congr_torus`, `coeffs_const_mul` and `coeffs_congr_map` are inductions on `L`, unfolding
  `coeffs` and `blockFourierCoefficient` to interval integrals. For `coeffs_congr_torus` the
  integrand at `θ` is handled by the induction hypothesis at `r_{s.p}(θ) g`, using that
  `x · r_{s.p}(θ) ∈ torus (s :: L)` for `x ∈ torus L`.
* `val_conj` uses `r_p(θ)⁻¹ = r_p(−θ)` (`blockRotation_neg`). `conj_ia_ib` and
  `conj_apply_of_ne` evaluate the entries by the Library formulas
  `RealBlockDerivative.conj_apply` and `RealBlockDerivative.blockRotation_mul_apply`.
* `isAdapted_conj`: the diagonal is computed by the Library's `RealBlockDerivative.conj_diag`
  (with `cos² θ + sin² θ = 1` on the block), the entries below the diagonal by
  `RealBlockDerivative.conj_lower` (the only possibly nonzero one is
  `kappa = cos θ sin θ (c_pp − c_qq) − sin² θ c_pq`, which vanishes because `c` is the identity
  on the block). On the block `s` itself `conj_ia_ib` applies; on any other block `t` of `L` the entries
  are unchanged by `conj_apply_of_ne`, since `s` and `t` are disjoint
  (`List.Pairwise.forall` with the symmetric relation `Slot.Disjoint`).
* `isAdapted_conj_of_mem_torus`: induction over the submonoid closure
  (`Submonoid.closure_induction`); for a product `x y`,
  `(x y) c (x y)⁻¹ = x (y c y⁻¹) x⁻¹`.
* `apply_mul_of_upper`: write `c = d · n` with `d = diag(c_ii) = exp(diag(log c_ii))`
  (`RealPrincipalSeriesDuality.matrixExpUnit_diagonal`, `Iwasawa.diagonalUnits`) and
  `n = d⁻¹ c` upper unipotent, and apply `IsExpEquivariant`.
* `apply_mul_mul_of_mem_torus`: `x c g = (x c x⁻¹)(x g)`, where `x c x⁻¹` is upper triangular with
  positive diagonal equal to that of `c` (`isAdapted_conj_of_mem_torus`); apply
  `apply_mul_of_upper`.
* `coeffs_mul_adapted`, `coeffs_mul_adapted'`: by `coeffs_const_mul` and `coeffs_congr_torus` it
  suffices to compare the integrands on `torus L`, where `apply_mul_mul_of_mem_torus` applies.
* `blockB_inv`: `blockB_eq_blockMat`, `blockMat_mul` (from `RealInducedBlockSlice`) and
  `blockMat_eq_one_add` (from `RealInducedBlockBound`) reduce the product `b(x, y, w) · b(−x, −y, −w e^{−x−y})` to a
  `2 × 2` computation on the block.
* `exists_factor`: induction on `L`. For `s :: rest`, the induction hypothesis gives
  `c = c_1 · point (readSlots c rest)` with `c_1` adapted to `rest` and with the columns of `c`
  outside the blocks of `rest` unchanged; in particular the columns `s.p, s.p + 1` of `c_1` are
  those of `c` (disjointness). Put `c'' = c_1 · b(x, y, w)⁻¹` with `x, y, w` read off from `c` at
  the block `s`. By `blockB_inv` and `mul_blockB_apply`, `c''` changes only the columns
  `s.p, s.p + 1` of `c_1`, it is upper triangular, and on the block `s` it is the identity:
  `c_pp e^{−x} = 1`, `c_qq e^{−y} = 1` and `c_pp · (−w e^{−x−y}) + w e^{−y} = 0`. The other blocks
  of `rest` are untouched, so `c''` is adapted to `s :: rest`, and
  `c'' · point (readSlots c (s :: rest)) = c_1 · b⁻¹ · b · point (readSlots c rest) = c`.
* `exists_decomp`: the Library's Iwasawa decomposition
  `RealBlockPropagation.exists_expDiagonal_mul_upperUnipotent_mul_unitaryCompact` writes
  `y = exp(diag l) · n · k` with `n` upper unipotent and `k ∈ O(N)`; the matrix
  `b = exp(diag l) · n` is upper triangular with positive diagonal, and `exists_factor` applied to
  `b` gives `b = c · point (readSlots b L)`. Take `C = b`.

## Use

For pairwise disjoint slots, `exists_decomp` writes any `y` as `c · point(slots') · k` where
`slots' = readSlots C slots` has the same blocks and modes as `slots`, and `coeffs_mul_adapted`
removes the adapted factor `c` from a torus average at the cost of the scalar `chi α c`. This
reduces torus averages at arbitrary points to the averages at `point slots' · k` computed in
`RealInducedTorusCore`; this reduction is intended for the torus-pairing bound in the proof of
`RealStandardLanglandsQuotientStatement`.

## Provenance

This is derived, internal infrastructure for the proof of `RealStandardLanglandsQuotientStatement`;
it states no literature result. The
factorization is elementary linear algebra on upper triangular matrices, and the decomposition
combines it with the Iwasawa decomposition `GL_N(ℝ) = A N O(N)` from the Library.
