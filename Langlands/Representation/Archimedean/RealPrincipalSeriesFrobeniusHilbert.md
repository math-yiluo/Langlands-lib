# Genuine Hilbert orbits of real Frobenius vectors

A real Jacquet functional defines a Frobenius map into the smooth principal
series and hence into its compact Hilbert completion. The map intertwines
orthogonal-group translation with the given compact action.

The analytic germ for the compact profile maps into \(L^2\) by the bounded
continuous-function inclusion, followed by orthogonal projection onto the
closed Hilbert space of the principal series. The projection fixes translated
profiles because those profiles already belong to this space. Translation
carries the local smooth orbit to every group point. Along a matrix
exponential the one-parameter law similarly gives real analyticity at every
time.

The derivative of the compact profile is determined by bounded evaluation at
each orthogonal matrix. The published Frobenius derivative identifies each
value with the compact restriction of the Frobenius image of the given Lie
action. Applying the bounded map to the Hilbert completion proves the
corresponding derivative of the genuine Hilbert orbit. The matrix exponential
has tangent \(X\) at the identity, so the same derivative computes the
Library's smooth-vector Lie operator.

This internal construction uses the published Jacquet Frobenius map and right
derivative together with the analytic compact profile and the compact Hilbert
principal-series action.
