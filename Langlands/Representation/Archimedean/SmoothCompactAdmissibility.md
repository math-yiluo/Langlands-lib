# Compact admissibility of the genuine smooth action

The genuine smooth action is admissible if every continuous finite-dimensional matrix type of the compact subgroup has a finite-dimensional space of intertwiners into the smooth carrier. This is the same test used for the original normed action, with the transported action on the smooth-vector carrier as codomain.

Postcomposition by the empty-word coordinate embeds these intertwiner spaces into the corresponding spaces for the original normed action. This coordinate is equivariant for the actual action and records the underlying vector, so it is injective. Admissibility of the normed action therefore supplies the required finiteness. The lemma works for a subgroup with the same finite-dimensional test and in particular applies to the orthogonal and unitary subgroups of the actual archimedean general linear groups.
