# Support of the compact Fourier projection at a real Cartan

Each high-mode filter is the identity minus its finite low-mode
projection. The compact column formed from any selected sublist of
low-mode projections only uses rotations of the sublist's coordinate
pairs and diagonal signs. All of those factors preserve its refined
blocks. Pointwise vanishing on the associated compact subgroup is
preserved by each sign filter and each selected Fourier integral.

The source is an invertible normal matrix whose surjective label map partitions the coordinates into lines and planes. Entries between different labels are zero, and each plane has opposite nonzero off-diagonal entries. The Gram matrix is diagonal with a constant squared radius on each label. The squared radii are distinct across all labels, including across lines and planes.

Under these hypotheses, if a selected sublist has fewer pairs than the source Cartan matrix, the fixed-flag support theorem supplies an identity neighborhood
where such tests give a zero column. There are only finitely many
selected sublists, so the neighborhoods can be intersected. An
induction on the filters then leaves precisely the signed term
using the low projections at every slot whenever the Cartan rank
is at least the number of slots. If it is greater, this full term
also vanishes.

The calculation applies to the actual continuous compact test trace
and its signed orthogonal principal-series column. It is an internal
support calculation using the block placement and compactness lemmas.
