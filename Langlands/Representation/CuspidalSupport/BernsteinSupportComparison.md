# Retained actual cuspidal-support comparison targets

Author: Worker 1153.

This module makes the exact missing source comparisons for the constructed Bernstein objects explicit. It defines actual untwisted association and actual Jacquet-constituent support, and names five Prop-valued targets. None is assumed by the cuspidal-data quotient or the full block categories. The only unconditional proof is the elementary implication from actual untwisted association to inertia; the other two proofs are explicitly conditional consequences of the stated source targets.

The original is David Renard, *Représentations des groupes réductifs p-adiques*, 9 July 2026 version, registered as `renard-2026-representations-groupes-reductifs-padiques`, SHA256 `7b539996793b7c3620e72e1e389588eb42d1a8e91d6f68b2eead5c2e2ffc182c`. Source locations are VI.5.4, Theorem and proof, printed pp.173–175 / PDF pp.179–181, especially the construction from an irreducible induction subquotient on printed p.174; and VI.7.1, Lemma and support definitions, printed pp.180–181 / PDF pp.186–187. This is a derived statement interface on the actual standard rational-point family; it does not purport to be a verbatim restatement for arbitrary parabolics.

The parameters, topology and structural hypotheses are those of `BernsteinData` and `BernsteinBlock`: an arbitrary connected reductive group over a nonarchimedean local field, an actual maximal split torus and generic cocharacter, finite actual simple-root set, actual standard and Levi-in-Levi decompositions, and actual Levi/unipotent closedness. The ambient canonical point topology has explicit local-compactness and nonarchimedean-group instances. Ambient local finite type is an instance, supplied by the proved `BernsteinStandardFamily.locallyOfFiniteType`. The field/group universe `uF` and carrier universe `uV` stay independent; all support targets use the common carrier universe `max uF uV` for data and ambient representations, so normalized induction remains in that universe.

`AreBernsteinCuspidalDataAssociated a b` asks for an actual `RationalLeviConjugacy` of their embedded standard Levi schemes, with an actual smooth equivariant isomorphism from `a.representation` to the pullback of `b.representation`. It uses an actual ambient rational point and an all-test scheme-conjugation equation. It has no unramified twist. `AreBernsteinCuspidalDataAssociated.inertia` proves inertial equivalence using the trivial full rational unramified character.

The five targets are:

- `BernsteinCuspidalSupportExistenceStatement`: every actual irreducible smooth representation admits an actual cuspidal-datum induction-subquotient presentation. This is the standard-family existence assertion underlying the source support relation, without selecting a support map.
- `BernsteinCuspidalSupportAssociationStatement`: if an actual irreducible representation occurs as a subquotient of both actual cuspidal inductions, their data are actually associated. This is the common-constituent implication of VI.5.4.
- `BernsteinAssociatedSupportInvarianceStatement`: actually associated data have the same irreducible induction-subquotients. This is the association-to-equal-Jordan–Hölder-factors implication of VI.5.4, expressed only as irreducible occurrence. It applies to untwisted association, rather than arbitrary inertia equivalence.
- `BernsteinInertialSupportUniquenessStatement`: if the explicit class-saturated induction support relation holds for classes `s` and `t` of the same actual irreducible, then `s = t`. The module proves this conditional on `BernsteinCuspidalSupportAssociationStatement` by extracting the two datum witnesses, applying actual association, using its elementary implication to inertia, and applying the proved quotient equality criterion. The association theorem itself remains unproved here.
- `BernsteinInductionJacquetSupportComparisonStatement`: the induction-defined and Jacquet-defined class support relations agree for every actual inertial class and actual representation. Both relations already require irreducibility. `IsBernsteinJacquetCuspidalSupport a π` says that the actual action of `a`, transported to the literal standard Levi by the inverse canonical homeomorphism, is an actual subquotient of the published normalized Jacquet module of `π` for that standard parabolic. `IsBernsteinJacquetInertialSupport s π` existentially ranges over all data in `s`. This comparison is at the class level: a constituent of the induction of one datum need not contain that identical datum in its Jacquet module for that identical parabolic. The proof of VI.5.4 on printed p.174 instead permits a conjugate standard cuspidal datum. Unramified twisting likewise need not preserve the constituents of one fixed induction. The class-level target avoids those stronger assertions.

The conditional theorem `bernsteinInertialSupport_existsUnique_of_comparisons` takes the exact existence and uniqueness targets as hypotheses and proves unique existence of the inertial support class of an irreducible. Its proof uses the actual datum from the existence hypothesis and the uniqueness hypothesis; it neither chooses a support function nor establishes any input theorem. No assumed Bernstein decomposition, block projector, variety structure or `I`/`R` functor occurs.

The Library's `Langlands.Aubert.General.RepresentedParabolic.LeviCuspidalSupportAssociationStatement` states VI.7.1 association for actual Jacquet constituents of arbitrary represented rational parabolics, with cuspidality quantified over all represented proper parabolics. `LeviCuspidalSupportSurjectiveStatement` states a quotient-of-Jacquet existence and finite-list assertion for each specified datum. `LeviSupercuspidalInductionAssociationStatement` states the VI.5.4 four-way equivalence for actual represented parabolics. These named targets explain the intended source dependency chain; none supplies a proof merely by existing as a proposition definition. Applying that chain here still requires its proofs and comparisons between the literal standard-family functors/cuspidality and the represented-parabolic functors/all-parabolic cuspidality. This module does not import an assumed instance of those propositions or claim that these bridges have been established.

The block properties already proved representative-independent in `BernsteinBlock` are defined by existential saturation under the genuine inertial quotient. That elementary invariance does not depend on these missing targets. Identifying their full categories with the source's single-valued Jacquet support fibres requires the comparisons just named. The Bernstein decomposition theorem itself is a further obligation outside this construction task.
