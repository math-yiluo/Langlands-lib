# Fixed vectors detected by irreducible actual subquotients

Worker 1751. This internal strengthening of the Library's cyclic-subquotient
argument retains a selected fixed vector. It uses the actual orbit-span,
maximal-subrepresentation and smooth-quotient constructions already used by
[`IrreducibleSubquotientExistence`](IrreducibleSubquotientExistence.md).
It requires no new representation-theoretic theorem from the literature.

`HasFixedVectorConstituent A H` means that there is a smooth representation D
in the same carrier universe as A which is irreducible, is an actual subquotient
of A, and has a nonzero H-fixed vector. Here H is any subgroup of the acting
group; no openness or compactness is needed.

`hasFixedVectorConstituent_of_nontrivial` proves this property whenever A has
a nonzero H-fixed vector. The proof chooses such a vector v, forms its actual
cyclic orbit-span subrepresentation B, and uses its one-element generating set
to obtain a maximal proper subrepresentation T. The actual quotient D=B/T is
irreducible by the existing maximal-kernel theorem. The cyclic generator cannot
lie in T, since then T would contain the whole orbit-span B. Consequently its
image in D is nonzero. The quotient map is an intertwiner, so its restriction
to H-fixed vectors supplies the required nonzero fixed vector of D. The actual
submodule and quotient, with the identity isomorphism, witness that D is a
subquotient of A. This is the existing cyclic argument with the additional
nonzero-image observation; merely applying the older existential theorem would
not guarantee preservation of the fixed vector.

`finite_fixedVectorSupport_of_finite_constituent_classes` is a conditional
class-counting consequence. An actual family A(i) is indexed by a type of class
labels. Q is a property of irreducible objects and c assigns a class label to
each irreducible smooth object. The hypotheses require every irreducible actual
subquotient of A(i) to satisfy Q and have class i, and finiteness of the labels
which admit an irreducible Q-object with a nonzero H-fixed vector. If A(i) has
nonzero H-fixed vectors, the first theorem extracts just such a constituent.
The supplied block condition gives its label i, placing i in that finite set.
Thus only finitely many A(i) have nonzero H-fixed vectors.

The class assignment and Q are explicit parameters of this internal lemma;
no actual inertia quotient, block decomposition or fixed-level finiteness is
constructed or assumed to exist globally. In the intended rational cuspidal
application those parameters must be the published actual inertia quotient and
proper-standard cuspidality, and the finite-class hypothesis must be proved by
the actual compact-level finiteness theorem. This unit does not discharge those
inputs or establish compression stability.

Both statements hold for any group with any topology and arbitrary smooth
complex representations. The group, carrier and class-label universes are
independent. No admissibility, finite dimension, finite generation of A, finite
length or reductive-group hypothesis is used. Only the cyclic subrepresentation
chosen inside A is generated by one vector.
