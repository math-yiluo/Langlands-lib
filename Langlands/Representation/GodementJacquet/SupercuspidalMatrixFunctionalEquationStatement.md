# Supercuspidal matrix functional-equation base

`Langlands.GodementJacquet.SupercuspidalMatrixFunctionalEquationStatement.{uF,uV}`
defines the full normalized matrix functional-equation existence proposition
for irreducible supercuspidal complex representations of `GL_d`, with `d ≥ 2`,
with both Euler denominators fixed to `1`. It supplies a statement only.

The quantifiers retain every prime `p`, every `F : PadicField.{uF} p`, the
canonical topology, valuation and local-field structures, and Borel structures
on the field and group. For every nontrivial continuous unitary additive
character `ψ`, every supplied scalar additive Haar measure `ν` with
`IsSelfDual ψ ν`, and every `n : ℕ`, the actual group is `GL_(n+2)`. Thus `n=0`
is rank two; rank one is handled by the separate Tate base statement.

The carrier `V : Type uV` has an independent universe and only its additive
commutative group and complex module structures. The actual representation `σ`
has premises `GeneralLinear.IsSupercuspidal σ` and
`Representation.IsIrreducible σ`. The existing supercuspidal predicate includes
admissibility, hence smoothness, and the vanishing of the actual Jacquet
coinvariants for every proper ordered block parabolic and every conjugate of
its unipotent radical. Irreducibility is a separate premise. No Whittaker
functional, selected central character, unitarity, matrix-coefficient support,
analytic assertion or chosen equivalent model is assumed.

The conclusion constructs a complex unit `c` and an integer `a` with

```text
Padic.NormalizedMatrixFunctionalEquationData (n := n+1)
  F ψ ν σ 1 1 c a.
```

Both polynomials are exactly the constant polynomial `1`. The full existing
data predicate retains common right half-planes of absolute convergence on
both sides for all full-matrix Schwartz–Bruhat tests and actual bi-smooth
coefficients, rational continuation for every pair, and both Laurent-span
generator equalities. The latter say that each rational-value family spans the
Laurent module generated by `1`. The polynomial constant coefficients equal
one. The original normalized exponent is `s+(n+1)/2`, and the transformed
exponent is `1-s+(n+1)/2`, since the actual rank is `n+2`.

For each test the Schwartz Fourier witness precedes every coefficient and
continuation pair. It retains integrability at each matrix and the plus
transpose formula with the exact square product of the supplied scalar measure
`ν`. The group measure and absolute value remain the canonical ones. The
transformed coefficient is `f(transpose(g⁻¹))`. The central scalar is `1` and
sign exponent is `0`. With `q` the canonical residue cardinality, the guarded
normalized equation specializes to

```text
RDual(q^(-(1-s))) = c (q^(-s))^a R(q^(-s)).
```

It holds for every actual continuation pair whenever both continuation
denominator evaluations are nonzero. The statement retains existence of these
continuations and does not replace it by the displayed conditional equation.

The source's absolutely cuspidal condition (2.13), printed page 26, uses the
vanishing quotient `V/V(P)` for every maximal proper parabolic. The space
`V(P)` is defined by compact-open unipotent averaging on printed pages 24–25.
The Library's actual Jacquet-quotient vanishing condition for all proper block
parabolics and conjugates is its algebraic form for these smooth complex
representations. In particular it includes every maximal proper parabolic of
`GL_d`; it is a sufficient hypothesis for the source theorem. The implementation
of a future proof must establish any averaging or compact-support consequences
it uses, rather than adding them as premises.

descendant of it. The scalar Tate case and the reduction from general
irreducible representations to cuspidal support are separate obligations.
