# The complex matrix equation for an evaluated principal series vector

`exists_complexPrincipalSeries_matrixZetaFunctionalEquation` proves the matrix functional equation for the value of a smooth complex principal series vector. It uses the basic trace character and assumes the vector has a polynomial height bound. Both of the matrix zeta integrals converge in a common right half-plane and have meromorphic continuations. The normalized equation is an equality of punctured germs.

The proof obtains two fixed diagonal Schwartz tests, related by Fourier transform, and uses the same Haar comparison scalar for both integrals. The torus density transports each inducing character and determinant power to a product Tate kernel. Initial convergence follows from the height estimate for matrix integrals. Inverse transpose preserves the height. The diagonal meromorphic Tate equation gives the matrix equation after multiplication by the common scalar.

This is the evaluation case of the Godement–Jacquet input to Jacquet's argument in Sections 4.7 and 8. The additive matrix transform here uses the Library's positive trace convention and its corresponding scalar Tate epsilon factors.
