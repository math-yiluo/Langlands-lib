# Matrix functional-equation data on irreducible Whittaker-type representations

`Langlands.GodementJacquet.GenericMatrixFunctionalEquationStatement.{uF,uV}`
is a closed proposition defining the existence assertion needed for
irreducible generic blocks. It states a restricted specialization of
Godement–Jacquet Theorem 3.3, using the existing data predicate in
`Langlands.Representation.GodementJacquet.AnalyticData`. This module defines
the proposition; it does not prove it.

## Exact scope

The statement quantifies every prime `p`, its primality instance, and every
`F : PadicField.{uF} p`. It installs the topology, valuation relation and
local-field instance from `F.canonicalTopologicalData`, with the Borel
measurable structures on the field and the general linear group. There is
no independently supplied topology.

For every bundled nontrivial continuous unitary additive character `ψ` and
every supplied scalar additive Haar measure `ν`, the premise is
`HarmonicAnalysis.IsSelfDual ψ ν`. The statement then quantifies every
`n : ℕ`, so the actual matrix rank is `d = n+1` and includes rank one at
`n=0`. The representation carrier `V : Type uV` has an independent universe
from the field, with only its additive commutative group and complex module
structures supplied.

For each actual representation
`σ : Representation ℂ (Langlands.GeneralLinear (n+1) F.Carrier) V`,
the representation premises are precisely

- `RankinSelberg.IsOfWhittakerType n (Whittaker.standardCharacter ψ n) σ`;
- `Representation.IsIrreducible σ`.

The full published Whittaker-type predicate retains admissibility, finite
generation of `σ.asModule` over the complex group algebra, and a nonempty
complex linear equivalence between the entire specified Whittaker functional
space and `ℂ`. A selected nonzero functional alone does not replace this
certificate. Irreducibility is an additional premise.

The conclusion is

```text
∃ (P PDual : Polynomial ℂ) (c : ℂˣ) (a : ℤ),
  GodementJacquet.Padic.NormalizedMatrixFunctionalEquationData F ψ ν
    σ P PDual c a.
```

It concerns the specified representation `σ` on `V`, without replacing it
by a coefficient model or an equivalent carrier. No scalar central
character, model equivalence, analytic assertion, continuation, generator
or selected factor is an additional premise. Any such intermediate input
needed by a future proof must be established there.

## The full data conclusion

The conclusion reuses the published `Padic.NormalizedMatrixFunctionalEquationData`
unchanged. Its canonical residue cardinality is `q`, its absolute value is
`RankinSelberg.normalizedAbsoluteValue F.canonicalTopologicalData`, and its
group measure is `RankinSelberg.generalLinearHaar F.Carrier n`.

The predicate includes common right half-planes of actual convergence for
all full-matrix Schwartz–Bruhat tests and all actual bi-smooth matrix
coefficients of `σ`, on both the original and inverse-transpose sides.
Each side also requires actual rational continuation for every test and
coefficient. The two proposed polynomials satisfy constant coefficient
one and the two equalities between the respective Laurent spans of
rational values and the modules generated by their reciprocal polynomials.
The two polynomials, unit `c` and integer `a` precede every test and coefficient.

For every full-matrix test `Φ`, the predicate requires a Schwartz–Bruhat
Fourier witness `ΦHat` before quantifying over all original coefficients
and all pairs of continuations. The Fourier relation includes integrability
at every matrix and equality with the actual integral using the plus
transpose pairing

```text
ΦHat(x) = ∫ Φ(y) ψ(Tr(y * transpose x)) dy.
```

The measure is exactly
`RankinSelberg.rectangularMeasure ν (n+1) (n+1)`, the product over all square
matrix entries of the same supplied scalar measure. Self-duality is a premise
on this `ν`; the statement neither selects a measure nor rescales it.
The transformed coefficient is explicitly
`coefficientIota f (g) = f(transpose(g⁻¹))`.

The original integral has exponent `s+n/2` and continuation variable
`q^(-s)`. On the transformed side these become `1-s+n/2` and
`q^(-(1-s))`. The equation is the existing
`RankinSelberg.NormalizedFunctionalEquation q P PDual 1 c 0 a R RDual`.
Thus, wherever both continuation denominator evaluations are nonzero, it reads

```text
PDual(q^(-(1-s))) RDual(q^(-(1-s)))
  = c (q^(-s))^a P(q^(-s)) R(q^(-s)).
```

The central scalar is `1` and the sign exponent is `0`. The equation ranges
over every pair of actual continuations, with both denominator guards.
The included existence clauses for continuations and Fourier witnesses
are retained; the conclusion is more than a gamma-factor existence assertion.
