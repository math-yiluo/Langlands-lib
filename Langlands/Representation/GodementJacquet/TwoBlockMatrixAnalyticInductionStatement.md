# Conditional two-block matrix analytic induction

Author: Worker 1075.

This module defines one proposition,
`Langlands.GodementJacquet.TwoBlockMatrixAnalyticInductionStatement.{uF,uV}`.
It is a statement target, not a proof. It formulates the analytic and
product-generator part of Godement–Jacquet Theorem 3.4 for two blocks of
split general linear groups over a p-adic field. The induced representation is
the actual normalized parabolic induction of the Library. The conditional
hypotheses are the published block functional-equation packages, and the
conclusion is a conjunction of the two published matrix analytic predicates.

## The statement

For every prime `p` and every `F : PadicField.{uF} p`, the canonical
realization `F.canonicalTopologicalData` supplies the topology, valuation and
local-field instances of `F.Carrier`. The field also gets its canonical Borel
measurable structure. These are the structures that the `Padic` wrappers of
`GodementJacquet.AnalyticData` install. The right uniform structure
and the published nonarchimedean instance
`HarmonicAnalysis.rowFourierCutoff_nonarchimedean` are installed only so that
`IsSelfDual` can find its `LocallyCompactSpace`, `T2Space` and
`TotallyDisconnectedSpace` instances. This is the same instance block as in the
published `HarmonicAnalysis.PadicRowFourierCutoffStatement`. Those three classes
are propositions, so the choice of instance proofs does not change the meaning
of `IsSelfDual`.

The remaining quantifiers come in this order.

1. `t : ℕ`, `m : Fin 2 → ℕ` and `h : ∑ i, (m i + 1) = t + 1`. The ambient
   group is `GL(t+1, F)`. The two blocks have actual ranks `m 0 + 1` and
   `m 1 + 1`, both positive and otherwise unrestricted. The block shape is the
   published `RankinSelberg.succBlockShape m h`, whose `i`-th size is
   `m i + 1`.
2. A dependent family `V : Fin 2 → Type uV` with explicit instances
   `[∀ i, AddCommGroup (V i)]` and `[∀ i, Module ℂ (V i)]`, and actual
   representations
   `σ i : Representation ℂ (GeneralLinear (m i + 1) F.Carrier) (V i)`.
   No irreducibility or Whittaker type is assumed.
3. `ψ : UnitaryAdditiveCharacter F.Carrier`. This structure contains continuity
   and the field `nontrivial : toAddChar ≠ 1`, so nontriviality of `ψ` is part
   of the binder itself and is not repeated as a separate premise.
4. `ν : AdditiveHaarMeasure F.Carrier` with the premise
   `HarmonicAnalysis.IsSelfDual ψ ν`. This intrinsic self-duality says that
   for every Schwartz–Bruhat function the second Fourier integral converges and
   the Fourier transform applied twice is reflection. The same `ν` is passed
   to both block packages, so the block Fourier data use exactly this measure.
5. `ω : Fin 2 → HarmonicAnalysis.Quasicharacter F.Carrier`, which are bundled
   continuous homomorphisms `F.Carrierˣ → ℂˣ`, together with
   `Classification.HasGLCentralCharacter F.Carrier (m i + 1) (σ i)
   (ω i : F.Carrierˣ →* ℂˣ)` for each `i`. Unfolded, this says
   `σ i (scalar a) v = ω i a • v` for every unit `a` and every vector `v` of the
   whole carrier `V i`.
6. `∀ i, IsSmooth (σ i)` and `∀ i, IsAdmissible (σ i)` in the canonical
   topology of `GL(m i + 1, F)`. The published `IsAdmissible` already contains
   `IsSmooth`. The smoothness premise is kept because the task contract lists
   it; it adds no restriction.
7. Proposed polynomials `Pi PDual : Fin 2 → Polynomial ℂ`, units
   `c : Fin 2 → ℂˣ`, integers `a : Fin 2 → ℤ`, and for each `i` the published
   package
   `GodementJacquet.Padic.NormalizedMatrixFunctionalEquationData F ψ ν (σ i)
   (Pi i) (PDual i) (c i) (a i)`.

The conclusion is exactly

```text
GodementJacquet.Padic.MatrixAnalyticAssertions F
    (F.canonicalNormalizedProductInduced (RankinSelberg.succBlockShape m h) σ)
    (∏ i, Pi i)
  ∧
GodementJacquet.Padic.IotaMatrixAnalyticAssertions F
    (F.canonicalNormalizedProductInduced (RankinSelberg.succBlockShape m h) σ)
    (∏ i, PDual i).
```

Since the index type is `Fin 2`, `∏ i, Pi i` is `Pi 0 * Pi 1`, and likewise
for `PDual`.

## What the hypotheses contain

Each block package
`Padic.NormalizedMatrixFunctionalEquationData F ψ ν (σ i) (Pi i) (PDual i)
(c i) (a i)` is the published conjunction of three parts. All of them use the
canonical residue cardinality `q`, the normalized absolute value, and the
canonical group Haar measure `generalLinearHaar F.Carrier (m i)`.

- `MatrixAnalyticAssertions` for `σ i` and `Pi i`. These are one common
  right half-plane of shifted convergence for all full-matrix Schwartz–Bruhat
  tests and all actual bi-smooth coefficients of `σ i`, an actual rational
  continuation in `q^(-s)` for every test and coefficient, and
  `IsNormalizedGenerator` for `Pi i`. The last condition means
  `(Pi i).coeff 0 = 1` and that the Laurent span of the value family equals
  the module generated by `(Pi i)⁻¹`.
- `IotaMatrixAnalyticAssertions` for `σ i` and `PDual i`: the same three
  conditions for the inverse-transpose functions `coefficientIota f` of the
  same original coefficients `f`.
- For every test `Φ` a Fourier witness `ΦHat`, together with the actual
  transpose-plus Fourier relation for `ν`, its integrability at every matrix,
  and the normalized functional equation with constants `c i` and `a i`. That
  equation is required for every coefficient and every pair of continuations,
  wherever both denominators are nonzero.

These packages are hypotheses only. The statement does not assert that they
exist for any block, irreducible or not.

## What the conclusion contains

The representation
`F.canonicalNormalizedProductInduced (RankinSelberg.succBlockShape m h) σ` is
the published normalized induction `i(σ 0, σ 1)` of `Induction/BlockFactors`.
It is the representation of `GL(t+1, F)`, acting by right translation, on
smooth functions `f` such that
`f(p x) = sqrt(δ_P(l)) • (σ 0 (l 0) ⊗ σ 1 (l 1)) (f x)`. Here `P` is the
standard upper block-triangular parabolic with top-left block of size
`m 0 + 1`, and `l = (l 0, l 1)` is the Levi part of `p`. Its carrier lies in
`Type (max uF uV)`. No equivalent model replaces it.

The first conjunct, unfolded through the published `Padic` wrapper, says three
things.

- One real `a` such that for every full-matrix test
  `Φ : MatrixTestFunction t F.Carrier`, every actual bi-smooth coefficient `f`
  of the induced representation, and every `s` with `a < s.re`, the matrix
  integral at `s + t/2` converges. The bound is chosen before the tests and
  coefficients.
- For every such `Φ` and `f`, a rational function `R` with
  `HasShiftedRationalValue`. Through the published
  `RankinSelberg.HasRationalContinuation`, this requires actual agreement of
  the shifted integral with `R(q^(-s))` on a right half-plane, where the
  denominator of `R` is also required to be nonzero.
- `IsNormalizedGenerator` for `∏ i, Pi i` and the published matrix value
  family. This means `(∏ i, Pi i).coeff 0 = 1` and that the Laurent span of all
  continuations equals the module generated by `(∏ i, Pi i)⁻¹`. This is an
  equality of submodules, so both inclusions are required.

The second conjunct says the same for the functions `coefficientIota f`,
`g ↦ f(transpose(g⁻¹))`, where `f` ranges over the actual bi-smooth
coefficients of the same induced representation. Its generator is
`∏ i, PDual i`. These functions are not identified, by definition, with the
coefficients of a smooth contragredient of the induced representation.

## Original source and exact correspondence

The principal source is Roger Godement and Hervé Jacquet, *Zeta Functions of
Simple Algebras*, Lecture Notes in Mathematics 260 (1972), registered as
`godement-jacquet-1972-zeta-simple-algebras`, SHA256
`86a8900900504adeb5757a04b5bb8a8754e6ef00b0fff49754096d371f59d568`.
The retained original is
`/home/taskhub/central-library/Godement-Jacquet--Zeta functions of simple algebras (book)--1972.pdf`.
The one-based PDF page is the printed page plus 10.

- Printed page 12 (PDF 22, checked visually) defines `Ind(G, P, σ)` on smooth
  functions with `f(pg) = δ(p)^(1/2) σ(p) f(g)` (2.8.1), acting by right
  translation. Printed pages 13 and 37 put `P` in upper block form
  `p = (g' u; 0 g'')`. So the source induction is normalized upper block
  induction, as in `canonicalNormalizedProductInduced`. Its first block `g'`
  corresponds to `σ 0` and its second block `g''` to `σ 1`.
- Printed pages 30–33 (PDF 40–43) state Theorem 3.3. Its assertions are:
  (1) common convergence of `Z(Φ, s+(n-1)/2, f)` for `Re s > s₀`;
  (2) a factor `L(s, π) = P(q^(-s))⁻¹` with `P(0) = 1` such that every
  normalized integral `Z/L` is a Laurent polynomial in `q^(-s)`;
  (3) some finite sum of these Laurent polynomials is `1`;
  (4) the functional equation.
  Assertions (1)–(3) for a representation are what
  `MatrixAnalyticAssertions` with proposed polynomial `P` records. Rational
  continuation and Laurent generation together say that the Laurent span of
  the values is generated by `P(q^(-s))⁻¹`.
- Printed pages 33–34 (PDF 43–44) explain that the assertions make sense for
  an admissible representation with scalar central quasicharacter even if it
  is not irreducible, that they are then not necessarily true, and that some
  such representations do satisfy them.
- Printed page 36 (PDF 46, checked visually) states Theorem 3.4. `P` is a
  maximal proper parabolic with `P/U ≅ G' × G''`, and `σ'`, `σ''` are
  admissible representations of `G'`, `G''`. They are not assumed
  irreducible, but quasicharacters `ω'`, `ω''` with `σ'(a) = ω'(a)·1` and
  `σ''(a) = ω''(a)·1` are assumed, and `π = Ind(G, P, σ' × σ'')`. If the
  assertions of (3.3) hold for `σ'`, `σ''` and their contragredients, then
  they hold for `π` and `π̃`, with
  `L(s, π) = L(s, σ')L(s, σ'')`, `L(s, π̃) = L(s, σ̃')L(s, σ̃'')` and
  `ε(s, π, ψ) = ε(s, σ', ψ)ε(s, σ'', ψ)`.

The formalized statement is the split case `H = F` of Theorem 3.4, with
`G = GL(t+1, F)`, `G' = GL(m 0 + 1, F)` and `G'' = GL(m 1 + 1, F)`. The
correspondence is as follows.

- Hypotheses: admissibility of each block is `IsAdmissible (σ i)`. The scalar
  central quasicharacters are `ω i` with `HasGLCentralCharacter`. The
  assertions of (3.3) for each block and its contragredient are the two
  analytic predicates inside each block package, with `L(s, σ_i)` given by
  `Pi i` and the second factor given by `PDual i`. The source's assertion (4)
  for each block is the package's functional-equation part. Its ε-factor is a
  nonzero constant times a power of `q^(-s)` (printed page 33), recorded as
  `c i` and `a i`. The central-character law `ω = ω'ω''` for `π` (printed
  page 36) is a consequence in the source and is not stated here.
- Conclusion: the assertions (1)–(3) for `π` together with
  `L(s, π) = L(s, σ')L(s, σ'')` form the first conjunct with generator
  `Pi 0 * Pi 1`. The assertions (1)–(3) for `π̃` together with
  `L(s, π̃) = L(s, σ̃')L(s, σ̃'')` form the second conjunct with generator
  `PDual 0 * PDual 1`, in the transpose convention described below.
- Not part of this statement: assertion (4) for `π`, the ε-product formula,
  the central character of `π`, Proposition 3.5 (printed pages 45–46, any
  number of blocks), Corollary 3.6, and any existence of the block data.

The proof in the source, which a future proof must reproduce for the actual
Lean objects, runs as follows. Printed page 38 (PDF 48) chooses the additive
measures with `dm = dx dy du dv` for self-dual `dm`, `dx`, `dy`, and proves
the partial Fourier Lemma 3.4.0. Printed page 39 expresses the coefficients of
`π` as `f(g) = ∫_K ⟨v(kg), ṽ(k)⟩ dk` and uses the shifts `s+(n-1)/2`,
`s+(n'-1)/2` and `s+(n''-1)/2`. Printed pages 40–41 (PDF 50–51) expand
`Z(Φ, t, f)` as a finite sum of products of block integrals, with constants
`C_ij`. This gives common convergence and the inclusion of the normalized
values of `π` in the product of the block Laurent modules. Printed page 42
(PDF 52) gives the analogue for `π̃` and the functional equation. Printed pages
43–45 (PDF 53–55), using Lemma 3.4.6, prove the reverse inclusion: every
product of block integrals is a finite sum of integrals of `π`. The equality
of submodules in the conclusion needs both inclusions.

## Convention adaptation

The published predicates follow the transpose-adapted conventions of
H. Jacquet, I. I. Piatetski-Shapiro and J. Shalika, *Automorphic Forms on
GL(3) I* (1979), printed page 177, one-based PDF page 10, equations
(1.1.1)–(1.1.2). This source is registered as `jps-1979-gl3-i`, SHA256
`6446822f267f9f95156ce7a193409209e56ce7858ed6d3d350480e73f35b1aa5`, and
retained at
`/home/taskhub/central-library/Jacquet-Piatetski-Shapiro-Shalika--Automorphic Forms on GL(3) I--1979.pdf`.

- The Fourier transform is `ΦHat(x) = ∫ Φ(y) ψ(Tr(y * transpose x)) dy`, with
  a plus sign. The published `MatrixFourierPair` uses
  `rectangularPairing y x = ∑ i, ∑ j, y i j * x i j`, which equals
  `Tr(y * transpose x)`.
- The transformed coefficient is `f^ι(g) = f(transpose(g⁻¹))`, which is
  `coefficientIota f` with an explicit formula. In its irreducible setting the
  1979 source identifies it with a coefficient of the contragredient. Here no
  such identification is made. For the induced representation, a bridge
  between `coefficientIota` of its coefficients and the source's `π̃` is a
  future proof obligation, with all its hypotheses checked. In particular,
  inverse transpose carries the upper block parabolic to the lower one.
- For actual rank `r = n+1`, the integral is evaluated at
  `s + (r-1)/2 = s + n/2`, the published `jpssShift n`. For the induced
  representation this is `s + t/2`, and for block `i` it is `s + (m i)/2`.
  The rational variable is `q^(-s)`.

Section 7 of the 1979 paper treats `GL(3)`. It is used here only for these
conventions, not as an analytic substitute for arbitrary rank.

The coefficient family is that of H. Jacquet, I. I. Piatetski-Shapiro and
J. A. Shalika, *Rankin–Selberg Convolutions* (1983), Section 5, printed
pages 420–423 (PDF 55–58, checked visually), registered as
`jpss-1983-rankin-selberg`, SHA256
`d9feed6388ca5acf02ecc6a8cce984871a7c28f062ff441e45a71fa2d8962245`, and
retained at
`/home/taskhub/central-library/Jacquet-Piatetski-Shapiro-Shalika--Rankin-Selberg Convolutions--1983.pdf`.
Section 5.2 (printed 420–421) uses the bi-`K`-finite coefficients and the
integral `Z(Φ, s+(t-1)/2, f)` with Laurent variable `X = q^(-s)`. Printed
page 422, (5.4)(2), restates the conventions `f^ι(g) = f(ᵗg⁻¹)` and
`Φ̂(x) = ∫ Φ(y) ψ(tr(y ᵗx)) dy`. The applications of Godement–Jacquet
Theorem 3.4 there do not use the original blocks directly. In (5.3), printed
pages 421–422, each Whittaker-type block `σ_i` is first replaced by its
quotient acting on the Whittaker model `W(σ_i; ψ)`. In (5.4), printed
pages 422–423, the theorem is applied to the induction of the generic
constituents `(σ_i)_0`. This statement makes no such passage. It is
conditional on supplied matrix data for the actual blocks and concludes only
analytic assertions for the actual induced carrier, not a matrix functional
equation.

## Measures and internal packaging

The block packages and the conclusion use the canonical group Haar measure
`generalLinearHaar` on each general linear group, as fixed by the published
`Padic` wrappers. The source uses some Haar measure `d^×g`. A different
choice multiplies every integral by one positive constant and changes neither
convergence nor any Laurent span. The supplied self-dual `ν` enters only
through the block Fourier relations, as the scalar factor of the product
measure on full matrices. Printed page 38 factors the self-dual matrix measures
in the source. Keeping a self-dual `ν` as a premise retains that hypothesis of
the conditional source theorem for the future proof. No choice or rescaling of
`ν` takes place.

The statement is a derived formulation, not a verbatim transcription. It uses
specific Lean packages: a conjunction of two published predicates for the
conclusion, the full functional-equation package for each block as the
hypothesis, and products of proposed polynomials for the generators. These
choices follow the task contract and the published `AnalyticData` interface.
They keep every part of those predicates, including integrability and the
denominator guards inside continuation.

## Universes and scope

The universes `uF` of the field and `uV` of the block carriers are
independent. The induced carrier lies in `Type (max uF uV)`. Development
inspection reports level parameters `uF, uV`, a `Prop`-valued declaration,
and only the axioms `propext`, `Classical.choice` and `Quot.sound`.

No existing Library Lean or Markdown file is changed. The module proves
nothing. It asserts no existence of block packages, no matrix functional
equation or ε-product for the induced representation, no JPSS factor
certificate, no multiplicativity for Whittaker-type inputs, and no generic
constituent occurrence.
