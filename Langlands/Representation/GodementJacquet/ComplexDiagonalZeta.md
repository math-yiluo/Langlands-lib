# Complex diagonal zeta integrals

`complexDiagonalZeta` is a meromorphic continuation of the additive-coordinate zeta integral with integral angular weights and independent complex spectral exponents. Each scalar kernel uses the density for multiplicative Haar and is defined by zero at the origin. The product additive measure is the one self-dual for the trace character.

The proof uses polar coordinates in each complex variable. The Jacobian changes the powers of the radii to the positive-coordinate Mellin exponents \(2u_i-1\). The angular integral is a real Schwartz test by the Schwartz averaging theorem. A product majorant gives absolute integrability before Fubini, and the real coordinate Mellin continuation gives meromorphy on every complex affine line with real coordinate slopes.

This module supplies the diagonal analytic input to the triangular calculation of the matrix integrals. It is an auxiliary result for Jacquet's argument in Section 4.7 of *Archimedean Rankin–Selberg Integrals*.
