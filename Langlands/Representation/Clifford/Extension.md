# Extension of an invariant irreducible representation across a finite cyclic quotient

This internal module proves the classical extension lemma: an irreducible
finite-dimensional complex representation `c` of a normal subgroup `K` of a
group `H` extends to `H` when `H / K` is finite cyclic, generated by the class
of some `g`, and `c` is equivalent to its conjugate by `g`. Only the algebraic structure is used; `H` may be infinite.

## Setting

`H` is a group, `K` a normal subgroup and `g ∈ H`. `conjPow K g i` is the
endomorphism `k ↦ g^i k g^(-i)` of `K`. The hypotheses of the main result
are:

- every `x ∈ H` is congruent to a power of `g` modulo `K`
  (`∀ x, ∃ i, x * (g^i)⁻¹ ∈ K`),
- `g^e ∈ K` for some `e > 0`, and `g^i ∈ K` only if `e ∣ i`, so that `H / K`
  is cyclic of order `e` with generator the class of `g`,
- `c` is irreducible and equivalent to its conjugate `c ∘ conjPow K g 1`.

## Results

- `units_zpow_mul_eq`: if an invertible operator `T` satisfies
  `T * c k = c (g k g⁻¹) * T` for all `k`, then `T^i * c k = c (g^i k g^(-i)) * T^i`
  for every integer `i`, by induction on `i` in both directions.
- `exists_normalized_intertwiner`: there is such a `T` with, in addition,
  `T^e = c (g^e)`. Starting from the inverse `T₀` of a given equivalence, the
  operator `c (g^e)⁻¹ * T₀^e` commutes with `c`, so by Schur's lemma
  (`CyclicRestriction.end_eq_smul_one`) it is a scalar `l`, nonzero because
  the operator is invertible. Dividing `T₀` by an `e`-th root of `l` in `ℂ`
  gives `T`.
- `exists_extension`: under the hypotheses above there is a representation
  `θ` of `H` with `θ ∘ K.subtype = c`. Writing `x = k g^i` with `k ∈ K`, it is
  defined by `θ x = c k * T^i`. The value does not depend on the choice of
  `i`, since two choices differ by a multiple of `e` and `T^e = c (g^e)`; the
  homomorphism property follows from `units_zpow_mul_eq`.
