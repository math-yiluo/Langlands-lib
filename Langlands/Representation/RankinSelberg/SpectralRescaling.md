# Spectral rescaling of rational continuations and Laurent generators

Author: Worker 352.

This module constructs substitution `X ↦ c X` for every complex unit `c` and
proves its compatibility with the existing rational-continuation and normalized
Laurent-generator relations. It imports `RationalContinuation` and `RationalZeta`
without changing their definitions. All declarations below are in
`Langlands.RankinSelberg`.

## Provenance and scope

This is derived algebraic infrastructure, not a transcription of a numbered
analytic theorem. Its motivating source is Jacquet, Piatetski-Shapiro and
Shalika, *Rankin–Selberg Convolutions*, American Journal of Mathematics 105
(1983), 367–464, §2.4, printed p.387, and Theorem (2.7)(i)–(ii), printed
pp.390–391. Registered source: `jpss-1983-rankin-selberg`; retained PDF SHA-256:
`d9feed6388ca5acf02ecc6a8cce984871a7c28f062ff441e45a71fa2d8962245`.
In the retained scan these are PDF pages 22 and 25–26, counting from one.
Section 2.4 introduces the zeta integrals with their spectral powers, and
Theorem (2.7) supplies convergence, rationality in `q^(-s)` and a Laurent
fractional ideal generated by `1/P(q^(-s))` with `P(0)=1`.

The present construction abstracts elementary substitution in the polynomial
ring, its fraction field, and its Laurent subring. It does not prove convergence
or rationality of any integral, existence of a normalized generator, or an
identity between twisted integrals. Its continuation results apply to arbitrary
functions `f : ℂ → ℂ`, rational functions `R`, complex shifts `u`, and natural
numbers `q` with `1 < q`. Its algebraic results apply to arbitrary sets `S` of
actual rational functions and arbitrary polynomials `P`, with no analytic
hypotheses. No transport law is supplied as an assumption.

## Construction and algebraic API

`polynomialRescale c : ℂ[X] ≃ₐ[ℂ] ℂ[X]` is the polynomial algebra automorphism
`P ↦ P.comp (C (c : ℂ) * X)`. The construction uses
`Polynomial.algEquivOfCompEqX`, checking that composition with the corresponding
polynomial for `c⁻¹` gives `X` in both orders. `polynomialRescale_apply` gives the
formula and `polynomialRescale_symm` identifies the inverse.

`rationalRescale c : RationalFunctions ≃ₐ[ℂ] RationalFunctions` extends this
map to the fraction field by `IsFractionRing.algEquivOfAlgEquiv`.

| Declaration | Result |
| --- | --- |
| `rationalRescale_algebraMap` | A polynomial embedded in the rational function field maps to the embedding of `P.comp (C (c : ℂ) * X)`. |
| `rationalRescale_symm` | The inverse automorphism is `rationalRescale c⁻¹`. |
| `rationalRescale_inv_apply`, `rationalRescale_apply_inv` | Rescaling by `c` and `c⁻¹` cancels in either order. |
| `rationalRescale_C`, `rationalRescale_X` | Constants are fixed, and `X` maps to `RatFunc.C (c : ℂ) * RatFunc.X`. |
| `rationalRescale_num_div_denom` | The rescaled function is the quotient of the embedded, substituted numerator and denominator of `R`. |
| `rationalRescale_denom_dvd` | Its reduced denominator divides `R.denom.comp (C (c : ℂ) * X)`. |
| `rationalRescale_denom_ne_zero` | If `R.denom.eval ((c : ℂ) * x) ≠ 0`, the rescaled reduced denominator is nonzero at `x`. |
| `rationalRescale_denom_ne_zero_iff` | The preceding nonvanishing conditions are equivalent. |
| `rationalRescale_eval` | Under that nonvanishing condition, evaluation of the rescaled function at `x` equals evaluation of `R` at `(c : ℂ) * x`. |

The quotient formula follows by mapping `RatFunc.num_div_denom`. The denominator
bound then uses `RatFunc.denom_div_dvd`, so it concerns the actual reduced
denominator, not an alternative denominator chosen as part of the definition.
Evaluation of this divisibility proves forward nonvanishing. Applying it again
to the inverse rescaling proves the converse. For the evaluation identity, the
proof uses `RatFunc.num_mul_eq_mul_denom_iff` to cross-multiply the displayed
fraction. Evaluation of that polynomial equality and both nonzero denominators
then gives equality of the evaluated fractions. The API does not assert that
rational evaluation is an unconditional ring homomorphism at poles.

## Transport of the actual Laurent span

`rationalRescale_laurentToRatFunc c a` constructs a Laurent coefficient `b` with

```lean
laurentToRatFunc b = rationalRescale c (laurentToRatFunc a)
```

The proof uses finite Laurent sums. On a monomial `a T^n`, with integer `n`,
it uses `(a * c^n) T^n`; on a sum, it adds the constructed coefficients.
Thus the result uses the actual Laurent embedding. Applying the same result
to `c⁻¹` also preserves the coefficient ring under the inverse map; a separate
bundled Laurent automorphism is unnecessary for this interface.

`rationalRescale_mem_zetaSpan c h` transports membership from `zetaSpan S` to
`zetaSpan (rationalRescale c '' S)`. Its proof is induction on the Laurent
module span: generators map into the image set, sums and zero are preserved,
and the constructed Laurent coefficients handle scalar multiplication.
`rationalRescale_mem_zetaSpan_iff c S R` proves the reverse direction by inverse
rescaling and cancellation of the two images. These are semilinear transport
properties of the existing Laurent scalar action, not complex-linear span
substitutes.

The main normalization API is:

```lean
IsNormalizedGenerator.rescale
  {S : Set RationalFunctions} {P : ℂ[X]}
  (h : IsNormalizedGenerator S P) (c : ℂˣ) :
  IsNormalizedGenerator (rationalRescale c '' S)
    (P.comp (C (c : ℂ) * X))
```

The proof uses `isNormalizedGenerator_iff`. Substitution leaves evaluation at
zero unchanged, hence preserves `P.coeff 0 = 1`. For each image generator it
maps the old denominator-clearing identity and transports its Laurent
coefficient. Finally, the reciprocal polynomial belongs to the old span, so
span transport puts the reciprocal substituted polynomial in the new span.
The characterization then yields exactly equality of the new Laurent span
with the span of that reciprocal polynomial.

## Spectral shifts

`spectralShiftUnit q hq u : ℂˣ` is `Units.mk0 (spectralPoint q u)`.
Nonvanishing follows from `q > 1` and complex-power nonvanishing.
`coe_spectralShiftUnit` gives its value `spectralPoint q u = (q : ℂ)^(-u)`.
`spectralPoint_add hq s u` proves

```lean
spectralPoint q (s + u) = spectralPoint q u * spectralPoint q s
```

using `Complex.cpow_add` with nonzero base. Consequently
`spectralShiftUnit_neg` identifies the unit for `-u` with the inverse unit.
There is no restriction on the real or imaginary part of `u`.

`HasRationalContinuation.shift hq h u` proves

```lean
HasRationalContinuation q (fun s => f (s + u))
  (rationalRescale (spectralShiftUnit q hq u) R)
```

from `h : HasRationalContinuation q f R`. If the old continuation has threshold
`a`, the proof takes threshold `a - u.re`. At each point in this actual right
half-plane, `s + u` lies in the old half-plane. The spectral-point product
identity, the reduced-denominator nonvanishing lemma, and the rational
evaluation lemma then prove both conjuncts of the continuation relation.

`hasRationalContinuation_shift_iff hq f R u` states the full equivalence, with
the shifted relation on the left and `HasRationalContinuation q f R` on the
right. The reverse implication shifts by `-u`, cancels the translations and
uses inverse rescaling. Thus both directions retain the existing actual
right-half-plane denominator requirement. These results supply the algebraic
interface for the separate unramified-twist integral transport.
