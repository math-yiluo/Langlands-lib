# Normalized generator existence from a common denominator

`Langlands.RankinSelberg.NormalizedGeneratorExistenceStatement` is the
Prop-valued definition

```lean
∀ values : Set RationalFunctions,
  HasCommonDenominator values →
  (1 : RationalFunctions) ∈ zetaSpan values →
  NormalizedGeneratorExists values
```

This module states this implication. It neither proves nor assumes it. It
imports `Langlands.Representation.RankinSelberg.RationalZeta` and reuses its
objects without changing them.

## Meaning of the statement

All names below are in `Langlands.RankinSelberg`. `RationalFunctions` is
`RatFunc ℂ`, and `LaurentCoefficients` is `LaurentPolynomial ℂ`. The map
`laurentToRatFunc` embeds the latter ring into the former field, sending the
Laurent variable to the rational indeterminate `X`. The scalar action used by
`zetaSpan values = Submodule.span LaurentCoefficients values` is multiplication
through that embedding.

`HasCommonDenominator values` means that there exists one nonzero Laurent
polynomial `d` such that for every `f ∈ values` there is a Laurent polynomial
`p` with `laurentToRatFunc p = laurentToRatFunc d * f`. The choice of `d` is
uniform over the whole set. Having `values : Set RationalFunctions` gives
pointwise rationality; it does not supply a uniform denominator for an
arbitrary, possibly infinite set. The statement adds no polynomial-denominator
or finiteness hypothesis.

The second hypothesis places `1` in the Laurent span. It need not belong to
the original value set: a finite Laurent linear combination of values may
equal `1`. This condition also excludes the zero span, without a separate
nonemptiness assumption.

`NormalizedGeneratorExists values` means that there is a polynomial
`P : ℂ[X]` satisfying `IsNormalizedGenerator values P`. The latter predicate
requires `P.coeff 0 = 1` and

```lean
zetaSpan values = Submodule.span LaurentCoefficients
  {(algebraMap ℂ[X] RationalFunctions P)⁻¹}
```

The constant-coefficient condition implies that `P` is nonzero. Any such
reciprocal-generated span contains `1`, since multiplying its generator by
`P.toLaurent` gives `1`. Thus unit membership is necessary. Ordinary
principality alone permits the zero span and proper integral ideals, such as
the ideal generated by `X - 1`, which do not contain `1`.

## Derived algebraic provenance

The implication isolates the elementary algebra behind the normalization in
JPSS. The existing `hasCommonDenominator_iff_isFractional` identifies the first
hypothesis with fractionality of the span. The Laurent ring is a PID, as
recorded by `laurentCoefficientsIsPrincipalIdealRing`, and
`exists_rationalGenerator` already gives a rational generator `g` for such a
fractional ideal.

If the span contains `1`, then `g` is nonzero and `1 = a * g` for an embedded
Laurent polynomial `a`. Consequently `g⁻¹` is a Laurent polynomial. Write this
nonzero Laurent polynomial as `c * X^m * P`, where `m` is its least exponent,
`c` its nonzero coefficient there, and `P` is a polynomial with constant
coefficient `1`. Powers of `X` and nonzero complex scalars are Laurent units.
It follows that `P⁻¹ = c * X^m * g` generates the same Laurent span.

This paragraph explains the derived algebraic argument intended for a
separate proof. It is not an implemented Lean proof in this module.
`zetaSpan_isPrincipal` and `exists_rationalGenerator` supply ordinary
principality, while `IsNormalizedGenerator.unique` compares two already
normalized generators. Those existing results do not already prove the
existence implication stated here. No analytic or representation-theoretic
hypotheses, including irreducibility, are added to this algebraic statement.

## Original source

H. Jacquet, I. I. Piatetski-Shapiro and J. A. Shalika,
*Rankin–Selberg Convolutions*, American Journal of Mathematics 105 (1983),
367–464, proof of Theorem 2.7(i)–(ii), printed pp.392–394:

- On p.392, following formula (6), the equal-rank integrals are shown to be
  rational functions with a denominator independent of the Whittaker and
  Schwartz data; their span is then treated as a Laurent module.
- On p.393, after constructing an integral equal to `1`, the paragraph ending
  the equal-rank argument passes from the ideal containing `1` to its unique
  generator `P(X)⁻¹` with `P(0) = 1`.
- On p.394, following formula (7), the unequal-rank argument gives a fixed
  denominator, a fractional ideal `I_j` containing `1`, and the corresponding
  generator `P_j(X)⁻¹` with `P_j(0) = 1`.

The proposition here is a derived algebraic abstraction of those steps,
quantified over an arbitrary set of rational functions. It is not a verbatim
JPSS theorem and does not formalize the analytic arguments establishing its
hypotheses, the uniqueness assertion, or independence of `j`.
