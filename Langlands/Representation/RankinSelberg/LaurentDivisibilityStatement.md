# Laurent-span criteria for polynomial divisibility

This module states three algebraic criteria and their conjunction
`Langlands.RankinSelberg.LaurentPolynomialDivisibilityStatement`.
Every declaration is a Prop-valued definition. The module supplies no proof of
any of these criteria and assumes none of them as an axiom.

All declaration names below lie in `Langlands.RankinSelberg`. The definitions
are imported from [RationalZeta](RationalZeta.md): `LaurentCoefficients` is
`LaurentPolynomial ℂ`, `RationalFunctions` is `RatFunc ℂ`, and the Laurent
scalar action is multiplication through `laurentToRatFunc`. That ring homomorphism
sends the Laurent variable to the rational indeterminate. Write `ι` for the
polynomial embedding `algebraMap ℂ[X] RationalFunctions`, and write `R` for
`LaurentCoefficients`. Thus the spans below use the existing Laurent action,
not a separately chosen action.

1. `ReciprocalLaurentSpanClearingStatement` quantifies all polynomials
   `P, A : ℂ[X]` with `P ≠ 0` and `A ≠ 0`. It states
   \[
   ι(P)^{-1} \in \operatorname{span}_R\{ι(A)^{-1}\}
   \quad\Longleftrightarrow\quad
   \exists Q\in\mathbb C[X],\ \exists e\in\mathbb N,\quad
   X^e A = QP.
   \]
   The equation is in the polynomial ring and the exponent is nonnegative.
2. `NormalizedReciprocalLaurentSpanDivisibilityStatement` quantifies all
   `P, A : ℂ[X]` with `P.coeff 0 = 1` and `A ≠ 0`. It states
   \[
   ι(P)^{-1} \in \operatorname{span}_R\{ι(A)^{-1}\}
   \quad\Longleftrightarrow\quad P\mid A.
   \]
   Normalization implies `P ≠ 0`; `A` is not required to be normalized.
3. `NormalizedGeneratorSpanDivisibilityStatement` quantifies all sets
   `S, T : Set RationalFunctions` and polynomials `P, A : ℂ[X]`, under
   `IsNormalizedGenerator S P` and `IsNormalizedGenerator T A`. It states
   \[
   \operatorname{zetaSpan}(S)\leq\operatorname{zetaSpan}(T)
   \quad\Longleftrightarrow\quad P\mid A.
   \]
   Each normalized-generator hypothesis asserts constant coefficient one
   and identifies the corresponding Laurent span with the singleton span of
   the reciprocal polynomial. Both polynomials are consequently nonzero,
   as already expressed by `IsNormalizedGenerator.polynomial_ne_zero`.
   The sets are arbitrary rational-function sets; no origin as analytic
   zeta integrals is assumed.

The aggregate is exactly the conjunction of clauses 1, 2, and 3 in that order.
In clauses 2 and 3, the direction is `P` divides `A`: the reciprocal of `P`
belongs to the Laurent span generated by the reciprocal of `A`.

## Internal provenance and rationale

This is a derived algebraic interface from the published `RationalZeta`
constructions, not a separately cited theorem from the Rankin–Selberg
literature. Worker 46 specified this interface to expose algebra needed by
later factor-divisibility arguments. Worker 356 authored this statement pair.
The predecessor module, authored by Worker 31, already contains the private
lemmas `polynomial_dvd_of_laurent_multiple` and
`polynomial_dvd_of_reciprocal_mem`. They motivate the normalized forward
implication; this module neither edits them nor refers to their private Lean
names in any declaration.

The algebraic rationale is that singleton-span membership means multiplication
by one Laurent polynomial. Clearing its negative powers of `X` yields the
first displayed equation; conversely that equation gives the Laurent
multiplier `Q X^{-e}`. When `P(0) = 1`, `P` is coprime to `X`, so the power of
`X` can be removed from the divisibility condition. Finally, inclusion of two
singleton spans is equivalent to membership of the first generator in the
second span. These observations explain the proposed statements; their Lean
proofs remain separate work.

No analytic rationality, multiplicativity, convergence, or existence of a
normalized generator is stated or proved here. The sole project import is
`Langlands.Representation.RankinSelberg.RationalZeta`; its Lean/Markdown pair
and all existing Library pairs are unchanged.
