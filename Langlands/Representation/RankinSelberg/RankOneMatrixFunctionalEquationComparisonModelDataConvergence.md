# Raw convergence from matrix data on the actual model

This internal adapter keeps the representation carrying the supplied matrix data explicit. That representation is the right-translation action on the actual coefficient-image model; no matrix bound on the original, possibly reducible carrier is assumed.

`RawModelMatrixConvergence` and `RawModelIotaMatrixConvergence` express genuine unshifted matrix convergence on a possibly test-dependent right half-plane for a fixed original model vector, and for its actual inverse-transpose function, respectively. They use the existing matrix tests, matrix integrands, and normalized general-linear Haar. Both include every full-matrix Schwartz test and every rank, including the scalar case.

`coefficientModelEvaluation_coefficient` proves that evaluation at the identity, applied to the translated model vector, is exactly the original model function: `W(1*g) = W(g)`. `rawModelMatrixConvergence_of_modelMatrix` therefore applies RawConvergence to the model representation and this actual evaluation functional. Smoothness descends to the model, and the original model vector itself is the vector used in that coefficient.

The generic theorem `whittakerCoefficientIota_matrixConvergesOnRight_of_iota` first handles an abstract smooth representation and its actual coefficient. For `rawModelIotaMatrixConvergence_of_modelIota`, this generic theorem is specialized to the model representation and evaluation functional. Continuous inverse-transpose pullback transports the supplied transformed matrix bounds to ordinary bounds on the pulled-back model representation. Its first dual functional has the inverse additive character and its coefficient is exactly the unsigned long-Weyl dual of the original function. RawConvergence applies with this actual scaled character. The existing Weyl change of variables then gives convergence of the literal inverse-transpose function against the original full-matrix test, with no scalar. No equivalence with the original carrier or identification of the two coefficient images is used.

`rawModel_pair_convergence_of_data` extracts the two convergence hypotheses from the exact matrix functional-equation data on the representation appearing in the host target. It requires smoothness of the original representation but no irreducibility, admissibility, finite generation, nonzero functional, or self-duality hypothesis for this convergence-only conclusion. The character, normalized Haar, arbitrary independent field and carrier universes, all ranks, and full test space are retained. The spectral exponents in the two raw conclusions are unshifted; RawConvergence has already accounted for the published matrix shift in the half-plane threshold.

This is source-free composition of the proved raw convergence theorem, actual evaluation on a coefficient image, smooth pullback, first-dual coefficient transport, and the actual measure-preserving Weyl substitution. It supplies convergence only and proves neither rational continuation nor the final gamma comparison.
