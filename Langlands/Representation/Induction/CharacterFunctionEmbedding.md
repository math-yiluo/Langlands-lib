# Character functions in smooth induction

This internal construction applies to any commutative coefficient ring, an
actual topological group, a subgroup, and a subgroup representation whose
action is scalar by the restriction of a supplied character of the full group.
The character must have open kernel.

A vector `v` defines the function `g ↦ χ(g) • v`. The scalar-action hypothesis
proves covariance, and the open character kernel is one right stabilizer for
the entire function. These functions give a linear intertwiner from the
character twist of the trivial representation on the same carrier into the
actual smooth induced representation. Right translation multiplies the
function by the character. Evaluation at the identity recovers `v`, proving
injectivity. No irreducibility or dimension assertion is made.
