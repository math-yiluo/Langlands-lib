# The natural compact-induction comparison map

Worker 133, Task 5403. Derived construction for Renard III.2.6,
printed pp.75–76 / PDF pp.81–82, registered source
`renard-2026-representations-groupes-reductifs-padiques`.

The elementary comparison is viewed as an additive pairing on the original
carriers. Its proved subgroup Hecke balancing lets the published universal
property descend it through the actual nonunital tensor quotient over the
integers. `compactComparisonLift` is this additive quotient map and has the
original elementary compact-function value on every pure tensor.

The published equivariant tensor lift, using ambient Hecke compatibility,
bundles the same map as `compactComparisonHom`, a morphism between the exact
Hecke tensor-induction and relatively twisted compact-induction functors.
Postcomposition with a subgroup intertwiner commutes with the algebraic
integrated action. Equality on pure tensors then proves naturality, giving
`compactComparisonNatTrans`. This construction does not assert bijectivity.
