# Actual subquotient generation and categorical subobject closure

Module `Langlands.Representation.Hecke.FixedVectorSubquotientClosure`, namespace
`Langlands.Hecke`.

This is an internal adapter between published Library definitions. Its setting
is any group `G : Type u` with a topology and an open subgroup `K`; smooth
complex representation carriers have independent universe `v`. Compactness,
local compactness, Haar measure, and reductive or Iwahori structure are not
assumed.

`fixedVectorSubquotientClosure K` is a proposition: for every smooth
representation `V` generated by its `K`-fixed vectors, every actual smooth
subquotient `D` of `V` is also generated by its `K`-fixed vectors. It uses exactly
`fixedVectorGeneratedProperty` from the generation bridge and the published
`SmoothRep.IsSubquotient` relation. This definition asserts no closure theorem.

`fixedVectorGenerated_closedUnderSubobjects_of_subquotients K h` proves
categorical subobject closure from an explicit proof `h` of that proposition.
A categorical monomorphism is an injective intertwiner by
`SmoothRep.mono_iff_injective`. It therefore witnesses the published
`SmoothRep.IsSubrepresentation` relation, which implies `IsSubquotient` by
`SmoothRep.IsSubrepresentation.isSubquotient`. Applying `h` gives the property
of the monomorphism's source.

The general subrepresentation-to-subquotient lemma is imported from
`Classification.SupercuspidalSupport`; no classification assertion is used.
The adapter is an internal consequence of these two published lemmas. It does
not assume a proof of the named VI.9.4 statement, nor does it establish closure
for any compact open subgroup or prove Renard VI.10.6 Proposition (ii)
(`StandardIwahoriCornerInductionEquivalenceStatement`). Its intended
application supplies `h` from a separate VI.9.4 proof.
