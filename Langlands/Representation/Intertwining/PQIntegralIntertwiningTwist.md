# Character multiplication and integral-normalized intertwining

This internal lemma applies the published normalized-induction character equivalence to a represented parabolic. The smooth ambient character is trivial on the image of the source unipotent radical, and the coefficient character is its pullback along the intrinsic Levi inclusion. The equivalence multiplies each function value by the ambient character on the original coefficient carrier.

Start with a map satisfying `IsIntegralIntertwiner` and use the pointwise multiplication formula for both the source and target equivalences. Character multiplication preserves vanishing on the boundary of the identity double coset. It fixes the tested values on the integration subgroup when the character is trivial there, and fixes evaluation at the identity. The conjugated map satisfies the same integral formula at the same measure.
