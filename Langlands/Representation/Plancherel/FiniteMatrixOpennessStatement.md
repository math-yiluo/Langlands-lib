# Finite matrix irreducibility and openness

This internal auxiliary proposition concerns an arbitrary family of complex
square matrices on a finite coordinate space. The parameter space is any
topological space, and the matrix labels form any type. If every matrix entry
depends continuously on the parameter, the parameters at which the matrices
have no common invariant subspace other than zero and the full space form an
open set.

The statement uses the published
`Langlands.UnitarizabilityContinuation.IsIrreducibleFamily`. This convention
also holds on the zero-dimensional space; no nonzero-carrier condition is
asserted. The finite coordinate type and the matrix-label and parameter types
have independent universes.

This is a derived linear-algebra step for the character-family openness
argument in Waldspurger IV.2.2(i). It is not a transcription of that proposition,
and it does not assert irreducibility of any induced representation. Connecting
it to actual compact-fixed families requires additional specialization and
uniform subquotient detection results.
