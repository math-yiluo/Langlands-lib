# Compact test normalization for the continued actual opposite pair

`forwardIntertwiner` and `reverseIntertwiner` are the actual ambient maps in
the continued opposite composite. For each direction their value at one on
a section with compact support on the target radical is given by the scalar
Bochner integrals against every algebraic linear form. The Haar measure is
normalized by the original input compact subgroup.

On the original domain, the intersection of the two radicals is trivial and
has mass one. The trivial-quotient comparison identifies the weak integrals
with the radical Haar integrals. Open-kernel twisting preserves the weak
integral relation. The compact-picture continuation then propagates the
compact test identity to every regular parameter. Applying compact
restriction commutes with evaluation at one and returns the same continued
map.
