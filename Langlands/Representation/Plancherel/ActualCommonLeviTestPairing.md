# The compact test pairings on the two actual integral domains

The forward standard integral is tested against the target test section
at each compact argument. The reverse integral of the dual section is
tested against evaluation on the source test section at that argument.
Each statement uses the smooth scalar test in the defining weak integral
on its own convergence domain.

Radical invariance of the other section identifies each scalar integrand
on quotient representatives with the common test pairing. This pairing
is the finite, nonnegative normalized average in either presentation.
The real nonnegative integral formula gives its Bochner integral as the
real value of the corresponding iterated nonnegative integral. The
compact integral therefore has the exact positive value supplied by the
equality of the two actual quotient test masses.

These evaluations use the ambient Haar measure normalized to give the
Iwasawa subgroup mass one, restricted to that subgroup. The forward
evaluation uses the target Iwasawa factorization. The reverse evaluation
uses both factorizations to identify its mass with the forward value.
The pointwise test identity uses the supplied squared-modulus compatibility.
These calculations are internal tests for Waldspurger's adjunction in IV.1(11).
