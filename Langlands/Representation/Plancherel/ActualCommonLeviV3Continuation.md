# Actual continued pairs from common-Levi continuation existence

`continuedPairOfContinuation` uses the published common-Levi continuation
existence proposition on the displayed actual parabolics and inducing
object. It takes the squared-modulus identity, the nonempty open starting
region, the full-domain inclusion, and the actual compact continuation
supplied by that proposition. The resulting `ContinuedPair` uses the same
standard-integral family and the same quotient measure.

For an admissible irreducible inducing object, the published finite-length
result for irreducible objects applies. Admissibility and finite length pass
to the smooth contragredient by the respective duality theorems using
compact-open cofinality. One can therefore obtain both directions for the
original inducing object and both directions for its smooth dual.

This derived step transfers the actual common-Levi continuation input of
Waldspurger (2003), Theorem IV.1.1, printed p. 278 / PDF p. 44, to the
operators in Lemma V.3.1 and formula (1), printed p. 295 / PDF p. 61
(`waldspurger-2003-plancherel`).
The continuation existence proposition is the premise. Generic
invertibility, scalar composition, and unitary regularity are subsequent
obligations.
