# The standard operator under restriction to an intermediate Levi

This derived operator comparison uses the actual weak standard integral.
`RepresentsStandardIntegral` says that all source vectors have their weak
integrals represented by the evaluations of a specified linear map into the
actual normalized target. The comparisons use the exact pushed-forward
quotient measure inside the intermediate Levi.

Apply the weak-integral restriction theorem for each ambient source vector.
The normalized target restriction has the same evaluation formula as the
source restriction, with the common outer half-character. Thus the
restricted output represents the inner integral of the restricted input.
A linear right inverse of the source restriction therefore gives a full
inner weak-integral operator. Every other full operator at the same
transported measure satisfies the same square, by uniqueness of the
smooth-functional representing vector.
