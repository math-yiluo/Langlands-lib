# Restriction between compact pictures for induction in stages

This derived construction assumes Iwasawa factorizations for the ambient
source and the inner source with the actual intersection of the ambient
compact subgroup and the intermediate Levi. The inner inducing object and
unramified norm characters are transported through the continuous inducing
group isomorphism. The usual compact-picture equivalences identify the
varying source models with their fixed compact spaces.

Conjugating the stages restriction by those equivalences gives a surjective
linear map. Its value at each inner compact point is the input compact
function at the same ambient point, multiplied by the inverse fixed outer
Levi half-character there. This formula proves that the map is independent
of the unramified parameter. A constant linear section of this map can
therefore be used to transport an operator numerator.
