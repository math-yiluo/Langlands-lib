# Exact compact tests of the continued common-Levi operators

The two test sections restrict to fixed vectors in the two actual
compact pictures. This follows from the parameter-independent compact
restriction of each test section. The original compact Haar probability
is the comap of the ambient Haar measure normalized on the Iwasawa
subgroup, so each compact pairing on the integral domain has the same
nonzero value as the ambient test integral.

Pairing against the fixed other test vector is a complex linear map.
The identity theorem for linear images of rational operator families
continues the value from the forward starting region to its regular
locus. Applying the same theorem to the reverse-dual starting region
continues the same value at all parameters where that operator's
presentation is regular. These are the fixed compact tests for the
bilinear adjunction used in Waldspurger's V.3.1.
