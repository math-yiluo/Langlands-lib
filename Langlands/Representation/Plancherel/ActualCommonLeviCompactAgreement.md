# Agreement of actual compact intertwiners

For any regular parameter where both induced representations are irreducible,
two continuations of the same ordered standard intertwining integral agree.
The same comparison applies to the integral on its full weak domain. The
published compact adjunction test gives both operators the same nonzero
matrix coefficient. Schur's lemma makes them proportional, and this
coefficient fixes the proportionality. This lets the argument for
Waldspurger, *La formule de Plancherel pour les groupes p-adiques*, V.2.2 and
V.3.1, work with separately prescribed convergence loci and the same actual
quotient Haar normalization.
