# Uniform fixed levels in the original standard induced Jacquet family

This derived module completes the fixed-space comparison for the original
standard unramified induced family. The same normalized ordinary Jacquet
object is used as for the chosen actual standard constant term.

`standardInducedFixedOrder` is the fixed dimension of the untwisted actual
normalized induction at an ambient compact-open level. At any supplied
standard parabolic basis member, a strict central component element gives
the actual Iwahori contraction. The uniform induced-Jacquet dimension theorem
then bounds the normalized localized Jacquet fixed dimension over every
unramified source twist. The exact normalized-to-ordinary Jacquet equivalence
identifies the corresponding fixed spaces and transports that bound.

For unitary twists, the previously proved finite norm set for this original
standard family also gives a common bound strictly below one on all exponent
norms that are strictly below one. This is a finite supremum, and asserts no
contraction of exponents not already known to contract.

The final conditional assembly takes any family of actual induced coefficient
tensors, a shared standard right-invariance level, and contraction at the
specified point of every nonunitary generalized Jacquet exponent. It derives
induced admissibility and an actual stable pairing. The chosen constant terms
then lie in coefficient spans from the same fixed Jacquet spaces. These spaces
are component-stable and their dimensions have the uniform bound just proved.
Each occurring eigenvalue function is packaged as its actual unit-valued
character, with a uniform power. The finite spectral norm set upgrades strict
contraction to a common gap. The fixed-level coefficient theorem gives the
existing `HasUniformSplitAnnihilators` property for the original chosen
constant terms. In particular, it derives the polynomial degrees and imposes
no tensor-rank assumption. Contraction and shared right invariance remain
explicit intermediate hypotheses; the module does not claim they follow
from square integrability here.

The original source action, rational norm family, literal subgroups, specified
component and independent field and representation-carrier universes remain
unchanged. No positive-decay conclusion is claimed.

The contextual source is Waldspurger, *La formule de Plancherel pour les
groupes p-adiques, d'après Harish-Chandra* (2003), I.3 and the proofs of
VI.2.1 and VI.2.3, printed pp.243 and 297–300, source
`waldspurger-2003-plancherel`. The proof combines actual standard contraction,
compact-trivial induced fixed-space comparison, Jacquet quotient surjectivity,
the exact ordinary quotient equivalence and the finite spectral norm set.
