# Actual standard Jacquet exponent bounds along a specified strict ray

`HasStandardJacquetExponentNormBoundAt` specifies a bound at a given
component point for all generalized exponents of the ordinary normalized
standard Jacquet action. For an admissible representation the theorem
supplies the bound `1` on the strict component lattice chamber, under
original-coefficient Xi bounds and a polynomial ray upper bound for that Xi.

First the given standard compact-open basis supplies cofinally small
Iwahori contractions for that same specified point, rather than only the
previously chosen strict point. The unchanged standard component map is
central in the actual standard Levi. The existing normalized Jacquet
eigen-coefficient theorem consequently produces a nonzero exact matrix
coefficient with exponential factor `δ(a)^(1/2) χ(a)`. The equivalence with
the ordinary normalized coinvariant action retains the actual Jacquet
module used by the chosen constant term.

The supplied Xi bound and ray estimate bound that exact coefficient by
`C δ(a)^(n/2) (1+n)^d`. The existing comparison of exponential and
polynomial growth gives `|δ(a)^(1/2) χ(a)| ≤ δ(a)^(1/2)`. The half-modulus
is nonzero, so cancellation yields the claimed norm bound.

The contextual source is Waldspurger, *La formule de Plancherel pour les
groupes p-adiques, d'après Harish-Chandra* (2003), Proposition III.2.2,
printed pp.265–266, and its use in VI.2.3, printed pp.299–300, source
`waldspurger-2003-plancherel`. This actual-point specialization is derived
project content. The coefficient Xi bound and Xi ray upper bound remain
explicit intermediate inputs, and this module does not assert that the
original decay task is complete.
