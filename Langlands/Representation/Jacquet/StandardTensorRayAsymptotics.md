# A fixed-dimensional ray threshold for the original chosen tensor constant term

This derived module applies the explicit fixed-dimensional ray threshold to
arbitrary original coefficient tensors that share a compact-open group of
bi-invariance. It asserts a formula along one specified strict component ray;
it does not assert the full closed-chamber threshold target.

Compact averaging on the actual smooth-dual tensor factor is identified with
averaging for the second coordinate of the actual product action, by naturality
on pure tensors and linearity. The corresponding source-factor identity is
already proved. If the original coefficient function is bi-invariant, both
averages preserve that exact function. Equality is proved pointwise by applying
evaluation to the finite orbit mean. This argument needs neither a bound on
tensor rank nor a choice of pure-tensor expansion fixed across parameters.

Every pure summand of the doubly averaged tensor has source and smooth-dual
vectors fixed at the same level. The stable-pairing ray formula therefore
holds for it from any upper bound on the source fixed-space dimension.
Tensor induction proves the same formula for the entire averaged tensor.
For actual standard parabolics, choose the existing actual stable pairing,
use the exact tensor constant-term equality, and then the unchanged original
coefficient function. The ray is the powers of the original compatible
component's `centralStrictElement`; the half modulus is the original
`standardHalfModulus`. All structural, admissibility, good-level and dimension
conditions are explicit.

The contextual original source is Waldspurger, *La formule de Plancherel pour
les groupes p-adiques, d'après Harish-Chandra* (2003), Proposition I.4.3,
printed p.245, and its application to induced coefficients in VI.2.3,
printed pp.299–300, source `waldspurger-2003-plancherel`. The averaging and
explicit dimension bound are derived project content.
