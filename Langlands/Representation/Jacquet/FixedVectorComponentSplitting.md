# Fixed-vector splitting from actual component coproducts

Author: Worker 146. This is an internal categorical adapter for the splitting
used in Renard VI.10.6(iii). It does not prove the Bernstein decomposition or
the fixed-level comparison for its blocks.

For any actual coproduct cofan of smooth complex representations,
`fixedVectorComponentProjector` constructs an endomorphism by coproduct
descent: it is the identity on fixed-vector-generated components and zero
on the others. Assume now that each component is generated by its fixed
vectors or has zero fixed vectors. `fixedVectorSplitting_of_cofan` proves
that the endomorphism is idempotent, its actual range is generated by fixed
vectors, and its actual kernel has zero fixed vectors. Their sum is the
whole representation.

The range argument expresses every vector as a finite sum of component
vectors using the existing `cofanDirectSumMap_surjective`. Each generated
component maps into any invariant subspace of the range containing its
fixed vectors; every other component maps to zero. The kernel argument
uses the existing equivalence between the actual coproduct carrier and
the algebraic direct sum, together with the equivalence for fixed vectors
of that direct sum. Every fixed vector is a finite sum of fixed component
vectors. The endomorphism fixes each of these, since the components on
which it is zero have no fixed vectors. A fixed vector in its kernel
therefore vanishes.

`fixedVectorSplitting_of_components` applies this argument to every
coproduct supplied by `Renard.EveryObjectIsCoproductOfComponents`. Its
component dichotomy remains an explicit hypothesis. Only the coproduct
part of a category decomposition is needed. The group, carrier and index
universes are independent, and no finiteness, admissibility or compactness
condition is added. The subgroup is open, as in the existing splitting
interface.

The provenance is internal: the proof uses the published actual smooth
coproduct comparison, componentwise fixed-vector sum equivalence and
fixed-vector generation criterion. It supplies the assembly step of the
retained splitting specialization, while the actual Bernstein
decomposition and its fixed-level block dichotomy remain separate
representation-theoretic obligations.
