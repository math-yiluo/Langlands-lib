# Full unitary induced Jacquet exponent norms on literal point subgroups

This derived module transports the finite spectral-norm result for actual
represented parabolics to their literal point-image induction and Jacquet
functors, preserving the original source action and component point group.

Pull a smooth literal Levi action through the canonical Levi point
homeomorphism. Twisting by an actual rational unramified character on the scheme
then inducing is equivalent to twisting the original action by the transported
character and inducing from the original literal subgroup. The equivalence is
induced by the identity on the original carrier; the inverse point maps cancel.

Applying the actual Jacquet functor and restricting through the exact component
point map gives an equivalence with the represented Jacquet-induction family.
The canonical point homeomorphism carries the component scheme map to the
literal split-component point map. Thus generalized eigencharacters and their
values at the chosen unchanged component point agree.

For an irreducible admissible literal source action, its pullback is admissible
and has finite length. The full represented finite-norm theorem applies. Every
unitary unramified character of the transported literal norm family is the image
of a unitary scheme character under the actual unramified-character
homeomorphism. The same finite set therefore contains every literal-family
exponent norm, over the whole unitary parameter space. The field and carrier
universes remain independent.

This supports the actual exponent polynomials in Waldspurger VI.2.1 and VI.2.3,
printed pp.297–300 of *La formule de Plancherel pour les groupes p-adiques,
d'après Harish-Chandra* (2003), source `waldspurger-2003-plancherel`. The proof
composes canonical point transport, normalized induction equivalence, Jacquet
functoriality, exact component inclusion, and the full geometric-lemma
finite-norm theorem. It proves no coefficient bound or positive-decay estimate.
