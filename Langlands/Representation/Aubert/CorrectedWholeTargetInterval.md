# Actual support activity and the whole-target interval

Author: Worker 194.

This internal bridge connects the actual corrected singleton support quotient
to the whole-target Boolean interval. It uses the existing inversion-length
minimality criterion, the whole-target Weyl intersection characterization, and
the actual inactive and proper-target vanishing results. It introduces no new
representation-theoretic premise.

On a full inversion-length tail containing the removed permutation, membership
of that permutation in the corrected two-sided core is equivalent to the
increasing-block minimal-representative condition. This follows by composing
the existing singleton-drop criterion with the equivalence between a changed
core and membership of the removed point. The actual upper-support hypotheses
supply the full-tail assumptions: if a remaining point had smaller length,
upper closure after the removal would put the removed point back in the lower
support, a contradiction; upper closure of the upper support supplies every
point of strictly larger length.

Inversion exchanges the source and target increasing-block conditions.
Applying the existing whole-target interval theorem to the inverse
permutation therefore identifies actual core membership together with the
whole target Weyl intersection with three conditions: the inverse is
increasing on target blocks, it sends each uncut target edge to an adjacent
increasing edge, and the source cuts lie between the permutation's descents
and the allowed cuts of its inverse. Under the two fixed inverse-permutation
conditions, this is exactly Boolean interval membership.

If this conjunction fails, an inactive singleton step has zero actual quotient.
In an active step the length-tail criterion supplies the actual source
increasing condition. A whole target intersection would force the conjunction,
so the target intersection is proper. The target Jacquet block bound and the
existing actual graded orbit isomorphism then make the quotient subsingleton.
In particular, every cut set outside the Boolean interval gives zero, whether
or not the fixed inverse-permutation conditions have been assumed. The
canonical zero-module equivalence records the same conclusion linearly.

All group actions, normalized functors, support images, and quotient maps are
those of the existing actual construction. The representation carrier is
saturated as required by the block bound; the field and representation
universes remain independent. No positive rank assumption is used. This unit
does not itself assemble the signed diagram or assert exactness at its
surviving terminal homology.
