# Separating full-Hecke quotients from compact-open corners

Author: Worker 138. Namespace `Langlands.Renard.Smooth`.

This derived construction unit gives the actual full-Hecke action on a quotient of its unitization and proves that a nonnilpotent compact-open corner element has a separating, nondegenerate, additively simple quotient. It is an intermediate step toward Renard III.1.11, and does not yet assert the existence of the separating smooth representation or prove `HeckeCompletenessStatement`.

The governing source is David Renard, *Représentations des groupes réductifs p-adiques*, French version dated 9 July 2026, III.1.11, printed pp.64–65 / PDF pp.70–71, together with Appendix B.III, printed p.273 / PDF p.279; registered as `renard-2026-representations-groupes-reductifs-padiques`, SHA256 `7b539996793b7c3620e72e1e389588eb42d1a8e91d6f68b2eead5c2e2ffc182c`. The unitization compression argument is internal derived content replacing the printed proof's use of countability of the whole Hecke algebra. Only the fixed corner needs countable dimension here.

`cornerUnitizationInclusion` composes the faithful actual corner inclusion with the canonical map into the full Hecke algebra's unitization. Write this map as `j`, and put `e = j 1`. `cornerUnitizationCompression b` is the actual corner element `b.fst • 1 + project b.snd`, whose image is `e b e` by `cornerUnitizationCompression_eq`. The identity follows from the unitization multiplication formulas and the actual normalized indicator's idempotence.

If `c` has no left inverse in the corner, `corner_no_leftInverse_unitization` proves that `x = j c + (1-e)` has no left inverse in the full unitization. A purported inverse `b x = 1`, compressed on both sides by `e`, would give a left inverse to `c` in the corner. The proof uses the explicit compression, preserving the actual corner and unitized elements.

For `exists_separating_unitization_quotient`, apply the published `nonnilpotentLeftResolvent` to the countable-dimensional corner to obtain a nonzero `z` with no left inverse for `c = f-z·1`. The previous argument gives a non-left-invertible `x` in the full unitization. Apply the published `leftShiftSimpleQuotient` to the element `x+1` with scalar shift `1`; this yields a simple quotient by a maximal left ideal containing `x`. In that quotient write `v = [1]`. It is nonzero. Since `(1-e)x = 1-e`, the equation `x v = 0` forces `e v = v`. Substituting `c = f-z·1` then gives `j f v = z v`. Thus the same actual quotient separates `f`.

`separatingQuotientAction μ I` is precisely the original Hecke action obtained by restricting the canonical unitization quotient action, using `Unitization.lift.symm` on `Algebra.lsmul`. In `exists_separating_nondegenerate_quotient`, the nonzero eigenvalue proves this original action is nonzero. The published `unitizationQuotient_module_eq` identifies its reconstructed unitized module with the canonical quotient module. The published `simpleUnitizationRestriction` proves simplicity for every stable additive subgroup, rather than just stable complex subspaces. The published original orbit-surjectivity theorem writes every vector as `a v`. A compact-open normalized indicator which is a left local unit for `a` then fixes this vector. This proves original-action nondegeneracy.

The final result retains the actual unitization quotient carrier in the group's universe, the original action, its nonzero value on the corner element, additive simplicity and nondegeneracy. The scalar structures used before reconstruction are the quotient's inherited complex scalars. No small realization or smooth action is claimed here; those are subsequent steps. No countability assumption on the full Hecke algebra is used.
