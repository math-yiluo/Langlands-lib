# Fixed-level finiteness of compact-coefficient classes from a corner sandwich structure

This module carries out Bernstein--Zelevinsky (1976), 4.16, page 41, for an
arbitrary topological group. It uses the facts from 2.10 and 2.40 that 4.16
relies on. Throughout, `G` is a topological group with Borel measurable
structure and a left Haar measure `μ` (`μ.IsHaarMeasure`). `N` is an open
subgroup of `G` with compact underlying set (`hN`). `ρ` is a smooth complex
representation. Only left invariance of `μ` is used: the module needs neither
unimodularity nor right invariance, and it does not use Schur's lemma.

## Inputs from `FixedVectorsFiniteDimensional`

The inverse coefficients, the averages `dualAverage` over `N`, the extension
`fixedExtension` and `finiteDimensional_fixedVectors` (BZ 2.40/2.41) are in the
module `Langlands.Representation.CompactCoefficient.FixedVectorsFiniteDimensional`,
which this module imports.

## Simplicity over the corner (BZ 2.10)

- `exists_cornerAction_eq_fixedProjection`: for a fixed vector `w`, the vector
  `P_N (ρ g w)` equals the action of the corner element
  `Corner.project (leftTranslate g e_N)` on `w`.
- `isSimpleModule_fixedVectors`: for irreducible `ρ` with a nonzero `N`-fixed
  vector, the fixed space is a simple module over
  `HeckeAlgebra.Corner μ N hN` (module structure `cornerModule`).
  - The proof uses `isSimpleModule_iff_toSpanSingleton_surjective`.
  - For nonzero `w`, the preimage under `P_N` of the corner orbit of `w`
    contains the `G`-orbit of `w`, hence it is everything.
  - Since `P_N v = v` for fixed `v`, every fixed `v` is in the corner orbit.

## An invariant Hermitian form

Fix a smooth dual vector `ℓ` of a representation with compact smooth-dual
coefficients.

- `invariantForm μ ρ hρ hc ℓ hℓ y` is the functional
  `x ↦ ⟨x, y⟩ = ∫ ℓ (ρ g⁻¹ x) * conj (ℓ (ρ g⁻¹ y)) dμ(g)`. The integrand is
  continuous with compact support.
- `invariantForm_rho`: the form satisfies `⟨ρ h x, ρ h y⟩ = ⟨x, y⟩`, by left
  invariance.
- `invariantForm_conj`: the form is Hermitian.
- `invariantForm_self_ne_zero`: `⟨v, v⟩ ≠ 0` when `ℓ v ≠ 0`. The proof uses
  `integral_mul_conj_ne_zero`: a nonzero continuous compactly supported `φ` has
  `∫ φ * conj φ ≠ 0`, by positivity of Haar measure on open sets
  (`Continuous.integral_pos_of_hasCompactSupport_nonneg_nonzero`).
- `isSmoothVector_dual_of_invariant`: an `N`-invariant functional is a smooth
  dual vector.

## Separating corner elements (BZ 4.16)

`exists_separating_corner_element μ N hN D hD` takes an irreducible
compact-coefficient representative `D` with a nonzero `N`-fixed vector. It
produces `f : HeckeAlgebra.Corner μ N hN` whose action on the `N`-fixed vectors
of `D` is nonzero and whose action on those of every `E` with
`ofRep D ≠ ofRep E` is zero.

1. Choose a fixed `v₀ ≠ 0` and a functional `ℓ₀` with `ℓ₀ v₀ ≠ 0`
   (`Module.forall_dual_apply_eq_zero_iff`). Let `ℓ` be its average over `N`;
   then `ℓ v₀ = ℓ₀ v₀ ≠ 0`.
2. Let `Λ = ⟨·, v₀⟩`. It is `N`-invariant by invariance of the form, since
   `v₀` is fixed.
3. Let `φ = inverseCoefficient Λ v₀`, so `φ g = ⟨ρ g⁻¹ v₀, v₀⟩`. It is
   bi-`N`-invariant and defines the corner element `f`.
4. **Nonzero on `D`.** If `f` acted as zero on `v₀`, then by
   `integratedAction_dual`, `0 = Λ (ρ(φ) v₀) = ∫ φ g * Λ (ρ g v₀)`. Since
   `Λ (ρ g v₀) = conj (φ g)`, this is `∫ φ * conj φ`. That integral is nonzero
   because `φ 1 = ⟨v₀, v₀⟩ ≠ 0`.
5. **Zero on `E`.** For a fixed vector `w` of `E`, the map
   `S v = σ(inverseCoefficient Λ v) w` is an intertwiner from `D` to `E`, by
   `inverseCoefficient_apply_rho` and `integratedAction_leftTranslate`. By
   `intertwiningMap_eq_zero_of_ne`, `S = 0`, so `σ(φ) w = S v₀ = 0`.

## Finiteness of the fixed-level stratum

- `adjoin_range_append_eq_top`: if `H` is spanned by products `x i * m * x j`,
  with `m` in the subalgebra generated by the `a k`, then
  `Fin.append x a` generates `H` as an algebra.
- `fixedStratum_finite_of_sandwich μ N hN hB x a ha hspan` concludes that
  `fixedStratum N.toSubgroup` is finite. Its hypotheses are
  `hB : SandwichSimpleModuleDimensionBoundStatement.{uG, uV}` and a sandwich
  structure `x, a, ha, hspan` of the corner `H_N`.
  1. For each class `c`, use the representative `c.out`.
  2. For `c` in the stratum, the `N`-fixed space is a simple module
     (`isSimpleModule_fixedVectors`) and finite-dimensional
     (`finiteDimensional_fixedVectors`), with the scalar tower
     `cornerModule_isScalarTower`. `hB` then bounds its dimension by
     `q ^ (2 ^ l)`.
  3. Fix one dimension `s`. Choosing bases (`Module.finBasisOfFinrankEq`) turns
     the corner actions into matrix representations
     `LinearMap.toMatrixAlgEquiv ∘ cornerAction` of size `s`.
  4. The separating elements make this family separated, so
     `finite_of_separated_matrixRepresentations` gives finiteness for that `s`.
  5. The stratum is the union of these finite sets over `s ≤ q ^ (2 ^ l)`.
