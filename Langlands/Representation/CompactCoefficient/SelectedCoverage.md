# Selected-type detection from the common annihilator

`classesOfFiniteFamily` takes the image of a finite index set in the quotient of irreducible compact-coefficient representations by isomorphism. It removes repeated classes. Its membership lemma identifies membership with the existence of an index in the original family.

This internal algebraic lemma proves type coverage conditional on disjointness from the selected common annihilator. If an irreducible smooth representation embeds into an ambient representation with range disjoint from that annihilator, choose a nonzero source vector. Its image cannot be in the annihilator. Thus an outgoing intertwiner to some representative of a selected class is nonzero on the image. Its composite with the embedding is a nonzero map between irreducible representations; Schur's elementary injective/surjective alternative makes it an equivalence. The second lemma applies this result to the composite of two actual subrepresentation inclusions.

The argument was suggested by Worker 276 and implemented by Worker 319, using the published intrinsic-annihilator and irreducibility APIs. It requires no admissibility, retraction, finite-dimensionality or semisimplicity. Selection is a finite set of compact-coefficient classes, with independent representative and ambient universes. The general output is equivalence to a representative of a selected class. For the classes of a supplied finite family, the last lemma returns an index in that original family, using the class equality to transport the equivalence. Repeated equivalent members of the family cause no problem. Analytic complementarity, selection construction, semisimplicity and the final block-isolation theorem remain separate obligations.
