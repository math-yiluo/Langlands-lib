# Whittaker multiplicity at most one

Author: Worker 350.

`Langlands.Whittaker.MultiplicityOneStatement.{uF,uV}` is an unproved
Prop-valued statement. It asserts that, for an irreducible admissible complex
representation of `GL_(n+1)(F)`, every standard Whittaker functional is a
unique complex scalar multiple of any specified nonzero such functional:

```text
∀ ℓ₁ ℓ₂ : glFunctionals ψ n π, ℓ₁.val ≠ 0 →
  ∃! c : ℂ, ℓ₂ = c • ℓ₁.
```

The equality and scalar action are in the existing functional submodule.
Its subtype inclusion identifies this equality with equality of the underlying
complex linear forms. The condition `ℓ₁.val ≠ 0` is exactly nonvanishing of
the first linear form.

The statement quantifies over every prime `p`, its `Fact p.Prime` witness,
every finite extension `F : PadicField.{uF} p`, and every natural number `n`.
It installs `F.canonicalNormedField`, so the character and admissibility use
the canonical p-adic field topology and the induced matrix-group topology.
The carrier `V : Type uV` has only `AddCommGroup` and `Module ℂ` structures;
the field and carrier universes are independent. There is no topology or
finite-dimensionality assumption on `V`. `IsAdmissible π` includes smoothness
and finite-dimensional fixed-vector spaces for open subgroups; the only other
representation hypothesis is `Representation.IsIrreducible π`.

`HarmonicAnalysis.UnitaryAdditiveCharacter` already bundles continuity,
nontriviality and unit-circle values. The imported `glFunctionals ψ n π`
uses the actual upper-unipotent subgroup and the existing standard character
`ψ(∑ i, u[i,i+1])`. Additivity makes this the product of the values on the
first-superdiagonal entries. No subgroup, character, functional space, or
prerequisite statement is redefined.

The source is H. Jacquet, I. I. Piatetski-Shapiro and J. A. Shalika,
*Rankin–Selberg Convolutions*, American Journal of Mathematics 105 (1983),
367–464, Section 2.1, printed p.385 (PDF page 20). Equation (1) defines the
linear forms with this unipotent equivariance. The paragraph after equation
(2) recalls, with attribution to Gelfand–Kazhdan, that for every positive
rank and irreducible representation their space has dimension zero or one.
Section 0.3, printed pp.375–377, supplies the matrix group, upper-unipotent
subgroup, and standard-character conventions. These pages were read directly
from registered source `jpss-1983-rankin-selberg`, SHA256
`d9feed6388ca5acf02ecc6a8cce984871a7c28f062ff441e45a71fa2d8962245`.
No source-specific errata note was found in the project or published notes.

This formulation specializes the source's nonarchimedean local field to a
finite extension of the p-adic numbers. In Section 2.1 the source initially
works with admissible representations of finite type on a nonzero space.
Irreducibility supplies those qualifications: an irreducible representation
is nonzero and is generated by any nonzero vector. The source separately
assumes dimension one in equation (2) to define representations of Whittaker
type. That assumption is not used here: the target is the recalled
dimension-zero-or-one conclusion for irreducible admissible representations.

The scalar statement expresses multiplicity **at most** one. If the
functional space is zero, no `ℓ₁` satisfies the premise, so the assertion is
vacuous. If `ℓ₁` is nonzero, dimension at most one says it spans the space;
its nonvanishing makes the scalar unique. Conversely, the stated spanning
property forces a nonzero functional space to be one-dimensional. This is
the mathematical explanation of the formulation, not an implemented proof
of a dimension equivalence or of multiplicity one. No nonzero functional
is asserted to exist, and genericity is not assumed.

Positive rank is `n + 1`, including rank one when `n = 0`. The imported
`glFunctionals_rankOne` identifies the rank-one functional space with the
whole algebraic dual because the unipotent group is trivial. The same
multiplicity assertion is retained in this case. The module only defines
the target proposition; its proof remains a separate obligation.
