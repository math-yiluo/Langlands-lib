# Proof: the Weyl group of a finite crystallographic root pairing is a Coxeter group

Module `Langlands.Group.RootPairingCoxeterProof`. It proves the published statement
`Langlands.Group.RootPairingWeylCoxeterStatement` (module
`Langlands.Group.RootPairingCoxeterStatement`):

```lean
theorem rootPairingWeylCoxeterStatement_proof :
    RootPairingWeylCoxeterStatement.{u₁, u₂, u₃, u₄}
```

for arbitrary universes `u₁ u₂ u₃ u₄`. The theorem's type is the statement itself. The module
contains only that public theorem; all its lemmas are private.

## Supporting modules

- `Langlands.Group.CoxeterOfExchange` provides `exists_coxeterSystem_of_exchange`. Let `s` be an
  injective family of involutions generating a group `W`, and let `N : W → ℕ` satisfy
  `N 1 = 0`, `N (w * s b) = N w ± 1` and the right exchange property. Then `W` has a Coxeter
  system with simple reflections `s` and length `N`. See its Markdown.
- `Langlands.Group.RootPairingWeylGeneration` provides `exists_list_prod_ofIdx_baseOf`: every
  element of `P.weylGroup` is a product of reflections in simple roots. See its Markdown.

## Setting and notation

`P : RootPairing ι R M N` is a root pairing over a linearly ordered field, with `ι` finite and
`P` crystallographic. The form `f : Module.Dual R M` is nonzero on every root. The simple roots
are `Δ = IsAddIndecomposable.baseOf P.root f`, the `f`-positive roots that are not sums of two
`f`-positive roots. For `b ∈ Δ`, `sr P f b` is the simple reflection
`RootPairing.weylGroup.ofIdx P b`. A root `α_i` is *indivisible* (`Indiv P i`) if
`n • α_j ≠ α_i` for every `n ≥ 2` and every root index `j`. The inversion set of `w` is

`invSet P f w = {i | 0 < f α_i ∧ α_i indivisible ∧ f (w • α_i) < 0}`,

which is exactly the set counted in clause 3 of the statement. The length used throughout is
`N w := (invSet P f w).ncard`.

## Proof as implemented

1. **Weyl group basics.** Elements of `P.weylGroup` are equal if they act equally on `M`
   (`weyl_ext`, via `RootPairing.Equiv.weightHom_injective`), and `ofIdx P i` acts as
   `P.reflection i`. Hence `ofIdx_mul_self` holds, and `conj_ofIdx` gives
   `u * s_i * u⁻¹ = s_{u i}` (via `RootPairing.Equiv.weightEquiv_reflection`).
   Proportional roots give the same reflection (`ofIdx_eq_of_root_eq_smul`, via
   `RootPairing.smul_coroot_eq_of_root_eq_smul`).
2. **Coefficient lemma** (`eq_nsmul_of_add_eq_smul`). Every `f`-positive root lies in the
   additive monoid generated by the simple roots (Mathlib's
   `AddSubmonoid.closure_image_isAddIndecomposable_baseOf`). Simple roots are linearly
   independent (`RootPairing.linearIndepOn_root_baseOf'`). Comparing ℕ-coefficients therefore
   shows: if `x + y = t • α_a` with `x` and `y` in that monoid and `a ∈ Δ`, then `x = n • α_a`
   for some `n : ℕ`.
3. **Consequences.**
   - If `a ∈ Δ`, `f α_i > 0` and `f (s_a α_i) < 0`, then `α_i = n • α_a`
     (`eq_nsmul_of_reflection_neg`). This uses `α_i + (-s_a α_i) = ⟨α_i, α_a^∨⟩ • α_a`.
   - Simple roots are indivisible (`indiv_of_mem_base`).
   - Indivisibility is preserved by reflections (`indiv_reflectionPerm`).
   - An indivisible `α_i = n • α_a` forces `i = a` (`eq_of_indiv_of_eq_nsmul`).
   - Distinct simple roots have distinct reflections (`ofIdx_injOn_base`). If `s_a = s_b`,
     then `α_a + α_a = ⟨α_a, α_b^∨⟩ • α_b`, so `α_a` is a multiple of `α_b`.
4. **Length changes by one** (`invSet_mul_sdiff`, `ncard_invSet_mul`). For `a ∈ Δ`,
   `s_a` permutes the indivisible positive roots other than `α_a` (`pos_reflectionPerm`).
   So `invSet (w * s_a) \ {a}` is the preimage of `invSet w \ {a}` under the
   permutation `reflectionPerm a`. Moreover `a` lies in exactly one of `invSet (w * s_a)`
   and `invSet w`, according to the sign of `f (w • α_a)`, which is nonzero. Hence
   `N (w * s_a) = N w + 1` when `f (w • α_a) > 0`, and `N (w * s_a) + 1 = N w` when
   `f (w • α_a) < 0`.
5. **Exchange** (`exchange`). If `f (π x • α_b) < 0` for a word `x` of simple roots, then
   `π x * s_b = π (x.eraseIdx k)` for some `k`. The proof is by induction on `x = c :: x'`.
   If `f (π x' • α_b) < 0`, use the induction hypothesis. Otherwise `π x' • α_b` is a positive
   root sent to a negative one by `s_c`, so it is a multiple of `α_c` by step 3. By steps 1
   and 3, `π x' * s_b = s_c * π x'`, and the first letter is deleted. In `main_of_generates`
   this applies because `N (π x * s_b) < N (π x)` forces `f (π x • α_b) < 0` by step 4.
6. **Coxeter system.** `exists_coxeterSystem_of_exchange` is applied to `s = sr P f` and `N`.
   Its hypotheses come from steps 1 and 3–5, from `N 1 = 0`, and from generation
   (`exists_list_prod_ofIdx_baseOf`). This gives `Mx` and `cs` with `cs.simple b = s_b`
   (clause 2) and `cs.length w = N w` (clause 3).
7. **Finiteness** (clause 1). `N w ≤ Nat.card ι`, so every element is the product of a
   `cs`-reduced word of length at most `Nat.card ι`. There are finitely many such words over
   the finite type `Δ` (`List.finite_length_le`).
8. **Descent** (clause 4). By step 4, `cs.length (w * cs.simple b)` exceeds `cs.length w`
   exactly when `f (w • α_b) > 0`.

`main_of_generates` carries out steps 1–8 with generation as a hypothesis, and the public
theorem supplies it from `RootPairingWeylGeneration`.

## Scope

The statement's generality is kept throughout. Nonreduced pairings are handled by counting only
indivisible roots: step 4 needs indivisibility to make `s_a` permute the counted roots, and
step 3 shows simple roots are indivisible. If there are no roots, `Δ` is empty and the argument
needs no special case. Spanning is never used: the
coefficient lemma only needs linear independence of the simple roots, not a basis of `M`.

## Literature

The route follows the classical proof cited by the task: Bourbaki, *Groupes et algèbres de
Lie*, Ch. VI §1.5 Thm. 2 and §1.6–1.7. There the length equals the number of inverted positive
roots, and the exchange property comes from roots. Bourbaki is not in the project literature,
and these locators are taken from the task, not checked. Springer, *Linear Algebraic Groups*
(2nd ed., 1998), 8.2.8 (pp. 140–141) and 8.3.1–8.3.2 (p. 142), treats the reduced case:
there the length is the number of positive roots made negative, and it changes by ±1 under a
simple reflection according to the sign of
`w • α`. The formal route differs in two ways. The Coxeter presentation is obtained from the
exchange property via Matsumoto's argument (`CoxeterOfExchange`). The length function is the
inversion count from the start, so it is never compared with a separately defined word
length.
