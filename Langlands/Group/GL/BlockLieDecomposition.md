# Block matrix decomposition for Lie differentiation

Let the lower block part of a matrix retain exactly the entries in a
strictly lower block. Subtract its conjugate transpose from it to obtain
a skew-adjoint matrix with the same lower block entries. Subtract the
block diagonal and this skew-adjoint matrix from the original matrix.
The entries that remain lie in the strictly upper blocks.

This is an internal matrix decomposition for the derivative of a
constant-term section at a standard compact argument. It singles out
the block Lie directions, the strict upper block directions, and the
directions of the standard compact at the archimedean places.
