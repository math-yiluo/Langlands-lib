# Finite generation of dominant zero-sum exponent tuples

This module proves an elementary combinatorial fact. Under addition, the
antitone integer tuples `lam : Fin m → ℤ` with `∑ i, lam i = 0` are generated
by finitely many of them. In the proof of
Bernstein--Zelevinsky (1976), Lemma 4.9, page 39, this fact gives the finitely
many commuting generators of the dominant part of a block torus of `G°`. BZ76
states finite generation of the relevant monoid without proof; the argument
here is our own.

## Declarations

- `zeroSumDominant m`: the set of antitone `lam : Fin m → ℤ` with
  `∑ i, lam i = 0`.
- `dominantGenerators m`: the members of `zeroSumDominant m` whose entries all
  satisfy `|lam i| ≤ m ^ 2`.
  - `dominantGenerators_subset`: it is contained in `zeroSumDominant m`.
  - `dominantGenerators_finite`: it is finite, because it lies in the finite
    box `∏ i, [-m², m²]`.
- `dominantStep k` for `k : Fin n`: the tuple in `Fin (n + 1) → ℤ` equal to
  `n - k` at indices `≤ k` and to `-(k + 1)` after them.
  - `dominantStep_antitone`, `dominantStep_sum`: it is antitone with sum zero.
    The sum is `(k + 1)(n + 1) - (n + 1)(k + 1) = 0`.
  - `dominantStep_mem`: it belongs to `dominantGenerators (n + 1)`.
- `sub_le_of_gaps`: if every consecutive gap `lam k - lam (k + 1)` is at most
  `n`, then `lam 0 - lam j ≤ j · n`. The proof is induction on `j`.
- `zero_le_apply_zero`, `apply_last_nonpos`: a zero-sum antitone tuple has
  `lam 0 ≥ 0` and `lam (last) ≤ 0`, by comparing the sum with `(n + 1)` times
  the first or last entry.
- `mem_closure_dominantGenerators_succ d lam`: if `lam ∈ zeroSumDominant (n + 1)`
  has spread `lam 0 - lam (last) ≤ d`, then `lam` lies in the additive
  submonoid generated by `dominantGenerators (n + 1)`.
- `mem_closure_dominantGenerators`: every `lam ∈ zeroSumDominant m` lies in
  `AddSubmonoid.closure (dominantGenerators m)`. For `m = 0` the tuple is `0`.
  For `m = n + 1`, apply the previous lemma with `d` the spread.

## Proof of `mem_closure_dominantGenerators_succ`

Strong induction on `d`.

1. Suppose some gap `lam k - lam (k + 1)` is at least `n + 1`. Then
   `lam - dominantStep k` is still antitone, because the only drop of
   `dominantStep k` is `n + 1`, between `k` and `k + 1`. It still has sum zero.
   Its spread is the spread of `lam` minus `n + 1`, which is positive. By
   induction it lies in the closure, and `lam` is that tuple plus the generator
   `dominantStep k`.
2. Otherwise every gap is at most `n`. Then `sub_le_of_gaps` bounds the spread
   by `n · n ≤ (n + 1)²`. Every entry lies between `lam (last) ≤ 0` and
   `lam 0 ≥ 0`, so `|lam j|` is at most the spread. Hence `lam` itself is a
   generator.
