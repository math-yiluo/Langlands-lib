# A smooth chart of the actual Bruhat cell

At an actual cell point, start with the straightened chart for the chosen nonzero normal matrix. Restrict the source to an open neighborhood in which the matrix image lies in the prescribed ambient neighborhood and the actual cell agrees with the zero normal slice. The forward map and the inverse retain their smoothness on the new domains. The last-coordinate derivative is unchanged.

The resulting chart packages the geometry used for the local vanishing step of Shalika's Proposition 2.10.
