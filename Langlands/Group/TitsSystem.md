# Tits systems on actual subgroups

This module defines the Tits-system (BN-pair) predicate `Langlands.Group.IsTitsSystem`
for subgroups `B` and `N` of an arbitrary group `G`. It also defines the Bruhat cells
and the standard parabolic subsets that the axioms and their consumers use. The module
imports only Mathlib. It is the shared interface for the actual reductive-group
realization (`Langlands.GroupScheme.Rational.RelativeTitsSystemStatement`), for the
comparison with standard parabolic subgroups and for the abstract Bruhat theory
written elsewhere. No theorem about Tits systems is assumed or proved here beyond the
elementary consequences listed below.

## The Weyl group as data

Classically the Weyl group of a Tits system is the quotient `N / (B ∩ N)`. Here it is
an arbitrary group `W` with a homomorphism `π : N →* W`, where `N` is viewed as a group
through its subgroup coercion. The first two fields require that `π` is surjective and
that its kernel is `B ⊓ N`, seen as a subgroup of `N` (`B.subgroupOf N`). So `π`
identifies `W` with `N / (B ∩ N)`. These two fields also contain the classical axiom
that `B ∩ N` is normal in `N`, because a kernel is normal. Taking `π` as data lets a
consumer use a concrete Weyl group literally. For example, the reductive
realization uses the published quotient
`relativeWeylGroup i = normalizerPoints i ⧸ centralizerPoints i` and its quotient map,
so the target does not mention an abstract copy of `N(k)/Z(k)`.

## Definitions

- `TitsSystem.cell B π w` is the Bruhat cell `B w B`, written in terms of
  representatives. It is the set of products `b * n * b'` with `b, b' ∈ B` and `n ∈ N`
  such that `π n = w`. This makes sense for every `π`. When `ker π ≤ B ⊓ N`, it is the
  double coset `B n B` of any single representative `n` (lemma `mem_cell_iff`).
- `TitsSystem.standardParabolic B π X` is the subset `B W_X B` of `G`, where `W_X` is
  the subgroup of `W` generated by `X ⊆ W`. It is the union of the cells of the
  elements of `W_X`. It is defined as a set. For a Tits system with `X ⊆ S` it is a
  subgroup, but proving that belongs to the abstract theory, so it is not assumed here.
- `IsTitsSystem B N π S` is a structure with the following fields.
  - `surjective`: `π` is surjective.
  - `ker_eq`: `π.ker = B.subgroupOf N`, so `ker π` is `B ∩ N`.
  - `sup_eq`: `B ⊔ N = ⊤`, so `B` and `N` generate `G`.
  - `closure_eq`: `Subgroup.closure S = ⊤`, so `S` generates `W`.
  - `ne_one`, `mul_self`: every `s ∈ S` satisfies `s ≠ 1` and `s * s = 1`, so it has
    order exactly `2`.
  - `mul_mem_cell` (Bruhat multiplication axiom): for `s ∈ S`, any representatives
    `n` of `s` and `m` of `w = π m`, and any `b ∈ B`, the product `n * b * m` lies in
    `cell B π w ∪ cell B π (s * w)`. This is `s B w ⊆ B w B ∪ B s w B`.
  - `conj_not_le` (nondegeneracy): for `s ∈ S` and every representative `n` of `s`,
    some `b ∈ B` has `n * b * n⁻¹ ∉ B`. This is `n B n⁻¹ ⊄ B`.

## Comparison with the classical axioms

The classical axioms (Tits; Bourbaki, *Lie* IV §2.1) are as follows.

- (T1) `B ∪ N` generates `G`, and `T = B ∩ N` is normal in `N`.
- (T2) `W = N / T` is generated by a set `S` of elements of order `2`.
- (T3) `s B w ⊆ B w B ∪ B s w B` for `s ∈ S` and `w ∈ W`.
- (T4) `s B s ≠ B` for `s ∈ S`.

(T1) and (T2) are the fields `surjective`, `ker_eq`, `sup_eq`, `closure_eq`, `ne_one`
and `mul_self`, as explained above. (T3) is `mul_mem_cell`. The classical sets
`s B w` and `B w B` do not depend on the representatives because `T ⊆ B`. The field
quantifies over all representatives, which is the same condition.

(T4) is `conj_not_le` in the following form. Let `n` represent `s`. Since `s * s = 1`,
the element `n * n` lies in `ker π = B ∩ N ⊆ B`. So the set `n B n` equals
`(n B n⁻¹) (n n)`, which is `B` exactly when `n B n⁻¹ = B`. Moreover `n B n⁻¹ ⊆ B`
already forces equality: conjugating by `n` gives `B = (n n) B (n n)⁻¹ ⊆ n B n⁻¹`.
Therefore `s B s ≠ B` is equivalent to `n B n⁻¹ ⊄ B`, which is `conj_not_le`. This
inclusion form is chosen because it is a statement about a single element `b` and is
easy to state with representatives. Both equivalences hold for all representatives at
once, so requiring them for every representative is no stronger than the classical
axioms. This equivalence is explained here and is not formalized.

## Elementary lemmas

- `TitsSystem.mem_cell`, `TitsSystem.mem_standardParabolic`: unfolding lemmas.
- `TitsSystem.coe_mem_cell`: each `n : N` lies in the cell of `π n`.
- `TitsSystem.mem_cell_iff`: if `π.ker ≤ B.subgroupOf N`, then the cell of `π n` is the
  double coset `B n B`.
- `TitsSystem.cell_one`, `TitsSystem.standardParabolic_empty`: under the same kernel
  hypothesis, the cell of `1` and the standard parabolic subset of `∅` are both `B`.
- `IsTitsSystem.inf_eq`: if `ker π` is a given subgroup `Z ≤ N`, viewed inside `N`,
  then `B ⊓ N = Z`. For the reductive realization, where `π` is the quotient map by the
  centralizer points, this gives `B ⊓ N = centralizerPoints i`.
- `IsTitsSystem.cell_one`, `IsTitsSystem.standardParabolic_empty`: the same two
  identities for a Tits system.
- `IsTitsSystem.eq_one_of_empty`, `IsTitsSystem.eq_top_of_empty` (rank zero): if
  `S = ∅`, then `W` is trivial and `B = G`. In the reductive case this is the
  convention of Borel–Tits §5.12 that the minimal parabolic `P_∅` is `G` when there
  are no simple roots.

## Sources and provenance

The predicate has **derived** provenance. It packages the axioms that Borel–Tits
verify in §§5.15–5.16 and invoke in §5.18, and that Renard V.4.1 cites, in the
representative form above. The packaging steps are the Weyl map `π` and the
representative form of (T3) and (T4); both are explained above.

- Borel and Tits, *Groupes réductifs* (1965), source
  `borel-tits-1965-groupes-reductifs`.
  - §5.15 (printed p.100): for `N = 𝒩(S)`, the group `G_k` is the disjoint union of the
    double cosets `P_k.w.P_k` (`w ∈ _kW`).
  - §5.16 (printed p.101): for a fundamental reflection `r`,
    (i) `r.P_k.{w, r.w}.P_k = P_k.{w, r.w}.P_k` and (ii) `r.P_k.r ≠ P_k`.
  - §5.18 (printed p.101): "5.15 et 5.16 montrent que les axiomes de [33] sont
    vérifiés", where [33] is Tits's paper on Tits systems.
- Renard, *Représentations des groupes réductifs p-adiques*, French version dated
  9 July 2026, source `renard-2026-representations-groupes-reductifs-padiques`,
  V.4.1 (printed p.118). This states that `(G, P_∅, N_G(A_∅), S_∅)` is a Tits system,
  citing Borel–Tits [7]. Bourbaki, *Lie* IV supplies background on the abstract
  axioms; it is not an additional citation printed on this proposition.

Bourbaki *Lie* IV and Tits's paper are not in the project's literature collection.
The list (T1)–(T4) above is the standard one cited by both sources. The field names
and the Lean formulation are internal to this project.
