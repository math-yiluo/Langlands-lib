# Elementary chains in a finite Coxeter group

Module `Langlands.Group.RelativeWeylElementaryChain`, namespace
`Langlands.Group.RelativeWeylIndexing`. This is the Coxeter-group part of the
proof of Renard 2026, VI.5.4, Lemma (Bernstein–Zelevinsky 1977, Lemma 2.17).
The group-scheme proof `Langlands.GroupScheme.standardWeylElementaryChain`
uses it as a helper module. The module has no statement of its own to prove. Its
definitions and theorems are internal tools for that proof.

## Setting and notation

`B : Type u`, `W : Type v`, `[Group W]`, `M : CoxeterMatrix B` and
`cs : CoxeterSystem M W`. Write `s_i = cs.simple i`, `ℓ = cs.length`, and
`W_I = standardSubgroup cs I` for `I : Finset B`, which is the published subgroup
generated by the `s_i` with `i ∈ I`. We say `x` is *right `I`-minimal* when
`ℓ x ≤ ℓ (x y)` for all `y ∈ W_I`, that is, when `x` is a shortest element of
`x W_I`. Unless a declaration says otherwise, `[Fintype B]` and `[Finite W]` are
assumed only where they are needed. Every fact about a standard subgroup `W_S` is
proved in the ambient system `cs`; no Coxeter system on `W_S` is built.

## Provenance

The overall route is Bernstein–Zelevinsky's proof 6.5 (registered source
`bernstein-zelevinsky-1977-induced-i`, journal pp. 469–470, PDF pp. 30–31). The
steps are numbered as follows:

* 6.5(2): for `w` minimal, `w' = w s_L s_S` is shorter.
* 6.5(3): exactly two elements `v ∈ W_S` have `v(Γ) ⊆ Π`, so `l_S(L) = 2`.
* 6.5(4): induction on `l(w)` using a simple `α ∉ Γ` with `w(α) < 0` and
  `ŵ = s_S s_L`.

The Coxeter facts are derived internally from the Coxeter presentation and the
published minimal-representative API. These are the longest element of `W_S`
and its length complement, the two-coset lemma, and the descent criterion for
the longest element. No other text is formalized line by line. Roots appear
in BZ, but here only simple reflections and lengths are used. The transport
relation `R` stands for "`w ∈ W(L_I, L_J)`" and is abstract here; it is
instantiated in `StandardWeylElementaryChainProof`.

## Minimal coset representatives and descents

* `length_lt_mul_simple_of_right_minimal`: if `x` is right `I`-minimal and
  `i ∈ I`, then `ℓ x < ℓ (x s_i)`. This holds because `ℓ(x s_i) ≠ ℓ x`.
* `exists_right_descent_of_mem` and `exists_left_descent_of_mem`: if
  `x ∈ W_S` and `x ≠ 1`, then `x` has a right (resp. left) descent `s_i` with
  `i ∈ S`. Otherwise `right_minimal_of_simple` (resp. `left_minimal_of_simple`)
  makes `x` minimal in `x W_S`, which contains `1`, so `ℓ x = 0`.
* `exists_right_minimal_decomposition`: every `w` is `x y` with `y ∈ W_I` and
  `x` right `I`-minimal. This uses `exists_minimal_in_doubleCoset_unrestricted`
  with the empty left index set.
* `length_mul_simple_of_not_mem` (`[Fintype B]`): if `b ∉ I` and `x ∈ W_I`,
  then `ℓ(x s_b) = ℓ x + 1`. For `i ∈ I` we have `s_i s_b ≠ 1`, so
  `ℓ(s_i s_b) = 2` and `s_b` is left `I`-minimal. Then
  `length_mul_of_left_minimal` applies.

## Conjugation of standard subgroups

The hypothesis `hc : ∀ g, g ∈ W_J ↔ x⁻¹ g x ∈ W_I` says that conjugation by
`x` carries `W_I` onto `W_J`. Assume also that `x` is right `I`-minimal.

* `conj_left_minimal` turns these assumptions into the published
  `IsMinimal cs J I x`, meaning `x` is minimal in `W_J x W_I`.
* `conj_simple_into` and `conj_simple_onto` (`[Fintype B]`): each `i ∈ I` has
  some `j ∈ J` with `x s_i x⁻¹ = s_j`, and each `j ∈ J` is reached from some
  `i ∈ I`. Both come from `exists_conj_simple_eq_of_isMinimal`, the second
  applied to `x⁻¹` through `isMinimal_inv`.

## The longest element of a standard parabolic subgroup

* `exists_longest_mem` (`[Finite W]`): `W_S` has an element `w₀` of maximal
  length.

In section `Longest`, fix `w₀ ∈ W_S` of maximal length in `W_S`.

* `length_mul_longest_add`: `ℓ(x w₀) + ℓ x = ℓ w₀` for every `x ∈ W_S`. For
  `y ∈ W_S` and `i ∈ S`, the reflection `t = y⁻¹ s_i y` satisfies
  `ℓ(t w₀) < ℓ w₀`, because `t w₀ ∈ W_S`. By `length_reflection_mul_lt_iff`,
  `reflectionParity cs w₀ t = 1`. The proof is by induction on `ℓ x`, splitting
  off a left descent `s_i` (`i ∈ S`) of `x`, so `ℓ(s_i x) = ℓ x − 1` and
  `reflectionParity cs (s_i x) s_i = 0`. The parity cocycle identity
  `reflectionParity_mul` then gives `reflectionParity cs (s_i x w₀) s_i = 1`,
  i.e. `ℓ(x w₀) < ℓ(s_i x w₀)`. Together with the induction hypothesis
  `ℓ(s_i x w₀) + ℓ(s_i x) = ℓ w₀`, this gives the step.
* `longest_mul_self` and `longest_inv`: `w₀² = 1` (take `x = w₀`), so
  `w₀⁻¹ = w₀`.
* `length_longest_mul_add`: `ℓ(w₀ x) + ℓ x = ℓ w₀` for every `x ∈ W_S`
  (invert the previous identity).
* `length_longest_mul_simple`: `ℓ(w₀ s_i) + 1 = ℓ w₀` for `i ∈ S`.
* `eq_longest_of_forall_descent`: if `c ∈ W_S` has every `s_i` with `i ∈ S` as
  a right descent, then `c = w₀`. Otherwise `c⁻¹ w₀ ≠ 1` has a left descent
  `s_i` with `i ∈ S`. Then `w₀ = (c s_i)(s_i c⁻¹ w₀)` has length at most
  `ℓ w₀ − 2`, which contradicts `ℓ(c⁻¹ w₀) = ℓ w₀ − ℓ c`.
* `longest_conj_simple` (`[Fintype B]`): for `i ∈ S`,
  `w₀ s_i w₀⁻¹ = s_j` for some `j ∈ S`. The element has length `1` by two
  applications of the complement identities, and `exists_simple_of_mem_standardSubgroup`
  applies.

## The two cosets of a maximal standard subgroup (BZ 6.5(3))

* `mem_or_longest_inv_mul_mem` (`[Fintype B]`): let `I ⊆ S ⊆ insert b I`, with
  `w₀` longest in `W_S` and `wI` longest in `W_I`. If `v ∈ W_S` conjugates
  `W_I` onto some `W_K`, then `v ∈ W_I` or `w₀⁻¹ v ∈ W_I`. Write `v = v' m`
  with `m ∈ W_I` and `v'` right `I`-minimal, so `v'` still conjugates `W_I`
  onto `W_K`. If `v' ≠ 1`, then `y = v' wI` has every `s_j` (`j ∈ S`) as a
  right descent:
  * for `j ∈ I`, use length additivity at `v'` and the descent of `wI`;
  * for the remaining index `j = b`, `v'` has a right descent in `S`, which
    lies outside `I` and hence equals `b`. Write `y = (v' wI v'⁻¹) v'` with
    `v' wI v'⁻¹ ∈ W_K`. Left additivity at the left `K`-minimal `v'` together
    with the triangle inequality gives `ℓ(y s_b) < ℓ y`.

  Hence `y = w₀` by `eq_longest_of_forall_descent`, and
  `w₀⁻¹ v = wI⁻¹ m ∈ W_I`.
* `length_lt_longest_mul_mul_simple`: for `I ⊆ S`, `ŵ = w₀ wI` satisfies
  `ℓ ŵ < ℓ(ŵ s_i)` for all `i ∈ I`. This follows from the complement identities.
* `longest_mul_conj_simple` (`[Fintype B]`): `ŵ s_i ŵ⁻¹ = s_j` with `j ∈ S`
  for `i ∈ I` (apply `longest_conj_simple` twice).
* `exists_simple_image` (`[Fintype B]`): if each `i ∈ I` has some `j ∈ S` with
  `x s_i x⁻¹ = s_j`, then there is `K ⊆ S` with `K.card = I.card` such that `x`
  sends `I` into `K` and reaches every element of `K`. The chosen map is
  injective by `simple_reflection_injective`.
* `exists_not_mem_of_card_add_one`: if `K ⊆ S` and `K.card + 1 = S.card`, then
  some `c ∈ S \ K` has `S ⊆ insert c K`.
* `nat_card_image_mk_eq_two`: suppose a set `X` in a group contains `1` and some
  `g ∉ H`, and every element of `X` lies in `H` or in `g H`. Then `X` has exactly
  two images in `G ⧸ H`.

## Elementary chains

For a predicate `R : Finset B → Finset B → W → Prop` ("transports `I` to `J`")
and a family `WS : Finset B → Subgroup W`:

* `IsElementaryTransport R WS I J g` holds when `R I J g` holds and there is some
  `S` with `I ⊆ S`, `J ⊆ S` and `g ∈ WS S`, such that the elements
  `v ∈ WS S` with `R J K v` for some `K ⊆ S` have exactly two images in
  `W ⧸ WS J`.
* `HasElementaryChain R WS I J w` holds when there are `m`, index sets
  `Ls : Fin (m + 1) → Finset B` and elements `ws : Fin m → W` such that:
  `Ls 0 = I`; `Ls (Fin.last m) = J`; each `ws j` is elementary from
  `Ls j.castSucc` to `Ls j.succ`; and `w` is the product of
  `(List.ofFn ws).reverse`, i.e. `w = w_{m-1} ⋯ w_0`.

These two definitions have exactly the shape of the target statement's
`IsElementary` and conclusion, with `R I J w` read as `w ∈ W(L_I, L_J)`. The
target's parabolic inclusions are replaced by the index inclusions `I ⊆ S` and
`J ⊆ S`. `hasElementaryChain_refl` gives the empty chain from `I` to `I` with
product `1`. `hasElementaryChain_cons` prepends an elementary step: from `g`
elementary `I → J` and a chain `J → K` for `x`, it builds a chain `I → K` for
`x g`, using `Fin.cons` and `List.ofFn_succ`.

## Transport theorems

Section `Transport` assumes `[Fintype B]`, `[Finite W]` and three properties of
`R`, all with `W_I = standardSubgroup cs I`:

* `hR1`: `R I J x` implies `g ∈ W_J ↔ x⁻¹ g x ∈ W_I` for all `g`;
* `hR2`: if `ℓ x < ℓ(x s_i)` for all `i ∈ I`, and `x s_i x⁻¹` runs through
  simple reflections of `J` and reaches all of them, then `R I J x`;
* `hR3`: `x ∈ W_I` implies `R I I x`.

The theorems are:

* `transport_of_right_minimal`: a right `I`-minimal `x` conjugating `W_I` onto
  `W_J` satisfies `R I J x`. It combines `hR2` with the conjugation lemmas above.
* `nat_card_transport_cosets_eq_two` (BZ 6.5(3)): for `I ⊆ S`, `b ∈ S \ I` and
  `S ⊆ insert b I`, the elements `v ∈ W_S` with `R I K v` for some `K ⊆ S` have
  exactly two images in `W ⧸ W_I`. The two cosets are those of `1` (by `hR3`)
  and of `ŵ = w₀ wI`. The element `ŵ` satisfies `R I K ŵ` by `hR2`, using
  `exists_simple_image` and `longest_mul_conj_simple`. It is not in `W_I`:
  otherwise `w₀ ∈ W_I`, and then `length_mul_simple_of_not_mem` at `b`
  contradicts `length_longest_mul_simple`. Every element is covered by
  `mem_or_longest_inv_mul_mem` together with `hR1`.
* `hasElementaryChain_of_right_minimal` (BZ 6.5(2), 6.5(4)): this is proved by
  strong induction on `n = ℓ x`. Suppose `x` is right `IL`-minimal, `R IL IM x`,
  and `IL ≠ univ` (some `a ∉ IL`). Then
  `HasElementaryChain R (standardSubgroup cs) IL IM x`.
  * If `x = 1`, then `W_IL = W_IM`, so `IL = IM` by
    `standardSubgroup_injective`, and the chain is empty.
  * Otherwise take a right descent `α` of `x`. Then `α ∉ IL` by minimality.
    Set `S = insert α IL`, let `w₀` and `wI` be the longest elements of `W_S`
    and `W_IL`, and let `ŵ = w₀ wI`. Choose `K ⊆ S` with `R IL K ŵ` via `hR2`;
    it has `|K| = |IL|`, so `S ⊆ insert c K` for some `c ∈ S \ K`.
  * The element `y = x wI` has every `s_j`, `j ∈ S`, as a right descent. For
    `j ∈ IL` this follows from additivity. For `j = α`, write
    `y = (x wI x⁻¹) x` with `x wI x⁻¹ ∈ W_IM` and use left additivity, as in
    the two-coset lemma.
  * Decompose `y = x' u` with `u ∈ W_S` and `x'` right `S`-minimal. By
    additivity `u` has full `S`-descent, so `u = w₀` and `x' = x ŵ⁻¹`. This
    element is strictly shorter than `x`: `ℓ x = ℓ x' + ℓ w₀ − ℓ wI` and
    `ℓ w₀ > ℓ wI` (via `length_mul_simple_of_not_mem` at `α`). This is BZ 6.5(2).
  * `x'` conjugates `W_K` onto `W_IM` and is right `K`-minimal (as `K ⊆ S`), so
    `R K IM x'` holds by `transport_of_right_minimal`. Also `c ∉ K`, so the
    induction hypothesis gives a chain `K → IM` for `x'`.
  * `ŵ` is elementary `IL → K` with the witness `S`, by
    `nat_card_transport_cosets_eq_two` for `K ⊆ S` and `c`. Prepending it
    gives a chain for `x' ŵ = x`.
* `hasElementaryChain` (BZ Lemma 2.17): let `WS` be a family with
  `standardSubgroup cs I = WS I` for all `I`, let `IL ≠ univ`, and suppose
  `R IL IM w`. Then `HasElementaryChain R WS IL IM w`. Write `w = x u` with
  `u ∈ W_IL` and `x` right `IL`-minimal. Then `x` still conjugates `W_IL` onto
  `W_IM`, so `R IL IM x` holds and the minimal case gives a chain for `x`.
  The element `u` is elementary `IL → IL` by `hR3`, with the witness
  `S = insert a IL` and `nat_card_transport_cosets_eq_two` for `a`. Prepending
  `u` gives the chain for `x u = w`.
