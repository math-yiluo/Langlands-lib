# The explicit Euler test function

Worker 1786 proves that the published explicit test is a Schwartz–Bruhat function for every supplied topology. The integer-ring indicator is a lattice-coset test. The inverse-character test uses Worker 1248's conductor-lattice local-constancy and compact-support lemmas in `GaussDual`. These show that the function extended by zero from the integral-unit annulus is a Schwartz–Bruhat function.

For an unramified character, the previously computed lattice integral and the unit-character average give the unit mass times the Euler factor. For a ramified character, the inverse character cancels the character in the integrand, and the normalized absolute value on the unit annulus is one. The resulting integral is precisely the unit mass, equal to the requested Euler expression in this case.
