# Real block lists of total rank one

`eq_singleton_of_realRank_eq_one` identifies a list of real Weil blocks of total
rank one with a singleton character block. A character contributes rank one
and an induced block contributes rank two. Expanding `realRank_cons` excludes
both an induced head and a second block. The global Rankin–Selberg module and
the real rank-one standard-module proof both use this calculation.
