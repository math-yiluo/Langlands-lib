# A finite extension of discrete valuation rings with separable residue extension is monogenic

`Langlands.LocalFactor.Ramification.Monogenic`. A finite injective local homomorphism of discrete
valuation rings `A → B` with separable residue field extension makes `B` generated over `A` by one
element. This is the hypothesis of the monogenic form of Herbrand's theorem
(`Herbrand/CosetDepth.lean`, `Herbrand/LowerQuotient.lean`), and the Library uses it in
`LocalFactor/DeligneHenniartTopLayerDifferent.lean`.

## Statement

Name space `Langlands.Ramification`.

```lean
theorem exists_adjoin_singleton_eq_top_of_isSeparable_residueField
    {A : Type*} [CommRing A] [IsDomain A] [IsDiscreteValuationRing A]
    {B : Type*} [CommRing B] [IsDomain B] [IsDiscreteValuationRing B]
    [Algebra A B] [IsLocalHom (algebraMap A B)] [Module.Finite A B]
    [Algebra.IsSeparable (IsLocalRing.ResidueField A) (IsLocalRing.ResidueField B)]
    (hinj : Function.Injective (algebraMap A B)) :
    ∃ x : B, Algebra.adjoin A {x} = ⊤
```

`Monogenic.exists_adjoin_singleton_eq_top` is the same with the separability as an explicit
hypothesis.

## Proof

Let `ᾱ` be a primitive element of the residue extension, `x ∈ B` a lift, and `G ∈ A[X]` a monic
lift of the minimal polynomial of `ᾱ`; write `Φ` for `G` over `B`. Then `Φ(x) ∈ m_B`, and `Φ'(x)` is
a unit because the minimal polynomial is separable. If `v_B(Φ(x)) = 1`, then `Φ(x) ∈ A[x]` is a
uniformizer of `B`. Otherwise, for a uniformizer `π₀` of `B`, Taylor expansion gives
`Φ(x + π₀) ≡ Φ'(x) π₀` modulo `m_B²`, so `Φ(x + π₀)` is a uniformizer, and `x + π₀` still lifts `ᾱ`.
In both cases the subalgebra `S = A[y]` contains a uniformizer of `B` and maps onto the residue
field of `B`. Successive approximation gives `B = S + m_B^n` for every `n`, in particular for the
`n` with `m_A B = m_B^n`; Nakayama's lemma (`IsLocalRing.map_mkQ_eq_top`, `B` being finite over
`A`) then gives `S = B` (`Monogenic.Subalgebra.eq_top_of_irreducible_mem_of_residue_surjective`).

## Literature

Serre, *Local Fields*, GTM 67 (1979), Chapter III, §6, Proposition 12, printed page 57: if the
residue extension of a finite extension of complete discretely valued fields is separable, the
ring of integers is generated by one element. Serre assumes only that the integral closure `B`
(hence `A`) is a discrete valuation ring and that the residue extension is separable, `B` being the
integral closure of `A` in a finite separable extension; completeness is not needed there.
