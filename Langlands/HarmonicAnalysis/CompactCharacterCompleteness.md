# Completeness of separating compact-group characters

This internal supporting argument proves that a subgroup of the continuous
circle-valued characters of a compact Hausdorff group is the entire continuous
dual if it separates points. It is an analytic input for adelic additive
duality; it asserts no arithmetic parametrization of characters.

`complexMap` views a circle-valued character as a continuous complex-valued
function. `characterAlgebra` is the complex algebra generated by the characters
in a subgroup `H`. Inversion of characters is complex conjugation, so this is a
star algebra. Products stay in `H`, hence the algebra is already their linear
span. If `H` separates points, Stone–Weierstrass makes this span dense in all
continuous complex-valued functions on the compact group.

Translation invariance makes the integral of a nontrivial character zero:
translate by a point where the character is not one, obtaining an equality
between the integral and a nonunit scalar multiple of itself.

For any character `χ` outside `H`, integration against the inverse of `χ`
defines a bounded complex linear functional on continuous functions. Every
character in `H` lies in its kernel by the preceding orthogonality argument.
The kernel is closed, and density therefore makes the functional identically
zero. But its value on `χ` itself is one for a probability measure, a
contradiction. `mem_of_separates` accepts an explicitly supplied left invariant
probability measure. `eq_top_of_separates` constructs one using Haar measure
normalized on the entire compact group.

The provenance is the standard Stone–Weierstrass and invariant-integral
argument, developed here as an internal proof ingredient. The implementation
follows the existing Library pattern in `TorusFourierInversion` for passing
from density of a character span to a closed kernel of an integral functional,
but applies to arbitrary compact groups and arbitrary separating character
subgroups. Worker 1843 proposed this analytic route for the adelic proof.
