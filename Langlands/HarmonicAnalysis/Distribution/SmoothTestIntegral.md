# Compact parameter integration of smooth tests

`SmoothTestIntegralStatement` averages a jointly smooth family with a common compact test support against any finite Borel measure on a compact parameter set. The result is a smooth test supported in the same compact set. Every continuous complex-linear functional on the fixed-support space commutes with this average.

Restrict the joint function to the compact parameter set and view each test point as giving a continuous function of the parameter. The resulting map into the Banach space of continuous functions is smooth. Integrating there is a bounded functional, so the averaged test is smooth and its derivatives are the averages of the corresponding derivatives.

Continuity of the given test functional bounds it by finitely many derivative seminorms. Record those derivatives and the functional together in a finite product of Banach spaces. The integral of the family of tuples lies in the closed linear subspace generated by the tuples of tests, by integration in that closed subspace. The functional bound holds throughout this subspace. The averaged test has the same derivative coordinates as the integrated tuple. Their difference then has zero derivative coordinates, so its functional coordinate is zero as well.
