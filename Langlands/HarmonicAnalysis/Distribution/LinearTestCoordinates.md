# Linear changes of coordinates for smooth tests

`openLinearTestPullbackCLM` pulls a real test back along a continuous linear equivalence that identifies two open sets. It is the smooth chart pullback for the restriction of the equivalence. The test already vanishes outside its domain, so the composition formula holds throughout the ambient space.

The chain rule commutes this pullback with a constant derivative after transporting the direction by the same equivalence. The result is used when splitting orbit coordinates and reordering the orbit, slice and normal factors.
