# Gluing locally integrable densities for distributions

`LocallyIntegrableDensityGluingStatement` concerns a second-countable locally profinite space with its Borel measurable structure. Take an indexed family of measures and an indexed family of complex distributions. Suppose each point has an open neighborhood with a single function that is locally integrable for each measure there and realizes each corresponding distribution on tests supported in the neighborhood. If these functions are locally constant at points of a prescribed set within their neighborhoods, `exists_locallyIntegrableDensity_of_locally` gives one globally defined function with the same integrability, test-integral identity, and local constancy. Indexing by Haar measures permits using the same character function for every Haar normalization.

Clozel's proof of Theorem 1 deduces the character theorem from local density results near semisimple elements. This lemma supplies the topological and integration step once a local density is available at each point. [Clozel, *Characters of non-connected, reductive p-adic groups*, §3.4, pp. 154–156](https://doi.org/10.4153/CJM-1987-008-3)

The proof refines the local neighborhoods to clopen sets and takes a countable subcover. Removing the earlier members of the subcover from each clopen set gives a disjoint clopen cover. On each piece the global function is the corresponding local function, giving local integrability and local constancy there. A finite collection of pieces covers any compact test-function support, so multiplying by their indicators writes the test as a finite sum. Linearity and the local test identities give the global integral formula.
