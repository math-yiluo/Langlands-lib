# Factoring a distribution through a box integral

A continuous linear functional on tests supported in a parameter domain times an open box factors through integration in the box variables if it annihilates all derivatives in those variables. Its induced parameter functional evaluates a parameter test multiplied by any fixed scalar box test of integral one.

For the proof, split the first box coordinate by a linear equivalence. The interval primitive identifies the functional after integrating that coordinate. Multiplication by a fixed interval test commutes with derivatives in the remaining coordinates, so the reduced functional satisfies the same hypothesis. Fubini's theorem identifies the iterated integrals with the full box integral. In dimension zero the volume is the Dirac measure at the unique point.

This is the orbit integration step for normalized distributions in real matrix conjugation charts.
