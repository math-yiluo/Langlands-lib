# Recenter the actual Weyl comparison at the intrinsic target index

Waldspurger, *La formule de Plancherel pour les groupes p-adiques (d'après
Harish-Chandra)* (2003), V.1 (printed pp. 288–289) and VI.3 (p. 306), compares
sections at an actual inducing object and its Weyl conjugate. The full index
in the Library fixes a base object once per unitary orbit. The comparison
instead ends at the conjugate of its source base.

The compact Weyl lift acts by inverse conjugation on the inducing
representations. This point map agrees with the inverse Levi homeomorphism
used in geometric orbit transport. Transporting the chosen source discrete
series class therefore gives the class of the conjugate base, with the given
Haar on the target split-central quotient. Its orbit is precisely the target
index. This establishes membership of the conjugate base and allows the
published smooth change of base there. That change reindexes each actual
inducing object and preserves its coefficient value, including when its
class is represented by more than one inducing object.
