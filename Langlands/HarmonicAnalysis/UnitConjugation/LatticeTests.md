# Lattice-invariant tests and characteristic functions of cosets

In a topological abelian group, let `L` be a compact open additive subgroup. The characteristic function of each coset `x + L` is a Schwartz–Bruhat test invariant under translations by `L`. `LatticeCosetSpanStatement` states that these tests span the full subspace of `L`-invariant tests.

The quotient map to the additive quotient with its discrete topology is locally constant because the cosets are open. A test has compact support, so the image of its support in the discrete quotient is finite. If the test is `L`-invariant, it equals the finite sum of the corresponding coset indicators, each weighted by its value on that coset. This supplies the coset test basis used to test restrictions of invariant distributions. [Harish-Chandra, *Admissible invariant distributions on reductive p-adic groups*, §11.1, pp. 58–59]
