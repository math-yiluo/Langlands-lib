# Cotangent spaces at a rational point and maximal ideals

Author: Worker 303. This module is local commutative algebra. It is the bridge
between two forms of the good-point condition used in the etale slicing proof of
`Langlands.AlgebraicGeometry.SmoothEquivalenceRelationEtaleSliceStatement`
(task `3c6168ac-543c-4dc2-a8a6-81647cb26eb6`): the equality of ideals in
`Langlands.AlgebraicGeometry.SmoothRelationGoodPoint.IsGoodPoint`, and the
spanning of the relative cotangent space by differentials, which is the input of
the slicing step.

The module imports only `Mathlib`. All declarations are in namespace
`Langlands.AlgebraicGeometry.SmoothRelationGoodPoint`.

## Setting

`B` is a local ring with maximal ideal `𝔪 = maximalIdeal B` and residue field
`κ = ResidueField B`. `A` is a commutative ring with `[Algebra A B]`; write
`σ = algebraMap A B`. `θ : A →+* B` is a second ring map. Write
`𝔭 = 𝔪.comap σ = σ⁻¹(𝔪)`. Differentials are `Ω[B⁄A]`, the Kähler differentials of
`B` over `A` through `σ`, and `D = KaehlerDifferential.D A B`.

## Definitions

- `IsConst A z` (for `z : B`): there are `a a' : A` with `σ a' ∉ 𝔪` and
  `σ a' * z = σ a`. So `z` is the fraction `σ a / σ a'` with a unit denominator.
  The lemmas `IsConst.const`, `add`, `neg`, `sub` and `mul` show that constants
  form a subring containing `σ(A)`. `IsConst.mem_map` shows that a constant in `𝔪`
  lies in `σ(𝔭) B`. `IsConst.D_eq_zero` shows that a constant has differential `0`.
- `IsRationalPoint A B`: for every `b : B` there are `a a' : A` with `σ a' ∉ 𝔪` and
  `σ a' * b - σ a ∈ 𝔪`. In words, the residue field `κ` is generated by the image
  of `A` (it is the fraction field of `A / 𝔭`). `IsRationalPoint.exists_const`
  restates it as: every `b` is congruent modulo `𝔪` to a constant.
- `cotangentSpan θ`: the `κ`-submodule of `κ ⊗[B] Ω[B⁄A]` spanned by the elements
  `1 ⊗ D(θ g)` for `g ∈ 𝔭`.
- Auxiliary, used in the proof of the converse: `sqSupIdeal A B` is the ideal
  `𝔪² + σ(𝔭) B`; `constRep hrat b` is a chosen constant congruent to `b` modulo
  `𝔪`; `residueDerivation hrat` is the `A`-derivation
  `b ↦ [b - constRep hrat b]` from `B` to `B / (𝔪² + σ(𝔭) B)`.

## Main results

- `span_one_tmul_D`: the elements `1 ⊗ D b`, `b : B`, span `κ ⊗[B] Ω[B⁄A]` over
  `κ`.
- `cotangentSpan_eq_top_of_maximalIdeal_eq`: if `IsRationalPoint A B` and
  `𝔪 = σ(𝔭) B + θ(𝔭) B` (written `𝔭.map σ ⊔ 𝔭.map θ`), then
  `cotangentSpan θ = ⊤`.
- `maximalIdeal_eq_of_cotangentSpan_eq_top`: conversely, assume
  `𝔪.comap θ = 𝔭`, `IsRationalPoint A B`, and that some finitely generated ideal
  `N ≤ 𝔪` satisfies `𝔪 ≤ σ(𝔭) B + N`. If `cotangentSpan θ = ⊤`, then
  `𝔪 = σ(𝔭) B + θ(𝔭) B`.

Helper lemmas: `one_tmul_smul` and `one_tmul_D_mul_of_mem` (for `z ∈ 𝔪`,
`1 ⊗ D(b z) = b̄ · (1 ⊗ D z)`); `mem_sqSupIdeal_of_one_tmul_D_eq_zero` (an element
`z ∈ 𝔪` with `1 ⊗ D z = 0` lies in `𝔪² + σ(𝔭) B`);
`exists_eq_one_tmul_D_of_mem_cotangentSpan` (every element of the span is
`1 ⊗ D y` for some `y ∈ θ(𝔭) B`); and `le_of_le_sup_sq`, a form of Nakayama's
lemma: if `𝔪 ≤ P + N` with `N ≤ 𝔪` finitely generated, `P ≤ I` and
`𝔪 ≤ I + 𝔪²`, then `N ≤ I`.

## Proofs

Forward direction. Every `z ∈ 𝔪` has `1 ⊗ D z` in the span: write `z` in the
ideal `σ(𝔭) B + θ(𝔭) B`; generators `σ a` have differential `0`, generators
`θ g` give spanning elements, and multiples `b z` with `z ∈ 𝔪` give
`b̄ · (1 ⊗ D z)` by the Leibniz rule. For an arbitrary `b : B`, rationality gives a
constant `c` with `b - c ∈ 𝔪` and `D b = D(b - c)`. Since the `1 ⊗ D b` span, the
span is everything.

Converse. The derivation `b ↦ [b - c(b)]` into `B / (𝔪² + σ(𝔭) B)` is
well defined because sums, products and differences of constants are constants,
and a constant in `𝔪` lies in `σ(𝔭) B`. Its lift `ψ : Ω[B⁄A] → B / (𝔪² + σ(𝔭) B)`
has image inside the image of `𝔪`, so it kills `𝔪 · Ω[B⁄A]`. If `z ∈ 𝔪` and
`1 ⊗ D z = 0`, then `D z ∈ 𝔪 · Ω[B⁄A]` (Mathlib's `quotTensorEquivQuotSMul`),
so `[z - c(z)] = ψ (D z) = 0`, and `z ∈ 𝔪² + σ(𝔭) B`. Given the spanning
hypothesis, each `b ∈ 𝔪` has `1 ⊗ D b = 1 ⊗ D y` with `y ∈ θ(𝔭) B`, so
`b - y ∈ 𝔪² + σ(𝔭) B`. Hence `𝔪 ≤ I + 𝔪²` for `I = σ(𝔭) B + θ(𝔭) B`. The
Nakayama form `le_of_le_sup_sq` (via Mathlib's
`Submodule.le_of_le_smul_of_le_jacobson_bot`) applied to `N` gives `N ≤ I`, so
`𝔪 ≤ σ(𝔭) B + N ≤ I`. The reverse inclusion `I ≤ 𝔪` uses `𝔪.comap θ = 𝔭`.

## Provenance

The module is internal to the slicing proof. It formalizes the standard
identification of the relative cotangent space at a rational point,
`κ ⊗_B Ω_{B/A} ≅ 𝔪 / (𝔪² + σ(𝔭) B)` with `D b` corresponding to the class of
`b - c(b)`, in the form of a spanning criterion. Compare the second fundamental
exact sequence `𝔪/𝔪² → Ω_{B/A} ⊗_B κ → Ω_{κ/A} → 0` (Stacks Project, Lemma 00RU),
where `Ω_{κ/A} = 0` at a rational point. It then applies Nakayama's
lemma (Stacks Project, Lemma 00DV). The finiteness hypothesis `N` in the converse
holds for stalks of schemes locally of finite type over the base point's local
ring; it is stated as a hypothesis here.
