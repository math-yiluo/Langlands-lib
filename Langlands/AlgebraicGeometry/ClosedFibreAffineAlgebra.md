# The actual algebras of affine closed-fibre neighbourhoods

This internal module equips the actual ring `Γ(X, U)` of an affine source
open with its algebra structure over the given ring `R`, using the actual
morphism `Spec Γ(X, U) → X → Spec R`. The definition
`affineSectionAlgebra` uses the inverse equivalence between affine scheme
morphisms and ring homomorphisms. The lemma
`affineSectionAlgebra_specMap` identifies the resulting spectrum map with
that original composite, so the coefficient structure is fixed by the
geometry rather than supplied as an extra hypothesis.

`finitePresentation_affineSectionAlgebra` and
`flat_affineSectionAlgebra` transfer local finite presentation and flatness
of the original scheme morphism to algebra finite presentation and module
flatness of these actual sections. The proofs compose with the affine
chart's open immersion and apply Mathlib's spectrum-map criteria. No
finiteness as an `R`-module is asserted.

For a local commutative ring `R`, a smooth geometrically connected
morphism `p`, and an affine open `U` meeting its closed fibre,
`geometricallyIntegral_affineSectionAlgebra` proves geometric integrality
of that same algebra's spectrum map. It uses the imported integrality
result for the restricted open and transports it through the canonical
affine-chart isomorphism.

`closedFibreIdeal_isPrime_of_geometricallyIntegral` is an independent
algebraic consequence for any `R`-algebra `A` over a local ring. If its
actual spectrum map is geometrically integral, the ideal generated by
the maximal ideal of `R` is prime in `A`. The proof base changes to the
field `R/m`, identifies the pullback with the spectrum of
`A ⊗[R] (R/m)`, and obtains that this tensor algebra is a domain. The
standard quotient–tensor isomorphism identifies it with `A/mA`, proving
primality, including properness of the ideal.
`closedFibreIdeal_isPrime_affineSectionAlgebra` specializes this to the
actual affine section rings above.

All declarations preserve an arbitrary universe `u`. The provenance is
internal, combining the imported closed-fibre geometry with Mathlib's
affine duality, morphism properties, geometric base change and quotient
tensor product isomorphism. This module does not prove projectivity,
choose compatible normalizations of frames, or extend a line bundle.
