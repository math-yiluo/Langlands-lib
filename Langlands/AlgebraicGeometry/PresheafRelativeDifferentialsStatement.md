# Universality of the constructed relative derivation

Module `Langlands.AlgebraicGeometry.PresheafRelativeDifferentialsStatement`.

The declaration `Langlands.PresheafDifferentials.DerivationUniversalStatement` is
a proposition definition. It is parameterized by categories `C : Type u₁`
(`[Category.{v₁} C]`) and `D : Type u₂` (`[Category.{v₂} D]`), with no smallness
assumption, a functor `F : C ⥤ D`, presheaves of commutative rings
`S : Cᵒᵖ ⥤ CommRingCat.{u}` and `R : Dᵒᵖ ⥤ CommRingCat.{u}`, and a morphism
`φ : S ⟶ F.op ⋙ R`. This file states the proposition; it contains no proof.

## Exact statement

```lean
def DerivationUniversalStatement (φ : S ⟶ F.op ⋙ R) : Prop :=
  Nonempty (derivation φ).Universal
```

Here `derivation φ : (relativeDifferentials φ).Derivation φ` is the explicit
derivation of module `Langlands.AlgebraicGeometry.PresheafRelativeDifferentials`:
`relativeDifferentials φ : PresheafOfModulesOfCommRing.{u} R` has, over `Y : Dᵒᵖ`,
the Kähler differentials of `R.obj Y` relative to the subring generated by all
`R.map f (φ.app X a)`, and `derivation φ` sends `b` to its Kähler differential
`d b`.

`PresheafOfModulesOfCommRing.Derivation.Universal` is Mathlib's existing structure
(`Mathlib/Algebra/Category/ModuleCat/Differentials/Presheaf.lean`). For the
derivation `d₀ := derivation φ` with values in `P := relativeDifferentials φ`, a
term of `d₀.Universal` consists of:

- `desc`: for every presheaf of `R`-modules `M'` with module carriers in the same
  universe `u` as `P`, and every φ-derivation `d' : M'.Derivation φ`, a morphism
  `desc d' : P ⟶ M'` of presheaves of `R`-modules;
- `fac`: `d₀.postcomp (desc d') = d'`, i.e. `d'` factors through `d₀`;
- `postcomp_injective`: two morphisms `α β : P ⟶ M'` with
  `d₀.postcomp α = d₀.postcomp β` are equal.

So the proposition says that `(relativeDifferentials φ, derivation φ)` represents
the functor `M' ↦ M'.Derivation φ` on presheaves of `R`-modules at universe `u`.
Since `Universal` is a subsingleton in Mathlib, `Nonempty` loses no information.
The statement concerns the explicit object and derivation; it does not assume
`HasDifferentials φ`, and it is not an existence statement for some universal
object.

`φ : 𝒪₁ → 𝒪₂` on a topological space, the functor `ℱ ↦ Der_{𝒪₁}(𝒪₂, ℱ)` on
`𝒪₂`-modules is representable; Definition 17.28.3 names the representing object

`Ω_{𝒪₂/𝒪₁}` with the sheafification of `U ↦ Ω_{𝒪₂(U)/𝒪₁(U)}`.

The Lean proposition is the presheaf analogue for an arbitrary functor `F` of
index categories, with the vanishing condition given by `φ : S ⟶ F.op ⋙ R`. The
literature does not state this general-category result; it is internal
infrastructure for the scheme case `F = TopologicalSpace.Opens.map f.base`,
`φ = f.c`. It says nothing about sheaves or sheafification.
