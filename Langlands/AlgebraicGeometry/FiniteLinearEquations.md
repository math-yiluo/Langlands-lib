# Coordinate algebras of finite homogeneous linear systems

For an arbitrary commutative ring `R` and a finite matrix `a`, this module
constructs the quotient of `R[X₁, …, Xₙ]` by its row equations. The ideal is
finitely generated because it is generated by the image of `Fin m`.
Consequently `CoordinateRing a` is a finitely presented `R`-algebra.

`Solutions a S` is the type of vectors in any commutative `R`-algebra `S`
that satisfy every row equation. `pointsEquiv` identifies this type with
the actual `R`-algebra maps from the coordinate ring to `S`. The inverse
uses polynomial evaluation, which factors through the quotient because
the solution kills each generating row polynomial. The inverse identities
use the quotient and polynomial universal properties. The naturality
formula states that postcomposing the algebra map applies the same map to
every coordinate.

This is the algebraic construction in the last paragraph of the proof of
Stacks Project Lemma 99.3.8, Section 99.3 (Tag 08JS). The retained original
`08JS.html` belongs to registered source
`stacks-hom-functor-08js-2026-11-02`, folder SHA-256
`2d60cda5ae13d9daa5c318ca4cd199e47a3a00b39f5062492b2207f7b56432c4`.
The full section, proofs and its two typo-only comments were read; no
project errata entry was found. The implementation uses Mathlib's
polynomial and ideal-quotient universal properties.

The module establishes the coordinate algebra and all algebra-valued
points. It does not yet construct a natural isomorphism on all scheme
tests, or obtain a matrix model for coherent-family Hom. Those are separate
geometric obligations in the proper-Hom proof.
