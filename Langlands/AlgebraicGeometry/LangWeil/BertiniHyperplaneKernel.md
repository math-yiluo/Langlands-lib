# The kernel of the generic hyperplane evaluation

Author: Worker 205.

This internal helper module is the second step of the proof of
`Langlands.AlgebraicGeometry.LangWeil.BertiniGenericHyperplaneStatement`. It identifies the
generic hyperplane section of `Spec D`, for a domain `D`, with the kernel of a map into a field.
It also proves two general lemmas on prime radicals of principal ideals.

## Notation

Let `k` be a field, `D` a commutative `k`-algebra and `g : Fin N → D`.

- `𝒫 = k[a_*, a_0, …, a_{N-1}]` is `MvPolynomial (Option (Fin N)) k` (with `a_*` indexed by
  `none`), and `𝓛 = Frac 𝒫`.
- `hyperplaneEq k g = a_* ⊗ 1 + ∑ᵢ aᵢ ⊗ gᵢ ∈ 𝓛 ⊗[k] D`. For `D = A` this is the element `h`
  of the target statement, written in the same way.
- When `D` is a domain, `𝒦 = Frac D`, `𝒬 = 𝒦[x_0, …, x_{N-1}]`, `ℱ = Frac 𝒬`, and
  `linearForm g = ξ = ∑ gᵢ xᵢ ∈ ℱ`.

## General lemmas

- `sub_mem_span_of_ringHom`: two ring homomorphisms `f₁, f₂` out of `MvPolynomial σ R` that
  agree on constants satisfy `f₁ p - f₂ p ∈ (f₁ Xᵢ - f₂ Xᵢ)ᵢ` for every `p`. Proof by
  `MvPolynomial.induction_on`, using
  `f₁(pXᵢ) - f₂(pXᵢ) = (f₁ p - f₂ p) f₁(Xᵢ) + f₂(p)(f₁ Xᵢ - f₂ Xᵢ)`.
- `radical_span_singleton_isPrime_of_ker`: let `Φ : S → T` satisfy `Φ y = 0` and
  `Φ s = 0 → s ∈ (y)`. If the nilradical of `T` is prime, then `√(y)` is prime, because
  `√(y) = Φ⁻¹(nil T)`.
- `radical_span_singleton_isPrime_of_surjective`: let `χ : R → S` be surjective with kernel
  contained in the nilradical. If `√(χ x)` is prime, so is `√(x)`, because
  `√(x) = χ⁻¹(√(χ x))`. For the inclusion `⊇`: if `χ(r)^m = χ(a) χ(x)`, then `r^m - a x` is
  nilpotent, so `r^m ∈ √(x)`.
- `exists_tmul_mul_eq_map` (clearing denominators): for a domain `R` with fraction field `Fr`
  and every `z ∈ Fr ⊗[k] B`, there are `q ≠ 0` in `R` and `w ∈ R ⊗[k] B` with
  `(q ⊗ 1) z` the image of `w`. Proof by induction on `z`, using a common denominator for
  sums.

## The evaluation and its kernel

Assume that `D` is a domain.

- `paramEval₀ : 𝒫 →ₐ[k] ℱ` sends `a_* ↦ -ξ` and `aᵢ ↦ xᵢ`. By `paramEval₀_injective`, it
  is injective if `![g j, g l]` is algebraically independent over `k` in `𝒦`. Proof: by
  `algebraicIndependent_option_linearForm` (module `BertiniHyperplaneSeparable`), restricted
  to the entries `ξ, x_0, …, x_{N-1}` and mapped into `ℱ`, the family `(ξ, x)` is
  algebraically independent; replacing `ξ` by `-ξ` keeps it independent (`IsAlgebraic.neg`).
- `paramEval : 𝓛 →ₐ[k] ℱ` is the induced field embedding (`IsFractionRing.liftAlgHom`).
- `tensorEval : 𝓛 ⊗[k] D →ₐ[k] ℱ` is `paramEval` on the left factor and `D → 𝒦 → ℱ` on the
  right factor. `tensorEval_hyperplaneEq` says that it kills `hyperplaneEq k g`:
  `-ξ + ∑ xᵢ gᵢ = 0`.

The main result is `tensorEval_eq_zero_iff`: `tensorEval z = 0` if and only if `z` lies in the
ideal generated by `hyperplaneEq k g`. The reverse direction is the previous paragraph. For
the forward direction:

1. Clearing denominators gives `q ≠ 0` in `𝒫` and `w ∈ 𝒫 ⊗[k] D` with `(q ⊗ 1) z` the
   image of `w`.
2. `polyEval : 𝒫 ⊗[k] D → D[x]` sends `a_* ↦ -∑ C(gᵢ) xᵢ`, `aᵢ ↦ xᵢ`, `d ↦ d`.
   `polySection : D[x] → 𝒫 ⊗[k] D` sends `xᵢ ↦ aᵢ ⊗ 1` and `d ↦ 1 ⊗ d`. By
   `sub_polySection_mem`, `w - polySection (polyEval w)` lies in the ideal generated by the
   polynomial hyperplane equation `a_* ⊗ 1 + ∑ aᵢ ⊗ gᵢ` of `𝒫 ⊗[k] D`. It is proved by
   `sub_mem_span_of_ringHom` on pure tensors `p ⊗ 1`, then for `p ⊗ d` and sums.
3. `tensorEval_comp_map` shows that `tensorEval` composed with `𝒫 ⊗ D → 𝓛 ⊗ D` equals the
   injective map `polyMap : D[x] → ℱ` composed with `polyEval`. Since
   `tensorEval((q ⊗ 1) z) = 0`, this gives `polyEval w = 0`.
4. Hence `w` lies in the polynomial hyperplane ideal, so `(q ⊗ 1) z` lies in the ideal of
   `hyperplaneEq k g`. Since `q ⊗ 1` is a unit of `𝓛 ⊗[k] D`, so does `z`.

## Provenance

Internal. In the Stacks Project, Section 37.32 (Tag 0G4C), the proof of Lemma 37.32.3
(Tag 0G4F) notes that where the coefficient `f_1` is invertible, the universal divisor
`Spec(A[x_1, …, x_r]/(∑ xᵢ fᵢ))` is an affine space over `Spec A_{f_1}`, by eliminating `x_1`.
Here the coefficient of `a_*` is `1`, and eliminating `a_* = -ξ` gives the kernel statement
above. The lemmas on prime radicals and on clearing denominators are elementary commutative
algebra.
