# Module presheaves of a formal module system

Author: Worker 1405.

This module is `Langlands.AlgebraicGeometry.Modules.FormalModuleSystemPresheaves`.
All declarations are in the namespace
`Langlands.AlgebraicGeometry.Modules.FormalModuleSystemPresheaves`.

## Setting

Let `f : X ⟶ Spec R` be a morphism and `I` an ideal of `R`. The `n`-th adic
thickening is `X_n = adicSpace f I n = X ×_{Spec R} Spec (R / I^(n+1))`, with
the closed immersion `p_n = adicProjection f I n : X_n ⟶ X` and the transition
`t_n = adicTransition f I n : X_n ⟶ X_(n+1)` (Library definitions in
`Langlands.AlgebraicGeometry.Picard.FormalLineBundleSystem`, namespace
`Picard.FormalLineBundle`). A `FormalModuleSystem f I`
(`Langlands.AlgebraicGeometry.Modules.FormalModuleSystem`) consists of module
sheaves `F.obj n` on `X_n` and isomorphisms
`F.transition n : t_n^* F_(n+1) ≅ F_n`.

## Main results

For a formal module system `F`:

- `presheaf F n : OModulePresheaf f` is the module presheaf
  `U ↦ Γ(F_n, p_n⁻¹ U)` on `X`, defined as
  `OModulePresheaf.pushforward f p_n (OModulePresheaf.ofModules (p_n ≫ f) F_n)`
  with the Library `OModulePresheaf` constructions.
- `transitionSections F n U s` sends `s ∈ Γ(F_(n+1), p_(n+1)⁻¹ U)` to
  `(F.transition n).hom` applied to the pullback of `s` along `t_n`,
  restricted to `p_n⁻¹ U`. Lemmas `transitionSections_add`, `_smul` and `_map`
  record additivity, semilinearity and compatibility with restriction.
- `phi F n : OModulePresheaf.AffHom (presheaf F (n + 1)) (presheaf F n)` is the
  morphism on affine opens given by `transitionSections`, with
  `phi_app` holding by definition.

Assume `hF : ∀ n, (F.obj n).IsFinitePresentation` (Mathlib's local finite
presentation). Then:

- `isCoherent_presheaf F hF n`: `(presheaf F n).IsCoherent`, that is,
  `Γ(F_n, p_n⁻¹ U)` is a finite `Γ(X, U)`-module for every affine open `U`.
- `isQuasicoherent_presheaf F hF n`: `(presheaf F n).IsQuasicoherent`, that
  is, for affine `U` and `r ∈ Γ(X, U)` the restriction to `D(r)` is a
  localization at `r` in the two-condition form of the Library definition.
- `surjective_and_ker_phi F hF n U`: for every affine open `U`, `(phi F n).app U`
  is surjective and its kernel is `I^(n+1) • ⊤`.

These are exactly the hypotheses on the system of presheaves in the FLT
existence theorem that `ProperFormalCoherentExistenceOfFLT` assumes.

## Proof outline

- Coherence: `Γ(F_n, p_n⁻¹ U)` is finite over `Γ(X_n, p_n⁻¹ U)`
  (`hasFiniteAffineSections_of_isFinitePresentation`), and
  `Γ(X, U) → Γ(X_n, p_n⁻¹ U)` is finite because `p_n` is a closed immersion,
  hence finite. Finiteness composes along this tower.
- Quasi-coherence: `p_n⁻¹ D(r)` is the basic open of the image of `r` on the
  affine open `p_n⁻¹ U`, and the two localization conditions for a
  quasi-coherent module sheaf on a basic open of an affine open come from
  `AffineVanishing.exists_pow_smul_eq_res_aux` and
  `AffineVanishing.exists_pow_smul_eq_zero_aux` (wrapped as `loc_core_mod`).
- Transition maps: on the affine opens `W = p_(n+1)⁻¹ U` and `W' = p_n⁻¹ U`,
  the ring map `σ : Γ(X_(n+1), W) → Γ(X_n, W')` is surjective with kernel
  generated by `I^(n+1)` (`adicTransition_appLE_surjective_and_ker`), from the
  pullback square `isPullback_adicTransition` over
  `R / I^(n+2) → R / I^(n+1)` and the pushout lemma
  `surjective_and_ker_eq_of_isPushout`. Pulled-back sections over `W'` are
  `Γ(X_n, W') ⊗ Γ(F_(n+1), W)` (`pullbackTensorMap_bijective`, for the
  quasi-coherent `F_(n+1)`). Along a surjective ring map, a map out of a scalar
  extension is bijective exactly when `n ↦ g (1 ⊗ n)` is surjective with kernel
  `ker σ • N` (`bijective_of_one_tmul`, `surjective_and_ker_of_bijective`,
  section `ExtendScalars`). Composing with the transition isomorphism gives
  `surjective_and_ker_sectionPullbackLE`, and restricting scalars from
  `Γ(X_(n+1), W)` to `R` gives the kernel `I^(n+1) • ⊤`.

## General lemmas

- Section `ExtendScalars`: `kerSMul`, `exists_one_tmul`, `descend`,
  `one_tmul_eq_zero_iff`, `bijective_of_one_tmul`,
  `surjective_and_ker_of_bijective` for `ModuleCat.extendScalars σ` along a
  surjective ring map `σ`.
- Sections `PushoutSurj`, `RingCat`, `Kernel`: a surjection base-changed along
  a pushout of commutative rings stays surjective with kernel generated by the
  image of the original kernel, and the resulting statement on sections over
  inverse images of affine opens for a pullback square of schemes
  (`surjective_and_ker_app`).
- Section `Adic`: closed-immersion instances for `adicBaseProjection` and
  `adicProjection`, `adicTransition_preimage`, `le_adicTransition_preimage`,
  `isPullback_adicTransition`, `appLE_algebraMap_comp`,
  `algebraMap_adicProjection_eq_zero` (the structure map of `X_n` kills
  `I^(n+1)`).
- Section `Sections`: `app_bijective_of_iso` and
  `surjective_and_ker_sectionPullbackLE`.

## Purpose and provenance

This is the input bridge of the proof task `20cb772c` (proper coherent formal
existence): it turns a formal module system with finitely presented terms into
a system of `OModulePresheaf`s satisfying the hypotheses of the FLT presheaf
existence theorem. It follows the line-bundle version in the FLT source and
replaces every use of invertibility by finite presentation.
