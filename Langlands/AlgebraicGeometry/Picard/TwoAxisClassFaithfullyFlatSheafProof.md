# The two-axis class presheaf satisfies faithfully flat descent: proof

Author: Worker 384.

The module
`Langlands.AlgebraicGeometry.Picard.TwoAxisClassFaithfullyFlatSheafProof`
proves

```lean
theorem Langlands.AlgebraicGeometry.Picard.noetherianTwoAxisClassFaithfullyFlatSheaf :
    Langlands.AlgebraicGeometry.Picard.NoetherianTwoAxisClassFaithfullyFlatSheafStatement.{u}
```

It imports the published statement module
`Langlands.AlgebraicGeometry.Picard.TwoAxisClassMurreConditionsStatement`
unchanged and keeps the arbitrary universe `u`. Take a noetherian ring `R` in
`Type u`, an abelian scheme `A` over `Spec R`, and a morphism of test objects
`g : T' ⟶ T` in `Over (Spec R)` whose underlying morphism `g.left` is flat,
surjective and quasi-compact. Then `TwoAxisRigidifiedLineBundle.classPresheaf A`
satisfies the sheaf condition for the singleton presieve on `g`. This is
Murre's condition (F1b), `UnramifiedFunctor.FaithfullyFlatSheaf`.

The proof does not use the noetherian hypothesis.

## Implemented proof

The theorem is one line. For each `R` and `A` it applies

```lean
UnramifiedFunctor.faithfullyFlatSheaf_of_isSheaf_fpqc
  (TwoAxisRigidifiedLineBundle.classPresheaf_isSheaf_fpqc A)
```

Both results are in the support module
`Langlands.AlgebraicGeometry.Picard.TwoAxisClassFpqcSheaf`, which is part of
this contribution; see `TwoAxisClassFpqcSheaf.md` for the full proof.

- `TwoAxisRigidifiedLineBundle.classPresheaf_isSheaf_fpqc A` proves that the
  class presheaf is a sheaf for `Scheme.fpqcTopology.over S`, for every abelian
  scheme over every base `S`. It embeds the two-axis classes into the
  one-section rigidified classes of `A ×_S A` along the unit section `(e, e)`.
  These are an fpqc sheaf by the published descent results for rigidified
  classes. The image consists of the classes whose pullbacks to `A` along the
  two axes `(id, e)` and `(e, id)` are trivial. The comparison works with
  classes of underlying line bundles. It uses the published facts that a
  two-axis-rigidified line bundle is determined by its carrier
  (`nonempty_iso_of_carrierIso`) and that a line bundle trivial along both axes
  admits a two-axis rigidification (`nonempty_twoAxisRigidification`).
- `UnramifiedFunctor.faithfullyFlatSheaf_of_isSheaf_fpqc` shows that every fpqc
  sheaf `F` on `Over S` satisfies `FaithfullyFlatSheaf F`. By
  `Presieve.isSheafFor_iff_generate`, it suffices that the sieve generated by
  `g` is an fpqc covering of `T` in `Over S`. The singleton presieve is written
  as `Presieve.ofArrows` over `PUnit` (`Presieve.ofArrows_pUnit`). Then
  `GrothendieckTopology.mem_over_iff` and `Sieve.overEquiv_ofArrows` reduce the
  claim to the sieve generated by the singleton presieve on `g.left` in
  `Scheme`. That presieve belongs to the fpqc precoverage
  (`Scheme.Hom.singleton_mem_fpqcPrecoverage`, using the flatness, surjectivity
  and quasi-compactness of `g.left`). So the sieve it generates is in
  `Scheme.fpqcTopology` (`Precoverage.generate_mem_toGrothendieck`).

## Source

The statement is Murre's condition (F1b), specialized to the functor of
divisorial correspondences in the proof of Raynaud, *Faisceaux amples sur les
schémas en groupes et les espaces homogènes*, LNM 119, Theorem III 4.4. See
`TwoAxisClassMurreConditionsStatement.md`. The proof deduces it from the fpqc
sheaf property. The route through rigidified classes on `A ×_S A` is internal
to this development.
