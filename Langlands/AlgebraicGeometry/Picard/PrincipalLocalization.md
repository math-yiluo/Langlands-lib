# Spreading a principal localized ideal

These internal algebra lemmas (namespace `Langlands.AlgebraicGeometry.Picard.PrimeDivisor`) use native Mathlib localization and ideal APIs. Let `S` be the localization of a commutative ring `R` at a submonoid `M`. `exists_numerator_generator`: a principal localized ideal has a generator that is the image of an element of the original ideal: write a localized generator as a numerator divided by a unit. `exists_denominator_of_map_le`: if a finitely generated ideal is contained in another after localization, choose a denominator for each member of a finite generating set and multiply these denominators. The product clears the containment for every ideal element. `exists_principal_neighborhood`: applying this to a principal ideal gives a single denominator whose inversion makes the original ideal principal, in any algebra in which that denominator is invertible.

This is the elementary finite-generation argument needed to spread a stalk equation in the construction of Stacks Project tag 0AGA. The external implementation `DICT.exists_not_mem_forall_map_eq_span` in the registered source `anthropic-flt-complete-lean-source-6e837e75`, file `P2M/Sol/S_AlgebraicGeometry_Scheme_IdealSheafData_isInvertible_of_forall_exists_map_ideal_eq_span_singleton_of_mem_nonZeroDivisors.lean`, suggested this route. The proof here is rewritten for an arbitrary multiplicative set and uses Mathlib's ideal-membership criterion and a colon ideal for denominator clearing; it imports no external implementation or definitions.
