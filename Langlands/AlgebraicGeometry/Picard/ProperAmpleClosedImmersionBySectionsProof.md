# Proof: projective embeddings by sections from properness and ampleness

Authors: Worker 5705.

The module `Langlands.AlgebraicGeometry.Picard.ProperAmpleClosedImmersionBySectionsProof`
proves

```lean
theorem properAmpleClosedImmersionBySections :
    ProperAmpleClosedImmersionBySectionsStatement.{u}
```

Let `R` be a noetherian ring, `f : X ⟶ Spec R` proper, and `L` a line bundle on `X` that is
ample in the Library sense (`LineBundle.IsAmple`). The proof builds sections `σ_0, …, σ_N` of a
single tensor power `M` of `L`, takes the morphism `X → ℙᴺ_R` that they define, and shows that
this morphism is a closed immersion. The Library equivalence
`exists_closedImmersionBySections_iff_isHProjective` (in the statement's module) then gives the
required invertible module and presentation. The statement's Markdown cites the Stacks
Project; Task 5904 supplies EGA and Hartshorne references for this classical argument
(EGA II 4.5.2 and 4.5.10; Hartshorne II.7.6). The implemented
details follow. Auxiliary declarations live in the namespace
`Langlands.AlgebraicGeometry.Picard.ProperAmpleClosedImmersionBySections`.

## Auxiliary lemmas

- `frame_of_trivializesOn`, `le_trivializationOpen_of_frame`: for a section `s` of a module
  `M`, the condition "`g ↦ g • s|_W` is bijective for every open `W ⊆ V`" (the `frame` field of
  the FLT `Scheme.Modules.ProjPresentation`) is equivalent to `TrivializesOn M s V`, by the
  Library's `LineBundleDescent.trivializesOn_iff_bijective` and `sectionHom_app`. In
  particular, an open where `s` is a frame lies in the generation open `trivializationOpen M s`
  (which is the supremum of all opens where `s` trivializes `M`).
- `exists_clear_of_le`: suppose a global section `a₀` of `L^{m₀}` satisfies
  `a₀|_T = r • (s^{m₀})|_T`. Then for every `m ≥ m₀` there is a global section `a` of `L^m` with
  `a|_T = r • (s^m)|_T`. The proof is induction on `m` (`Nat.le_induction`): multiply by `s`
  using `SectionClearing.sectionMul` (from the Library's clearing proof), whose value on `s^m`
  is `s^{m+1}` (`sectionMul_app_sectionPow`). Restriction commutes with module morphisms
  (`SectionClearing.hom_app_map`), and module morphisms are linear (`Hom.app_smul`).
- `isClosedImmersion_of_restrict`: let `g : X ⟶ Y` have closed range, and let `D i` be opens of
  `Y` whose union contains the range. If every `g ∣_ D i` is a closed immersion, then `g` is a
  closed immersion. Being a closed immersion is local on the target
  (`IsZariskiLocalAtTarget.of_iSup_eq_top`), and the opens `D i` together with the complement of
  the range cover `Y`. Over the complement, the preimage is empty, and a morphism from the empty
  scheme is a closed immersion (Mathlib instance).
- `isClosedImmersion_restrict_chart`: let `𝔓 : M.ProjPresentation f N` and `t : Fin (N + 1)`.
  Let `P = 𝔓.toProj ⁻¹ᵁ D₊(X t)` be affine, and suppose every function on `P` lies in the
  subring generated by the image of `Γ(Spec R)` under `f` and by the functions `r` with
  `σ_j|_P = r • σ_t|_P` for some `j`. Then `𝔓.toProj ∣_ D₊(X t)` is a closed immersion. The
  map `χ = 𝔓.toProj.app D₊(X t)` hits the image of the base, because `𝔓.toProj ≫ π = f`
  (`Scheme.Hom.comp_appLE`, `map_appLE`, `app_eq_appLE`). It hits each such `r`: by the field
  `app_ratio_smul`, `χ(X_j/X_t) • σ_t|_P = σ_j|_P = r • σ_t|_P`, and the frame property of
  `σ_t` on `P` is injective, so `χ(X_j/X_t) = r`. Hence `χ` is surjective. Both `P` and
  `D₊(X t)` are affine (`Proj.isAffineOpen_basicOpen`), so
  `IsClosedImmersion.of_surjective_of_isAffine` applies. Here `morphismRestrict_appTop` and
  `surjective_app_comp_eqToHom` identify the map on global sections with `χ`, up to restriction
  along an equality of opens.
- `exists_generators`: on an affine open `T` of `X`, `f.appLE ⊤ T` is of finite type, because
  `f` is locally of finite type (`HasRingHomProperty.appLE`). So there is a finite set `G` of
  functions on `T` such that every function lies in the subring generated by the image of the
  base and `G` (`Algebra.adjoin_eq_ring_closure`).

## Assembly

`exists_closedImmersionBySections_of_sections` takes the following data and hypotheses.

- Data: a module `M`, sections `σ : Fin (N + 1) → Γ(M, ⊤)`, indices `base i` and opens `T i`
  with `trivializationOpen M (σ (base i)) = T i`.
- Hypotheses: the `T i` cover `X` and are affine, and the functions on each `T i` are generated
  by the base and by the ratios `r` with `σ_j|_{T i} = r • σ_{base i}|_{T i}`.

Its conclusion is the target's conclusion. The proof:

1. The generation opens `U t = trivializationOpen M (σ t)` cover `X`, and each `σ t` is a frame
   on `U t` (`trivializesOn_trivializationOpen`). The FLT theorem
   `Scheme.Modules.exists_projPresentation_of_iSup_eq_top` gives `𝔓` with `𝔓.σ = σ` and
   `U t ≤ 𝔓.toProj ⁻¹ᵁ D₊(X t)`.
2. Conversely, `𝔓.frame` makes `σ t` a frame on `𝔓.toProj ⁻¹ᵁ D₊(X t)`, so this preimage lies
   in `U t` (`le_trivializationOpen_of_frame`). Hence `𝔓.toProj ⁻¹ᵁ D₊(X (base i)) = T i`.
3. By `isClosedImmersion_restrict_chart`, `𝔓.toProj ∣_ D₊(X (base i))` is a closed immersion
   for every `i`.
4. `f = 𝔓.toProj ≫ π` is proper, hence universally closed, and `π` is separated (the Library
   instance `projectiveSpaceToSpec_isProper`). So `𝔓.toProj` is universally closed
   (`UniversallyClosed.of_comp_of_isSeparated`) and has closed range. The opens
   `D₊(X (base i))` contain the range, since the `T i` cover `X`. So `isClosedImmersion_of_restrict`
   shows that `𝔓.toProj` is a closed immersion.
5. Thus `f` is H-projective (`⟨N, 𝔓.toProj, _, 𝔓.toProj_π⟩`), and
   `exists_closedImmersionBySections_iff_isHProjective` concludes.

## The main proof

Fix `R`, `f` and an ample `L`. `X` is quasi-compact (`IsAmple.compactSpace`) and quasi-separated
(`quasiSeparatedSpace_of_quasiSeparated f`, since `f` is separated and `Spec R` is affine).

1. `LineBundle.IsAmple.finiteAffinePowerSectionCover` gives a degree `d > 0` and sections
   `s_0, …, s_n` of `L^d` whose generation opens `T i` are affine and cover `X`. Let `L'` be the
   line bundle `L^d` (`tensorPow_isLocallyFreeRankOne`).
2. For each `i`, `exists_generators` gives a finite set `G i` of functions on `T i`.
3. For each `r ∈ G i`, the Library's clearing theorem `lineBundleSectionClearing` gives `m₀` and
   a global section `a₀` of `L'^{m₀}` with `a₀|_{T i} = r • (s_i^{m₀})|_{T i}`. Let `m` be one
   more than the maximum of these exponents, so `m > 0`. Then `exists_clear_of_le` gives sections
   `a_{i,r}` of `M = L'^m` with `a_{i,r}|_{T i} = r • (s_i^m)|_{T i}`.
4. The finite index type `Σ i, Option (G i)` has cardinality `N + 1` and is enumerated by
   `Fin (N + 1)`. Its entries are the sections `s_i^m` (index `⟨i, none⟩`) and `a_{i,r}`
   (index `⟨i, some r⟩`).
5. The assembly applies with `base i = ⟨i, none⟩`. The generation open of `s_i^m` is `T i`
   (`trivializationOpen_sectionPow`, since `m > 0`). Each generator `r ∈ G i` is a ratio, via
   the index `⟨i, some r⟩`.

The proof uses only the axioms `propext`, `Classical.choice` and `Quot.sound`.
