# Ramification index one and the normalized residue fibre

`localizedQuotientEquivResidue_of_ramificationIdx_eq_one` compares the
localization at a prime over the closed point, modulo the extended base
maximal ideal, with the residue field of that localization. The
ramification index is the module length of the localized quotient.
Length one makes that module simple, so the extended ideal is maximal
and equals the local maximal ideal.

For an algebra over a DVR, if every maximal ideal contains the base
uniformizer and has ramification index one, the same argument shows
that the uniformizer generates the maximal ideal in each maximal
localization. The principal quotient is reduced, and the residue
tensor is isomorphic to that quotient.

This is a derived local calculation for the generic-point criterion
in Conrad's appendix to Prasad–Yu, *On quasi-reductive group schemes*,
author preprint, Remark A.7 on printed and PDF p. 30. The registered
source is `prasad-yu-2006-quasi-reductive-author-preprint`, SHA-256
`138d931a21fa522d97449c77acf429918826b1ef649be940d4721d616a1fc73b`.
