# Local finite type from factorizations through finitely generated subalgebras

Author: Worker 3643.

Module `Langlands.AlgebraicGeometry.SubalgebraFactorizationFiniteType` proves an
elementary sufficient criterion for local finite type, derived internally: a scheme `P`
over `Spec R` is locally of finite type as soon as every morphism from the spectrum of an
`R`-algebra into `P` factors through the spectrum of a finitely generated subalgebra. Only the existence of such
factorizations is assumed; no uniqueness or filtered-colimit statement is needed. The
results are internal helpers with no further external input. They use the affine test
objects `affineBase R C` (the slice object `Spec C → Spec R`), the canonical arrows
`affineSubalgebraMap C₁ : Spec C → Spec C₁` and the stage maps
`affineAlgebraStageMap (h : C₁ ≤ C₂) : Spec C₂ → Spec C₁` from the Library modules
`Picard.AffineFamilyDescent` and `Picard.AffineIsomColimit`.

## `exists_subalgebra_comap_mem_of_isOpen`

Let `B` be an `R`-algebra, `B₁ ⊆ B` a finitely generated `R`-subalgebra and `U` an open
subset of `Spec B₁` containing the image of `Spec B`. Then there is a finitely generated
subalgebra `B₂` with `B₁ ≤ B₂ ≤ B` such that the image of `Spec B₂` in `Spec B₁` lies in `U`.

Proof. Write the closed complement of `U` as the zero locus of an ideal `I ⊆ B₁`. Since no
prime of `B` contracts into `V(I)`, the extended ideal `I B` is the unit ideal (otherwise a
maximal ideal containing it would give such a prime). Hence `1 = Σ_{t ∈ T} c_t t` for a
finite set `T ⊆ I B` of images of elements `x_t ∈ I` and coefficients `c_t ∈ B`. Let `B₂` be
generated by `B₁` and the finitely many `c_t`. If a prime `p` of `B₂` contracted into `V(I)`,
then every `x_t` would lie in `p`, so `1 = Σ c_t x_t ∈ p`, which is impossible.

## `exists_affineAlgebraStageMap_range_subset`

The same statement for the scheme maps: if an open `U` of `(affineBase R B₁).left` contains
the range of `(affineSubalgebraMap B₁).left`, then some finitely generated `B₂ ≥ B₁` has the
range of `(affineAlgebraStageMap hle).left` inside `U`. The underlying maps of these Spec
morphisms are `PrimeSpectrum.comap` of the inclusions, so this is the previous lemma.

## `finiteType_preimage_of_subalgebraFactorization`

Hypothesis `H`: for every `R`-algebra `C` in universe `u` and every arrow
`x : affineBase R C ⟶ P` in `Over (Spec R)`, there are a finitely generated subalgebra `C₁`
and `y : affineBase R C₁ ⟶ P` with `affineSubalgebraMap C₁ ≫ y = x`.

Conclusion: for every ring `C` and every open immersion `j : Spec C ⟶ P.left`, the ring map
`φ = Spec.preimage (j ≫ P.hom) : R → C` is of finite type.

Proof. Make `C` an `R`-algebra through `φ`; then `j` is an arrow `x : affineBase R C ⟶ P`.
Apply `H` to get `C₁` and `y`. The preimage `U` under `y` of the open image of `j` contains
the range of `Spec C → Spec C₁`; by the previous lemma some finitely generated `C₂ ≥ C₁` maps
into `U`. Then `y₂ = (stage map ≫ y).left` factors through `j` as `g : Spec C₂ ⟶ Spec C`
(`IsOpenImmersion.lift`). Since `j` is a monomorphism and
`Spec C → Spec C₂ → Spec C₁ → P` equals `x`, the composite `Spec C → Spec C₂ → Spec C` is the
identity. Writing `g = Spec.map ψ`, the composite `C → C₂ → C` of `ψ` and the inclusion is the
identity, so every element of `C` lies in `C₂`. Thus `C₂ = ⊤` is finitely generated, which
is `Algebra.FiniteType R C`, i.e. `φ` is of finite type.

## `locallyOfFiniteType_of_subalgebraFactorization`

Under hypothesis `H`, `P.hom` is locally of finite type. The proof covers `P.left` by its
chosen affine open cover `P.left.affineOpenCover`; for each member `j : Spec Cᵢ ⟶ P.left`,
`j ≫ P.hom = Spec.map φᵢ` with `φᵢ` of finite type by the previous lemma, so
`HasRingHomProperty.Spec_iff` gives local finite type of `j ≫ P.hom`, and
`IsZariskiLocalAtSource.of_openCover` concludes. The locality instance is supplied
explicitly as `HasRingHomProperty.instIsZariskiLocalAtSource`.

## `locallyOfFinitePresentation_of_subalgebraFactorization`

If moreover `R` is noetherian, `P.hom` is locally of finite presentation. This follows from
the previous theorem and Mathlib's instance that a morphism locally of finite type to a
locally noetherian scheme (here `Spec R`) is locally of finite presentation.
