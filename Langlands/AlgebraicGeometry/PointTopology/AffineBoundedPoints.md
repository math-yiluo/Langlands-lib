# Bounded sets of algebra points

Author: Worker 105.

This module contains elementary lemmas used for the total disconnectedness part of
Proposition 5.4 of Brian Conrad, *Weil and Grothendieck approaches to adelic points*
(December 31, 2011), printed p.15 (source `conrad-2011-weil-grothendieck-adelic-points`,
SHA-256 `fe4a9193aff4ef575665b40971f3da32f850a74d87b3f2d0fa28bba26b9cbabb`). All are proved
in Lean.

- `mem_closure_of_isPushout`: in a pushout square of commutative rings, the pushout is
  generated as a ring by the images of its two legs. The subring generated by the images
  receives compatible maps from the two legs. The universal property gives a map from the
  pushout to it, and that map is a section of the inclusion.
- `bounded_of_mem_closure`, `bounded_of_adjoin_eq_top`: for a set `T` of `K`-algebra maps
  `A → K`, if every element of a generating set is bounded on `T`, then every element of
  the generated subring, respectively of `A` when the set generates `A` as a
  `K`-algebra, is bounded on `T`. The proof is induction on the generation.
- `exists_isClopen_bounded`: over an ultrametric field `K`, let `A` be a finitely generated
  `K`-algebra and `u` a `K`-point of `A` (Library topology on `AlgPoint`: pointwise
  convergence). Then every neighbourhood of `u` contains a clopen neighbourhood `B` on
  which every element of `A` is bounded. Take `B` to be the set of points `φ` with
  `‖φ(i) - u(i)‖ ≤ ε_i / 2` for the finitely many coordinates `i` of a basic neighbourhood,
  and `‖φ(g) - u(g)‖ ≤ 1` for a finite generating set. Closed balls in an ultrametric field
  are open, so `B` is clopen. The generators are bounded on `B`, hence so is all of `A`.
