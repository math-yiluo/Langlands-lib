# Integer polynomial charts in characteristic zero

`IntegerPolynomialChartStatement.{u}` asserts that every characteristic-zero
domain `A : Type u` of finite type over the integers has the following
property. At each maximal ideal `q` of `A`, there is a natural number `n`
and an injective integer algebra map
`f : MvPolynomial (Fin n) ℤ →ₐ[ℤ] A` for which `A` is quasi-finite at `q`
over the polynomial ring. The last condition uses the algebra structure
induced by `f`; it is Mathlib's `Algebra.QuasiFiniteAt` condition.

This auxiliary statement is an internal deduction from field Noether
normalization and standard commutative algebra. The integers are a Jacobson
ring, so the residue field at `q` is finite over the integers. The
contraction `m` of `q` is therefore a nonzero maximal ideal of the integers,
generated by an integer `r`. Apply field Noether normalization to the
nontrivial closed fibre `A / mA` over `ℤ / m` and lift its polynomial
variables to `A`. The kernel of the lifted map lies in the principal ideal
generated by the constant polynomial `r`. Successive division in the
kernel, followed by Krull intersection, proves injectivity. The closed
fibre is module-finite over the lifted polynomial ring, which gives
quasi-finiteness at `q`.

The statement does not assert module finiteness of `A` over this polynomial
ring, or finite normalization of `A`. It is an intermediate chart assertion
for the separate integer finite-type normalization target. This file
supplies the proposition only.
