# Universality of the constructed relative derivation: proof

Module `Langlands.AlgebraicGeometry.PresheafRelativeDifferentialsUniversalProof`,
namespace `Langlands.PresheafDifferentials`.

This module proves the Library statement
`Langlands.PresheafDifferentials.DerivationUniversalStatement`
(module `Langlands.AlgebraicGeometry.PresheafRelativeDifferentialsStatement`).

## Result

```lean
theorem derivationUniversalStatement : DerivationUniversalStatement φ
```

The parameters are the same as those of the statement, in the same order:
categories `C : Type u₁` (`[Category.{v₁} C]`) and `D : Type u₂`
(`[Category.{v₂} D]`), with no smallness assumption; implicit
`S : Cᵒᵖ ⥤ CommRingCat.{u}`, `F : C ⥤ D` and `R : Dᵒᵖ ⥤ CommRingCat.{u}`; and the
explicit morphism `φ : S ⟶ F.op ⋙ R`. So for every such `φ`, the explicit
derivation `derivation φ : (relativeDifferentials φ).Derivation φ` has Mathlib's
universal structure `PresheafOfModulesOfCommRing.Derivation.Universal`, with
test presheaves of `R`-modules in universe `u`. The proof uses only the axioms
`propext`, `Classical.choice` and `Quot.sound`.

The module also contains the supporting definition

```lean
noncomputable def derivationUniversal : (derivation φ).Universal
```

which is the universal structure itself; the theorem is `⟨derivationUniversal φ⟩`.

## Proof

Write `ι := pullbackRingι φ : pullbackRing φ ⟶ R` for the inclusion of the
presheaf of subrings generated by the restrictions of the image of `φ`, and
`U := DifferentialsConstruction.isUniversal' ι` for Mathlib's proof that the
identity-functor derivation `DifferentialsConstruction.derivation' ι` is
universal. By definition (module
`Langlands.AlgebraicGeometry.PresheafRelativeDifferentials`),
`relativeDifferentials φ` is `DifferentialsConstruction.relativeDifferentials' ι`
and `derivation φ` is `ofPullbackDerivation (DifferentialsConstruction.derivation' ι)`.

The conversions `toPullbackDerivation` and `ofPullbackDerivation` between
`φ`-derivations and `ι`-derivations keep the underlying additive maps. Hence:

- they are mutually inverse definitionally (`derivationEquiv` has `rfl`
  inverse laws);
- they commute with `Derivation.postcomp` definitionally
  (`toPullbackDerivation_postcomp`, `ofPullbackDerivation_postcomp` are `rfl`).

The three fields of `derivationUniversal` are transported from `U`:

- `desc`: for a `φ`-derivation `d' : M'.Derivation φ`, take
  `U.desc (toPullbackDerivation d') : relativeDifferentials φ ⟶ M'`.
- `fac`: `U.fac (toPullbackDerivation d')` says
  `(derivation' ι).postcomp (desc d') = toPullbackDerivation d'`. Applying
  `ofPullbackDerivation` to both sides (`congrArg`) gives
  `(derivation φ).postcomp (desc d') = d'`, since both sides agree with the
  required ones definitionally.
- `postcomp_injective`: if `(derivation φ).postcomp α = (derivation φ).postcomp β`,
  applying `toPullbackDerivation` (`congrArg`) gives
  `(derivation' ι).postcomp α = (derivation' ι).postcomp β` definitionally, and
  `U.postcomp_injective` gives `α = β`.

No further mathematical input is needed: the vanishing of a `φ`-derivation on
the subrings `pullbackSubring φ Y` (lemma `derivation_eq_zero_of_mem`) was
already used to build `toPullbackDerivation`.

## Provenance

The statement is internal infrastructure derived from the Stacks Project,
Section 17.28 (tag 08RL), Lemma 17.28.2 and Definition 17.28.3; see the
statement's Markdown for the source details. This proof follows the reduction
to the identity-functor case outlined in the header of Mathlib's
`Mathlib/Algebra/Category/ModuleCat/Differentials/Presheaf.lean` and reuses
Mathlib's `DifferentialsConstruction.isUniversal'`; it does not follow a proof
from the literature. It says nothing about sheaves or sheafification.
