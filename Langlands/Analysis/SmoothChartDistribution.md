# Distribution transport to a smooth chart

A test in the chart is pulled back by the inverse chart and included in the ambient test space. The inclusion retains the transported function when the chart target lies in the ambient open set. If the ambient distribution vanishes on a set containing the chart image of a test's support, it vanishes on that transported test. The support bound for smooth pullback gives this comparison.

This is the support transport needed in the lower Bruhat cell argument.
