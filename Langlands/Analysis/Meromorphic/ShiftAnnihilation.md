# Meromorphic continuation of finite shift annihilators

`MeromorphicShiftAnnihilationStatement` considers a scalar family on an
arbitrary set of evaluation points. Each finite product is composed of
shifts minus scalar coefficients. If some product from a countable sequence
annihilates the family at every parameter in an open patch, one product
annihilates it throughout the common holomorphy domain. The choice can vary
with the parameter in the hypothesis.

Finite shifts preserve scalar meromorphy at each evaluation point. On the
part of the initial patch in the holomorphy domain, the zero set of each
product is closed, since it is the intersection of the evaluation zero sets.
Baire's theorem selects a product that vanishes on a nonempty open subset.
Scalar meromorphic uniqueness propagates that vanishing on the common domain.

This is an internal analytic input for continuing moving cuspidal exponent
constraints from the convergent region of the Eisenstein series.
