# Cutoffs of locally smooth fields

Choose an open neighborhood of the compact set whose closure lies in the field's smooth domain. The smooth cutoff is one on the compact and has support in this neighborhood. Its product with the field is smooth on the domain, and it vanishes locally at every point off the domain.

This derived use of the smooth Urysohn lemma allows the operators in the slice-distribution argument to use globally smooth fields on a fixed compact support.
