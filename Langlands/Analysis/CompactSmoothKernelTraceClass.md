# Trace class for compact kernels with a smooth extension

A continuous kernel on a second-countable compact space with a finite Borel measure yields a trace-class L² endomorphism if it is the restriction of a smooth function of real normed coordinates, with finite-dimensional output coordinates. The compact output coordinate image fits inside a box. The scaled real parts of circle coordinates cover the box. The coordinatewise arccosine construction gives a continuous section on the box.

The smooth real-angle lift gives jointly continuous iterated angular derivatives of each torus slice. Compactness bounds finitely many such derivatives uniformly across the slices. The existing Fourier kernel factorization and the continuous kernel trace-class criterion then give the result.

This is an internal result for the smoothing operators of the real compact-picture representation in Task 7534.
