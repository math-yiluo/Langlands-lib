# Differentiating a functional of a smooth test family

For a smooth family with a common compact support,
write the difference from its value at parameter zero as
the parameter times the average of its parameter
derivative along the intervening interval. The average is
jointly smooth by compact integration. Its value at zero
is the parameter derivative, and its value at any other
parameter is the usual difference quotient. These
identities give the same compact support for the average.

The average is therefore continuous in the fixed-support
test topology. Applying a continuous linear functional
to it gives the limit of the scalar difference quotients.
This identifies the derivative with the functional
applied to the parameter derivative of the test. The
result supplies the differentiation step for upper-root
covariance in Shalika (1974), Proposition 2.10.
