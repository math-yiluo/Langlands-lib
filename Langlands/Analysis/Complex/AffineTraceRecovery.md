# Recovering the ordinary traces at arbitrary parameters

A function of an adjoining parameter and a spectral variable agrees
with two ordinary traces in this statement. The primal agreement holds
on one nonempty open set of adjoining parameters and a spectral right
half-plane. The dual agreement holds on a second nonempty open set of
adjoining parameters and uses the reflected spectral argument `1 − s`.

For a requested adjoining parameter, the proof chooses a disk containing
it and a point of the relevant open set. It chooses the spectral real
part large enough for the ordinary trace to be holomorphic throughout
that disk. For this fixed spectral value the one-variable identity
theorem extends the agreement to the requested adjoining parameter.
The same argument for the second trace and the maximum of the resulting
abscissas give both equalities on one right half-plane.

This is an internal trace-identification step for analytic continuation
in the adjoining parameter in Jacquet, *Archimedean Rankin–Selberg
integrals* (2009), §8.2, pp. 55–56. Holomorphy of the continued function
along complex curves and the two chamber agreements are its inputs.
