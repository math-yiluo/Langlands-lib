# Rapid polynomial approximation in real coordinates

`Langlands.Analysis.SmoothCoordinatePolynomialApproximationStatement` concerns a real smooth function with values in the complex numbers on `(J → ℝ) × Y`, where `J` is finite and `Y` is a real normed space. Fix a positive real `r` and a compact subset `S` of `Y`. For every natural exponent `q` there are polynomials `P m y` in the real coordinates, with complex coefficients and total degree at most `card J * m`. On the box given by `|x j| ≤ r` for all `j` and the parameter set `y ∈ S`, the error is bounded by `C / (m + 1)^q`, with the same constant for the entire box and parameter set. The index and parameter universes are independent.

This is a derived consequence of Fourier inversion and rapid Fourier decay on a product of circles. Pull back the real variables through `x j = r cos θⱼ`. The resulting function is even in each angle and its angle derivatives have bounds uniform over the compact parameter set. Fourier truncation to `|a j| ≤ m` can be written using products of cosines by averaging under independent changes of sign of the angles. Each `cos(a j θⱼ)` is a Chebyshev polynomial of degree `|a j|` in `cos θⱼ`. Absolute Fourier decay bounds the truncation error at any prescribed power of `m + 1`.
