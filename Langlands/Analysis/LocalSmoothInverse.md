# Smooth inverse on an open chart

Mathlib's inverse function theorem supplies an open partial homeomorphism at a point where the derivative of a smooth real map is an equivalence. The set of positions with invertible derivative is open because the derivative is continuous and the continuous linear equivalences form an open subset of the operator space. Restricting the chart to this set makes its inverse smooth at every point of its open target.

This auxiliary result is derived from Mathlib's inverse function theorem and the openness of invertible operators. It supplies open charts for the distribution argument in Shalika's Proposition 2.10.
