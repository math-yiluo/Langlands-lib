# Distributional traces of weakly continuous trace-class test operators

Let a real-linear family assign a trace-class operator on a complex Hilbert
space to each real smooth test function on an open subset of a real normed
space. Assume that, for every fixed Hilbert vector, its diagonal matrix
coefficient is continuous in the test function. The operator trace then
defines a complex-valued distribution.

On each fixed compact support, the sums of diagonal coefficients over
finite subsets of a Hilbert basis are continuous linear maps. For each
test function their norms are bounded by its absolutely summable diagonal
series. The fixed-support test space is Baire, so Banach–Steinhaus gives
equicontinuity of these finite sums. The net of sums converges pointwise to
the basis-independent trace, giving continuity on that fixed-support space.
The universal property of the test function topology and linearity of
the trace give the distribution on the open set.

This internal construction uses the Library's trace laws and the Baire
property of smooth fixed-support test spaces.
