# Almost-everywhere equality and actual normalized quotient periods

`Langlands.QuotientIntegration.QuotientPeriodAEEqStatement` is an internal
representative-independence target for the existing actual quotient character
period. The ambient group is locally compact Hausdorff, second countable and
Borel with a left Haar measure and a discrete subgroup. The quotient measure
is exactly the existing restricted-pushforward discrete quotient measure.

For an independently sized locally compact Hausdorff second-countable Borel
period group, a discrete period subgroup, a compact-finite period measure,
a continuous group homomorphism mapping period subgroup elements into the
ambient subgroup, and a continuous complex-units character trivial on the
period subgroup, consider two specified strongly measurable quotient functions
that agree almost everywhere for that actual ambient quotient measure.

For Haar-almost every ambient translation, their actual period integrands
agree almost everywhere on the period quotient with its existing canonical
normalized measure. Consequently their periods converge absolutely together
and their total Bochner periods agree. Convergence is compared separately; it
is not inferred from equality of totalized integrals. Neither function is
assumed L2 or globally integrable. The period quotient need not be compact,
its canonical domain need not have finite or positive mass, and the period
measure need not be invariant. No unitary character or normal subgroup is
required. These additional assumptions are unnecessary for this congruence.

The derivation first lifts a quotient null set through countably many translated
fundamental domains to a Haar null set upstairs. Left Haar invariance preserves
it under every period-group translation. Measurable almost-everywhere Fubini
interchanges the period parameter and ambient group, and the actual normalized
restricted pushforward descends the resulting domain equality.

This internal result supplies the representative comparison needed when
transporting the compact-period analysis of Getz–Hahn, Section9.2 (printed
pp.243–246), along an actual measure-preserving quotient identification.
The registered October2026 errata's compact period quotient convention is
retained. It proves neither compact-period L2 convergence nor cuspidal
closedness, and it does not replace an almost-everywhere Lp pullback equality
by pointwise equality.
