# Integrated actions in a compact picture

A compact profile extends to the ambient group through a continuous compact factor and a continuous scalar weight. A compactly supported continuous test and an ambient Borel measure finite on compact sets give a continuous kernel by Bochner integration. The integrand has common compact support in the ambient integration variable. For the operator formula, the ambient measure is s-finite and right invariant, and the second-countable compact group has a left-invariant Borel probability measure. If the compact factor is equivariant for right translations and the weight is invariant, averaging and Fubini rewrite the integrated profile using this kernel.

This internal result provides the compact-picture operator kernel used to study real principal series smoothing in Task 7534.
