# Local vanishing of a distribution

Choose a finite subcover of the support of the test from open sets where the distribution vanishes. A smooth partition of unity subordinate to this cover expresses the test as a finite sum. Multiplication keeps each summand supported in the corresponding open set and preserves the test's compact support. Applying the linear functional to the sum proves vanishing.

This derived support lemma combines the local vanishing statements in the Bruhat filtration.
