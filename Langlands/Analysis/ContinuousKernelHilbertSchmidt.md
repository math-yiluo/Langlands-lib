# Continuous compact kernels as Hilbert–Schmidt operators

A continuous scalar kernel on the product of two compact spaces defines a bounded map from the input L² space for a finite Borel measure to continuous output profiles. The conjugate of a kernel row represents evaluation of the output by an L² inner product. Its L² norm has a bound uniform over the output parameter. Composing the profile map with the inclusion into output L² for a finite Borel measure meets the uniform evaluation criterion for a Hilbert–Schmidt operator.

This is an internal analytic result for the integrated compact-picture operators in Task 7534, derived from the Library's Hilbert–Schmidt evaluation criterion.
