# A primitive in one normal coordinate

Integrate a smooth function in the last coordinate from zero to
the current coordinate. Rescaling to the fixed unit interval
writes the primitive as the last coordinate times a compact
parameter integral. The smooth compact-family theorem and bounded
integration give smoothness. Evaluation of each Fréchet derivative
of the compact family commutes with evaluation at the interval
parameter. The rescaling in the last coordinate preserves the
zero slice, so vanishing jets of the original function give
vanishing jets of the integral. Multiplication by the last
coordinate raises the order of vanishing by one.

The fundamental theorem of calculus gives the original function
as the last-coordinate derivative of the primitive. This supplies
a test-function construction for descending a finite jet bound
in the transverse derivative argument of Shalika (1974), §2.
