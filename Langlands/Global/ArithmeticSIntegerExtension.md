# Original S-integer extension maps

This derived construction supports the integral model step in Conrad,
*Weil and Grothendieck approaches to adelic points* (2011), Example 4.2,
printed pages 9–10. It constructs the actual maps of outside-S integer rings
at the full upper exceptional preimage, and proves their intrinsic compatibility
with the original field embedding.

Both arithmetic branches preserve and reflect the outside-S integrality test.
The forward implication uses an upper place above each lower place; the reverse
implication uses exact restriction and full-preimage membership. The curve
branch uses the actual valuation-subring comap and the proved surjectivity of
restriction. The number-field branch uses the ramification formula, whose
positive exponent preserves and reflects the inequality with one, and the
existing existence of places above a finite place.

The ring homomorphisms are restrictions of the original field embedding,
are injective, and carry scoped algebra and scalar-tower instances. Their
composites into the original upper field are the literal original embedding.
The integral closure of each lower integer ring in that upper field is contained
in the corresponding upper integer ring: integrality passes to every required
upper valuation ring, which is integrally closed.

All fields inhabit an arbitrary common universe. The curve branch requires only
a finite extension with compatible constant-field algebras and scalar tower;
it needs neither separability, perfect or finite constants, nor a function-field
presentation. The number-field branch uses actual finite places and the original
rings of integers. Empty exceptional sets are allowed. This file does not prove
the reverse integral-closure inclusion, finite local freeness, or the adelic Weil
comparison; these remain obligations of the host task.
