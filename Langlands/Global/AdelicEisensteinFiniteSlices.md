# Finite parameter translations on infinite slices

A finite right translation changes the height by a displacement that is constant on each infinite slice when the compact subgroup contains the projections of its elements to the infinite factor. To see this, factor the infinite argument by Iwasawa and project the factorization to the infinite factor. The resulting parabolic point can be put on the left, and the compact factor can be put on the right because it commutes with the finite arguments. Neither changes the displacement. The exponential of the resulting parameter pairing is the constant scalar multiplying the translated slice.

This derived identity supplies fixed-carrier finite translations in the holomorphic section construction of Langlands, *On the notion of an automorphic representation* (1979), proof of Proposition 2, printed pp. 204–206, Corvallis Part I PDF pp. 199–201. The height is the one defined on the actual group-scheme points.
