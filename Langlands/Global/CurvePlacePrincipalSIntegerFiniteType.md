# Cofinal actual function-field integer levels of finite type

This derived arithmetic construction supplies an actual cofinal integer level
for a finite-constant-field function field. It is an implementation prerequisite
for the enlargement of arithmetic models used in Conrad, *Weil and Grothendieck
approaches to adelic points* (2011), Remark 3.5 on printed p.6 and the proof of
Theorem 4.5 on printed pp.12–13. It is not an additional assertion of the paper.

Let `k` be a finite field and `F` a finite extension of `RatFunc k` with the
specified compatible `k`-algebra structure, in an arbitrary common universe.
Let `S` be any finite set of actual `AlgebraicCurve.Place k F`, including the
empty set. The parameter is the image of the original rational-function `X`.
The published function-field finite-dimensionality result shows that `F` is
finite-dimensional over the intermediate field generated by that parameter.

`curvePlacePrincipalDenominator` chooses a nonzero element of its actual
normalized chart ring. The published
`exists_curvePlacePrincipalExceptional_superset` ensures that its principal
exceptional set contains `S`. That set consists of the poles of the parameter
and of the inverse denominator. `curvePlacePrincipalLevelAbove` retains this
finite exceptional set together with the containment proof, as an actual
`AdelicLevelIndexAbove S`.

The instance `curvePlacePrincipalLevelAbove_finiteType` proves
`Algebra.FiniteType ℤ` for the literal outside-set subring
`curvePlaceSIntegers k F (curvePlacePrincipalLevelAbove k F S).val`.
The published principal-level localization construction already gives finite
type over `k` for this ring. A finite field is a finite module, hence a finite
type algebra, over the integers; transitivity gives the displayed instance.
All coefficient elements remain in the original subring of `F`.

This unit neither asserts finite type for every initial level nor constructs
scheme models. Compatible smooth geometrically connected models, uniform
Lang–Weil, point lifting and local and adelic openness remain separate results.
