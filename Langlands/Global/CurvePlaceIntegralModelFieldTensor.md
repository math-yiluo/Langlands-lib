# Completed-field tensor of the original function-field integral model coefficients

This derived bridge supports the integral-model passage in Conrad, *Weil and Grothendieck approaches to adelic points* (December 31, 2011), Example 4.2, printed p.10. Fix the original compatible extension K → L of function fields over finite constants k, a given function-field presentation of K and an actual original lower curve place p. The original presentation and extension may be inseparable. Let R be p's original valuation ring and S its actual integral closure in the original upper field L. The upper index consists of all original curve places q above p.

The scoped coefficient actions on every actual upper completed field use the original maps R → L → L_q and S → L → L_q. Their scalar towers with the lower completion and upper integer ring are proved from the original completion-embedding formula and the original integral coefficient map. Low-priority coefficient algebra instances preserve the existing fraction-field actions.

`tensorMap` is the canonical K_p-algebra map from K_p tensor_R S to the product of all actual L_q. Its pure-tensor formula uses precisely the original completion embedding K_p → L_q and S → L → L_q. `tensorMap_eq_fieldComparison` identifies this map, on pure tensors and sums, with the already proved `CurvePlaceIntegralTensor.fieldComparison`: the latter is the actual localization base-change equivalence followed by the full original completed-field tensor equivalence. Its bijectivity therefore supplies `tensorEquiv` as an algebra equivalence, with the original pure-tensor and one-tensor component formulas.

This bridge retains the original valuation-ring model coefficients. It repeats no normalization, degree-sum or approximation proof and assumes none of those conclusions as a hypothesis. All rings and fields lie in an arbitrary common universe. Finite constants, the given original FunctionField presentation, the finite original upper extension and compatible constant scalar tower are required for the final equivalence, matching the reused arithmetic theorem. The coefficient maps and scalar towers themselves do not require those extra finiteness hypotheses.

This is a local algebra construction. Scheme point topology, a generic-fiber comparison, one common model outside finitely many places and the global adelic homeomorphism are not claimed here.
