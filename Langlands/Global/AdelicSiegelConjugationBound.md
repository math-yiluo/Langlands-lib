# Bounded heights of chamber conjugates of compact unipotent sets

Author: Worker 5414.

This module supplies Part B of the planned proof of
`Langlands.Global.AdelicSiegelFactors.SiegelNormMinimalityStatement` (Task 5910). Its main
theorem is a uniform height bound. Conjugating a compact set of adelic points of the
standard unipotent subgroup by the inverse of a weak simple-root chamber point has
bounded full adelic height. All declarations are in the namespace
`Langlands.Global.AdelicSiegelFactors`.

## Statements

### Chamber lower bounds

- `normCharacter_comp_add_val`: for `j : T₀ ⟶ T`, an adelic point `x` of `T₀`, and
  characters `β₁ β₂` of `T`,
  `normCharacter F T₀ (j ≫ (β₁ + β₂)) x = normCharacter F T₀ (j ≫ β₁) x * normCharacter F T₀ (j ≫ β₂) x`
  as elements of `ℝ≥0`.
- `normCharacter_comp_zero_val`: under the same hypotheses,
  `normCharacter F T₀ (j ≫ 0) x = 1`.
- `exists_le_normCharacter_of_mem_closure`: let `β` lie in the additive submonoid
  generated by `simpleRelativeRoots i ν`, and let `t : ℝ≥0ˣ`. Then some `L > 0` satisfies
  `L ≤ normCharacter F T₀ (j ≫ β) a` for every `a` in
  `PositiveRealTorus.weakSimpleRootChamber F T₀ T j G i ν t`.
- `inv_le_max_of_le_pow`: if `σ L : ℝ≥0`, `D ≠ 0`, `0 < L` and `L ≤ σ ^ D`, then
  `σ⁻¹ ≤ max 1 L⁻¹` in `ℝ`.

### Scaling adeles

- `realScaling F c` is the adele whose component at every infinite place is the real
  number `c` and whose finite component is `1`. It is
  `(PositiveRealIdeles.infiniteRealEmbedding F c, 1)`.
- `continuous_realScaling`: `realScaling F` is continuous on `ℝ`.
- `coe_full_eq_realScaling`: for `σ : ℝ≥0ˣ`, the positive real idele
  `PositiveRealIdeles.full F σ`, viewed as an adele, equals `realScaling F σ`. This holds by
  definition.

### Main theorem

`exists_adelicHeight_conj_unipotent_le` takes the following data:

- a number field `F : Type u`;
- a group scheme `G` over `Spec F` with `[IsAffineHom G.X.hom]` and
  `[LocallyOfFiniteType G.X.hom]`, and `hG : IsConnectedReductive G`;
- a setup with `IsSiegelAlgebraicSetup F G T i ν T₀ j`;
- a matrix representation `rho : MatrixRepresentation G (Fin N)` with `0 < N`;
- a compact set `Ω` of adelic points of `Standard.unipotentScheme i ν ∅`;
- a threshold `t : ℝ≥0ˣ`.

It gives a real `B` with

```
adelicHeight F G rho ((positiveMap a)⁻¹ * map (Standard.unipotentHom i ν ∅) n * positiveMap a) ≤ B
```

for every `n ∈ Ω` and every `a` in the weak simple-root chamber with threshold `t`. Here
`positiveMap a = positiveMap F G T i T₀ j a`.

## Provenance

Mœglin–Waldspurger 1995 (`moeglin-waldspurger-1995-spectral-decomposition`), I.2.2,
printed pp. 20–21, proves norm minimality on Siegel sets. One step there is that
conjugating the compact unipotent factor by the inverse of a chamber element stays in a
compact set, because the positive roots are bounded below on the chamber. This module
proves the height consequence of that step for the Library's actual Siegel setup. The
lemmas in the first two groups are auxiliary.

## Proof

### Chamber lower bounds

`restrictedNormHom j x` (module `AdelicSiegelMeasureReduction`) is an additive monoid
homomorphism from characters of `T` to `Additive ℝ≥0`. Its underlying function sends `β`
to `ofMul (normCharacter F T₀ (j ≫ β) x)`. Its `map_add` and `map_zero` give the first two
lemmas.

`exists_le_normCharacter_of_mem_closure` uses `AddSubmonoid.closure_induction`:

- For a simple relative root `β`, membership in the weak chamber gives
  `t ≤ normCharacter F T₀ (j ≫ β) a`. Take `L = t`.
- For `β = 0`, the value is `1`. Take `L = 1`.
- For a sum `β₁ + β₂`, multiply the two lower bounds, using `normCharacter_comp_add_val`.

`inv_le_max_of_le_pow` splits into two cases:

- If `1 ≤ σ`, then `σ⁻¹ ≤ 1`.
- If `σ < 1`, then `σ ^ D ≤ σ` because `D ≥ 1`. So `L ≤ σ`, and inverting gives
  `σ⁻¹ ≤ L⁻¹`.

### Main theorem

1. **Setup.** The setup gives `IsMaximalSplitTorus i` and `IsGenericCocharacter i ν`. The
   Library theorem `positiveTorusTriangularCoordinates` (module
   `GroupScheme.Rational.PositiveTorusTriangularCoordinatesProof`) then provides global
   functions `tc : Fin d → AffineCoordinateRing F U.X` on
   `U = Standard.unipotentScheme i ν ∅`. These identify the coordinate ring of `U` with
   `MvPolynomial (Fin d) F`. It also provides weights `w : Fin d → characterLattice T`
   with three properties:
   - (conjugation) if `x = i(s) · y · i(s)⁻¹` in `G(A)`, then
     `x(tc k) = χ_{w k}(s) · y(tc k)` for every `k`;
   - (positivity) every `w k` lies in `positiveRelativeRoots i ν`;
   - a triangular product formula and the multiplicity of each weight. This proof does not
     use them.

   `coordinateHomeomorph` (module `Global.PositiveTorusUnipotentModulus`) turns the
   coordinate functions into a homeomorphism `Φ₀ : U(𝔸_F) ≃ₜ (Fin d → 𝔸_F)`.

2. **Lower bounds on the weights.** By
   `positiveRelativeRoots_subset_closure_simpleRelativeRoots` (module
   `GroupScheme.Rational.PositiveRootInduction`), each `w k` lies in the additive
   submonoid generated by the simple relative roots. So
   `exists_le_normCharacter_of_mem_closure` gives `L k > 0` with
   `L k ≤ normCharacter F T₀ (j ≫ w k) a` on the chamber. Put
   `C k = max 1 (L k)⁻¹`.

3. **A compact parameter set.** Let `S (c, y) k = realScaling F (c k) * y k`. The map `S`
   is continuous. The set `K = (∏ₖ [0, C k]) × Φ₀(Ω)` is compact. The function
   `p ↦ adelicHeight F G rho (map (Standard.unipotentHom i ν ∅) (Φ₀.symm (S p)))` is
   continuous, by `continuous_adelicHeight` (module
   `AdelicRepresentationHeightPropernessProof`). So it is bounded above on `K` by some
   `B`.

4. **The conjugate in coordinates.** Fix `n ∈ Ω` and a chamber point `a`. Let `s` be the
   adelic point of `T` obtained from `a` through `j`. Then `positiveMap a` is the image of
   `s` under `i`.
   - Because `a` is an intrinsic positive point, each character value `χ_{w k}(s)` equals
     `PositiveRealIdeles.full F (σ k)` for some `σ k : ℝ≥0ˣ`. This uses
     `PositiveRealTorus.mem_intrinsicSubgroup_iff` and `Lie.characterValue_comp`.
   - `PositiveRealIdeles.absoluteValue_full` gives
     `(σ k)^[F:ℚ] = normCharacter F T₀ (j ≫ w k) a`.
   - The `T`-image normalizes the standard unipotent image, by
     `positiveMap_mem_normalizer`. So the conjugate `(positiveMap a)⁻¹ · n · positiveMap a`
     equals the image of a point `y` of `U(𝔸_F)`.
   - The conjugation formula gives `Φ₀(n)_k = full(σ k) · Φ₀(y)_k`. Hence
     `Φ₀(y) = S(c, Φ₀ n)` with `c k = (σ k)⁻¹`.

5. **The scaling factors are bounded.** Step 2 gives
   `L k ≤ (σ k)^[F:ℚ]`, and `[F:ℚ] ≥ 1`. So `inv_le_max_of_le_pow` gives
   `0 ≤ c k ≤ C k`. Therefore `(c, Φ₀ n) ∈ K`. The height of the conjugate is the value of
   the function in step 3 at `(c, Φ₀ n)`, so it is at most `B`.

The proof does not estimate polynomial entries. Compactness and the continuity of the
height replace that estimate.
