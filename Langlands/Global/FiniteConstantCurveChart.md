# Finite normalized curve charts over finite constants

This module proves finiteness, the Dedekind property and finite type for actual
normalized curve charts over a finite constant field. It identifies all
nonzero chart primes with all original discrete curve places integral on that
chart. The parameter and reciprocal charts cover every actual curve place.
The chosen parameter need not give a separable field extension.

These are derived arithmetic constructions for Conrad, *Weil and
Grothendieck approaches to adelic points* (December 31, 2011), Example 4.2,
printed page 10. That passage uses the arithmetic of global field extensions
in the completed tensor decomposition and integral-model comparison.
The present unit supplies normalized function-field base charts in the
positive-characteristic case. It does not construct the tensor decomposition
or the Weil integral models.

## Actual parameter algebra and normalization

Let `k` and `F` be fields in one arbitrary common universe, with
`[Finite k]` and `[Algebra k F]`. Choose an actual `s : F` and assume
`[FiniteDimensional k⟮s⟯ F]`. Here `k⟮s⟯` is the existing intermediate
field generated by `s`, with its canonical inclusion in `F`.
There is no separability, characteristic-zero or transcendence hypothesis.
In the function-field application `s` can be the original rational-function
parameter or its inverse.

Write `A = Algebra.adjoin k {s}` for the original parameter subalgebra of
`F`, and `C = AlgebraicCurve.CurveModel.chartRing k {s}` for its existing
normalization inside `F`. The latter's elements are precisely the elements
of `F` integral over `A`. Both rings and their inclusions are existing actual
subalgebras; the module does not replace them by unrelated presentations.

All declarations are in `Langlands.Global.FiniteConstantCurveChart`.
`moduleFinite` proves `Module.Finite A C`. It uses the published

```text
Langlands.AlgebraicGeometry.NoetherianApproximation.
  finite_integralClosure_of_normal_integer_finiteType
```

from `InseparableNormalization.lean`. The parameter algebra `A` is a
principal ideal domain, hence normal and noetherian. It is of finite type
over `k`, which is finite over the integers, so it is of finite type over
the integers as required by the reused theorem. The fraction field is
the existing `k⟮s⟯`, and the extension to `F` has the given finite degree.
The theorem gives finiteness of `integralClosure A F` without separability.
`IsIntegralClosure.equiv` then transfers that module finiteness to the
actual existing chart `C`.

The published normalization theorem handles the purely inseparable part
using a bounded iterate of Frobenius and finite Frobenius on the base,
along with the separable trace argument. The present module invokes that
proved result; it does not add a separability or finite-normalization
premise.

## Fraction field, Dedekind property and finite type

The scoped instance `fractionRing` proves `IsFractionRing C F` using
`IsIntegralClosure.isFractionRing_of_finite_extension`.
The scoped instance `dedekind` derives noetherianness from `moduleFinite`,
dimension at most one from integrality over `A`, and integral closedness
from the defining integral-closure property. These are the actual
Dedekind-domain conditions, with no use of a separable parameter extension.

The scoped instance `finiteType` derives `Algebra.FiniteType k C`
from the finite-type parameter algebra and the proved finite module.
These scoped instances permit use of the existing chart ring at an
inseparable presentation without introducing a competing global instance.
The fraction-field construction itself does not need finite constants.

## Original primes and original curve places

For a valuation subring `O` of `F` containing the constants and the
parameter, the existing `CurveModel.primeOfValuationSubring` is its actual
center prime in `C`, provided `O ≠ ⊤`.
`valuationSubringAtPrime_eq` proves that localization at this actual
center prime recovers exactly `O`.

The private containment argument writes an element of the localization as
`a / b`, where `b` lies outside the center. Such `b` has valuation one,
while the numerator has valuation at most one. The localization therefore
lies in `O`. The equality then follows from the existing valuation-subring
comparison theorem and nontriviality of `O`.
This adapts the existing characteristic-zero chart argument using the
newly proved Dedekind structure.

For an actual `p : AlgebraicCurve.Place k F` with `s` integral at `p`,
`ofHeightOneSpectrum_center` states that the place of its center prime is
exactly the original `p`. Its proof compares actual valuation subrings.

`primeEquivChartPlaces` constructs

```text
HeightOneSpectrum C
  ≃ {p : AlgebraicCurve.Place k F // s ∈ p.toValuationSubring}.
```

Its forward map is the original `Place.ofHeightOneSpectrum`, as
`primeEquivChartPlaces_apply` states. Integrality of `s` follows from its
membership in the actual chart. Injectivity is the existing injectivity
of `Place.ofHeightOneSpectrum`; surjectivity is the center-prime identity
just proved. Thus every actual place on the chart is included.

## Two actual parameter charts

`adjoin_inverse_eq` proves `k⟮s⁻¹⟯ = k⟮s⟯`. This algebraic identity requires
neither finite constants nor finite dimensionality.
It supplies finite dimensionality for the reciprocal chart internally.

`twoChartsCover` states that every actual curve place is the original
place associated to a nonzero prime on the `s` chart or on the `s⁻¹`
chart. A valuation subring contains `s` or `s⁻¹`, so the theorem applies
`ofHeightOneSpectrum_center` on the appropriate chart. No extra inverse-chart
instance is required from the caller.
