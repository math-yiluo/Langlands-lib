# Equal-rank Gaussian coverage from adjacent ordinary coverage

`complexOrdinaryEqualCoverageStep` adjoins a character to the retained list of an adjacent pair. If the two resulting equal-rank lists are irreducible, pointwise adjacent coverage gives a nonzero normalized equal-rank integral with a standard polynomial Gaussian row at each spectral value.

A lower adjacent witness gives a nonzero linear functional in the larger coefficient at the chosen value. Square convolution generation gives a standard square polynomial Gaussian on whose convolution output the functional is nonzero. Split the square test into finitely many products of rectangular and row Gaussians. The polynomial convolution outputs add because the square integral is linear on a right half-plane and the output intertwiner is injective. Each separated output gives the corresponding normalized ordinary equal-rank value by the equal square trace formula. At least one value is nonzero. The continued Godement model comparison puts its first coefficient in the model for the supplied larger list. This implements the equal-rank recurrence using Jacquet's equal unfolding and square integrals. [Jacquet, *Archimedean Rankin–Selberg Integrals*, §§8.2, 9–10](https://www.math.columbia.edu/~hj/PerfectRankinSelberg.pdf)
