# Uniform Schwartz estimates for translated Godement tests

`ComplexGodementTranslatedBounds.complexGodementTranslatedBounds` controls the outer integral in Jacquet's formula (7.6) for a right-translated Schwartz test. The smaller Whittaker family is continuous in the group and has locally uniform simple-root estimates on the parameter set under consideration. The real part of the determinant exponent after the change of column variables is bounded there.

Right multiplication on the rectangular matrices and its inverse have operator norms bounded by `rightTestSize`. The chain rule and the operator norm estimate for a multilinear map give the power of this size that controls each weight and derivative order. For the transformed test, the partial Fourier weighted value estimate and the fixed changes of matrix coordinates give a continuous seminorm of the input to the transform. It is bounded by a finite supremum of standard Schwartz seminorms. The existing Godement majorant yields a pointwise bound by an integrable function of the smaller group variable times the group size power and the seminorms of the original test. Integration gives the bound for the integral. The growth order depends on the spectral bound and the smaller family estimates, and is uniform in the original Schwartz test.
