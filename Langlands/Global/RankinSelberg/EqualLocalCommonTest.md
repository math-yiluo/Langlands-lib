# Combining nonzero equal-rank local tests

A germ along the real part tending to positive infinity is zero exactly when
the integral vanishes throughout some right half-plane. Thus a nonzero germ
gives a nonzero value in every right half-plane. Absolute convergence on a
right half-plane for each input allows integral additivity on the
intersection of the two half-planes for the summand inputs. The ordinary and
dual integrals therefore give additive maps of germs in each test slot.

For two additive maps with nonzero values at inputs `x` and `y` respectively,
either an endpoint works for both or `x + y` works. In the latter case the
other endpoint maps to zero for each map. Apply this argument to the first
coefficient, then to the second coefficient with the selected first entry,
then to the Schwartz test with both selected coefficients. The final triple
has nonzero germs for both integrals.

This internal lemma uses an additive input map for each of the three slots
and each of the two integrals. This permits the dual and Fourier operators
to be part of the input maps. The two witnesses are taken for the same
quotient measure.
