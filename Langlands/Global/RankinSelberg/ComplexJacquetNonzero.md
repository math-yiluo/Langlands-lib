# Nonzero canonical complex Jacquet evaluation

The canonical Jacquet evaluation has a compact-finite standard vector with nonzero value at the group identity in every positive rank and at every inducing parameter.

In rank one, the canonical evaluation is the original section, and the determinant character has value one at the identity. For the induction step, take a smaller-rank vector with nonzero value and form its fixed compact-profile family. Its local uniform simple-root estimates and continuity give a compact full-row-rank unitary-finite test that detects this value in the continued Godement integral. Form the exact standard vector from this test and the original smaller profile. The generator evaluation theorem identifies its canonical Jacquet value with the nonzero continued Godement value.
