# Parameter holomorphy of compactly supported complex Godement sections

`ComplexGodementCompactHolomorphicStatement` proves joint holomorphy at each fixed larger group argument for the upper-Borel Godement section in (7.1). The parameter space is finite-dimensional and complex. The added character has fixed angular weight and an entire radial exponent. The smaller inducing functions are jointly continuous in the parameter and group argument and pointwise entire in the parameter. The test is continuous with compact topological support contained in the full-row-rank locus, and the smaller-group measure is locally finite.

For a fixed larger argument, `exists_compact_godementSection_support` gives one compact set of smaller group elements outside which the kernel vanishes for all parameters. The added character weight equals its value at zero radial exponent times the exponential of the radial exponent multiplied by twice the logarithm of the determinant norm. This proves joint continuity of the kernel and pointwise holomorphy in the parameter. On the product of a closed parameter ball with the compact smaller-group set, continuity bounds the kernel by a constant. The restriction of the locally finite measure to that set integrates the constant.

The dominated holomorphic integral theorem then proves holomorphy for the restricted integral. The vanishing outside the compact set identifies it with the full integral. The same determinant character calculation proves holomorphy of the exterior factor. This derives joint parameter holomorphy in the compact-support case of Jacquet, *Archimedean Rankin–Selberg integrals* (2009), §7.1, (7.1) and Proposition 7.1(iii), p. 43. The result concerns the inducing section used before applying the Jacquet integral.
