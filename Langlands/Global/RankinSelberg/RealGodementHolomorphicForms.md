# Entire linear forms from spanning sections

`RealGodementHolomorphicFormsStatement` fixes an entire family of columns in a finite-dimensional complex coordinate space, with an entire scalar value assigned to each column. At each parameter, some square subfamily must have nonzero determinant. If the assignments arise from linear forms throughout one neighborhood, they arise from a family of linear forms at all parameters. Its evaluation on each fixed vector is entire.

The proof chooses a basis at each parameter and defines a form using the adjugate divided by the determinant. The analytic relation theorem compares this choice with each supplied column. It follows that the chosen form realizes all assigned values. Near any fixed parameter the basis used there remains a basis. In that neighborhood the form computed in that fixed basis agrees with every pointwise choice, since they agree on the basis columns. Cramer's rule gives the required differentiability of the fixed-basis formula.

This is an internal lemma for the finite compact-type argument behind Jacquet, *Archimedean Rankin–Selberg Integrals* (2009), §7.1, Proposition 7.1(v), and §7.2, pp. 46–48. Its hypotheses ask for the actual entire coordinates and spanning property. In the intended application the scalar assignments are leading-exponent Jacquet values of Godement sections.
