# Split test arguments under leading determinant normalization

Right multiplication by an invertible leading block rescales the leading square matrix in the stacked test. The same formula holds on the inverse-transpose side. The first tail column and the last inverse row stay fixed. The earlier triangular Fourier inputs are supported in the tail, so the extra inverse-transpose leading block acts as the identity on them.

The proof uses the four consecutive blocks of the rank inclusion. It computes its effect on a stacked column and on a column supported in the tail. Applying that calculation to the earlier Fourier columns proves equality of the full triangular Fourier factors.
