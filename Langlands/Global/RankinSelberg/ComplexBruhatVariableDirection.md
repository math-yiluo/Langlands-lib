# Variable directions in the complex Bruhat chart equation

The infinitesimal equations for fixed strictly upper matrices imply a corresponding equation for a smoothly varying strictly upper matrix. The resulting test operator includes the same field, inducing scalar and Whittaker frequency at the current point, with one additional smooth real scalar.

The proof expands the variable matrix in real and imaginary elementary matrices. For each fixed direction it applies the distribution equation to the test multiplied by the corresponding real coefficient. The sum of these identities is zero. The product rule gives the directional derivative of each real coefficient in the additional scalar, while real linearity in the matrix direction combines all the remaining terms.
