# Simultaneous density after a genuine right translation

Fix a smooth general linear group function, a group element g, and a
compact difference order. Extend the function smoothly with compact
matrix support on the compact set of values `k₁ g k₂` for unitary `k₁`
and `k₂`. The difference caused by an additional right compact move is
then a smooth matrix right difference pulled back by the linear map of
right multiplication by g. The one-move derivative estimate, the
iterated chain rule for this linear map, and the matrix derivative bound
for compact differences control the translated profile difference by a
uniform constant times the move's displacement.

For a smooth standard section, a central polynomial average is a
compact-finite standard vector on the full group. Use a nonnegative
weight of mass one and small first displacement moment. At identity the
compact convolution error estimate controls the profile difference.
After translation by g the error is the average of the profile
differences estimated above. Iterated right differences commute with
that integral by linearity and integrability on the compact group.
The same first displacement moment controls both errors, giving a
single approximant before and after the fixed translation.
