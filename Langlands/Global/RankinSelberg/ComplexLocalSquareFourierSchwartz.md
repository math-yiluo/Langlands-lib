# Continuous square Fourier transformation

Jacquet’s equal-rank unfolding in §8.2 uses a square matrix Schwartz test and a Fourier transform with the self-dual trace measure. This internal comparison realizes the Library’s positive trace convention by a continuous complex-linear map on the square Schwartz space.

The map flattens the matrix into its entries, uses the real Euclidean Fourier transform with the frequency change for the negative of the trace parameter, and restores the matrix coordinates. The finite-coordinate trace Fourier evaluation supplies the scalar for the self-dual measure. Flattening preserves the product measure, the sum over flattened entries is the rectangular pairing, and the measure is unchanged when the parameter is negated. This gives the exact positive square Fourier integral at every matrix.
