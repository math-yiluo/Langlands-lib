# Ascending quotients of compact parabolic sections

`realAscendingParabolicQuotient` supplies a continuous group intertwiner from the ambient smooth standard module of the two ascending character lists to the smooth standard module of the original concatenation. Each compact-finite target vector has a compact-finite preimage. There are two continuous Levi maps such that the ambient map carries every compact transverse section to the section of the two mapped inputs with the same test.

For a positive absolute-weight induced block, the same recurrent tail symbol defines the local and ambient maps. The ambient position is shifted by the rank of the preceding list. The smooth Fourier multiplier theorem retains the algebraic tail map on compact-finite vectors, which gives the preimages, and the parabolic multiplier theorem gives the section identity. For weight zero, block expansion gives equal scalar standard spaces. The identification from `RealPrincipalSeriesSmoothQuotient` recovers the same scalar function on each smooth carrier, so it preserves the section formula. An individual character uses the identity map. List induction composes these maps in each Levi slot and then composes the two resulting ambient quotients.

`hasParabolicTraceDetection_of_characters` reduces nonvanishing on a compact transverse section to the case of two character lists. Pullback preserves covariance and is nonzero because the ambient quotient reaches every compact-finite vector and those vectors are dense. The section identity then transfers a section of nonzero value to the original lists. This derives a model comparison for the compact-section restriction in [Jacquet, *Archimedean Rankin–Selberg Integrals*, Proposition 14.1, pp. 103–104](https://www.math.columbia.edu/~hj/PerfectRankinSelberg.pdf#page=103).
