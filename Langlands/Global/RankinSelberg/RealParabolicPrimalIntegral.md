# Primal real Rankin–Selberg kernels under a parabolic restriction

A leading-block restriction is an identity for a Whittaker function on the
padded smaller group. Its value is the smaller function times a Schwartz
function of the last row and the half power of the determinant prescribed
by the size of the other block.

If the leading block has the same rank as the other representation, the
Schwartz row is the equal-rank test and the determinant factors cancel.
If the leading block has greater rank, padding again makes its last row
the final coordinate row. The row test is required to take value one
there, and the determinant factors give the ordinary smaller unequal-rank
kernel. If the leading block has smaller rank, the row-weighted smaller
integral agrees with the kernel on that rank in which both Whittaker
functions are evaluated on padded matrices. All three are pointwise
kernel identities on the same unipotent quotient, so they preserve the
integral and integrability for the same compatible quotient measure.

When the resulting primal integral equals the leading-block integral,
`appendLeftNormalization` multiplies its entire normalized value by the
complementary pair denominator. This uses the exact product of
reciprocal Gamma factors for the concatenated block list. Cancellation
occurs on a common right half-plane where the complementary denominator
has no zeros.

These are the kernel comparisons for the first inclusion in H. Jacquet,
*Archimedean Rankin–Selberg Integrals* (2009), Proposition 14.3, author-posted
pp. 104–105. The leading-block coefficient restriction is a hypothesis from
Propositions 14.1–14.2. The third comparison gives the kernel to which the
lowered-rank integration argument of Lemma 14.1 applies.
