# Finite unequal-rank Whittaker tests

This is the finite-place calculation used in the unequal-rank pointwise factorization of the integrands in Cogdell, *Analytic theory of L-functions for GL_n* (2004), proof of Theorem 4.1, p. 219. The construction is internal: it uses the Library's p-adic JPSS functional equation and does not assume a separate finite-place test-vector theorem.

`padicUnequalNonvanishingTest` applies `unequalRankFunctionalEquation` with the compatible local quotient Haar measure and the supplied self-dual additive measure. In block zero the normalized ordinary generator supplies a nonzero rational value. The value-set description gives an actual pair of model vectors realizing it. Uniqueness of rational continuation identifies the ordinary value in the functional equation with that nonzero value. The normalized functional equation gives a nonzero dual rational value for the same pair. Each nonzero rational continuation yields a nonzero integral arbitrarily far to the right. These are individual nonvanishing claims, not assertions at every point of a half-plane.

`testIntegrand_integral` and `testDualKernel_integral` compare the local integrals with the ordinary and dual kernels written in the `ArchimedeanLocal` conventions. The block-zero matrix is the padded matrix, the empty block has unit mass, and the complementary block in the dual integral is the rectangular point. The local Weyl elements agree by the size identity for the lower block. The iterated-integral description of JPSS then gives both equalities for all spectral parameters, with the same measures as in the test data.

On the actual finite components, `exists_tests` obtains Whittaker genericity from the embedded cuspidal realization and local irreducibility and admissibility, also applying the result to the character scaled by minus one in the smaller rank. The canonical inverse component has this same inverse unipotent character. `inverseFactorCoefficient` keeps the underlying functional and function values under that character identification, then uses the published finite-factor equivalence and normalized reference-vector construction. The ordinary coefficient is transported by the same published construction with no change of character.
