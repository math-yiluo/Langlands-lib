# The adjoining character and the spectral variable

This internal result isolates the adjoining exponent in Jacquet's equal-rank matrix term, *Archimedean Rankin–Selberg integrals* (2009), §8.2, printed pp. 55–57. Adding `z` to the radial exponent multiplies the character of the determinant by the normalized determinant power at `z`. The matrix spectral parameter therefore becomes `s + z`. Unitary determinants have normalized absolute value one, so the compact character and the compact projection can be kept fixed.

The companion holomorphy lemma expresses the determinant power as the complex exponential of a real logarithm. It applies the holomorphic exponential integral theorem on any open set of absolute convergence.
