# Comparing Whittaker models on adelic form completions

For two cuspidal operator realizations, supply adelic form completions whose coordinate embeddings have smooth values on the original vectors. Assume the indicated mixed Whittaker models for the same character, uniqueness on the first mixed space, and a bounded full adelic intertwiner extending the original linear map.

The two restrictions of this intertwiner give the mixed smooth pullback. On original vectors the induced map computes the given extension. The mixed comparison theorem then supplies one scalar for all original Whittaker values. This is the step in the comparison argument of Cogdell (2004), printed p. 202, that applies uniqueness before using the Fourier expansion.
