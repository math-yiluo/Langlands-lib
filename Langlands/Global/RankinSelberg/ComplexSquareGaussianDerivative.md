# Linear directional derivatives of square polynomial Gaussians

`complexSquareGaussianDerivative` shows that applying the derivative along a continuous real-linear vector field to a square polynomial Gaussian preserves the class at scale \(2\pi\).

Each component of the vector field has a linear polynomial in the real and imaginary entries. The product rule then gives a polynomial derivative for each polynomial multiplier. The squared entry norm is also a polynomial in the same coordinates. Differentiating the Gaussian contributes the derivative of that polynomial times the original Gaussian. This derived closure property applies to the polynomial Gaussian square tests in Jacquet, *Archimedean Rankin–Selberg Integrals*, §8.2.
