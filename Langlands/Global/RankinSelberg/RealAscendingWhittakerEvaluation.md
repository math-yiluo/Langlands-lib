# Smooth evaluation on ascending real character presentations

Given real smooth Casselman–Wallach extension, a uniform Whittaker coefficient
map of an irreducible real standard module has a continuous Whittaker evaluation
on its genuine smooth vectors. Pull this evaluation back along the equivariant
smooth quotient from the ascending character presentation. The quotient maps
onto every original compact-finite vector, so the pulled-back evaluation
recovers all its translated coefficients.

For a character list the full smooth standard module equals the position
principal series. The equivalence from that standard module to the genuine
smooth vectors intertwines actual right translation. The continuous evaluation
therefore gives a Whittaker form on the full position series with the finite
compact right-derivative bound supplied by the derivative topology. This proves
`RealAscendingWhittakerEvaluationStatement`.

The same argument gives a bounded realization of the canonical Jacquet map
when the character source itself is irreducible and Casselman–Wallach extension
is available. Whenever the ascending canonical realization has a compact bound,
Whittaker uniqueness identifies the pulled-back form up to scalar with the
canonical form. The scalar is absorbed into a compact-finite vector, so every
original coefficient then occurs in the canonical map on the ascending list.
The comparison at reducible parameters requires the canonical bound separately.
