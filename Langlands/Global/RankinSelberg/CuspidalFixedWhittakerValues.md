# Actual translated values of a fixed-level smooth Whittaker evaluation

The analytic comparison identifies the smooth orbit lift with the actual
Whittaker integral on the original fixed vectors. Evaluating that equality
at an archimedean matrix gives the translated value. If the translating
matrix is the infinite component of an adelic unipotent element with
finite component one, the actual left covariance of the Whittaker
integral gives the generic character factor. These are internal
consequences of the analytic comparison and actual adelic product formula.
