# Realizing the specified complex Whittaker model

Fix an actual cuspidal realization over a number field with compact additive
adelic quotient, an adelic unitary additive character trivial on the diagonal
field, and its compatible scale at a complex place. Given a standard parameter
of the realization at that place, every function in the specified ordinary
Whittaker model is the restriction of a global Whittaker function of an actual
cuspidal vector, with finite coordinate one.

The Library's actual-place intertwiner theorem gives a map from the chosen
compact-finite standard module into the cuspidal realization and a local
coefficient map defined by taking those global restrictions. The coefficient
map is nonzero because one source vector gives value one at the identity.
Exact complex Whittaker multiplicity one identifies the entire specified
model with the range of this map. Choose a preimage of the given coefficient
and apply the map into the actual realization to obtain the required vector.
This is an internal consequence of those two Library theorems.
