# Smooth extension of exact complex Whittaker identity evaluation

A smooth function on the invertible matrices has a smooth compactly
supported extension agreeing with it on any chosen compact subset. A
smooth cutoff is one on the subset and supported in an invertible
neighborhood with compact closure. Multiplying by this cutoff lets the
extension be smooth and zero locally outside the invertible matrices.
The resulting uniform matrix derivative bounds give finite bounds for
all specified compact difference orders of the original profile.

Use compact-finite density to choose approximants to each smooth section
with geometrically decreasing difference error at the order that
controls Whittaker evaluation. Evaluation of the difference of two
approximants is bounded by the sum of their errors, so the complex
values form a Cauchy sequence. Comparison with any other sequence whose
errors tend to zero gives the same limit. Applying this comparison to
sums, scalar multiples and constant sequences proves linearity and
agreement with the original evaluation. Taking the limit in the
uniform bound gives the same difference order and constant on every
smooth standard section.
