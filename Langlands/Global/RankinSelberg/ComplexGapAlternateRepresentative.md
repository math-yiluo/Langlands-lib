# Sparse representatives for the alternate complex tail

`ComplexGapAlternateRepresentativeStatement` evaluates the alternate
kernel at a chart representative with the first rectangular column
retained and the upper-unipotent tail included in the trailing block.
It gives the same retained factor and the same inverse-transpose
frequency factors as the fixed-fiber Fourier formula.

Moving the unipotent tail to the diagonal block changes the representative
by a right upper rectangle supported in the later columns. The first
column is fixed because the tail is upper unipotent. The Whittaker
character is trivial on the later rectangle, which leaves the leading
test, first column and determinant fixed. Its inverse has identity rows
on the trailing block, so the inverse-transpose tail columns, including
the final frequency, also agree.

This is a chart identity for the alternate expression in H. Jacquet,
*Archimedean Rankin–Selberg Integrals* (2009), §10.2, author pp. 72–73,
formula (10.5).
