# Distributions from smooth complex standard-module functionals

Fix the supplied complex standard-module list and a Borel left
Haar measure on the second-countable upper triangular subgroup.
A complex-linear functional on the smooth module whose values are
bounded by a fixed compact difference order gives a distribution
on the open set of invertible matrices. Its evaluation on a test
is evaluation of the original functional on the Borel-averaged
section.

For each fixed compact test support, the profile estimate bounds
this composition by a constant times the supremum of the source
derivative seminorms through the controlling order. The fixed-support
linear map is therefore continuous. The test-function topology's
universal property gives continuity on the full test space.
Surjectivity of the Borel test map transfers any proportionality
of the resulting distributions to the original functionals.

The pointwise average also changes a left matrix-test translation
into the inverse right translation of the section. This yields
the translation formula used for the Whittaker character. These
constructions use the Library's actual test spaces and induced
sections throughout.
