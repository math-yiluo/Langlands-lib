# Consecutive coordinates for the sparse alternate chart

`ComplexGapAlternateCoordinatesStatement` identifies the sparse tail
matrix with the two-block right-tail factor in the absolute
convergence estimate. The trailing rank `q + 1` equals the
result of subtracting the leading rank from the ambient rank.
Reindexing the logarithms, the tail unipotent and the first
rectangular column along that equality gives the same group element.

The accompanying identities identify the first physical tail column,
the trailing inverse-transpose columns and the leading test input.
For the leading input, the embedded matrix contributes the leading
square with a zero lower rectangle.

These are coordinate identities for the alternate chart in H. Jacquet,
*Archimedean Rankin–Selberg Integrals* (2009), §10.2, author pp. 72–73,
and the convergence argument in §10.4, author pp. 79–81.
[Registered author edition](https://www.math.columbia.edu/~hj/PerfectRankinSelberg.pdf)
