# Duality of the real open-cell Jacquet value

`RealGodementOpenCellDualStatement` applies the Library's Weyl inverse-transpose function transform to the real open-cell Jacquet value. It identifies the result with the Jacquet value of the transformed inducing function using the opposite additive parameter. The formula is an identity of total Bochner integrals.

The change of variables is the automorphism of the upper unipotent given by inverse transpose conjugated with the long Weyl element. It is involutive, so its positive Haar scaling factor has square one and the specified entry Haar is preserved. The existing superdiagonal identity negates the first-superdiagonal sum. The real self-dual entry measure is the same for \(a\) and \(-a\), and the group argument agrees pointwise after the change of variable.

This function identity relates the open-cell integral of Jacquet, *Archimedean Rankin–Selberg Integrals* (2009), §7.2, p. 47, to its Weyl inverse-transpose convention. Identifying the transformed inducing function with a specified contragredient model is a separate representation-theoretic step.
