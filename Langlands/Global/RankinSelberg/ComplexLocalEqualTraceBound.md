# Dependence on the last-row Schwartz test on vertical lines

This internal result gives the trace estimate used in the passage to general Schwartz tests in Jacquet, *Archimedean Rankin–Selberg integrals* (2009), §8.1, printed p. 54. For fixed Whittaker coefficients the same right half-plane works for every test. The bound on each vertical line is a continuous function of the test and vanishes at zero.

In logarithmic Iwasawa coordinates, the two Whittaker estimates fix the growth exponent before the determinant parameter is chosen. On each vertical line the Schwartz seminorm and the simple-root decay absorb the positive logarithmic coordinates. The resulting absolute majorant is integrable for the quotient measure because it cancels the Iwasawa density and leaves exponential decay in each logarithmic coordinate.
