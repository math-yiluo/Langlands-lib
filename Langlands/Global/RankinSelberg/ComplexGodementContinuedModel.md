# Continued Schwartz Godement values in the irreducible Whittaker model

The continued Godement integral of a right unitary-finite rectangular Schwartz test and a smaller canonical Jacquet value belongs to the exact larger Whittaker model at each irreducible inducing parameter. The angular weights stay fixed as the radial exponents vary.

In a strong chamber, the ordinary Godement sections belong to the standard modules. The compact restrictions of these sections lie in one finite-dimensional space of profiles since the Schwartz test has finite right unitary orbit span. The continued Godement values agree there with canonical evaluation on this space. Both the canonical evaluations and the continued values are pointwise entire in the inducing parameters. Holomorphic uniqueness first varies the adjoined exponent for each strictly ordered tail, then varies all exponents from the resulting open set.

Irreducibility and the nonzero Jacquet intertwiner make canonical evaluation injective on the space of profiles at the specified parameter. The analytic range lemma therefore gives the required profile there. Multiplicity one identifies its image with the exact Whittaker model for the prescribed inducing list and additive character.

This is a derived use of the Godement section and its continuation from H. Jacquet, *Archimedean Rankin–Selberg Integrals* (2009), Proposition 7.1 and Proposition 7.2, author pp. 43–49.
