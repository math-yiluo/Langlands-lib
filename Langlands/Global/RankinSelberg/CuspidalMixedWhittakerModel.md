# Mixed smooth realization of the actual Whittaker values

A model consists of one mixed Whittaker functional whose values after
the two translations agree with the original cuspidal Whittaker
integral. Any nonzero original vector certifies that the functional is
nonzero. This packages the conclusion of the mixed Whittaker
construction for a specified original map.

The accompanying uniqueness proposition asserts proportionality of
two such character functionals continuous for the derivative topology
at each compact open level, once the first is nonzero. These are
internal interfaces for comparing actual cuspidal realizations.

For two such models, the bounded extension of the original map
pulls the second character functional back to the first space.
Irreducibility of the original realization supplies a nonzero
vector, hence the first model functional is nonzero. The supplied
mixed uniqueness assertion then gives the scalar relation, which
transfers to all original integrals by the translated value formulas.
