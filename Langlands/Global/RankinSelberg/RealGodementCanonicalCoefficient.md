# Canonical continued real Jacquet maps on K-finite sections

`canonicalJacquetMap` is a complex linear map on the real K-finite standard module for a list of characters at any exponent vector. `RealGodementCanonicalCoefficientStatement` records its agreement with the convergent Jacquet integral on the strict dominant chamber. On each fixed compact profile the map gives a spectral family with holomorphic right derivatives and locally uniform derivative growth.

For each compact profile choose the Jacquet family furnished by uniform continuation. On the chamber its values are the open-cell integral of the standard section. Extending a compact profile is linear, and the convergent Jacquet integral is linear on the smooth position principal series. The identity theorem transfers addition and scalar multiplication from the chamber to every exponent vector. Restriction to the orthogonal group recovers the profile of each standard section, so applying the continued family to those restrictions defines the map on the actual K-finite source.

This map packages the fixed-profile continuation of Jacquet, *Archimedean Rankin–Selberg Integrals* (2009), §7.2, for the real character lists and the positive-phase open-cell convention.
