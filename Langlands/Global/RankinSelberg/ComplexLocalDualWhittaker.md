# Duals of complex local Whittaker functions

The published dual function is pullback by \(g \mapsto w_0 (g^{-1})^\mathsf{T}\).
For a list of the indicated length, this pullback carries the complex Whittaker model for
the list \(d\) and parameter \(a\) to the model for the reversed inverse list and parameter
\(-a\). The result uses the Library's unsigned long Weyl element.

The pullback is a linear involution on functions. On the standard module it gives a linear
equivalence with the module of the reversed inverse inducing characters. The proof conjugates
each Whittaker intertwiner by these two maps. The left equivariance uses the unipotent
reflection, which reverses and negates the adjacent upper entries. Smoothness follows from
smoothness of the pullback. The growth bound uses invariance of the matrix height under
inversion, transposition and row or column reversal. The compact and Lie equivariances use
inverse transpose on the compact factor and negative transpose on its real Lie algebra
directions. The resulting maps carry each intertwiner range into the target model, so they
also carry the supremum of those ranges into it.

This internal result combines the published inverse-transpose maps and character reflection
with the Library definition of the complex Whittaker model. It gives the transport of the
functions in the dual integral of Jacquet 2009, Theorem 2.1.
