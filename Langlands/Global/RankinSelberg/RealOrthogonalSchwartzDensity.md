# Density of real square Schwartz tests of finite left orthogonal span

In `RealOrthogonalSchwartzDensityStatement`, a Schwartz test `Φ` on real `n × n` matrices
(with the operator norm, as for the other real square tests in the Library) has finite left
orthogonal span if the functions `X ↦ Φ(k⁻¹ X)` span a finite-dimensional complex space as `k`
ranges over the orthogonal group `unitaryCompact ℝ n`. The statement says that these tests are
dense in the Schwartz topology. `exists_tendsto_realOrthogonalFiniteSchwartz` restates this as
the existence of a sequence of such tests converging to any given Schwartz test.

The Lean proof is the real analogue of the published `ComplexUnitarySchwartzDensity`. Left
multiplication by an inverse orthogonal matrix is a real continuous linear map. It depends
continuously on the orthogonal matrix. Compactness of the orthogonal group gives one constant
`C` with `‖X‖ ≤ C ‖k⁻¹ X‖` for all `k`. The Library's compact average theorem
(`SchwartzCompactAverage.mem_closure_average_of_dense`) then approximates any compactly supported
Schwartz test by Haar averages `∫ w(k) Φ(k⁻¹ X) dk`, where `w` ranges over any uniformly dense set
of continuous weights on the orthogonal group. The weights used are the star subalgebra
generated by the matrix entries (`OrthogonalFinitePolynomial.polynomialStar`). It separates
points, so Stone–Weierstrass makes it dense.

For such a polynomial weight `w`, translating the average by `u` amounts, after left invariance
of Haar measure, to replacing the weight by `v ↦ w(u⁻¹ v)`. Since `u⁻¹ = uᵀ`, the Library lemma
`OrthogonalFinitePolynomial.inv_mul_mem_separated` writes this function of `(u, v)` as a finite
sum of products `α(u) β(v)`. Hence every translate lies in the finite-dimensional span of the
integrals `X ↦ ∫ β(v) Φ(v⁻¹ X) dv`. Finally, compactly supported Schwartz tests are dense
(`dense_hasCompactSupport_schwartz`), which gives the conclusion for every Schwartz test.

This is an internal approximation step for the left orthogonal-finite square tests in the
equal-rank argument of Jacquet, *Archimedean Rankin–Selberg integrals* (2009), §8.2, pp. 56–57.
There, Jacquet needs a left `K_n`-finite square test to replace the matrix integral by a finite
sum. The statement asserts only density; it proves nothing about Rankin–Selberg integrals.
