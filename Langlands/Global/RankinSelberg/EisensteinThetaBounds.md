# Bounds for the theta series on scalar idele fibres

This internal module supplies estimates for the Mellin transform of the nonzero-row theta
sum in Cogdell (2004, §2.3, pp.208–209). Compact representatives for the norm-one idele
classes and the archimedean norm section reduce the estimate to the Library's uniform
bound for the theta sum on the archimedean diagonal torus. The same compact set bounds a
continuous idele class character after removing its exponential on the norm section.
