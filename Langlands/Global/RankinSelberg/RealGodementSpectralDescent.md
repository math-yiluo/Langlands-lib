# Finite spectral descent with uniform right derivatives

`RealGodementSpectralDescentStatement` takes a spanning family with holomorphic coordinates and smooth group-valued coefficients. It assumes pointwise holomorphy for all right derivatives and locally uniform derivative growth for each generator. If the prescribed generator values come from linear evaluation on a nonempty open set, the descended linear maps agree there and reproduce the generator values at every parameter.

For each group element the scalar holomorphic continuation theorem determines the linear evaluation on the coordinate space. Near any fixed parameter choose generators with an invertible coordinate matrix. Cramer's rule expresses any coordinate vector in that local basis, using holomorphic coefficient functions. The descended group function and each iterated right derivative are finite linear combinations of the corresponding generator values on this neighborhood. Shrink to a common ball on which the coefficients are bounded and all selected generators have their uniform estimates. The maximum of their growth exponents then works for every derivative word. The same local formula gives group smoothness and spectral holomorphy of each derivative.
