# Spanning by Weyl-translated Godement monomials

In the strict chamber with a sufficiently large exponent on the adjoining character, the polynomial Gaussian Godement sections span the compact-finite inducing space. Lean uses integrability of the finite family of monomial tests to pass the polynomial expansion through the Godement integral. The canonical Jacquet value on each section is its continued Godement value at zero shift.

Right translation by the tail Weyl element preserves the inducing space and the exact Whittaker model. Canonical Jacquet evaluation commutes with this translation, which is an involution. The Weyl-translated monomial values thus span every larger canonical value in the chamber. This derived spanning statement prepares the split-test comparison in Jacquet’s Section 10.2.
