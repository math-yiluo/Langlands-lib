# Continuous Whittaker evaluation of real standard block models

`RealExactBlockStandardEvaluationStatement` applies to every real inducing block list whose total rank is the matrix rank. For every nonzero real additive scale and every exact `IsRealWhittakerIntertwiner` on the compact-finite standard module, it supplies a continuous scalar functional on the genuine smooth vectors of that module's compact Banach representation. The functional has the same coefficients on the compact-finite vectors at all group elements and satisfies the Whittaker transformation law on every smooth vector.

Pass to the ascending character expansion by `compactlySplitStandardQuotient_ascendingExpand`, with quotient \(T\) and section \(S\). The character result in `RealWhittakerFiniteOrder` bounds the identity value of \(B\circ T\) at a fixed compact difference order. The section commutes with every orthogonal right translation and is bounded on compact values by `RealBlockFourierSupNorm`. Because \(S\) commutes with all iterated compact differences, it multiplies the bound at the same order by one fixed constant. The equation \(T(Sf)=f\) gives the finite-order bound for \(Bf(1)\) directly.

`RealExactStandardEvaluation.exists_continuous_identityEvaluation` extends the identity value using the genuine derivative-word topology. Then `isWhittakerStandardEvaluation_of_identity` establishes the translate and character identities. The continuous Whittaker evaluation is the form of the coefficient model used in Jacquet, *Archimedean Rankin–Selberg Integrals*, §2, p. 4 in the author-posted edition. The compact-section and finite-order argument here derives it for the Library's specified exact coefficient maps.
