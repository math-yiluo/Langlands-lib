# Canonical holomorphic coefficient families along real block deformations

Assume the uniform Whittaker model of every real character list lies in the range of its canonical Jacquet map. `realCanonicalOrdinaryDeformation` lifts an exact coefficient at any rank-correct real block list to a family along the ascending character expansions of `deformBlocks`. The family specializes to the given coefficient at \(z=1\). At every \(z\) it belongs to the uniform character model with the same additive parameter, is a regular Whittaker function, and is holomorphic in \(z\) at each group element. It has a common toral gauge for \(|z|<3\).

The ascending positions of a deformed block have fixed parities and holomorphic exponents. The ascending quotient sends the original coefficient into the uniform character model at \(z=1\). Canonical range gives a compact profile producing that coefficient. Keeping this profile fixed in the continued Jacquet map constructs the family. Its local uniform derivative bounds give a single bound on the image of the closed parameter disk, and simple-root differentiation gives the toral gauge.

`realOrdinaryHolomorphicTestFamiliesOn_of_ascending` takes reverse ascending inclusion on a specified parameter set \(S\). It gives exact block membership on \(S\) within the disk. The unequal- and equal-rank joint-integral lemmas use the ascending families to give holomorphy of their ordinary integrals on a common right half-plane, with the original quotient measure and any equal-rank Schwartz test fixed. The imaginary axis is the set of parameters at which the block assembly uses exact block membership.

`realOrdinaryHolomorphicTestFamilies_of_ascending` applies this result to the whole parameter plane. The construction uses the principal-series reduction and holomorphic variation in Jacquet, *Archimedean Rankin–Selberg integrals*, Proposition 11.1, p. 82 of the author-posted edition.
