# Nonvanishing of exact real Whittaker models for imaginary exponents

`RealTemperedWhittakerModelNonvanishingStatement` asks that every rank-correct real block list with purely imaginary inducing exponents have a nonzero exact Whittaker coefficient space for each nonzero real additive scale. The conclusion concerns smooth functions represented by the specified compact-finite standard module. The corresponding smooth parabolic-induction construction is given by Shahidi, *Whittaker models for real groups* (1980), Proposition 3.2 and Corollary 3.2, pp. 120–121. The Library statement uses its exact coefficient model for \(\mathrm{GL}_{r+1}(\mathbb R)\) and the imaginary-exponent specialization of Jacquet, *Archimedean Rankin–Selberg integrals* (2009), §3.4 and Proposition 11.1.

For a real character list, `realCharacterWhittakerModel_ne_bot` uses a nonzero canonical Jacquet coefficient. The canonical map at the negative of the given additive scale has the desired Whittaker character, and uniform coefficients belong to the exact model. This works at every inducing exponent. `realWhittakerModel_ne_bot_of_index_le_one` applies this to the only block shape in rank one, and to the ascending character expansion in rank two using the equality of its exact model with that of the original list.
