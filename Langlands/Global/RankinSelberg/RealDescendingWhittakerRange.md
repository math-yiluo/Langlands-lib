# Exact Whittaker coefficients of the descending block inclusion

`realDescendingWhittakerRange` identifies the exact Whittaker model of a rank-correct list of real blocks with the range of any nonzero exact coefficient map on its descending character expansion, restricted to the original compact-finite standard functions. Both models use the same arbitrary nonzero real additive scale. The expansion preserves the position characters and omits the Fourier cutoffs for two-dimensional blocks. `realWhittakerModel_eq_range_descendingCanonical` gives the range of the restricted canonical Jacquet map with the sign convention of `RealGodementCanonicalModel`.

For a single block of nonzero weight in arbitrary surrounding lists, the binomial Frobenius map to the ascending pair records the compact Fourier modes below the absolute weight. Every vector in its kernel belongs to the original standard module. Its image is in the ascending tail kernel, whose elements are uniformly polynomial along the lower simple root of the pair. If a nonzero exact coefficient map vanished on the original standard vectors, its nonzero torus evaluation would descend to this polynomial image as an infinitesimal Whittaker functional. The growth argument in `RealWhittakerPolynomialKernel` rules out such a functional. For weight zero the rotation condition is vacuous. Repeating the one-block restriction preserves nonvanishing through the full list.

Pull back the restricted map and any other exact block map along the surjective ascending intertwiner. Exact character multiplicity one makes these pullbacks proportional. Surjectivity gives the same proportionality on the original standard vectors, so their coefficients all lie in the range of the restricted map.

Jacquet, *Archimedean Rankin–Selberg Integrals* (2009), §11, author pp. 81–82, uses a descending principal-series inclusion and invokes Lemma 2.4, author p. 9, for nonzero restriction of the continuous Whittaker form. The compact-finite argument here derives restriction from the binomial and tail multipliers, polynomiality along the lower root, and exact character multiplicity one.

`restrict_expand_ne_zero` states the nonvanishing part for any specified inclusion of the compact-finite standard modules.
