# Ascending Whittaker descent from proportionality and nonvanishing

`realAscendingWhittakerDescentFromMultiplicity` gives the inclusion of exact ascending character coefficients in the exact model of the underlying real block list. It assumes that the ascending exact coefficient maps are all proportional to any nonzero one, and that the original block coefficient model contains a nonzero function. The hypotheses and the inclusion use the same real additive parameter.

Choose a nonzero exact block intertwiner. Its pullback along the surjective ascending quotient is a nonzero exact character-list intertwiner. Proportionality then expresses the image of any ascending intertwiner as values of a scalar multiple of this pullback. By linearity these values belong to the image of the chosen block intertwiner. Taking all images establishes the model inclusion.

The proportionality premise is on the compact-finite coefficient maps used in the Library. The corresponding smooth Whittaker multiplicity-one result for character principal series is Theorem 9.1 of Casselman, Hecht and Miličić, *Bruhat filtrations and Whittaker vectors for real groups*, p. 184. Connecting the smooth result to the exact coefficient maps and establishing nonvanishing of the block model are separate inputs.
