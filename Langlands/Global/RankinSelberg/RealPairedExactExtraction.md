# Exact ordinary tests from nonzero paired smooth values

A continuous linear spectral evaluation that vanishes on a set vanishes on the closure of its span. The compact-finite pure pairs span a dense subspace of the genuine product-group smooth space. With entire normalizations for the paired family, any nonzero normalized spectral value is therefore detected by one compact-finite pure pair.

`realPairedUnequalExactExtraction` and `realPairedEqualExactExtraction` use the exact kernel identities on those pure pairs to retain the normalization with the same scalar value. The two functions come from the prescribed Whittaker models at opposite scales. In the equal case the Schwartz row is held fixed throughout. [Jacquet, *Archimedean Rankin–Selberg Integrals*, §15, pp. 108–109](https://www.math.columbia.edu/~hj/PerfectRankinSelberg.pdf)
