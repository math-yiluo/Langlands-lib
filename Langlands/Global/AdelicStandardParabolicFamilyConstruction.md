# Construction of a compatible adelic standard parabolic family

Fix a maximal split torus and a generic cocharacter in a connected
reductive group over a number field. The construction uses the published
standard parabolic schemes, Levi schemes and unipotent radical schemes
for each subset of the ambient simple roots.

Each standard Levi has a split component whose inclusion factors
through the prescribed maximal split torus. The standard root
presentation theorem supplies the full compatibility data for these
choices. The ambient relative reflection theorem provides one coroot
family. The factorization of the maximal split torus through each Levi
is the published `Standard.leviTorusHom`. Closedness, affineness and
finite type follow from the actual standard inclusions. Connected
reductivity of each Levi gives its smooth relative dimension.

This assembles the standard family used in Bernstein–Lapid §§2.1 and 6.1
in the Library's `StandardParabolicFamily` interface.

[Bernstein–Lapid, On the meromorphic continuation of Eisenstein series](https://doi.org/10.1090/jams/1020)
