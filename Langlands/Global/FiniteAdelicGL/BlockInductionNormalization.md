# The finite-place normalization of adelic block induction

Fix a number field \(F\), a finite place \(v\) and a positive ordered block shape \(B\) of rank \(n\). The module uses the actual finite matrix inclusion supported at \(v\). `finitePlaceParabolicInclusion` restricts it to the standard upper block parabolic and `finitePlaceLeviInclusion` applies it to each diagonal block. At \(v\) the inserted matrix is the given one. At every other place it is the identity. The diagonal-block projection commutes with these inclusions by checking the matrix entries at each place.

`norm_eq_canonicalNormalizedAbs` identifies Mathlib's norm on the completion with the normalized absolute value of `CompletionPadic.padicField v`. The completion valuation and the discrete valuation on the canonical p-adic object define the same valuation order and both surject onto \(\mathbb Z^{\times 0}\), the multiplicative integers with zero adjoined. The greatest value strictly below \(1\) is `WithZero.exp (-1)`. An element with that value for either valuation has the same value for the other, since the valuations have the same order and the other valuation also attains this value. Powers of this element realize every nonzero value, so the two valuations agree on the whole completion. The integer rings agree inside the completion, and `CompletionResidue.card_adicResidueField` identifies the common residue cardinality with `Ideal.absNorm v.asIdeal`. The two norm formulas then have equal bases and exponents, and both take the value \(0\) at zero.

`determinantNorm_finitePlaceInclusion` applies the norm comparison to the determinant of the inserted matrix. Applying it to all the blocks identifies the adelic pairwise determinant character with the published p-adic Levi modulus. The equality of `parabolicHalfCharacter` with `parabolicHalfModulus` on the inserted parabolic follows by the diagonal-block identity and equality of positive square roots. This gives precisely the scalar in the covariance of `canonicalNormalizedProductInduced` at the finite place.

This is an internal comparison between the published adelic determinant character and the canonical p-adic block modulus. It supplies the normalization identity used in the local-to-global induction comparison. The positive half in the finite-place covariance appears in Getz and Hahn (2024), §8.1 and (8.1), p. 213 (PDF 226). The global and local conventions for distributing the inducing twist are discussed in §10.1, p. 271 (PDF 283). The Lean result compares the characters on the specified matrices and leaves the comparison of the induced section spaces to a separate argument.
