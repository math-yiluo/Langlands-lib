# Local integration in a discrete left coset quotient

Let the quotient map be injective on a measurable patch which maps
into a measurable subset of the quotient. The integral on the patch
of a nonnegative pulled-back function is bounded by its integral over
that subset in the actual discrete quotient measure. This measure is
the pushforward from the Library's Borel fundamental domain.

Apply the fundamental-domain integration formula to the indicator of
the patch times the pulled-back function. Each orbit contributes at
most one point of the patch, by injectivity. The orbit sum is bounded
by the value of the quotient function restricted to the given subset.
This is an internal application of the discrete quotient integration
formula, including the case where the patch meets only part of the
specified quotient subset.
