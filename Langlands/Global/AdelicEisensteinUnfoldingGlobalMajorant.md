# Global majorants on rational unipotent stabilizer quotients

A compact set of representatives for the rational radical quotient reduces an arbitrary radical point to a product of a rational point and an element of the compact set. Matrix height is bounded on the compact set. Submultiplicativity therefore bounds the height of its product with the external adelic argument by a fixed constant times the external height.

The map from rational radical points to Eisenstein cosets has fibres lying in single cosets of the full rational parabolic stabilizer. The compact-cover majorant converts a summable bound on the Eisenstein cosets into an integrable bound on this stabilizer quotient. The argument retains the same polynomial power of the external adelic height, which will allow testing against rapidly decreasing Levi functions.
