# Polynomial bounds for fixed adelic Iwasawa height powers

For a closed matrix embedding, each rational character norm and its inverse are polynomially bounded in the matrix height. This bounds the absolute value of the logarithm of each character norm. Apply the logarithm bound to pure tensors in the character parameter space and use multiplication of powers for sums of parameters.

For an Iwasawa decomposition of an adelic point, the rational characters depend only on the parabolic factor. The restricted representation has the same matrix height as the ambient representation at that factor. Compactness bounds the height of the other factor and its inverse, giving a polynomial bound in the ambient matrix height.

The change of the Iwasawa log under arbitrary right translation is the log of the translating element multiplied on the left by an element of the fixed compact subgroup. This yields the uniform bound for the ratio of the fixed parameter powers, as used when integrating against rapidly decreasing Levi tests.
