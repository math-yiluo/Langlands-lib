# Reflex fields of CM types and Clozel's field `E = F_c R`

Author: Worker 34. For a CM field `K` with a CM type `Φ` (published
`Langlands/Global/CMType`), this module defines the reflex field `R` of
`(K, Φ)` as a subfield of `ℂ`. For an embedding `ι₀ : K → ℂ` it defines
Clozel's field `E = F_c R`, the compositum of `ι₀(K)` and `R`. It proves that
`E` is a number field and that `ι₀` embeds `K` in `E`. For the CM type that
Harris uses, induced from an imaginary quadratic subfield, it proves
`E = ι₀(K)`.

## Source

L. Clozel, *Représentations galoisiennes associées aux représentations
automorphes autoduales de GL(n)*, Publ. Math. IHÉS 73 (1991), §5.1, printed
p.131 (checked against the page image). Registered original
`clozel-1991-selfdual-galois`, SHA256
`9de7c13c9ae108e481de170327a06e44845cf87a6aabc1d5600176ee695e91ac`.

"Soit `Σ` un type CM pour le corps `F_c` … Soit `R` le corps reflex de
`(F_c, Σ)`. (Rappelons que c'est le sous-corps de `Q̄ ⊂ ℂ` engendré par les
traces partielles des éléments de `F_c` obtenues en sommant sur les plongements
`F_c → Q̄` appartenant à `Σ`.) … Fixons `ι₀ ∈ Σ` … Le choix de `ι₀` identifie `F_c`
à un sous-corps de `ℂ`. Définition 5.2. — Le corps reflex … est le corps
`E = F_c R ⊂ ℂ`."

Clozel (1991), §5.3, printed p.142, uses the same `E = R F_c` for CM fields.
M. Harris, *The local Langlands conjecture for GL(n) over a p-adic field,
n < p*, Invent. Math. 134 (1998), printed p.185 (registered
`harris-1998-local-langlands`, SHA256
`7934239ea37d0b91f741ae70c2ac157fe5d619cda4dd992ac24e39ae460c375b`): for an
arbitrary CM field "one only obtains Galois representations over a certain
reflex field containing `E` as a proper subfield, in general", while for
`E = E₀ K₀` "the reflex field is just `E` itself".

## Definitions

In namespace `Langlands.Global.CMType`, for `K` with `Field`, `NumberField`
and `IsCMField` instances and `Φ : CMType K`:

- `Φ.partialTrace x = ∑_{σ ∈ Φ} σ x ∈ ℂ`, the sum over the selected embeddings.
- `Φ.reflexField`: the intermediate field of `ℂ/ℚ` generated by all partial
  traces (`IntermediateField.adjoin`). This is Clozel's definition.
- `Φ.clozelReflexField ι₀ = Φ.reflexField ⊔ ι₀(K)`, for any ring homomorphism
  `ι₀ : K →+* ℂ` (Clozel takes `ι₀ ∈ Σ`; the statements that use it assume this).
- `Φ.toClozelReflexField ι₀ : K →+* E`, the map `x ↦ ι₀ x` with values in `E`.

## Proved properties

- `partialTrace_mem_iSup`, `clozelReflexField_le_iSup`: `E` lies in the
  compositum of the images of all complex embeddings of `K`.
- Instances `finiteDimensional_fieldRange`, `finiteDimensional_clozelReflexField`
  and `numberField_clozelReflexField`: each image `σ(K)` is finite-dimensional
  over `ℚ`, hence so is the finite compositum (Mathlib's
  `IntermediateField.finiteDimensional_iSup_of_finite`) and `E`; so `E` is a
  number field.
- `coe_toClozelReflexField`: the embedding is `ι₀`.
- `partialTrace_inducedFromImaginaryQuadratic`: for the published
  `inducedFromImaginaryQuadratic ι τ` (all `σ` with `σ ∘ ι = τ`, for an
  imaginary quadratic `ι : F → K` and `τ : F → ℂ`), the partial trace of `x` is
  `τ(Tr_{K/F} x)`. The proof is Mathlib's `trace_eq_sum_embeddings`, with the
  selected embeddings identified with the `F`-algebra maps `K → ℂ`.
- `clozelReflexField_inducedFromImaginaryQuadratic`: for that type and
  `ι₀ ∈ Φ`, `E = ι₀(K)`, because `τ = ι₀ ∘ ι` maps every partial trace into
  `ι₀(K)`.

## Conventions and scope

- The reflex field is defined by Clozel's generators. Its standard
  description as the fixed field of `{s ∈ Aut(ℂ) : s ∘ Φ = Φ}` (used, for the
  Hodge function of a Shimura datum, by the published
  `Langlands.Shimura.reflexField`) is not proved here.
- `E` is a subfield of `ℂ`; its absolute Galois group is Mathlib's
  `Field.absoluteGaloisGroup` of the corresponding type, as for every number
  field in the Library.
- Clozel's remark that `R` is a CM field contained in the Galois closure of
  `F_c` is not proved; only finite dimensionality is.
