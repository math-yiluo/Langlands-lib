# Smooth openness in the original adelic local factors

This module proves `Langlands.Global.AdelicSmoothLocalPointOpenStatement` in the common arbitrary universe `u`. The target is the conjunction of the curve-place and number-field assertions in `AdelicSmoothLocalOpenStatement`. The actual point spaces, coefficient actions and topologies are those of that statement.

## Source and scope

The source is Brian Conrad, *Weil and Grothendieck approaches to adelic points*, December 31, 2011, registered as `conrad-2011-weil-grothendieck-adelic-points`, printed p.12, the first two proof paragraphs of Theorem 4.5. Those paragraphs use complete-field smooth openness and the open embedding of completed-integer points into completed-field points. This proof supplies that local input, with the exact qualifications of the independently stated target. It does not prove almost-all surjectivity, compatible spreading, the dimension reduction, the uniform Lang–Weil estimate or the global adelic theorem.

The curve assertion ranges over arbitrary fields `k` and `F` with an algebra structure, and all the existing discrete curve places. It does not need a finite constant field or the global function-field hypothesis. The number-field assertion includes every infinite place, the supported finite completed fields and the completed integer rings outside the enlarged finite set. Both branches retain the original S-integer coefficient base, arbitrary nonaffine locally finite-type separated models, smoothness of the given relative morphism, and every finite enlarged level. Local openness needs no surjectivity or geometric connectedness assumption.

## Implemented proof

1. `smooth_ringBaseChangeMap` uses Mathlib's `MorphismProperty.overPullbackMap` for the actual base-change functor. Smoothness of the original relative morphism therefore gives smoothness after extending the original coefficient base to the completed field.
2. `isOpenMap_completeFieldCoefficientSmoothPointMap` applies the published `isOpenMap_smoothSchemePointMap` to this base change over the complete nontrivially normed field. The actual pullback-adjunction point homeomorphisms, `schemePointBaseChangeHomeomorph`, and `ringPointBaseChangeEquiv_natural` conjugate the resulting open map to the point map of the original scheme. The original-base and extended-base point topologies are independently defined; the published homeomorphism proves their compatibility.
3. `isOpenMap_integralCoefficientSmoothPointMap` treats an arbitrary reduced topological local ring `R` openly embedded as an algebra into the complete field `K`. The published coefficient results make the source coefficient point map open. On the separated target they make the coefficient point map continuous, injective and open, hence an open embedding. Associativity of actual relative scheme morphisms identifies the resulting square. The target embedding then reflects openness of the integral point map. This argument retains local finite type of both models and separatedness of the target.
4. `curvePlaceSmoothLocalPointOpen` splits the original sum index into completed-field and completed-integer factors. For each native completion, Mathlib's rank-one discrete valuation supplies a `RankOne` structure. `Valued.toNontriviallyNormedField` extends the existing field structure while retaining its uniform space, hence its topology and completeness. For integral factors, the coefficient algebra is exactly the existing factor algebra restricted along the original S-integer inclusion. Composing that algebra map with the native valuation-subring inclusion defines the field coefficient algebra, so the inclusion is an algebra homomorphism by reflexivity. `Valued.isOpen_valuationSubring` supplies its open embedding. The generic integral result now applies with the native completed integer ring and topology.
5. `numberFieldSmoothLocalPointOpen` performs the analogous three-way split. Finite factors use the native discrete completion exactly as in the curve branch. For an infinite factor, the existing `NormedField` structure is extended to a `NontriviallyNormedField` by proving that the norm of `2` exceeds `1`, using Mathlib's isometric complex embedding. This preserves the original norm, field structure and topology. The existing completeness instance then permits application of the complete-field result.
6. `adelicSmoothLocalPointOpen` pairs the two branch proofs. Its type is precisely the named target proposition, without additional premises.

The integral topological-ring instances come directly from the native subrings. No valuation or point topology is redefined. The only extra structures in the finite-field factors preserve their original uniform spaces definitionally, and the infinite-factor extension preserves the existing normed-field structure. All coefficient point maps are actual morphism compositions in the relative `Over` category.
