# Place module laws for compact-finite automorphic operator sources

`HasWeaklyContinuousOrbits` asks that each linear functional of each
compact orbit be continuous. It restricts along injective intertwiners
by extending a linear functional from the image. It descends along
spanning images by linearity and continuity on each image.

For an action of the actual automorphic operator algebra, full compact
finiteness, weak continuity and `CompactDualDerivative` give the real
and complex place module laws. The orbit at one place spans a subspace
of the full compact orbit span. Placing a compact curve in the full
compact inserts its tangent in the chosen archimedean Lie factor.
The operator covariance identity and the matrix adjoint comparison
supply the remaining module law at that place.

These internal lemmas pass the analytic properties of the source
compact action to the place actions used for the block evaluations.
