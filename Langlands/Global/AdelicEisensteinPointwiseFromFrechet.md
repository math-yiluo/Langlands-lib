# Finite-family pointwise Eisenstein continuation from Fréchet continuation

Apply the function-valued continuation to each inducing form using the positive-size closed embedding reduction. Choose a single linear parameter chart. In each local Fréchet space, continuous linear evaluations at all adelic points give scalar meromorphic data with a common local denominator. The scalar gluing theorem gives one chart domain for all evaluations of each form. Intersect these domains for the finite family and transport the resulting open dense domain to parameter space. The coordinate change theorem gives scalar meromorphy in every chart.

A common bound on the finitely many agreement thresholds gives equality with the actual Eisenstein series in the required chamber. An empty family imposes no restriction on the chart or the threshold. This is a consequence of the function-valued continuation in Bernstein–Lapid Theorem 2.3(1) and the corollary in §8.6.
