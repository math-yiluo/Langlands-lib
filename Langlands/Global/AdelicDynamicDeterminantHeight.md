# Adelic height bounds for the actual dynamic determinant

The published exterior power of the ambient adjoint representation contains
the determinant vector of the dynamic unipotent radical. Its rational
coordinates are nonzero and extend to the adelic coordinates by the same
minors. `adjointExteriorFinRepresentation` reindexes the existing matrix
representation by a finite initial segment. Reindexing the actual adelic
action preserves its scalar, the character of the parabolic conjugation
action on the Lie algebra of the radical.

The Iwasawa orbit height bound applies to this vector. On principal rational
points the projective logarithmic height is nonnegative, so the Iwasawa
evaluation at the dynamic determinant character is bounded above.

This is an internal application of the published adjoint exterior line and
adelic orbit-height interfaces to the convergence argument of
Mœglin–Waldspurger II.1.5.
