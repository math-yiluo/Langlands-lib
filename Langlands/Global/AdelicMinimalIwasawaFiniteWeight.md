# Finite weighted measure from minimal-parabolic Iwasawa coordinates

`AdelicMinimalIwasawaFiniteWeightStatement` assumes an actual Siegel algebraic setup over a number field, a compact Iwasawa subgroup for the canonical minimal parabolic \(P_0\), and finite real logarithm coordinates from a splitting of the maximal split torus. The compact-representative theorem gives a continuous positive torus section \(a\) of the \(P_0\) logarithm and one compact set of norm-one parabolic left factors. Each adelic point has the specified representative up to left \(P_0(F)\) translation.

Write \(H_0\) for Iwasawa height on \(P_0(F)\backslash G(\mathbb A)\) and \(v(z)\) for the vector of torus logarithm coordinates of \(a(H_0(z))\). There is \(c>0\) such that on any measurable region \(S\) the actual weighted quotient measure with density \(\exp(-2\ell(H_0(z)))\) has finite total mass whenever

\[
  c\|v(z)\|\le 2\ell(H_0(z))+b\qquad(z\in S)
\]

for a fixed real \(b\). This applies to each region where the weight has the required lower bound, including a boundary subset with its restricted measure.

The inverse torus log map takes the additive coordinate group continuously and multiplicatively into the actual adelic group. The compact-representative formula therefore gives a finite exponential height moment on the rational-parabolic quotient. On \(S\), the assumed lower bound for the weight bounds its density by \(\exp(b)\) times this integrable exponential. The argument realizes a finite-mass input for sufficiently positive weights in Bernstein–Lapid, §7.4, pp. 215–217.
