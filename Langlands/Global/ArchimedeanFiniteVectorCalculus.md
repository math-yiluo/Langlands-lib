# Locality, linear coefficients and left translation for vector differentiation

This internal supporting construction uses the actual finite-coordinate
vector smooth differential. An ambient expression agreeing with the original
function on every invertible matrix gives the same differential: the units
are an open neighborhood of each evaluation point, so the two expressions
are eventually equal there. No regularity outside this neighborhood is needed.

Fixed continuous complex-linear maps between finite coordinate coefficient
spaces commute with the real differential. The proof differentiates the
linear map composed with the original local coordinate expression, using its
proved genuine differentiability. Source and target finite index universes
are independent of each other and of the number-field universe.

`finiteVectorSmoothLeftTranslation` is actual pullback by left multiplication,
constructed through the scalar coordinate equivalence. The proved scalar
left-translation law gives commutation with the real differential on every
coordinate. This is an endomorphism for each group element, with the same
actual function value formula; no opposite-action convention is hidden in a
new representation.

This infrastructure proves no algebraic/analytic comparison or automorphic
cohomological statement. It supports actual coefficient orbit differentiation.
