# Siegel finiteness for the actual adelic `GL(n)` Siegel sets

Module: `Langlands.Global.AdelicGLSiegelFinitenessStatement`.
Proposition: `Langlands.Global.PrimitiveAdelicHeight.SiegelSetGLFinitenessStatement`
(universe parameter `u` of the number field). It is a proposition definition; the
module proves nothing.

## Statement

For every number field `F : Type u`, every `n : ℕ` (including `n = 0`), every set
`Ω_N` of `n × n` adele matrices, every set `C` of ideles and every real `c`, assume

- `Ω_N` is compact and every `N ∈ Ω_N` is unitriangular (`IsUnitriangular N`: upper
  triangular with diagonal entries `1`);
- `C` is compact and contained in the norm-one ideles
  `NormOneIdeleClass.normOneIdeles F`;
- `0 < c`.

Then the set of rational invertible matrices `γ : RationalGL F n` for which some `g` in
the Siegel set `siegelSetGL F n Ω_N C c` satisfies
`AdelicGL.rational F n γ * g ∈ siegelSetGL F n Ω_N C c` is finite (`Set.Finite`).

The Siegel set is the Library's `siegelSetGL` of
`Langlands.Global.AdelicGLSiegelShape`, unchanged: the matrices
`N · diag(ω) · diag(a(r)) · κ` with `N ∈ Ω_N`, every `ω i ∈ C`, `a(r i)` the positive real
idele with value `r i` at every infinite place and `1` at every finite place, `κ` in the
standard compact subgroup `standardCompact F n`, and `|a(r (i+1))| ≤ c · |a(r i)|` for the
normalized idele absolute value. The hypotheses on `Ω_N`, `C` and `c` are exactly those
satisfied by the data produced by the Library theorem
`PrimitiveAdelicHeight.exists_rational_mul_mem_siegelSetGL`, and also by any enlargement of
`Ω_N` by a compact set of unitriangular left factors.

Equivalently: for a fixed Siegel set `𝔖`, each rational orbit `GL_n(F) · g` meets `𝔖`
in at most `#{γ : γ𝔖 ∩ 𝔖 ≠ ∅}` points of the form `γ g`. This bounded multiplicity of the
projection `𝔖 → GL_n(F) \ GL_n(𝔸_F)` is what integration estimates over Siegel sets need.

## Provenance (derived)

Source: R. Godement, *Domaines fondamentaux des groupes arithmétiques*, Séminaire
Bourbaki 1962/63, exposé 257 (1964), registered as
`godement-1963-bourbaki-257-domaines-fondamentaux` (SHA-256
`b0a531469f376c1a56a7816f0fa579cd301c4162fb1c1aa8909c886e303c722d`), §10,
Théorème 9 (Borel), printed p. 216 (PDF page 17): « Soient 𝔖′ et 𝔖″ deux ouverts de
Siegel dans G_A ; alors l'ensemble des γ ∈ G_k tels que 𝔖′γ rencontre 𝔖″ est fini. »
Godement works over the base field `k = ℚ` (fixed on printed p. 201) with a connected
reductive `ℚ`-group `G`. His Siegel opens (§10, printed pp. 215–216) are
`𝔖 = M · T_∞⁺(c₀) · F`: `T` is a maximal `ℚ`-split torus, `T_∞⁺` the identity component
of the real Lie group `T(ℝ)`, `T_∞⁺(c₀)` its elements satisfying Godement's inequality
`α_i(t) < c₀` for the simple roots `α_i` of a minimal parabolic `P ⊇ T`; `F` is a relatively
compact open subset of `P_A⁰` (the elements of `P(A)` on which every rational character
has idelic absolute value one) with `P_A⁰ = F · P_ℚ`; and `M` is a compact set with
`G_A = M · P_A` whose archimedean image is a maximal compact subgroup adapted to `T_∞`.

### From a number field `F` to Godement's base field `ℚ`

Apply Godement's theorem to the Weil restriction `G = Res_{F/ℚ} GL(n)`, with
`d = [F : ℚ]`. Then `G(ℚ) = GL_n(F)` (the Library's `RationalGL F n`) and
`G(A_ℚ) = GL_n(𝔸_F)` (the Library's `AdelicGL F n`), compatibly with the rational
embedding `AdelicGL.rational`.

- The diagonal torus `T = 𝔾_m^n ⊂ Res_{F/ℚ}(𝔾_m^n)` (diagonal matrices with entries in
  `ℚ`) is a maximal `ℚ`-split torus. `T_∞⁺` consists of the diagonal matrices
  `diag(a(r_1), …, a(r_n))` whose `i`-th entry is the same positive real `r_i` at every
  infinite place of `F`, which is exactly the Library's `PositiveRealIdeles.full F (r i)`
  at the infinite places (and `1` at the finite places, where `T_∞` has no component).
- `P = Res_{F/ℚ} B` for the upper triangular Borel subgroup `B` is a minimal
  `ℚ`-parabolic containing `T`; the relative simple roots are `α_i(t) = t_i / t_{i+1}`.
  Its rational characters are generated by `N_{F/ℚ} ∘ t_i`, so
  `P_A⁰ = {p ∈ B(𝔸_F) : |t_i(p)|_{𝔸_F} = 1 for all i}` (normalized idele absolute value).
- The Library's `standardCompact F n` (orthogonal or unitary groups at the infinite places,
  `GL_n(𝒪_v)` at the finite places) satisfies `GL_n(𝔸_F) = K · B(𝔸_F)` and its archimedean
  part is a maximal compact subgroup adapted to `T_∞`: the Cartan involution
  `g ↦ (g*)⁻¹` inverts `T_∞⁺`.

### Root normalization

By the Library theorem `PositiveRealIdeles.absoluteValue_full`, the normalized idele
absolute value of `a(r)` is `r^d`. Hence the Library chamber condition
`|a(r (i+1))| ≤ c · |a(r i)|` says `(r_{i+1} / r_i)^d ≤ c`, i.e. the real root value
`r_{i+1} / r_i ≤ c^{1/d}`; it is the `d`-th power of the real root that is compared with
`c`, not the root itself. Fix any `c₀ > c^{1/d}`.

### Containment and conclusion

Write `h = N · diag(ω) · diag(a(r)) · κ` for an element of `siegelSetGL F n Ω_N C c`. Then

`h⁻¹ = κ⁻¹ · diag(a(r))⁻¹ · (diag(ω)⁻¹ N⁻¹)`.

- `κ⁻¹` lies in the adapted compact `M = standardCompact F n`.
- `t = diag(a(r))⁻¹ ∈ T_∞⁺` has simple-root values `α_i(t) = r_{i+1} / r_i ≤ c^{1/d} < c₀`,
  so `t ∈ T_∞⁺(c₀)` (for the strict or the non-strict form of the inequality).
- `diag(ω)⁻¹ N⁻¹` lies in `B(𝔸_F)`, and `|t_i| = |ω_i|⁻¹ = 1` because the `ω_i` are norm-one
  ideles; so it lies in `P_A⁰`. As `ω` ranges over `C^n` and `N` over `Ω_N`, these elements
  form a compact subset `Q` of `P_A⁰`. Choose any Godement fundamental open `F₀ ⊆ P_A⁰`
  (relatively compact, open, `P_A⁰ = F₀ · P_ℚ`; it exists by §8 since `P_A⁰ / P_ℚ` is compact)
  and a relatively compact open neighbourhood `F₁` of `Q` in the locally compact group
  `P_A⁰`. Then `F = F₀ ∪ F₁` is again a relatively compact open set with
  `P_A⁰ = F · P_ℚ`, containing `Q`. The compact `M` keeps Godement's adaptedness condition.

So `(siegelSetGL F n Ω_N C c)⁻¹ ⊆ 𝔖 = M · T_∞⁺(c₀) · F`, a Godement Siegel open. If
`γ h ∈ siegelSetGL` with `h ∈ siegelSetGL`, then `h⁻¹ γ⁻¹ ∈ (siegelSetGL)⁻¹`, so
`𝔖 γ⁻¹ ∩ 𝔖 ≠ ∅`; by Théorème 9 only finitely many `γ⁻¹`, hence finitely many `γ`, occur.
Central rational elements cause no exception: a central `γ = z · 1` with `z ∈ F^×` lies in
`G(ℚ)` and is covered by the same finiteness.

## Use

This is the reduction-theory input for square-integral estimates over Siegel sets in the
proof of joint admissibility of unitary cuspidal realizations (task
`8bbced72-78d7-454d-9328-2e7f0da33e8a`, cuspidal contragredient existence). Its proof is a
separate obligation.
