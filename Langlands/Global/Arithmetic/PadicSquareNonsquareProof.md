# Signed rational local squares avoiding a number field

`Langlands.Global.padicSquareNonsquare.{u}` proves exactly the published
`Langlands.Global.PadicSquareNonsquareStatement.{u}`. For every rational prime
`p`, arbitrary number field `K : Type u`, and Boolean `positive`, it supplies
a rational `d` of the prescribed strict sign which is a square in `Padic p`
and a nonsquare in `K`, using the canonical rational algebra maps. The theorem
has no additional outer hypotheses. It includes `p = 2` and does not require
`K` to be totally real or Galois.

The implementation chooses `d` to be a signed prime. Its private helpers
establish the following finite obstruction and local lifting arguments.

For a rational `s` with `s² = 1`, the `q`-adic valuation of `s` is zero,
so the valuation of `s*q` is one whenever `q` is prime. The rational
square criterion therefore makes `s*q` a nonsquare. The same criterion
shows that the product of two distinct primes is a rational nonsquare.
These are `signedPrime_not_isSquare` and
`distinctPrime_product_not_isSquare`.

The quadratic-field comparison is also proved in this module. If
`x² = d` with rational `d` nonsquare, then `x` is not rational.
The published `squareRoot_isIntegral` and `squareRoot_minpoly` results
give a power basis of dimension two for `ℚ⟮x⟯`. Consequently every
element of this field is `a + b*x` with `a,b` rational
(`sqrt_adjoin_expression`). If another irrational square root `y` of
`e` lies in that field, expanding `(a+b*x)² = e` gives a rational
multiple `2*a*b*x` equal to a rational scalar. Irrationality forces
`a*b = 0`; irrationality of `y` forces `b ≠ 0`, so `a = 0`.
Thus `e = b²*d` and `d*e = (b*d)²`. This proves
`sqrt_same_adjoin_product_isSquare`.

For fixed `s² = 1`, consider primes `q` for which `s*q` becomes a square
in `K`. Choose one root for each such prime and map it to the intermediate
field generated by that root. The comparison just proved makes this map
injective: equality of two fields would make
`(s*q)*(s*r) = q*r` a rational square, forcing `q = r`.
The primitive element theorem and finiteness of intermediate fields in a
finite separable simple extension make the codomain finite. This proves
`finite_signedPrimes_square_in_numberField`, without choosing a Galois
closure or imposing a signature on `K`.

The local helper `padic_isSquare_of_congruent_one` shows that an integer
`d` with `4*p ∣ 1-d` is a square in `Padic p`. Apply Hensel's lemma to
`X²-d` at `1` in the ring of p-adic integers. Writing `1-d = 4*p*k`,
the norm bound for p-adic integers gives

```text
‖1-d‖ ≤ ‖2‖² * ‖p‖ < ‖2‖².
```

This is the strict Hensel condition, since the derivative at `1` is `2`.
The proof uses `‖p‖ < 1` and `2 ≠ 0`; it does not assume that `2` is a
unit. In particular, for `p = 2` the modulus is `8`, and the same argument
applies. The resulting root in the p-adic integers maps to a root in
`Padic p`.

Finally, Dirichlet's theorem supplies infinitely many primes congruent to
`1` modulo `4*p` and infinitely many congruent to `-1` modulo `4*p`,
since both residue classes are units. For `positive = true`, remove the
finite obstruction set for `s = 1` and choose a prime `q` in the first
progression; take `d = q`. For `positive = false`, remove the obstruction
set for `s = -1` and use the second progression; take `d = -q`.
Both choices satisfy `d ≡ 1 mod 4*p`, so the local helper applies.
Primality gives the requested strict sign, and removal of the obstruction
set gives nonsquareness in `K`.
