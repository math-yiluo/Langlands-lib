# The index of `p`-th powers in S-unit groups

Author: Worker 226.

This module computes `[U_S : U_S^p]` for the `S`-units of a number field containing a
primitive `p`-th root of unity. The answer is `p ^ s`, where `s` counts the places in `S`
together with all infinite places. Along the way it proves the rank part of the `S`-unit
theorem. Everything is in namespace `Langlands.Global.Arithmetic.SUnitIndex`.

## Finitely generated abelian groups

- `index_nsmul_range_of_finite`: on a finite abelian group the image of `x ↦ n • x` has
  index equal to the order of its kernel. This follows from `|A| = |ker| · |range|` and
  `|A| = |range| · [A : range]`.
- `nsmul_range_prod`, `natCard_nsmul_ker_prod`, `nsmul_range_map_equiv`,
  `natCard_nsmul_ker_congr`: the image and the kernel of multiplication by `n` are compatible
  with products and with additive equivalences.
- `index_nsmul_range_pi`, `natCard_nsmul_ker_pi`: on `Fin r → ℤ` the image of
  multiplication by `n` is `∏ nℤ`, of index `n ^ r` (Mathlib's `AddSubgroup.index_pi` and
  `Int.index_zmultiples`). For `n ≠ 0` the kernel is trivial.
- `rank_pi_prod_of_finite`: `(Fin r → ℤ) × T` has rank `r` over `ℤ` when `T` is finite,
  by rank–nullity for the first projection. Its kernel is a copy of `T`, which has rank `0`
  because `|T| • x = 0`.
- `index_nsmul_range`: if `A` is finitely generated and `n ≠ 0`, then
  `[A : nA] = n ^ (finrank ℤ A) · |A[n]|`, where `A[n]` is the kernel of multiplication by
  `n`. Mathlib's structure theorem `AddCommGroup.equiv_free_prod_directSum_zmod` writes
  `A ≃ (Fin r →₀ ℤ) × T` with `T` a finite direct sum of `ZMod (p i ^ e i)`. The index and
  the kernel are then computed factor by factor, using the lemmas above.
- `index_pow_range`: the same statement for a commutative group `G` with `Monoid.FG G` and
  `n`-th powers. The rank is `finrank ℤ (Additive G)`. The proof passes to `Additive G`.

## S-units

Let `K` be a number field and `S` a finite set of finite places
(`S : Finset (HeightOneSpectrum (𝓞 K))`).

- `sUnits K S` is Mathlib's group of `S`-units `(↑S : Set _).unit K ⊆ Kˣ`: the elements of
  valuation `1` at every finite place outside `S`.
- `valuationVector K S : sUnits K S →* (S → Multiplicative ℤ)` sends an `S`-unit to its
  valuations at the places of `S`, via Mathlib's `HeightOneSpectrum.valuationOfNeZero`.
- `unitsToSUnits` views a global unit as an `S`-unit; it is injective
  (`unitsToSUnits_injective`). `range_unitsToSUnits` shows that its image is exactly the
  kernel of `valuationVector`. An element of the kernel has valuation `1` at every finite
  place, so it and its inverse are integral (Mathlib's
  `mem_integers_of_valuation_le_one`). `kerEquivUnits` is the resulting isomorphism
  `ker ≃* (𝓞 K)ˣ`.
- `exists_generator`: for every finite place `v` there is `g ∈ 𝓞 K`, `g ≠ 0`, with
  `g ∈ v` and `g ∉ w` for every other finite place `w`. Let `h` be the class number. Then
  `v^h` is principal, because the class of `v` has order dividing `h`
  (`ClassGroup.mk0_eq_one_iff`). Take a generator `g`. If `g ∈ w`, then `v^h ⊆ w`, so
  `v ⊆ w` and `v = w` by maximality.
- `generatorUnit K S v` is this `g`, as an `S`-unit for `v ∈ S`. Its valuation vector is
  trivial away from `v` (`valuationVector_generatorUnit_of_ne`) and nontrivial at `v`
  (`valuationVector_generatorUnit_ne`).
- `index_range_valuationVector_ne_zero`: the image of `valuationVector` has finite index.
  It contains the product over `v ∈ S` of the cyclic subgroups generated by the valuations
  of the `generatorUnit`s, and that product has finite nonzero index. `nonempty_rangeEquiv`
  then uses Mathlib's `Int.subgroup_index_ne_zero_iff`: the image is isomorphic to
  `S → Multiplicative ℤ`.
- `valuationVectorLinear` is the valuation vector as a `ℤ`-linear map of additive groups.
  `kerLinearEquiv` identifies its kernel with `Additive (𝓞 K)ˣ`. `rangeLinearEquiv`
  identifies its image with `S → ℤ`.
- Instances `Module.Finite ℤ (Additive (sUnits K S))` and `Monoid.FG (sUnits K S)`: a module
  is finitely generated when its image and kernel under a linear map are
  (`Submodule.fg_of_fg_map_of_fg_inf_ker`). The image is free of finite rank, and the
  kernel is the global units, which are finitely generated by Dirichlet's theorem.
- `finrank_sUnits` (the `S`-unit theorem, rank part): `finrank ℤ (Additive (sUnits K S)) =
  |S| + rank K`, where `rank K = r₁ + r₂ - 1` is Mathlib's `NumberField.Units.rank`. This is
  rank–nullity (`LinearMap.rank_range_add_rank_ker`) together with Dirichlet's unit theorem
  `NumberField.Units.finrank_eq`.
- `powKerEquivRootsOfUnity`: the `S`-units `x` with `x ^ p = 1` are exactly the `p`-th roots
  of unity of `K`. A root of unity has valuation `1` everywhere, since `ℤᵐ⁰` has no nontrivial
  torsion.
- `index_pow_sUnits` (main result): if `p` is prime and `ζ ∈ K` is a primitive `p`-th root of
  unity, then

  `[sUnits K S : (sUnits K S)^p] = p ^ (|S| + |InfinitePlace K|)`.

  By `index_pow_range` the index is `p ^ (|S| + r₁ + r₂ - 1) · |μ_p(K)|`. Here
  `|μ_p(K)| = p` (Mathlib's `IsPrimitiveRoot.card_rootsOfUnity`), and
  `r₁ + r₂ = |InfinitePlace K| ≥ 1`.

## Provenance

The index formula is E. Artin and J. Tate, *Class Field Theory* (2009), source
`artin-tate-2009-class-field-theory` (PDF page = printed page + 9), Chapter VI §3, formula
(1), printed p.24 (PDF p.33): if `S` consists of `s` primes, including all archimedean ones,
then `k_S` is free on `s - 1` generators modulo roots of unity and `(k_S : k_S^n) = n^s` when
`k` contains the `n`-th roots of unity. The same count appears in J. S. Milne, *Class Field
Theory* v4.03 (2020), source `milne-2020-class-field-theory`, Chapter VII §6, printed p.215
(PDF p.224): `U(S) ≈ ℤ^{s-1} × U(S)_tors` and `U(S)/U(S)^p ≈ (ℤ/pℤ)^s`. In this module `S`
contains only finite places and the infinite places are counted separately, so the
literature's `s` is `|S| + |InfinitePlace K|`. The derivation of the `S`-unit rank from
Dirichlet's theorem and the finite class group, and the general index formula for finitely
generated abelian groups, are standard and internal to this formalization. This module is
the first prerequisite of the prime-degree second inequality
(`Langlands.Global.AdelicFunctoriality.IdeleClassPrimeDegreeSecondInequality`).
