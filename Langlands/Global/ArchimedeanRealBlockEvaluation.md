# Compact block tensor evaluation for real standard modules

For ordered lists of real blocks `ds i`, the ambient real standard module has the concatenated list and rank equal to the sum of the block ranks. `realBlockSlice` compares its standard functions with the original standard functions of any individual block. The consecutive-coordinate embedding of `RealInductionStages` agrees with the corresponding block diagonal embedding. The normalized slice has the local principal series character because the position characters agree at the included positions. The Fourier coefficient comparison moves each low-weight test in a block to the ambient rotation at its translated position. Compact-finite vectors remain compact finite at a compact base point.

`realEvaluation` assembles those slices into a linear map from the ambient standard module to the algebraic tensor of the individual real standard modules at each compact point. Evaluating this tensor on a tuple of orthogonal block elements recovers the ambient standard function at the block diagonal element times the base point. This identity gives both compact covariance laws. Evaluation on the identity tuple and uniqueness of a principal-series function from its orthogonal restriction prove that the family detects every source vector.

This is an internal comparison for normalized induction in the given block order. It uses the function-level slice of induction in stages from Knapp and Vogan (1995), §11, (11.196), as implemented in `RealInductionStagesSlice`. Getz and Hahn (2024), §10.1, pp. 270–271 (PDF 282–283), describe normalized scalar Levi slices in the compact model.
