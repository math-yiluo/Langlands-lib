# Proof of the transport for conjugate Iwasawa compacts

Factor \(gt^{-1}\) and \(t^{-1}\) with the original Iwasawa compact. Combining the parabolic factors and conjugating the resulting compact factor gives a factorization of \(g\) with the conjugate compact.

If \(g=pk\) with \(k\in K\), then \(gt=pt(t^{-1}kt)\). The height for the conjugate compact is therefore \(H_K(g)+H_{K'}(t)\). This separates the parameter twist into the twist for the right-translated inducing function and a scalar independent of \(g\).

Pull the scalar through the rational coset sum defining each Eisenstein series and the integral defining the intertwining operator. The negative transported height power in the normalized operator contributes the second scalar.
