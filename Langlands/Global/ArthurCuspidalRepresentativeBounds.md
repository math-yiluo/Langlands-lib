# Weighted cuspidal bounds on norm-one representatives

Assume `ArthurSiegelSetsStatement` for the connected reductive group carrying the test function. The input is a finite plot-smooth rational-invariant function for the specified smooth structure and positive-size closed matrix embedding. It has uniform moderate growth on the full adelic group, with one exponent for all enveloping-algebra derivatives. Its constant terms along proper parabolics vanish.

Character restriction to the maximal split torus is a real bijection for the minimal parabolic because that torus is the split component of its Levi. A positive multiple of the generic defining cocharacter is a valid truncation parameter. Uniform moderate growth supplies the rapid decrease estimate for the truncated function. The vanishing constant terms identify this truncation with the original function.

The full-index Siegel covering gives a representative of every rational left coset. This representative remains in the norm-one group because rational points have norm one. For any nonnegative real weight, use an integer decay order at least as large and the lower bound of one for the normalized matrix height. The normalized height differs from the source norm by a fixed scalar, so the decay estimate gives one weighted bound on the chosen representatives of all norm-one rational cosets.

This is a reduction to the published statements of Arthur's covering and Proposition 13.2(a), using the derived bijectivity of the minimal-parabolic character restriction.
