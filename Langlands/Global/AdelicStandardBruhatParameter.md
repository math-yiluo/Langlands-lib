# The Weyl linear part of a Bruhat exponent

Each standard parabolic in the family has a lift of the same maximal split torus. Compatibility with the ambient inclusion identifies the composite of the smaller lift and the parabolic inclusion with the original lift. Restricting real characters to these lifts shows that restriction to a smaller standard parabolic preserves the original ambient parameter.

Apply the ambient Weyl parameter theorem after this restriction. The resulting parameter has ambient real part given by the Weyl action on the original ambient parameter. This determines the linear term used in the labels of the competing Bruhat exponents.
