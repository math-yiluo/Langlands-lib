# Actual split presentations trivialize scalar descent defects

This internal unit first proves that a scalar twist of an honest lift has the
coboundary of that scalar one-cochain as its defect. An actual matrix untwisting
a semilinear matrix action makes its chosen inner lifts scalar twists of the
honest lift `Q σ(Q)⁻¹`, so the actual scalar defect is an actual coboundary.

For an algebra given an actual ground-field matrix presentation, scalar extension
has a canonical matrix chart intertwining the coefficient actions. The published
inner comparison of two matrix charts compares any supplied splitting chart to
that canonical chart by an actual invertible matrix. This is an untwisting matrix
for the supplied chart's action and therefore trivializes its actual scalar
defect. The statement retains the actual chart, algebra presentation, and field
coefficient actions; no Brauer class or cohomological comparison is assumed.
