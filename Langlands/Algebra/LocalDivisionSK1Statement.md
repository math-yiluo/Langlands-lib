# Local division algebras have trivial reduced Whitehead group

`Langlands.CentralDivision.LocalSK1Statement.{u}` states local SK₁
vanishing using the actual canonical reduced norm.

For every nonarchimedean local field `F : Type u`, and every
finite-dimensional central division `F`-algebra `D : Type u`, it states

```text
ker (Dˣ → (F ⊗[F] D)ˣ → Fˣ) = commutator Dˣ.
```

The first map is the actual map on units induced by the tensor inclusion
`a ↦ 1 ⊗ a`. The second is
`Langlands.CentralSimple.reducedNormUnits F D F`, constructed from the
canonical reduced norm and characterized by determinant after matrix
splitting. Thus the left side is the subgroup of original units having
actual reduced norm one, and the right side is the actual subgroup
generated by group commutators. Neither subgroup is defined to be the
other.

The local field hypotheses are `Field`, `ValuativeRel`,
`TopologicalSpace` and `IsNonarchimedeanLocalField`, matching the local
Kneser–Tits target. The algebra hypotheses are exactly `DivisionRing`,
`Algebra F D`, `FiniteDimensional F D` and `Algebra.IsCentral F D`.
The division ring instance supplies ring simplicity for the canonical
norm construction. The common universe is arbitrary, and there is no
characteristic, degree, ramification or separability restriction.
No valuation on `D`, unramified subfield, cyclic generator, conjugating
unit, field-norm comparison or local SK₁ result is an additional premise.

The source is Jacques Tits, *Groupes de Whitehead de groupes algébriques
simples sur un corps*, Séminaire Bourbaki, exposé 505 (1977),
registered as `tits-1977-whitehead-bourbaki-505`, SHA256
`293a1b0637af56694914a6a4999b3bb56ae69d41444f748ad3fca037cce2f229`.
The introduction, printed page 218 / PDF page 2, defines
`SK₁(D) = SL₁(D)/(Dˣ)'`, with `SL₁(D)` the reduced-norm-one group.
Section 1.2, printed page 221 / PDF page 5, explicitly states
`SK₁(D) = 1` over local fields with finite residue field and explicitly
uses that local-field convention without a characteristic restriction.
Section 2, printed page 224 / PDF page 8, again identifies this as the
local and global SK₁ theorem.

This formal statement expresses the same vanishing as equality of the
actual norm kernel and the actual commutator subgroup, avoiding a
separate quotient definition. Any homomorphism to the abelian group
`Fˣ` kills commutators, so this equality is precisely triviality of that
source quotient. `Algebra.IsCentral` says the center is the scalar image;
the unital base-field map is injective, identifying the source's center
field with `F`. The canonical norm's determinant normalization agrees
with the source's reduced norm.

Tits also gives a valued-division-algebra route in sections 3.1–3.3,
printed pages 227–228 / PDF pages 11–12. Proposition 3.3 concerns a
commutative **residue** division algebra. Applying that route here would
require constructing the extended valuation and proving finiteness and
commutativity of the residue algebra, as well as the unramified-field,
conjugacy, norm-restriction and arbitrary-element reductions. These are
proof obligations, rather than hypotheses silently added to the
statement. No bound of two on the number of commutators is asserted.

This module only states the proposition. It supplies no proof, binary
matrix generation, group-scheme comparison, other rank-one cases or
proof of `LocalKneserTitsStatement`.
