## Actual maximum

The imported `Langlands.Algebra.RenardNilpotentDimensionMaximum` is
used unchanged. In it, `nilpotentGeneratedPhi l k` is the maximum
dimension of `Algebra.adjoin ℂ (Set.range a)`, taken over tuples
`a : Fin l → Module.End ℂ (Fin k → ℂ)` of pairwise commuting nilpotent
endomorphisms. This is Renard's `φ_l(k)`: the largest dimension of a
commutative subalgebra of `End(V)` generated by `l` nilpotent elements
and the identity, for `dim V = k`. The identity and the scalars lie in
the unital adjoin without being counted as generators. The module proves
that the maximum is attained by an actual tuple. It also proves the
ambient bound by `(dim V)²`, which on the canonical carrier gives
`φ_l(k) ≤ k²`.

The statement is purely numeric and has no carrier parameter.
The canonical carrier `Fin k → ℂ` loses no generality: the published
theorem `Langlands.Renard.nilpotentDimensionTransport` shows that the
maximum on every finite-dimensional complex carrier, in any universe,
equals `nilpotentGeneratedPhi l (Module.finrank ℂ V)`. This statement
does not import that theorem; it only records the interpretation that
the published Library already gives to `nilpotentGeneratedPhi`.

No abstract comparison function, recurrence, sharp estimate, maximizing
witness or splitting estimate is supplied as data or as a hypothesis.

## Domain and arithmetic

The quantified parameters are natural numbers `l` and `k` with
`1 ≤ l` and `1 ≤ k`.

The source needs a first generator `a_1` and writes `φ_(l-1)`, so it
works with `l ≥ 1`. Since `l` is positive, the natural subtraction
`l - 1` is the ordinary predecessor. This is the only natural
subtraction in the statement.

The source divides by `k = dim V`, so the statement requires `k ≥ 1`.
Dimension zero is excluded. In Lean the quotient by zero would be zero,
and the strict descent clause `⌊q⌋₊ < 0` would then be false.

The proposition binds the local real number

```text
q = (k : ℝ) - (nilpotentGeneratedPhi l k : ℝ) / (k : ℝ).
```

Both natural numbers are cast to `ℝ` before the quotient. The quotient
and the subtraction are real operations, so no natural-number division
or truncated subtraction occurs in the floor argument. The `let`
binding is only notation. A development check confirmed that the
declaration is definitionally the same proposition with `q` written out
in each clause.

The notation `⌊q⌋₊` is `Nat.floor q`. It uses Mathlib's floor on `ℝ`,
imported from `Mathlib.Algebra.Order.Archimedean.Real.Basic`. For
nonnegative `q` it is the ordinary integer floor `⌊q⌋` viewed as a
natural number (Mathlib's `Int.floor_toNat`). The first clause states
`0 ≤ q` as a conclusion. So the natural-number floor never replaces a
negative source argument by zero, and the first summand is the source's
`φ_l(⌊k - φ_l(k)/k⌋)` evaluated at a natural index.

## The three conclusions

For all such `l` and `k`, the conjunction states:

1. `0 ≤ q`.
2. `Nat.floor q < k`.
3. `nilpotentGeneratedPhi l k ≤
   nilpotentGeneratedPhi l (Nat.floor q) +
   nilpotentGeneratedPhi (l - 1) k`.

The third clause is the displayed source recurrence.

The first two clauses are derived details; Renard does not display
them. The source uses them implicitly. The floor must make sense as a
dimension, and the induction on printed p.276 / PDF282 applies the
induction hypothesis to the pair `(l, ⌊q⌋)`. That pair has the same
generator count and a strictly smaller dimension. The first clause
follows from the ambient bound `φ_l(k) ≤ k²`. The second follows from
`φ_l(k) ≥ 1`: on a nonzero space the unital adjoin contains the nonzero
identity. Then `q ≤ k - 1/k < k`. These two clauses are stated here,
not proved. A development check derived them from the published
maximum, base-case and monotonicity theorems; this confirms that the
clauses have the intended meaning.

### Boundary cases

- **Floor index zero.** When `⌊q⌋₊ = 0`, the first summand is the
  zero-dimensional value `nilpotentGeneratedPhi l 0`. It is the actual
  maximum on the zero space, which the published
  `nilpotentGeneratedPhi_zero` evaluates as `0`. The recurrence then
  reads `φ_l(k) ≤ φ_(l-1)(k)`. The zero-dimensional value is
  meaningful and is not a placeholder.
- **One-generator tail.** When `l = 1`, the tail summand is
  `nilpotentGeneratedPhi 0 k`, the actual maximum over the empty
  tuple. The empty tuple generates the scalar subalgebra. The published
  base-case theorem `Langlands.Renard.nilpotentDimensionBaseCases`
  evaluates this maximum as `1` for `k ≥ 1`. So for `l = 1` the
  recurrence reads `φ_1(k) ≤ φ_1(⌊q⌋₊) + 1`.
- **Dimension one.** The statement includes `k = 1`. There,
  `φ_l(1) = 1` by the published base cases, so `q = 0` and
  `⌊q⌋₊ = 0 < 1`. The recurrence compares `1` with
  `φ_l(0) + φ_(l-1)(1) = 0 + 1`. Renard derives the display for a space
  of arbitrary dimension `k`. His induction treats `k = 1` directly as
  the trivial case `φ_l(1) = 1`, and applies the display only for
  `k ≥ 2`. Including `k = 1` therefore matches the source derivation,
  although the source never uses that instance.

## Source route and remaining proof obligations

Renard's argument on PDF281 runs as follows. Take an algebra `R` of
maximal dimension, generated by commuting nilpotent `a_1, ..., a_l`.
Let `W` be a complement of `V_1 = I·V` in `V` and let `s = dim W`.
Since `R·W = V`, each element of `R` is determined by its restriction to
`W`, so `φ_l(k) ≤ s k`. Hence `k - s ≤ q`. Since `k - s` is a
nonnegative integer, `k - s ≤ ⌊q⌋`. Write `R = R' + R''`, where `R'` is
generated by `a_2, ..., a_l` and the identity and `R''` is the ideal
generated by `a_1`. Then `dim R' ≤ φ_(l-1)(k)`. Also `dim R''` is at
most the dimension of the restriction of `R` to `V_1`, so
`dim R'' ≤ φ_l(k - s)`. Monotonicity of `φ_l` in the dimension then
gives the display.

Each step of this route is a mathematical proof obligation for the
separate exact proof task. None of them is an assumption of this
statement. They include the choice of an attaining tuple and a
complement, the complement bound, the head/tail dimension comparisons,
transport from `V_1` to the canonical carrier, and monotonicity applied
to `k - s ≤ ⌊q⌋₊`. A future proof must import independently published
theorems for these steps, without assuming this conclusion. The
head/tail dimension statement, the maximizing-complement statement and
the complement-restriction proof keep their separate tasks and owners.
Renard's numerical contradiction for a strict counterexample, the final
bound and the remaining whole-book assertions are also separate.
