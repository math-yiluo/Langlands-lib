# Essential finite presentation under base change (Stacks 0AUF)

The module `Langlands.Algebra.EssFinitePresentationBaseChangeStatement` defines
`Langlands.Algebra.EssFinitePresentationBaseChangeStatement.{u, v, w} : Prop`.
It states the essential-finite-presentation part of Stacks Lemma 10.54.3
(tag 0AUF). This is a proposition definition; the module supplies no proof or
assumed theorem.

## Exact statement

```lean
def EssFinitePresentationBaseChangeStatement : Prop :=
  ∀ (R : Type u) (A : Type v) (B : Type w)
    [CommRing R] [CommRing A] [CommRing B]
    [Algebra R A] [Algebra R B],
    EssFinitePresentation R A → EssFinitePresentation B (B ⊗[R] A)
```

Both occurrences use the existing, unchanged
`Langlands.Algebra.EssFinitePresentation`. Its witnesses are a quotient
`MvPolynomial (Fin n) R ⧸ I` with `I.FG`, an arbitrary submonoid of that
quotient, and an `R`-algebra equivalence from its localization to the target.
In the conclusion the coefficient ring of the same predicate is `B`.

## Tensor product and algebra maps

The given algebra maps are `R → A` and `R → B`. The conclusion uses Mathlib's
actual commutative algebra tensor product `B ⊗[R] A`, with the ring structure
provided by `Mathlib.RingTheory.TensorProduct.Basic`.

Its `B`-algebra is the canonical left-factor instance
`Algebra.TensorProduct.leftAlgebra`, specialized to the self-algebra of `B`.
The algebra map is

```text
B → B ⊗[R] A,    b ↦ b ⊗ 1.
```

On pure tensors its scalar action is
`b • (b' ⊗ a) = (b * b') ⊗ a`. The right-factor map sends `a` to `1 ⊗ a`.
The balancing relation identifies `(algebraMap R B r * b) ⊗ a` with
`b ⊗ (algebraMap R A r * a)`. Thus the conclusion concerns precisely the
base change of the given map `R → A` along the given map `R → B`.
The statement quantifies over neither an additional algebra structure on the
tensor product nor an abstract pushout.

## Universes and hypotheses

The rings `R : Type u`, `A : Type v`, and `B : Type w` have three independent
universes. Mathlib constructs the tensor carrier as a quotient generated by
pairs of elements of `B` and `A`; it lies in `Type (max v w)`. The coefficient
universe `u` enters the balancing relation, without requiring an equality
between any of these universes.

All three rings are arbitrary commutative rings. In particular, zero rings are
allowed. The only premise beyond the given ring and algebra structures is
`EssFinitePresentation R A`. There is no local, Noetherian, flatness,
injectivity, nontriviality, or finite-presentation requirement on `B`.
The submonoids in the unchanged EFP predicate are arbitrary, including ones
containing zero or zero divisors; localization maps need not be injective.

([tag 00QM](https://stacks.math.columbia.edu/tag/00QM)), lines 163–174.

The source says that essential finite presentation is preserved by base change
and omits its proof. The Lean assertion specializes that ring-map property to
the tensor-product presentation of base change for commutative algebras. It
states the assertion for essential finite presentation only. Composition closure
and identifications of particular residue-field fibres are separate results.
