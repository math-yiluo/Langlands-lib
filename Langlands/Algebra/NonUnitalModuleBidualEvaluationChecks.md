The complete unapplied types check the actual `Bidual`, its named transported action and nondegeneracy, the full evaluation functional and its linear packaging, the original-local-fixer law and second-dual membership, the restricted original-module evaluation and canonical-scalar linear packaging, the iterated actual double pullback, whole-map naturality and the natural transformation into exactly the published left categorical composite. Every type quantifies its original rings, additive groups and specified actions before its hypotheses. No complex module on an original carrier is an input. The carrier, action, evaluation, both linear packages, target nondegeneracy, functor, natural transformation and whole component-map interfaces are also checked at both unequal algebra/carrier universe assignments `(0,1)` and `(1,0)`. The original-map interfaces are checked with unequal source and target universes in both directions. No universe inequality or carrier lift is required.

The `CompetingStructures` section introduces additional ambient original, first-dual and bidual actions and additional complex modules on all three carriers. Its initial equalities establish that ordinary instance inference selects these competing structures. The subsequent checks instead pass the original action explicitly, name `bidualAction` in the entire target Hom type and projected scalar-multiplication formulas, and install the published first-dual action and recovered scalar modules locally. The checks retain the evaluation intertwining law, its original bidual-action formula, full and restricted linear packages, first-dual pointwise scalar compatibility and complex linearity of evaluation. Overlapping-instance and unused-section-variable lint checks are disabled only in this section because those overlaps are its deliberate inputs.

The `RightModules` section specializes the generic construction to `Aᵐᵒᵖ`, retaining independent source and target universes for whole-map naturality. It makes no comparison with the actual right categorical composite. The `ZeroCarriers` section uses `PUnit` at independent universe levels. Its internal `punit_isNondegenerate` proof chooses the zero idempotent and uses equality in a singleton carrier. The checks instantiate original evaluation, its zero value and its canonical-scalar linear package for the zero module, the categorical natural transformation over the zero algebra, and evaluation when both algebra and module are zero.

The source supplies the canonical evaluation map. These complete-type checks and concrete compilation probes are derived internal validation details. The core proof constructs actual second-dual membership from an original idempotent fixing each input vector; it does not use fixed-part duality or separation. Injectivity, monomorphism, exactness, reflexivity and comparison with the actual right categorical composite remain outside this pair.
