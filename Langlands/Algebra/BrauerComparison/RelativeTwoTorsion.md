# Two-torsion in the relative Brauer class

`Langlands.BrauerComparison.RelativeBrauerTwoTorsionStatement` says that when the Brauer class of a central simple algebra is killed by two, the corresponding relative class in any matrix splitting chart is also killed by two. This follows from the existing comparison between tensor products and relative cohomology.

The tensor square has zero actual Brauer class, so it admits a matrix chart over the ground field. Its relative class is zero. The tensor splitting chart computes the sum of the original relative class with itself. Independence of chart and index identifies these two computations.

The module also shows that an algebra isomorphic to its opposite has Brauer class killed by two, since taking the opposite negates its class.
