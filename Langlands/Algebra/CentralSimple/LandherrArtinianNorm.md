# Binary norm equations in commutative Artinian rings

Module: `Langlands.Algebra.CentralSimple.LandherrArtinianNorm`.

- `exists_sq_eq_one_add_of_isNilpotent`: in a commutative ring in which `2` is a unit, `1 + n`
  is a square for every nilpotent `n`.
- `exists_sq_sub_mul_sq_eq_of_maximal`: in a commutative Artinian ring `R` in which `2` is a
  unit, let `d, c ∈ R` with `c` a unit. If `X² - d Y² ≡ c` is solvable modulo every maximal
  ideal, then `X² - d Y² = c` is solvable in `R`.

## Proofs

`exists_sq_eq_one_add_of_isNilpotent`: by induction on `k` with `n^(2^k) = 0`. With
`w₀ = 1 + n/2`, which is a unit, `(1 + n) / w₀² = 1 + m` with
`m = -(n/2)² / w₀²`, and `m^(2^(k-1)) = 0`; by induction `1 + m = w'²`, so
`1 + n = (w₀ w')²`.

`exists_sq_sub_mul_sq_eq_of_maximal`: an Artinian ring has finitely many maximal ideals,
which are pairwise coprime, so the Chinese remainder theorem
(`Ideal.quotientInfRingEquivPiQuotient`) gives `X₀, Y₀` with `X₀² - d Y₀² - c` in every
maximal ideal, hence in every prime ideal, hence nilpotent. Write
`X₀² - d Y₀² = c (1 + n)` with `n` nilpotent, choose `v` with `v² = 1 + n` (a unit), and take
`X = X₀ v⁻¹`, `Y = Y₀ v⁻¹`.

## Provenance

Standard commutative algebra (Chinese remainder theorem and lifting square roots through a
nilpotent ideal when `2` is invertible). It reduces the norm equation in the commutative
algebra generated by one element, used in the proof of Landherr's theorem, to its residue
fields.
