# Essential finite presentation under finite ideal quotients

The module `Langlands.Algebra.EssFinitePresentationFiniteQuotientStatement`
defines the proposition
`Langlands.Algebra.EssFinitePresentationFiniteQuotientStatement`.
It states that if a commutative `R`-algebra `B` is essentially of finite
presentation and `J` is a finitely generated ideal of `B`, then `B ⧸ J`
is essentially of finite presentation over `R`.
This file states the property; it does not prove it.

## Exact statement and algebra structure

```lean
def EssFinitePresentationFiniteQuotientStatement : Prop :=
  ∀ (R : Type u) (B : Type v) [CommRing R] [CommRing B] [Algebra R B]
    (J : Ideal B),
    EssFinitePresentation R B → J.FG → EssFinitePresentation R (B ⧸ J)
```

The universes `u` and `v` are independent. `J.FG` means that `J` is
finitely generated as an ideal of `B`. The quotient has Mathlib's canonical
commutative ring and `R`-algebra structures. In particular, the instance
`Ideal.Quotient.algebra` defines its structure map as

```lean
(Ideal.Quotient.mk J).comp (algebraMap R B)
```

Thus the map sends `r` to the class of `algebraMap R B r` modulo `J`;
`Ideal.Quotient.mk_comp_algebraMap` expresses this equality. No independently
chosen algebra structure on the quotient is quantified over.

The imported `Langlands.Algebra.EssFinitePresentation` is unchanged. It asks
for a finite-variable polynomial ring over `R`, a finitely generated ideal
`I` in that ring, an arbitrary submonoid of its quotient, and an `R`-algebra
isomorphism from the resulting localization to the given algebra.
The statement adds no Noetherian, local, domain, nonzero, or flatness
assumptions and imposes no equality between the universes. It includes the
unit ideal and zero quotient. Finite generation of `J` is required; this
is not a statement about arbitrary ideal quotients.

## Derived provenance

The source is the registered snapshot
`stacks-algebra-flatness-criteria-2026-10-22`, folder SHA256
`4bc1f2db6141508f6dad2132d4abc7963380cd71497ad20620c0e511b972a949`.
In `07DR.html`, Definition 10.54.1 (tag 00QM) defines essential finite
presentation as being a localization of a finitely presented algebra.
Comment #2262 specifies that localization permits an arbitrary
multiplicatively closed subset.

The proof of Lemma 10.128.9 (tag 05UV), in `05UV.html`, uses the property
for the intermediate quotients `B/J'` with `J'` finitely generated, where
`B` is a polynomial localization. After ideal stabilization, it uses
finite generation of `J` to conclude that `B/J` is essentially finitely
presented. The proposition here isolates the general algebraic closure
property underlying those steps. It is derived from the definition and
this use, rather than transcribed from a separately numbered lemma. The
local and flatness hypotheses of 05UV are not needed for this closure
property.

The informal justification is compatible with the explicit published
definition. Write `B` as a localization of
`A = R[x₁, …, xₙ]/I`, with `I` finitely generated, and transport a finite
generating family for `J` to that localization. Represent each generator
by a fraction. Its denominator is a unit, so the ideal generated by these
fractions is generated by their finitely many numerators. Choose polynomial
lifts of these numerators and adjoin them to the finite generators of `I`.
Localization commutes with the resulting quotient, giving `B/J` as a
localization of a polynomial ring modulo a finitely generated ideal.
The isomorphisms respect the displayed canonical map from `R`.
This paragraph explains the derived statement's provenance and the intended
proof route; no such closure proof is supplied by this statement module.
