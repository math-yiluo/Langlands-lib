# Right-module Hom interface checks

This companion contains internal compile-time checks of `NondegenerateRightHomFunctor`. Its source provenance and scope are those of the paired main module: these checks verify the implementation and do not formalize further assertions from Renard. The file imports only the general construction, so no specialization or coefficient hypothesis is needed.

The private interface abbreviations state entire unapplied types. The checks assign the actual declarations with `@`, retaining all ring, additive-group and original-action arguments, to those types. They cover the published named `rightSourceAction`, whole `ambientMap`, ambient functor, actual `homPart`, whole `partMap`, the composite and restricted functors and their equalities, both natural inclusions, whole-map composition and whole-map naturality. Each interface is checked at arbitrary independent universes and at complementary unequal 0/1 assignments. Output Hom carriers remain in exactly the maximum of fixed-source and variable-carrier universes. Composition retains independent intermediate and target universes.

The competing-structure sections place two ring structures and two additive groups on original carriers, alternative original source and variable actions, and an alternative residual Hom action in scope. Explicitly selected structures survive in the entire output carrier, group, named action and postcomposition additive map. A further test checks the actual part's inherited subgroup group and inherited module instance. The coincident-carrier test makes both rings, fixed source and variable carrier the same type while retaining independently supplied group/action choices. These are equalities by reflexivity; no transport or instance replacement is introduced. Only the overlapping-instance linter is locally disabled in these deliberate stress cases. The maximum-universe linter is disabled for private interface type abbreviations.

The subsingleton cases use the published Hom extensionality consequences for a subsingleton source or target, and inherit subsingletonness for the actual part.

The meaningful degenerate example uses the nonzero integer additive group for both source and variable module, with zero original left and right actions. Its actual right-linear Hom contains a nonzero identity additive map, witnessed by evaluation at `1`. Extensionality and preservation of zero show that every entire residual scalar endomorphism is zero. Idempotent fixation therefore forces a Hom to be zero, so the actual nondegenerate part is subsingleton and excludes the nonzero identity. The checks verify both the actual submodule inclusion and the natural inclusion component as subtype values, as well as the restricted identity map's subtype-value formula.

The regular integer example selects the actual regular left and right actions on the original integer carrier and their published commutation witness. The residual evaluation has order `a * b`. The identity Hom belongs to the actual part using the original-ring idempotent `1`; its inherited action has that same formula. A bundled nondegenerate right integer module also verifies the restricted object's carrier and the restricted natural inclusion's complete component. All proofs use extensionality, definitional equality, inherited instances and elementary integer ring identities.
