# Signed Casimir elements adapted to a Cartan involution

Module `Langlands.Algebra.SignedCartanCasimir` (namespace
`Langlands.Algebra.SignedCartanCasimir`). This is a supporting proof module for the adapted
Casimir element of Harish-Chandra, *Two theorems on semi-simple Lie groups* (Ann. of Math. 83,
1966), proof of Lemma 33, where `ω = ω_𝔭 - ω_𝔨` is formed from a Cartan decomposition
`𝔤 = 𝔨 ⊕ 𝔭` and an invariant form that is positive on `𝔭` and negative on `𝔨`. The module states
and proves only the linear-algebraic part, for an arbitrary finite-dimensional real Lie algebra
`L` with an invariant form and an involution; it makes no claim about Lie groups.

## Declarations

- `exists_orthonormal_basis_of_pos`: if `Q` is a symmetric real bilinear form on `L` and `Q x x > 0`
  for every nonzero `x` in a subspace `S`, then `S` has a finite basis `b` with
  `Q (b i) (b j) = if i = j then 1 else 0`.
  *Proof.* Mathlib's `LinearMap.BilinForm.exists_orthogonal_basis` gives a `Q|_S`-orthogonal
  basis; each vector has positive square, and is divided by the square root of it.
- `realGenerator : L →ₗ⁅ℝ⁆ UniversalEnvelopingAlgebra ℂ (ℂ ⊗[ℝ] L)`, `x ↦ ι(1 ⊗ x)`.
  It is the real-linear map `x ↦ 1 ⊗ x` followed by the complex generator map `ι` (restricted
  to real scalars). It preserves brackets because
  `⁅1 ⊗ x, 1 ⊗ y⁆ = 1 ⊗ ⁅x, y⁆` in the scalar extension
  (`LieAlgebra.ExtendScalars.bracket_tmul`) and `ι` is a Lie homomorphism.
- `ι_tmul`: `ι(z ⊗ x) = z • ι(1 ⊗ x)`.
- `mem_center_of_commute_real`: an element of `U(ℂ ⊗ L)` commuting with every `ι(1 ⊗ x)` is in
  the centre. *Proof.* Its centralizer is a complex subalgebra containing all `ι(1 ⊗ x)`, hence all
  `ι(z ⊗ x) = z • ι(1 ⊗ x)` and, by tensor induction, all of `ι(ℂ ⊗ L)`; the enveloping algebra is
  generated by these (`Langlands.Algebra.LieCasimir.enveloping_adjoin_range`).
- `sum_signed_eq`: for `J ⊆ Fin n`,
  `∑ i, (if i ∈ J then -1 else 1) • g i = ∑ i, g i - 2 • ∑ j ∈ J, g j`.
- `exists_signed_casimir` (main result). Let `L` be finite-dimensional, `B` a symmetric bilinear
  form with `B ⁅x, y⁆ z = B x ⁅y, z⁆`, and `s` a linear map with `s (s x) = x`,
  `B (s x) (s y) = B x y`, and `0 < B x (s x)` for `x ≠ 0`. Then there are `n`, `X : Fin n → L`
  and `J : Finset (Fin n)` such that the `X i` span `L`, `s (X j) = -X j` for `j ∈ J`, and
  `∑ i, ι(1 ⊗ X i)^2 - 2 • ∑ j ∈ J, ι(1 ⊗ X j)^2` lies in the centre of
  `UniversalEnvelopingAlgebra ℂ (ℂ ⊗[ℝ] L)`.

## Proof of `exists_signed_casimir`

1. Let `P = ker (s - 1)` and `K = ker (s + 1)`. They are complementary:
   `x = ½(x + s x) + ½(x - s x)`, and `s x = x = -x` forces `x = 0`.
2. For `x ∈ P` nonzero, `B x x = B x (s x) > 0`; for `x ∈ K` nonzero,
   `-B x x = B x (s x) > 0`. For `x ∈ P`, `y ∈ K`, `B x y = B (s x) (s y) = -B x y`, so
   `B x y = 0`.
3. Take a `B`-orthonormal basis of `P` and a `(-B)`-orthonormal basis of `K`
   (`exists_orthonormal_basis_of_pos`), combine them through
   `Submodule.prodEquivOfIsCompl` into a basis of `L` indexed by `Fin p ⊕ Fin k`, and reindex it
   by `finSumFinEquiv` to a basis `b` indexed by `Fin (p + k)`. Let `J` be the indices coming from
   `K`, and `ε i = -1` for `i ∈ J`, `ε i = 1` otherwise. Then
   `B (b i) (b j) = if i = j then ε i else 0`.
4. `B` is nondegenerate: `B x y = 0` for all `y` gives `B x (s x) = 0`, so `x = 0`; on the right,
   use symmetry. The `B`-dual basis of `b` is `ε i • b i`: both have the same coordinates in the
   dual basis, by `LinearMap.BilinForm.dualBasis_repr_apply` and step 3.
5. Hence the Casimir image `Langlands.Algebra.LieCasimir.casimirImage B hB b realGenerator`
   equals `∑ i, ε i • ι(1 ⊗ b i)^2`, which by `sum_signed_eq` is the required signed sum. By
   `Langlands.Algebra.LieCasimir.casimirImage_commutes_generator` (uses only invariance and
   nondegeneracy) it commutes with every `realGenerator x`, so it is central by
   `mem_center_of_commute_real`.
6. `X = b` spans `L` (`Basis.span_eq`), and each `X j` with `j ∈ J` is a vector of the basis of
   `K`, so `s (X j) = -X j`.
