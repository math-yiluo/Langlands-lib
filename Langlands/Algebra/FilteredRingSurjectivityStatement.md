# Finite-type surjectivity descent for filtered ring diagrams

Worker 105 states `Langlands.Algebra.FilteredRing.FiniteTypeSurjectivityDescent`
as a derived algebraic prerequisite for the closed-immersion clause of
Brian Conrad, *Weil and Grothendieck approaches to adelic points*
(2011), printed pp. 5–6, Theorem 3.4(2).
The registered source is
`conrad-2011-weil-grothendieck-adelic-points`, SHA-256
`fe4a9193aff4ef575665b40971f3da32f850a74d87b3f2d0fa28bba26b9cbabb`.
This algebra assertion is not quoted as a separate theorem in the paper.

Let `J` be a small filtered category, `A` and `B` actual diagrams of
commutative rings, and `α : A ⟶ B` a natural transformation. Let `cA`
and `cB` be actual cocones with colimit witnesses. The ring map
`φ : cA.pt ⟶ cB.pt` commutes with every cocone leg and `α`.
Choose an object `j₀` for which `α.app j₀` is a finite-type ring map.
For each actual arrow `r : j₀ ⟶ k`, require the naturality square
with sides `α.app j₀`, `A.map r`, `B.map r`, and `α.app k` to be a
categorical pushout of commutative rings.

If `φ` is surjective, there are an object `k` and an actual arrow
`r : j₀ ⟶ k` for which `α.app k` is surjective.
The arrow is part of the existential conclusion, so `k` is a later
stage relative to the chosen object. All category and ring sizes
share arbitrary universe `u`. No ring transition is required to be
injective, and no finite-presentation hypothesis is imposed.
Only the outgoing squares from `j₀` are required to be pushouts.

The derived provenance is the finite-generator argument underlying
closed-immersion descent on affine charts. Surjectivity at the
colimit lifts each of the finitely many generators to the other
diagram after passage to a later stage. Filteredness gathers these
equalities along a single arrow from `j₀`. The pushout ring is
generated by the images of its two incoming maps, which then lie
in the range of `α.app k`. This explains the finite-type
hypothesis, without assuming the desired later surjectivity.

This file defines only a proposition. A proof and the geometric
passage through actual affine charts and global sections are
separate obligations. In particular, this algebraic assertion alone
does not establish closed-immersion or separatedness descent, nor
the other properties or point topologies in Conrad's paper.
