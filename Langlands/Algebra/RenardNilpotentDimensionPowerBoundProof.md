# Renard C.I: the power bound on the actual nilpotent maximum

`Langlands.Renard.nilpotentDimensionPowerBound` proves the unchanged
`Langlands.Renard.NilpotentDimensionPowerBoundStatement`. For every natural
generator count `l` and dimension `k`, its conclusion is

```text
(nilpotentGeneratedPhi l k : ℝ) ≤
  Real.rpow (k : ℝ) (2 - Real.rpow 2 (1 - (l : ℝ))).
```

Here `Phi(l,k) = nilpotentGeneratedPhi l k` is the published actual maximum
of dimensions of unital complex algebras generated by `l` commuting
nilpotent endomorphisms of `Fin k → ℂ`. The identity and scalars belong to
the unital adjoin without counting as tuple entries. Zero and repeated
entries are permitted. The theorem has no carrier parameter or additional
hypothesis. Both subtractions in the displayed exponent and both powers
are real operations; the maximum is cast from the natural numbers.

## Implemented induction and boundary cases

The proof uses strong induction on `l`, with strong induction on `k` inside
each positive-generator case. The outer induction hypothesis applies at
every smaller generator count and every dimension. The inner hypothesis
applies at the same generator count and every smaller dimension.

The published `nilpotentDimensionBaseCases.{0}` handles three boundaries.
At `l = 0`, the actual maximum is zero for `k = 0` and one otherwise.
The real exponent is zero, so `Real.rpow (k : ℝ) 0 = 1`, including at zero;
the branch follows by simplifying this formula and splitting on `k = 0`.
At positive `l` and `k = 0`, the maximum is zero; the implemented proof
uses nonnegativity of `Real.rpow` at the nonnegative base zero. At `k = 1`,
the maximum is one and every real power of one is one. Thus the remaining
case has `1 ≤ l` and `2 ≤ k`, in particular a positive real denominator `k`.

The one-generator case is included in the induction step, as explained
below. The published base-case theorem also contains its Cayley–Hamilton
bound, but this implementation does not branch on that conclusion.

## Recurrence and the two induction hypotheses

In the remaining case, put, using real arithmetic,

```text
r = 2 - 2^(1-l),
D = k^r,
P = k^(2 - 2^((1-l)+1)),
q = k - Phi(l,k)/k.
```

Assume the strict counterexample `D < Phi(l,k)`. The exact theorem
`nilpotentDimensionFloorRecurrence` gives all three facts

```text
0 ≤ q,
n = Nat.floor q < k,
Phi(l,k) ≤ Phi(l,n) + Phi(l-1,k).
```

The strict descent is supplied by that theorem about the actual maximum.
It justifies applying the dimension induction at `n`, including when
`n = 0`. The outer induction applies at the natural predecessor `l-1`,
which is strictly smaller than `l` because `1 ≤ l`. These hypotheses give
`Phi(l,n) ≤ n^r` and `Phi(l-1,k) ≤ P`, after casting maxima to the reals.

For the second comparison the code explicitly proves

```text
1 - ((l - 1 : ℕ) : ℝ) = 1 - (l : ℝ) + 1.
```

It uses `Nat.cast_sub` with `1 ≤ l`, followed by cast simplification and
ring arithmetic. This is the only natural subtraction used for the
predecessor; the resulting exponent agrees with the real expression in
the numerical theorem. Casting the natural recurrence and adding the two
induction bounds yields `Phi(l,k) ≤ n^r + P` in the reals.

## Strict power comparison and the numerical contradiction

The exact theorem `commutativeDimensionNumericalContradiction` supplies
`1 ≤ r` and the final weak inequality

```text
(k-D/k)^r + P ≤ D.
```

Its published proof normalizes the expression by `D > 0`, sets
`x = k^(-2^(1-l))`, and uses `0 < 1-x < 1` and
`(1-x)^r ≤ 1-x`. This pair applies that theorem's conclusions directly.

Nonnegativity of `q` gives `(n : ℝ) ≤ q` by `Nat.floor_le`.
The strict counterexample and the positive denominator imply
`Phi(l,k)/k > D/k`, hence `q < k-D/k`. Therefore
`0 ≤ (n : ℝ) < k-D/k`. Since `r ≥ 1 > 0`,
`Real.rpow_lt_rpow` gives the strict inequality

```text
n^r < (k-D/k)^r.
```

Combining this with the cast recurrence and both induction hypotheses
produces

```text
D < Phi(l,k) < (k-D/k)^r + P ≤ D,
```

a contradiction. Strictness comes from the counterexample and this power
comparison; no strict version of the numerical theorem is required.
At `l = 1`, `r = 1`, the predecessor exponent is zero, and `P = 1`.
The numerical comparison is equality, `(k-1) + 1 = k`, so retaining its
weak inequality is essential and still closes the same contradiction.
