# Bounded generation of stable families of submodules

Author: Worker 1645.

This module proves a graded Hilbert-basis statement in elementary form, without
introducing graded rings. It is internal infrastructure for a uniform Serre
vanishing argument by induction on the number of degree-raising actions.

## Setting

Let `C` be a commutative ring, `N : ℕ → Type*` a family of `C`-modules, `r` a
natural number and `t i n : N n →ₗ[C] N (n + 1)` for `i : Fin r` a family of
`C`-linear maps. Write `⨁ n, N n` for Mathlib's direct sum.

- `total t` is the `C`-linear endomorphism of `⨁ n, N n` which sends the
  degree `n` summand to the degree `n + 1` summand through `t n`. The lemmas
  `total_lof`, `total_apply_succ` and `total_apply_zero` compute it on the
  canonical inclusions and on the components: the degree `n + 1` component of
  `total t x` is `t n (x n)`, and its degree `0` component is `0`.
- `total_comm` shows that `total t` and `total s` commute when
  `t (n + 1) ∘ s n = s (n + 1) ∘ t n` for all `n`.
- Suppose `comm`: `t i (n + 1) (t j n x) = t j (n + 1) (t i n x)` for all
  `i, j, n, x`. Then the endomorphisms `total (t i)` commute pairwise
  (`pairwise_commute`). `polyAct t comm` is the `C`-algebra homomorphism from
  `MvPolynomial (Fin r) C` to `Module.End C (⨁ n, N n)` that sends the variable
  `X i` to `total (t i)` (`polyAct_X`) and a constant `c` to multiplication by `c`
  (`polyAct_C`). It is Mathlib's `MvPolynomial.aeval` into the commutative
  subalgebra generated by these endomorphisms, followed by the inclusion.

## Main theorem

`exists_stable_generation` assumes:

- `C` is noetherian and every `N n` is a finite `C`-module;
- `comm` as above;
- generation in bounded degree: there is `N₀` with
  `⨆ i, LinearMap.range (t i n) = ⊤` for all `n ≥ N₀`;
- a family of submodules `K n ≤ N n` with `(K n).map (t i n) ≤ K (n + 1)` for
  all `i` and `n`.

It concludes that there is `N₁` such that
`K (n + 1) = ⨆ i, (K n).map (t i n)` for all `n ≥ N₁`. So the stable family `K`
is again generated in bounded degree. For `r = 0` the supremum over `Fin 0` is
`⊥`; the hypothesis then says `N (n + 1) = 0` for `n ≥ N₀`, and the conclusion
says `K (n + 1) = 0` for large `n`.

## Proof

Let `A = MvPolynomial (Fin r) C` act on `M = ⨁ n, N n` through `polyAct`
(`Module.compHom`). Each `N n` is spanned over `C` by a finite set. The canonical
images of these sets for `n ≤ N₀` form a finite set `G`. Induction on `n` shows
that the canonical image of every `N n` lies in the `A`-span of `G`: for
`n ≤ N₀` because constants of `A` act by the `C`-action, and for `n + 1 > N₀`
because `N (n + 1)` is spanned by the ranges of the `t i n`, and
`lof (n + 1) (t i n w) = X i • lof n w`. Hence `M` is a finite `A`-module.
Since `A` is noetherian (Mathlib's Hilbert basis theorem for finitely many
variables), `M` is a noetherian `A`-module.

Let `S k` be the `A`-span of the canonical images of `K n` for `n ≤ k`. This is
an increasing chain, so it is constant from some `D` on
(`monotone_stabilizes_iff_noetherian`). Let `W` be the set of `x ∈ M` with
`x n ∈ K n` for all `n` and `x (n + 1) ∈ ⨆ i, (K n).map (t i n)` for all
`n ≥ D`. It is closed under addition and the `C`-action. It is closed under each
`total (t i)` by stability of `K` and the component formulas. Induction on
polynomials (`MvPolynomial.induction_on`) shows that `W` is an `A`-submodule.
The generators of `S D` lie in `W`, because their components in degrees above
`D` vanish. Now let `n ≥ D` and `y ∈ K (n + 1)`. Its canonical image lies in
`S (n + 1) = S D ≤ W`, and taking the degree `n + 1` component gives
`y ∈ ⨆ i, (K n).map (t i n)`. The reverse inclusion is the stability
hypothesis.

## Provenance

Derived internal content. It is the finite-generation input of the dévissage
proof of the uniform vanishing in the proof of Stacks Project, Lemma 30.21.3
(tag [02OF](https://stacks.math.columbia.edu/tag/02OF)). That proof notes that
`⨁ n, 𝔪ⁿℱ/𝔪ⁿ⁺¹ℱ` is a graded module of finite type over `Gr_𝔪(A)`, generated in
degree zero, and applies graded Serre vanishing. The statement here is the
standard fact that a graded submodule of a finitely generated graded module over
a noetherian polynomial ring is finitely generated, hence generated in bounded
degree. It is formulated without graded rings, for direct use with sections of
sheaves.
