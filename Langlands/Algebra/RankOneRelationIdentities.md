# Identities from the rank-one open-cell relation

Author: Worker 4348.

Module `Langlands.Algebra.RankOneRelationIdentities`, namespace
`Langlands.Algebra.RankOneRelation`.

This is pure group theory over an arbitrary field `k` and an arbitrary group `H`. It
records consequences of the relation satisfied by linked root parametrizations of a split
rank-one group. In `SL₂` the elements are `x₊(X) = [[1, X], [0, 1]]`,
`x₋(Y) = [[1, 0], [Y, 1]]` and `h(u) = diag(u, u⁻¹)`. The module is a helper for the proof
that rational points of the centralizer of a maximal split torus lie in the subgroup
generated by the rational root groups, for a quasi-split simply connected group.

## The data

`Data k H` is a structure with fields:

- `xp xm : k → H`, additive into `H`: `xp (a + b) = xp a * xp b` and likewise for `xm`;
- `h : kˣ →* H`, a group homomorphism;
- `h_xm`: `h t * xm c * (h t)⁻¹ = xm (t⁻¹ ^ 2 * c)`. This is the action of the coroot
  `h = β∨` on the negative root group, since `⟨-β, β∨⟩ = -2`;
- `relation`: for all `X Y : k` and every unit `u` with `u = 1 + X Y`,
  `xp X * xm Y = xm (u⁻¹ * Y) * h u * xp (u⁻¹ * X)`.

The last field is the relation of the Library's `RootCell.RelationOver` on rational
points.

## Results

- `xp_zero`, `xm_zero`, `xp_neg`, `xm_neg`: additivity gives `xp 0 = 1` and
  `xp (-a) = (xp a)⁻¹`, and likewise for `xm`.
- `h_mul_xm`: `h t * xm c = xm (t⁻¹ ^ 2 * c) * h t`.
- `h_eq_word u`: for every unit `u`,
  `h u = (xm (u⁻¹ * (u - 1)))⁻¹ * xp 1 * xm (u - 1) * (xp u⁻¹)⁻¹`.
  This is `relation` with `X = 1` and `Y = u - 1`. So the coroot value `h u` is a word in
  root elements whose coefficients are polynomial in `u` and `u⁻¹`.
- `w c` (definition): `xm (-c⁻¹) * xp c * xm (-c⁻¹)`, the Weyl-type element.
- `w_mul_w_one_inv v`: for every unit `v`, `w v * (w 1)⁻¹ = h v`. The proof:
  1. `(w 1)⁻¹ = xm 1 * xp (-1) * xm 1`, by the negation lemmas.
  2. Merge `xm (-v⁻¹) * xm 1 = xm (1 - v⁻¹)`.
  3. Apply `relation` with `X = v`, `Y = 1 - v⁻¹` and `u = v`, since `1 + v (1 - v⁻¹) = v`.
  4. Cancel `xp 1 * xp (-1)` and move `h v` to the right with `h_mul_xm`.
  5. The coefficients of the remaining `xm` factors sum to `0`.
- `w_eq_h_mul_w_one v`: `w v = h v * w 1`.
- `InCell g` (definition): `g = xm Y * h t * xp X` for some `Y`, unit `t` and `X`. This is
  membership in the open cell, with torus factor in the image of `h`.
- `eq_neg_one_of_not_inCell e₁ e₂`: if neither `xm e₁ * xp 1 * xm e₂` nor its inverse
  satisfies `InCell`, then `e₁ = -1` and `e₂ = -1`.
  - If `1 + e₂ ≠ 0`, `relation` with `X = 1`, `Y = e₂` rewrites the element as
    `xm (e₁ + u⁻¹ e₂) * h u * xp (u⁻¹)` with `u = 1 + e₂`, so it lies in the cell.
  - If `1 + e₁ ≠ 0`, the inverse is `xm (-e₂) * xp (-1) * xm (-e₁)`. Then `relation` with
    `X = -1`, `Y = -e₁` puts the inverse in the cell.

  In the intended application, an opposite factor pair `(xm e₁, xm e₂)` of `xp 1` gives a
  normalizer element with nontrivial Weyl class. Such an element lies outside the open
  cell, and so does its inverse. So the opposite pair of `xp 1` is `(xm (-1), xm (-1))`,
  and its product is `w 1`.

## Provenance

These are the familiar `SL₂` matrix identities, which can be checked directly on the
matrices listed above. Here they are derived purely from the displayed relation, as an
internal helper. They introduce no assertion about any group scheme.
