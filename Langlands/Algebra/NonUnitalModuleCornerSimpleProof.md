## Implemented proof

The final theorem assembles the following component proofs, each documented
in its own same-stem Markdown.

1. `simpleFixedPart`, in `NonUnitalModuleCornerSimpleSubmodules`, applies
   categorical simplicity to the original stable subgroup generated by a
   corner submodule. Projection by `e` sends that subgroup back into the
   original corner submodule, so the latter is zero or the entire fixed part.
2. `simpleInducedQuotient`, in `NonUnitalModuleCornerSimpleInduced`, uses
   the fixed-part equivalence, generation of the induced quotient and
   vanishing of its `eA`-annihilator. Each stable subgroup has zero or full
   fixed part and is accordingly zero or the whole quotient.
3. `fixedPartInducedQuotient`, in
   `NonUnitalModuleCornerSimpleFixedComparison`, composes the published
   (I.3.2.1) and (I.3.2.2) linear equivalences. The composite forward map is
   exactly `w ↦ [e ⊗ w]`.
4. `inducedQuotientFixedPart`, in
   `NonUnitalModuleCornerSimpleEvaluation`, shows that a simple module
   with nonzero fixed part is generated and has zero annihilator. Evaluation
   therefore descends through the source annihilator quotient. The published
   kernel-annihilation lemma and surjectivity criterion make it bijective.
   That module assembles the four clauses as `simpleCorrespondence`.
5. `cornerEquivalenceCriterion`, in
   `NonUnitalModuleCornerEquivalenceCriterionProof`, proves necessity
   by reflecting the annihilator-quotient projection isomorphism, then
   quotienting a generated module by the image of the generated part of an
   arbitrary subobject. Sufficiency uses the actual corner/induction
   equivalence constructed in `NonUnitalModuleCornerEquivalenceConstruction`.
6. `generatedCategoryAbelian`, in the construction module, transports
   finite products and abelianness from ordinary corner modules. Mathlib's
   `abelianOfEquivalence` retains the inherited preadditive structure
   definitionally.
7. `cornerInductionInverse`, in `NonUnitalModuleCornerClosedEvaluation`,
   uses subobject closure to make the evaluation kernel generated. The
   published kernel lemma says `e` kills it, so it is zero; evaluation is
   already surjective by generatedness.

Every component theorem above belongs to
`Langlands.Algebra.NonUnitalModuleCornerSimpleProof`; the file names
identify its implementation location. The internal subgroup criteria,
explicit natural isomorphisms and concrete quotient reduction are derived
proof infrastructure. They introduce no assumed mathematical input.

The assembly in this file first forms `cornerEquivalence`, the three-clause
Theorem, and then pairs it with `simpleCorrespondence`. The implemented
route follows Renard's generation and quotient arguments, with the
zero-annihilator formulation replacing the maximal-kernel step for
evaluation on simple modules.
