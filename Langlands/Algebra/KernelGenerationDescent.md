# Descent of algebra generation by a linear kernel

Internal algebraic support for descent of primitive coordinate generation.
For a linear map from a commutative R-algebra B to an R-module V,
`kernelAdjoin` is the R-subalgebra generated by its kernel. If a faithfully
flat commutative scalar extension S has its extended algebra S tensor B
generated over S by the kernel of the extended linear map, then
`kernelAdjoin` is all of B.

Flatness identifies the extended kernel with the tensor image of the original
kernel. Thus the extended kernel lies in the scalar extension of kernelAdjoin.
The generation premise makes that extended subalgebra the whole tensor algebra.
Faithful flatness reflects surjectivity of the inclusion of kernelAdjoin into B.

An element of an algebra generated by a set uses finitely many members of that
set, by induction on algebra generation. In a finite-type algebra this extracts
a finite generating subset of any specified generating set. Consequently, under
the same scalar extension hypothesis, a finite-type B has a finite family of
kernel elements generating it as an R-algebra.

The ring, algebra, target module and scalar extension have independent universes.
No finiteness assumption on the whole kernel as a module is imposed. This result
does not identify a group scheme's primitive subspace with such a kernel or
prove the hypothesis of algebra generation after scalar extension.

`kernelAdjoin_eq_top_of_baseChange` uses the actual linear extension
`AlgebraTensorModule.lTensor S S d : S ⊗[R] B →ₗ[S] S ⊗[R] V`.
The premise is equality with top of its kernel's generated S-subalgebra.
The conclusion is `kernelAdjoin d = ⊤`, retaining the original coefficient
ring R. The proof uses Mathlib's `Module.Flat.ker_lTensor_eq` to express
each extended kernel element in the tensor image of `ker d`. Tensor
induction places it in `kernelAdjoin d` after scalar extension. The
subalgebra inclusion has surjective tensor extension, and
`Module.FaithfullyFlat.lTensor_surjective_iff_surjective` reflects that
surjectivity.

The imported `PTorsionHopf.exists_finset_of_mem_adjoin` extracts the finite support of a generated
algebra element, using singletons for specified generators and unions for
addition and multiplication. `exists_finset_generators` applies that
extraction to a finite algebra-generating set provided by
`Algebra.FiniteType`. Finally,
`exists_finite_kernel_generators_of_baseChange` returns
`T : Finset (LinearMap.ker d)` such that
`Algebra.adjoin R (Subtype.val '' T) = ⊤`.

All uses of faithful flatness are explicit hypotheses. The results apply
in particular to field extensions, and do not assume that the kernel is
finite dimensional. Their provenance is this internal assembly of the
existing flat-kernel and faithfully-flat-surjectivity theorems, with reuse of the published
finite-support induction. The group-theoretic interpretation and the
scalar-extension generation premise remain for the consumer.
