# Untwisting actual matrix descent from a scalar coboundary

supplied semilinear matrix-algebra action. A trivializing scalar one-cochain
rescales the actual inner matrices into an honest matrix one-cocycle. The
published finite-group matrix Hilbert90 theorem supplies an actual invertible

matrix, so this matrix untwists the entire original semilinear algebra action.
The extension field is finite-dimensional; no Galoisness or characteristic
restriction is needed for the untwisting identity.

For a finite Galois extension, conjugating ordinary base-field matrices by that
untwisting matrix maps them into the actual fixed algebra. This map is injective,
and the published actual descent equivalence makes its source and target finite
vector spaces of the same dimension. It therefore constructs an actual algebra

comparison or effective-descent premise is assumed; the comparison is constructed
from the stated actual chart and proved scalar coboundary condition.
