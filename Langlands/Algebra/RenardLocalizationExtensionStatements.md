# Inverse-power extensions characterize endomorphism localization

Authors: Worker 709 (statement design and draft) and Worker 922
(source recheck, compilation and submission).

This statement unit covers the converse in the final paragraph of the proof
of Renard's A.III.1 unnumbered lemma (ii), printed253/PDF259. It also states
the resulting unique comparison with the actual published localization.
The module imports only `Langlands.Algebra.RenardEndomorphismLocalization`.

`Langlands.Renard.EndomorphismLocalization`; none is proved here.

The source has formed the quotient L' by the union of the power kernels,
proved its induced operator a' injective, and identified L' with its image
in its localization. It then asserts the converse: if (M, beta) is an
extension of L', beta restricts to a', beta is invertible, and M is the
union of beta to the power minus n applied to L', then (M, beta) has the
universal property characterizing the localization of (L', a').

Here an injective linear map j represents the actual inclusion of the
source module in M. Using an arbitrary embedded module V in place of
the particular quotient L' is an internal abstraction of that paragraph.
The commutative-ring generalization is also internal; the source uses
an arbitrary field. The explicit unique equivalence with the actual
localization is a derived consequence of the converse and the uniqueness
of solutions to a universal problem, recalled at the top of PDF258.
These extensions and the explicit set-union encoding are not attributed
verbatim to the book. No result about the quotient L/K is assumed or
implemented in this unit.

## Actual objects, hypotheses and universes

The general statements quantify over a commutative unital ring
`R : Type u`, an additive group `V : Type v` with an R-module structure,
`a : Module.End R V`, and an additive group `M : Type x` with an R-module
structure. They take actual data

```lean
β : M ≃ₗ[R] M
j : V →ₗ[R] M
```

The automorphism β supplies both the invertible endomorphism
`β.toLinearMap` and its inverse `β.symm.toLinearMap`. These are actual
linear maps on M. The inverse is not asserted to be a scalar action.
The hypotheses are exactly:

1. `Function.Injective j`, expressing that M is an extension of V.
2. `∀ z : V, j (a z) = β (j z)`, expressing that β extends a.
3. The literal set-union exhaustion

   ```lean
   (Set.univ : Set M) =
     ⋃ n : ℕ, Set.range ((β.symm.toLinearMap ^ n).comp j)
   ```

The n-th range consists of the elements beta to the power minus n
applied to j(v), for v in V. Thus every element of M is an inverse
iterate of an element of the embedded source. The statement does not
replace this condition by the submodule generated by those elements.
Natural exponents include zero.

The coefficient, source, extension and universal-property target
universes u, v, x and w are independent. The actual `Localized a`
has carrier universe `max u v`, as in the imported construction.
No `Small` or universe-shrinking hypothesis is imposed.

There is no finite-dimension, finite-generation, Noetherianity,
nontriviality, nonzero-operator or stabilization hypothesis.
Injectivity of a need not be an additional hypothesis: it follows
mathematically from injectivity of j, the intertwining equation and
injectivity of β. That observation explains the faithful abstraction
of the source's a'; it is not a new theorem proved in this file.
The zero ring and zero module are permitted. A noninjective source
operator cannot satisfy these extension hypotheses.

## Exact proposition declarations

`ExtensionConverseStatement.{u,v,x,w}` asserts that every set of data
and hypotheses above satisfies

```lean
HasUniversalProperty.{u, v, x, w} a β.toLinearMap j
```

This reuses the published predicate. It quantifies over every actual
R-module `W : Type w`, every `b : Module.End R W` with `IsUnit b`, and
every linear f from V to W intertwining a with b. It concludes that
there exists a unique linear g from M to W such that
`g (β z) = b (g z)` for every z and `g.comp j = f`.
In particular, no universal property is an input hypothesis.

`ExtensionComparisonStatement.{u,v,x}` uses the same extension
hypotheses and asserts

```lean
∃! e : Localized a ≃ₗ[R] M,
  e.toLinearMap.comp (iota a) = j ∧
  ∀ z : Localized a, e (localizedEnd a z) = β (e z)
```

This is an actual linear equivalence, not an unspecified relation
between two carriers. Its first equation makes it the comparison
compatible with the embedded source and the canonical map.
Its second equation intertwines the actual localized operator and β.
Uniqueness is among all linear equivalences satisfying both equations.
It concerns an arbitrary inverse-power extension of V, rather than
the separate comparison between the localizations of V and V/K.

`FieldExtensionStatement.{u,v,x,w}` repeats the same quantifiers and
hypotheses for an arbitrary field k, and concludes both the universal
property and the unique compatible comparison. This gives the exact
field specialization of the abstract extension converse, with the
comparison consequence identified above.

`LocalizationExtensionStatements.{u,v,x,w}` is the closed aggregate
conjunction of `ExtensionConverseStatement`,
`ExtensionComparisonStatement` and `FieldExtensionStatement`.
The aggregate introduces no ambient parameters or extra assumptions.
