# A polynomial quotient retaining a finite monomial box

This derived algebraic construction starts with a field `k`, an arbitrary
variable type `sigma`, and a finitely supported bound `N : sigma -> Nat`.
The quotient is the polynomial ring modulo all monomials outside the
coordinatewise lower box `a <= N`. The definition `boxIdeal` uses Mathlib's
`MvPolynomial.restrictSupportIdeal` for the upper set complementary to that
box. `mem_boxIdeal` identifies this condition with the vanishing of every
coefficient in the box. `boxIdeal_eq_span` proves that the ideal is exactly
the ideal generated by `X i ^ (N i + 1)`, using Mathlib's characterization
of membership in a monomial ideal.

`boxAlgebra N` is the actual quotient commutative algebra. Its universal
parameter in coordinate `i` is the image of `X i`, and its power
`N i + 1` vanishes. The linear functional `coefficient N a ha` extracts
the coefficient of exponent `a <= N` from an element of this quotient.
Evaluating any polynomial at the universal tuple and applying this
functional returns the polynomial's original coefficient at `a`.
For every commutative `k`-algebra `A`, a tuple satisfying these same power
relations determines a unique `k`-algebra homomorphism from `boxAlgebra N`
to `A`, given by `lift`. No reducedness, characteristic or infinitude
hypothesis on these algebras is required.

The simultaneous coefficient map is a linear equivalence with all scalar
functions on `Set.Iic N`. Surjectivity uses the sum of the corresponding
monomials, and injectivity uses the defining vanishing condition of
`boxIdeal`. Thus the quotient is finite dimensional with dimension
the product of `N i + 1` over the support of `N`, including dimension
one when `N = 0`.

Multiplication by the class of the complementary monomial `N - a`
recovers the coefficient at `a` as the top coefficient at `N`. This
follows directly from the polynomial monomial-product coefficient
formula and `N - (N - a) = a` for `a <= N`. Consequently every nonzero
element has a multiplier whose product has nonzero top coefficient:
the top-coefficient multiplication pairing is nondegenerate.

This unit has no external source assertion. It concerns an explicit
polynomial quotient, without any group action or root coordinate premise.
It does not prove existence or irreducibility of Steinberg representations.
