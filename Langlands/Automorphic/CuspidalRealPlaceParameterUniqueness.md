# Real parameter comparison for cuspidal classes

The proof takes the local real standard-module comparison as a premise.
It obtains an irreducible admissible real-place component of a cuspidal
realization and maps it to the quotient presentation with zero
denominator. The restriction is isotypic for this component by
`isRealPlaceIsotypic_restrict`, the isotypic restriction argument of
Flath (1979), end of the proof of Theorem 1, p. 180 (one-based PDF
p. 176).

Each real parameter specifies an injective standard-module map. The
proof transports both maps to the quotient and applies
`RealStandardIsotypicParameterUniquenessStatement` to the common
isotypic restriction. Its conclusion is equality up to permutation
of the Mœglin data, as explained in the statement's paired Markdown.
The class version uses a representative and the class invariance of
the parameter condition.
