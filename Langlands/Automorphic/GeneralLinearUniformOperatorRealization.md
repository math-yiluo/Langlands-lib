# Uniform adelic forms of `GL_n` as an operator realization

Fix a number field `F`, a rank `n`, and the actual general linear group scheme
`GL_n` over `F`. Fix also a matrix representation `rho` of `GL_n` of dimension
`N`. This module uses `rho` only through the published full adelic height
`RepresentationGrowth.adelicHeight F GL_n rho`.

## The matrix-side uniform-growth condition

`IsGeneralLinearUniformGrowth F n rho f` is a predicate on a function `f` in
the original matrix carrier `FiniteSmoothRationalFunctions F n`. That carrier
holds the `GL_n(F)`-invariant continuous functions on `GL_n(𝔸_F)` that are
smooth at the infinite places and have one common open finite-adelic
stabilizer. The predicate says that there is one natural exponent `e` such
that every element `a` of the original enveloping algebra
`ArchimedeanGL.EnvelopingAlgebra F n` has a constant `C ≥ 0` with

`|(a·f)(g)| ≤ C · H_rho(g)^e` for every `g ∈ GL_n(𝔸_F)`.

Here `a·f` is the published `finiteSmoothEnvelopingAction`, and `H_rho(g)` is
the height of `rho` at the actual group-scheme point corresponding to `g`
under `GeneralLinearGroupPoints.adelicHomeomorph`. The predicate is
definitionally the right-hand side of the published
`hasAdelicUniformPolynomialGrowth_iff_generalLinear`. It is therefore the
transport of the group-scheme condition `HasAdelicUniformPolynomialGrowth`.
That condition carries the bound quantifiers of Getz–Hahn Definition 6.3.1
(uniform moderate growth): one exponent, chosen before all `X ∈ U(𝔤)`. The
exponent is a natural number and the height is the dimension-scaled one; the
published `hasAdelicUniformModerateGrowth_iff` shows this is equivalent to the
real-exponent bound for the exact norm.

The predicate is closed under the following operations:

- zero, addition and scalar multiplication. Addition takes the larger
  exponent and uses `H_rho ≥ 1`, which needs `0 < N`.
- every enveloping operator. The bound for `a` applied to `b·f` is the bound
  for `a*b` applied to `f`, with the same exponent.
- right translation by any adelic point `x`. `norm_evaluate_rightAction_le`
  uses the published submultiplicativity `H_rho(gx) ≤ H_rho(g)·H_rho(x)`, so
  the constant is multiplied by `H_rho(x)^e`. For a finite-adelic `x`,
  translation commutes with every enveloping operator. For an
  infinite-adelic `x`, the published covariance
  `finiteSmoothRightAction_envelopingAction` gives `a·(R(x)f) = R(x)(a'·f)`,
  where `a'` is the image of `a` under the inverse of
  `ArchimedeanGL.envelopingConjugation F n x`. The bound for `a'` then gives
  the bound for `a`.

`generalLinearUniformGrowthSubmodule F n rho hN` is the resulting complex
subspace. By the published `operator_invariant_iff`, it is invariant under the
whole concrete operator algebra `automorphicOperatorAlgebra F n`. That algebra
is generated by finite translations, standard infinite compact translations
and enveloping operators.

## The invariant subspace and the operator realization

`uniformGeneralLinearFormSubrepresentation F n rho hN` is the subrepresentation
of the published `fullAutomorphicAction F n` that consists of the original
automorphic forms satisfying the predicate. These forms are the published
`AutomorphicForms F n`, and the operator algebra acts on all of them.
`uniformGeneralLinearOperatorRealization F n rho hN` is the existing
`OperatorRealization` that corresponds to this subrepresentation under the
published order isomorphism `operatorRealizationFullFormOrderIso`. Its
`fullFormImage` equals the subrepresentation.

## Comparison with the group-scheme uniform forms

The remaining results take further hypotheses: a smooth atlas `hsmooth` of
relative dimension `d`, the scalar-commutator premise `hcalc`, a closed
embedding `hrho`, `0 < N`, and connected reductivity `hG`. With these,
`UniformGeneralLinearAdelicForms` abbreviates the published actual uniform
adelic forms
`uniformAdelicAutomorphicSubrepresentation` for the transported standard
maximal compact `generalLinearStandardInfiniteCompact F n`.

- `mem_uniformAdelicAutomorphic_iff_generalLinear`: an actual function lies in
  this space exactly when its matrix function under
  `finitePlotSmoothGeneralLinearEquiv` is an original automorphic form that
  satisfies the predicate. The full adelic moderate-growth conjunct in the
  group-scheme form definition is then automatic: it is the bound for the
  identity differential.
- `range_uniformAdelicAutomorphicGeneralLinearMap`: the range of the
  published injection `uniformAdelicAutomorphicGeneralLinearMap` is exactly
  the subrepresentation above.
- `uniformAdelicAutomorphicGeneralLinearEquiv` is the resulting linear
  equivalence onto the subrepresentation. It keeps the underlying matrix
  function. The equivalence carries the actual enveloping action to the
  original differential operator of the corresponding enveloping element
  under `GeneralLinearGroupPoints.infiniteEnvelopingEquiv`. It carries actual
  finite translation by `c` to the original finite operator of
  `GeneralLinearGroupPoints.finiteHomeomorph F n c`.
- `uniformAdelicAutomorphicRealizationEquiv` composes this with the published
  `fullFormEquiv` inverse. The result is a linear equivalence onto the space
  of `uniformGeneralLinearOperatorRealization`, which keeps the underlying
  matrix function.
- `finitePlotSmoothGeneralLinearEquiv_infiniteSubgroupAction`: the function
  equivalence carries right translation by an element `k` of an infinite
  subgroup to matrix right translation by the corresponding original point.
- `uniformAdelicAutomorphic_infiniteSubgroupAction_mem`: the actual uniform
  space is closed under right translation by
  `generalLinearStandardInfiniteCompact F n`. The translate's matrix function
  is a translate by the original standard compact. That translate is again a
  form (`fullAutomorphicSubrepresentation`) and again satisfies the
  predicate. `uniformAdelicAutomorphicCompactSubrepresentation` packages
  this closure as a subrepresentation of
  `finitePlotSmoothInfiniteSubgroupAction`.

The compact-translation closure was listed as open in
`GeneralLinearAdelicUniformForms`. This module proves it for `GL_n` and the
transported standard maximal compact only.

## Provenance

The content is internal: it is derived from published Library constructions.
Getz–Hahn, *An Introduction to Automorphic Representations*, Definition 6.3.1
(printed pp. 161–162), defines uniform moderate growth; it is cited only for
that definition. The published `GroupSchemeAdelicUniformGrowth` explains how
the Library carrier differs from the Getz–Hahn smooth space (6.1), which is an
algebraic tensor product. That difference is unchanged here.

## Scope

The module does not prove:

- that every original automorphic form has uniform growth, so the
  subrepresentation may be proper.
- that the subrepresentation or realization is irreducible, cuspidal or of
  some central character.
- independence of the embedding `rho`.
- any statement for groups other than `GL_n`, or for other maximal compacts.
- any comparison with `L²` spaces or square integrability.
