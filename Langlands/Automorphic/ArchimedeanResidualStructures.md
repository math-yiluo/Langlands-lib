# Compact and Lie structures on residual multiplicities

This internal construction for the proof of
`CuspidalTransposeInverseContragredientStatement` equips simultaneous compact and
Lie multiplicities with every remaining commuting group representation
and complex Lie action. It packages the existing postcomposition
endomorphisms into a representation and a Lie homomorphism.

The representation and Lie laws follow by evaluating each multiplicity
map at a source vector and applying the corresponding laws on the
original target. The same pointwise argument preserves commutation of
any two remaining operators. Tensor evaluation carries these residual
actions on its second factor to the original target actions.

The result uses arbitrary groups, Lie algebras and carrier universes.
Only the stated commutation with the removed factor is required. It
provides the action structures needed for repeated factor separation,
without asserting residual irreducibility, local factor existence or a
pairing.
