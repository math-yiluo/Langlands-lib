# From Hilbert slice comparison to the mixed tensor comparison

Take an actual cuspidal operator realization over a number field with
compact additive adele quotient. Supply a continuous unitary character
acting as its central character and a unitary form computing the
canonical determinant-band inner product. The original finite operators
intertwine with the mixed finite action along a supplied map whose
underlying values are the original Hilbert embedding.

For a standard additive character and under continuous unitary Whittaker
uniqueness at real and complex places, this gives the archimedean
condition for the mixed tensor comparison. Each fixed-context infinite
slot with a nonzero first restriction has proportional restrictions of
the two mixed Whittaker functionals.

The actual slice comparison already supplies the scalar equality along
the algebraic slice map. The pointwise equality between the tensor
functional slot and that restriction is equality of linear maps, so
the same scalar satisfies the required tensor condition. This is an
internal bridge between the Hilbert and multilinear steps.
