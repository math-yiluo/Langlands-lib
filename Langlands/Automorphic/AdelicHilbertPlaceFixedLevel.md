# Fixed-level smooth place embeddings for an adelic Hilbert completion

In an adelic Hilbert completion with bounded operators compatible with
the original action, the actions of the finite adelic group and the
archimedean group in mixed coordinates commute. This follows by applying
the bounded representation to the commutation identity in the adelic
matrix group.

The `SupportsRealPlaceFixedSmoothRealization` and
`SupportsComplexPlaceFixedSmoothRealization` properties concern the
closure of each irreducible admissible place component in that same
completion. If a supplied finite subgroup fixes the component under the
original finite operators, the original inclusion on the component
extends to a continuous local-to-global smooth map into that fixed Hilbert
level. The map uses the closure's actual local action and the global
representation's actual archimedean restriction. The genuine derivative
topologies are used on both sides.

The place support theorems take the given local Hilbert realizations,
ambient unitarity and smoothness of the embedded algebraic vectors. They
transfer the subgroup's algebraic fixing identity to the embedded image
using bounded finite-operator compatibility. The actual smooth place
splitting and fixed-level closure theorem give the result. This is an
internal consequence of the adelic and Hilbert comparison interfaces.
