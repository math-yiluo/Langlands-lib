# Closed embeddings for automorphy on the rational quotient

Two closed matrix embeddings of an affine number-field group define the same automorphic functions on its rational quotient. The statement fixes the infinite compact, smooth dimension, and differential data and allows either matrix size to be zero.

For positive sizes, continuity and rational invariance put the underlying function in `ContinuousRationalFunctions`. The published growth-independence theorem then compares the only condition that uses the embedding. A closed embedding of size zero makes the group of adelic points a subsingleton, so every function has a bound with exponent zero for either norm. This comparison is used for the two ambient matrix embeddings restricted to one Levi in the Eisenstein cusp tests.
