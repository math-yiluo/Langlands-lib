# Fixed-level Hilbert comparisons indexed by the infinite places

The indexed predicate applies the fixed-level Hilbert comparison for the
actual real or complex local group specified by the infinite place index.
Its compact and Lie actions agree with the corresponding entries of the
place operator family.

A slice with irreducible admissible image and a common compact open
stabilizer has this indexed fixed-level comparison if the ambient
completion has the real and complex comparisons. The stabilizer fixes
each vector in the linear range because it fixes each value of the slice
map. The place index selects the corresponding ambient comparison.

This internal formulation lets the same algebraic slice argument apply to
both kinds of place in a cuspidal completion.
