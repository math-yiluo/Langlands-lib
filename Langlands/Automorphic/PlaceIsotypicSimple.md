# Isotypic place actions and scalar vectors

Module `Langlands.Automorphic.PlaceIsotypicSimple`, namespace
`Langlands.Automorphic.PlaceIsotypic`. Worker 5665 wrote it for Task 7399, as a step in the
proof of `ComplexPlaceParameterIrreducibleStatement`. Provenance: internal.

The module is abstract module theory. It uses Mathlib's semisimple and isotypic modules
(`IsSemisimpleModule`, `IsIsotypicOfType`, `isotypicComponent`, module
`Mathlib.RingTheory.SimpleModule.Isotypic`).

## Simplicity from a scalar vector

`isSimpleModule_of_scalar`. Let `R` be a `ℂ`-algebra and `M` an `R`-module (with compatible
`ℂ`-scalars) that is semisimple and isotypic of a simple type `S`. Suppose `f₀ ∈ M` is nonzero
and every `R`-linear endomorphism `E` of `M` has `E f₀ = a • f₀` for some `a ∈ ℂ`. Then `M` is
simple.

Proof. By `IsIsotypicOfType.linearEquiv_finsupp`, `M ≃ ι →₀ S` for some index type `ι`.
Write `φ` for the image of `f₀`, and pick `i` with `φ i ≠ 0`. Suppose `j ≠ i`. The endomorphism
"move the `i`-component to `j`" (`Finsupp.lsingle j ∘ Finsupp.lapply i`, conjugated back to
`M`) maps `f₀` to `a • f₀` for some `a`. Compare components:
- at `i`: `0 = a φ i`;
- at `j`: `φ i = a φ j`.

If `a = 0` the second gives `φ i = 0`. If `a ≠ 0` the first does, since `a` is invertible. Both
contradict the choice of `i`. So `ι` is a subsingleton, and `M ≃ S`
(`Finsupp.uniqueLinearEquiv`) is simple.

## The operator algebra of a place action

Let `V` be a complex vector space with a representation `κ` of a group `K` and a Lie algebra
action `π` of `𝔤`.

- `opAlg κ π`: the subalgebra of `End V` generated by all `κ k` and `π X` (`Algebra.adjoin`).
  `V` is a module over it (Mathlib's `Subalgebra.moduleLeft`). `compact_mem_opAlg` and
  `lie_mem_opAlg` say the generators lie in it.
- `apply_mem_of_isStable`: every element of `opAlg κ π` preserves a subspace that is stable in
  the sense of the Library's `PlaceComponent.IsStable` (by `Algebra.adjoin_induction`).
- `toOpSubmodule Z hZ`: a stable subspace as an `opAlg κ π`-submodule with the same carrier.
  `mem_toOpSubmodule` unfolds membership.
- `isStable_restrictScalars`: conversely, an `opAlg κ π`-submodule is stable.
- `comm_of_mem_opAlg`, `toOpLinear`: a linear map commuting with all `κ k` and `π X` commutes
  with all of `opAlg κ π`, hence is `opAlg κ π`-linear.
- `isSimpleModule_toOpSubmodule`: an irreducible stable subspace
  (`PlaceComponent.IsIrreducible`) is a simple `opAlg κ π`-module (`isSimpleModule_iff_isAtom`).
- `isSemisimple_isotypic_of_commutant`. Suppose `W₀` is an irreducible stable subspace, and
  every subspace stable under `κ`, `π` and every linear map commuting with them is `⊥` or `⊤`.
  Then `V` is a semisimple `opAlg κ π`-module, isotypic of the type of `W₀`.
  - The isotypic component `C` of `W₀` is mapped into itself by every `opAlg κ π`-linear
    endomorphism (`LinearMap.le_comap_isotypicComponent`), so by every map commuting with
    `κ` and `π` (`toOpLinear`).
  - It is also stable, so `C = ⊥` or `C = ⊤`. It contains `W₀ ≠ ⊥`, so `C = ⊤`.
  - `C` is semisimple (Mathlib instance), hence so is `V`
    (`isSemisimpleModule_of_isSemisimpleModule_submodule'`).
  - Isotypy is `IsIsotypicOfType.of_isotypicComponent_eq_top`.

All results use only the axioms `propext`, `Classical.choice` and `Quot.sound`.
