# The mixed tensor comparison for a standard complex character

For the mixed cuspidal tensor comparison, a standard complex additive
character has a bundled unitary character with the same complex values.
Its restriction to the diagonally embedded number field is trivial by
equality of the underlying complex values in the circle.

If the supplied original mixed and archimedean source maps agree, the
fixed-level source images are derivative-dense, and the archimedean
slice comparison holds for the bundled character, the mixed tensor
comparison gives uniqueness for the original character. This is an
internal application of the character and comparison interfaces.
