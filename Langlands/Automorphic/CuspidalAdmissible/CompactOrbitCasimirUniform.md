# A common compact Casimir annihilator

Fix a compact-finite vector in a source representation and any actual
automorphic operator realization as a target. The source vector's
compact orbit spans a finite-dimensional subrepresentation. Choose
coordinates on that span to apply the Library's uniform compact
Casimir annihilator for a fixed finite-dimensional source.

Every compact intertwiner from the source restricts to an intertwiner
from this span. The same nonzero polynomial therefore annihilates the
compact Casimir on the image of the original vector under all such
intertwiners. The argument also applies after restricting a larger
group action along a homomorphism from the block compact, since the
restricted orbit span is contained in the original one.

This is an internal application of compact Casimir uniformity. It supplies
the compact polynomial shared by the one-coordinate Levi slices of a
given ambient vector in Task 6823.
