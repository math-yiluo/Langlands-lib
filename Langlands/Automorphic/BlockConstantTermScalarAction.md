# The scalar ideles of a block Levi and their action on functions

Each block idele embeds as a scalar matrix in its Levi block. The resulting continuous homomorphism takes values in the centre of the full Levi. Left translation by these embedded scalars defines `blockConstantTermScalarAction` on functions on the adelic general linear group.

`blockShapeConstantTermLinear` gives the normalized block constant term as a complex linear map from finite-smooth rationally invariant functions to functions on the full group.
