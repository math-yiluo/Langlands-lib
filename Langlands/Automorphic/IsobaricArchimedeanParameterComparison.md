# Pooling the archimedean parameters of matched cuspidal classes

Getz–Hahn (2024), §10.6, (10.33), p. 284 (one-based PDF p. 296), pool
the blocks of the constituents for the isobaric parameter. Their
Langlands order is given by (10.30), p. 283 (PDF p. 295). The theorem
here is the permutation calculation for that construction. It allows
each block to be mapped to a list before comparison, which accommodates
the two character data of a weight-zero real induction block. See
Knapp (1994), (3.2)–(3.4), pp. 402–403 (PDF pp. 412–413), for the
Weil data and the corresponding real blocks.

The local uniqueness premise is given on `PositiveRankCuspidalClass`.
The equality of classes transports the parameter property across both
the rank and the full operator class. A matched pair contributes the
same multiset of expanded blocks by local uniqueness. Expanding a
concatenated list distributes over its component lists. Finally the
bijection reindexes the sum of their multisets, which proves that the
two expanded pooled lists are permutations.
