# Real block Lie directions on the Levi period

Apply the block matrix decomposition to the actual real archimedean Lie
algebra. Its diagonal block part is the sum of the actual block Lie
inclusions. The skew-adjoint matrix belongs to the Lie algebra of the
standard compact. The remaining matrix has entries only in strictly
upper blocks.

The complexification of a strict upper block direction is supported in
strictly upper blocks in each complex matrix factor. Its enveloping
generator is therefore in the positive-weight right ideal generated by
the matrix units of those blocks. The period on the actual Levi kills
this ideal, and hence it kills each of the real upper block generators.

This is an internal application of the actual block differential and
period identities in the Library. It prepares the differentiation of
projected constant-term sections at the standard compact arguments in
Task 6823.

The decomposition of real Lie directions is proved in [Block-shape real Lie decomposition](BlockShapeRealLieDecomposition.md).
