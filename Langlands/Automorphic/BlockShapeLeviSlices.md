# Matrix Levi slices and archimedean Iwasawa detection

`blockShapeLeviSlice B` evaluates the normalized block constant term at
`m g` for an adelic Levi element in the product of the original block
general linear groups. The embedding and the ambient normalized term are
continuous. Invariance under left multiplication by the radical gives the
parabolic transformation rule after decomposition into radical and Levi
factors. Right translation of the original form acts by right translation
of the ambient argument of the slice.

Every archimedean matrix factors into an upper triangular matrix and a
standard compact element. Upper triangular matrices lie in the given
standard block parabolic, so the parabolic rule expresses every value of the
term using a slice at a standard compact element paired with the original
finite argument.

This is the matrix realization of the evaluations used in Langlands (1979),
Lemma 4 and the argument following Lemma 6, printed pp. 204–205 (Corvallis
Part I, PDF pp. 199–200). The registered source is
`langlands-1979-notion-automorphic-representation`, SHA-256
`3b9fe0145da81d870ef8967be83635cd440a2581fe043e64e63324e22dec4db5`.
