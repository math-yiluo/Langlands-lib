# Smoothness and growth of the individual Levi slices

Polynomial growth of the original function is uniform on a compact set
of finite adelic parameters because a common open stabilizer leaves
only finitely many right cosets there. The constant-term integral is
computed on a radical domain with compact closure. The matrix height
of the archimedean radical factor is therefore bounded, so
submultiplicativity of the matrix height bounds the integral by a
polynomial in the original archimedean argument.

The block diagonal inclusion that is the identity on the other blocks
is affine in matrix coordinates. Its linear part inserts the variable
block and vanishes on all other entries. Composition with this affine
map and fixed right multiplication gives smoothness of the original
slice at every finite argument. A bound for the linear part bounds
both the matrix and its inverse, giving polynomial growth on the block.
`blockShapeFiniteSmoothLeviSliceFactor` combines the resulting
smoothness with the common finite stabilizer proved for the same slice.
