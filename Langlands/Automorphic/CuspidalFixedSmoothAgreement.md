# Continuous agreement on the original fixed smooth image

Suppose the original fixed vectors are dense in the fixed smooth vectors
of the same completed form, for the genuine derivative topology. A
supplied smooth embedding whose underlying vector is the canonical
Hilbert image gives the smooth representative of each of these original
vectors. Restrict the continuous functions to the fixed smooth subspace
and extend their equality from the dense image by closedness of the
equality set.

This internal criterion uses the supplied form, completed finite action
and archimedean action. Its cuspidal application supplies the density
hypothesis by fixed-level derivative density.

For a genuine smooth functional and a fixed archimedean element, its
composition with translation is continuous for the derivative topology.
The agreement criterion therefore extends a scalar covariance identity
from the original fixed vectors to every genuine fixed smooth vector.
