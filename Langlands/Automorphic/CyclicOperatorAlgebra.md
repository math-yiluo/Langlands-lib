# The algebra action on a cyclic subrepresentation

The module generated by a vector under the monoid algebra is an actual invariant subspace of the given representation. Restricting the original algebra action to this subspace retains its addition, multiplication and complex scalar action. The canonical map from the monoid algebra to the represented algebra collapses every finite linear combination of operators to a single algebra element. Thus the distinguished vector has the whole cyclic subspace as its orbit span.

The inclusion identifies the restricted representation's monoid-algebra module with the cyclic submodule. Composing with this identification transfers a surjective module map to an intertwiner onto the original target representation. This is an algebraic helper for the character selection in the proof of `CuspidalSupportExistenceStatement`, following the cyclic construction used in Langlands, *On the notion of an automorphic representation* (1979), Lemma 6, printed pp. 204–205.
