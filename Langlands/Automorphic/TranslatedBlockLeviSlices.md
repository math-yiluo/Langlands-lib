# Cuspidal coordinate slices of an actual translated period

Fix a block and the adelic points in the other blocks. Evaluation into complex-valued functions on the block is injective on finite-smooth rational-invariant functions. Every translated-period vector has the same Levi restriction as an original realized form. The original block slice therefore witnesses membership in the range of evaluation. The inverse on this range defines a linear slice map on the translated-period quotient.

A single original realized form gives all the block slices of a fixed vector. The slice inherits finite smoothness, compact and enveloping-centre finiteness, and polynomial growth from this form. When all strict refinements of the original constant term vanish, the transitivity and refinements of block constant terms give cuspidality in each block. If the translated-period vector transforms by a character of the separate block scalars, its slice transforms by the restriction of that character to the selected block. The last step is a calculation using the actual scalar on that block and the translation action on period evaluation.

This is a derived step in the cuspidal block construction for Task 6823, using the period properties of Langlands, *On the notion of an automorphic representation* (1979), Lemma 4 and the argument preceding Lemma 6, printed pp. 204–205.
