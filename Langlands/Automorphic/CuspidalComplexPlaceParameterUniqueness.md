# Uniqueness of the complex parameter of a cuspidal class

The actual cuspidal realization has an irreducible admissible component
at the given complex place by `exists_complexPlaceComponent`. Its
quotient presentation with zero denominator identifies the same operator
space and carries the chosen component to the quotient. The component
makes the entire restriction isotypic, as in Flath (1979), end of the
proof of Theorem 1, p. 180 (one-based PDF p. 176).

Each parameter gives an embedding of a standard module. The proof
composes these embeddings with the equivalence to the quotient, whose
compact and Lie actions agree with the original ones on projections.
The embedded-standard comparison then shows that the parameter lists
are permutations. That comparison uses the scalar vector of a complex
standard module and the uniqueness of the Langlands parameter in
Knapp (1994), (4.3) and Theorem 4(a), (c), p. 405 (one-based PDF p. 415).

The class version takes a representative of the positive-rank cuspidal
class and applies the actual-realization result. Both parameter
properties are invariant under the full operator equivalence.
