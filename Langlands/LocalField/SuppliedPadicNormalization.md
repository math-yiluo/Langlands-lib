# The additive conductor of supplied p-adic data

`toLocalFieldData_additiveConductor` compares the two definitions of the additive conductor of the same character on a supplied p-adic field. The underlying local-field interface and the p-adic interface use the same valuation lattices. Each definition is the greatest triviality level for these lattices, so the greatest-level property gives both inequalities.

This is an internal comparison of the Library's definitions, using the convention of Bushnell, Henniart and Kutzko, *Local Rankin–Selberg convolutions for GL(n), explicit conductor formula* (1998), introduction, printed p. 703.
