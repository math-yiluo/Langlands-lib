# The affine Weyl image of the actual root-reflection representatives

This internal construction defines `ValuationBuildingData.reflectionNormalizer`
as the subgroup of the actual `normalizerPoints B.i` generated by the literal
products from all supplied opposite factor pairs for nonidentity root points.
The ambient field has arbitrary universe `u`, and all groups, apartments,
functionals and actions come from the supplied building data. The definition
does not assume that opposite pairs exist for every root point.

The action of each supplied pair lies in `W(Ψ)` under the apartment axioms and
the explicit fixed-hyperplane hypothesis `B.HasRootReflections`. The imported
`RootReflectionAction` module computes the actual affine action and its
`IsCoroot Ψ ψ` vector for the point's functional `ψ`. This functional belongs
to `Ψ′`. AS 4 gives either `ψ ∈ Ψ` or `2ψ ∈ Ψ`. In the latter case the vector
is divided by two: the pairing remains two and the induced action on affine
functionals is unchanged. The corresponding geometric reflection is also
unchanged. Either case gives a generator of the affine Weyl group. Subgroup
closure proves `reflectionNormalizer_map_le_affineWeylGroup`.

The reverse containment additionally assumes
`RelativeRoot.HasRankOneFactorization B.i`. Since `Ψ ⊆ Ψ′` and `Ψ′` is the
set of root-point functionals, every affine root is represented by an actual
nonidentity root point. The explicit factorization hypothesis supplies an
opposite pair. The imported arbitrary-coroot action comparison identifies its
actual action with the chosen affine Weyl generator. Closure proves
`affineWeylGroup_le_reflectionNormalizer_map` and hence the equality of the
generated subgroup's affine image with `W(Ψ)`.

For `P : ParahoricBuildingData G`,
`reflectionNormalizer_le_simplyConnectedImage` needs only the apartment
axioms. Each generator belongs to the actual supplied simply connected image
by the imported root-group lifting result, and that image is a subgroup.
With the additional fixed-hyperplane and factorization hypotheses, this gives
`affineWeylGroup_le_simplyConnectedNormalizer_map`: every element of `W(Ψ)`
is the actual action of a normalizer point in the supplied simply connected
image.

The provenance is derived. These are deductions from the imported actual
reflection-action adapter, AS 4, the equality describing `Ψ′`, and subgroup
generation. No additional claim from external literature is introduced.
The module does not discharge the two explicit additional hypotheses, prove
the opposite containment for the entire simply connected normalizer image,
or prove the apartment-only affine Iwahori–Tits statement.
