# Parahorics at points of the diagonal apartment of `GL_N`

Module `Langlands.Geometry.Building.DepthZero.GeneralLinear.PointParahoric`, namespace
`Langlands.Geometry.Building.GeneralLinearParahoric`.

## Conjugation by diagonal matrices (any field)

- `diagPoint_inv`, `conj_diagPoint_symm_apply`: inverses of diagonal points, and inverse
  conjugation by `diag(d)` is conjugation by `diag(d⁻¹)`.
- `conj_diagPoint_diagPoint`: diagonal matrices commute.
- `conj_diagPoint_transvectionPoint`: `d (1 + t E_{kl}) d⁻¹ = 1 + d_k t d_l⁻¹ E_{kl}`
  (`diagGL_conj_transvectionGL`).

## Orders, integral units and integral points

- `localFieldOrder_nonneg_iff`: `ord t ≥ 0` exactly when `t ∈ 𝒪_F`
  (`FML.ord_nonneg_iff_mem_integer`, `Plancherel.fieldOrderUnits_ord`).
- `localFieldOrder_mk0_mul_mul`: `ord(a t b) = ord a + ord t + ord b`.
- `valuation_algebraMap_unit`: a unit of `𝒪_F` has valuation one; `integralUnit d hd`: a unit
  of `F` of valuation one as a unit of `𝒪_F`.
- `glIntegralInclusion_diagUnit`, `glIntegralInclusion_transvectionUnit`: the inclusion
  `GL_N(𝒪_F) → GL_N(F)` on diagonal and elementary matrices.
- `mem_integralPoints_iff`: a rational point lies in `K = GL_N(𝒪_F)`, the integral points of
  the standard model, exactly when its matrix is the image of an invertible matrix over `𝒪_F`
  (`GeneralLinear.mem_standardIntegralModel_integralPoints_iff`).

## Apartment lemmas

For apartment data `A` of the diagonal torus:

- `linear_eq_rootForm_of_apply_eq`: an affine function `y ↦ c_{kl}(y) + m` has derivative
  `e_k − e_l` (`rootValue_vadd`).
- `transvectionPoint_mem_affineRootGroup`: for `t ≠ 0`, `1 + t E_{kl}` lies in `U_ψ` when `ψ`
  has derivative `e_k − e_l` and `ψ(x) ≤ ord t + c_{kl}(x)`
  (`KPApartmentData.mem_affineRootGroup_iff`, `val_transvectionPoint`).
- `exists_intCast_sub_of_isVertex`: at a vertex the root values are `c_{kl}(x) = y_k − y_l`
  with integers `y_k` (`isVertex_iff`, `rootValue_add`, `rootValue_swap`).
- `exists_rootValue_eq_zero`: some point of the apartment has all root values zero (translate
  any point by the vector with coordinates `−y_k`, `exists_eval_coordCharacter`).

## Generators of the point parahorics

Let `P` be parahoric building data of `GL_N`, `σ : P.S ≅ D_N`, `f` an automorphism of `GL_N`
with `P.i ≫ f = σ ≫ diagTorus`, and `P' = P.basedTransport σ f h`, whose maximal split torus is
the diagonal torus. For a point `x` of the apartment of `P'`, the subgroup
`P'.nonnegativeRootSubgroup {x}` (generated by the image of `Z(F)^0` and the groups `U_ψ`,
`ψ ∈ Ψ`, `ψ(x) ≥ 0`; `ParahoricBuildingData.nonnegativeRootSubgroup`) is described as follows.

- `exists_diagGL_of_mem_map_centralizerZero`: the image of `Z(F)^0` consists of invertible
  diagonal matrices whose entries have valuation one. `Z(F)^0 ⊆ Z(F)^1`
  (`ZeroSubgroupDatum.centralizerZero_le_rationalCommonNormKernel`); the minimal Levi subgroup
  is identified with the diagonal torus (`SubgroupFunctor.IsRepresentedBy.isoOfIsRepresentedBy`
  with `isRepresentedBy_torusCentralizer_diagTorus`), which carries `Z(F)^1` into the torus
  points with unit coordinates (`map_characterValuationKernel_le`,
  `SplitTorusValuation.mem_integralUnitKernel`).
- `diagGL_mem_map_centralizerZero`: conversely every such diagonal matrix is in the image of
  `Z(F)^0`, since the minimal Levi subgroup is a split torus (`isSplitTorus_centralizer`) and
  then `Z(F)^1 ⊆ Z(F)^0` (`rationalCommonNormKernel_le_centralizerZero`).
- `diagGL_mem_nonnegativeRootSubgroup`: these diagonal matrices lie in
  `P'.nonnegativeRootSubgroup Ω` for every `Ω`.
- `transvectionPoint_mem_nonnegativeRootSubgroup`: `1 + t E_{kl}` lies in
  `P'.nonnegativeRootSubgroup {x}` when `t = 0` or `ord t + c_{kl}(x) ≥ 0`: it lies in `U_ψ` for
  the affine root `ψ = c_{kl} + ⌈−c_{kl}(x)⌉` (`exists_affineRoot_eq`), which is non-negative at
  `x`.
- `nonnegativeRootSubgroup_singleton_le`: `P'.nonnegativeRootSubgroup {x}` is contained in every
  subgroup containing these diagonal matrices and these transvections. Each generator `U_ψ` has
  derivative some `e_k − e_l` (`exists_eq_rootCharacter`), its points are transvections
  `1 + t E_{kl}` (`exists_eq_transvectionGL_of_mem_rootGroupPoints`) with
  `ord t + c_{kl}(x) ≥ ψ(x) ≥ 0`.

## Hyperspecial points

- `uniformizerDiag y`: the diagonal entries `ϖ^{−y_k}` for `y : Fin N → ℤ`, with
  `ϖ = SplitTorusValuation.uniformizerUnit F`; `localFieldOrder_uniformizerDiag`.
- `nonnegativeRootSubgroup_singleton_eq_of_intCast_sub`: **if `c_{kl}(x) = y_k − y_l` with
  integers `y_k`, then `P'.nonnegativeRootSubgroup {x} = d K d⁻¹`, where `K = GL_N(𝒪_F)` and
  `d = diag(ϖ^{−y_1}, …, ϖ^{−y_N})`.** For `⊆`, `nonnegativeRootSubgroup_singleton_le` applies:
  `d⁻¹` conjugates a diagonal matrix with unit entries to itself and a generator `1 + t E_{kl}`
  to `1 + ϖ^{y_k − y_l} t E_{kl}`, whose coefficient has order `ord t + c_{kl}(x) ≥ 0`. For `⊇`,
  the preimage in `GL_N(𝒪_F)` of `d⁻¹ P'.nonnegativeRootSubgroup {x} d` contains the invertible
  diagonal matrices and every `1 + c E_{kl}` (`c ∈ 𝒪_F`), whose conjugate by `d` is
  `1 + ϖ^{y_l − y_k} c E_{kl}` with `ord + c_{kl}(x) = ord c ≥ 0`; so it is all of `GL_N(𝒪_F)`
  (`eq_top_of_diagUnit_transvectionUnit_mem`).

This is the computation of the parahoric subgroups of `GL_N` at the hyperspecial vertices of
the standard apartment (Kaletha–Prasad, *Bruhat–Tits Theory: A New Approach*, Cambridge
University Press, 2023, §15.1 and 15.1.33; literature ID
`kaletha-prasad-2023-bruhat-tits-new-approach`), carried out here through the generators of
Axiom 4.1.8 (2) rather than through lattices.
