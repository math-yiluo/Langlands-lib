# Generation of `GL_n(R)` and of the Iwahori subgroup over a local ring

Module `Langlands.Geometry.Building.DepthZero.GeneralLinear.Generation`, namespace
`Langlands.Geometry.Building.GeneralLinearParahoric`. It imports only Mathlib.

Let `R` be a commutative ring and `n ∈ ℕ`.

- `transvectionUnit hij c`: the elementary matrix `1 + c E_{ij}` (`i ≠ j`) in `GL_n(R)`, the
  image of `Matrix.SpecialLinearGroup.transvection`; `coe_transvectionUnit`.
- `diagUnit d`: the invertible diagonal matrix with diagonal `d : Fin n → Rˣ`; `coe_diagUnit`.
- `transvectionUnit_mul_apply`: left multiplication by `1 + c E_{ij}` adds `c` times row `j` to
  row `i`.
- `ColumnsCleared g k`: the first `k` columns of the matrix `g` are diagonal (all off-diagonal
  entries vanish).
- `isUnit_apply_self_of_columnsCleared`: in an invertible matrix whose first `k` columns are
  diagonal, the first `k` diagonal entries are units (compare the `(j, j)` entry of
  `g⁻¹ g = 1`).

From now on `R` is local.

- `exists_isUnit_of_columnsCleared`: if the first `k` columns of an invertible `g` are diagonal
  and `k < n`, some entry `g_{ik}` with `i ≥ k` is a unit. The `(k, k)` entry of `g⁻¹ g = 1` is
  `∑_i (g⁻¹)_{ki} g_{ik}`; the terms with `i < k` vanish, and in a local ring a sum that is a
  unit has a unit term (`IsLocalRing.exists_of_isUnit_sum`).
- `mem_of_columnsCleared_all`: a subgroup containing all invertible diagonal matrices contains
  every invertible matrix whose columns are all diagonal (it is diagonal with unit entries).
- `exists_mul_columnsCleared_succ`: **clearing one column.** If the first `k` columns of `g`
  are diagonal, `g_{kk} = u` is a unit and `H` contains the transvections
  `1 − g_{ik} u⁻¹ E_{ik}` (`i ≠ k`), then some `h ∈ H` makes the first `k + 1` columns of `h g`
  diagonal; a property of matrices preserved by these row operations passes from `g` to `h g`.
  The proof clears the rows of a finite set of indices by induction on the set.
- `eq_top_of_diagUnit_transvectionUnit_mem`: **a subgroup of `GL_n(R)` containing all invertible
  diagonal matrices and all transvections `1 + c E_{ij}` is the whole group.** By downward
  induction on the number of diagonal columns: for column `k`, a unit entry `g_{i₀k}`
  (`i₀ ≥ k`) is moved to the diagonal if necessary by `1 + E_{k i₀}` (in a local ring, if
  `g_{kk}` is not a unit then `g_{kk} + g_{i₀k}` is), and then the column is cleared.
- `mem_of_iwahori`: **a subgroup containing all invertible diagonal matrices, the transvections
  `1 + c E_{ij}` with `i < j`, and those with `i > j` and `c` in the maximal ideal, contains
  every invertible matrix whose entries below the diagonal lie in the maximal ideal.** The same
  induction, with the property "entries below the diagonal lie in the maximal ideal" carried
  along: it forces the pivot `g_{kk}` to be the unit entry, and the row operations used have
  coefficients in the maximal ideal below the diagonal.

This is the standard Gaussian elimination over a local ring; for `R = 𝒪_F` it shows that
`GL_N(𝒪_F)` and its standard Iwahori subgroup are generated by their diagonal and elementary
matrices (Kaletha–Prasad, *Bruhat–Tits Theory: A New Approach*, Cambridge University Press,
2023, §15.1; literature ID `kaletha-prasad-2023-bruhat-tits-new-approach`).
