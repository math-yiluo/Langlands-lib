# Geometric chamber walls and simple affine reflections

This definition unit works on the existing `AffineRootSystem` objects, for independent
universes `uV`, `uA`, a real vector space `V`, a `V`-torsor `A`, and the given affine
functionals `Ψ`. It supplies no root-system axioms, generating set chosen independently
of the geometry, or structural truth theorem.

## Declarations and formulas

All declarations below are in `Langlands.Geometry.Building.AffineRootSystem`.

| Declaration | Formula and source |
| --- | --- |
| `IsChamberWall Ψ C H` | `IsChamber Ψ C`, `H = hyperplane ψ` for some `ψ ∈ Ψ` with `ψ.linear ≠ 0`, and `affineSpan ℝ Fa = H` for a face `IsFaceOf Ψ Fa C`. Remark 1.3.16, printed p. 19 / PDF p. 50. |
| `simpleAffineRoots Ψ C` | The `ψ ∈ positiveRoots Ψ C ∩ nonDivisibleRoots Ψ` with `IsChamberWall Ψ C (hyperplane ψ)`. Definitions 1.3.18–19, printed p. 22 / PDF p. 53. In particular `ψ / 2 ∉ Ψ`; positivity alone does not define simplicity. |
| `chamberSimpleReflections Ψ C` | The elements `s : affineWeylGroup Ψ` for which `s = affineReflection ψ hv.1` for a simple affine root `ψ` and an actual coroot `hv : IsCoroot Ψ ψ v`. Definition 1.3.1 and Remark 1.3.2 for the existing reflection; Proposition 1.3.20 and Proposition 1.3.22(1), PDF pp. 53–54, for the set used in the Coxeter and generation assertions. |
| `facetSimpleAffineRoots Ψ C Fa` | The `ψ ∈ simpleAffineRoots Ψ C` such that `∀ x ∈ Fa, ψ x = 0`. Proposition 7.5.5, printed pp. 261–262 / PDF pp. 292–293. |
| `facetSimpleReflections Ψ C Fa` | The same actual coroot reflections, restricted to `facetSimpleAffineRoots Ψ C Fa`. Proposition 7.5.5, same location. |

`IsChamberWall` is an internal expression of codimension one using the existing
open-facet and affine-span interfaces. A face is nonempty by `IsFaceOf`; its affine
span being a nonconstant root hyperplane expresses that it has codimension one.
The face is the relatively open boundary facet in that hyperplane. Remark 1.3.16
speaks of the intersection of the hyperplane with the chamber closure as a face;
that closed intersection also contains its lower-dimensional boundary faces.
We use the affine span of the open face rather than identifying an open facet
with that entire closed intersection. No topological closure theorem is imported
or silently assumed by this convention.

The coroot-reflection formula is literally `x ↦ (-ψ x) • v +ᵥ x`, with
`ψ.linear v = 2` and preservation of `Ψ` as required by `IsCoroot`. Membership in
the ambient affine Weyl group is built into the subtype. The definition does not
choose a coroot: it ranges over coroot witnesses. On an affine root system the
published `IsAffineRootSystem.isCoroot_unique` supplies their uniqueness.

`simpleAffineRoots_subset` and `facetSimpleReflections_subset` merely extract
conjuncts or reuse witnesses. `simpleAffineRoots_empty` and
`chamberSimpleReflections_empty` unfold the definitions in the absence of roots.
They are intrinsic packaging lemmas, with no geometric generation proof.

## Rank zero and retained obligations

For `Ψ = ∅` on the rank-zero apartment, there are no walls, no simple affine
roots, and no simple reflections; the facet subset is also empty by
`facetSimpleReflections_subset`. The subgroup generated by the empty set is
trivial. No nonempty set of simple reflections is required. The generic
`IsTitsSystem.eq_one_of_empty` and `IsTitsSystem.eq_top_of_empty` describe the
corresponding rank-zero Tits system once its predicate has been proved.

Coxeter generation, the existence of the required walls and coroots under the
root-system axioms, chamber simple transitivity, and identification of the
facet-generated subgroup with a setwise facet stabilizer remain structural
proof obligations. This module does not prove KP Propositions 1.3.20, 1.3.22,
7.5.5, or either Chapter 7 double-coset target. It provides the geometric sets
that the actual Tits and facet-parabolic predicates must use.
