# Group properties of the groups `G(K)_{x,r}` over `K = F^ur`

This module states, as one proposition, the group properties of the groups
`G(K)_{x,r}` that `BuildingData.moyPrasad` (module
`Langlands.Geometry.Building.KPLocalMoyPrasadGroups`) defines for quasi-split
building data over the maximal unramified extension `K = F^ur`. The properties are
normality, equivariance, commutators, intersections with root subgroups, the
Iwahori factorization, intersections with Levi subgroups and with the centralizer,
and separation. It is a statement only: nothing here is proved.

The main declaration is

```
Langlands.Geometry.Building.MaximalUnramified.LocalMoyPrasadGroupPropertiesStatement
```

It bundles eight Prop-valued clauses, `LocalMoyPrasadNormality`, …,
`LocalMoyPrasadSeparated` (same namespace), each defined separately so that later
work can cite the clause it uses.

## Setting

The setting and binder convention are D1's (`KPLocalMoyPrasadGroups.md`):

- `F : Type u` is a nonarchimedean local field (`Field`, `ValuativeRel`,
  `TopologicalSpace`, `IsNonarchimedeanLocalField`), of any characteristic and in
  an arbitrary universe;
- `K = UnramifiedClosure F`;
- `H` is a group scheme over `Spec K` with `[IsAffineHom H.X.hom]`, and
  `B : MaximalUnramified.BuildingData F H`;
- the only extra binder is `hZ : IsTorus B.centralizer.Z`, which says that the
  centralizer `Z` of the maximal `K`-split torus `B.S` is a torus. This is the
  quasi-split case.

Notation in the clauses:

| KP | Lean |
| --- | --- |
| `G(K)` | `rationalPoints H` |
| `G_{x,r} = G(K)_{x,r}`, `x ∈ A`, `r ≥ 0` | `B.moyPrasad hZ x r`, `x : B.Apartment`, `r : ℝ≥0` |
| `Z(K)_r` | `B.centralizerTorusFiltration hZ r` |
| `j(Z(K)_r)` | `B.centralizerTorusImage hZ r` |
| `j : Z(K) → G(K)` | `rationalPoints.map B.centralizer.j` |
| relative roots `Φ` | `relativeRoots B.i` |
| `U_b(K)` | `B.rootGroup b` |
| `U_{b,x,r}` | `B.filtration x b r` |
| `N(K)` | `normalizerPoints B.i` |
| `[x] = [(1, x)]` in the reduced building | `B.apartmentMap x` |

## Encodings chosen here

The task leaves the encoding of `λ`, `⟨b, λ⟩`, `U_Ψ` and `M_λ` to the statement.
The choices are:

- **`λ` and `⟨b, λ⟩`.** `λ` is a vector `ν : V B.S` of the real cocharacter space
  `V B.S = ℝ ⊗[ℤ] X_*(S)` (`Langlands.GroupScheme.RealTorusSpace.V`), the space on
  which `KPApartmentData` evaluates roots. The pairing `⟨b, λ⟩` is
  `eval B.S b ν` (`RealTorusSpace.eval`), the `ℝ`-linear extension of the
  character–cocharacter pairing. Every open half-space of the real character
  space has the form `{b | 0 < ⟨b, ν⟩}` for some `ν`. The letter `ν` replaces
  `λ` because `λ` and `μ` are reserved tokens in Lean.
- **Sets of roots.** `B.positivePairingRoots ν`, `B.negativePairingRoots ν` and
  `B.zeroPairingRoots ν` are the relative roots `b` with `⟨b, ν⟩ > 0`, `< 0` and
  `= 0`.
- **Closed sets.** `B.IsClosedRootSet Ψ` says that `Ψ ⊆ relativeRoots B.i` and
  that `p • b + q • c ∈ Ψ` whenever `b, c ∈ Ψ`, `p, q` are positive integers and
  `p • b + q • c` is a relative root. This is the closedness condition of the
  task, with the containment in `Φ` made explicit.
- **`U_Ψ`.** `B.rootGroupSpan Ψ = ⨆ b ∈ Ψ, B.rootGroup b`, the subgroup generated
  by the root groups `U_b(K)`, `b ∈ Ψ`. Then `U_{±λ}` is
  `B.rootGroupSpan (B.positivePairingRoots ν)` and
  `B.rootGroupSpan (B.negativePairingRoots ν)`.
- **The group generated by the `U_{b,x,r}`, `b ∈ Ψ`.**
  `B.rootFiltrationSpan x Ψ r = ⨆ b ∈ Ψ, B.filtration x b r`.
- **`M_λ`.** `B.pairingLeviSpan ν` is the range of `j` on `K`-points joined with
  `B.rootGroupSpan (B.zeroPairingRoots ν)`. This is the subgroup generated by
  `j(Z(K))` and the `U_b(K)` with `⟨b, ν⟩ = 0`, the task's definition of `M_λ`.
  It is the group of `K`-points of the Levi subgroup `M_λ`, because that group is
  generated by `Z(K)` and its root groups. The statement uses only the generated
  subgroup and asserts nothing about this identification.
- **Normality and conjugation.** Mathlib's `Subgroup.normalizer` takes a set, so
  clause 1 is `G_{x,0} ≤ Subgroup.normalizer (G_{x,r} : Set _)`. Conjugation by
  `g` is `(MulAut.conj g).toMonoidHom`, and "maps `G_{x,r}` onto `G_{x',r}`" is an
  equation `Subgroup.map … = …` of subgroups.
- **Commutators.** `⁅P, Q⁆` is Mathlib's commutator subgroup of two subgroups.

The helper definitions `rootGroupSpan`, `rootFiltrationSpan`, `IsClosedRootSet`,
`positivePairingRoots`, `negativePairingRoots`, `zeroPairingRoots` and
`pairingLeviSpan` are in namespace
`Langlands.Geometry.Building.MaximalUnramified.BuildingData`, like D1's
declarations, so dot notation works (`B.rootGroupSpan Ψ`). They are internal
encodings of the notions above, which are all in KP §7.3 and Lemma 8.5.19, and
make no assertion.

## The clauses

For every `F`, `H`, `B`, `hZ` as above, all of the following hold. Each clause
quantifies over all `x : B.Apartment` and `r : ℝ≥0` (and `s`, `ν`, `Ψ`, `g`, `n`
as needed).

1. **Normality** (`LocalMoyPrasadNormality`; KP Proposition 7.3.17). `G_{x,0}`
   normalizes `G_{x,r}`:
   `B.moyPrasad hZ x 0 ≤ Subgroup.normalizer (B.moyPrasad hZ x r : Set _)`.
2. **Equivariance** (`LocalMoyPrasadEquivariance`; KP Proposition 7.3.17,
   Remark 7.6.5 and (7.6.2); compare Proposition 13.2.5(2)). Both forms:
   - if `B.apartmentMap x' = g • B.apartmentMap x`, then
     `(G_{x,r}).map (MulAut.conj g).toMonoidHom = G_{x',r}`;
   - for `n : normalizerPoints B.i`,
     `(G_{x,r}).map (MulAut.conj n).toMonoidHom = G_{n • x, r}`.
3. **Commutators** (`LocalMoyPrasadCommutator`; KP Proposition 13.2.5(4) for the
   quasi-split group over `K`). `⁅G_{x,r}, G_{x,s}⁆ ≤ G_{x,r+s}`.
4. **Unipotent intersections** (`LocalMoyPrasadRootIntersection`; KP
   Proposition 7.3.12(1), (3) and (5)). If `Ψ` is closed
   (`B.IsClosedRootSet Ψ`) and `0 < ⟨b, ν⟩` for all `b ∈ Ψ`, then
   `U_Ψ ⊓ G_{x,r} = B.rootFiltrationSpan x Ψ r`. For a relative root `b`, take
   `Ψ = {b, 2b}` if `2b` is a relative root and `Ψ = {b}` otherwise. This `Ψ` is
   closed, since no multiple `m • b` with `m ≥ 3` is a root, and it lies in a
   half-space. In KP's convention `U_{2b} ⊆ U_b`, so `U_Ψ = U_b(K)`, and the
   clause gives `U_b(K) ⊓ G_{x,r}` as the subgroup generated by `U_{b,x,r}` and
   `U_{2b,x,r}`. That is the subgroup generated by the block
   `B.apartment.filtrationBlock x (fun _ => r) b`.
5. **Iwahori factorization** (`LocalMoyPrasadIwahoriFactorization`; KP
   Proposition 7.3.12(5) for a positive system adapted to `ν`, with Lemmas 7.3.16
   and 8.5.19; compare Proposition 13.2.5(3) and (5)). For `0 < r`, if
   `v' * m * v ∈ G_{x,r}` with `v' ∈ U_{-ν}`, `m ∈ M_ν` and `v ∈ U_ν`, then `v'`,
   `m` and `v` lie in `G_{x,r}`. The restriction `r > 0` is KP's: at `r = 0` the
   factor `N♯_{x,0}` of Proposition 7.3.12(1) need not lie in `Z(K)`
   (Proposition 7.3.12(4) needs `f(0) > 0`).
6. **Levi intersection** (`LocalMoyPrasadLeviIntersection`; KP Lemma 8.5.19, and
   Proposition 13.2.5(6)). For all `ν`, `x` and `r ≥ 0`,
   `M_ν ⊓ G_{x,r} = j(Z(K)_r) ⊔ B.rootFiltrationSpan x (B.zeroPairingRoots ν) r`.
   The right side is KP's `M(K)_{π(x),r}`: the torus `Z` is also the centralizer
   of `S` in `M_ν`, and the filtration of `U_b` for a root `b` of `M_ν` at the
   restricted point `π(x)` is `U_{b,x,r}` (KP §6.7).
7. **Centralizer intersection** (`LocalMoyPrasadCentralizerIntersection`; KP
   Lemma 7.3.16). For all `x` and `r ≥ 0`, the preimage of `G_{x,r}` under `j` is
   `Z(K)_r`:
   `(B.moyPrasad hZ x r).comap (rationalPoints.map B.centralizer.j) = B.centralizerTorusFiltration hZ r`.
   Since `j` is injective on points, this is KP's `G(K)_{x,r} ∩ Z(K) = Z(K)_r`.
8. **Separation** (`LocalMoyPrasadSeparated`; the separatedness asserted in KP
   Proposition 13.2.5). `⨅ r : ℝ≥0, G_{x,r} = ⊥`.

Clauses 4, 6 and 7 hold for every `r ≥ 0`, as in KP Proposition 7.3.12, Lemma
7.3.16 and Lemma 8.5.19, which hold for every concave function `f`. Clause 5 is
stated only for `r > 0`.

## Clause 2 from clause 1 and `N(K)`-equivariance

The two forms of clause 2 are equivalent given clause 1. The argument uses the
definition of the Library's reduced building. `B.ReducedBuilding` is
`B.apartment.ReducedBuilding` (module `KPBuilding`). That is the quotient
`ApartmentQuotient B.apartment.sharpFixerFamily` of `G(K) × A` by the relation
(7.6.2): `(g, x) ∼ (h, y)` if and only if some `n ∈ N(K)` has `n • x = y` and
`g⁻¹ h n ∈ G(K)♯_x`, where `G(K)♯_x = B.apartment.sharpFixer {x}`
(`ApartmentQuotient.mk_eq_mk_iff`). The point `B.apartmentMap x` is the class of
`(1, x)`, and `g • [(h, y)] = [(g h, y)]` (`ApartmentQuotient.smul_mk`).

- The second form is a special case of the first: `n • [x] = [n • x]` by
  `normalizer_smul_apartmentMap`.
- The first form follows from the second and clause 1. Suppose that
  `B.apartmentMap x' = g • B.apartmentMap x`, that is, `[(1, x')] = [(g, x)]`.
  By the relation, some `n ∈ N(K)` has `n • x = x'` and
  `p := g⁻¹ n ∈ G(K)♯_x`. Now `G(K)♯_x = B.apartment.sharpFiltration x (fun _ => 0)`
  (`sharpFiltration_zero`), and this group lies in `G_{x,0}`
  (`sharpFiltration_le_moyPrasad`). So `p⁻¹ ∈ G_{x,0}`, and by clause 1
  conjugation by `p⁻¹` maps `G_{x,r}` onto itself. Since `g = n p⁻¹`,
  conjugation by `g` is conjugation by `p⁻¹` followed by conjugation by `n`. By
  the second form it maps `G_{x,r}` onto `G_{n • x, r} = G_{x',r}`.

The second form is the `N(K)`-equivariance of the generators. Conjugation by `n`
maps `U_{b,x,r}` onto `U_{n·b, n·x, r}`, where `n·b = weylAction B.i n b`. The
Library's `KPApartmentData.conj_mem_filtration` gives the inclusion
`n U_{b,x,r} n⁻¹ ⊆ U_{n·b, n·x, r}` for every `n`, and applying it to `n⁻¹` gives
the reverse inclusion. It maps `j(Z(K)_r)` onto itself because `Z(K)_•` is
`N(K)`-stable, which is part of S1 (Task 5890, KP Lemma 7.2.3 over `K`).

## Apartment axioms

The statement assumes no hypothesis on `B` beyond the setting. KP Chapter 7
assumes the assertions AS 1–AS 5 of Axiom 4.1.6 for the apartment
(corrections, PDF p. 33). That page says that AS 1–AS 4 are proved in KP §6.3.
It also says that AS 5 is known when `G` is quasi-split, by KP Propositions
6.3.13 and 6.6.2. Here `G = H` is quasi-split over `K`, since the centralizer `Z`
of the maximal split torus is a torus (`hZ`). So no clause needs AS 5 as an extra
hypothesis, and the statement takes none. No hypothesis concerns `G(K)_{x,r}`,
the torus filtration or any stated property.

## Remarks for the proof (not part of the statement)

- Clause 7 at `r = 0` uses that the zero term of the torus filtration is the
  Iwahori subgroup `Z(K)^0` (KP Lemma 2.6.27, used in the proof of Lemma 7.3.16).
  D1's Markdown records the Library's status: `Z(K)_0` is the norm Iwahori
  (`centralizerTorusFiltration_zero`), but no Library result proves that the
  character-valuation kernel it uses is the maximal bounded subgroup.
- KP prove clause 3 for `r, s > 0` from the product decomposition
  (Proposition 13.2.5(3)), Axiom V 3 and Lemma 7.1.2 together with the
  commutator-friendliness of `Z(K)_•`. When a double root occurs, that needs the
  sharper `2r` bound for the `Z`-component of commutators of root elements.

## Provenance

The eight clauses are source statements: each is the KP result cited at the
clause, specialized to `K = F^ur`, the constant concave function `f = r`, and the
Library's torus filtration `Z(K)_•` of D1. The helper definitions are internal
encodings of KP's notions, described above.
