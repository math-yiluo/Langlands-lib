# Reducing `G(F)^0_Ω ⊆ P_Ω` to the normalizer (KP Lemma 7.7.4)

This module works with building data `P : ParahoricBuildingData G` over a nonarchimedean local
field that satisfies the apartment axioms (`P.SatisfiesApartmentAxioms`). It defines one
predicate on `P` and proves supporting lemmas for KP Axiom 4.1.8 (2). Nothing in it assumes a
published but unproved statement. The hypotheses are `P.SatisfiesApartmentAxioms` and, where
stated, the predicate below or a condition on one element. All published definitions and
statements are imported unchanged.

## The definition

```
def ParahoricBuildingData.HasNormalizerParahoricFixers (P : ParahoricBuildingData G) : Prop :=
  ∀ Ω : Set P.Apartment, Ω.Finite → Ω.Nonempty → ∀ n : normalizerPoints P.i,
    (n : rationalPoints G) ∈ P.zeroSubgroup → (∀ x ∈ Ω, n • x = x) →
      (n : rationalPoints G) ∈ P.parahoric Ω
```

In KP's notation (Kaletha–Prasad, *Bruhat–Tits Theory: A New Approach*, §7.7), the predicate
says `N(F)^0_Ω ⊆ P_Ω` for every finite non-empty `Ω ⊆ A(S)`. Here `N(F)^0_Ω` is the set of
elements of `N(F) ∩ G(F)^0` that fix `Ω` pointwise, and `P_Ω = P.parahoric Ω` is the subgroup
generated by `Z(F)^0` and `G(F)^♯_Ω`. In KP this inclusion is the normalizer part of
Lemma 7.7.4 and Proposition 7.7.5(1). It follows from Theorem 7.5.3 there. The predicate is
derived for this reduction and is not a numbered definition in KP.

## Main results

All declarations are in namespace `Langlands.Geometry.Building.ParahoricBuildingData`.

* `hasZeroFixerGenerators_of_hasNormalizerParahoricFixers (hP) (hN) : P.HasZeroFixerGenerators`.
  This is KP Axiom 4.1.8 (2) for `P`, given the predicate. `P.HasZeroFixerGenerators` says
  that for non-empty bounded `Ω`, `P.zeroFixer Ω` equals the subgroup generated by `Z(F)^0` and
  the `U_ψ` with `ψ ≥ 0` on `Ω`. The published `parahoric_eq_nonnegativeRootSubgroup`
  identifies that subgroup with `P.parahoric Ω`. The published `parahoric_le_zeroFixer` gives
  `P.parahoric Ω ≤ P.zeroFixer Ω`. This module proves the other inclusion
  `P.zeroFixer Ω ≤ P.parahoric Ω` (`zeroFixer_le_parahoric`), which is the case `∗ = 0` of KP
  Proposition 7.7.5(1). The theorem rewrites with `parahoric_eq_nonnegativeRootSubgroup` and
  concludes by `le_antisymm`.
* `hasNormalizerParahoricFixers_of_mem_affineWeylGroup (hP) (hNW)`. If every element of
  `N(F) ∩ G(F)^0` acts on `A(S)` through `W(Ψ)`, the predicate holds. This is
  `normalizer_mem_parahoric` below, applied to each element.

KP Axiom 4.1.8 (3) (`P.HasRootZeroFixers`) is already the published, premise-free
`ParahoricBuildingData.hasRootZeroFixers`.

How this is meant to be used: the published `normalizerAffineEquiv_mem_affineWeylGroup` derives
the hypothesis of `hasNormalizerParahoricFixers_of_mem_affineWeylGroup` from the range part of
KP Theorem 7.5.3(2) (`SimplyConnectedNormalizerAffineWeylStatement`). That statement is open
(Task 4675). Once it is proved, these two theorems and `hasRootZeroFixers` give
`RootGroupActionAxiomStatement`. This module neither proves nor assumes that statement.

## Source and route

The route follows KP Lemma 7.7.4 and the proof of Proposition 7.7.5(1), printed pp.268–270
(PDF pp.299–301), for the group `G(F)^0`. KP reduces Proposition 7.7.5(1) to one point by
Lemma 7.7.4. It then handles one point with Theorem 7.5.3 and Lemma 7.4.7. Lemma 7.7.4 does
finite sets by induction, adding one point at a time with a Bruhat-decomposition argument. It
does general sets by an increasing-union argument. The Lean proof differs in two places:

1. It does not first prove `N^0_Ω = ⋂ N^0_x`. It takes `N^0_Ω ⊆ P_Ω` for finite `Ω` as the
   hypothesis `HasNormalizerParahoricFixers`. Separately, it shows that an element of
   `N(F) ∩ G(F)^0` that acts through `W(Ψ)` and fixes a finite `Ω` lies in `P_Ω`
   (`normalizer_mem_parahoric`).
2. For bounded `Ω` it skips the increasing-union argument. The published
   `exists_finite_subset_parahoric_eq` gives a finite `Ω' ⊆ Ω` with `P_{Ω'} = P_Ω`, so it is
   enough to know `G(F)^0_{Ω'} ⊆ P_{Ω'}` and `G(F)^0_Ω ⊆ G(F)^0_{Ω'}`.

## The lemmas

All lemmas are in namespace `Langlands.Geometry.Building.ParahoricBuildingData`.

* `exists_sharpFixer_normalizer_eq_affineReflection`. Let `ψ ∈ Ψ` vanish on `Ω` and let `v`
  be a coroot of `ψ`. Then some `m ∈ N(F)` with `m ∈ G(F)^♯_Ω` acts on the apartment as the
  reflection `r_ψ`. Proof: choose `u ∈ U_ψ ∖ U_{ψ+}` (the two differ by the definition of
  `Ψ`). Use `reflectionFunctional_eq_of_mem_diff` and an opposite factor pair `u′ u u″` from
  `hasOppositeFactorPairs`, with `u′, u″ ∈ U_{-ψ}` by `oppositeFactors_mem_neg_affineRootGroup`.
  Since `ψ = 0` on `Ω`, each of `u`, `u′`, `u″` is in a root fixer `U_{±a,Ω,0}`, so the product
  `m(u) = u′ u u″` is in `G(F)^♯_Ω`. Its action is `r_ψ` by
  `normalizerAffineEquiv_reflectionElement_eq_of_isCoroot`.
* `normalizer_mem_parahoric`. For a finite non-empty `Ω`, an `n ∈ N(F) ∩ G(F)^0` whose action
  `w` on the apartment lies in `W(Ψ)` (hypothesis `hnW`) and which fixes `Ω` pointwise lies in
  `P_Ω`. Proof:
  `AffineRootSystem.exists_generic_point` (local finiteness of `Ψ`) gives a point `z` such that
  every affine automorphism of the apartment fixing `Ω` pointwise fixes `z`, and every `ψ ∈ Ψ` with `ψ(z) = 0` vanishes on
  `Ω`. Then `mem_closure_pointReflections_of_apply_eq` puts `w` in the subgroup generated by
  the reflections in the roots vanishing at `z`. The previous lemma realizes each such
  reflection by an element of `N(F) ∩ G(F)^♯_Ω`. So `w` is the action of some
  `m ∈ N(F) ∩ G(F)^♯_Ω ⊆ P_Ω`. Then `m⁻¹ n ∈ N(F) ∩ G(F)^0` acts trivially, so
  `normalizerAffineEquiv_eq_one_iff` and `mem_normalizerZero_iff` put it in the image of `Z(F)^0`,
  which lies in `P_Ω` (`map_centralizerZero_le_parahoric`).
* `zeroFixer_anti`: `Ω ⊆ Ω'` implies `G(F)^0_{Ω'} ≤ G(F)^0_Ω`.
* `hasNormalizerParahoricFixers_of_mem_affineWeylGroup`, described above.
* `zeroFixer_singleton_le_parahoric` (assumes `HasNormalizerParahoricFixers`), the one-point
  case `G(F)^0_x ⊆ P_x`. If
  `g ∈ G(F)^0` fixes the image of `x`, then `ApartmentQuotient.mem_stabilizer_apartment_iff`
  writes `g = s n` with `s ∈ G(F)^♯_x` and `n ∈ N(F)` fixing `x`. Since `s ∈ P_x ⊆ G(F)^0`, also
  `n ∈ G(F)^0`, so the predicate for `Ω = {x}` gives `n ∈ P_x`.
* `exists_genericCocharacter_eval_nonneg`. For each `w ∈ V(S)` there is a generic cocharacter
  `ν` such that every relative root `b` with `⟨b, ν⟩ > 0` has `b(w) ≥ 0`. This is KP's choice of
  "a positive system of roots, all of which are non-negative on `x − y`". Proof:
  `RootFaceCone.exists_int_sign_realization` (from `Langlands.LinearAlgebra.RootFaceReflection`)
  gives a cocharacter `mu` with `⟨b, mu⟩ < 0` whenever `b(w) < 0`. Take a generic `ν₀` and
  `M = 1 + Σ_b |⟨b, ν₀⟩|`. Then `ν = M • mu + ν₀` is generic: `⟨b, ν⟩` is `⟨b, ν₀⟩ ≠ 0` when
  `⟨b, mu⟩ = 0`, and otherwise it has the sign of `⟨b, mu⟩`. If `b(w) < 0` then `⟨b, ν⟩ < 0`.
* `smul_eq_self_of_unipotent_mul_smul_apartmentMap_eq` is the Bruhat step. Let `ν` be generic,
  `v ∈ U_ν(F)` and `n ∈ N(F)`, and suppose `v n` fixes the image of `x`. Then `n` fixes `x`.
  Proof: `ApartmentQuotient.mem_stabilizer_apartment_iff` writes `v n = s m` with
  `s ∈ G(F)^♯_x` and `m ∈ N(F)` fixing `x`. Decompose `s` by
  `sharpFixer_subset_mul_sharpNormalizerStabilizer` (for `-ν`) as `v′ w k` with `v′ ∈ U_ν`,
  `w ∈ U_{-ν}` and `k ∈ N(F)` fixing `x`. Then `k m n⁻¹ = w⁻¹ (v′⁻¹ v)` lies in
  `U_{-ν} · U_ν`. So the published `normalizer_eq_one_of_unipotent_product` (Bruhat) gives
  `n = k m`, which fixes `x`.
* `exists_mul_mul_normalizer_of_mem_parahoric`, KP's decomposition `G(k)^0_Ω = U⁺_Ω U⁻_Ω N^0_Ω`
  (Proposition 7.3.12) in the form needed here. For finite non-empty `Ω` and generic `ν`, each
  `g ∈ P_Ω` is `u v n` with `u` in the subgroup generated by the `U_{b,Ω,0}` for `⟨b, ν⟩ > 0`,
  `v` in the subgroup generated by the `U_{b,Ω,0}` for `⟨b, ν⟩ < 0`, and
  `n ∈ N(F) ∩ G(F)^0` fixing `Ω`. Proof: `coe_parahoric_eq_mul_reverse` writes
  `g = s · z` with `s ∈ G(F)^♯_Ω` and `z ∈ Z(F)^0`. The published `finiteSharpFixerExchange`
  writes `s = u v h` with `h ∈ N(F) ∩ G(F)^♯_Ω` fixing `Ω`. Set `n = h z`.
* `mem_parahoric_insert` (assumes `HasNormalizerParahoricFixers`), the induction step of KP
  Lemma 7.7.4. If `Ω` is finite and non-empty,
  `g ∈ P_Ω`, and `g ∈ G(F)^0` fixes the image of `insert x Ω`, then `g ∈ P_{insert x Ω}`.
  Proof: pick `y ∈ Ω`, write `x = y + w`, and choose `ν` adapted to `w` as above. Decompose
  `g = u v n`.
  - Each generator of `u` lies in `U_{b,Ω,0}` with `⟨b, ν⟩ > 0`, so `b(w) ≥ 0`. Then
    `filtration_mk_vadd` gives `U_{b,y,0} ⊆ U_{b,x,0}`. So `u ∈ G(F)^♯_{insert x Ω} ⊆
    P_{insert x Ω}`.
  - Hence `v n` fixes the image of `insert x Ω`. The `U_{b,Ω,0}` with `⟨b, ν⟩ < 0` lie in the
    unipotent group `U_{-ν}(F)` (`RelativeRoot.subgroup_le_dynamicUnipotent`). So the Bruhat
    step shows that `n` fixes `x`. The predicate for `insert x Ω` gives `n ∈ P_{insert x Ω}`.
  - Then `v` fixes the image of `insert x Ω`. `mem_positiveRootGroups_of_mem_unipotent_of_smul_apartmentMap_eq`
    puts `v` in `⋂_{z ∈ insert x Ω} ⨆_b U_{b,z,0}`.
    `iInf_iSup_chamberRootGroup_eq_iSup_rootFixer` identifies this with
    `⨆_b U_{b, insert x Ω, 0} ⊆ G(F)^♯_{insert x Ω}`.
  - So `g = u v n ∈ P_{insert x Ω}`.
* `zeroFixer_le_parahoric_of_finite` (assumes `HasNormalizerParahoricFixers`): `G(F)^0_Ω ⊆ P_Ω` for finite non-empty `Ω`, by
  `Set.Finite.induction_on`. The singleton case is `zeroFixer_singleton_le_parahoric`. The
  insertion case combines the induction hypothesis (through `zeroFixer_anti`) with
  `mem_parahoric_insert`.
* `zeroFixer_le_parahoric` (assumes `HasNormalizerParahoricFixers`): `G(F)^0_Ω ⊆ P_Ω` for non-empty bounded `Ω`, by the
  finite-subset reduction `exists_finite_subset_parahoric_eq` described above.

* `hasZeroFixerGenerators_of_hasNormalizerParahoricFixers`, described above.

## Scope

This module does not prove `RootGroupActionAxiomStatement`. It proves KP Axiom 4.1.8 (2) for
data that satisfy `HasNormalizerParahoricFixers`. It also proves that this predicate holds when
`N(F) ∩ G(F)^0` acts through `W(Ψ)`. Whether that holds for all data satisfying the apartment
axioms is the open range part of KP Theorem 7.5.3(2).
