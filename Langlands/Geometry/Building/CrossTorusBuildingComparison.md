# Actual roots and reduced quotients for a chosen target class

This derived unit takes actual torus and ambient-group isomorphisms over an
arbitrary field, their commuting square with the embedded tori, and two
supplied apartment data with the same scalar function. The inclusions are
monomorphisms on their underlying schemes and both ambient structural
morphisms are affine. One transported source valuation family is required
to lie in the chosen target class.

The existing full-equipollence-class argument identifies the entire
transported apartment datum with the supplied target datum. For the
resulting canonical affine comparison, the ordinary and extended affine
roots are exactly the inverse-precomposition images of the source root
sets. Both assertions concern the entire sets and preserve and reflect
membership of every affine functional. The existing actual root-group
comparison retains the original strict-group and double-root tests.

`reducedBuildingTransportEquivOfMem` composes the existing actual reduced
quotient transport with the equality identifying the chosen target datum.
It maps every original representative `(g,x)` to actual ambient transport
of `g` and the canonical affine comparison of `x`. It commutes with the
canonical apartment maps and intertwines the existing rational-point
actions. Every full point stabilizer has exactly its actual ambient
subgroup image. The equivalence does not depend on which matching source
valuation witnesses the class equality, and injectivity of the apartment
chart is preserved and reflected.

The provenance is internal: full-class equality, actual cross-torus
affine-root transport and actual quotient transport are imported unchanged.
Equality elimination reduces the chosen-target statements to those
existing transports. No common-apartment axiom or chart injectivity is
needed to construct this quotient equivalence. Both apartment data, the
actual isomorphisms and the one matching-family premise remain inputs;
the unit constructs no such premise for arbitrary data and asserts no
unconditional building or reductive-group existence theorem.
