# Full point fixers on restricted root groups

This internal supporting result works over an arbitrary field with a supplied
KP apartment for a maximal split torus in a connected reductive group. It
compares the full stabilizer of an apartment point with the canonical root
filtration obtained by restriction to a smaller split torus. It does not
construct integral models or prove the host depth-zero opposite-factor
statement.

`KPApartmentData.semigroupPoints_inf_reducedFixer_eq_selectedRootDepth`
assumes a character semigroup excluding zero and an integral cocharacter
pairing positively with all actual roots selected by that semigroup. Its
conclusion identifies the actual semigroup-subgroup points that stabilize the
apartment point with the subgroup generated by its selected depth-zero root
groups.

The proof perturbs the positive direction to a generic integral cocharacter
while preserving its positive root pairings. Selected semigroup points then
belong to that cocharacter's actual dynamic unipotent subgroup. The published
`mem_positiveRootGroups_of_mem_unipotent_of_smul_apartmentMap_eq` puts a
stabilizing point in the positive depth-zero root subgroup. The exact
semigroup-intersection theorem and
`selectedRootDepthSubgroup_inf_semigroup_eq` retain precisely the selected
filtered factors. Conversely every selected root filtration fixes the
apartment point.

`KPApartmentData.restrictedRootGroupPoints_inf_reducedFixer_eq_depthZero`
specializes this comparison to the inverse image of the positive integral
ray of a nonzero character of the smaller split torus. A cocharacter pairing
positively with that character provides the required positive direction.
The actual restricted root functor is the selected semigroup subgroup by
`subgroup_comp_torusHom_eq_semigroupSubgroup`; at zero depth the multiplier
scalings all vanish. The conclusion therefore identifies its intersection
with the full point stabilizer with the original
`torusRestrictedRootDepthSubgroup` at zero, including nonreduced root systems
and roots occurring with several restriction multipliers.

`KPApartmentData.restrictedRootFixerEquivDepthZero` packages this exact subgroup
equality as a multiplicative equivalence. The accompanying coercion theorem
proves that it preserves each ambient rational point.

All inputs are published algebraic and apartment results. The proof uses
neither a lower root-datum valuation nor apartment affine-root-system axioms.
Its provenance is this composition of the published positive-unipotent
stabilizer, filtered semigroup-intersection and torus-restriction results.
