# Root intersections of the groups `G(K)_{x,r}` at positive depth

Helper module for the proof of `LocalMoyPrasadGroupPropertiesStatement`. It proves clause 4
(`LocalMoyPrasadRootIntersection`) for `r > 0`, assuming the sign product cover described
below. The module introduces no definitions. Its results are theorems about the published
objects `BuildingData.moyPrasad`, `BuildingData.rootGroupSpan` and
`BuildingData.rootFiltrationSpan`, and about the filtrations `KPApartmentData.filtration` of
a KP apartment.

Source: Kaletha–Prasad, *Bruhat–Tits theory: a new approach* (2023), Proposition 7.3.12(1),
(3), (5). For a closed set `Ψ` of roots in an open half-space, `U_Ψ ∩ G_{x,r} = U_{Ψ,x,r}`.
KP derive this from the integral model `G_{x,r}` and the product decomposition of its
`O`-points. The Lean proof below takes a different route. It uses the sign product cover
together with the Library's unique ordered coordinates on the positive unipotent group.

## KP apartment data over any field `k`

Fix KP apartment data `D` for a torus `i : S → G` with `G` affine, and a point `x` of the
apartment.

- `exists_mem_filtration`: every point `g` of a root group `U_a(k)` lies in some filtration
  subgroup `U_{a,x,s}`. If `x_a(g) = ∞`, take `s = 0`; otherwise take `s = x_a(g)`.
- `rootGroupPoints_commutator_le` (axiom V 3 for the full root groups): let `a, b` be roots
  with `b` not a negative multiple of `a`. Then `[U_a(k), U_b(k)]` lies in the subgroup
  generated by the root groups `U_{pa+qb}(k)` with `p, q > 0` and `pa + qb` a root.

  *Proof.* For generators `g ∈ U_a(k)` and `h ∈ U_b(k)`, choose depths `s, s'` with
  `g ∈ U_{a,x,s}` and `h ∈ U_{b,x,s'}`. The Library's commutator estimate
  `filtration_commutator_le` puts `[g, h]` in the span of the `U_{pa+qb,x,ps+qs'}`. Each of
  these lies in the full root group `U_{pa+qb}(k)`.

- `mem_iSup_filtration_of_mem_rootGroups`: let `G` be connected reductive and `S` a maximal
  split torus. Let `ν` be an integral cocharacter and `r ≥ 0`. Let `Ψ` be a set of
  `ν`-positive roots that is closed: if `b, c ∈ Ψ`, `p, q > 0` and `pb + qc` is a root,
  then `pb + qc ∈ Ψ`. Suppose `g` lies in `U_Ψ`, the subgroup generated by the `U_b(k)`
  with `b ∈ Ψ`. Suppose also that `g` lies in the subgroup generated by the `U_{b,x,r}` with
  `b` `ν`-positive. Then `g` lies in the subgroup generated by the `U_{b,x,r}` with `b ∈ Ψ`.

  *Proof.* List the indivisible `ν`-positive roots as `a_1, …, a_n` (`Set.Finite.fin_param`).
  Every `ν`-positive root is some `a_j` or some `2a_j`
  (`HasOppositeFactorPairs.exists_indivisiblePositiveRoot_eq_or_double`, with the opposite
  factor pairs from the rank-one factorization). Order the roots `a_1, 2a_1, …, a_n, 2a_n`.
  Attach to each the subgroup `H_l = U_{c_l}(k)` if its root `c_l` lies in `Ψ`, and
  `H_l = 1` otherwise.

  1. *`U_Ψ` is an ordered product.* Weight each `H_l` by the height `⟨c_l, ν⟩`. By
     `rootGroupPoints_commutator_le` and `positiveRootCombination_height`, the commutator of
     two of these subgroups lies in the span of subgroups of strictly larger height. The
     relevant combinations `pc_j + qc_l` lie in `Ψ` because `Ψ` is closed. The Library's
     `HeightCollection.range_orderedProduct_eq_iSup` then says the ordered products
     `h_1 ⋯ h_{2n}` exhaust the span of the `H_l`, which contains `U_Ψ`. Grouping the
     factors in pairs (`range_orderedSubgroupPairsProduct`) writes
     `g = s_1 ⋯ s_n` with `s_j ∈ H_{a_j} · H_{2a_j}`. Each `s_j` lies in `U_{a_j}(k)`,
     because `U_{2a_j}(k) ≤ U_{a_j}(k)` (`RelativeRoot.double_subgroup_le`).
  2. *Block coordinates.* By `range_orderedPositiveFiltrationBlockProduct_eq_iSup_of_reductive`
     (from the companion module `KPLocalMoyPrasadIntersectionCell`), `g = t_1 ⋯ t_n` with
     `t_j ∈ U_{a_j,x,r} · U_{2a_j,x,r}`. Here `U_{2a_j,x,r} = 1` if `2a_j` is not a root.
  3. *Uniqueness.* Multiplication `∏_j U_{a_j}(k) → G(k)` is injective
     (`RelativeRoot.orderedRootSubgroupPoints_injective_of_statement` with the Library's
     `dynamicRootOrderedProduct`). Hence `s_j = t_j` for every `j`.
  4. *Each `t_j = u v` lies in the target span*, with `u ∈ U_{a_j,x,r}` and
     `v ∈ U_{2a_j,x,r}`. There are three cases.
     - `a_j ∈ Ψ`. Then `u` is a generator. If `2a_j` is a root, then `2a_j = a_j + a_j ∈ Ψ`
       by closedness, so `v` is a generator too. Otherwise `v = 1`.
     - `a_j ∉ Ψ` and `2a_j ∈ Ψ`. Then `s_j ∈ U_{2a_j}(k)`, so
       `u = s_j v⁻¹ ∈ U_{2a_j}(k)`. Axiom V 4 (`IsRootDatumValuation.double`) gives
       `x_{2a_j}(u) = 2 x_{a_j}(u) ≥ 2r ≥ r`, using `r ≥ 0`. So `u ∈ U_{2a_j,x,r}`, and
       `t_j = u v` lies in the target span.
     - `a_j ∉ Ψ` and `2a_j ∉ Ψ`. Then `s_j = 1`, so `t_j = 1`.

## Building data over `K`

Fix building data `B` over `K = F^ur` with `Z = Z_G(S)` a torus (`hZ`).

- `mem_rootFiltrationSpan_of_mem_rootGroupSpan`: for an integral `μ`, `r ≥ 0` and a closed
  set `Ψ` of `μ`-positive roots,
  `U_Ψ ∩ U_{Φ⁺(μ),x,r} ⊆ U_{Ψ,x,r}`. This is `mem_iSup_filtration_of_mem_rootGroups` for
  the apartment of `B`. The proof matches the filtration span over `K = UnramifiedClosure F`
  against the apartment lemma over the inertia fixed field. Lean checks this match slowly,
  so the theorem raises `maxHeartbeats` to `800000`.
- `rootIntersection_of_productCover` (**clause 4 for `r > 0`**). Assume the sign product
  cover `hPC`: for every `x`, every `r > 0` and every generic integral cocharacter `μ`,

  `G(K)_{x,r} = U_{Φ⁺(-μ),x,r} · j(Z(K)_r) · U_{Φ⁺(μ),x,r}`.

  This is exactly the conclusion of `LocalMoyPrasadPositiveProductStatement`. Let `Ψ` be closed with
  `⟨b, ν⟩ > 0` for every `b ∈ Ψ`, where `ν` is real. Then for `r > 0`,
  `U_Ψ ⊓ G(K)_{x,r} = U_{Ψ,x,r}`.

  *Proof.* `⊇`: each `U_{b,x,r}` lies in `U_b(K)` and in `G(K)_{x,r}`. `⊆`: by
  `exists_sign_and_generic` (Levi module), choose a generic `μ` positive on every
  `ν`-positive root, so `Ψ ⊆ Φ⁺(μ)`. By the cover, `g = u · j(z) · v` with
  `u ∈ U_{Φ⁺(-μ),x,r}`, `z ∈ Z(K)_r` and `v ∈ U_{Φ⁺(μ),x,r}`. Also `g = 1 · j(1) · g`
  with `g ∈ U_Ψ ⊆ U(μ)(K)`. Open-cell uniqueness (`eq_of_mul_eq_mul`, Cell module) gives
  `g = v ∈ U_{Φ⁺(μ),x,r}`. The previous theorem then gives `g ∈ U_{Ψ,x,r}`.

The case `r = 0` of clause 4 is not covered here. The cover hypothesis is stated only for
`r > 0`, and the depth-zero case needs a separate argument.
