# Actual real-depth root-generated subgroups

This file constructs the real-valued specialization of the root-generated
subgroups in Kaletha–Prasad Definition 7.3.3(1)–(3), then identifies its
constant-zero case with the actual point parahoric. It asserts no
compactness, boundedness or openness.

The source is *Bruhat–Tits theory: a new approach* (2023), Definition
7.3.1, printed p. 246 / PDF p. 277; Definition 7.3.3, Remark 7.3.4 and
Example 7.3.7(1), printed p. 247 / PDF p. 278; and Definition 7.4.1,
printed p. 255 / PDF p. 286. The registered source ID is
`kaletha-prasad-2023-bruhat-tits-new-approach`, SHA-256
`05ad9a284a2577b34d1a270228b74dfb28f520561ae7772d8f38dddb78938732`.
The 1 November 2024 corrections are
`kaletha-prasad-2024-corrections`, SHA-256
`23293f51e58d5ceecb91f834743f68058b98431797d2531142415d013fdf61ed`.
Their PDF pp. 33–35 correct the Chapter 7 assumptions and point-parahoric
singleton notation. This construction supplies no certificate of the
full corrected building axioms.

`IsRealDepthConcave` tests the source's pairwise concavity condition on
the actual relative roots together with zero. Its function is defined
on the full character lattice, and values outside that subset are
irrelevant. The constant-zero function satisfies the condition directly.
Strict depths and infinite depths are outside this real-valued API.

`sharpFiltration x f` is the subgroup generated by all actual
`filtrationBlock x f a`, for `a` an actual relative root. Each block is
the existing set product
`U_{a,x,f(a)} U_{2a,x,f(2a)}`, with the second factor trivial when `2a`
is absent. The construction makes sense for any real-valued `f`;
concavity is required for further structural assertions in the source.

The helper equality `sharpFiltration_eq_iSup` expresses the same
generated subgroup as the supremum of all ordinary root filtration
groups. Each ordinary factor lies in its block by taking the second
factor equal to one. Conversely, both factors of each block lie in
that supremum: the doubled-root factor is itself indexed by `2a` when
present and is trivial otherwise. This argument does not replace an
individual block by its first factor, and requires no root-valuation
scaling assertion. At constant depth zero, `rootFixer_singleton`
therefore identifies `sharpFiltration` with the actual sharp fixer.

For `P : ParahoricBuildingData G`, `zeroCentralFiltration x f` joins
that generated subgroup with the image of the same actual
`P.centralizerZero`. Its source interpretation is the full `P_{x,f}`
when `f` is concave and `f(0) = 0`. The total construction is also
defined outside those conditions, where no such interpretation is
claimed. Its constant-zero case is exactly `P.parahoricAt x`, including
the central factor. Arbitrary nonzero central depths and their
centralizer filtrations are outside this API.

The zero-specialization equalities are derived from the published actual
definitions. They hold in rank zero and both local-field
characteristics without additional apartment axioms. These comparisons
do not prove KP Corollary 7.3.14 or the chamber compact-openness target.
