# Collection with primitive and doubled-root ray factors

This internal construction works over a field in universe u with the original
monomorphic torus map into an affine group scheme, an actual root-function
family, and an actual root-datum valuation. It uses the explicit closed positive
root and depth conditions of `IsClosedPositiveRootDepth`.

The set `rootRayDepthSet i φ Ψ f a` retains the filtration of a at f(a) when a is
selected. If a is absent but 2a is selected, it retains the filtration of 2a at
f(2a), including actual membership in the doubled-root group. If neither is
selected, its only element is the identity. `orderedRootRayDepthProduct` is the
actual ordered product set of these factors, and `rootRayDepthSubgroup` equips
each factor with the subgroup structure already supplied by V1. Every factor
lies in the original root group of a, using the actual doubled-root inclusion.

Compression requires the additional bound 2*f(a) ≤ f(2a) whenever both roots
are selected. V4 proves the arbitrary-depth inclusion of the doubled-root
filtration in the primitive-root filtration under exactly this bound.
The closed positive depth condition supplies the reverse inequality, so these
two assumptions together impose equality when both roots are selected.
The bound is not asserted for an arbitrary depth function.

For any finite supplied list a such that each root of Ψ is a list entry or its
double, `orderedRootRayDepthProduct_eq_iSup` identifies its actual ordered
product set with the subgroup generated by the original filtrations on Ψ.
The order and all original real depths are preserved. The list can contain
repetitions or extra positions; no primitive-root property or injectivity is
assumed of the list. The supplied covering condition remains explicit and is
not inferred from the valuation axioms. In particular, this result retains
sets containing 2a without a.

The proof collects the selected entries of the doubled list using the existing
positive-height commutator theorem and `HeightCollection`. Unselected entries
contribute the identity subgroup. V4 makes each adjacent primitive/double pair
comparable; if the primitive root is absent, it is the identity subgroup.
A finite ordered-product calculation combines each comparable pair into its
supremum. This supremum is exactly the explicitly retained ray factor.
The provenance is internal composition of the actual V1, V3 and V4 interfaces,
the published root-subgroup inclusion, and finite group collection. No new
assertion from external literature is used.

This construction does not yet prove field-extension reflection of the
generated subgroup or establish V3 for a restricted family. It does not
construct a valuation, an apartment, or the supplied-model building comparison.

The finite-list adjacent-pair product identity reuses `prod_ofFn_pairs` from `ChamberPositiveCollection`.
