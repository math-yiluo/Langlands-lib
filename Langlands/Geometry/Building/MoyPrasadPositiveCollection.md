# Collection of original constant-depth blocks within one sign

This internal construction extends the published positive chamber collection argument to any constant nonnegative real depth. It retains the original two-factor blocks and their given order.

V3 bounds each commutator by root subgroups in directions `p a + q b` with `p,q > 0`. If both roots are positive for the supplied cocharacter, their lattice heights strictly increase. The resulting depth `(p + q) r` is at least `r` for `r ≥ 0`, so the same finite height-collection theorem applies.

To retain multipliable roots, each listed indivisible positive root is expanded to two adjacent positions, its original root and its double. The double position uses the trivial subgroup precisely when that root is absent. The published affine-root-system and derivative-root assumptions show that these positions cover all positive roots. Height collection then gives the subgroup generated by all positive root filtrations. A separate elementary pairing lemma identifies the range of the expanded product with the ordered product of the original set-product blocks. This argument never discards the doubled-root factor or assumes it is contained in the first factor at the same positive depth.

`positiveFiltrationBlockProductEquiv` combines this range equality with the proved actual algebraic ordered-root injectivity to give bijective coordinates on that positive generated subgroup. The construction is at the same apartment point and depth and works for every complete injective ordering, including the empty root system. It establishes the fixed-sign collection step only; exchange between opposite signs, the full Moy–Prasad covering theorem, covariance and the host simultaneous-basis statement remain open.
