# Proof of the parahoric double-coset bijection

Lean module: `Langlands.Geometry.Building.ParahoricDoubleCosetProof`,
namespace `Langlands.Geometry.Building`.

This module proves the published target
`Langlands.Geometry.Building.ParahoricDoubleCosetStatement` of
`Langlands/Geometry/Building/IwahoriWeylStatement.lean`, which is KP Theorem 7.8.1(3).

## Statement

```
theorem Langlands.Geometry.Building.parahoricDoubleCoset :
    ParahoricDoubleCosetStatement.{u}
```

The type is exactly the published proposition, at an arbitrary universe `u`, with no further
hypothesis. Unfolded, it reads:

```
ParahoricDoubleCosetStatement.{u} =
  ∀ (F : Type u) [Field F] [ValuativeRel F] [TopologicalSpace F]
    [IsNonarchimedeanLocalField F] (G : GroupScheme (Spec (CommRingCat.of F)))
    [IsAffineHom G.X.hom] (P : ParahoricBuildingData G),
    P.apartment.SatisfiesApartmentAxioms P.centralizer →
      ∀ C F₁ F₂ : Set P.Apartment, AffineRootSystem.IsChamber P.affineRoots C →
        AffineRootSystem.IsFaceOf P.affineRoots F₁ C →
        AffineRootSystem.IsFaceOf P.affineRoots F₂ C →
        P.ParahoricDoubleCosetBijection F₁ F₂
```

where, for fixed data `P` and subsets `F₁`, `F₂` of the apartment,

```
P.ParahoricDoubleCosetBijection F₁ F₂ =
  ∃ (_ : P.normalizerZero.Normal),
    ∃ e : DoubleCoset.Quotient (P.affineFacetStabilizer F₁ : Set P.IwahoriWeylGroup)
          (P.affineFacetStabilizer F₂) ≃
        DoubleCoset.Quotient (P.parahoric F₁ : Set (rationalPoints G)) (P.parahoric F₂),
      ∀ n : normalizerPoints P.i,
        e (DoubleCoset.mk (P.affineFacetStabilizer F₁) (P.affineFacetStabilizer F₂)
            (QuotientGroup.mk n)) =
          DoubleCoset.mk (P.parahoric F₁) (P.parahoric F₂) (n : rationalPoints G)
```

In words: let `P` be parahoric building data of a group `G` over a nonarchimedean local field
`F`, of either characteristic, whose apartment satisfies the apartment axioms (V 6, V 7, AS 2–AS 5,
with the AS 5 of the corrected opening of KP Chapter 7). Let `F₁`, `F₂` be faces of a common
chamber `C`. Then `Z(F)^0` is normal in `N(F)`, and there is an equivalence between two
double-coset spaces. The first is `W^aff_{F₁}\W̃^0/W^aff_{F₂}`. Here `W̃^0 = N(F)/Z(F)^0` is
the full Iwahori–Weyl group (`P.IwahoriWeylGroup`), and `W^aff_{Fᵢ}` is the actual affine
facet stabilizer `P.affineFacetStabilizer Fᵢ`, a subgroup of `W̃^0`. The second is
`P_{F₁}\G(F)/P_{F₂}`, for the full parahoric subgroups `P_{Fᵢ} = P.parahoric Fᵢ`. The
equivalence sends the double coset of the class of every actual normalizer point
`n ∈ N(F)` to `P_{F₁} n P_{F₂}`. An equivalence is injective and surjective. It keeps all
components of `W̃^0` and of `G(F)`.

## Proof

The theorem is the single application

```
parahoricDoubleCosetStatement_of_statements iwahoriWeylChamberSplitting
  facetParabolicComparison
```

of the published reduction `parahoricDoubleCosetStatement_of_statements` (module
`Geometry.Building.DoubleCosetStatementReduction`). That reduction derives the target from two
published statements, each discharged here by a theorem proved in the Library:

1. `iwahoriWeylChamberSplitting : IwahoriWeylChamberSplittingStatement.{u}` (module
   `Geometry.Building.IwahoriWeylProof`), KP 7.8.2. Under the apartment axioms, for every
   chamber `C`, `Z(F)^0` is normal in `N(F)` and `G(F)^0` is normal in `G(F)`. Moreover
   `W̃^0 = W_aff ⋊ W̃^0_C`, and the stabilizer `W̃^0_C` of `C` maps bijectively onto
   `G(F)/G(F)^0`.
2. `facetParabolicComparison : FacetParabolicComparisonStatement.{u}` (module
   `Geometry.Building.FacetParabolicComparisonProof`), the common-chamber form of KP
   Proposition 7.5.5. Under the apartment axioms, for every chamber `C` and faces `F₁`, `F₂`
   of `C`, the two normalities hold and `P.CommonChamberFacetParabolics C F₁ F₂` holds. That
   is, there is a single comparison `e` of the affine part with `W_aff`, with:
   - one actual affine Iwahori–Tits datum `P.AffineIwahoriTitsWith C e` for the full Iwahori
     subgroup `P.parahoric C` inside `G(F)^0`;
   - for each `Fᵢ`, a comparison `P.FacetParabolicComparisonWith C Fᵢ e`. It consists of
     `P.parahoric Fᵢ ≤ P.zeroSubgroup`; the equality of the subgroup generated by the
     facet-simple reflections with `P.affineFacetStabilizer Fᵢ`; and the equality of the
     restriction of `P.parahoric Fᵢ` to `G(F)^0` with the union of the Iwahori Bruhat cells
     indexed by that subgroup.

For each field, group, data, apartment-axiom proof, chamber and pair of faces, the reduction
instantiates both statements at exactly those premises. The common-chamber face premises are
used, not dropped. It then applies the fixed-data assembly
`ParahoricBuildingData.parahoricDoubleCosetBijection_of_splitting_of_commonChamberFacetParabolics`,
which passes the following to the adapter `parahoricDoubleCosetBijection_of_zeroTits_subgroupOf`
(module `Geometry.Building.ParahoricDoubleCosetComponents`):

- component surjectivity of the chamber stabilizer, from the splitting
  (`chamberStabilizer_toComponents_surjective_of_splitting`);
- the chamber containment and the Tits system of the one common datum;
- the facet-simple generator sets, contained in the Tits generators by
  `facetSimpleInAffinePart_subset`;
- for each facet, the stabilizer equality, the containment in `G(F)^0` and the Bruhat-cell
  comparison.

The adapter first builds the Iwahori equivalence `W̃^0 ≃ P_C\G(F)/P_C` of KP Theorem 7.8.1(2),
the same equivalence as in `Geometry.Building.IwahoriDoubleCosetProof`. It then converts the
two subgroup-form Bruhat-cell comparisons into comparisons in the full group `G(F)`. The
published `subgroupParabolicDoubleCosetEquiv` passes from the Iwahori equivalence to the
equivalence `W^aff_{F₁}\W̃^0/W^aff_{F₂} ≃ P_{F₁}\G(F)/P_{F₂}`. Its application lemma gives
the prescribed value on every `n ∈ N(F)`, and the normality of `Z(F)^0` comes from the
proved statements.

Neither the normalities, nor the splitting, nor the Tits system, nor the facet comparisons, nor
any decomposition or bijection is a premise of `parahoricDoubleCoset`. Each is a conclusion of
the proved theorems above, derived from the unchanged apartment, chamber and face hypotheses.

## The corrected injectivity argument

The printed proof of KP Theorem 7.8.1(3) deduces it from Theorem 7.8.1(2) together with
Proposition 7.5.5. The printed injectivity proof of 7.8.1(2) uses only the equality
`I ∩ N(k) = Z(k)^0`. The authors' corrections of 1 November 2024 (PDF p. 35) state that this
argument is insufficient. They replace it with a component comparison through 7.8.2 and
Theorem 7.8.1(1), followed by the Bruhat decomposition for the Iwahori–Tits system of
Theorem 7.5.3. The Iwahori equivalence used here is built by that corrected route: equal
double cosets have equal components, since `I ⊆ G(F)^0`. A common chamber-stabilizer
representative normalizing `I` is removed, and Bruhat uniqueness is applied in `G(F)^0`. The
bare equality `I ∩ N(F) = Z(F)^0` is not used. The facet step then uses Proposition 7.5.5,
through the stabilizer equalities and Bruhat-cell comparisons of `facetParabolicComparison`.

## Scope

The result is conditional on actual `ParahoricBuildingData` whose apartment satisfies the
apartment axioms. It does not construct such data for every group, and it does not prove the
validity conditions of KP Definition 4.1.26.
