# Proof of the apartment coset promotion statement

`Langlands.Geometry.Building.lieCosetPromotionOfPositiveRootSupport` proves
the Library proposition
`Langlands.Geometry.Building.LieCosetPromotionOfPositiveRootSupportStatement`
(module `Langlands.Geometry.Building.KPLieCosetPromotionStatement`) at
arbitrary universe `u`. The theorem's type is exactly that proposition. It
is a step in the geometric argument of Kaletha–Prasad Proposition 13.6.7,
not that proposition.

## Setting

As in the statement, `L : P.LieFiltrationData` is supplied periodic
relative affine-root Lie data on supplied `P : ParahoricBuildingData G`.
`x` is an apartment point, `v` an apartment translation vector and `r` a
real depth. Put `n = ⌈−r⌉₊` and `t = r + n ≥ 0`. The premises are finite
generation of `𝔤_{x,r+}` and root support of `𝔪ⁿ X`: each `a • X` with
`a ∈ 𝔪ⁿ` lies in the sum of the root lattices `L.affineRootLie ψ` for which
`ψ(x) > t`, or `ψ(x) = t` and `ψ̇(v) > 0`.

## Three helper lemmas (private)

- `shiftRightWindow`: some `b > r` satisfies `⌈−s⌉₊ = ⌈−r⌉₊` for all
  `s ∈ [r, b)`. Hence `s + ⌈−s⌉₊ = s + n` there.
- `exists_le_of_fg_le_iSup`: a finitely generated submodule contained in
  the supremum of a nonempty directed family lies in one member. This is
  compactness of finitely generated submodules
  (`Submodule.fg_iff_compact`, `isCompactElement_iff_le_of_directed_sSup_le`).
- `eventually_affine_lt`: if `ψ(x) > t`, or `ψ(x) = t` and `ψ̇(v) > 0`,
  then `ψ(εv +ᵥ x) > t` for all sufficiently small `ε > 0`. The first case
  uses the bound `|ψ̇(v)|`; the second holds for every `ε > 0`.

## The proof

1. Ideals of `𝒪[F]` are principal, so `𝔪ⁿ` is generated by one element
   `a` (`Submodule.IsPrincipal.generator`). Let `S` be the span of `a • X` and `a • 𝔤_{x,r+}`.
   It is finitely generated by the finite-generation premise.
2. For `δ > 0` let `Q(δ)` be the intersection of the strict lattices
   `𝔤_{εv +ᵥ x, t+}` (published `lieFiltrationPlus` at the nonnegative
   depth `t`) over `0 < ε < δ`. These form a directed family as `δ`
   decreases; let `U` be its supremum.
3. `S ≤ U`. Every root lattice in the support premise lies in `U` by
   `eventually_affine_lt`, together with
   `affineRootLie_le_lieFiltration` and `lieFiltration_le_lieFiltrationPlus`.
   This gives `a • X ∈ U`. For `Z ∈ 𝔤_{x,r+}`, periodicity
   (`mem_lieFiltrationPlusReal`) gives `Z ∈ 𝔤_{x,q}` for some `q > r`.
   Antitonicity (`lieFiltrationReal_antitone`) moves this to some
   `q′ ∈ (r, b)`. There the shift is still `n`, so `a • Z ∈ 𝔤_{x,q′+n}`
   with `q′ + n > t`. That lattice is the centralizer term plus root terms
   with `ψ(x) ≥ q′ + n > t`. Both lie in `U` for all small `ε`.
4. Compactness for `S` gives one `δ` with `S ≤ Q(δ)`. Fix `0 < ε < δ` and
   `y = εv +ᵥ x`. Then `S ≤ 𝔤_{y,t+}`, which is the directed union of
   `𝔤_{y,q}` over `q > t`. Compactness again gives one `q > t` with
   `S ≤ 𝔤_{y,q}`.
5. Choose `s` with `r < s < min(b, q − n)`. Then `s + ⌈−s⌉₊ = s + n ≤ q`.
   Every `c ∈ 𝔪ⁿ` is a multiple of `a`, so `a • Z ∈ S` gives
   `Z ∈ 𝔤_{y,s}` by the definition of `lieFiltrationReal`. Applying this
   to `X` and to `Y − X` for every `Y` with `Y − X ∈ 𝔤_{x,r+}` gives
   `Y ∈ 𝔤_{y,s}`. The depth `s` is chosen before `Y`, as the statement
   requires.

The theorem uses only the standard axioms `propext`, `Classical.choice` and
`Quot.sound`.

## Relation to the source

Kaletha–Prasad, *Bruhat–Tits Theory: A New Approach* (2023), printed p. 481 /
PDF p. 512, translate `x` to `x′ = εν + x` and choose `s` on finitely many
affine-root conditions. Here the root decomposition is the supplied relative
one. Finite generation of the strict denominator replaces the finiteness
the source takes from its Moy–Prasad lattices. The proof does not supply
the root support premise from contraction, parahoric conjugacy or an
optimal point; those are separate Library statements.
