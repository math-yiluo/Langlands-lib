# The unique fixed point of an Iwasawa subgroup containing a regular torus element

Module `Langlands.Geometry.Building.GenericSpecialFixedPoint`.

This derived unit proves the uniqueness clause of the special-stabilizer
identity in an abstract form. The setting is apartment data
`D : KPApartmentData i ω` over an arbitrary field `k : Type u`. We assume that
`G` is connected reductive (`hG`), that `i` is a maximal split torus (`hi`),
and that the relative roots are reduced: `2 • a ∉ Φ` for every `a ∈ Φ`. No
apartment axiom is assumed.

## Main theorem

`KPApartmentData.eq_apartmentMap_of_forall_smul_eq` has the following
hypotheses:

* `x : D.Apartment`, and a subgroup `K` of `G(k)` fixing `D.apartmentMap x`;
* a generic cocharacter `ν` with the Iwasawa covering
  `∀ g, ∃ κ ∈ K, ∃ p ∈ P(k), g = κ * p`. Here `P` is
  `Dynamic.parabolic (CommGroupScheme.groupHom ν ≫ i)`;
* a point `s ∈ K ∩ centralizerPoints i`. As a normalizer point, `s` fixes `x`.
  For every positive root `b` of `ν`, every `h ∈ U_b(k)` and every apartment
  point `z`, it satisfies `z.val b (h⁻¹ * (s * h * s⁻¹)) = z.val b h`;
* `D.filtration x a 0 ≤ K` for every relative root `a`;
* for every relative root `a`, some `u ∈ U_a(k)` with `x.val a u = 0`.

Under these hypotheses, every point `y` of `D.ReducedBuilding` fixed by all of
`K` equals `D.apartmentMap x`.

In the intended application, `K` is the image of the integral points of a
model. The covering comes from
`HenselianParabolicCovering.hasLeftIntegralCovering_parabolic`. The element
`s` is the image of a cocharacter at a unit `c` such that `c^m - 1` is a unit
for the finitely many relevant `m`. The value conditions come from a root-group
parametrization with valuations `ord(c)` at `x`.

## Implemented proof

*Contraction lemma.* Put `v = u⁻¹ (s u s⁻¹)`. Since `s` lies in the dynamic
parabolic, `v ∈ U(ν)(k)` (`Dynamic.conj_mem_unipotent`), and `v` fixes the
image of `z`. The unipotent-stabilizer lemma of `GenericPointSharpExchange`
gives `v ∈ X_z := ⨆_{b > 0} U_{b,z,0}`. `exists_shift_mem` gives `T` with
`u ∈ X_w`, for `w = z + T ν`. Take a sorted enumeration `a` of the positive
roots. Apply `HeightContraction.mem_iSup_of_inv_mul_map_mem` with
`H j = U_{a_j,w,0}`, `X j = U_{a_j,z,0}`, the heights `⟨a_j, ν⟩` and
conjugation by `s`. Its inputs come from the following facts.

* Both families satisfy the published commutator height bound.
* `X j ≤ H j`, by `filtration_le_filtration_shift`.
* Ordered products of the `H j` are injective, by the published
  `orderedRootSubgroupPoints_injective_of_statement` and
  `dynamicRootOrderedProduct`.
* Conjugation by `s` preserves every `U_{a,y,0}`. Indeed `s` fixes every
  apartment point (`smul_eq_self_of_mem_centralizerPoints`) and acts trivially
  on roots (`weylAction_eq_one_iff`), so `conj_mem_filtration` applies.
* The rank-one condition is exactly the value hypothesis.

*Final step.* Fix a relative root `a` and an element `u` of value zero at `x`.
Choose `±ν₀`, for a generic `ν₀`, so that `a` is positive. Then
`u ∈ U(±ν₀)(k)` fixes the image of `z`. The unipotent-stabilizer lemma and the
depth-zero lemma give `u ∈ U_{a,z,0}`. Hence `a(v) ≥ 0`, where
`z.val = v +ᵥ x.val`. Using `-a` gives `a(v) = 0` for every root. So `v` lies
in the root annihilator and `z = x`.

*Main theorem.* Write `y = g • [z]` (`exists_smul_apartmentMap`) and
`g = κ p` (covering). The published `parabolic_eq_centralizer_mul_unipotent`
splits `p = l u`, with `l` in the dynamic centralizer and `u ∈ U(ν)(k)`.
`genericCentralizer` and `torusCentralizer_carrier_base` give
`l ∈ centralizerPoints i`. Then `y = κ • u′ • [z′]`, with `u′ = l u l⁻¹` in
`U(ν)(k)` and `z′ = l • z`. Since `K` is a group containing `κ`, `u′ • [z′]` is
fixed by `K`. In particular `s` fixes it, and `s` fixes `z′`. The contraction
lemma gives `u′ • [z′] = [z′]`. The final step, applied with the depth-zero
root groups at `x` contained in `K`, gives `z′ = x`. Therefore
`y = κ • [x] = [x]`.

## Provenance and scope

This is a derived unit with an internal proof. It establishes the
fixed-point uniqueness that accompanies Bruhat–Tits II, Proposition 4.6.28(i)
and Corollary 4.6.29(i) (printed pp. 135–136 / PDF pp. 132–133). It uses
neither the common-apartment property nor the schematic arguments of that
source. Instead it combines an Iwasawa covering, the unipotent-stabilizer
lemma (the input of Kaletha–Prasad Lemma 7.7.3, printed p. 268 / PDF p. 299),
and the filtration contraction lemma of `HeightContraction` for a regular
centralizer element. The Lean statements are not quoted from either source.

The unit does not construct `K`, the covering, the element `s` or the point
`x` for any model. It assumes reduced relative roots. It does not prove the
special-stabilizer statement itself.
