# Actual root reflections under apartment comparison

This internal derived unit compares two supplied actual valuation-building
data for the same connected reductive group over the same nonarchimedean
local field. An isomorphism of their embedded maximal split tori must
commute with the embeddings into that group.

The actual root subgroups, including the negative root subgroups, and
actual normalizers agree after character reindexing. The predicate for an
ordered opposite factor pair is therefore equivalent on both sides.
`oppositeFactorPairsEquivOfTorusIso` identifies the entire types of these
pairs, using the identity on both actual rational points. The associated
normalizer element retains the exact product of the first factor, the
middle root point and the second factor.

A supplied affine apartment equivalence must compare the full valuation
families at every corresponding apartment point. Evaluation then agrees
for every character and rational point. The entire source reflection
hyperplane maps onto the target hyperplane. For a nonidentity actual
root-group point, the transported reflection functional also equals the
target functional, using its known equality with the valuation at every
point. No comparison of only chosen hyperplanes or base points is used.

The AS1 theorem pulls back every target relative root through the existing
actual relative-root equivalence and retains each ordered opposite factor
pair. It pulls a target hyperplane point back through the apartment
equivalence, applies the supplied source pointwise-fixation witness and
uses compatibility of the actual normalizer actions. Its conclusion is
the unchanged `HasRootReflections`, with its quantifier over every
opposite factor pair.

The provenance is the unchanged definitions of actual opposite factor
pairs, reflection elements, hyperplanes and functionals, together with
the existing actual cross-torus comparisons. This is a derived transport
argument. Both actual data, the torus square, affine equivalence,
every-point family comparison, action comparison and source AS1 witness
remain explicit inputs. This unit neither constructs an opposite factor
pair nor proves the unconditional building-construction statement.
