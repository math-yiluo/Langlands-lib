# Commutators of Moy–Prasad subgroups at one apartment point

Module `Langlands.Geometry.Building.MoyPrasadCommutatorGenerators`. It proves the commutator
inclusion `⁅P_{x,r}, P_{x,s}⁆ ≤ P_{x,r+s}` (Kaletha–Prasad, Proposition 13.2.5(4)) for supplied
parahoric building data `P` and a supplied centralizer filtration `Zf`, under
`P.SatisfiesApartmentAxioms`, `Zf.SatisfiesFiltrationAxioms` and
`Zf.IsDoubleRootCommutatorFriendly`. The final theorem is
`ParahoricBuildingData.CentralizerFiltration.commutator_moyPrasad_le`. The proof follows the
route of KP's proof of 13.2.5(4). `P_x` normalizes `P_{x,r+s}` and contains both groups, so
the inclusion reduces to commutators of generators. Opposite root pairs are handled by
translating the apartment point. Here `P_{x,r} = Zf.moyPrasad x r` is the subgroup generated
by `j(Z(F)_r)` and the blocks `U_{a,x,r} U_{2a,x,r}`, and `P_x = P.parahoricAt x`.

All declarations are in namespace `Langlands.Geometry.Building`. Results cited from other
modules are published Library theorems.

## A group-theoretic reduction

`commutator_closure_le_of_le_normalizer`: let `M` be a group with subgroups `N` and `K`, where
`K ≤ normalizer N`, and let `S, T ⊆ K` be sets. If `⁅g, k⁆ ∈ N` for all `g ∈ S` and `k ∈ T`,
then `⁅closure S, closure T⁆ ≤ N`.

The proof is a closure induction, first in the second argument and then in the first. It uses
the identities `⁅g, k₁k₂⁆ = ⁅g, k₁⁆ · k₁⁅g, k₂⁆k₁⁻¹`, `⁅g, k⁻¹⁆ = k⁻¹⁅g, k⁆⁻¹k` and their
mirror images. Each conjugating element lies in `closure S ≤ K` or `closure T ≤ K`, so it
normalizes `N`.

## Translating the apartment point (namespace `ParahoricBuildingData`)

- `exists_eval_eq_of_mem_relativeRoots`: for a relative root `a` and `c : ℝ` there is
  `w ∈ V(S)` with `a(w) = c`. It takes `w = (c / ⟨a, ν⟩) ⊗ ν` for a generic cocharacter `ν`
  (`IsSplitSubtorus.exists_genericCocharacter`), which pairs nontrivially with every root.
- `mem_filtration_vadd_of_mem` and `mem_filtration_of_mem_vadd` move membership between
  `U_{a,x,ρ'}` and `U_{a,x+w,ρ}` whenever the depths satisfy `ρ - a(w) ≤ ρ'`, respectively
  `ρ' ≤ ρ - a(w)`. Here `x + w` is `(Submodule.Quotient.mk w : TranslationSpace P.i) +ᵥ x`.
  Both use `KPApartmentData.filtration_mk_vadd` (`U_{a,x+w,ρ} = U_{a,x,ρ-a(w)}`, module
  `RootFixerExchange`) and `KPApartmentData.filtration_antitone`.

## Results on the filtration (namespace `ParahoricBuildingData.CentralizerFiltration`)

- `moyPrasad_eq_closure`: `P_{x,r}` is the subgroup generated by `j(Z(F)_r)` and all root
  filtrations `U_{b,x,r}`, `b` a relative root. The proof unfolds `moyPrasad` and uses
  `KPApartmentData.sharpFiltration_eq_iSup`.
- `filtrationBlock_vadd_subset_moyPrasad`: the block `U_{a,x+w,R} U_{2a,x+w,R}` lies in
  `P_{x,D}` when `D ≤ R - a(w)` and `D ≤ R - 2a(w)`. The `2a`-factor is trivial when `2a` is
  not a root (`doubleFiltration_of_mem`, `doubleFiltration_of_not_mem`).
- `commutator_mem_of_opposite_coordinates` handles the bookkeeping for opposite roots. Let
  `u ∈ U_a(F)` and `v ∈ U_{-a}(F)`, with the factorization `u v = v₁ c u₁` where
  `v₁ ∈ U_{-a}(F)`, `c ∈ Z(F)` and `u₁ ∈ U_a(F)`, and with `c ∈ N`. Suppose that
  `u v u⁻¹ = n c' q` and `v⁻¹ u⁻¹ v = m c'' q'` are factorizations in
  `U_{-a}(F) Z(F) U_a(F)`, respectively `U_a(F) Z(F) U_{-a}(F)`, whose last factors `q, q'`
  lie in `N`. If moreover `v` normalizes `N`, then `⁅u, v⁆ ∈ N`. By the injectivity of
  `U_{-a}(F) × Z(F) × U_a(F) → G(F)` (`oppositeRootTripleProduct_injective`, module
  `MoyPrasadDoubleRefinement`), `u₁u⁻¹ = q` and `v⁻¹v₁ = q'⁻¹`. Then
  `⁅u, v⁆ = v (v⁻¹v₁) c (u₁u⁻¹) v⁻¹ = v (q'⁻¹ c q) v⁻¹ ∈ N`.
- `commutator_opposite_mem_moyPrasad` treats ordinary opposite pairs. For `r, s > 0`,
  `u ∈ U_{a,x,r}` and `v ∈ U_{-a,x,s}`, if `v` normalizes `P_{x,r+s}`, then
  `⁅u, v⁆ ∈ P_{x,r+s}`. `exists_rankOne_depth_factorization` (module `MoyPrasadRankOne`, which
  uses commutator friendliness) gives `u v = v₁ j(z) u₁` with `z ∈ Z(F)_{r+s}`. For the
  factorization of `u v u⁻¹`, choose `w` with `a(w) = -r`. At `x + w` the element `u` has depth
  `0` and `v` has depth `r + s`, so `conjugate_opposite_mem_root_centralizer_block` (module
  `MoyPrasadRootConjugation`) puts `u v u⁻¹` in
  `U_{-a}(F) Z(F) (U_{a,x+w,r+s} U_{2a,x+w,r+s})`. Read at `x`, this last block lies in
  `P_{x,r+s}`. For `v⁻¹ u⁻¹ v`, choose `w'` with `a(w') = s` and apply the same lemma to the
  root `-a`. The bookkeeping lemma finishes the proof.
- `commutator_double_opposite_mem_moyPrasad` treats mixed pairs. For `r, s > 0`, a root `a`
  with `2a` a root, `u ∈ U_{a,x,r}` and `v ∈ U_{-2a,x,s}`, if `v` normalizes `P_{x,r+s}`, then
  `⁅u, v⁆ ∈ P_{x,r+s}`. Axiom V 4 (`filtration_double_le_half`, module `MoyPrasadRootSeparation`)
  gives `v ∈ U_{-a,x,s/2}`. Then `exists_rankOne_depth_factorization` gives `u v = v₁ j(z) u₁`.
  The depth of `z` is improved by double-root friendliness. At `x + w` with `a(w) = -r`, the
  element `u` has depth `0` and `v ∈ U_{-2a,x+w,s+2r}`. Then
  `double_opposite_central_mem_of_doubleRootCommutatorFriendly` (module
  `MoyPrasadDoubleRootConjugation`) gives `z ∈ Z(F)_{s+2r} ⊆ Z(F)_{r+s}`. At the same point,
  `conjugate_double_opposite_mem_root_centralizer_block` (module `MoyPrasadMixedConjugation`)
  factors `u v u⁻¹` with last factor in the block of depth `s + 2r` at `x + w`, which lies in
  `P_{x,r+s}`. For `v⁻¹ u⁻¹ v`, choose `w'` with `a(w') = s/2` and apply
  `conjugate_opposite_mem_root_centralizer_block` to `-a` at depth `r + s/2`. The block it
  gives lies in `P_{x,r+s}` because `r + s/2 + s/2 = r + s` and `r + s/2 + s ≥ r + s`.
- `image_zero_le_normalizer_moyPrasad`: under `IsCommutatorFiltered`, `j(Z(F)_0)` normalizes
  `P_{x,t}`. For generators `j(w₀)` of `j(Z(F)_t)` it uses
  `j(z₀) j(w₀) j(z₀)⁻¹ = j(⁅z₀, w₀⁆) j(w₀)` and `⁅Z(F)_0, Z(F)_t⁆ ≤ Z(F)_t`. For root
  generators it uses `image_le_normalizer_filtration` (module `MoyPrasadBlockExchange`).
- `parahoricAt_le_normalizer_moyPrasad`: `P_x = j(Z(F)^0) ⊔ G(F)^♯_x` normalizes every
  `P_{x,t}`. It combines the previous item, via `image_zero`, with
  `sharpFixer_le_normalizer_moyPrasad_of_doubleRootCommutatorFriendly` (module
  `MoyPrasadDoubleRootConjugation`). That result uses `IsCommutatorFriendly`,
  `IsRootCompatible` and `IsDoubleRootCommutatorFriendly`.
- `generator_commutator_mem_moyPrasad`: for `r, s > 0`, the commutator of a generator of
  `P_{x,r}` with a generator of `P_{x,s}` lies in `P_{x,r+s}`. There are four cases.
  - Two central generators: `IsCommutatorFiltered`.
  - A central and a root generator, in either order: `IsRootCompatible` puts the commutator in
    the block of depth `r + s` (`block_subset_moyPrasad`, module `MoyPrasadRootConjugation`).
    The reversed order uses `⁅k, g⁆ = ⁅g, k⁆⁻¹`.
  - Two root generators `b, b'` with `b'` not a negative multiple of `b`: axiom V 3
    (`KPApartmentData.filtration_commutator_le`, module `ChamberPositiveCollection`) bounds the
    commutator by the subgroups `U_{pb+qb',x,pr+qs}` with `p, q ≥ 1`. Each of these lies in
    `U_{pb+qb',x,r+s} ≤ P_{x,r+s}`.
  - Two root generators with `b' = -t b` for some `t > 0`: then `-b'` is a root
    (`KPApartmentData.neg_mem_relativeRoots_of_rankOne`). Also `b' = -b`, `b' = -2b` or
    `b = -2b'` (`KPApartmentData.eq_or_double_of_eval_eq_smul`, module `ChamberExchange`,
    which uses the apartment axioms). These are the ordinary, the mixed and the reversed mixed
    cases above. The required normalization of `P_{x,r+s}` by `v` holds because
    `v ∈ U_{b',x,s} ≤ P_{x,s} ≤ P_x` (`moyPrasad_le_parahoricAt`), together with
    `parahoricAt_le_normalizer_moyPrasad`.
- `commutator_moyPrasad_le` is the main result: `⁅P_{x,r}, P_{x,s}⁆ ≤ P_{x,r+s}` for all
  `r, s ≥ 0`. If `r = 0`, then `P_{x,0} = P_x` (`moyPrasad_zero`) normalizes `P_{x,s}`, so
  `Subgroup.le_normalizer_iff_commutator_le_right` gives the claim. The case `s = 0` is
  symmetric. If `r, s > 0`, write both groups as generated subgroups (`moyPrasad_eq_closure`).
  Their generators lie in `P_x` (`moyPrasad_antitone`, `moyPrasad_zero`). Then apply
  `commutator_closure_le_of_le_normalizer` with `K = P_x`, `N = P_{x,r+s}` and
  `generator_commutator_mem_moyPrasad`.

## Where the double-root premise enters

`IsDoubleRootCommutatorFriendly` is used twice. It gives the central depth `Z(F)_{s+2r}` for
mixed pairs. Without it, commutator friendliness only gives `Z(F)_{r+s/2}` there. It also
enters `sharpFixer_le_normalizer_moyPrasad_of_doubleRootCommutatorFriendly`, the normality of
`P_{x,t}` under `G(F)^♯_x`.
