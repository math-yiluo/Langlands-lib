# Vertex rigidity inside the actual apartment

These supporting lemmas prove rigidity inside the base apartment of the
actual quotient. The field is arbitrary; the valuation need not come from
a local field. Connected reductivity and a maximal split torus are explicit
inputs to the root arguments.

The affine closure lemma uses the midpoint of two points. Every affine
functional has the same sign at the midpoint as at the first point if the
second lies in the formal facet closure. At a vertex the midpoint must
equal the vertex, and therefore the second point equals it too.

`exists_rootPoint_of_extendedAffineRoot` uses the strict difference between
the affine root group and its positive-depth subgroup. An element in that
difference is a nonidentity actual root element whose valuation equals the
extended affine root at every apartment point.

`neg_mem_extendedAffineRoots` chooses an opposite factor of this element.
Valuation axiom V5 makes its value the negative of the original value at
one apartment point; the normalizer's root reflection identifies its
character with the opposite root. The existing affine-functional jump
lemma produces an extended affine root with that derivative and value.
Equality of affine maps identifies it with the negative root. This proves
closure of the extended affine roots under negation.

`extendedAffineRoot_nonneg_of_fixed_by_sharpFixer` takes apartment points
`x, y` and assumes that every element of the actual sharp fixer of `x`
fixes `D.apartmentMap y`. A jump representative for a root nonnegative
at `x` lies in the depth-zero filtration at `x`, and hence in that sharp
fixer. The imported root-group/fixer intersection theorem puts it in the
depth-zero filtration at `y`. Its exact value then gives nonnegativity
at `y`.

`mem_facetClosure_of_fixed_by_sharpFixer` applies that argument to an
affine root and its negative. When the root is negative, zero or positive
at `x`, it is respectively nonpositive, zero or nonnegative at `y`.
These are exactly the alternatives in the formal sign-facet closure.
`eq_of_vertex_of_fixed_by_sharpFixer` applies the midpoint lemma, giving
`y = x` when the facet of `x` is the singleton `{x}`. The proof needs no
extra apartment axioms, local finiteness or topology.

`sharpFixer_le_characterValuationKernel` works for any supplied valuation
of the field in a linearly ordered commutative value group with zero.
Every root group lies in the character-valuation kernel, so the subgroup
generated by the root fixers lies there too. For integer-valued building
data, `sharpFixer_le_oneStabilizer` combines this inclusion with the
existing sharp-fixer inclusion into the full point stabilizer.
Consequently `eq_of_vertex_of_fixed_by_oneStabilizer` proves the same
apartment rigidity for the actual one-stabilizer.

`Langlands.Geometry.Building.ApartmentVertexRigidityStatement.{u}` is the
Prop-valued statement of this last result: for every field `k : Type u`,
affine group scheme `G`, integer-valued valuation `v`, supplied
`IntegerValuationBuildingData v G`, and apartment points `x, y`, if `x`
is a vertex and every element of its actual one-stabilizer fixes
`B.apartmentMap y`, then `y = x`. The theorem `apartmentVertexRigidity`
proves this statement by the preceding lemma, at arbitrary universe `u`.

The provenance is internal: all arguments derive from the imported
valuation, root-group, affine-root and quotient definitions. The result
concerns apartment points of the original quotient. It supplies no
common-apartment existence, global vertex fixed locus, algebraic
boundedness, bounded-subgroup fixed point or maximality theorem.
