# Doubling for the actual torus-restricted valuation

Work over any field `k : Type u`. Let `G` be a smooth affine actual group
scheme, let `S` and `T` be split tori, and let `i : T → G` have monomorphic
underlying map. Retain the existing upper valuation `hφ` and
`HasOppositeFactorPairs i`. The torus map `f : S → T` is arbitrary; its
monomorphy is not required.

For every nonzero lower character `α` and every real `r`, the exact
canonical filtration identity is

```
H(2 • α, 2 * r) = H(α, r) ∩ U_(2 • α)(k).
```

`H` is `torusRestrictedRootDepthSubgroup`: the subgroup of the original
`rationalPoints G` generated by the upper root filtrations at `m * r` for
actual upper roots restricting to `m • α`, with positive natural `m`.
The other factor is the actual root group of the composite `S → T → G`.
This equality requires no assertion that `α` or `2 • α` is an actual root,
and no sign restriction on `r`.

`torusRestrictedRootDepthDoublePointsEquiv` is the multiplicative
equivalence induced by this equality between the doubled-depth subgroup
and the intersection subgroup. Its value theorem says that the equivalence
preserves the underlying rational point of `G`.

When both `α` and `2 • α` are actual lower roots, the scalar theorem is
precisely the original valuation axiom V4:

```
φ_f(2 • α, g) = 2 • φ_f(α, g)    for g ∈ U_(2 • α)(k),
```

where `φ_f` is the already constructed
`torusRestrictedRootFunctionFamily hS hT hE hφ f`. The equality is in
`WithTop ℝ`, so it includes the identity point and its infinite values.

## Implemented proof

Choose a cocharacter `ν` pairing positively with `α`, using splitness and
`α ≠ 0`. The auxiliary additive upper depth associated to `(α,r)` is the
pairing against `ν ≫ f`, scaled by `r / ⟨α,ν⟩`. Pairing additivity shows
that the depth associated to `(2 • α,2 * r)` is the same additive function.
The auxiliary depth lemma only requires the pairing to be nonzero.

Let `A` be the character-restriction preimage of the positive cyclic tail
of `α`, and let `B` be that of `2 • α`. Then `B ≤ A` and `0 ∉ A`.
The cocharacter `ν ≫ f` is positive on every actual root selected by `A`.
Rewrite both canonical filtered groups using these selected semigroups and
the same additive depth. The exact selected-depth intersection theorem
gives `H_A ∩ U_B(k) = H_B`. The intrinsic restricted root-functor comparison
identifies `U_B` with the actual lower doubled root functor. This proves
the full equality, and the subgroup equality induces the point equivalence.

For the scalar theorem, the arbitrary-base actual doubled-root inclusion
puts `g` in the original lower root group as well. The exact finite level-set
comparison and the subgroup identity now give, for every real `r`,

```
2 * r ≤ φ_f(2 • α, g)  ↔  r ≤ φ_f(α, g).
```

At `g = 1`, both values are top. Otherwise the already proved exact-top
criterion makes both values finite. Write them as real numbers `s` and `t`.
Evaluating the equivalence at `t` and at `s / 2` gives `2 * t ≤ s` and
`s / 2 ≤ t`, hence `s = 2 * t`. This proves the required `WithTop` equality.
No discrete value group or characteristic restriction is used.
