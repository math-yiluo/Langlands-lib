# Full valuation transfer under an actual central isogeny

This derived module proves that the normalized central-isogeny pullback preserves
the complete predicate `IsRootDatumValuation`, including V3. It uses a supplied
commuting square of actual group schemes over an arbitrary field `k : Type u`:
affine, locally finite type ambient groups `C` and `G`, a central isogeny
`q : C ⟶ G`, split tori `S` and `T`, a torus isogeny `t : S ⟶ T`, and
monomorphic embeddings `i : S.toGrp ⟶ C` and `j : T.toGrp ⟶ G` satisfying
`i ≫ q = groupHom t ≫ j`.

The V3 lemma itself does not require the source embedding to be monomorphic;
the complete valuation predicate requires that instance for its reflection
clause. No reductivity or maximality premise is added to the supplied square.

## The commutator axiom

`IsRootDatumValuation.centralIsogenyPullback_commutator` takes target roots
`a` and `b`, two real levels, and the V3 exclusion of opposite positive real
rays for the restricted source characters. It proves the V3 commutator
inclusion for those source characters and levels.

First, a linear map on the actual integral character lattices, followed by
base change to the reals, sends any opposite-ray relation for the target
characters to one for their restrictions. Thus the source ray exclusion
implies the target ray exclusion. This step needs only linearity, not
injectivity of the real restriction map.

The source characters are roots by the established root-membership comparison,
so each is nonzero. `TwoCharacterPositiveCocharacter` supplies one actual
integral cocharacter pairing positively with both. The actual source root
subgroups, and those for every positive integral combination appearing in V3,
lie in its contracting unipotent subgroup by `subgroup_le_dynamicUnipotent`.
Their filtration sets, generated subgroups and commutator subgroup therefore
lie there as well.

The private generator-image lemma identifies the image of the union of source
filtration sets in V3 with the corresponding target union. It uses exact root
membership and filtration-image comparisons, together with additivity of
character restriction. Mapping subgroup closures and commutators now reduces
the required image inclusion to the target valuation's V3 axiom.

Finally, every element of the source commutator has the same image as an
element of the source subgroup generated by the positive-combination
filtrations. Both elements lie in the common contracting unipotent subgroup.
`Dynamic.unipotentPointsMap_injective`, applied to the central kernel of `q`,
identifies them and proves the original source inclusion. No injectivity on
ambient rational points is assumed.

## Complete transfer and the bundled map

`IsRootDatumValuation.centralIsogenyPullback_isRootDatumValuation` proves every
field of the existing source valuation predicate. The root-support equivalence
lifts each source root to a target root. Normalization comes from the
normalized pullback construction; the V0, V1, V2, V4 and V5 clauses come from
`CentralIsogenyValuation`; and V3 comes from the preceding argument.

`centralIsogenyValuationPullback` sends the subtype of actual target root
function families satisfying `IsRootDatumValuation j` to the corresponding
source subtype satisfying `IsRootDatumValuation i`. Its underlying family is
the previously defined normalized pullback, as the definitional evaluation
lemma `centralIsogenyValuationPullback_val` records.

The provenance is a direct derivation from the existing valuation predicate,
actual root and contracting subgroup constructions, the established
central-isogeny comparisons and the integral two-character positivity lemma.
No separate literature assertion is introduced. This module constructs neither
the cover tori nor apartment data, proves no source apartment axioms, and does
not claim `SimplyConnectedNormalizerAffineWeylStatement`.
