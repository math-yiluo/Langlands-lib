# Simply connected normalizer facet stabilizers: proof

Lean module: `Langlands.Geometry.Building.SimplyConnectedFacetFixingProof`,
namespace `Langlands.Geometry.Building`.

## Statement

```
theorem Langlands.Geometry.Building.simplyConnectedFacetFixing :
    SimplyConnectedFacetFixingStatement.{u}
```

The type is exactly the published proposition
`Langlands.Geometry.Building.SimplyConnectedFacetFixingStatement.{u}` of the
module `Langlands.Geometry.Building.SimplyConnectedFacetFixingStatement`, at an
arbitrary universe `u`, with no further hypothesis. Unfolded, it reads:

```
∀ (F : Type u) [Field F] [ValuativeRel F] [TopologicalSpace F]
  [IsNonarchimedeanLocalField F]
  (G : GroupScheme (Spec (CommRingCat.of F))) [IsAffineHom G.X.hom]
  (B : ValuationBuildingData G),
  IsSimplyConnected G →
  ∀ (Fa : Set B.Apartment),
    AffineRootSystem.IsFacet B.affineRoots Fa →
    ∀ (n : normalizerPoints B.i),
      (fun x : B.Apartment => n • x) '' Fa = Fa →
      ∀ x ∈ Fa, n • x = x
```

In words: for every nonarchimedean local field `F`, every affine group `G`
over `F` with valuation building data `B`, if `G` is simply connected, then
every rational point `n` of the normalizer of the maximal split torus that
preserves a facet `Fa` of the apartment as a set fixes every point of `Fa`.

## Proof

The Lean proof is the single application

```
simplyConnectedFacetFixing_of_rankOneCentralizerGeneration
  simplyConnectedRankOneCentralizerGeneration
```

of the theorem `simplyConnectedFacetFixing_of_rankOneCentralizerGeneration`
(module `Geometry.Building.SimplyConnectedFacetFixingReduction`), which derives
the statement from `SimplyConnectedRankOneCentralizerGenerationStatement.{u}`.
That hypothesis is discharged by `simplyConnectedRankOneCentralizerGeneration`
(module `GroupScheme.SimplyConnected.RankOneCentralizerGenerationProof`),
proved in the Library without hypotheses: for simply connected `G` over a
nonarchimedean local field, `Z(F)` lies in the subgroup generated by the groups
`Z(F) ∩ ⟨U_a(F), U_{-a}(F)⟩` and the norm-one subgroup `Z(F)^1`.

Inside the reduction, rank-one generation and relative-root rank-one
factorization give the equality of the reflection and centralizer translation
lattices (`simplyConnectedReflectionTranslation_of_rankOneGeneration`), and
`simplyConnectedFacetFixingReduction` turns that equality, with the opposite
factor pairs and the surjectivity of the reflection map onto the relative Weyl
group, into pointwise fixing; the details are on the page of
`Geometry.Building.SimplyConnectedFacetFixingReduction`. The statement is not
modified and no hypothesis is added.

## Literature

T. Kaletha and G. Prasad, *Bruhat–Tits Theory: A New Approach* (2023),
Chapter 9, §9.3, paragraph 9.3.26, printed p. 344: for semisimple simply
connected `G`, `G(k)^0 = G(k)`, so the stabilizer in `G(k)` of a facet fixes
the facet pointwise. The Lean statement is the restriction of this conclusion
to the normalizer of the maximal split torus acting on the apartment of the
supplied valuation data; the comparison of that apartment with the building of
the book is described on the statement's page.
