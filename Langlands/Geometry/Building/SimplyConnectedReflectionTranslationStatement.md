# Simply connected realization of actual centralizer translations

`Langlands.Geometry.Building.SimplyConnectedReflectionTranslationStatement.{u}`
is a proposition. For each nonarchimedean local field `F : Type u`, affine
group scheme `G` and supplied `B : ValuationBuildingData G`, it asserts
`B.reflectionTranslationLattice = B.centralizerTranslationLattice` whenever
`IsSimplyConnected G`. The latter predicate includes semisimplicity.

Both subgroups are the actual additive images defined in
`ReflectionTranslationLattice`. The centralizer subgroup is the image of
the represented centralizer's translation homomorphism in the reduced
translation space. The reflection subgroup is the image of those actual
centralizer points whose normalizer images belong to `B.reflectionNormalizer`,
the subgroup generated by actual opposite-pair reflection representatives.
Their definitions assert no freeness or discreteness property.

The existing unconditional containment of the reflection image in the
centralizer image makes the asserted equality equivalent to the following
realization requirement: for every actual centralizer point `z`, there is
an actual centralizer point `w` whose normalizer image belongs to
`B.reflectionNormalizer` and whose reduced translation equals that of `z`.
The equality concerns integral images of actual points. A rational span
comparison or a finite-index comparison alone would not establish it.

The quantified data have the same field, group and valuation-data scope
as `SimplyConnectedFacetFixingStatement`. In particular, the full supplied
omega-compatible valuation class and its actual normalizer action are used.
There is no splitness, relative-root-system, opposite-pair-existence,
apartment-axiom or source-comparison premise in this proposition.

Its provenance is internal. The proved
`ValuationBuildingData.reflections_sup_ker_eq_top_iff_translationLattice_eq`
identifies this equality as precisely the remaining centralizer condition
for full normalizer generation modulo the apartment-action kernel, once
finite relative-Weyl surjectivity is established. The proved
`ValuationBuildingData.normalizer_facet_fixing_of_translationLattice_eq`
then supplies facet fixing when actual opposite pairs and that
surjectivity are also available. This gives a focused structural proof
obligation for the direct route to the existing facet-fixing target.

This file supplies the statement for a separate proof. Opposite-pair
existence and finite relative-Weyl generation remain separate inputs to
that direct route. Neither this equality nor
`SimplyConnectedFacetFixingStatement` is proved here.
