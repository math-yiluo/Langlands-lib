# Depth-zero intersections of `G(K)_{x,0}` over the maximal unramified field

This module states
`Langlands.Geometry.Building.MaximalUnramified.LocalMoyPrasadDepthZeroStatement`,
at arbitrary universe `u`. It asserts two intersection properties of the
actual depth-zero group `G(K)_{x,0} = B.moyPrasad hZ x 0`:

- (a) the full-group form of Kaletha–Prasad (KP) Proposition 7.3.12(1)–(3) for
  the concave function `f = 0`;
- (b) the inclusion `M(K) ∩ G(K)_{x,0} ⊆ M(K)_{π(x),0}` of KP Lemma 8.5.19 at
  `f = 0`, for the Levi subgroup `M_ν`.

This is a statement only. No proof of it is supplied here, and nothing in this
file claims that it has been proved.

## Data, with no further premise

Let `F : Type u` have `Field F`, `ValuativeRel F`, `TopologicalSpace F` and
`IsNonarchimedeanLocalField F`. Put `K = UnramifiedClosure F`. Let `H` be a group
scheme over `Spec K` with `[IsAffineHom H.X.hom]`, let
`B : MaximalUnramified.BuildingData F H`, and let
`hZ : IsTorus B.centralizer.Z`.

These are exactly the data of the published
`LocalMoyPrasadGroupPropertiesStatement` (S2). The proposition quantifies over
them and adds no hypothesis. In particular it assumes neither S2, nor the
torus-filtration statement S1, nor a product cover, nor apartment or building
axioms. The data `B` supply a connected reductive group over `K`, a maximal
split torus `B.S` with inclusion `B.i`, a class of valuations of the actual
root datum, the actual centralizer `Z = B.centralizer.Z` with closed embedding
`B.centralizer.j`, and compatibility with the integer-valued field valuation.
The hypothesis `hZ` says that `Z` is a torus, which is the quasi-split case.

## The two clauses

The proposition is the conjunction of the following two clauses.

(a) For every apartment point `x : B.Apartment` and every integral cocharacter
`mu : cocharacterLattice B.S` with `IsGenericCocharacter B.i mu`:

```lean
B.rootGroupSpan (positiveRelativeRoots B.i mu) ⊓ B.moyPrasad hZ x 0 =
  B.rootFiltrationSpan x (positiveRelativeRoots B.i mu) 0
```

(b) For every apartment point `x : B.Apartment` and every `ν : V B.S`:

```lean
B.pairingLeviSpan ν ⊓ B.moyPrasad hZ x 0 ≤
  B.centralizerTorusImage hZ 0 ⊔ B.rootFiltrationSpan x (B.zeroPairingRoots ν) 0
```

The `0` in `moyPrasad` and `centralizerTorusImage` is `(0 : ℝ≥0)`. The `0` in
`rootFiltrationSpan` is `(0 : ℝ)`. This is definitionally the coercion
`↑(0 : ℝ≥0)` that S2 uses at `r = 0`. Both clauses are displayed exactly as in
the task objective. Clause (b) is kept as an inclusion; it is not strengthened
to an equality.

## The imported definitions

All definitions are used unchanged:

| Expression | Published meaning |
| --- | --- |
| `B.rootGroup b` | The actual root group `U_b(K) = rootGroupPoints B.i b` |
| `B.filtration x b r` | The root filtration subgroup `U_{b,x,r}` of the valuation `x` |
| `B.rootGroupSpan Ψ` | `⨆ b ∈ Ψ, B.rootGroup b`, the subgroup `U_Ψ` generated by these root groups |
| `B.rootFiltrationSpan x Ψ r` | `⨆ b ∈ Ψ, B.filtration x b r`, the generated subgroup |
| `B.zeroPairingRoots ν` | The relative roots `b` with `eval B.S b ν = 0`, written `Φ₀(ν)` |
| `B.pairingLeviSpan ν` | `M_ν(K)`: the subgroup generated by `j(Z(K))` and `U_b(K)`, `b ∈ Φ₀(ν)` |
| `B.centralizerTorusFiltration hZ r` | `Z(K)_r`, the published `localTorusFiltration` of the torus `Z` |
| `B.centralizerTorusImage hZ r` | Its image `j(Z(K)_r)` under `rationalPoints.map B.centralizer.j` |
| `B.moyPrasad hZ x r` | `G(K)_{x,r}`, generated by `j(Z(K)_r)` and `U_{b,x,r}` for all relative roots `b` |
| `positiveRelativeRoots B.i mu` | The relative roots `b` with `0 < latticePairing B.S b mu` |
| `IsGenericCocharacter B.i mu` | Every relative root pairs nontrivially with `mu` |

The definitions `rootGroupSpan`, `rootFiltrationSpan`, `zeroPairingRoots` and
`pairingLeviSpan` are in `KPLocalMoyPrasadGroupProperties`. The definitions
`moyPrasad`, `centralizerTorusImage` and `centralizerTorusFiltration` are in
`KPLocalMoyPrasadGroups`. The description of `moyPrasad` in the table is the
published equality `BuildingData.moyPrasad_eq_sup_iSup`. The definition is
`B.centralizerTorusImage hZ r ⊔ B.apartment.sharpFiltration x (fun _ => r)`.
The second term is `G(K)♯_{x,r}` of KP Definition 7.3.3(1),(2), and it includes
the divisible relative roots. The root definitions are in
`Langlands.GroupScheme.Rational.StandardParabolic` and
`Langlands.GroupScheme.Rational.RelativeRoots`.

For a generic `mu`, `positiveRelativeRoots B.i mu` is the positive system
`Φ⁺` of relative roots determined by `mu`. Divisible roots `2a` with
`a ∈ Φ⁺` are included.

## Comparison with KP: clause (a)

KP Proposition 7.3.12 (printed p. 250 / PDF p. 281) fixes a concave function
`f`, a point `x` and a positive system `Φ⁺`. It sets
`U^±_{x,f} = U^±(k) ∩ G(k)♯_{x,f}` and asserts:

- (1) `G(k)♯_{x,f} = U⁻_{x,f} · U⁺_{x,f} · N♯_{x,f}`;
- (2) `N♯_{x,f}` is generated by the groups `N^{(a)}_{x,f}`;
- (3) the product of the groups `U_{a,x,f}` over `a ∈ Φ^{±,nd}`, in any fixed
  order, is a bijection onto `U^±_{x,f}`.

Here `U_{a,x,f} = U_{a,x,f(a)} · U_{2a,x,f(2a)}` (Definition 7.3.3(1), printed
p. 247 / PDF p. 278). At `f = 0`, (3) says that `U⁺(k) ∩ G(k)♯_{x,0}` is the
product of the blocks `U_{a,x,0} U_{2a,x,0}` for indivisible `a ∈ Φ⁺`. That
product is a group by Lemma 7.3.11, so it is the subgroup generated by all
`U_{b,x,0}`, `b ∈ Φ⁺`, divisible roots included. This generated subgroup is
`B.rootFiltrationSpan x (positiveRelativeRoots B.i mu) 0`. The left factor
`B.rootGroupSpan (positiveRelativeRoots B.i mu)` is the subgroup generated by
the root groups of `Φ⁺`. In KP's setting this is `U⁺(K)`, the rational points
of the unipotent radical of the Borel subgroup determined by `Φ⁺`. The Lean
statement uses the generated subgroup and does not depend on this
identification. Clause (a) asserts no ordered coordinate bijection.

KP states (1)–(3) for the sharp group `G(k)♯_{x,f}`. Clause (a) concerns the
full group `G(K)_{x,0} = G(K)♯_{x,0} · Z(K)_0` of Definition 7.3.3(3), whose
torus part is `Z(K)_0 = B.centralizerTorusFiltration hZ 0`. This is the
derived part of the statement. The following explains where it comes from; it
is not a proof.

- `Z(K)_0` normalizes every `U_{b,x,0}`. It lies in the character-valuation
  kernel (`centralizerTorusFiltration_le_characterValuationKernel`). By the
  compatibility built into `B`, it therefore acts on the apartment with zero
  translation, and Axiom V 6 gives the normalization.
- KP's proof of 7.3.12 (printed pp. 250–251 / PDF pp. 281–282) writes
  `G(k)♯_{x,f}` as `X⁻ · X⁺ · N′`, and also as `X⁺ · X⁻ · N′`, where `N′` is
  generated by the groups `N^{(a)}_{x,f}`. It then uses the Bruhat
  decomposition (PDF p. 282, citing [Bor91]) to show that an element of this
  set lying in `U⁻(k)` comes from `X⁻`, and in the same way that an element
  lying in `U⁺(k)` comes from `X⁺`. The same argument works with `N′`
  replaced by `Z(K)_0 · N′ ⊆ N(K)`. This gives
  `U⁺(K) ∩ G(K)_{x,0} = X⁺`.

## Comparison with KP: clause (b)

KP Lemma 8.5.19 (printed p. 319 / PDF p. 350) takes a Levi subgroup `M ⊆ G`, a
maximal split torus `S ⊆ M`, and a valuation `x` of the root datum for `S` and
`G`. With `π(x)` the restricted valuation for `S` and `M` (§6.7), it asserts
`M(K)_{π(x),f} = M(K) ∩ G(K)_{x,f}` for every concave `f`. Clause (b) is the
inclusion `⊇` of that equality for `f = 0` and `M = M_ν`.

- **The Levi subgroup.** The roots `b` with `⟨b, ν⟩ = 0` for real `ν` are those
  of a rational `ν′` with the same sign pattern on the finitely many relative
  roots. Hence `M_ν` is the Levi subgroup with relative roots `Φ₀(ν)`. It is
  the centralizer of the identity component of `⋂_{b ∈ Φ₀(ν)} ker b ⊆ S`, and
  it contains `S` and `Z`. By the Bruhat decomposition of `M_ν(K)`, this group
  is generated by `Z(K)` and the root groups `U_b(K)`, `b ∈ Φ₀(ν)`. The
  Library's `pairingLeviSpan ν` is this generated subgroup by definition. The
  Lean statement does not depend on the identification.
- **The right side.** KP's `M(K)_{π(x),0}` is generated by `T(K)_0` and the
  groups `U_{b,π(x),0}`, `b ∈ Φ(S, M)`. Here `T` is the centralizer of `S` in
  `M`, which is again `Z`. The restriction `π(x)` of §6.7 (printed p. 233 /
  PDF p. 264) forgets the functions `φ_b` for `b ∉ Φ(M, S)` and keeps the
  others, so `U_{b,π(x),0} = U_{b,x,0}`. The right side
  `B.centralizerTorusImage hZ 0 ⊔ B.rootFiltrationSpan x (B.zeroPairingRoots ν) 0`
  is therefore `M_ν(K)_{π(x),0}`, subject to the D1 caveat below.
- **The reverse inclusion.** `≥` holds by the definitions, since every
  generator on the right lies in both `M_ν(K)` and `G(K)_{x,0}`. It is
  deliberately not part of the proposition.
- **KP's proof** (printed pp. 319–320 / PDF pp. 350–351) uses the integral
  model `G_{x,f}` of §8.5. It takes the fixed-point scheme of `A_M` acting on
  it, which is smooth by Proposition 2.11.5. It uses Lemma 7.3.16 for the torus
  part, Proposition 7.3.12 for the root groups, and Proposition 8.2.8 for
  generation. None of these is available in the Library for the K-level groups.
  The proof successor must supply its own route.

If `Φ₀(ν) = ∅`, then `pairingLeviSpan ν = j(Z(K)) ⊔ ⊥`. In that case clause (b)
says `j(Z(K)) ∩ G(K)_{x,0} ⊆ j(Z(K)_0)`, which is the nontrivial inclusion of
KP Lemma 7.3.16 (printed p. 252 / PDF p. 283) at `f(0) = 0`. KP proves that case
by reduction to a simply connected semisimple group, using boundedness
(Corollary 7.3.14, PDF p. 282) and Lemma 2.6.27 (printed p. 105 / PDF p. 136).

## Why depth zero needs its own statement

At positive depth `r`, `G(K)_{x,r}` is the three-factor product
`U⁻_{x,r} · Z(K)_r · U⁺_{x,r}`. This is KP Proposition 7.3.12(4),(5), and its
Library form is the separate positive-depth product statement
`LocalMoyPrasadPositiveProductStatement`, which assumes `0 < r`. Part (4)
requires `f(0) > 0`. At depth zero the product description fails.

Take `SL₂` over `K` with its diagonal torus, root `a`, root groups
`x_a(t) = [[1, t], [0, 1]]` and `x_{-a}(t) = [[1, 0], [t, 1]]`, and the
standard point `x` with `U_{±a,x,0} = x_{±a}(O)`. Then

```text
w = x_a(1) · x_{-a}(-1) · x_a(1) = [[0, 1], [-1, 0]] ∈ SL₂(O) = G(K)_{x,0}.
```

A product `[[1, 0], [c, 1]] · diag(t, t⁻¹) · [[1, b], [0, 1]]` has top-left
entry `t ≠ 0`. The top-left entry of `w` is `0`. So `w` does not lie in
`U⁻(K) · T(K) · U⁺(K)`, let alone in `U⁻_{x,0} · T(K)_0 · U⁺_{x,0}`. In KP's
terms, `N♯_{x,0}` is strictly larger than `Z♯_{x,0}`.

So clauses (a) and (b) are not consequences of the positive-depth product
cover. Their source is the Bruhat-decomposition argument of Proposition 7.3.12
and the integral-model argument of Lemma 8.5.19.

## Scope: maximal unramified, quasi-split, no apartment-axiom premise

The authors' corrections, PDF p. 33, make AS 5 an additional Chapter 7
hypothesis beside AS 1–AS 4, which §6.3 proves. They state that AS 5 is known
when `G` is quasi-split, by Propositions 6.3.13 and 6.6.2. Here `hZ` makes `Z` a
torus, which is the quasi-split case. The corrections, PDF p. 37, replace the
first sentence of §8.3. That section and the following ones, including §8.5
(printed p. 310 / PDF p. 341), work over the maximal unramified extension `K`
of a field with perfect residue field, and there `G_K` is quasi-split by
Corollary 2.3.8. The residue field of the nonarchimedean local field `F` is
finite, hence perfect, and `K = F^ur` is the field of the data.

Hence the theory behind both clauses applies to the data `F`, `H`, `B`, `hZ` as
they stand. The geometric facts the source proofs use are consequences to be
established from these data. They are not premises of the target. This file
does not infer AS 5 from the root-valuation axioms. The proof successor must
justify every geometric consequence its route uses. The field `K` has infinite
residue field and is not treated as a nonarchimedean local field. Only `F`
carries that instance.

**D1 caveat on the zero term.** By `centralizerTorusFiltration_zero`, the zero
term `Z(K)_0` is `torusNormIwahori` for every finite Galois splitting field.
The Library takes this group as `T(K)^0` by definition.
`KPLocalMoyPrasadGroups.md` ("Property (1)") records that no Library result
identifies it with KP's `T(K)^0`, which KP defines through maximal bounded
subgroups. KP §8.5.1 (PDF p. 341) assumes an admissible, schematic, connected
and congruent filtration of `T(K)`. For general tori it uses the minimal
congruent filtration of Definition B.10.8. `KPLocalMoyPrasadGroups.md` notes
that the Library filtration is not defined as that filtration. The two agree at
`r = 0`, subject to the same caveat, and only `r = 0` occurs here. So clause (b) is KP's Lemma 8.5.19 at `f = 0` exactly to the
extent that the Library's `Z(K)_0` is KP's `T(K)^0`. S2 inherits the same
identification.

The corrections contain no change to Proposition 7.3.12(1)–(3), Lemma 7.3.16
or Lemma 8.5.19. The added Proposition 7.3.12(6) (PDF p. 33) concerns
`f(0) > 0` only and is not used here.

## Relation to S2

Both clauses are specializations of S2 at `r = 0`. Clause (a) is clause 4 of
S2 with `Ψ = positiveRelativeRoots B.i mu`: this set is closed and lies in the
open half-space of `mu`. Clause (b) is the `≤` half of clause 6. The
proposition is therefore no stronger than S2. It is the depth-zero
prerequisite for the `r = 0` cases of clauses 4, 6 and 7 of S2. It is not a
restatement of S2's eight clauses.
