# Collection data for the canonical torus restriction

Work over a field `k : Type u`. The ambient actual group scheme `G` is affine
and smooth, `S` and `T` are split tori, and the upper torus map `i : T → G`
is monomorphic. Retain the given upper root-datum valuation and actual
`HasOppositeFactorPairs i`. The morphism `f : S → T` is arbitrary; no
monomorphism of `f` or of the lower composite is assumed.

`torusRestrictedRootDepthCollectionData` constructs `RootDepthCollectionData`
for the existing scalar family `torusRestrictedRootFunctionFamily` and the
actual composite `S → T → G`. On each actual lower root `a`, its subgroup
at real depth `r` is exactly `torusRestrictedRootDepthSubgroup hφ f a r`.
This is the subgroup generated by the upper root filtrations at `m * r` for
positive integral restriction multipliers `m`. At a character outside the
actual root set, use the whole corresponding root group. The scalar family
is top there, so this also has precisely the literal `rootFiltration` carrier.
The two accompanying subgroup equalities record these cases.

The exact finite-level comparison proves carrier equality on actual roots.
The already established canonical subgroup commutator bound gives the V3
field of the collection data; every mixed output is retained at its actual
root and original depth. For the arbitrary-real-depth doubled inclusion,
first use antitonicity to replace `s ≥ 2 * r` by `2 * r`. The proved exact
identity `H(2a,2r) = H(a,r) ∩ U_(2a)(k)` then supplies the inclusion into
`H(a,r)`. No positivity of the real depths, discrete value group or
characteristic assumption is used.

This is internal content combining the existing actual torus restriction,
commutator, doubled-intersection and depth-collection interfaces. It adds no
new assertion attributed to original literature. In particular the supplied
upper valuation remains a premise. The result makes the generic collection
and field-descent lemmas applicable to the canonical restricted family before
a full lower valuation is available; it does not prove reflection V2,
opposite-root V5, compatible initial apartment existence, the building
geometry or the supplied-model building comparison.
