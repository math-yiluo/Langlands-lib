# Axiom 4.1.8 (2) and (3) for the building of a valuation of the root datum: proof

Lean module: `Langlands.Geometry.Building.RootGroupActionAxiomProof`,
namespace `Langlands.Geometry.Building`.

## Statement

```
theorem Langlands.Geometry.Building.rootGroupActionAxiom :
    RootGroupActionAxiomStatement.{u}
```

The type is exactly the published proposition
`Langlands.Geometry.Building.RootGroupActionAxiomStatement.{u}` of the module
`Langlands.Geometry.Building.RootGroupActionAxiomStatement`, at an arbitrary
universe `u`, with no further hypothesis. Unfolded, it reads:

```
∀ (F : Type u) [Field F] [ValuativeRel F] [TopologicalSpace F]
  [IsNonarchimedeanLocalField F]
  (G : GroupScheme (Spec (CommRingCat.of F))) [IsAffineHom G.X.hom]
  (P : ParahoricBuildingData G),
  P.SatisfiesApartmentAxioms →
    P.HasZeroFixerGenerators ∧ P.HasRootZeroFixers
```

with, from the module `Langlands.Geometry.Building.ParahoricBuildingAxioms`,

```
P.HasZeroFixerGenerators =
  ∀ Ω : Set P.Apartment, Ω.Nonempty → P.IsBoundedSubset Ω →
    P.zeroFixer Ω = P.nonnegativeRootSubgroup Ω

P.HasRootZeroFixers =
  ∀ Ω : Set P.Apartment, Ω.Nonempty → P.IsBoundedSubset Ω →
    ∀ α : relativeRoots P.i, P.rootGroup α ⊓ P.zeroFixer Ω = P.rootFixer α Ω
```

In words: for parahoric building data `P` of a group over a nonarchimedean
local field satisfying V 7 and AS 2–AS 5, and every non-empty bounded subset
`Ω` of the apartment, (2) the elements `G(F)^0_Ω` of `G(F)^0` fixing the image
of `Ω` in the building pointwise form the subgroup generated by `Z(F)^0` and
the groups `U_ψ` with `ψ ∈ Ψ` non-negative on `Ω`; and (3) for every relative
root `a`, `U_a(F) ∩ G(F)^0_Ω = U_{a,Ω,0}`.

## Proof

The Lean proof is the term

```
fun _ _ _ _ _ _ _ P hP => ⟨P.hasZeroFixerGenerators_of_hasNormalizerParahoricFixers hP
  (P.hasNormalizerParahoricFixers_of_mem_affineWeylGroup hP fun n hn =>
    P.normalizerAffineEquiv_mem_affineWeylGroup hP simplyConnectedNormalizerAffineWeyl
      ⟨n, Subgroup.mem_subgroupOf.2 hn⟩), P.hasRootZeroFixers hP⟩
```

1. **Part (3).** `ParahoricBuildingData.hasRootZeroFixers` (module
   `Geometry.Building.RootGroupZeroFixer`) proves `P.HasRootZeroFixers` from
   the apartment axioms.
2. **Part (2).** `ParahoricBuildingData.hasZeroFixerGenerators_of_hasNormalizerParahoricFixers`
   (module `Geometry.Building.ZeroFixerNormalizerReduction`) proves
   `P.HasZeroFixerGenerators` from the apartment axioms and
   `P.HasNormalizerParahoricFixers`: every element of `N(F) ∩ G(F)^0` fixing a
   finite non-empty `Ω` pointwise lies in the parahoric `P_Ω`. In the same
   module, `ParahoricBuildingData.hasNormalizerParahoricFixers_of_mem_affineWeylGroup`
   gives this from the condition that every `n ∈ N(F)` with `n ∈ G(F)^0` acts
   on the apartment through the affine Weyl group `W(Ψ)`.
3. **The action of `N(F) ∩ G(F)^0`.** For `n ∈ N(F)` and `hn : n ∈ G(F)^0`,
   `Subgroup.mem_subgroupOf.2 hn` makes `n` an element of
   `P.normalizerZeroComponent = P.zeroSubgroup.subgroupOf (normalizerPoints P.i)`.
   `ParahoricBuildingData.normalizerAffineEquiv_mem_affineWeylGroup` (module
   `Geometry.Building.IwahoriWeylExactSequenceReduction`) then places its
   apartment action in `W(Ψ)`, given the apartment axioms and
   `SimplyConnectedNormalizerAffineWeylStatement`: it writes `n = c · y` with
   `c ∈ G(F)^♮` and `y ∈ Z(F)^0`, and `y` acts trivially. That statement is
   discharged by `simplyConnectedNormalizerAffineWeyl` (module
   `Geometry.Building.SimplyConnectedNormalizerAffineWeylProof`), proved
   without hypotheses.

The group structure on `rationalPoints G` used by `Subgroup.mem_subgroupOf`
is scoped in `CategoryTheory.MonObj`, which the module opens. The statement is
not modified and no hypothesis is added.
