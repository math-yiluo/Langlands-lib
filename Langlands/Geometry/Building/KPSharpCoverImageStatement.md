# Actual root groups and sharp fixers in the simply connected image

This module isolates the algebraic input to the simply connected reduction in
KP Lemma 7.3.16. It states that the actual relative root groups lift on rational
points through the supplied simply connected derived cover and proves the
elementary passage from that statement to all sharp fixers.

The field `F : Type u` is any nonarchimedean local field of either
characteristic, at arbitrary universe `u`. The root target uses every supplied
`E : ZeroSubgroupDatum i j`; its maximal split torus, centralizer, derived
subgroup and simply connected cover are the existing actual data. The sharp
target uses every actual `P : ParahoricBuildingData G`, with the existing
affineness instance required for that type.
The root target obtains the ambient affineness instance from the connected
reductivity recorded in `E.isSimplyConnectedDerivedCover`.

## Exact targets and scope

`E.RootGroupLeSimplyConnectedImageStatement` states

```text
∀ a ∈ relativeRoots i, rootGroupPoints i a ≤ E.simplyConnectedImage.
```

Here the left side is the existing rational-point subgroup of
`RelativeRoot.subgroup i a`. The right side is the range of the actual map
`rationalPoints.map (E.π ≫ E.d)`, from the supplied simply connected group
through the actual derived subgroup into `G`. No substitute cover or abstract
homomorphism is introduced. The substantive lifting statement is unproved.

`P.SharpFixerLeSimplyConnectedImageStatement` states

```text
∀ Ω : Set P.Apartment, P.sharpFixer Ω ≤ P.simplyConnectedImage.
```

It has no apartment-axiom or nonemptiness premise. Its content is algebraic:
the sharp subgroup is generated by subgroups of the actual relative root
groups. In particular, for the empty subset it is generated by all of those
root groups. This containment does not imply the final centralizer-parahoric
intersection without further input.

The root and sharp targets are equivalent on `P.zeroDatum`, as proved in the
module. The targets themselves remain unproved. They are not new fields of
the building data or new premises in the final KP Lemma 7.4.3 statement.

## Sources and provenance

The original source is Kaletha–Prasad, *Bruhat–Tits theory: a new approach*
(2023), registered as `kaletha-prasad-2023-bruhat-tits-new-approach`.
The original proof of Lemma 7.3.16, printed page 252 / PDF page 283, was read
directly. In its case `f(0) = 0`, the source uses containment of the sharp
subgroup in the simply connected image before reducing to a semisimple
simply connected group. Definition 2.6.20, printed page 104 / PDF page 135,
defines that image. Definition 7.4.1(1)–(2), printed page 255 / PDF page 286,
defines the root fixers and the sharp subgroup generated by them.

The root-group target is a derived formulation of the algebraic input behind
that containment, rather than a separately numbered assertion attributed to
the book. Its proof must supply actual rational lifts through the given cover;
formal manipulation of the generated subgroup does not supply those lifts.
The module's all-subset formulation follows exactly from root-group containment
and the published sharp-fixer definition.

The 1 November 2024 corrections, registered as
`kaletha-prasad-2024-corrections`, PDF page 25, insert the Henselian and
perfect-residue-field assumptions before Definition 2.6.20, satisfied for the
local fields used here. PDF page 33 adds AS 5 to the Chapter 7 standing
apartment hypotheses. The present algebraic implication uses neither apartment
axioms nor a centralizer intersection, and the final centralizer target keeps
its corrected apartment premise unchanged. No project errata file for either
registered source was found.

## Implemented proofs

`sharpFixer_le_simplyConnectedImage_of_rootGroups` proves the containment
conditionally on the root-group target. It unfolds the sharp fixer as the
supremum over actual relative roots. Membership in each root fixer gives
membership in its root group, where the supplied lifting hypothesis applies.

`rootGroupLeSimplyConnectedImage_iff_sharpFixer` proves the reverse implication
by evaluating the sharp target on the empty subset. Every element of a root
group belongs to its empty-set root fixer, because the filtration intersection
has no conditions. That root fixer is contained in the empty-set sharp fixer.

`parahoric_le_zeroSubgroup_of_rootGroups` includes the mapped centralizer-zero
factor into `P.zeroSubgroup` by its existing defining inclusion. It includes
the sharp factor by the conditional containment just proved and the existing
simply connected image inclusion. The join universal property combines them.

The missing work is the root-group rational lifting target itself. The module
does not construct a root-subgroup isomorphism under a central isogeny, prove
independence of zero data, establish sharp-fixer boundedness, or identify the
centralizer-zero subgroup with a norm kernel.
