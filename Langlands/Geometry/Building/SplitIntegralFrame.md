# Split integral frames on integer-valued building data

Let `k` be a field and `v : Valuation k (WithZero (Multiplicative ℤ))` a
valuation. No completeness, discreteness or Henselian hypothesis is used.
`B : IntegerValuationBuildingData v G` is the Library building datum of a group
scheme `G` over `Spec k` with affine structure map. It contains a maximal split
torus `B.i : S ⟶ G` of the connected reductive group `G`, the apartment class
`B.apartment` with apartment `B.Apartment`, the actual centralizer
`B.centralizer` (`Z = Z_G(S)`, inclusion `j : Z ⟶ G`), and the root groups
`B.rootGroup a = U_a(k)`. The relative roots are `Φ = relativeRoots B.i`, and
`ord = IntegerValuation.order v` is the additive valuation of a unit.

The module defines a *split integral frame* on `B` and proves that a frame
determines a special point `x` of the apartment with `K = G(k)^1 ∩ G(k)_x`.
The intended source of a frame is a reductive model of `G` over the valuation
ring with a split maximal torus. `K` is then its group of integral points and
the `u_a` its root parametrizations. Constructing a frame from a model is not
done here.

## The structure `SplitIntegralFrame`

`B.SplitIntegralFrame` has the following fields. Below, `a` ranges over `Φ`,
`c` over `k`, and `t` over `S(k)`.

- `K : Subgroup G(k)`, the integral subgroup.
- `u : characterLattice S → k → G(k)`, the root parametrizations. Only the
  values at roots are constrained.
- `u_add`: `u a (c + d) = u a c * u a d`.
- `u_mem`: `u a c ∈ U_a(k)`.
- `u_surjective`: every point of `U_a(k)` is `u a c` for some `c`.
- `u_eq_one`: `u a c = 1` implies `c = 0`.
- `torus_conj`: `t · u a c · t⁻¹ = u a (a(t) c)`, where `a(t) = B.charEval a t`.
- `rankOne`: for every unit `c` there are opposite factor pairs `p` of
  `u a c` and `q` of `u a 1`, and `t ∈ S(k)` with `a(t) = c²`, such that
  `p.1 · u a c · p.2 = t · (q.1 · u a 1 · q.2)`. An opposite factor pair
  (`RelativeRoot.IsOppositeFactorPair`) of `g ∈ U_a(k)` is a pair of points of
  `U_{-a}(k)` whose product with `g` in the middle normalizes `S`. The relation
  says `m(u_a(c)) = a^∨(c) · m(u_a(1))`.
- `two_smul_not_mem`: `2 • a ∉ Φ` (the relative root system is reduced).
- `u_mem_K`: `u a c ∈ K ↔ v c ≤ 1`.
- `centralizer_mem_K`: `j(z) ∈ K` for every `z` in the Library
  `characterValuationKernel v Z` (written `Z(k)^1`: the points on which every
  rational character of `Z` has valuation `1`).
- `K_le_closure`: `K` is contained in the subgroup generated by `j(Z(k)^1)` and
  the sets `u a {c | v c ≤ 1}` for `a ∈ Φ`.
- `simple ⊆ Φ` (`simple_subset`), with `simple_linearIndependent`: the root
  forms `rootForm B.i b` on the translation space of the apartment, for `b` in
  `simple`, are linearly independent over `ℝ`.
- `weyl_mem`: for `b ∈ simple`, `u (-b) (-1) · u b 1 · u (-b) (-1)` normalizes
  `S`. This is the simple Weyl point `F.simpleWeyl b`.
- `induction`: a property of characters that holds for every simple root and
  passes from a root `a` to the image of `a` under the Weyl action of every simple
  Weyl point holds for every root.
- `weyl_generated`: every point of the normalizer `N(k)` has the same Weyl action
  as some element of the subgroup generated by the simple Weyl points.

## Results

Torus action on the apartment, for `t ∈ S(k)` (`B.torusNormalizer t` is `t` as a
point of the normalizer):

- `coe_torusNormalizer`, `weylAction_torusNormalizer`: it maps to `i(t)` in
  `G(k)` and acts trivially on characters.
- `torusNormalizer_smul_val`: `(t • x)_a(g) = x_a(g) − ord(a(t))` for `a ∈ Φ`.
  `rootForm_torusNormalizer_vsub`: the translation `t • x −ᵥ x` takes the value
  `−ord(a(t))` under the root form of `a`. `torusNormalizer_smul_eq_self`: if
  `ord(a(t)) = 0` for all roots, `t` fixes every apartment point.

For a frame `F` and an apartment point `x`:

- `rootValue x a` is the real number `x_a(u_a(1))` (`val_u_one`: this value is
  finite). `val_u`: `x_a(u_a(c)) = ord(c) + x_a(u_a(1))` for every unit `c`.
  `rootValue_vadd`: translating by `w` adds the root form of `a` at `w`.
- `neg_mem`: `−a ∈ Φ`. `u_zero`, `u_ne_one`, `u_one_ne_one`, `u_one_mem_K`.
- `rootForm_simple_surjective`, `exists_rootValue_simple_eq_zero`: some point has
  value `0` at every simple root.
- `rootValue_le_of_smul_eq_self`, `rootValue_weylAction_of_smul_eq_self`: a point
  `n` of `N(k)` in `K` fixing `x` satisfies `x_{n·a}(u_{n·a}(1)) = x_a(u_a(1))`.
- `simpleWeyl_mem_K`, `simpleWeyl_smul_eq_self`: a simple Weyl point lies in `K`
  and fixes every `x` with value `0` at its simple root.
- `exists_rootValue_eq_zero`: some point `x` has `rootValue x a = 0` for every
  `a ∈ Φ`.

The remaining results take such a point `x` (`∀ a ∈ Φ, rootValue x a = 0`).
Those marked (hk) also assume `hk : ∃ d : kˣ, d ^ 2 ≠ 1`, that is, `k` has a
unit other than `±1`. Below, `G(k)^1` is the Library `characterValuationKernel v G`.

- (hk) `rationalCharacterEval_u`, `u_mem_characterValuationKernel`: every rational
  character of `G` is trivial on `u a c`, so `u a c ∈ G(k)^1`.
- `u_mem_filtration`: `u a c ∈ U_{a,x,0}` when `v c ≤ 1`.
- (hk) `K_le_oneStabilizer`: `K ≤ B.oneStabilizer (B.apartmentMap x)`, the
  Library `G(k)^1 ∩ G(k)_x` of the image of `x` in the reduced building.
- `sharpFixer_le_K`: `G(k)^♯_x ≤ K` (`B.sharpFixer {x}`).
- (hk) `normalizer_mem_K`: a point of `N(k)` in `G(k)^1` fixing `x` lies in `K`.
- (hk) `oneStabilizer_le_K` and `K_eq_oneStabilizer`:
  `K = B.oneStabilizer (B.apartmentMap x)`.
- `rootForm_ne_zero`: every root form is nonzero.
  `affineFunctional_mem_affineRoots`: the affine functional `y ↦ a(y −ᵥ x)` is
  an affine root (`B.affineRoots`). `isSpecialPoint`: `x` is a special point of
  the Library affine root system `B.affineRoots`.
- (hk) `exists_isSpecialPoint_K_eq_oneStabilizer`: there is `x` with all root
  values `0`, `B.IsSpecialPoint (B.apartmentMap x)`, and
  `K = B.oneStabilizer (B.apartmentMap x)`.

## Proofs

- Torus translation: V 6 compatibility of every apartment point with the split
  torus (`isSplitTorusCompatible`) gives `torusNormalizer_smul_val`. Comparing
  one finite value gives the translation vector.
- `val_u`: the Library displacement formula `rootForm_oppositeFactorPair_vsub`
  computes `m • x −ᵥ x` under the root form for the products `m` of the two
  opposite factor pairs. `rankOne` writes the first product as `t` times the
  second, with `ord(a(t)) = 2 ord(c)`. Equating the two computations gives the
  formula.
- `neg_mem`: the product of the pair of `u_a(1)` sends `a` to `−a`
  (`IsOppositeFactorPair.weylAction_eq_neg`).
- `rootForm_simple_surjective`: the dual map of the evaluation at the simple
  root forms is injective by linear independence
  (`LinearMap.dualMap_injective_iff`).
- `rootValue_le_of_smul_eq_self`: for `n ∈ N(k) ∩ K` fixing `x` and `b = n·a`,
  `g = n⁻¹ u_b(1) n` lies in `U_a(k) ∩ K`, so `g = u_a(c)` with `v c ≤ 1`. The
  value of `g` at `x` equals the value of `u_b(1)` at `n • x = x`. By `val_u`
  this is `ord(c) + rootValue x a ≥ rootValue x a`. Applying this to `n⁻¹` gives
  equality.
- `simpleWeyl_smul_eq_self`: the Library `oppositeFactorPair_smul_eq_self` (the
  product of an opposite pair of an element of value `0` fixes the point).
- `exists_rootValue_eq_zero`: start from a point with simple values `0` and use
  `induction`, with the two previous items.
- `rationalCharacterEval_u`: choose `t` with `a(t) = d²`, so `a(t) ≠ 1`. By
  `torus_conj`, the additive character `c ↦ χ(u_a(c))` is invariant under
  multiplication by `a(t)`. Writing `c = a(t)c' − c'` with
  `c' = c / (a(t) − 1)` makes it trivial.
- `K_le_oneStabilizer`: check the generators of `K_le_closure`. For `j(Z(k)^1)`
  use the Library `map_mem_oneStabilizer`. For `u_a(c)` with `v c ≤ 1`, use
  `u_mem_filtration` and `sharpFixer_le_fixer`.
- `sharpFixer_le_K`: `G(k)^♯_x` is generated by the groups `U_{a,x,0}`
  (`sharpFixer_eq_closure`). Each of their points is `u_a(c)` with
  `ord(c) ≥ 0` by `val_u`.
- `normalizer_mem_K`: by `weyl_generated`, `n` and an element `m` of the group
  generated by the simple Weyl points have the same Weyl action, and `m ∈ K`
  fixes `x`. Then `m⁻¹n` acts trivially on characters, so it lies in `j(Z(k))`
  (`IsSplitTorus.weylAction_eq_one_iff` and the centralizer datum). It lies in
  `G(k)^1` and fixes `x`, so the Library
  `mem_characterValuationKernel_of_smul_eq` puts it in `j(Z(k)^1) ⊆ K`.
- `oneStabilizer_le_K`: by the Library `reducedFixer_apartmentMap`,
  `G(k)_x = G(k)^♯_x ⊔ N(k)_x`. `N(k)_x` normalizes `G(k)^♯_x`
  (`sharpFixer_le_comap`), so every `g` in `G(k)^1 ∩ G(k)_x` is `s n` with
  `s ∈ G(k)^♯_x ⊆ K` and `n ∈ N(k)_x`. Then `n ∈ G(k)^1`, and
  `normalizer_mem_K` gives `n ∈ K`.
- `rootForm_ne_zero`: the root takes the value `2` on the coroot class of the pair
  of `u_a(1)` (`rootForm_oppositeFactorPairCorootClass`).
- `affineFunctional_mem_affineRoots`: for `ψ = a(· −ᵥ x)`, `u_a(1) ∈ U_ψ` has
  value exactly `ψ(x) = 0`, so it is not in `U_{ψ+}`. `U_{2a}(k) = {1}` by
  `two_smul_not_mem`. So `U_ψ ⊄ U_{ψ+} U_{2a}(k)`.
- `isSpecialPoint`: by `AffineRootSystem.isSpecialPoint_iff_ker`, every affine
  root has derivative some root form `a`. The affine root `a(· −ᵥ x)` vanishes
  at `x` and has the same derivative.

## Provenance

`SplitIntegralFrame` is an internal definition. It is not quoted from a source,
and its field list is chosen for the proofs above. It records, on the field
level, the data of a Chevalley system in the split case of Kaletha–Prasad §6.1
(source `kaletha-prasad-2023-bruhat-tits-new-approach`, printed pp. 196–198,
PDF pp. 227–229). There, the isomorphisms `u_{o,a} : 𝔾_a → U_a` and the group
`P_{o,0}`, generated by `S(k)^0` and the `u_{o,a}(𝔬)`, appear. The valuation
`φ_{o,a}(u_{o,a}(c)) = ord(c)` there is the Chevalley valuation of Definition
6.1.9 (printed p. 202, PDF p. 233). The point `x` of
`exists_rootValue_eq_zero` is that valuation: its values are
`x_a(u_a(c)) = ord(c)`.

The frame differs from KP's data in these ways:

- `K` is any subgroup satisfying `u_mem_K`, `centralizer_mem_K` and
  `K_le_closure`, with `Z(k)^1` in place of `S(k)^0`.
- The Chevalley commutator relations are replaced by `rankOne`, `torus_conj`, the
  simple Weyl points, `induction` and `weyl_generated`.
- `weyl_mem` fixes a sign normalization of `u_{-b}` for simple `b`. The relation
  `rankOne` is unchanged when a single `u_a` is rescaled.

The results are internal Lean proofs, not quoted from the source. Their routes
are the ones listed above.
