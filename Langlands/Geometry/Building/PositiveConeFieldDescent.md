# Actual positive-cone depths under field extension

This internal construction defines `fieldExtendedAdditiveDepth` by composing
an additive real function on the original character lattice with the inverse
actual character pullback equivalence of a split torus. Evaluation at every
original pulled-back character recovers the original depth exactly. For a
smooth affine actual group, the actual positive integral cone upstairs has
exactly the original cone as its character preimage.

For a monomorphic split-torus inclusion with opposite factor pairs, a
cocharacter positive on both input characters, and a root-datum valuation
only upstairs, `mem_positiveConeGenerated_fieldExtend_iff` preserves and
reflects membership in the subgroup generated by the additive cone
filtrations. The proof constructs a finite injective enumeration of the
original indivisible positive roots. Opposite factor pairs cover the entire
original cone by those roots or their doubles. Character base change
transports this cover to the actual cone upstairs. Additivity supplies the
exact collection and doubled-depth conditions, and the preceding
generated-subgroup field-descent theorem reflects membership using collection
only upstairs. The downstairs family is the literal field restriction.
The real depths need not be positive. Doubled roots and selections consisting
only of a doubled root are retained by the imported descent theorem.

`rootDepthGeneratedSubgroup_positiveCone_of_outputDepth` identifies the cone
generated subgroup with the literal V3 union whenever an additive depth takes
the required value `p*r + q*s` at every actual output root `p*a + q*b`, for
strictly positive natural `p,q`. This hypothesis only constrains output
roots; the depth values on the two inputs are not required to equal `r,s`.
The proof compares the exact generating sets, without unique representations.

Under these same hypotheses, `fieldRestrict_commutator_of_outputDepth` proves
the literal V3 subgroup inclusion for the two original root filtrations.
Each original input filtration closure maps into the corresponding upstairs
closure, by the closure universal property and literal filtration reflection.
The common positive cocharacter makes the upstairs roots nonopposite, so V3
there places each extended commutator in the upstairs output subgroup.
The output-depth identity and cone membership reflection put the original
commutator in the exact original V3 subgroup. The subgroup commutator
universal property gives the asserted inclusion. No downstairs valuation or
commutator axiom is assumed in that proof.

The provenance is the existing actual character/root base-change equivalences,
finite root enumeration, opposite-factor-pair ray classification, subgroup
closure and commutator universal properties, and the preceding internal cone
and generated-subgroup constructions. All statements allow arbitrary common
universe parameter and arbitrary field extensions. This unit retains the
output-depth compatibility and common positivity hypotheses; it does not yet
supply them for every pair and every depth. It does not construct a valuation,
an apartment, or the supplied-model building comparison.
