# Proof of the depth-zero intersections of `G(K)_{x,0}` over `K = F^ur`

Author: Worker 82.

`Langlands.Geometry.Building.MaximalUnramified.localMoyPrasadDepthZero` proves
the unchanged published proposition
`Langlands.Geometry.Building.MaximalUnramified.LocalMoyPrasadDepthZeroStatement.{u}`
at arbitrary universe `u`. It quantifies over the same `F`, `H`, `B` and `hZ` and
adds no premise. The statement module
`KPLocalMoyPrasadDepthZeroStatement` and its Markdown are not modified. That
Markdown compares the two clauses with Kaletha–Prasad (KP) Proposition 7.3.12
and Lemma 8.5.19 at `f = 0`.

The proof does not follow KP's proofs. KP prove Proposition 7.3.12 with the
Bruhat decomposition and Lemma 8.5.19 with the integral models `G_{x,f}` of
§8.5. Neither tool is available in the Library for the K-level groups. The proof
below uses published K-level results on root groups, the Levi sharp transport,
the affine Weyl group, and the zero subgroup `G(K)^0`. It assumes neither S1, S2,
a product cover, AS 5, nor apartment or building axioms. Every imported result it
uses is unconditional, with one exception: one imported result takes the
proposition `SimplyConnectedNormalizerAffineWeylStatement` as an argument. The
proof supplies the published theorem
`MaximalUnramified.simplyConnectedNormalizerAffineWeyl` for it.

Notation: `K = UnramifiedClosure F`; `S = B.S` with inclusion `B.i`; `Φ` is the
set `relativeRoots B.i`; `Z = B.centralizer.Z` with embedding `j`;
`G(K)_{x,0} = B.moyPrasad hZ x 0`; `G(K)♯_x = B.sharpFixer {x}`;
`U_{b,x,0} = B.filtration x b 0`; `N(K) = normalizerPoints B.i`.

## Clause (a)

Theorem `BuildingData.rootGroupSpan_inf_moyPrasad_zero`. Let `mu` be a generic
integral cocharacter and `Φ⁺ = positiveRelativeRoots B.i mu`.

**`⊇`.** Each `U_{b,x,0}` lies in `U_b(K)` (`filtration_le_rootGroup`). For a
relative root `b` it also lies in `G(K)_{x,0}` (`filtration_le_moyPrasad`).
Hence `B.rootFiltrationSpan x Φ⁺ 0` lies in both sides of the intersection
(`rootFiltrationSpan_zero_le_rootGroupSpan`,
`rootFiltrationSpan_zero_le_moyPrasad`).

**`⊆`.** Let `g` lie in `⟨U_b(K) : b ∈ Φ⁺⟩ ∩ G(K)_{x,0}`.

1. Every `U_b(K)` with `b ∈ Φ⁺` lies in the dynamic unipotent subgroup
   `U(mu)(K)` (`RelativeRoot.subgroup_le_dynamicUnipotent`). So `g ∈ U(mu)(K)`.
2. `G(K)_{x,0}` fixes the image `[x]` of `x` in the reduced building
   (`moyPrasad_zero_le_fixer`). By `moyPrasad_eq_sup`, the group is
   `j(Z(K)_0) ⊔ G(K)♯_{x,0}`. At depth zero the sharp filtration is the point sharp
   fixer `G(K)♯_x` (`sharpFiltration_zero_eq_sharpFixer`). This group fixes
   `[x]` (`sharpFixer_le_fixer`). An element of `Z(K)_0` lies in the
   character-valuation kernel of `fixedFieldValuation F`
   (`centralizerTorusFiltration_le_characterValuationKernel`). By the
   equivalence `MaximalUnramified.valuation_isEquiv`, it also lies in the kernel
   for the valuation `MaximalUnramified.valuation F` used by `B`. So its image
   lies in the one-stabilizer (`map_mem_oneStabilizer`), which fixes `[x]`
   (`oneStabilizer_le_fixer`).
3. The published `KPApartmentData.mem_positiveRootGroups_of_mem_unipotent_of_smul_apartmentMap_eq`
   (module `GenericPointSharpExchange`) assumes only that `H` is connected
   reductive and that `S` is a maximal split torus, and both facts are fields of
   `B`. It sends an element of `U(mu)(K)` fixing `[x]` into the subgroup
   generated by the `U_{b,x,0}`, `b ∈ Φ⁺`. That subgroup lies in
   `B.rootFiltrationSpan x Φ⁺ 0` (`positiveZeroRootGroups_le_rootFiltrationSpan`).

## Clause (b)

Theorem `BuildingData.pairingLeviSpan_inf_moyPrasad_zero_le`. Fix `x` and
`ν : V B.S`.

### Step 1: an integral cocharacter with the same zero set

Section `DepthZeroApprox` proves a general approximation lemma for any
commutative group scheme `T` over a field. For a finite set `s` of characters and `ν ∈ V T = ℝ ⊗ X_*(T)`, there
is an integral cocharacter `lam` with `⟨χ, lam⟩ = 0 ↔ ⟨χ, ν⟩ = 0` for every
`χ ∈ s` (`exists_latticePairing_eq_zero_iff`). The proof has two steps.

- `exists_ratFunctional_ne_zero`: some `ℚ`-linear map `ψ : ℝ → ℚ` is nonzero on
  the finitely many nonzero values `⟨χ, ν⟩`. The proof is by induction on the
  finite set. A `ℚ`-dual vector separates each new value from zero, and since
  `ℚ` is infinite a suitable multiple of it can be added without creating new
  zeros.
- `exists_latticePairing_eq_mul`: applying `ψ` to the real coefficients of `ν`
  and clearing denominators gives `lam` and a nonzero integer `d` with
  `⟨χ, lam⟩ = d · ψ(⟨χ, ν⟩)` for all `χ`. The proof is by induction on the tensor
  `ν`.

The relative roots are finite (`IsSplitTorus.finite_relativeRoots`).
`⟨b, lam⟩ = 0` is equivalent to `lam ≫ b = 0`
(`comp_eq_zero_iff_latticePairing_eq_zero`, via `gmEndEquiv`). Together these
give `lam` with `Φ₀(ν) = {b ∈ Φ | lam ≫ b = 0}`
(`exists_cocharacter_comp_eq_zero_iff`, `zeroPairingRoots_eq_setOf`).

### Step 2: reduction to the centralizer of `lam`

`M_ν(K) = B.pairingLeviSpan ν` is generated by `j(Z(K))` and the `U_b(K)` with
`b ∈ Φ₀(ν)`. Both centralize the image of `lam : 𝔾_m → S`. The group `j(Z(K))`
centralizes `S` (`range_le_centralizerPoints`). A root group with `lam ≫ b = 0`
centralizes `lam` (`rootGroupPoints_le_centralizerPoints_of_comp_eq_zero`). This
is `pairingLeviSpan_le_centralizerPoints`. So clause (b) follows from
`mem_sup_of_mem_centralizerPoints_of_mem_moyPrasad`: an element `g ∈ G(K)_{x,0}`
centralizing the image of `lam` lies in `j(Z(K)_0) ⊔ R`, where
`R = B.rootFiltrationSpan x {b ∈ Φ | lam ≫ b = 0} 0`.

### Step 3: from `g` to a normalizer point

`j(Z(K)_0)` normalizes every `U_{b,x,0}` (`image_le_normalizer_filtration`), so
it normalizes `G(K)♯_x = ⨆_b U_{b,x,0}` (`sharpFixer_singleton_eq_iSup`). Hence
`G(K)_{x,0} = j(Z(K)_0) · G(K)♯_x` as sets (`coe_moyPrasad_zero`). Write
`g = z s` with `z ∈ j(Z(K)_0)` and `s ∈ G(K)♯_x`. Since `z` centralizes `lam`,
so does `s`. Then `s` normalizes the image of `lam` and fixes `[x]`
(`sharpFixer_le_reducedFixer`).

The published Levi sharp transport `KPApartmentData.exists_leviSharp_transport`
(module `LeviSharpTransport`) applies with `A = 𝔾_m`, `f = lam`, `n = s` and
`y = x`. It needs `K` infinite, which holds because `F` is an infinite local
field embedded in `K`. It gives `h` centralizing `lam` with
`h ∈ ⨆_{b ∈ Φ, lam ≫ b = 0} U_{b,x,0} ≤ R` and `n := s h ∈ N(K)`. Then
`n ∈ G(K)♯_x` (since `R ≤ G(K)♯_x` by `rootFiltrationSpan_le_sharpFixer`) and
`n` centralizes `lam`.

### Step 4: normalizer points in `G(K)♯_x` centralizing `lam`

`normalizer_mem_of_mem_centralizerPoints` shows `n ∈ j(Z(K)_0) ⊔ R`. Let
`E = UnramifiedZeroDatum.ofConnectedReductive H B.isConnectedReductive` and
`v = [1 ⊗ lam]` in the translation space.

1. `n ∈ E.zeroPoints = G(K)^0` (`sharpFixer_le_zeroPoints`). So the action
   `B.apartment.normalizerAffineEquiv n` lies in the affine Weyl group of
   `B.affineRoots` (`normalizer_mem_affineWeylGroup_of_mem_zeroPoints`,
   applied to the published `MaximalUnramified.simplyConnectedNormalizerAffineWeyl`).
2. `n` fixes `x` (`KPApartmentData.normalizer_smul_eq_self_of_mem_sharpFixer`,
   module `GenericApartmentInjection`). Since `n` centralizes `lam`, its Weyl
   action fixes `lam` (`comp_normalizingAut_hom_eq`). So it fixes `v`
   (`translationAction_tmul_eq_of_mem_centralizerPoints`) and the point
   `v +ᵥ x` (`normalizerAffineEquiv_vadd_eq_of_mem_centralizerPoints`).
3. The affine roots form a locally finite reflection arrangement
   (`isLocallyFiniteReflectionArrangement_of_hasOppositeFactorPairs`).
   `AffineRootSystem.exists_generic_point` gives a point `p` with two
   properties. Every affine automorphism fixing `x` and `v +ᵥ x` fixes `p`.
   Every affine root vanishing at `p` vanishes at both `x` and `v +ᵥ x`. So the
   action of `n` fixes `p`. By
   `AffineRootSystem.mem_closure_pointReflections_of_apply_eq`, it lies in the
   subgroup generated by the reflections in affine roots vanishing at `p`.
4. Each such reflection is the action of an element of `N(K) ∩ R`
   (`exists_rootFiltrationSpan_normalizer_eq_affineReflection`). Write the
   affine root as the reflection functional of a relative root `α` and some
   `u ∈ U_α(K)`. Its vanishing at `x` gives `φ_α(u) = 0` at `x`. Its vanishing
   at `v +ᵥ x` gives, by `val_mk_vadd_apply`, `⟨α, lam⟩ = 0`, so
   `lam ≫ α = 0` and `lam ≫ (-α) = 0`. The opposite factor pair of `u` gives
   the reflection element `m(u) = p₁ u p₂ ∈ N(K)` with `p₁, p₂ ∈ U_{-α}(K)`. By
   the opposite-value property of the valuation `x`, both `p₁` and `p₂` have
   value `0` at `x`. So `m(u)` lies in `U_{-α,x,0} U_{α,x,0} U_{-α,x,0} ⊆ R`. Its
   action is the given reflection (`normalizerAffineEquiv_reflectionElement`,
   `reflectionCoroot_eq_of_isCoroot`).
5. Hence there is `m ∈ N(K) ∩ R` acting on the apartment exactly as `n` does
   (`exists_rootFiltrationSpan_normalizerAffineEquiv_eq`). Also
   `m ∈ G(K)♯_x ⊆ G(K)^0`. So `m⁻¹ n` lies in `G(K)^0` and fixes the whole
   apartment image pointwise. By
   `UnramifiedZeroDatum.wholeApartmentZeroFixer_eq_centralizerTorusImage`, which
   uses `hZ`, this gives `m⁻¹ n ∈ j(Z(K)_0)`
   (`mem_centralizerTorusImage_of_normalizerAffineEquiv_eq`). Therefore
   `n = m · (m⁻¹ n) ∈ j(Z(K)_0) ⊔ R`.

### Step 5: conclusion

`g = z s = z n h⁻¹` with `z ∈ j(Z(K)_0)`, `n ∈ j(Z(K)_0) ⊔ R` and `h ∈ R`. So
`g ∈ j(Z(K)_0) ⊔ R`. Rewriting `R` by `zeroPairingRoots_eq_setOf` gives clause
(b).

## Final theorem

`MaximalUnramified.localMoyPrasadDepthZero` introduces `F`, `H`, `B` and `hZ` and
returns the pair of clause (a) and clause (b).
