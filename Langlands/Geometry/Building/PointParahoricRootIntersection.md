# Root groups intersected with an actual point parahoric

The entry construction `ParahoricBuildingData.rootGroupParahoricAtEquivFiltration`
is a multiplicative equivalence

```
(P.rootGroup a ⊓ P.parahoricAt x) ≃* P.filtration x a 0.
```

It sends each element to the same ambient rational point. The supporting
theorem `rootGroup_inf_parahoricAt_eq_filtration` proves equality of these
actual subgroups.

Here `F : Type u` is an arbitrary nonarchimedean local field, `G` is a group
scheme over `F` with affine structure morphism, and
`P : ParahoricBuildingData G`. Its connected reductive group, maximal split
torus, valuation apartment and generated full parahoric are the existing
objects. The point `x` is any apartment point, and `a` is any actual relative
root, including a divisible root. No chamber-point restriction occurs.

The construction assumes the existing apartment predicate
`P.apartment.SatisfiesApartmentAxioms P.centralizer`, opposite factor pairs
`RelativeRoot.HasRankOneFactorization P.i`, and the global proposition
`RelativeRoot.DynamicRootOrderedProductStatement.{u}`. The latter two
prerequisites remain explicit. This unit introduces no universal statement
of their truth or of the unconditional point-intersection conclusion.

The coordinate lemmas in `KPApartmentData` work over an arbitrary field.
They assume connected reductivity, maximal splitness, the affine-root-system
law for the extended roots, their derivative comparison with
`Set.range (rootForm i)`, and the Dynamic ordered product proposition.
The point-parahoric results obtain these data from `P` and the apartment
predicate.

## Implemented proof

For an apartment point and a generic cocharacter, point exchange with the
positive unipotent factor first writes an element of the actual full
parahoric as `v w n z`, with `v` in the subgroup generated by the positive
depth-zero filtrations, `w` in the negative counterpart, `n` in the sharp
normalizer stabilizer, and `z` in the actual centralizer-zero image.
The full parahoric product formula places `z` last, so `n z` is an
actual normalizer point.
If the element is positive unipotent, then
`n z = w⁻¹ (v⁻¹ g)` is an opposite-unipotent/unipotent product.
The published affine opposite-cell normalizer separation makes `n z` trivial.
Opposite unipotent separation then makes `w` trivial, so `g = v`.

For an indivisible positive root, positive collection expresses such an
element as an ordered product of zero-depth filtrations. The explicit
Dynamic ordered product premise makes multiplication of the actual root
groups injective. Compare with the tuple equal to the given element in
its root coordinate and the identity elsewhere. Equality of coordinates
puts the element in its own zero-depth filtration.

AS2 implies every positive root is indivisible or twice an indivisible
positive root. In the second case the actual doubled-root inclusion gives
membership in the primitive root group, and V4 transfers the resulting
nonnegative valuation back to the doubled root.

For an arbitrary root, choose a generic integral cocharacter using the
maximal split torus and connected reductivity. Its pairing with the root
is nonzero. Negate the cocharacter if necessary to make that pairing
positive. The actual root subgroup then lies in the associated Dynamic
unipotent subgroup. Apply the preceding parahoric extraction and coordinate
isolation to obtain membership in `P.filtration x a 0`.

The reverse inclusion follows because the filtration lies both in the
actual root group and in the singleton sharp fixer, which lies in the
full point parahoric. `MulEquiv.subgroupCongr` for the resulting subgroup
equality gives the entry equivalence and its ambient-point formula.
