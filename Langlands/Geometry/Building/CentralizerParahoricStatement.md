# The centralizer part of `G(F)^0_Ω`

Module `Langlands.Geometry.Building.CentralizerParahoricStatement`.
The Prop-valued target
`ParahoricBuildingData.CentralizerParahoricIntersectionStatement` states
Kaletha–Prasad Lemma 7.4.3 on the actual fixed apartment:
`Z(k) ∩ G(k)^0_Ω = Z(k)^0` for every non-empty `Ω ⊆ A`.
No proof is supplied. The statement asserts no existence of data.

## The Lean statement

The parameters are exactly an actual `P : ParahoricBuildingData G` over a
nonarchimedean local field `F` in an arbitrary universe, with
`[IsAffineHom G.X.hom]`. Both characteristics are covered.

```
P.apartment.SatisfiesApartmentAxioms P.centralizer →
  ∀ Ω : Set P.Apartment, Ω.Nonempty →
    centralizerPoints P.i ⊓ P.parahoric Ω =
      P.centralizerZero.map (rationalPoints.map P.centralizer.j)
```

- `centralizerPoints P.i` is the subgroup of `G(F)` centralizing the
  maximal split torus `S`. Its elements are the points of `Z(F)` inside
  `G(F)`, where `Z = Z_G(S)`.
- `P.parahoric Ω` is the existing definition
  `P.centralizerZero.map (rationalPoints.map P.centralizer.j) ⊔ P.sharpFixer Ω`,
  the subgroup generated by `Z(F)^0` and `G(F)^♯_Ω`. This is KP
  Definition 7.4.1(4).
- The right side is `Z(F)^0` (KP Definition 2.6.23(2), module
  `KPZeroSubgroups`), embedded in `G(F)` by the actual centralizer
  inclusion `j : Z → G`.

The premise `SatisfiesApartmentAxioms` only weakens the statement. No
topology, compactness, residue-field or tameness premise is added.

## Why `Ω` must be non-empty

In the Library, `rootFixer a ∅ = U_a(F)`, so `sharpFixer ∅` is generated
by all root subgroups. For `G = SL_2` this is all of `SL_2(F)`. Then
`Z(F) ∩ P_∅` is the whole diagonal torus `T(F)`, which is larger than
`Z(F)^0 = T(o)`. The equality fails for `Ω = ∅`, and the hypothesis
`Ω.Nonempty` is required.

## Use

With `Ω` a chamber `C`, this gives `Z(F) ∩ I_C = Z(F)^0`. That is the
central factor of the Iwahori factorization in
`ChamberIwahoriDecompositionStatement`.
