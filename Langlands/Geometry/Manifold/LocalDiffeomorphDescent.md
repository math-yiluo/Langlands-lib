# Local analytic descent through local diffeomorphisms

These internal lemmas support functoriality of the analytic point manifolds. A lifted map through a topological branch is analytic when it has a common refinement with an analytic second projection and a locally analytically invertible first projection. The proof composes with the first projection's analytic local inverse and uses the commuting equation to identify the lift on a neighborhood.

The same local inverse proves descent of analyticity for an arbitrary map. For descent of local analytic invertibility, compose its partial analytic diffeomorphism with the inverse branch of the first projection. The resulting partial diffeomorphism agrees with the actual map throughout its source. The statements allow different model spaces and every differentiability order.
