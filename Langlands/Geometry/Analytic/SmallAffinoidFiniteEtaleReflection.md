# Reflection of finite étaleness on small affinoid spectra

Let `K` be a complete ultrametric normed field. Let a finite Banach map
of presented affinoid `K`-algebras with both spectra small in the same
universe induce an étale map in the localized analytic category. Then
the original bounded map is algebraically finite étale.

The canonical strong representative retains the whole affinoid chart of
both spectra. Finiteness on those charts implies finiteness over every
recognized affinoid piece. The canonical strong étale property upgrades
this whole-space finite model to a finite étale model. The preimage of
the whole target chart has the whole source locus, so uniqueness of
recognized subsets identifies it with the recognized source chart.
The original-recognition restriction equivalences conjugate the bounded
map on those two pieces back to the original chart map. The saturation
formula transports its finite étaleness to the input bounded map.

This is a derived reflection result for finite Banach maps. It uses the
small-spectrum saturation comparison and the recognized finite étale
model theorem. The field and spectrum universes are independent.
