# Finite actual rational refinements of relative open covers

Author: Worker 36.

This internal construction supplies finite rational refinements of arbitrary
relative open covers of an actual rational chart. It derives the refinements
from the published ambient rational neighborhood theorem, explicit rational
intersections and compactness of represented domain loci. It assumes no
rational-neighborhood property for general affinoid domains.

Let `K : Type u` be a complete ultrametric normed field and let
`A : PresentedAffinoidAlgebra K` be the actual positive-polyradius closed
Tate quotient used throughout the imported constructions. Let
`d : RationalChart K A` be an actual rational presentation over `A`.
The cover label type `I : Type v` has an independent universe.

`RelativeNeighborhood d x W` stores an actual rational chart `chart`, an
actual bounded restriction `map : chart ⟶ d`, a proof that the preimage of
`chart.locus` in `d.locus` is a neighborhood of `x`, and containment of that
preimage in `W`. `ofNeighborhood` constructs this data from `W ∈ 𝓝 x`.
Mathlib's description of the subtype topology gives an ambient neighborhood
`V` whose preimage is contained in `W`. The published
`exists_rational_neighborhood` supplies an actual ambient rational chart `n`
whose locus is a neighborhood of the underlying point and is contained in
`V`. The constructed chart is `d.inter n`, with the original bounded
`interLeft d n` as its restriction. The exact intersection-locus equation and
continuity of the subtype inclusion prove the two required properties.

`FiniteOpenRefinement d U` stores a natural number, that many actual rational
charts and bounded restrictions to `d`, and an original cover label for each
chart. Each component's entire locus, viewed in `d.locus`, is contained in
the relative set with that label. The relative interiors of the component
loci cover `d.locus`. Component loci themselves need not be open.

`ofOpenCover` constructs this object when every `U i` is open in `d.locus`
and each point belongs to some `U i`. For every point it chooses a label and
uses `RelativeNeighborhood.ofNeighborhood` inside that cover member. The
interior of the resulting relative locus remains a neighborhood of the
point. Compactness of `d.toDomain.locus` selects finitely many such interiors.
Reindexing the selected finite set of points by `Fin` retains each actual
chart, bounded restriction, original label and subordination proof. Thus the
construction works for an arbitrary cover cardinality and label universe.

`covers` follows from containment of each relative interior in its locus.
`subordinate_point` applies the stored subordination to any ambient point
in a component, using the actual restriction's proved locus containment.
`toFiniteCover` keeps each quotient algebra and the exact bounded restriction
while regarding the components as represented domains; its restriction
equation is definitional. `coveringSieve` is generated by the actual chart
arrows. `coveringSieve_mem` witnesses its membership in the published finite
rational topology using the same family, with finite indices lifted into
universe `u`. The explicit `empty` construction has zero members when
`d.locus` is empty, even if the cover label type is empty.

The provenance is internal: the analytic neighborhood input is the published
`RationalLaurentNeighborhoods.exists_rational_neighborhood`; actual
intersections and their bounded arrows are from `RationalChartIntersection`;
the proved representation is packaged by `RationalChartDomain`; and
compactness and finite domain covers are from `DomainTopology`.
`RationalChartCovering` supplies the existing site. The proofs above combine
these published constructions with Mathlib's subtype topology and compact
neighborhood-subcover theorem. No new original-literature assertion is
introduced.

Arbitrary positive radii, trivial valuations, nilpotents, zero quotients and
empty spectra remain allowed. This unit gives a concrete input for descent
of actual algebra sections on topological opens. It does not construct that
sheaf, prove Gerritzen–Grauert for arbitrary represented domains, or construct
analytic atlases, etale sites, invariant refinements or the Harris tower.
