# Bounded quotient descent for strict base change

Author: Worker 972.

This module continues `StrictBaseChange`. There, a quotient presentation `P`
with arbitrary positive radii over an ultrametric field `K` is sent to a strict
presentation `Q = PresentedAffinoidAlgebra.strictBaseChange P ι hι hc` over a
larger ultrametric field `L`, with the ring homomorphism
`ψ = strictBaseChangeHom P ι hι hc : P →+* Q`. The inputs are the same:

- an isometric field embedding `ι : K →+* L` (`hι : ∀ a, ‖ι a‖ = ‖a‖`);
- elements `c i : L` with `‖c i‖` equal to the `i`-th radius of `P` (`hc`);
- an additive map `π : L →+ K` with `π (ι a * x) = a * π x` (`hπ`) and
  `‖π x‖ ≤ D * ‖x‖` (`hπD`), where `0 ≤ D` (`hD`).

The fields may live in different universes. Both carry `IsUltrametricDist`, as
in `StrictBaseChange`; no completeness is assumed. The task that requested this
module assumes `0 < D`. The Lean hypothesis `0 ≤ D` is weaker, so a caller with
`hD : 0 < D` passes `hD.le`. The normalisation `π 1 = 1` (`hπ1`) is an explicit
argument of exactly those results that need it.

`P` and `Q` are the actual quotient rings `GeneralizedTateAlgebra ⧸ P.ideal`
and `StrictTateAlgebra ⧸ Q.ideal` with their quotient norms. Here `Q.ideal` is
the closure of the ideal generated by `baseChange P.ideal`.

## The retraction `s : Q →+ P`

`strictBaseChangeRetraction P ι hι hc π hπ hD hπD : strictBaseChange P ι hι hc →+ P`
is the map `s` with `s [g] = [descend g]`. Here `[·]` denotes classes in the two
quotients and `descend` is the published series map
`GeneralizedTateAlgebra.descend P.polyradius hc π hπD`, which sends
`∑ g_d X^d` to the series with coefficients `π((c ^ d)⁻¹ g_d)`.

In Lean, `s` is Mathlib's `QuotientAddGroup.lift` applied to the additive map
`presentationMap K P ∘ descend` and the additive subgroup underlying
`Q.ideal`. (The quotient ring by an ideal is definitionally the quotient group
by its underlying additive subgroup.) The kernel condition holds because
`descend_mem_of_mem_closure_map` sends every element of `Q.ideal` into
`P.ideal`. That lemma uses that `P.ideal` is closed, which is part of the data
of `P`. So `s` is well defined on the actual quotient carrier and is additive.
It is not a ring homomorphism in general.

The results are:

- `strictBaseChangeRetraction_presentationMap` (representative formula): for
  every radius-one series `g` over `L`, `s` applied to the class of `g` in `Q` is
  the class of `descend g` in `P`. This holds by definition.
- `norm_strictBaseChangeRetraction_le`: `‖s b‖ ≤ D * ‖b‖` for the quotient
  norms. Given `ε > 0`, choose a representative `g` of `b` with
  `‖g‖ < ‖b‖ + ε / (D + 1)`. Then
  `‖s b‖ ≤ ‖descend g‖ ≤ D ‖g‖ ≤ D ‖b‖ + D ε / (D + 1) ≤ D ‖b‖ + ε`,
  using `norm_presentationMap_le` and `norm_descend_le`. Since `ε` is
  arbitrary, the bound follows.
- `strictBaseChangeRetraction_strictBaseChangeHom` (needs `hπ1`):
  `s (ψ a) = a`. Write `a = [f]`. Then `ψ a = [baseChange f]`
  (`strictBaseChangeHom_presentationMap`), and `descend (baseChange f) = f`
  (`descend_baseChange`).
- `strictBaseChangeRetraction_strictBaseChangeHom_mul`:
  `s (ψ a * b) = a * s b` for all `a : P` and `b : Q`. Write `a = [f]` and
  `b = [g]`. Then `ψ a * b = [baseChange f * g]`, and
  `descend (baseChange f * g) = f * descend g` (`descend_baseChange_mul`).
  This needs `hπ` but not `hπ1`.
- `strictBaseChangeRetraction_one` (needs `hπ1`): `s 1 = 1`, the case `a = 1`
  of the left-inverse equation.
- `strictBaseChangeHom_injective` (needs `hπ1`): `ψ` is injective, because `s`
  is a left inverse.

## Ideals and units

`strictBaseChangeDescentIdeal P ι hι hc π hπ hD hπD I` is the ideal of those
`b : Q` such that `s (g * b) ∈ I` for every `g : Q`; its membership is
`mem_strictBaseChangeDescentIdeal`. It is closed under addition because `s` is
additive, and under multiplication by `Q` because the condition quantifies over
all multipliers `g`. Here `I` is any ideal of `P`, not necessarily closed.

- `map_strictBaseChangeHom_le_strictBaseChangeDescentIdeal`:
  `Ideal.map ψ I` lies in the descent ideal of `I`. For `a ∈ I` and `g : Q`,
  `s (g * ψ a) = s (ψ a * g) = a * s g`, which lies in `I`.
- `map_strictBaseChangeHom_ne_top` (needs `hπ1`): if `I ≠ ⊤`, then
  `Ideal.map ψ I ≠ ⊤`. Otherwise `1` lies in the descent ideal of `I`; taking
  `g = 1` gives `s 1 = 1 ∈ I`, so `I = ⊤`.
- `map_strictBaseChangeHom_eq_top_iff` (needs `hπ1`): `Ideal.map ψ I = ⊤`
  if and only if `I = ⊤`. The converse direction is `Ideal.map_top`.
- `isUnit_strictBaseChangeHom_iff` (needs `hπ1`): `IsUnit (ψ a) ↔ IsUnit a`.
  A ring homomorphism preserves units. Conversely, if `ψ a * b = 1`, then
  `a * s b = s (ψ a * b) = s 1 = 1`, so `s b` is an inverse of `a` in the
  commutative ring `P`.

The last three results need no closedness of `I` and no flatness of `ψ`; they
use only the relative linearity of `s` and `s 1 = 1`.

## Scope and provenance

All statements here are internal consequences of the explicit coefficient
construction in `StrictBaseChange`; none of them is quoted from the
literature. This module does not identify `Q` with a completed tensor product
`P ⊗̂_K L`. It does not prove faithful flatness of `ψ`. It does not construct
`L`, `c` or `π`; when `K` is complete, `RadiusRealization` provides them,
with `0 < D`. The literature context of the strict base change itself is
recorded in `StrictBaseChange.md`.
