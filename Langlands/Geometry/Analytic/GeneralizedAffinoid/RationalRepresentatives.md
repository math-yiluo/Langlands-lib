# Changing representatives in a weighted rational presentation

Author: Worker 56.

This module constructs `RationalPresentation.representativeEquiv`, an actual
isometric bounded algebra equivalence between weighted rational quotients
whose chosen denominator and numerator series represent the same elements
of the same base presentation. It also constructs the induced spectrum
homeomorphism over the base spectrum. This is a derived compatibility of the
published quotient construction; it does not assume the rational bounded
extension theorem.

Fix an ultrametric normed field `K`, a finite positive-polyradius presentation
`A`, and a positive polyradius `s : PositivePolyradius (Fin m)`. Let `q` be
`presentationMap K A`, let `r = A.polyradius`, and let `i` be the bounded
inclusion `appendLeft r s K`. Suppose the old weighted series `g`, `g'`
and tuples `f`, `f'` satisfy

```
q(g) = q(g')
q(f(j)) = q(f'(j))  for every j : Fin m.
```

Write `R(g,f)` for the already constructed rational presentation
`algebra K A s g f`. Its carrier is the enlarged series algebra at `r.append s`
modulo the closure of the ideal generated by `i(A.ideal)` and all equations
`i(g) Y_j - i(f(j))`. Its norm is the actual quotient norm. The source and
target here use the identical enlarged series algebra and the identical
radii; only the chosen old series representatives differ.

## The comparison map and inverse

`representativeMap` descends the target quotient map through the source
closed relation ideal. The private lemma `representative_relations_vanish`
verifies its input on both parts of the source relation set. For an element
of the included old ideal, the target quotient map equals the target base
map applied to its zero class in `A`. For a rational equation, preservation
of subtraction and multiplication rewrites its image as

```
baseMap'(q(g)) * fraction'(j) - baseMap'(q(f(j))).
```

The assumed equalities of classes change this to the target fraction
equation, which is zero. The imported `descendRelations` then extends this
vanishing from the relation set to its closed generated ideal using the
closed kernel of the continuous bounded target map. This step does not
require completeness.

`representativeMap_presentationMap` states that every enlarged series has
the same projected representative under the comparison. The map is
contractive: the target quotient map has bound one, and
`norm_descendRelations_le` preserves that bound for the source quotient
norm. `representativeMap_baseMap` proves compatibility with the structural
map on every element of `A` by choosing an old series representative.
`representativeMap_fraction` is the corresponding identity on new quotient
coordinates.

Applying the same construction to the symmetric class equalities gives an
inverse. `representativeMap_inverse` verifies the inverse identity by the
surjectivity of the enlarged-series quotient map. Both composites act as
the identity on all projected enlarged series. `representativeEquiv`
packages these two bounded maps using `BoundedAlgEquiv.ofHomInv`.
The displayed projected-series identity determines the comparison uniquely
because the source quotient map is surjective; no choice of inverse or
coordinate extension is assumed.

`norm_representativeEquiv` combines contraction in both directions with
the inverse identity to prove equality of norms for every source element.
`isometry_representativeEquiv` derives the metric isometry from this norm
identity. The equivalence has the same projected-series, base-map and
fraction-coordinate formulas, exposed as
`representativeEquiv_presentationMap`, `representativeEquiv_baseMap` and
`representativeEquiv_fraction`.

## Spectrum and locus compatibility

`representativeSpectrumHomeomorph` is the existing bounded-equivalence
pullback homeomorphism on the actual spectra. Its direction is

```
BanachSpectrum R(g',f')  ->  BanachSpectrum R(g,f).
```

The theorem `spectrumMap_representativeSpectrumHomeomorph` proves that this
homeomorphism commutes with the maps to `BanachSpectrum A`. Evaluation at
each base element reduces the assertion to
`representativeEquiv_baseMap`.

`generatesUnitIdeal_congr` gives equivalence of the algebraic unit-ideal
predicates, and `locus_congr` gives equality of the weighted inequality
loci in the base spectrum. Both follow by substituting the equal
classes in their existing definitions. No generation condition is needed
for any comparison construction or identity in this module.

## Assumptions and source context

The construction does not assume coefficient completeness, nontrivial
valuation, properness of either ideal, positive variable count, or radii
in the value group. The empty numerator tuple and zero quotient rings are
allowed. Both old and new radii remain arbitrary strictly positive real
numbers. The base presentation itself remains fixed.

The source context is Berkovich, *Non-Archimedean analytic spaces*
(Trieste lectures, 2009): Example 1.2.2(v) and Definitions 1.2.3/1.2.5,
printed/PDF page 4, describe weighted restricted series and spectra; the
quotient-norm paragraph and Definitions 2.1.1–2.1.2 on page 7 describe
affinoid presentations; Exercise 2.2.2(ii), page 9, gives the rational
quotient equations in terms of elements of the base algebra. These pages
were read directly for this contribution. No source-specific errata file
was found in the supplied project or public Library notes.

The representative comparison is a derived algebraic and normed
compatibility, not a separately numbered assertion of that source. Its
proof is the closed-kernel quotient descent and two-contraction argument
implemented above. The source uses complete fields and relative affinoid
series for its analytic-domain theorem. This module uses the already
published direct field-coefficient presentation and proves only that equal
classes give the specified isometric comparison. It does not compare
arbitrary base presentations, identify relative series, prove reverse
spectrum inclusion or analytic-domain representability, or complete the
parent analytic-space/site task.
