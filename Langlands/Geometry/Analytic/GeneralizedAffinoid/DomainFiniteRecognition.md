# Full domain recognition from an actual finite domain cover

This derived construction proves a locality criterion for full represented affinoid domains. Let `f : B → A` be an actual bounded coefficient-algebra map between presented affinoids, with injective spectrum map. Take an actual finite full-domain cover of `A`. Assume that each actual composite `B → A → Aᵢ` represents a full domain in `B`. Then `f` itself represents its actual spectrum image against every finite positive-radius presented affinoid test algebra.

The proof constructs the unique bounded factor, rather than supplying it as data. For a test map `φ : B → R` with spectrum image in the image of `f`, pull back the local domains in `B` along `φ`. Their actual affinoid-pushout quotients form a finite full-domain cover of the unchanged test algebra `R`. The second pushout legs, composed with the original source restrictions, give local bounded factors from `A`.

The key cancellation argument preserves entire algebra maps, including nilpotent information. Spectral injectivity first proves that a competing map has image inside a specified source component. The source component's full universal property factors that map through its actual algebra. The full universal property of the same component over `B` then proves equality of the two bounded factors. Equality of spectrum points is used only for image containment; it is never used as faithfulness of algebra maps.

Apply this cancellation to every full-domain test into two pulled-back cover members. The local factors are compatible as full bounded maps. Existing finite full-domain bounded-map descent glues them in `R`, with a proved global bound. The cover detects equality to prove the equation over `B`; cancellation and the same descent uniqueness prove uniqueness of the factor. The actual spectrum image is closed by compactness. `domainOfFiniteCover` retains exactly `A`, `f`, and that literal image, with the newly proved full representation.

This is internal infrastructure derived from the existing full-domain universal property, actual affinoid pushouts and finite full-domain bounded descent. It supports the local domain argument of Berkovich 1993, Proposition 1.2.13(ii), but asserts no additional original-literature theorem. The finite component representations and spectral injectivity are explicit hypotheses, not assumed output representations for `f`. The coefficient field is complete and ultrametric; arbitrary positive radii, trivial valuations, nonreduced or zero quotients and empty domains remain allowed.
