# Actual bounded pushouts of finite positive-radius affinoid presentations

Let `K` be an ultrametric normed field and `A`, `B`, `C` actual presented
affinoid algebras over `K`. Given actual bounded `K`-algebra homomorphisms
`f : A → B` and `g : A → C`, this internal construction forms an actual finite
positive-radius quotient algebra with bounded maps from `B` and `C`. It proves
their compatibility over `A` and the bounded pushout property into every complete
ultrametric normed commutative `K`-algebra in an independent universe.

Completeness of `K` is not required for this construction. The existing quotient
Banach result supplies completeness of the resulting algebra when `K` is
complete. Arbitrary positive radii, empty coordinate blocks, trivial valuations,
nonreduced algebras, and zero quotients remain allowed.

## The quotient and its actual legs

In namespace `PresentedAffinoidAlgebra.AffinoidPushout`, `representative B b`
chooses a weighted-series representative of the actual quotient element `b`.
`presentationMap_representative` proves that its quotient class is `b`; no norm
estimate for the chosen representative is asserted or needed.

`relations f g` is a set in the weighted Tate algebra on the concatenated
original coordinate blocks of `B` and `C`, with the concatenated original
polyradii. It contains the image of every element of `B.ideal` under
`appendLeft`, the image of every element of `C.ideal` under `appendRight`, and,
for every actual element `a : A`, the difference

`appendLeft (representative B (f a)) - appendRight (representative C (g a))`.

`algebra f g` is the actual quotient by the closure of the ideal generated by
these relations. It uses the existing `ofRelations` construction; the chosen
finite presentation variables and positive radii are unchanged by the quotient.
The relation set need not be finite.

`leftMap` composes the left variable inclusion with the actual quotient map and
descends through `B.ideal`, whose image is among the relations. `rightMap` does
the same for `C.ideal`. `leftMap_presentationMap` and
`rightMap_presentationMap` compute these maps on every original weighted-series
representative. `norm_leftMap_le` and `norm_rightMap_le` prove contractivity for
the actual quotient norms. Their proofs combine the contractivity of the final
quotient map, the isometric coordinate-block inclusions, and the existing
quotient norm descent bound at constant one.

`condition` proves equality of the original composites
`leftMap.comp f = rightMap.comp g`. Evaluate the corresponding displayed
coefficient-identification relation in the quotient, distribute subtraction,
and use `presentationMap_representative` on each side. This is equality of
bounded algebra maps on all actual elements, rather than a criterion based only
on spectrum points. `leftMap_coordinate` and `rightMap_coordinate` identify the
two original coordinate blocks with their exact positions in the new finite
presentation.

## Universal bounded maps

`hom_ext` says that two bounded maps out of `algebra f g` into any normed
commutative `K`-algebra are equal when their composites with both quotient legs
agree. It needs no completeness or ultrametric assumption on that target.
The existing coordinate separation theorem reduces equality to every
presentation coordinate. Splitting the finite appended index into its two
blocks then uses `leftMap_coordinate` or `rightMap_coordinate` and the given
composite equality.

For actual bounded maps `α : B → E` and `β : C → E`, `tuple_bounded` proves the
weighted monomial bound for the concatenation of their original coordinate
images. It combines the existing bounded coordinate-tuple results for each map
with `hasBoundedMonomials_append`. This step allows arbitrary bounded maps;
neither supplied map is assumed contractive.

Now assume `E` is complete and ultrametric as well as a normed commutative
`K`-algebra. `evaluation` is the actual convergent weighted evaluation
homomorphism at this concatenated tuple. `evaluation_left` and
`evaluation_right` identify its composites with the two variable inclusions as
`α` and `β` composed with the original presentation maps. These identities are
proved on each coordinate using the weighted Tate universal property and the
exact appended coordinate formulas.

If `α.comp f = β.comp g`, `evaluation_relations` proves that this evaluation
annihilates all the displayed relations. On each old ideal it uses the
corresponding block identity and the original quotient kernel identity. On each
coefficient difference it uses those block identities, the representative
computation, and the supplied compatibility equality at the original element.
The existing continuous quotient descent then defines `lift` through the full
closed generated ideal. `lift_presentationMap` gives its exact value on every
weighted-series representative.

`lift_comp_leftMap` and `lift_comp_rightMap` recover the two supplied bounded
maps by testing on their original series representatives. `existsUnique_lift`
bundles this existence and uniqueness: the constructed lift has both original
composites, and `hom_ext` proves that any other such bounded map equals it.

## Provenance and scope

This is an internal construction from the actual weighted Tate algebras,
coordinate-block inclusions, closed relation quotients, quotient norm bounds,
weighted evaluation, and coordinate separation already implemented in the
Library. The concatenated tuple proof uses the existing append monomial bound.
It introduces no new original-literature assertion and does not assume a tensor
product, pushout algebra, map extension, or analytic output object as input.

This module proves the displayed bounded universal property into complete
ultrametric targets. It does not yet package a categorical colimit, prove an
actual spectrum pullback, construct intersections of full affinoid domains, or
extend unrestricted analytic atlases and sites. These are subsequent uses of the
constructed quotient and its actual maps.
