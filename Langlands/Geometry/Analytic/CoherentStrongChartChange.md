# Intrinsic bounded compatibility for strong atlas-map data

This internal module works over a complete ultrametric normed field `K` and two actual affinoid atlas presentations in coefficient, ambient-space and index universes `u`, `v`, `w`. The algebras and bounded maps are those of the existing presented-affinoid and `StrongHom` implementations.

`HasCoherentPullbacks f` is a proposition about the supplied bounded pullbacks of `f`. For each original source chart and every two admissible original target charts, it requires `IsMapChartChange` for their two bounded maps. This quantifies over every presented affinoid coefficient algebra, every bounded coefficient change and every factorization through a common original target subchart. It retains equalities of complete bounded algebra maps. It assumes no extended atlas, extended morphism, gluing output or analytic-category equivalence.

`hasCoherentPullbacks_of_saturated` proves the law when the source has all local full domains, using the previously constructed finite-cover recovery. Neither directedness nor target saturation is required. `pullback_eq_changeTargetPullback_of_coherent` uses the universal test uniqueness theorem to identify every supplied pullback with the actual bounded chart-change construction. `hasCoherentPullbacks_iff` proves that these equations characterize the law: the converse substitutes the equations into the already proved universal test property of the constructed change.

`hasCoherentPullbacks_id` proves the law for the identity on every original atlas. Its proof applies the original restriction-overlap theorem to arbitrary coefficient maps into two common subcharts. Thus this example needs no saturation. `ext_of_coherent` compares two coherent families with the same continuous map and one equal admissible bounded pullback per source chart. The preceding recovery equation expresses every other pullback using that selected one, giving equality of the entire dependent family and of the `StrongHom` records.

`mapAffinoidChart_isMapChartChange_of_coherent` proves that applying the original pullbacks preserves the full arbitrary-coefficient chart-change relation on arbitrary source and target atlases. The input consists of two bounded maps from source-chart algebras into one presented affinoid test algebra, the full source chart-change law, and containment of the first map's ambient image in the second chart. No inclusion between those original charts is required. The output is the full target chart-change law for their composites with the original pullbacks.

The implemented proof pulls a finite common-source-chart cover back to each coefficient test. The source universal law identifies the two local input maps. The original `restriction_comm` equations recover the pullbacks from each common source subchart. The intrinsic target coherence law then identifies their restrictions through each requested common target subchart. Finite-cover algebra separation proves equality of the complete bounded maps. This is the previously implemented saturated-source preservation argument with exactly its final coherence input made explicit.

The content is derived internal infrastructure, using the existing bounded chart-change construction, its universal test laws, and the source-saturated recovery. It does not assert that every `StrongHom` on an arbitrary unsaturated source satisfies `HasCoherentPullbacks`, or identify that earlier record's nested-chart compatibility with the full compatibility in Berkovich's strong-morphism definition. Whole-atlas extension and that comparison remain further obligations of the host task. This unit supplies a checkable intrinsic law and its consequences, rather than assuming the missing extension.
