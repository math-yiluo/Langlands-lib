# Rational factorization from spectrum-image containment

Proof author: Worker 36. Publication preparation: Worker 135.

This module proves `RationalFactorization.FactorizationStatement` using the actual rational quotient of the presented strict affinoid algebra. The coefficient field is complete and ultrametric. The original denominator and finite numerator tuple generate the algebraic unit ideal. Test algebras are presented strict affinoids over the same field. Empty tuples, zero quotients, nilpotents and trivial scalar valuations remain allowed.

The proof first shows that the denominator cannot vanish at a point of the rational locus: the inequalities would force all numerator values to vanish, so the point's proper kernel ideal would contain the unit ideal. Pulling back a target spectrum point gives nonvanishing of the image denominator. `isUnit_iff_forall_spectrum_ne_zero` then supplies an actual unit in the target algebra.

For any tuple solving the denominator equations, multiplicativity and strict positivity of the denominator value turn the rational inequalities into spectrum values at most one for every tuple member. The strict-affinoid spectral power-bound theorem bounds all powers. The finite tuple comparison in Tate evaluation converts these bounds to one bound on all monomials. Neither an inverse nor a power bound is supplied as a hypothesis of the final factorization criterion.

Using the inverse of the constructed unit gives a solution tuple. The existing actual-element rational localization extension evaluates the enlarged Tate series, descends to the closed relation quotient, and gives the prescribed base restriction. Its uniqueness theorem, using the original unit ideal, gives uniqueness among all bounded maps with that base restriction. Conversely, a bounded factorization pulls every target spectrum point back to a point of the rational quotient; the quotient equations and coordinate bounds already prove that this point lies over the rational locus.

The closing theorem assembles these implications into the exact statement. The additional `generatesUnitIdeal_iff_no_common_zero` lemma shows that the algebraic premise is equivalent to the absence of common spectrum zeros of the denominator and numerators. In the reverse implication a hypothetical proper generated ideal has a spectrum point annihilating it, contradicting the hypothesis. The corollary `factorization_of_no_common_zero` therefore gives the same unique factorization directly from the source's no-common-zeros premise. This is a proof of the derived target explained in `RationalFactorization/Statement.md`, which cites Berkovich's Trieste 2009 lectures, Definition 2.2.1 and Exercise 2.2.2(ii), p.9. The implementation relies on the separately proved spectrum unit criterion and spectral power bound, and does not assume the desired factorization. It retains unit radii, algebraic unit-ideal generation and strict affinoid tests. It does not claim the full domain property for arbitrary affinoid tests, a relative-series comparison, a structure sheaf, atlas gluing or an etale site.
