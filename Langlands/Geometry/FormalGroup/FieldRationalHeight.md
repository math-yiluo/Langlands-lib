# Recovering an actual kernel-rank height from a field-valued degree

Harris 1997, Appendix, printed p. 112 (PDF p. 38), expresses the height
as the difference of two logarithms of actual kernel ranks for a
local \(p\)-power presentation. The derived field-valued calculation
here uses a global uniformizer-power presentation. It connects its
rational rank ratio with the signed height of the global presentation.

Let \(q>1\) be a natural number and let the source have scalar height
\(H\) at \(\pi\). If a presentation clears a denominator of exponent
\(n\) and has degree \(q^i\), its integral numerator has kernel rank
\(q^{i+nH}\). This rank is a positive integer, so \(i+nH\) is nonnegative.
The same integral numerator therefore gives an actual kernel-rank
presentation of signed height \(i\). The result applies to a
field-valued tensor quasi-isogeny when \(\pi\) is a uniformizer of the
DVR and the target is \(\pi\)-divisible.
