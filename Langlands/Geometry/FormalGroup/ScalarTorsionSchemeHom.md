# Integral formal maps on scalar-power kernel schemes

For formal modules with scalar divisibility, each integral formal
homomorphism \(f\) takes points killed by \(\pi^n\) to points killed by
\(\pi^n\). It acts by the original homomorphism on these points and
commutes with extension of the affine test algebra.

`Hom.scalarTorsionSchemeMap` represents this natural transformation
using the finite projective models of the two kernels. Its affine point
formula recovers the restricted action of \(f\). Identity and
composition follow from the corresponding identities on kernel
points. The same morphisms give natural transformations of the
inclusion and scalar-multiplication diagrams, since \(f\) commutes with
inclusion and with every scalar power.

This is internal functoriality of the scalar-power torsion
construction. It supplies the action of an order endomorphism on
every kernel scheme, where precomposition with that scheme map
acts on relative Cartier characters.
