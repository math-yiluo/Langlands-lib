# Pullback of isometries of split polarized towers

For an affine coefficient map `R → S`, `baseChangeSplitTowerIso` pulls
back an isomorphism between two split towers over `R`. It uses the inverse
source split comparison, the pulled-back isomorphism and the forward
target split comparison. A proof of `FiniteCartierDualExactnessStatement`
forms the actual Cartier dual towers over both rings.

An equation intertwining the full split order actions pulls back through
this composite, by order equivariance of the two comparisons. If the
original isomorphism preserves the tautological polarization on every
finite level and test scheme, the new isomorphism does so on every level
and test over `S`. The test-point pullback equivalence commutes with the
isomorphism and evaluation takes values in the same global units. The
two split comparisons identify those units with evaluations over `S`.

The argument is derived from the pullback comparisons for the split
polarized product in Rapoport–Zink (1996), §6.43, printed p. 309
(PDF p. 321), before (6.17). It gives the target isometry and split order
conditions for changing the affine test in Harris (1997), Appendix,
printed p. 113 (PDF p. 39), C1.
