# Geometric rank one of the actual Drinfeld tangent components

Over an algebraically closed test field, geometric specialness gives a diagonalization by distinct characters. Each vector in a projector image transforms by its lifted character. Any nonzero coordinate of that vector in the geometric diagonalization therefore identifies the two characters. The sum of the projectors is the identity, so each geometric character occurs among the lifted characters. Distinctness and the finite common index set give a bijection of indices. Restricting the corresponding geometric coordinate gives a linear equivalence between the actual projector image and the test field.

This verifies the one-dimensional homogeneous tangent spaces in Drinfeld, *Coverings of p-adic Symmetric Regions* (1976), §2 A–B, printed pp. 109–110 (PDF pp. 3–4), for the actual character components over geometric test fields.
