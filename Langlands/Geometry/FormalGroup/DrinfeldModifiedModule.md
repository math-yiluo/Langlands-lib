# The modified Dieudonné module

The quotient in Drinfel'd's definition uses \(n+1\) copies of the
underlying module, where \(n+1\) is the number of slots in the
construction. The relation at each adjacent pair inserts \(Vx\) in
the first slot and \(-\Pi x\) in the second. The construction takes
the quotient by the sum of the ranges of these insertion maps.

Each slot has a canonical map into the quotient. If \(V\) and \(\Pi\)
commute, the weighted sum with coefficient \(\Pi^{n-i}V^i\) at index
\(i\) kills the adjacent relations and hence defines the map to the
original module. Taking the first slot modulo the image of \(V\)
also kills the relations and gives a surjection. A linear map
intertwining both operators induces the coordinatewise map on
quotients, and it is surjective when the original map is surjective.

These are the quotient and linear maps used before constructing the
fixed-point operator. [V. G. Drinfel'd, *Coverings of p-adic symmetric regions*, 1976, §2B, p. 110](https://doi.org/10.1007/BF01077936)
