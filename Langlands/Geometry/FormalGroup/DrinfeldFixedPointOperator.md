# The fixed-point operator

Given a lift \(L\) of Frobenius to the modified Dieudonné module, add
\(L(x_0)\) to the class of the tuple shifted one place to the left.
A relation involving the first slot is killed when \(L(Vx)\) equals
the class of \(\Pi x\) in the first slot. The other adjacent relations
shift into adjacent relations. This gives the endomorphism whose fixed
elements enter Drinfel'd's construction. A linear map compatible with
the two operators and with the lifts intertwines the resulting
endomorphisms.

If the weighted map to the original module is injective, the relation
for \(L(Vx)\) follows from \(FV=\pi\) and \(\Pi^{n+1}=\pi\).
Both sides have weighted image \(\pi x\).

The construction takes the lift \(L\) as input and implements descent
of the operator through the adjacent relations. [V. G. Drinfel'd, *Coverings of p-adic symmetric regions*, 1976, §2B, p. 110, following Proposition 2.2](https://doi.org/10.1007/BF01077936)
