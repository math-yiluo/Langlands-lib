# Injectivity on arbitrary rational Hom sections

This internal lemma passes from injectivity on basic opens to injectivity on the actual rational Hom sheaf in the nilpotent rigidity proof. Suppose the pullback of a section is zero. The sheafification unit supplies a presheaf representative near each point of the original open. Its pullback represents zero, so near a point lying over the original point the pulled-back tensor itself restricts to zero.

Refine that neighbourhood to the inverse image of a basic open. The surjective map on spectra ensures this basic open lies in the original representative's domain. Naturality and injectivity on basic opens give a zero representative there. These basic opens cover the original open, so sheaf separatedness gives a zero section.
