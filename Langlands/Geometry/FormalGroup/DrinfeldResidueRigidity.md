# Nilpotent rigidity of the actual Drinfeld residue coordinate

Drinfeld's *Coverings of p-adic Symmetric Regions* (1976), §2A, printed p. 109 (PDF p. 3), includes the map from the framing residue field to the actual quotient of the test algebra by the uniformizer. This module shows that this coordinate lifts uniquely across a surjective coefficient map with nilpotent kernel.

The induced map on the two uniformizer quotients is surjective. Its kernel is the image of the original coefficient kernel in the source quotient. To see this, pull the induced kernel back to the original source. The resulting ideal is the inverse image of the target uniformizer ideal, which is the sum of the source uniformizer ideal and the original kernel. Surjectivity of the source quotient map then gives the kernel identity. The image of the original kernel is nilpotent.

The uniformizer generates the maximal ideal of the scalar ring, so each actual uniformizer quotient receives the residue field action. The action restricts to the original scalar action, and an original scalar-linear algebra map between such algebras respects the residue field action by surjectivity of scalar reduction. Over the residue field, the separable algebraic framing field is formally étale. Formal smoothness lifts a residue map and formal unramifiedness gives uniqueness. The resulting equivalence uses postcomposition with the actual induced map on quotients, as in both residue-coordinate functors. The algebraic closure of the finite residue field in the comparison satisfies the separability hypothesis.
