# The kernel of reduction on the modified module

A surjective linear map intertwining Verschiebung and the uniformizer
sends each range of adjacent relations onto the corresponding range
in the target. It therefore maps the entire relation submodule onto
the target's relation submodule.

A class in the kernel has a tuple representative whose image is a
target relation. Lifting that relation and subtracting it gives a
representative with every entry in the kernel of the original map.

Suppose the lift carries an element of that kernel into the first slot
as the uniformizer applied to another kernel element. If the lift
commutes with the uniformizer, each further application on the first
slot adds one power of the uniformizer. The fixed-point operator sends
every later slot one place to the left. Thus if the \((n+1)\)-st power of
the uniformizer kills the original kernel, the \((2n+1)\)-st power of
the fixed-point operator kills the entire reduction kernel when there
are \(n+1\) slots. Compatible lifts on source and target then give a
linear equivalence on fixed submodules via the reduction map.

These algebraic implications apply to the kernel properties needed for
the square-zero step in Drinfel'd's construction. [V. G. Drinfel'd, *Coverings of p-adic symmetric regions*, 1976, §2B, Propositions 2.3–2.4](https://doi.org/10.1007/BF01077936)
