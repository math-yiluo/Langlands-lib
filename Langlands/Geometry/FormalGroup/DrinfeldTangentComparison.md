# Derivatives of actual order-linear maps on Drinfeld tangent components

The derivative of an order-linear formal homomorphism intertwines the two order actions. For each coefficient character, this takes the source eigenspace to the corresponding target eigenspace. These eigenspaces are the actual tangent projector images, so restricting the derivative gives the linear map on each image. When the original map has an order-linear inverse, differentiation of the two inverse equations yields inverse maps on each image.

This constructs the linear maps on the homogeneous pieces of the tangent object in Drinfeld, *Coverings of p-adic Symmetric Regions* (1976), §2 B, printed p. 110 (PDF p. 4).
