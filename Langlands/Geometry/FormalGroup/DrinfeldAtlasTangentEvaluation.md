# Chart evaluation of the split tangent projectors

Let the special atlas be over an affine nilpotent ring with a specified residue coordinate. On a test algebra in one chart, evaluate a compatible tangent vector by the actual map from the universal chart localization. The evaluation intertwines the full formal order action, whose chart representation is the derivative of the original formal endomorphisms.

Fix the atlas's embedded degree-\(d\) unramified coefficient field and a residue embedding into \(\kappa\). The chart test uses the reduction of the structural coefficient map to pull the residue coordinate forward. The character projectors on the compatible module and on the chart tangent module use the split coefficient algebra after tensoring with the base and the test ring. Compatibility of the two cyclic splittings, and the order and scalar formulas on pure tensors, identify evaluation of each global projector with the corresponding chart projector.

This gives the affine chart comparison for the tangent grading in Drinfeld, *Coverings of p-adic symmetric regions* (1976), §2 B, printed p. 110 (PDF p. 4).
