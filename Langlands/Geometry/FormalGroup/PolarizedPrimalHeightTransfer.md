# Scalar height of the split primal target

Rapoport–Zink 1996, (6.17) and Lemma 6.44, printed pp. 309–310 (PDF pp. 321–322), use the primal division summand and the quasi-isogeny on it. This module applies scalar-kernel height transfer to that actual rigidifier when the frame and target division images have coordinate presentations.

Extend the frame image from the residue coefficient ring and reduce the target image along the nilpotent quotient. The restriction of the polarized rigidifier gives a local quasi-isogeny between those image laws. Its target inherits the scalar-kernel rank formula of the primal frame. The target image before reduction is already p-divisible by the formal retraction. Every prime is in the image of the nilpotent-quotient spectrum, so the same ranks hold on the original test algebra.

The result uses the established scalar p-height of the chosen primal frame. It supplies the corresponding p-height of the primal target law, with the normalization by powers of the same prime.
