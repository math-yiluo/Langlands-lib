# Kernels under a change of central scalars

The order action restricted along `C → D` must act on every tangent vector by
multiplication through the structural map `C → R`. Under this condition the
central formal module shares the original commutative formal law and each
acting order endomorphism. Evaluating an order element on the shared nilpotent
points gives the same kernel functor and the same affine fppf lifting
condition. The comparison is the identity on underlying points.

A natural number `a` cast into `O` and `C` has the same image in the order. Its
powers therefore act by the same formal maps. The same representing algebra
computes the finite kernels, so the formula `q^(n*h)` transfers with the same
`q` and `h`. Divisibility by `a` transfers using the same nilpotence, scalar
torsion, and lifting. In the reverse height implication the original law is
assumed divisible by the natural-number scalar.

Drinfeld 1976, §1, printed p. 108 (PDF p. 2), gives the natural tangent
condition. Section 2A, printed p. 109 (PDF p. 3), uses the height condition.
Section 3, printed p. 111 (PDF p. 5), computes the kernel rank for the universal
special module. The change-of-scalars result here is derived transport of the
Library's `HasPiHeight` predicate.
