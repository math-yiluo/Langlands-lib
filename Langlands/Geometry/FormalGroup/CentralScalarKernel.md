# Kernels under a change of central scalars

A change of central scalar ring on an order action keeps the original commutative formal law and each acting order endomorphism. Evaluating an order element on the same nilpotent points gives the same kernel functor as a functor of sets, and the same lifting condition. The natural kernel comparison is the identity on underlying points.

Natural-number scalars agree in the order. Therefore their powers give the same formal maps with either central scalar ring. The same representing algebra computes the finite kernels, so the rank formula transfers with it. Divisibility by a natural-number scalar also transfers, using the same nilpotence, point lifting and scalar torsion. In the other direction the kernel rank formula transfers back if the original law is already divisible.

This is a comparison of the scalar-kernel height in Drinfeld 1976, §1, printed pp. 108–109, for the underlying p-divisible law and the central formal module law of a split summand.
