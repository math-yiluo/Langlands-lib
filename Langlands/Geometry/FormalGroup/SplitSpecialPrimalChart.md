# Special formal division-module charts of the primal image

Drinfeld 1976, §2 A, printed p. 109, uses a special formal module for the division order of dimension equal to the reduced degree. Rapoport–Zink 1996, §6.43 and (6.17), printed pp. 308–309 (PDF pp. 320–321), impose the special tangent condition on the primal factor of the split polarized object.

Start with a principal neighbourhood supporting coordinates for the actual formal division projector. Take the residue field at the base point and embed it in an algebraically closed field. The chosen principal element is invertible there, so this gives a field test on the chart. The chart's tangent identifies with the actual division tangent on that field. Its character decomposition forces the number of chart coordinates to equal the reduced degree.

The action of the central integer ring on the same formal group has the required structural tangent. The induced division order action retains the multiplicity-one characters, so the chart is a `SpecialModule` in the existing coordinate definition. Every point of the affine split-special target has such a chart. This construction supplies the formal module and the tangent condition. A finite-height certificate for its scalar kernels is an additional part of the Drinfeld moduli input.
