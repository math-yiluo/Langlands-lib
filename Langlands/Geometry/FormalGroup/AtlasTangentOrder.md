# The full order action on the compatible tangent module

Let a ring act on the chart laws of a finite-coordinate formal atlas over a commutative algebra, extending the scalar formal module action and commuting with the formal chart transitions. Differentiating gives linear operators on each test chart. The coefficient maps commute with these operators because the linear coefficients are obtained using the unique localization lifts. Differentiating the formal order-commutation equations shows that the chart transitions intertwine the operators.

The order therefore acts on tuples satisfying the tangent overlap equations. `tangentAction` is the ring map to the endomorphisms of this test-algebra module. The ring identities are verified componentwise using the tangent representations of the actual chart actions.

For the full division order this is the underlying order action for the tangent sheaf in Drinfeld, *Coverings of p-adic symmetric regions* (1976), §2 B, printed p. 110 (PDF p. 4).
