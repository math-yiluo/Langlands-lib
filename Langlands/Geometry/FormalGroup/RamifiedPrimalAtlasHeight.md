# Square height of the ramified split primal atlas

Let \(p=u\varpi^e\) with \(u\) an integral unit and \(e>0\). For every \(n\), the scalar map for \(\varpi^n\) and the scalar map for \(u^n\varpi^{(e-1)n}\) compose in both orders to multiplication by \(p^n\). The isogeny theorem for scalar composites over an arbitrary ring supplies the finite locally free kernel of \(\varpi^n\) from \(p\)-divisibility.

On a primal chart, the actual local rigidifier transfers the \(p\)-height of the given primal frame. The scalar composite argument supplies every required uniformizer kernel on the chart. For residue cardinality \(p^f\), the ramification and residue normalization then give the uniformizer height \(d^2\). `primalHeightSquaredAtlas` packages the actual split target atlas with the resulting square-height certificate.

The normalization is that of Drinfeld 1976, §2 A, printed p. 109. This is the primal formal module in Rapoport–Zink, (6.17) and Lemma 6.44, printed pp. 309–310.
