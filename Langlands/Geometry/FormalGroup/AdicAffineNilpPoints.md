# The affine formal spectrum on affine Nilp tests

An affine chart consists of an algebra complete for an ideal of definition containing the base parameter. Each quotient by a positive power of the ideal is a test on which that parameter is nilpotent. The algebra reductions from thicker quotients to thinner ones induce the maps in a directed diagram of representable point functors.

The affine formal spectrum on Nilp is the colimit of that diagram. On an affine test this uses ordinary maps to the spectra of the quotient algebras, written contravariantly as algebra homomorphisms. The colimit maps retain the compatibility of the finite quotients.

This implements the affine-test part of Rapoport and Zink, *Period Spaces for p-divisible Groups* (1996), §2.1, printed p. 49 (PDF p. 64). Harris uses formal schemes over the completed unramified base to represent the polarized moduli problem in his 1997 Appendix, printed p. 113 (PDF p. 39).
