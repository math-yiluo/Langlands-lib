# The norm-trivial count and the trace conductor formula in characteristic zero

This module proves the two premises of `cuspidalSigmaLiftConductorFromArbitraryTraceEpsilon` for actual nonarchimedean local fields `F` of characteristic zero. It then removes them from that reduction.

- `traceAdditiveConductorFormula : TraceAdditiveConductorFormulaStatement`. Let `E` be a finite `F`-algebra with the module topology, residue degree `f` (`IsResidueDegree`) and different exponent `d` (`IsDifferentExponent`). For nontrivial additive characters with `ψE x = ψF (Tr_{E/F} x)`, Tate's additive conductors satisfy `f · n(ψE) = [E:F] · n(ψF) + f · d`.
- `normTrivialCount : NormTrivialCountStatement`. If `IsCyclicAlgebra σ l`, every finite set consisting exactly of the characters `Fˣ →* ℂˣ` trivial on `N_{E/F}(Eˣ)` has `l` elements.
- `IsCyclicAlgebra.isAbelianGalois`. A field that is a cyclic algebra of degree `l` is an abelian Galois extension. `IsCyclicAlgebra.isGalois` gives the Galois property, and `σ` has order `l = [E:F] = |Gal(E/F)|`, so it generates the Galois group.
- `charZeroTraceConductorPremises` records both statements. `cuspidalSigmaLiftConductorFromArbitraryTraceData` proves `CuspidalSigmaLiftConductorFromArbitraryTraceDataStatement`: the arbitrary-character local epsilon data `CuspidalSigmaLiftArbitraryTraceEpsilonDataStatement` imply the exact four-universe `CuspidalSigmaLiftConductorStatement`.

Both proofs use the same realization as the characteristic-zero epsilon assembly. `CharZeroLocalField.padicField F` is a `PadicField` whose carrier is `F`, over the residue characteristic `p`; `topologicalData F` keeps the field's own topology and value relation. `E` becomes `PadicField.ofField E` through the composite `ℚ_p`-algebra structure, and `suppliedPadicExtension` supplies its topological data from the module topology. All instances agree definitionally with the ambient ones, so the hypotheses are passed unchanged. The trace formula is then `residueDegree_mul_additiveConductor_of_trace` (module `PadicNormTwistFactorComparison`). Its proof scales `ψF` to conductor zero, applies the published trace-codifferent computation and compares valuations through the norm. `toLocalFieldData_additiveConductor` identifies the two conductor normalizations. The count is `card_of_mem_iff_isNormTrivial` (same module): the norm subgroup has index `[E:F]` by local class field theory, so the characters of the finite quotient number `[E:F] = l`.

This internal module serves the proof of the conductor identity `CuspidalSigmaLiftConductorStatement` (Arthur–Clozel, Ch. 1, Prop. 6.9(ii)). It proves no epsilon identity and constructs no epsilon data, globalization or global lift. The remaining premise, `CuspidalSigmaLiftArbitraryTraceEpsilonDataStatement`, is open; it contains the cross-field epsilon comparison.
