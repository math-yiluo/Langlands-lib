# Base change on spherical two-block constant terms

Suppose the normalized radical integrals of a spherical function and its
base change are given as finite sums of spherical products on the two-block
Levis. Applying lower-rank base change to the factors of the extension-field
sum gives the base-field sum pointwise. The statement uses the actual
two-block coordinates and Haar measures of mass one on integral rectangles.

Concatenate arbitrary ordered Satake tuples on the two blocks. The
two-block Satake evaluation formula turns the value on each ambient
function into the sum of products of the block evaluations. Raising the
concatenated tuple to the base-change degree raises each block tuple
to that degree. The three base-change homomorphism identities therefore
give equality for every pair of block Satake evaluations.

For each fixed first-block Satake character, separation on the second block
gives equality of the partially evaluated spherical functions. Evaluating
that equality at any second-block group element and using separation on
the first block gives equality of the actual functions. This implements
the evaluation argument of Laumon (1996), Lemma 4.2.4, for the supplied
finite expansions.
