# Ordinary regular character values

These derived lemmas supply the ordinary character evaluations in the forward implication of Henniart–Lemaire (2011), II.2.9 and II.2.11. The local value is expressed as an equality of distributions on the Library's test functions.

For a test supported on a conjugate of the ordinary character neighborhood, its pullback is supported in the original neighborhood. The character and the Haar integral of the pullback both have the same positive modular factor, by the published modular transport formulas. Cancelling that factor gives evaluation on the conjugate neighborhood with the original value. The difference between the character and this scalar times the Haar distribution restricts to zero on each conjugate. The Library's open-restriction locality theorem extends the evaluation to all tests supported in their union.

The ordinary regular character value also follows from the twisted regular-value premise in degree one. The extension is the field itself, the twist and intertwiner are identities, and the degree-one norm is the element itself. Each regular ordinary element is thus associated with itself. The Library's identity-twist comparison turns the resulting twisted local value into an ordinary local value.
