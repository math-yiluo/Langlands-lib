# Separated standard factors of an actual supercuspidal orbit product

`OrbitStandardFactorSeparationStatement` concerns a finite extension of
local fields with the given relative module topology and a
characteristic-zero base. It assumes an irreducible supercuspidal first
block and an actual equivalence of the supplied positive-rank upper
representation with the normalized sigma-orbit product, using the given
rank equality.

The proof supplies finite p-adic data on the original field carriers and
uses the standard factor certificates for the actual Galois-conjugate
blocks. The forward and reflected dual block products have disjoint
nonzero roots. Whittaker type gives each block epsilon certificate. The
separated-product theorem computes the actual induced epsilon and forward
polynomial. Gamma multiplicativity then gives the induced
inverse-transpose dual polynomial. The usual rank cast for normalized
block induction and the supplied equivalence transport all three
certificates to the given upper representation. The original residue
cardinality gives the same reciprocal reflection.

This is the standard-factor calculation for the upper representation in
the completed-equation argument of Arthur–Clozel, Chapter 1, proof of
Proposition 6.9(ii), printed pp. 69–70. It uses the induced standard
factor relations of Jacquet–Piatetski-Shapiro–Shalika, Theorem (3.1),
printed pp. 404–405.
