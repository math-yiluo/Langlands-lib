# Cyclic norms and block centralizers

This algebraic input for parabolic descent uses the Library's standard block Levi and
cyclic norm. If two blocks have coprime characteristic polynomials, Cayley–Hamilton
and a Bézout identity force any rectangular intertwiner between them to be zero.
The matrix equation for an ambient centralizer element gives such an intertwiner on
every off-diagonal block. Coprimality persists under scalar extension.

When a twisted representative has cyclic norm exactly equal to the scalar extension
of an ordinary block diagonal element, that norm is fixed by the field automorphism.
The cyclic norm identity forces the given representative to commute with its norm.
The off-diagonal vanishing then puts this very representative in the Levi with the
exact norm equality on every block. For a norm association given up to conjugacy,
the conjugating element first yields such an exact representative. Conversely the
block association witnesses assemble under the block diagonal embedding. The same
off-diagonal vanishing places the ordinary centralizer inside the Levi.

These lemmas provide the algebraic step for the reduction to a proper Levi in
Arthur–Clozel (1989), Chapter 1, Theorem 4.5, and Henniart–Lemaire (2011), I.6.6.
