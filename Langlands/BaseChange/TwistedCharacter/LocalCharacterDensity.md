# Local character densities and conjugacy

`IsCharacterDensityOn` is the neighborhood form of `IsCharacterFunction` for an admissible complex representation of a locally profinite group. It uses local integrability on the given subset and the character identity for tests supported in that subset. It quantifies over left Haar measures on the Borel space. On a second-countable group, `isCharacterDensityOn_of_oneHaar` obtains this property from the identity for any one Haar measure. Haar uniqueness identifies a second measure as a positive scalar multiple. Integrating scalar coefficients shows that the integrated action scales by this scalar, and the same scaling applies to the trace and density integral.

`IsCharacterDensityOn.conjugate` pulls an open-neighborhood density back along conjugation. For a fixed Haar on the new neighborhood, use its conjugation pushforward on the original neighborhood. Transporting a test in the opposite direction conjugates the integrated action by the representing linear equivalence. The finite-rank trace and the density integral then give the identity for the composed function. Local integrability is transported by the same measure map.

`exists_characterFunction_of_conjugacyClosure` assumes a set meeting every conjugacy-orbit closure and a local character density near each point of that set. Each such neighborhood contains a point of the corresponding orbit. Pullback by a conjugating element provides a local density near the starting point. The clopen gluing theorem gives one global density for all Haar measures. If each local density is locally constant at the points of a conjugation-invariant subset in its neighborhood, the global density has the same property. In semisimple descent the input set is the semisimple locus. This is the local-to-global argument following Clozel's Lemma 8. [Clozel, *Characters of non-connected, reductive p-adic groups*, §3.4, p. 156](https://doi.org/10.4153/CJM-1987-008-3)
