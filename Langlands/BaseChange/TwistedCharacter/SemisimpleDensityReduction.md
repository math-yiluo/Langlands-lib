# Twisted character integrability from semisimple local densities

`TwistedCharacterFromSemisimpleDensityStatement` reduces the twisted character theorem to local character densities near the adjoint semisimple points of the actual cyclic extensions of `GL_n(E)`. The premise asks for a locally integrable representing density on an open neighborhood of each such point for each irreducible admissible representation of the extension, using a common representative for all left Haar measures. The local constancy in the conclusion concerns the σ-regular set in the generator component. The field, coefficient algebra and representation universes are independent.

Normalize the intertwiner by a scalar, form the ordinary character of the cyclic extension, and use the semisimple orbit-closure theorem to globalize its local densities. Restriction to the generator coset gives the twisted density, and scaling recovers the input intertwiner. The σ-regular locus is open and the regular values theorem gives actual local values there for the original twisted distribution. Almost-everywhere modification to these values provides the locally constant representative for every Haar normalization. [Clozel, *Characters of non-connected, reductive p-adic groups*, §3.4 and Lemma 8, pp. 154–156](https://doi.org/10.4153/CJM-1987-008-3)
