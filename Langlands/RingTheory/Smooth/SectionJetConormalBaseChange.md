# Arbitrary scalar extension of section conormals

For an augmented commutative algebra over `R` and any commutative
`R`-algebra `B`, `baseChangeConormalEquiv` identifies the scalar extension
of the augmentation conormal module with the conormal module of the
base-changed section. It sends the tensor of a scalar and the class of an
augmentation element to the class of their tensor.

The comparison on first jets commutes with arbitrary scalar extension.
Splitting both first jets along their sections identifies that comparison
as the identity on the base summand together with the conormal comparison.
The calculation on representatives determines the map on the actual
augmentation classes. This is the affine conormal base-change input to
SGA 3, Exposé XV, Lemma 5.4.
