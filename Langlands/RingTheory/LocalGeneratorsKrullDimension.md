# Krull dimension bounded by generators of a primary ideal modulo a power

Author: Worker 372.

This internal helper module works in a Noetherian local ring `O` with maximal ideal `𝔪`.

## Declarations

- `maximalIdeal_pow_le_span`: for a family `b : ι → O` and `c : ℕ`, if
  `𝔪 ^ c ≤ span (range b) ⊔ 𝔪 ^ (c + 1)`, then `𝔪 ^ c ≤ span (range b)`. This is Nakayama's
  lemma (`Submodule.le_of_le_smul_of_le_jacobson_bot`). The hypothesis says
  `𝔪 ^ c ≤ span (range b) ⊔ 𝔪 • 𝔪 ^ c`, and the Jacobson radical of `O` is `𝔪`.
- `ringKrullDim_le_card`: if moreover `ι` is finite and every `b i` lies in `𝔪`, then
  `ringKrullDim O ≤ Fintype.card ι`. Proof: by the previous lemma `𝔪 ^ c` lies in the ideal
  generated by the finite set `b '' univ`. That ideal lies in `𝔪`. So `𝔪` is a minimal prime over
  it: a prime containing it contains `𝔪 ^ c`, hence `𝔪`. Krull's height theorem
  (`Ideal.height_le_card_of_mem_minimalPrimes_span_finset`) bounds the height of `𝔪` by the
  number of generators. The height of `𝔪` is `ringKrullDim O`
  (`IsLocalRing.maximalIdeal_height_eq_ringKrullDim`).
