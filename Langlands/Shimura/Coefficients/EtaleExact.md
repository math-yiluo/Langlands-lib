# Exact associated étale coefficient sheaves and coefficient homology

The existing `etaleAssociatedFunctor` constructs actual module sheaves
by taking invariants of the diagonal action on the product with a cover.
This module proves that this functor preserves finite limits, finite
colimits, and homology when the cover is a genuine finite geometric
torsor. It then constructs the canonical homology isomorphism for the
already implemented associated-complex functor, including its naturality
and preservation of quasi-isomorphisms.

## Provenance

This is an internal categorical derivation from the published
`Etale`, `AssociatedComplex`, `TrivializationFromSplitting`,
`TorsorSectionSplittingProof`, and `EtaleCoverComparisonProof`
constructions, together with `Langlands.Sheaf.SliceExact`.
The geometric section-splitting theorem supplies the existing natural
trivialization; no comparison is supplied as an assumption.
The new homology isomorphism specializes the public generic
`Langlands.Cohomology.mapHomologicalComplexHomologyIso` from
`Cohomology/DivisibleSystem/InverseLimit`. Only that generic construction
is used from that module; no inverse-limit theorem is invoked.
There is no new external-source claim or identification with a theorem
of Harris.

## Genuine inputs and universes

The inputs are an actual scheme `X : Scheme.{u}`, a commutative ring
`R : Type u`, a group `G : Type u`, and an action `Y : Action X.Etale G`.
The explicit hypothesis `hY : IsFiniteGeometricTorsor X Y` requires:

- `G` is finite;
- the structure morphism of the actual étale object `Y.V` is finite
  and surjective;
- on geometric lifts over the same base point, the deck action has
  a unique group element carrying one lift to the other.

The functor is exactly

```text
F = etaleAssociatedFunctor (R := R) X Y :
  Action (ModuleCat.{u} R) G ⥤
    Sheaf X.smallEtaleTopology (ModuleCat.{u} R).
```

The coefficient modules have universe `u`. The complex degree type
`ι : Type uι` has an independent universe, and `c : ComplexShape ι`
is arbitrary. Neither finite coefficient modules nor invertibility
of the order of `G` in `R` is assumed.

## Exactness certificates and implemented proof

`etaleTorsorPullbackReflectsIsomorphisms` proves that

```text
L = X.smallEtaleTopology.overPullback (ModuleCat.{u} R) Y.V
```

reflects isomorphisms. The surjectivity in `hY` gives the singleton
covering condition by `etale_coversTop_of_surjective`, and
`Langlands.Sheaf.overPullbackReflectsIsomorphisms` supplies the conclusion.
This is conservativity of restriction to the cover.

`etaleAssociatedFunctorPreservesFiniteLimits` and
`etaleAssociatedFunctorPreservesFiniteColimits` prove the corresponding
preservation classes for `F`. The actual geometric section-splitting
theorem and `constantAssociatedTrivializationOfSplitting` give

```text
F ⋙ L ≅ Action.forget (ModuleCat R) G ⋙ constantSheaf ⋙ L.
```

The forgetful functor preserves finite limits and finite colimits.
Constant sheaf formation preserves finite limits through its
definition as the constant-presheaf functor followed by sheafification.
It preserves colimits by `constantSheafAdj`, using the actual terminal
object `Scheme.Etale.mk (𝟙 X)` and `etaleIdIsTerminal X`.
The right-hand composite therefore preserves finite limits and finite
colimits. `SliceExact` proves the same preservation for `L`, and its
conservativity makes it reflect these finite constructions. Mathlib's
reflection lemmas transfer preservation from `F ⋙ L` to `F`.

`etaleAssociatedFunctorPreservesHomology` then packages the kernel and
cokernel preservation as Mathlib's `Functor.PreservesHomology`.
These certificates retain `hY` as an explicit argument rather than
installing a global instance that would silently require a torsor proof.
For example, a consumer can locally install the result with
`have := etaleAssociatedFunctorPreservesHomology X Y hY`.

## Canonical homology comparison

Let `Hq` denote the categorical homology functor in degree `q`. The new
definition `etaleAssociatedHomologyIso X Y hY c q` has type

```text
etaleAssociatedComplexFunctor X Y c ⋙ Hq_sheaves
  ≅ Hq_representations ⋙ etaleAssociatedFunctor X Y.
```

At a coefficient complex `K`, it is the canonical isomorphism

```text
Hq(F_*(K)) ≅ F(Hq(K)).
```

The source category of coefficient actions and the target category of
module sheaves are the actual abelian categories supplied by Mathlib.
The component is the existing `(K.sc q).mapHomologyIso F`, constructed
from preserved kernels and cokernels. Naturality is inherited from
`mapHomologicalComplexHomologyIso`.

`etaleAssociatedHomologyIso_naturality` exposes that compatibility
for a chain map `f : K ⟶ L`:

```text
Hq(F_*(f)) ≫ e_L = e_K ≫ F(Hq(f)).
```

Its reassociated version is generated by `@[reassoc]`.
Finally, `etaleAssociatedComplexFunctor_preserves_quasiIso` proves
that a coefficient quasi-isomorphism maps to a sheaf
quasi-isomorphism, using Mathlib's homology-preservation theorem.

## Scope retained

This construction concerns one supplied finite geometric torsor and
homology in the category of sheaves. It does not construct a Shimura
scheme or its level tower, or the genuine torsors needed to specialize
those objects. It does not prove exactness of global sections or
identify sheaf homology with étale cohomology groups. No preservation
of infinite limits, inverse-limit comparison, derived completion,
compact-support comparison, Galois action, smooth group action, or
Harris cohomology theorem is asserted. Varying-cover diagram exactness
and its additional categorical compatibility remain separate
constructions.
