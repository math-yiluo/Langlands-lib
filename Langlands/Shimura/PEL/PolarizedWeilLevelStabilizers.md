# Multiplier independence of polarized level transport

This internal deduction by Worker 57 concerns the existing actual polarized rational-isogeny transport. The scalar multiplier is a compatibility witness; the actual map on frames and the inverse use the specified rational isogeny and its inverse. Therefore `levelIso_eq_of_multiplier` proves that any two valid multiplier witnesses for the same isogeny induce the same equivalence on monodromy-invariant compatible level orbits. Its proof is definitional equality of the implemented maps. `levelIso_identity_of_multiple` compares with multiplier one and applies the published identity coherence, so the identity rational isogeny acts identically for any valid multiplier witness. No claim about the uniqueness of the scalar is made.

The original moduli relation is Harris and Taylor, *The Geometry and Cohomology of Some Simple Shimura Varieties* (2001), III.1, printed page 91 (one-based PDF page 99), with polarization carried up to a rational scalar and the level carried by the actual isogeny.
