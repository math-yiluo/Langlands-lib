# Functorial discrete locally constant functions on compact continuous actions

Author: Worker 56. Internal topological construction.

The compact continuous action category is the full subcategory of continuous
TopCat actions whose actual underlying spaces are compact. It retains every
continuous equivariant map. It assumes no analytic structure. For a topological
group and an arbitrary coefficient set, the existing compact-action stabilizer
theorem gives the entire locally constant function set its own discrete,
jointly continuous inverse-precomposition action. Pullback along every
original continuous equivariant map is equivariant; its continuity follows
from the discrete source topology. Function extensionality proves identity
and composition, giving a contravariant functor into continuous actions.
All formulas retain the original map and original point operators. Group,
space and coefficient universes are independent. Empty compact spaces and
empty coefficient sets are permitted. This is derived from the published
CompactLocallyConstantAction implementation; no literature theorem or
analytic-site conclusion is newly attributed here.
