# Compatibility of the supplied additive right uniformity

Worker 100 states
`Langlands.LocalClassField.NYLL.SuppliedUniformityCompatibilityStatement.{u} : Prop`
for arbitrary universe `u`. Its internal quantifiers range over every natural
number `p` with `[Fact p.Prime]`, every `F : PadicField.{u} p`, and every
supplied `T : F.TopologicalData`.

The proposition locally installs `T.topology`, `T.valuativeRel`, and
`T.localField`, in that order. It asserts the conjunction

```lean
(suppliedUniformSpace T).toTopologicalSpace = T.topology ∧
  (letI := suppliedUniformSpace T
   IsUniformAddGroup F.Carrier)
```

The second conjunct uses exactly the uniform structure named by the imported
`suppliedUniformSpace T`. The algebraic operations come from `F.field`. There
is no existential choice of a uniform structure and no compatibility premise.
The supplied realization is arbitrary; no canonical realization is substituted.

## Construction and local-field compatibility

The imported adapter unfolds to
`IsTopologicalAddGroup.rightUniformSpace F.Carrier` under the three supplied
instances. Mathlib's generated additive constructor retains its input topology
as its `toTopologicalSpace` field. Its uniformity is the comap of the
neighborhoods of zero along `fun xy => xy.2 + -xy.1`, using that same topology.
Thus the named adapter's underlying topology is definitionally `T.topology`.

Consequently `T.localField` is directly usable as
`IsNonarchimedeanLocalField F.Carrier` after installing `T.valuativeRel` and
`suppliedUniformSpace T`, even when the topology is obtained from that uniform
structure. No additional transport or local-field compatibility conjunct is
needed. The explicit topology-equality conjunct still records the intended
interface for later consumers.

## Provenance and scope

This is an internally derived compatibility target for Worker 448's published
adapter in [SuppliedUniformity.lean](SuppliedUniformity.lean). It uses the same
Mathlib route as `Langlands.PadicField.TopologicalData.fieldT2` in
[LocalField.Topology](../../../LocalField/Topology.md): that certificate installs
the supplied data, the additive right uniformity, and
`isUniformAddGroup_of_addCommGroup`. The original `fieldT2` proof is by Worker 6,
with its shared interface by Worker 26.

The relevant Mathlib definitions are in
`Mathlib/Topology/Algebra/IsUniformGroup/Defs.lean` at commit
`5ed2965256430c3649e86755f9576b54eca72435`, used with Lean 4.34.0.
The additive constructor is generated by `to_additive`; its elaborated body
retains the original topological-space argument.

This module contains one Prop-valued definition and no proof of that target.
It introduces neither another uniform-space construction nor a global instance.
It supplies a prerequisite statement for the NYLL extension-uniformity route;
it makes no normalization, inertia, reciprocity, or extension-valuation claim.
No external NYLL source is copied or cited as proving this statement.
