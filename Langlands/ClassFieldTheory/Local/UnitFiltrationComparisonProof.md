# The two unit filtrations agree

Lean module: `Langlands.ClassFieldTheory.Local.UnitFiltrationComparisonProof`. It imports the
Library modules `Langlands.ClassFieldTheory.Local.FiniteConductorStatement`,
`Langlands.LocalField.Normalization.Proof` and
`Langlands.ClassFieldTheory.Local.UnitFiltrationStructuralProof`.

## Main result

- `Langlands.LocalClassField.unitFiltrationComparison : UnitFiltrationComparison.{u}`. This
  proves the published statement `UnitFiltrationComparison` (module
  `FiniteConductorStatement`): for every p-adic field `F`, every realization
  `T : F.TopologicalData` and every `n : ℕ`, `T.unitFiltration n = T.principalUnits n`.
  - `T.unitFiltration n` (module `ClassFieldTheory.Local.Units`) is the image in `Fˣ` of the
    integer units congruent to `1` modulo the `n`th power of the maximal ideal of
    `T.Integers`. It is the kernel of reduction modulo `m^n`.
  - `T.principalUnits n` (module `HarmonicAnalysis.Conductor`) is the set of `u ∈ Fˣ` with
    `v(u) = 1` and `v(u - 1) ≤ exp(-n)`, for the discrete valuation `v = T.discreteValuation`.

  The equality includes `n = 0`. There `m^0` is the whole ring, both sides are the integer
  units, and the condition `v(u - 1) ≤ 1` is automatic.

## Supporting results (namespace `Langlands.PadicField.TopologicalData`)

- `filtrationValuationIntegers` (imported from `UnitFiltrationConductor`): `T.Integers` is the ring of integers of
  `T.discreteValuation`, in the sense of Mathlib's `Valuation.Integers`.
- `integralUniformizer T`, the named definition: the chosen uniformizer `T.uniformizer`, as an
  element of `T.Integers`. `integralUniformizer_coe` records its value.
- `maximalIdeal_eq_span_integralUniformizer` and `integralUniformizer_irreducible`: the maximal
  ideal is generated by it, and it is irreducible. The proof uses `v(π) = exp(-1)` and the
  description of units as the elements of valuation `1`.

  The chosen-uniformizer generation and irreducibility results expose the same
  facts as the corresponding private normalization helpers. The valuation witness
  is shared with the existing public unit-filtration comparison.
- `mem_maximalIdeal_pow_iff_discreteValuation_le n x` (imported from `UnitFiltrationConductor`): an integer `x` lies in `m^n` if and only if
  `v(x) ≤ exp(-n)`. This is Mathlib's
  `Valuation.Integers.maximalIdeal_pow_eq_setOfPred_le_v_algebraMap_pow` with the irreducible
  chosen coordinate uniformizer.
- The Library lemma `mem_congruenceUnits_iff` (module `UnitFiltrationStructuralProof`) says that
  an integer unit `a` lies in `T.congruenceUnits n` if and only if `a - 1 ∈ m^n`.
- `unitFiltration_eq_principalUnits T n`: the equality for one realization.
  - Forward: a congruence unit `a` has valuation `1`, since it is a unit of the integer ring,
    and `v(a - 1) ≤ exp(-n)` by `mem_maximalIdeal_pow_iff_discreteValuation_le`.
  - Backward: `u` with `v(u) = 1` and its inverse are integers, so `u` comes from an integer
    unit. It is a congruence unit by the same two lemmas.

## Sources

Serre, *Local Fields*, Chapter IV, §2 (printed pp. 65–66, PDF pp. 72–73): the unit groups are
`U_L^{(0)} = U_L` and `U_L^{(i)} = 1 + 𝔭_L^i` for `i ≥ 1`. The Lean statement says that the
Library's two constructions of this filtration agree: the kernel of reduction modulo `𝔭^i`,
and the valuation condition. No other source is used.

The integrated module imports `UnitFiltrationConductor` for `filtrationValuationIntegers`, `mem_maximalIdeal_pow_iff_discreteValuation_le`, `unitFiltration_eq_principalUnits` and the unchanged exact `Langlands.LocalClassField.unitFiltrationComparison` proof. It retains the chosen integral uniformizer and its generation and irreducibility lemmas.
