This module defines the closed proposition
`Langlands.LocalClassField.TotallyRamifiedIntegerMonogeneity.{u,v}`.
It states the algebraic generation assertion and supplies no proof of it.

## Quantifiers and total ramification

For every natural number `p` with `[Fact p.Prime]`, the proposition quantifies
over `F : PadicField.{u} p` and `L : PadicField.{v} p` at independent arbitrary
universe levels. It retains every supplied `Algebra F.Carrier L.Carrier`,
its compatibility instance `IsScalarTower (Padic p) F.Carrier L.Carrier`,
and `[FiniteDimensional F.Carrier L.Carrier]`. Thus the field embedding in the
conclusion is always the supplied one.

Write `TF = F.canonicalTopologicalData`, `TL = L.canonicalTopologicalData`,
and `n = Module.finrank F.Carrier L.Carrier`. The one arithmetic hypothesis is

```text
TL.ramificationIndex = n * TF.ramificationIndex.
```

These are absolute ramification indices over `Padic p`, defined by the
normalized additive orders of the rational prime `p`. The relative
ramification index `e(L/F)` satisfies
`e(L/F) * e(F/Padic p) = e(L/Padic p)`. Since the absolute base index is
positive, the displayed equality encodes `e(L/F) = [L:F]`, Serre's
total-ramification hypothesis. Canonical finite p-adic extensions have their
complete discrete valuations, and the restriction of the canonical valuation
of `L` along the supplied compatible embedding agrees with that of `F`.
These facts explain the specialization of the source theorem; this statement
module does not prove the relative-index comparison or the source theorem.

The degree is unrestricted. In particular, degree one is included, with no
prime-degree, Galois, or ramification-group hypothesis. The canonical
topological data already carry the local-field structures needed to define the
integer rings, additive orders and supplied-uniformizer coordinates. No extra
topological or local-field instance is an outer premise.

## Actual integer scalars and every supplied uniformizer

Inside the proposition the local instance is exactly
`PadicField.TopologicalData.relativeIntegerAlgebra TF TL`. Its algebra map
is `relativeIntegerMap TF TL`, the restriction of the supplied field map
`algebraMap F.Carrier L.Carrier` to the two valuation integer rings.
`TF.Integers` and `TL.Integers` are the actual integer subrings of the
canonical valuations.

After the total-ramification hypothesis, the proposition quantifies over
every `π : L.Carrier` and every witness `hπ : TL.ord π = 1`.
The convention for `ord` at zero is zero; consequently this hypothesis
excludes zero. The imported definition `TL.coordinateUniformizer π hπ`
is an element of `TL.Integers` whose field value is precisely `π`,
as proved by `coordinateUniformizer_coe`. It uses the supplied element.
The imported theorem `maximalIdeal_eq_span_coordinateUniformizer` confirms
that this element generates the actual maximal ideal.

## Conclusion

The conclusion is the literal equality

```text
Algebra.adjoin TF.Integers {TL.coordinateUniformizer π hπ}
  = (top : Subalgebra TF.Integers TL.Integers).
```

`Algebra.adjoin` is Mathlib's smallest subalgebra containing the indicated
singleton. Thus every element of the extension integer ring belongs to the
algebra generated by the actual base integers and this particular uniformizer.
Equivalently, every such element is a polynomial in the uniformizer with
coefficients from the base integer ring. The target is an algebraic equality;
it requires finite polynomial expressions. It makes no claim about
topological closure, a completion of a polynomial algebra, a chosen alternate
uniformizer, or only a power-series expansion.

No generation certificate is assumed. There is no trace, different, norm, or
reciprocity hypothesis or conclusion. The imported coordinate and scalar
definitions are used without modifying them or the parent statement modules.

The source is Chapter I, §6(ii), Proposition 18, printed p.19 / PDF p.27;
its proof continues on printed p.20 / PDF p.28. Both pages were read,
including their rendered formulas.

Serre takes a DVR `A` with fraction field `K`, a finite extension `L/K`
of degree `n`, and its integral closure `B`. He assumes that `B` is a DVR
whose valuation extends that of `A` with ramification index `n`.
For a uniformizing element `x` of `B`, its characteristic polynomial is
Eisenstein, and evaluation at `x` identifies the corresponding polynomial
quotient `B_f` with `B`. In particular, `B = A[x]`.
The continued proof compares the valuations of the terms of the
characteristic-polynomial relation and applies the corollary to
Proposition 17.

The Lean declaration specializes only the last generation consequence to
the canonical integer rings of finite p-adic fields, using the absolute-index
equality above to encode relative total ramification. In this setting the
integer rings are DVRs and the extension integer ring is the integral closure
of the base integers. The separately published
`Langlands.LocalClassField.NYLL.relativeIntegerStructure` supplies that
integral-closure fact and module finiteness for the actual relative scalar
structure; neither is a premise of this proposition. The target does not
state the characteristic-polynomial or Eisenstein conclusions. This is a
derived specialization and extraction of Proposition 18's generation
consequence.
