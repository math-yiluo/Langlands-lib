# Actual residue coordinates on graded p-adic units

Worker 96 authored this construction. Worker 27 specified its scope and downstream
interface and authored the existing normalization proof from which the private
valuation-integer bridge and the uniformizer span argument are adapted.

All declarations lie in `Langlands.PadicField.TopologicalData`, for arbitrary
`p : ℕ`, `[Fact p.Prime]`, `F : PadicField.{u} p`, and supplied
`T : F.TopologicalData`. The universe `u` is unrestricted. The existing integer
ring, residue field, scalar maps, and unit filtration are used unchanged.

## The quotient and its actual representatives

Write `U^n = T.unitFiltration n`. `gradedUnitKernel n` is
`(U^(n+1)).subgroupOf (U^n)`. The map `gradedUnitInclusion n` uses the published
antitonicity theorem to include `U^(n+1)` into `U^n`, and
`gradedUnitInclusion_range` identifies its range with this subgroup.
`GradedUnits n` is the actual quotient of `U^n` by that subgroup, and
`gradedUnitProjection n` is its canonical projection.

`congruenceUnitsEquivFiltration n` identifies the integer congruence subgroup
with its image in field units, using the injectivity of the existing inclusion.
`filtrationIntegerUnit n` recovers the unique underlying integer unit as a
homomorphism. Its coercion to the field is the given unit
(`filtrationIntegerUnit_coe`); its membership in any congruence level is
equivalent to membership of the original field unit in that level
(`filtrationIntegerUnit_mem_iff`). Thus the use of an inverse to this canonical
image equivalence does not change any field value.

## Positive-level coefficients

Fix an arbitrary `π : F.Carrier` and `hπ : T.ord π = 1`.
`coordinateUniformizer π hπ` is this same element in `T.Integers`, as proved by
`coordinateUniformizer_coe`. The construction never substitutes `T.uniformizer`.
The private `coordinateValuationIntegers` transports the integer-ring condition
through the ordered discrete value-group isomorphism. Since `ord π = 1`, the
discrete valuation of `π` is `exp (-1)`. Discreteness then proves
`maximalIdeal_eq_span_coordinateUniformizer`, identifying the maximal ideal
with the principal ideal generated by this supplied uniformizer.
`mem_maximalIdeal_pow_iff_coordinate_dvd` converts membership in its powers to
divisibility by `π^n` in the integer ring.

For every natural `n` and `x : U^n`, `unitCoefficient π hπ n x` is **defined** as
the integer-ring subtype whose field value is the literal quotient

```text
((x : F.Carrier) - 1) / π^n.
```

Here the displayed field coercion passes through `F.Carrierˣ`.
`unitCoefficient_integral` supplies the subtype certificate: the unique integer
unit is congruent to one modulo the maximal ideal power, so its difference from
one is `π^n a` for an integer `a`. Cancellation in the field proves integrality
of the quotient. `unitCoefficient_coe` is the definitional computation rule.
`coordinateUniformizer_pow_mul_coefficient` gives the corresponding identity
inside the integer ring.

The normalized order has convention `ord 0 = 0`. The proof first deduces
`π ≠ 0` from `hπ`; it does not use an order inequality for a potentially zero
numerator. At the identity unit the coefficient is zero
(`unitCoefficient_one`). At level zero this coefficient remains the integral
expression `x - 1`; it is not used as an additive group coordinate.

For `hn : 0 < n`, the homomorphism

```text
positiveUnitCoordinate π hπ n hn : U^n →* Multiplicative T.ResidueField
```

sends `x` to the residue of `unitCoefficient π hπ n x`, expressed using
`Multiplicative.ofAdd`. `unitCoefficient_mul` proves the exact integer-ring
identity

```text
c(xy) = c(x) + c(y) + π^n c(x)c(y).
```

The residue of `π` is zero, and positivity of `n` makes the final term vanish
after reduction. This gives the required homomorphism certificate. No
positivity-free additive formula is asserted.

`residue_unitCoefficient_eq_zero_iff` proves that the coefficient residue
vanishes exactly when the field unit lies in `U^(n+1)`. The proof translates
residue zero into divisibility by `π`, uses the coefficient identity, and
cancels the nonzero factor `π^n`. Consequently
`positiveUnitCoordinate_ker` identifies the kernel with `gradedUnitKernel n`.
For surjectivity, lift any residue element to an integer `a`. The integer
`1 + π^n a` has residue one, hence is a unit, lies in the level `n` congruence
subgroup, and has coefficient exactly `a`. This proves
`positiveUnitCoordinate_surjective`.

`gradedUnitsPositiveEquiv π hπ n hn` applies the first isomorphism theorem to
this particular surjective homomorphism, transporting the quotient along the
proved kernel equality. It is a multiplicative equivalence

```text
GradedUnits n ≃* Multiplicative T.ResidueField.
```

Its computation theorem `gradedUnitsPositiveEquiv_projection` states that the
class of an actual `x : U^n` maps to `Multiplicative.ofAdd (T.residue
(T.unitCoefficient π hπ n x))`. Together with `unitCoefficient_coe` this exposes
the required literal residue formula for rewriting equations on quotient
classes. The forward map is induced by that formula, not selected from a
cardinality argument.

## Level zero

`zeroUnitCoordinate : U^0 →* T.ResidueFieldˣ` is the composition of
`filtrationIntegerUnit 0` with the existing `residueUnits`.
`zeroUnitCoordinate_apply` and `zeroUnitCoordinate_val` expose both its unit
value and its underlying residue-field value. Its kernel is exactly the next
filtration group, because reduction to one is equivalent to the difference
from one lying in the maximal ideal. Its surjectivity uses surjectivity of the
local-ring residue map on units and `congruenceUnits_zero`.

`gradedUnitsZeroEquiv : GradedUnits 0 ≃* T.ResidueFieldˣ` is the induced first
isomorphism theorem equivalence. `gradedUnitsZeroEquiv_projection` computes it
on actual unit classes. None of the zero-level declarations takes a uniformizer.
These are algebraic constructions and computation laws; this module asserts
no norm-filtration, naturality under extension, reciprocity, or ramification
break theorem.
