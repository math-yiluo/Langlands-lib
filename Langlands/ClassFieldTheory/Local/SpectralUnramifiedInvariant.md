# The invariant at arithmetic unramified stages

Serre, *Local Fields*, Chapter XIII, §3, Proposition 6 uses normalized
valuation, the inverse connecting homomorphism and evaluation at the
arithmetic Frobenius. This module implements that value at each actual
finite Galois arithmetic-unramified intermediate field of the separable
closure. The spectral local-field structures give a compatible extension
with ramification factor one. The arithmetic residue Frobenius supplies
the cyclic coordinate used by the finite norm invariant. The proved
connecting-map comparison identifies the same value using the inverse
arrow specified by the correction to printed page 193.

For nested stages, arithmetic Frobenius restricts to arithmetic Frobenius
and the cyclic coordinates are compatible by reduction. The published
carry calculation identifies inflation with replacing the defining base
unit by its power of exponent equal to the relative degree. Both its
normalized order and the denominator are multiplied by that degree, so
the value is unchanged. These statements hold for all nonarchimedean
local fields and every universe of the base field.
