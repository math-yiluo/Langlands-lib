# The normal closure in a tower of fields

Module `StacksCore.FieldTheory.Normal.Closure`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

The file works with Mathlib's relative normal closure `normalClosure K N L`, the intermediate field of `L/K` generated by the images of all `K`-embeddings `N → L`.

- `normalClosure' K M N L`: for fields with `L/N/M`, `N/K` and `L/K` and compatible scalar towers `K → N → L` and `M → N → L`, the normal closure of `N/K` in `L` seen as an `M`-intermediate field of `L`. It contains the image of `M` because it contains the image of `N`.
- `normalClosure.algebraOfTower` (instance): the resulting `M`-algebra structure on `normalClosure K N L`.

The file also adds the `mk_iff` attribute to Mathlib's `IsNormalClosure`, which generates `isNormalClosure_iff`.

## Watch for

`normalClosure.algebraOfTower` is a global instance on Mathlib's `normalClosure`.
