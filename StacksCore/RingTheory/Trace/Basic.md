# The trace in a cyclic Galois extension

Module `StacksCore.RingTheory.Trace.Basic`, an extract of the file of the same path of the Lean library AxiomMath/Stacks. The origin of the file and what the extract leaves out are given at the end of this page.

The file has one theorem, `IsGalois.trace_eq_of_zpowers_eq_top`: for a finite Galois extension `K/F` whose Galois group is generated by `σ`, and `x ∈ K`, the trace of `x` from `K` to `F`, viewed in `K`, equals the sum of `σⁱ(x)` over `0 ≤ i < n`, with `n = #Gal(K/F)`.

The proof starts from Mathlib's formula for the trace as the sum of `g(x)` over all automorphisms `g`, and uses that `σ⁰, …, σⁿ⁻¹` enumerate the cyclic group without repetition.

In the table of tags below, Tag 0BIH is attached to Mathlib's `trace_eq_finrank_mul_minpoly_nextCoeff`, which expresses the trace through the degree `[K : F(x)]` and the next-to-leading coefficient of the minimal polynomial of `x`; the file's own theorem carries no tag.
