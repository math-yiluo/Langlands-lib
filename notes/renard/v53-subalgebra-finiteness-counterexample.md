# Renard V.5.3: the generated subalgebra `M` need not be a finitely generated `A`-module

This note is dated 18 November 2026. Every step was checked a second time, independently, on paper.

**Status: an unformalized paper argument.** No Lean term is constructed.

This note is a paper counterexample to Renard's V.5.3 Lemma, "L'algèbre `M` est un
`A`-module de type fini". It applies to Renard's chamber-compatible transversal of V.3.23,
with `A` generated by the `a_z`, `z ∈ C_∅^+`. The source is David Renard, *Représentations
des groupes réductifs p-adiques*, French edition dated 9 July 2026, printed pp. 124–125 / PDF
pp. 130–131. The same example refutes condition (C) of the Markdown of
[`RenardIwahoriHeckeSubalgebraFinitenessStatement`](../../Langlands/Representation/Hecke/RenardIwahoriHeckeSubalgebraFinitenessStatement.md).

`Langlands.Hecke.RenardIwahoriHeckeSubalgebraFinitenessStatement` quantifies over an
available `KPBuildingAssignment`. The Library gives a valid assignment for every
connected reductive group over a nonarchimedean local field. To derive the Lean negation
from the example below requires comparing its rational-point group, torus, special
vertex, subgroup \(K\) and transversal with the data of the statement and formalizing
the Hecke calculation. [Availability proof](../../Langlands/Geometry/Building/BruhatTitsAvailabilityProof.md)

## Fields and the norm group

Let `F = ℚ₂(√2)`, with `𝒪_F = ℤ₂[√2]`, residue field `𝔽₂` and uniformizer `√2`. Let
`E = F(i) = ℚ₂(ζ₈)`, where `i = ζ₈²`. Then `E/F` is a ramified quadratic extension, and its
conjugation `σ` sends `ζ₈ ↦ ζ₈⁻¹` and `i ↦ -i`. The trace-zero elements of `E` are `F i`.
`ζ₈` satisfies `ζ₈² - √2 ζ₈ + 1 = 0`, so `𝒪_E = 𝒪_F + 𝒪_F ζ₈`, and

`N(a + b ζ₈) = a² + √2 ab + b²`  for `a, b ∈ 𝒪_F`.

Let `R₁ = ℤ₂ + 2√2 ℤ₂ = {c₀ + c₁√2 : c₁ ∈ 2ℤ₂}`. This is a subring of index 2 in `𝒪_F`.
It contains `2𝒪_F` and every square of `𝒪_F`, since `(c₀ + c₁√2)² = c₀² + 2c₁² + 2c₀c₁√2`.

**Norms of units lie in `R₁`.** Write `a = a₀ + a₁√2` and `b = b₀ + b₁√2` with `aᵢ, bᵢ ∈ ℤ₂`.
The `ℤ₂`-coordinate of `N(a + bζ₈)` is `a₀² + b₀² + 2(a₁² + b₁² + a₀b₁ + a₁b₀)`. Its
`√2`-coordinate is `a₀b₀ + 2(a₀a₁ + b₀b₁ + a₁b₁)`. The norm is a unit exactly when
`a₀ + b₀` is odd. Then `a₀b₀` is even, so the `√2`-coordinate is even. Hence
`N(𝒪_E^×) ⊆ R₁^×`, with equality by local class field theory; only the inclusion is used.

On the other hand, `N(1 - ζ₈) = 2 - (ζ₈ + ζ₈⁻¹) = 2 - √2`. Its `F`-valuation is 1, and it
does not lie in `R₁`. Moreover `R₁ + (2 - √2)R₁ = 𝒪_F`.

## The group

Let `G = U(1,1)` be the quasi-split unitary group of the hermitian form with matrix
`J = [[0,1],[1,0]]`. Its points are `G(F) = {g ∈ GL₂(E) : σ(g)ᵀ J g = J}`, and it is a
connected reductive `F`-group. Write

- `n(x) = [[1,x],[0,1]]` and `n̄(y) = [[1,0],[y,1]]` for `x, y ∈ F i`;
- `t(α) = diag(α, σ(α)⁻¹)` for `α ∈ E^×`.

The following identities are used throughout.

- `t(α) n(x) t(α)⁻¹ = n(N(α) x)` and `t(α) n̄(y) t(α)⁻¹ = n̄(N(α)⁻¹ y)`.
- Big cell: for `x, y ∈ F i` with `1 + xy ≠ 0` (note `xy ∈ F`),
  `n̄(y) n(x) = n(x/(1+xy)) t((1+xy)⁻¹) n̄(y/(1+xy))`.
- The decomposition `n(x) t(α) n̄(y)` of a big-cell element is unique.

The maximal split torus is `S = {t(b) : b ∈ F^×}`. Its centralizer is
`Z(F) = {t(α) : α ∈ E^×} ≅ E^×`, an induced torus, so `Z(F)^1 = Z(F)^0 = t(𝒪_E^×)`. The
relative roots are `±α`, with `U_α = n(F i)`, and `t(b)` acts on `U_α` by `b²`. The
valuation `Λ(t(α)) = val_F N(α) = val_E(α)` gives `Λ(Z) = ℤ` and `Λ(S) = 2ℤ`.

Let `K₀ = G(F) ∩ GL₂(𝒪_E)`. This is the stabilizer of the self-dual lattice `𝒪_E²`, a vertex
`y₀` of the Bruhat–Tits tree. Every vertex of this tree is special, because the relative root
system is reduced of type `A₁`.

Suppose `g ∈ K₀`. If its lower right entry is a unit, then `g` lies in
`n(𝒪_F i) t(𝒪_E^×) n̄(𝒪_F i)`. Otherwise its upper right entry is a unit, and `Jg` lies in that
set. Also `J = t(i)⁻¹ n(i) n̄(i) n(i)`. Hence `K₀` is generated by `n(𝒪_F i)`, `n̄(𝒪_F i)` and
`t(𝒪_E^×)`, and it is also the parahoric subgroup at `y₀`. Here and below, the factors of
the big-cell decomposition of an element of `G(F)` lie in `G(F)`, by uniqueness. Explicitly,

`n(x) t(β) n̄(y) = [[β + xσ(β)⁻¹y, xσ(β)⁻¹],[σ(β)⁻¹y, σ(β)⁻¹]]`,

so an element `g = (g_{ij})` with `g₂₂ ≠ 0` has `x = g₁₂/g₂₂`, `σ(β)⁻¹ = g₂₂` and
`y = g₂₁/g₂₂`.

Let `f = t(1 - ζ₈)`. Then `f` acts on `U_α` by `N(1 - ζ₈) = 2 - √2` and translates the
apartment of `S` by one edge. For `b ∈ F^×`, `t(b)` translates it by `2 val_F(b)` edges.
Write `y_ℓ = f^ℓ y₀`, so `Stab(y_ℓ) = f^ℓ K₀ f^{-ℓ}`. For `ℓ ≥ 1`,

`K₀ ∩ Stab(y_ℓ) = n({v i : v ∈ F, val_F v ≥ ℓ}) · t(𝒪_E^×) · n̄(𝒪_F i)`.

The restriction `ℓ ≥ 1` is needed: for `ℓ = 0` the left side is `K₀`, which contains `J`,
and `J` is not in the integral big cell.

To see the inclusion `⊆`, let `g ∈ K₀ ∩ f^ℓ K₀ f^{-ℓ}`. Conjugation by `f^{-ℓ}` multiplies
the upper right entry `g₁₂` by `N(1 - ζ₈)^{-ℓ} = (2 - √2)^{-ℓ}`, so
`g₁₂ ∈ (2 - √2)^ℓ 𝒪_E`. Since `ℓ ≥ 1`, `g₁₂` lies in the maximal ideal of `𝒪_E`. The
determinant `g₁₁g₂₂ - g₁₂g₂₁` is a unit, so `g₂₂` is a unit. Hence `g = n(x) t(β) n̄(y)`
with `β = σ(g₂₂)⁻¹ ∈ 𝒪_E^×`, `y = g₂₁/g₂₂ ∈ 𝒪_E ∩ F i = 𝒪_F i`, and
`x = g₁₂/g₂₂ ∈ (2 - √2)^ℓ 𝒪_E ∩ F i`. Write `x = v i` with `v ∈ F`. Since `i` is a unit of
`𝒪_E`, `v ∈ (2 - √2)^ℓ 𝒪_E ∩ F = (2 - √2)^ℓ 𝒪_F`, so `val_F v ≥ ℓ`. For the inclusion
`⊇`, conjugation by `f^{-ℓ}` sends `n(v i)` to `n((2 - √2)^{-ℓ} v i) ∈ K₀`, fixes
`t(𝒪_E^×)`, and sends `n̄(c i)` to `n̄((2 - √2)^ℓ c i) ∈ K₀`.

## The subgroup `K`

Fix an integer `m ≥ 1`. Put

`L = 2^m R₁ · i`,  `T_K = {t(α) : α ∈ 1 + 2^m 𝒪_E, N(α) ∈ 1 + 2^{m+1} 𝒪_F}`,

and `K = n(L) · T_K · n̄(L)`. Here `T_K` is a compact open subgroup of `t(𝒪_E^×)`, and
`N(T_K) ⊆ 1 + 2^{m+1}𝒪_F ⊆ R₁^×`.

- **`K` is a compact open subgroup.** `T_K` normalizes `n(L)` and `n̄(L)`, because
  `N(T_K) ⊆ R₁^×`. Take `x, y ∈ L`. Then `1 + xy ∈ 1 + 2^{2m}R₁ ⊆ R₁^×`, so
  `x/(1+xy)` and `y/(1+xy)` lie in `L`. Also `(1+xy)⁻¹ ∈ 1 + 2^{2m}𝒪_F ⊆ 1 + 2^m𝒪_E`, and
  its norm `(1+xy)⁻²` lies in `1 + 2^{2m}𝒪_F ⊆ 1 + 2^{m+1}𝒪_F`, because `2m ≥ m + 1` (this
  uses `m ≥ 1`). So the big-cell identity puts `n̄(y)n(x)` in `n(L) T_K n̄(L)`. Hence
  `K·K ⊆ K` and `K⁻¹ ⊆ K`. The set `K` is an open neighborhood of `1` in the big cell, and it
  is compact.
- **`K` is small.** Each of `n(L)`, `T_K` and `n̄(L)` lies in the group
  `I + 2^m Mat₂(𝒪_E)`, since `σ(α)⁻¹ ∈ 1 + 2^m𝒪_E` for `α ∈ 1 + 2^m𝒪_E`. So
  `K ⊆ G(F) ∩ (I + 2^m Mat₂(𝒪_E))`, and these sets form a neighborhood basis of `1` as `m`
  grows.
- **`K` is normal in `K₀`.** It suffices to check the generators of `K₀`.
  - `t(u)`, `u ∈ 𝒪_E^×`: it multiplies `L` by `N(u) ∈ R₁^×` and fixes `T_K`.
  - `n(c i)`, `c ∈ 𝒪_F`: it fixes `n(L)`. It sends `t(β) ∈ T_K` to
    `t(β) n((N(β)⁻¹ - 1)c i)`, and `(N(β)⁻¹ - 1)c ∈ 2^{m+1}𝒪_F ⊆ 2^m R₁`. It sends
    `n̄(y₀ i)` with `y₀ ∈ 2^m R₁` to
    `[[1 - cy₀, c²y₀ i],[y₀ i, 1 + cy₀]] = n(c²y₀ i/(1+cy₀)) t((1+cy₀)⁻¹) n̄(y₀ i/(1+cy₀))`.
    This lies in `K`. First, `c² ∈ R₁` and `(1+cy₀)⁻¹ ∈ R₁^×`. Second,
    `(1+cy₀)⁻¹ ∈ 1 + 2^m𝒪_F ⊆ 1 + 2^m𝒪_E`, and its norm `(1+cy₀)⁻²` lies in
    `1 + 2^{m+1}𝒪_F`. The last holds since `(1+cy₀)² = 1 + 2cy₀ + c²y₀²` with
    `2cy₀ ∈ 2^{m+1}𝒪_F` and `c²y₀² ∈ 2^{2m}𝒪_F ⊆ 2^{m+1}𝒪_F`; this uses `m ≥ 1`.
  - `n̄(c i)`: the same argument, after conjugating by `J`. `J` exchanges `n(L)` and `n̄(L)`.
    It preserves `T_K`, because `J t(α) J = t(σ(α)⁻¹)`, with `σ(α)⁻¹ ∈ 1 + 2^m𝒪_E` and
    `N(σ(α)⁻¹) = N(α)⁻¹ ∈ 1 + 2^{m+1}𝒪_F`.
- **The V.5.2 (ii)–(iv) clauses for the minimal standard parabolic** (root subset `∅`) hold
  with `K ∩ N_∅ = n(L)`, `K ∩ M_∅ = T_K` and `K ∩ N̄_∅ = n̄(L)`. This is the Iwahori
  decomposition `K = n(L) T_K n̄(L)`, and by uniqueness of the big-cell decomposition it gives the literal intersections.
  `S(F)` acts on `L` through `(𝒪_F^×)² · 2^ℤ`, and `(𝒪_F^×)² ⊆ R₁^×`. Hence:
  - `S(F)` normalizes `T_K`, since `Z` is commutative;
  - dominant elements contract `n(L)` and their inverses contract `n̄(L)`;
  - strictly dominant elements exhaust `N_∅` and `N̄_∅` and give power neighborhood bases;
  - the uniform containment and cofinality clauses hold, because the conjugates of `n(L)`
    are the `n(2^k u L)`.
- **The clauses for the root subset `{α}`** are trivial. The Levi factor is `G`, and `N`
  and `N̄` are trivial. The split component is trivial, because the center `U(1)` is anisotropic.

## The transversal

Let `C_∅ = {t(ϖ^j) : j ∈ ℤ}` for a uniformizer `ϖ` of `F`, and `C_∅^+ = {t(ϖ^j) : j ≥ 0}`.
These elements contract `n(L)`. Let `F_∅ = {1, f}`. It represents `Λ(Z)/Λ(S) = ℤ/2`, and
both of its elements are dominant. The dominant part of `C_∅ F_∅` is
`{t(ϖ^j), t(ϖ^j)f : j ≥ 0} = C_∅^+ F_∅`, so `F_∅` is chamber-compatible in the sense of V.3.23.

## Condition (C) fails

`f n(L) f⁻¹ = n((2 - √2)L)` is not contained in `n(L)`, since `2 - √2 ∉ R₁`. Likewise
`f⁻¹ n̄(L) f = n̄((2 - √2)L) ⊄ n̄(L)`. The subgroup `n((2 - √2)L) ⊆ K₀` normalizes `K`.
Since `R₁ + (2 - √2)R₁ = 𝒪_F`, the product is

`K' := K · f n(L) f⁻¹ = K · n(2^m 𝒪_F i)`,

and `[K' : K] = [𝒪_F : R₁] = 2`. A representative of the nontrivial coset is
`x₁ = n(2^m √2 i) ∈ K₀`, which normalizes `K`.

## The Lemma fails

Write `e_K` for the normalized indicator of `K` and `a_g = e_K δ_g e_K`. Then
`e_K = e_{n(L)} e_{T_K} e_{n̄(L)}`. As a function, `a_g = vol(KgK)⁻¹ · 1_{KgK}`. This is the
mass-one double-coset indicator of Renard II.3.11–II.3.12 and the Library's
`HeckeAlgebra.Corner.massIndicator`, which the target uses.

**A is the span of the `a_z`.** Take `z₁, z₂ ∈ C_∅^+`. Then `z₁` contracts `n(L)`, `z₂⁻¹`
contracts `n̄(L)`, and `z₂` commutes with `T_K`. Hence `a_{z₁} a_{z₂} = a_{z₁z₂}`. So the
algebra `A` generated by the `a_z`, `z ∈ C_∅^+`, is `span{a_z : z ∈ C_∅^+}`.

**Step 1: `a_{x₁fz} ∈ M` for every `z ∈ C_∅^+`.** The same absorption on the right gives

`a_f a_z = e_K δ_f e_{n(L)} δ_z e_K = e_K e_{f n(L) f⁻¹} δ_{fz} e_K = e_{K'} δ_{fz} e_K`.

Since `x₁` normalizes `K`, `e_{K'} = ½(e_K + e_K δ_{x₁} e_K)`, and so

`a_f a_z = ½ (a_{fz} + a_{x₁ f z})`.

The elements `a_f = a_{1·f}`, `a_z = a_{z·1}` and `a_{fz} = a_{zf}` are generators of `M`.
Hence `a_{x₁fz} = 2a_f a_z - a_{fz} ∈ M`.

**Step 2: a vanishing estimate.** Let `Φ ∈ H(G, K)` be supported on
`{h : d(y₀, h y₀) ≤ R}`. Then

`(a_{z'} * Φ)(x₁ f z) = 0` for every `z' ∈ C_∅^+`, whenever `d(y₀, f z y₀) ≥ R + 2m + 3`.

Proof.

1. Suppose the value is nonzero. Then there is `k ∈ K` with `d(z' y₀, P) ≤ R`, where
   `P = k⁻¹x₁ f z y₀`.
2. Since `k⁻¹x₁ ∈ K₀` fixes `y₀`, we have `d(y₀, P) = d(y₀, fzy₀) =: d`. Also
   `d(y₀, z'y₀) ≥ d - R`.
3. In the tree, the Gromov product `(z'y₀ | P)_{y₀}` is therefore at least `d - R ≥ 2m + 3`.
   So the geodesics `[y₀, z'y₀]` and `[y₀, P]` share their initial segment of length
   `ℓ = 2m + 3`.
4. `[y₀, z'y₀]` lies on the positive ray of the apartment, so the point at distance `ℓ` on
   it is `y_ℓ`. `[y₀, P]` is the image of `[y₀, fzy₀]` under `k⁻¹x₁`, and `y_ℓ` lies on
   `[y₀, fzy₀]`, so the point at distance `ℓ` on `[y₀, P]` is `k⁻¹x₁ y_ℓ`. Hence `k⁻¹x₁`
   fixes `y_ℓ`.
5. But `K x₁ ∩ Stab(y_ℓ) = ∅`. Since `x₁ ∈ K₀`, by the stabilizer formula (with
   `ℓ = 2m + 3 ≥ 1`) it suffices to take `s = n(v i) t(β) n̄(c₀ i)` with `val_F v ≥ ℓ`, `β ∈ 𝒪_E^×` and `c₀ ∈ 𝒪_F`. By
   the big-cell identity, the `N`-component of `s x₁⁻¹` is

   `(v - N(β) · 2^m √2 · (1 + 2^m √2 c₀)⁻¹) i`.

   Here `v ∈ 2^{m+1}𝒪_F ⊆ 2^m R₁`, since `val_F 2 = 2` and `ℓ = 2m + 3`. Since `m ≥ 1`,
   `2^m √2 c₀ ∈ 2√2 𝒪_F ⊆ R₁`, so `1 + 2^m√2 c₀ ∈ R₁^×`. Hence
   `N(β)(1 + 2^m√2 c₀)⁻¹ = b₀ + b₁√2` lies in `R₁^×`, so `b₀` is odd. So the `N`-component is `≡ -b₀ 2^m √2 i` modulo `L`, which is not in `L`.
   Since `K ∩ N_∅ = n(L)` and the big-cell decomposition is unique, `s x₁⁻¹ ∉ K`.

**Step 3: conclusion.** Suppose `D₁, …, D_n ∈ H(G, K)` satisfy
`M ⊆ span{u * D_k : u ∈ A}`. Every element of the right side is a finite linear combination
of the `a_{z'} * D_k`, `z' ∈ C_∅^+`. Choose `R` bounding the supports of all the `D_k`, and
`z ∈ C_∅^+` with `d(y₀, fzy₀) ≥ R + 2m + 3`. By Step 2, every element of the right side
vanishes at `x₁fz`. But `a_{x₁fz}(x₁fz) = vol(K x₁fz K)⁻¹ > 0`, and `a_{x₁fz} ∈ M` by Step 1. So
`M` is not a finitely generated `A`-module.

## Where the source argument and the hypotheses enter

- **The source proof.** The computation on printed p.124 / PDF p.130 treats the products
  `a_{z₁} a_{z₂f}`, `z₁, z₂ ∈ C_∅^+`, which need only the contraction properties of `z₁` and
  `z₂`. So it concerns the left `A`-span of the listed generators `a_{zf}`. The general
  combinatorial finiteness argument on the next page invokes V.3.24
  (`C_∅^+ / C_{A_G} ≅ ℕ^d`), which is false in general, for example for split `SL₃` (see the
  target's "Status of the assertion"). The finiteness of this left `A`-span for all data, the
  module form, is item 5 of the published `IwahoriHeckeDecompositionStatement`. The Library
  proves it (`iwahoriHeckeDecomposition`) without V.3.24. Neither argument
  shows that this span is closed under multiplication, and in the example it is not. The
  products `a_{zf} a_{z'}`
  have the transversal element on the left. Absorbing `e_K` as in the source computation
  would need `zf(K ∩ N_∅)(zf)⁻¹ ⊆ K`, which fails for `z = 1`. Step 1 shows that the
  products `a_f a_z` leave every finitely generated `A`-submodule.
- **What normality allows.** Normality of `K` in `K₀` requires `L` to be stable under
  multiplication by `N(𝒪_E^×)` and by the squares `c²`, `c ∈ 𝒪_F`. Both lie in the proper
  order `R₁`, so `L = 2^m R₁ i` is allowed. Meanwhile `f` acts through `2 - √2 ∉ R₁`.
- **The tamely ramified case behaves differently.** Let `E/F` be a tamely ramified
  quadratic extension (`p` odd). Every principal unit of `F` is then a norm from `𝒪_E^×`. So
  for `L ⊆ F i` stable under `N(𝒪_E^×)` we get `ϖ_F 𝒪_F L ⊆ L`, and a uniformizer `ϖ_E` of
  `E` acts through `N(ϖ_E) ∈ ϖ_F 𝒪_F`. This is why the example uses `p = 2`.
- **If `Λ(Z) = Λ(S)`,** for example for split groups, then every dominant `t` is `z u` with
  `z ∈ C_∅^+` and `u ∈ Z(F)^1`. The V.5.2 clause for the root subset `∅` makes `z` contract
  `K ∩ N_∅`, and `u` normalizes it, so (C) holds. The Lemma then follows by the
  sufficient-condition argument in the target's "Status of the assertion".
- **(C) holds on a deep part.** In the example, (C) holds for `fz` whenever `z ∈ C_∅^+` is
  nontrivial: `fz` acts through `(2 - √2)ϖ^{2j}` with `j ≥ 1`, which multiplies `R₁` into
  `2𝒪_F ⊆ R₁`. The failure comes from the single class `f`. It still produces the infinite
  family `a_{x₁fz}` in `M`.

## Scope

- **Unaffected: the (P)-conditional statement.** The published
  [`IwahoriHeckeSubalgebraFinitenessStatement`](../../Langlands/Representation/Hecke/IwahoriHeckeSubalgebraFinitenessStatement.md)
  assumes (P), and (P) fails for this `K` because `f` does not contract `K ∩ N_∅`. So this
  example does not bear on it. The Library proves it, as
  `iwahoriHeckeSubalgebraFiniteness`
  (`Langlands/Representation/Hecke/IwahoriHeckeSubalgebraFinitenessProof.lean`).
- **Unaffected: the module form.** The published module-form statement
  [`IwahoriHeckeDecompositionStatement`](../../Langlands/Representation/Hecke/IwahoriHeckeDecompositionStatement.md)
  and its proof `iwahoriHeckeDecomposition` are not affected.
- **Comparison with `RenardIwahoriHeckeSubalgebraFinitenessStatement`.**
  The paper example uses the specific torus and special vertex described above.
  A formal proof would transport those data and the Hecke calculation to the Lean
  proposition.
- **Refuted on paper: Renard's printed Lemma.** V.5.3 fixes a compact open `K` contained in
  and normal in `K₀` that admits Iwahori decompositions along the standard parabolics. For
  such `K`, the Lemma is false, even when `K` also has all the V.5.2 (ii)–(iv) properties.
  The example gives such `K` inside every neighborhood of `1`: `K ⊆ I + 2^m Mat₂(𝒪_E)` and
  `m ≥ 1` is arbitrary. It does not decide whether `K` can be chosen in the particular basis constructed in Renard's
  reference [24] for V.5.2. Possible repairs:
  - add (C), or (P), as a hypothesis;
  - restrict to `K` normalized by `F_∅` (if `f` normalizes `K`, then
    `f(K ∩ N_∅)f⁻¹ = K ∩ N_∅`);
  - restrict to groups where every class of `Λ(Z)/Λ(S)` has a representative in
    `S(F) Z(F)^1`.

  The Chapter V ledger ([item-ledger-v](item-ledger-v.md), V.5.3 subalgebra row, gap 4)
  records the source issue.
