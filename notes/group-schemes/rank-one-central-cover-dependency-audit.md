# Rank-one central cover: dependency audit of its proof

This note is a mechanical dependency check of the proof `Langlands.GroupScheme.rankOneCentralCover`
(`Langlands/GroupScheme/Reductive/RankOneCentralCoverProof.lean`), which proves the actual rank-one
`SL2` central cover independently of the dynamic-Borel route, of
`Langlands.GroupScheme.RankOneCentralCoverStatement`. The full list of Library constants reached
by the proof is in the companion note
[rank-one-central-cover-dependency-constants.md](rank-one-central-cover-dependency-constants.md).

## Method

The scan is a breadth-first closure over the constants used in the types and in the values of
declarations, opaque values included (`ConstantInfo.value? (allowOpaque := true)`). It starts from
the constants used by the proof term of `rankOneCentralCover`. The root's own type, the target
statement, is removed. The value of `RankOneLocalCover.rankOneCentralCover_of_inputs`, whose type
is the target, is scanned in its place. The scan does not expand through an excluded constant;
it records it as a hit, together with the path from the root.

Excluded constants:

- Statements; any use, as hypothesis or conclusion, counts: `ParabolicDynamicStatement`, `RegularCocharacterBorelStatement`, `RankOneSolvableObstructionStatement`, `RankOneBorelDynamicStatement`, `RankOnePositiveRootUniquenessStatement`, `RankOneAlgClosedPositiveRootUniquenessStatement`, `RootDatumExistenceStatement`, `RootReducednessStatement`, `ReductiveGeometricReductivityStatement`, `ReductiveLinearQuotientAffineStatement`, `DynamicQuotientProperStatement`, `SplitRankOneRootCellStatement`, `SplitRootLieLineStatement`, `ProjectiveTorusFixedPointDimensionStatement`, `SplitSimplyConnectedCorootSpanStatement`, `SplitCentralIsogenyExistenceStatement`, `SplitCommonTorusIsomorphismStatement`, `RelativeRootReflectionExistenceStatement`, `RankOneCentralCoverStatement`, `AlgClosedRankOneRootSupportLinesStatement`, `RankOneRootSupportLinesStatement`. `RankOneCentralCoverStatement` is included so that any circular use of the target, for example through the published cover-to-cell or cover-to-line consumers, would be a hit.
- Proofs and route cut points, matched as name prefixes so that `..._of_...` variants are caught:
  `parabolicDynamic`, `regularCocharacterBorel`, `rankOneSolvableObstruction`,
  `rankOneBorelDynamic`, `rankOnePositiveRootUniqueness`, `splitRankOneRootCell`,
  `splitRootLieLine`, `rootDatumExistence`, `rootReducedness`, `reductiveGeometricReductivity`,
  `absoluteBruhatCovering`, `steinbergBigCell`, `isParabolicSubgroup_of_range_eq_dynamicParabolic`,
  `dynamicQuotientProper`, `reductiveLinearQuotientAffine`, `rankOne_exists_rootCell`,
  `rankOne_exists_cell`, `rankOne_exists_rootGroup`, `relativeRootReflectionExistence`,
  `prescribedBorelProjectiveCurveData`, `projectiveTorusFixedPointDimension`,
  `splitSimplyConnectedCorootSpan`, `splitCentralIsogenyExistence`, `splitCommonTorusIsomorphism`,
  `HomogeneousQuotient.regularSignedCurveUnipotentDataOfIsConnectedReductive`,
  `rankOne_rootTangent_le_one_of_projectiveBorelInputs`,
  `positive_roots_eq_of_prescribedBorel_of_projectiveFixedPoints`,
  `rankOneAlgClosedPositiveRootUniqueness_of_projectiveBorelInputs`,
  `rankOnePositiveRootUniqueness_of_projectiveBorelInputs`,
  `HomogeneousQuotient.positive_roots_eq_of_rankOne_curve_quotient`,
  `HomogeneousQuotient.signedCurveUnipotentData`, `RootReducedness.neg_mem_roots_of_rankOne_algClosed`,
  `splitRankOneRootCell_of_centralCover`, `splitRootLieLine_of_centralCover`,
  `algClosedRankOneRootSupportLines_of_centralCover`. All are in namespace
  `Langlands.GroupScheme`.
- Every declaration of the modules `SimplyConnected.SplitCorootSpanLineReduction`,
  `ProjectiveTorusFixedPointDimension`, `Reductive.RankOneProjectiveBorelAssembly`,
  `Reductive.RootTangentCurveDimension`, `Reductive.RankOneCurveCentralizerProof`,
  `Reductive.RootReducednessProof`, `Reductive.GeometricReductivityProof`,
  `Absolute.ParabolicDynamicProof` and `Absolute.RegularCocharacterBorelProof`.

The scanner imports the modules that define these names, and reports names absent from the
environment, so that the check is not vacuous. Two names are absent from the Library at commit
`18c5dd82`: `RankOneRootSupportLinesStatement` and `splitRootLieLine_of_centralCover`.

## Result

The scan visited 115210 constants, of which 20999 are `Langlands` constants from 1682 modules. It
found **no hits**. The Library constants singled out by the ruling are in the closure and were
scanned through: `solvableProperFixedPoint`,
`IsBorelSubgroup.properQuotientData_of_solvableProperFixedPoint`,
`exists_proper_isBorelPair_of_relativeRoot`, `nonidentityNormalizerOfRootedSolvableQuotient` and
`HomogeneousQuotient.curveUnipotentDataOfPseudoReductive`. The statement
`AlgClosedReductiveNormalSolvableTorusStatement` and its proof
`algClosedReductiveNormalSolvableTorus` are not in the closure.

Two independent scans of the planned inputs, against their own 32 cut points, were also clean.

def prefixLanglands (s : String) : Name :=
  (`Langlands.GroupScheme).append (s.toName)

/-- A constant is excluded if it is a listed name, or an excluded proof prefix such as
`splitRootLieLine_of_...`, or lives in an excluded module namespace. -/
def isExcluded (env : Environment) (n : Name) : Bool :=
  let s := n.toString
  excludedStatements.any (fun e => n == prefixLanglands e) ||
  excludedProofs.any (fun e => s.startsWith (prefixLanglands e).toString) ||
  (s.startsWith "Langlands.GroupScheme.SimplyConnected.SplitCorootSpanLineReduction") ||
  (match env.getModuleIdxFor? n with
   | some idx =>
     let m := (env.header.moduleNames[idx.toNat]!).toString
     m == "Langlands.GroupScheme.SimplyConnected.SplitCorootSpanLineReduction" ||
     m == "Langlands.GroupScheme.ProjectiveTorusFixedPointDimension" ||
     m == "Langlands.GroupScheme.Reductive.RankOneProjectiveBorelAssembly" ||
     m == "Langlands.GroupScheme.Reductive.RootTangentCurveDimension" ||

     m == "Langlands.GroupScheme.Absolute.ParabolicDynamicProof" ||
     m == "Langlands.GroupScheme.Absolute.RegularCocharacterBorelProof"
   | none => false)

def scanDeps (ci : ConstantInfo) : Array Name :=
  let t := ci.type.getUsedConstants
  match ci.value? (allowOpaque := true) with
  | some v => t ++ v.getUsedConstants
  | none => t

/-- BFS over types and values from the given starting constants. -/
def scanFrom (env : Environment) (start : Array Name) :
    Std.HashSet Name × Array (Name × List Name) := Id.run do
  let mut parent : Std.HashMap Name Name := {}
  let mut visited : Std.HashSet Name := {}
  let mut queue : Array Name := start
  let mut hits : Array (Name × List Name) := #[]
  for s in start do visited := visited.insert s
  let mut idx := 0
  while idx < queue.size do
    let n := queue[idx]!
    idx := idx + 1
    if isExcluded env n then
      let mut path := [n]
      let mut cur := n
      let mut steps := 0
      while steps < 80 do
        match parent.get? cur with
        | some p => path := p :: path; cur := p
        | none => steps := 80
        steps := steps + 1
      hits := hits.push (n, path)
      continue
    match env.find? n with
    | none => pure ()
    | some ci =>
      for d in scanDeps ci do
        if !visited.contains d then
          visited := visited.insert d
          parent := parent.insert d n
          queue := queue.push d
  return (visited, hits)

elab "#finalScan" : command => do
  let env ← getEnv
  -- report excluded names that do not exist (to avoid vacuous checks)
  let mut missing : Array String := #[]
  for e in excludedStatements ++ excludedProofs do
    let pre := (prefixLanglands e).toString
    let found := env.constants.toList.any (fun (c, _) => c.toString.startsWith pre)
    if !found then missing := missing.push e
  logInfo m!"excluded names absent from the environment: {missing.toList}"
  -- the root's type is the target statement; scan the value of the root and its other type
  -- constants
  let root := `Langlands.GroupScheme.rankOneCentralCover
  let some ci := env.find? root | logInfo "missing root"
  let start := (scanDeps ci).filter (fun n => n != `Langlands.GroupScheme.RankOneCentralCoverStatement)
  logInfo m!"root value/type constants (statement removed): {start.toList}"

  let mut start' : Array Name := #[]
  for n in start do
    if n == `Langlands.GroupScheme.RankOneLocalCover.rankOneCentralCover_of_inputs then
      match env.find? n with
      | some c => match c.value? (allowOpaque := true) with
        | some v => start' := start' ++ (v.getUsedConstants.filter
            (fun m => m != `Langlands.GroupScheme.RankOneCentralCoverStatement))
        | none => pure ()
      | none => pure ()
    else start' := start'.push n
  let (visited, hits) := scanFrom env start'
  let lang := (visited.toArray.filter (fun n => n.toString.startsWith "Langlands")).qsort
    (fun a b => a.toString < b.toString)
  logInfo m!"visited {visited.size} constants, {lang.size} Langlands constants, hits {hits.size}"
  for (h, p) in hits do
    logInfo m!"HIT {h} via {p}"
  let mods := (lang.filterMap (fun n => (env.getModuleIdxFor? n).map
    (fun i => (env.header.moduleNames[i.toNat]!).toString))).toList.eraseDups
  logInfo m!"MODULES {mods.length}: {mods}"
  logInfo m!"CONSTANTS: {lang.toList}"
