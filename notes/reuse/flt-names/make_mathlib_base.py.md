# `make_mathlib_base.py`

This page holds the script `make_mathlib_base.py` as it is, in the code block below. To use it, save the content of the block under that name.

```python
#!/usr/bin/env python3
"""Make `Langlands/MathlibBase.lean`: all of Mathlib except the modules that clash with weil-conjectures.

Usage: notes/reuse/flt-names/make_mathlib_base.py [<workspace>]   (default: the current directory)

Reads `<workspace>/.lake/packages/mathlib/Mathlib.lean` and writes `<workspace>/Langlands/MathlibBase.lean`
with one plain `import` line for every module that `Mathlib.lean` imports, in the same order, except the
modules of EXCLUDED; the file declares nothing.  `Mathlib.lean` is a `module` file whose lines read
`public import X`; the Library's files are ordinary files, so the generated lines are plain `import X`,
which for an ordinary importer brings in exactly what `import Mathlib` brought in, less the excluded
modules.

Run it again whenever the Library's Mathlib moves.  It stops with an error if an excluded module is no
longer imported by `Mathlib.lean` (the exclusion list must then be re-examined), and it warns if some
Mathlib module imports an excluded one (the excluded declarations would then come back in through it).
See OPERATOR-NOTE-1 of 22 November 2026 and FLT-REPORT.md for the facts behind the list.
"""
import os
import re
import sys

# module -> the declarations it shares with weil-conjectures (module of weil-conjectures)
EXCLUDED = {
    'Mathlib.CategoryTheory.GuitartExact.Prod':
        (['CategoryTheory.TwoSquare.GuitartExact.prod'],
         'WeilConjectures.FromJoel.CategoryTheory.GuitartExact.Basic'),
    'Mathlib.RingTheory.Depth.Basic':
        (['Ideal.depth', 'IsLocalRing.depth'], 'WeilConjectures.RingTheory.Depth'),
    'Mathlib.RepresentationTheory.Stabilizer':
        (['Representation.stabilizer'], 'WeilConjectures.RepresentationTheory.GeometricConstituents'),
}

ws = sys.argv[1] if len(sys.argv) > 1 else '.'
mathlib = os.path.join(ws, '.lake/packages/mathlib')
src = os.path.join(mathlib, 'Mathlib.lean')
imports = []
for line in open(src, encoding='utf-8'):
    m = re.match(r'\s*(?:public\s+)?(?:meta\s+)?import\s+(\S+)\s*(?:--.*)?$', line)
    if m:
        imports.append(m.group(1))
missing = [x for x in EXCLUDED if x not in imports]
if missing:
    sys.exit('error: Mathlib.lean no longer imports ' + ', '.join(missing) + '; re-examine EXCLUDED')
kept = [x for x in imports if x not in EXCLUDED]

# warn if a Mathlib module imports an excluded one
pat = re.compile(r'^\s*(?:public\s+)?(?:meta\s+)?import\s+(' + '|'.join(map(re.escape, EXCLUDED)) + r')\s*$', re.M)
for root, _, fs in os.walk(os.path.join(mathlib, 'Mathlib')):
    for f in fs:
        if f.endswith('.lean'):
            p = os.path.join(root, f)
            with open(p, encoding='utf-8') as h:
                head = h.read(20000)
            for m in pat.finditer(head):
                print(f'warning: {os.path.relpath(p, mathlib)} imports {m.group(1)}', file=sys.stderr)

rows = '\n'.join(f'| `{mod}` | {", ".join("`%s`" % d for d in ds)} | `{w}` |'
                 for mod, (ds, w) in EXCLUDED.items())
out = []
out.append('/-\nGenerated by `notes/reuse/flt-names/make_mathlib_base.py` from `Mathlib.lean`; do not edit by hand, run the script\n'
           'again when Mathlib moves. The module docstring is after the import list.\n-/')
out += ['import ' + x for x in kept]
out.append('')
out.append(f'''/-!
# All of Mathlib except the three modules that clash with weil-conjectures

This module imports every module that `Mathlib.lean` imports, in the same order, except three. It declares
nothing. A Library file imports `Langlands.MathlibBase` where it would import `Mathlib`: it then sees the
same declarations as with `import Mathlib`, less those of the three modules.

The three modules each declare a name that weil-conjectures also declares in its own sources, so a module
that has one of them and the corresponding module of weil-conjectures in its import closure is rejected
by Lean ("already declared"):

| Mathlib module | Declarations also in weil-conjectures | Module of weil-conjectures |
|---|---|---|
{rows}

No module of Mathlib imports any of the three; weil-conjectures imports none of them. Leaving them out is
therefore enough for a Library module that imports all the rest of Mathlib to be loaded together with
weil-conjectures.

**Rule.** A Library file that needs a declaration of one of the three modules imports that module
explicitly, beside `Langlands.MathlibBase`. Such a file, and every module that imports it, cannot be loaded
together with the part of weil-conjectures that lies above the corresponding module of weil-conjectures
in the table. Nothing is renamed because of these clashes: they are Mathlib's, not the Library's.
-/
''')
dst = os.path.join(ws, 'Langlands/MathlibBase.lean')
open(dst, 'w', encoding='utf-8').write('\n'.join(out))
print(f'{dst}: {len(kept)} imports ({len(imports)} in Mathlib.lean, {len(EXCLUDED)} left out)')
```
