# Borel–Tits 3.22(b): a split D4 obstruction

This is a paper counterexample, dated 16 November 2026, to the mathematical assertion encoded by
`Langlands.GroupScheme.ClosedRootSubsetGroupIntersectionStatement`, in
`Langlands/GroupScheme/Rational/ClosedRootSubsetStatements.lean`. It is not a Lean
proof of the negation of that declaration. The finite and matrix computations
below have been checked with exact integer and rational arithmetic.

The obstruction concerns closed root subsets whose **intersection** is convex.
It does not contradict the separately stated
`Langlands.GroupScheme.ConvexRootSubsetGroupIntersectionStatement`, which
requires both subsets to be convex.

## Group and root subsets

Work over `k = C`. Let `V` have basis
`(e_1,e_2,e_3,e_4,f_1,f_2,f_3,f_4)`, with quadratic form
`q = sum_i x_i y_i`, and put `G = SO(V,q)`. This is a connected split reductive
group. Its diagonal split maximal torus is

`T = {diag(t_1,t_2,t_3,t_4,t_1^-1,t_2^-1,t_3^-1,t_4^-1)}`.

Writing `epsilon_i` for its coordinate characters, its root set is the reduced
system

`Phi = {±epsilon_i ±epsilon_j : 1 <= i < j <= 4}`.

Define

`S = {±epsilon_1 ±epsilon_2, ±epsilon_3 ±epsilon_4}`,

`X = {±epsilon_1 ±epsilon_3, ±epsilon_2 ±epsilon_4}`,

where the two signs vary independently. Each subset has eight roots and is
symmetric. Each is closed under additions that remain in `Phi`: the sum of two
roots on the same coordinate pair is never a root of `Phi`, and the sum of roots
on the two disjoint coordinate pairs has four nonzero coordinates. These are
closed subsystems of type `A1^4`.

They are disjoint. Thus `S ∩ X = empty`, which is convex, witnessed by the closed
convex cone `{0}`. Both displayed subsets themselves span `R^4`. Because they are
symmetric, a convex cone containing either subset contains all of `R^4`, hence
all 24 roots. Consequently neither subset is convex in `Phi`.

## The generated subgroups have a common point outside T

Write `H_S` and `H_X` for the closed subgroup schemes generated by `T` and their
respective standard root subgroups. Such a smallest closed subgroup exists in
the affine group `G`: in its coordinate Hopf algebra take the sum of the defining
Hopf ideals of all closed subgroups containing the generators. The resulting
closed subgroup contains every generator and is contained in every such closed
subgroup, on all test schemes. This is precisely the minimality required in
`IsRootSubsetGroup`.

The centralizer of `T` in `G` is `T`, so the subgroup for the empty root set is
`H_empty = T`.

Let `J` exchange `e_r` and `f_r` for every `r`. It preserves `q`, and
`det J = (-1)^4 = 1`. It is not diagonal, hence `J` does not belong to `T`.
We now exhibit `J` in both generated subgroups.

Let `E_ab` be matrix units in the displayed basis, with the index `4+i`
corresponding to `f_i`. For `i < j`, take the root elements

`x_(epsilon_i-epsilon_j)(t) = I + t E_ij - t E_(4+j,4+i)`,

`x_(epsilon_i+epsilon_j)(t) = I + t E_(i,4+j) - t E_(j,4+i)`.

For each displayed root `alpha`, take `x_(-alpha)(t) = x_alpha(t)^transpose`.
All these matrices preserve `q`, have determinant one, and have the indicated
torus weights. Set

`n_alpha = x_alpha(1) x_(-alpha)(-1) x_alpha(1)`.

Direct multiplication gives

`n_(epsilon_1-epsilon_2) n_(epsilon_1+epsilon_2)
 n_(epsilon_3-epsilon_4) n_(epsilon_3+epsilon_4) = -J`,

`n_(epsilon_1-epsilon_3) n_(epsilon_1+epsilon_3)
 n_(epsilon_2-epsilon_4) n_(epsilon_2+epsilon_4) = -J`.

The first word uses only root elements indexed by `S`; the second only those
indexed by `X`. Multiplying by `-I`, which belongs to `T`, proves
`J ∈ H_S(C) ∩ H_X(C)`.

The test scheme `Spec C` is reduced. Therefore this point contradicts
`HasReducedPointIntersection` for `H_S`, `H_X` and `H_empty = T`, with all the
closedness and intersection-convexity hypotheses satisfied. Replacing a
scheme-theoretic intersection by its reduction cannot remove this field-valued
point.

## Comparison with the Library root functor

The Library's `RelativeRoot.subgroup i alpha` is defined by extension of the
torus-conjugation orbit through the character `alpha`, with value the identity at
zero (`Langlands/GroupScheme/Rational/RootSubgroup.lean`).

In the present example this gives exactly the standard root subgroup used above.
Indeed, over any `C`-algebra, a matrix coordinate of torus weight `beta` can have
such an extension only if `beta` is a nonnegative integer multiple of `alpha`.
Distinct Laurent monomials are linearly independent over the coefficient ring.
The value at zero forces the weight-zero part to be the identity. Among the
matrix-coordinate weights of the standard representation, the only positive
multiple of either displayed root is that root itself, in precisely the two
displayed off-diagonal positions. The orthogonality equations make their
coefficients opposite. Thus the resulting matrix is exactly `x_alpha(t)`.
These coordinate descriptions glue over arbitrary test schemes. The same
weight calculation gives the all-test centralizer `Z_G(T) = T`.

This verifies the mathematical interpretation of the actual functors involved;
the identifications have not been implemented in Lean.

## Block groups, Weyl groups and the printed proof

There is also a familiar block description. With `V_r = <e_r,f_r>`, the
generated subgroups are

`SO(V_1 ⊕ V_2) × SO(V_3 ⊕ V_4)` and

`SO(V_1 ⊕ V_3) × SO(V_2 ⊕ V_4)`.

For each `SO4` block, the torus and its positive and negative root groups have a
dense open big-cell product, which proves this generation assertion. Preserving
both block decompositions forces preservation of each `V_r`. If `d_r` is the
determinant sign on `V_r`, the equations are

`d_1 d_2 = d_3 d_4 = d_1 d_3 = d_2 d_4 = 1`.

The only possibilities are all signs positive or all negative. The intersection
is consequently `T ∪ JT`, with identity component `T`. Thus the example is
compatible with the identity-component assertion in Borel–Tits 3.22(a).

Both reflection subgroups have order 16, and their intersection is
`{Id, -Id}`. The neutral common kernel in `T` of either root subset is trivial,
since each has rank four. The neutral common kernel for the empty intersection
is all of `T`. Thus `-Id` fixes the cocharacters of each of the first two kernel
tori, but does not fix the cocharacters of the third.

The original [Borel–Tits 1965 article](https://www.numdam.org/item/PMIHES_1965__27__55_0/),
registered as `borel-tits-1965-groupes-reductifs`, printed pp.83–84
(one-based PDF pages 30–31), was visually checked. Proposition 3.22(b) as printed
requires only convexity of the intersection. Its proof on p.84 makes the
kernel-torus inference just contradicted. Earlier in the same paragraph, its
identity `G_(psi_s) = Z_G(A)` also fails here: `A` is trivial, so its centralizer
is the whole `G`, while the generated `A1^4` subgroup is proper.

Section 5 of the [1972 supplement](https://www.numdam.org/item/PMIHES_1972__41__253_0/),
registered as `borel-tits-1972-complements-groupes-reductifs`, printed
pp.274–275 (one-based PDF pages 23–24), lists no correction to 3.22.
Its p.84 correction concerns the positivity wording in the proof of 3.24.
This is a check of that supplement, not a claim that no later correction exists.

## Verification and remaining formal work

A standard-library Python checker was written, read and rerun successfully.
It exhausts root-sum closedness and symmetry, computes the
two ranks and finite reflection groups, and checks the Gram matrix, determinants,
two root words, torus correction and determinant-sign equations above using
exact arithmetic. The root and Weyl argument was also checked independently.

These checks establish no Lean group-scheme refutation. A formal refutation would
still need the actual orthogonal group scheme, its maximal torus and root
identifications, the generated closed subgroups and the displayed field-valued
point connected to the Library definitions.

The statement concerned is
`Langlands.GroupScheme.ClosedRootSubsetGroupIntersectionStatement`, which the
Library states and does not prove; this note does not change its statement or
imports. The separately stated, individually convex result
`Langlands.GroupScheme.ConvexRootSubsetGroupIntersectionStatement` (proved in
the Library as `convexRootSubsetGroupIntersection`) is a different statement;
the present example does not satisfy its hypotheses.
